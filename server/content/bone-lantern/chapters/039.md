# 第三十九章 九个人的脚印

青布鞋漂来的方向，与水流相反。

河神庙下游水势向东，鞋底薄铜却在内侧留有连续撞痕，说明它不是顺水漂来，而是被一根水下细索贴着河床拖行。细索在第七码松脱，鞋才浮上水面。沈青崖沿三根标杆测出的倾角，算出拉索的人在南岸芦苇荡里。

芦苇荡没有船，只有一条退水后露出的泥埂。泥埂起初只有一行脚印，向里十余步后变成两行，再往前，湿泥上并排出现九个人的脚印。

九行都很小，像孩童留下的。脚印深浅不同，间距却完全一样，每一步都是一尺八寸；左脚落地比右脚早半指，转弯时同时向外偏。这不是九个孩子自然走出的队列。有人用不同鞋楦套在同一双脚上，一遍遍走过泥埂，制造了九个人经过的样子。

为了排除绳索牵拉木脚的可能，沈青崖让水工查看脚印前后。木脚落地时边缘受力均匀，真人行走则会先压足跟、再推前掌。九行泥印都有连续的重心过渡，且每到第七码，右足前掌会短暂停顿。它们确由同一个活人反复走出。泥层又有先后：最内一行已被昨夜露水填平，最外第九行压破了今晨新结的薄壳。制造脚印的人至少来回走了九次，并刻意让最后一行看起来最新。

裴照川蹲下看最外一行：“鞋可以换，步幅和重心难换。”

沈青崖用九根细竹标出每行足心。第一行鞋底平，第二行前掌缺角，第三行有两枚并列铜钉；外形各异，足心压力却都集中在左侧。走路的人右膝不敢完全伸直，不是右脚外翻的死者，也不是左脚拖步的面具人。

第九行脚印更新。泥边还没有塌，鞋跟刻着半个月形缺口。晏九低头看自己的鞋，右后跟恰少了一块皮。

他立刻后退，脚印落在干处。裴照川让他脱鞋比对。月形缺口宽窄相同，钉孔位置却不同；泥中那枚脚印比晏九的鞋短半寸，缺口也在皮层内，不是他刚才踩下。

“有人照着我的鞋做过一双。”晏九说。

“或者你的鞋照着它补过。”沈青崖检查他鞋跟。缺口边缘已磨圆，补皮下压着一缕褪色红线，缝法从下向上收针，与顾不言那本旧黑册相同。晏九说鞋是棺材铺掌柜三年前给他的，掌柜只说从慈安堂旧物堆里捡来。

三年前，又是三年前。

泥埂尽头立着一座废弃疫所。门板已经拆走，门槛却并排开着九道浅槽，每一道都能容一双小脚。槽内撒过石灰，石灰下有薄薄黑泥。沈青崖取样后发现，前八槽的泥来自十八年前沉城县志楼，只有第九槽混着近三年的奉安城墙白浆。

有人把不同年代的材料带来，重新铺过第九个位置。

疫所里没有病床。东墙钉着九块齐肩高的木板，板上没有名字，只画着九种动作：写字、听声、辨味、系结、量骨、记路、认钱、背诗、回头。每块木板下都有一双鞋槽，槽后接细铜管，铜管汇入屋中央一只空椅。

西墙还有一列被刮去的刻度。沈青崖用侧光看出刻度原先记录身高，每条旁边都写着日期。九名孩子在半年内只量过一次，空椅的位置却每隔七日调整，说明这里关注的不是他们是否长大，而是换一个人坐上去后，动作能否仍被同一声音引出。最下方留有一句未刮净的医嘱：“不应者停药，先问其惧。”字迹早于其余板书，后来又被“加量”二字覆盖。

早期记录仍把恐惧当作病情，后来的执行者却把恐惧当成了开关。

椅背有九道皮带压痕，却只能坐一个人。

晏九没有靠近。他把黑册放在窗台上，手指仍沾着昨夜抄录的墨。风翻动纸页，册子先停在“邵准”残字处，又向后翻过八页，露出九种明显不同的笔迹。有的字向左斜，有的收笔带钩，有的每写一个“口”便缺右下角。

“我抄的。”晏九说，“都是我抄的。”

沈青崖让他在不看旧页的情况下写同一句话。晏九平日左手执笔，第一遍字快而窄；听见铜管中传来三短两长后，他手腕忽然内扣，把“河”字三点写成了不同粗细。那种收笔方式与旧册第三种笔迹相同。

她立刻让人堵住铜管，不许再敲。动作被声音引出，只能证明晏九身体里存在一种受训反应，不能证明那段记忆属于谁，更不能把九种笔迹当作九个人同时说话。

空椅坐面下藏着一只浅匣。匣中有九枚蜡片，每枚都压着半枚足印。前八枚已经干裂，第九枚仍有柔韧，蜡中夹着一根少年黑发。黑发没有毛囊，不能验明血缘；蜡片边缘却有与两本黑册纸页一致的纤维，说明册子曾在这里被拆分或装订。

浅匣背面粘着一层药纸。药纸上列有九种不同反应：有人听见水声会闭眼，有人闻到桂叶会数指节，有人摸到旧钱便把拇指压在方孔左侧。第九行只有一句“见无名者即书”。晏九看见无名尸便记册的习惯，也许不全出于他的决定；可三年来每一次是否落笔、写下什么、是否更正，仍是他在现场做出的选择。训练可以留下冲动，不能替后来的人承担所有行为。

裴照川检查墙后。九根铜管并未直接连接河神庙，而是先经过一只分音匣。水流敲击一次，匣中九枚簧片依次震动，每片会改变一点音色。坐在椅上的人听见的不是一声河响，而是九种不同方向、不同高低的提示。

“让一个人学会九种反应。”他说。

“或把九个人留下的反应装进一个人。”沈青崖道。

这仍是两种解释。疫所没有尸骨，也没有九名儿童的完整名册。木板动作可以用于治疗患梦者，也可以用于制作活锚。必须找到受训者留下的身体证据，才能判断这里发生过什么。

后院井中有一层干燥木灰。灰下埋着九双旧鞋，每双只剩一只，另一只不知去向。鞋内没有姓名，只有年龄与动作编号。第一双标“六岁，认钱”，第九双标“十一岁，记名”。鞋楦尺寸并不相同，证实九行泥印所用鞋子至少来自九个不同孩子；相同步幅则是后来由一个人重新踏出的。

第九只鞋的鞋垫下压着一张棺材铺收据。日期是三年前，收件人一栏先写“九号”，又被添成“晏九”。添上的“晏”字墨色更深，笔势属于顾不言。

收据背后还写着两笔费用：一笔是旧鞋修补，一笔是“拒用药”。后者被掌柜朱笔圈过，没有收钱。若记录真实，至少在交到棺材铺那天，有人拒绝继续给九号使用忘尘；但拒绝者是晏九本人、顾不言还是掌柜，纸上没有主语。沈青崖把这四字单独拓下，不把它提前写成一次获救。

晏九盯着那两个字，半晌没有说话。

“九不是排行？”裴照川问。

“可能是位置。”沈青崖把收据封好，“也可能后来才被当成排行。纸只能证明有人把九号改写为晏九，不能证明现在的你来自哪一个孩子。”

井壁上还嵌着一排薄木片。前八片画着不同面孔，水汽已经把五官泡散；第九片空白，只留一圈脸部轮廓。轮廓尺寸与十一岁孩子相合，内侧却刻着九个极小的动作符号。

沈青崖没有让晏九把脸贴上去。她用软纸拓下刻纹，发现“记名”符号下还有一枚被磨去的第一号印。九号不是从第九个人开始，也许是把前八个位置收在最后一个人身上。

夕阳穿过疫所破窗，九道木板影子落在空椅上，最后只剩一张坐席。

晏九合上黑册：“若这些笔迹不是我的，我写下的名字还算数吗？”

“字是谁教的，与落笔时谁承担它，不是同一件事。”沈青崖说，“先找第一双鞋的主人。”

裴照川在第一块动作板背后找到一道活动木榫。木榫松开，板中落出一片薄如蝉翼的白蜡。白蜡上压着半张少年的脸，左眉断开，嘴角有一道旧裂伤。

晏九没有见过那张脸。

可他抬手时，指尖准确碰到了自己左眉同一位置。
