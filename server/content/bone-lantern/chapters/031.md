# 第三十一章 一夜归还

城墙上的黑蜡在子时后停止生长。

它没有变硬，仍保持被体温触过的柔软，只是不再向皇城方向延伸。七处旧门前的喊声也低了下来，守卒把三块白牌分别立好：愿承接、先听后决定、拒绝。最初有人把三块牌全举起来，后来书吏解释只能选一块，门前才渐渐安静。

沈青崖在最高处设了一张长案。案上没有香，也没有灯，只摆着六枚黑蜡、六张动作图、三十七份当夜证词和一卷空白登记册。她把入口页压在白布下，防止城墙的余振直接碰到纸面。

“第一枚对应谁？”裴照川问。

晏九把西库门外的石屑图摊开。六枚黑蜡的底部各有一道不同宽度的裂口，宽窄与六名被救者站过的门缝相合。最窄的一枚属于薛穗，她当时被推到门外，离火场最远；最宽的一枚属于一个不愿公开姓名的老人，他曾用肩顶住门轴。顺序不是按年纪、地位或谁最先喊出裴应，而是按人离开时实际站立的位置排列。

“不能只按图开。”沈青崖说，“还要问持有者。”

六位被救者被分置在六处门旁。薛穗举起先听后决定的白牌，缺腕疤的老人举了拒绝，其余四人一人愿承接，三人同意先听。没有人替他们作答。门内两名许兰和门外柳兰也各自选了牌，孩子阿满没有被要求选择，只被带到没有黑蜡的安全屋里。

第一枚黑蜡在冷水中显出一层薄光。沈青崖没有点照骨灯，只让两名书吏隔着铜片听取其中的声音。声音不是人的完整说话，而是木门受力时的摩擦、孩子鞋底在灰里的拖动和一声被压住的咳嗽。薛穗听完后没有认出裴应，只说那一夜确实有人从内侧推门。

她选择不承接。声音被重新封回蜡中，蜡面留下一个小小的凹点，像有人按下拒绝的指印。城墙外层头发线随之退开半寸，没有任何陌生记忆进入薛穗的身体。

第二枚黑蜡属于愿承接的老人。开封前，沈青崖让他先说出自己的病史、旧伤和最害怕听见的声音，再由书吏记录。老人说自己怕孩子敲门，因为每次听见都会想起一扇打不开的门。蜡中传出的却是铁链拖地声，和他的预期不符。它确实保存了当夜感知，却没有替他决定意义。

老人听完仍选择承接。黑蜡化成一线灰黑，沿他手背的旧针孔沉入皮下。他没有立刻哭，也没有喊出名字，只用左脚抵住地面，右手向身后摆了一下。那是六人共同保留的动作。片刻后，他说自己记起门外有一只缺耳木马，却不记得木马属于谁。

沈青崖让他停下，不许继续追问。承接后的情绪会把空白染上颜色，若此时逼他补全姓名，便是在制造新的伪证。

第三枚黑蜡开启时，城下传来一阵争执。有人举起愿承接的牌，又被亲属按下；有人拒绝后，旁边的人骂他忘恩。裴照川让巡夜卒把争执双方分开，记录争执发生的时辰和具体用词，不允许以家属关系替代本人选择。

“他们会说拒绝的人自私。”晏九道。

“那就把这句话也记下。”沈青崖说，“将来谁想把拒绝写成罪证，先得面对今天的记录。”

第四枚黑蜡中出现一段白衣记录官的手势：三指按纸、拇指压住页角、右腕向内折。手势与户籍房火灾现场留下的烟熏纸痕相同，却没有脸。沈青崖让书吏把手势摹下，与秦庐旧伤、复核印的年改痕分别比对。它能证明同一套抄录动作曾在不同地点出现，仍不能证明操作者是谁。

第五枚黑蜡没有声音，只有一阵持续的冷。开封后，三名拒绝承接的人同时说自己左肩发麻，却没人看见任何影像。沈青崖检查他们的脉搏、瞳孔和皮肤温度，发现城墙横向衣线在五息内收紧，像把未归还的感知停在门外。她命人撤下铜片，冷感随即消退。

“记忆也会被拒绝挡在外面。”裴照川说。

“挡不住所有。”沈青崖看向第六枚蜡，“但至少让它知道有人不愿意。”

第六枚对应那名抱孩子、从未回头的被救者。黑蜡管壁有新鲜指甲痕，说明有人在昨夜试图提前打开。沈青崖先让六名被救者互不见面，再由两名书吏同时记录。蜡中出现的不是开门，而是一只小手在墙上写下一个没有完成的“沈”字，写到竖钩便停。紧接着，另一个成年人的手把纸收走。

薛穗在远处听见摩擦声，举起了先听后决定的牌。她没有说那是沈照，也没有说那是周谨的女儿。她只问，写字的孩子是否自己愿意把纸交出去。

没有人能回答。

沈青崖把第六枚重新封好。她不让未完成的字成为寻找某人的强迫令。可她在蜡管底部发现一粒朱砂，朱砂里夹着极细的麻线，线结右侧留活眼，结法与周谨女儿头发上的结相同。它提供了新的方向，却仍不是一个可以代替当事人的名字。

子时将尽，六枚黑蜡只打开五枚，最后一枚留在铜盘内。闻如晦终于从太史局屋顶下来，站在白牌之外。

“你没有按入口页。”他说。

“入口页只决定次序，不决定谁必须承接。”

闻如晦看着老人手背那条灰线：“若明早一起冲破，后果由谁负责？”

沈青崖把责任栏空着的登记册推给他：“先把会冲破的证据写清楚。负责不是替别人同意。”

闻如晦没有接册。他看向第六枚黑蜡，轻声说：“还有一枚不在城墙上。”

“在哪里？”裴照川问。

“在一个不肯承认自己被救过的人手里。”

他没有再说。远处城门传来第一声未完成的钟响，黑蜡表面同时裂开细纹。最后一枚没有被打开，却开始自己发热。

沈青崖让人把那枚发热的蜡管放入三层冷水。第一层水面浮出细小油膜，第二层水底出现七个针尖大小的蓝灰沉淀，第三层没有任何变化。她分别取样，标明取样时间和水温，再请不知案情的郎中闻气味。郎中只说像旧书受潮后的蜡，并不能判断里面存的是什么。她把“不能判断”也写进记录，免得日后有人把沉淀解释成某个名字。

蜡管外壁那五道钥匙痕中，第四道最深，说明开启者曾在第四次尝试时停手。管口附近还粘着半片青布，布纹一横三竖，和周谨旧衣的补丁不同，却与慈安堂收容衣料相同。晏九找到衣料账，承熙五十八年曾发给七名儿童各一件青布短褂，编号只有一、二、三、四、五、六，七号一栏被整页裁去。

“第七枚蜡不是没有主人。”他低声说，“是主人被裁掉了。”

沈青崖没有让他把七号写进名单。她让晏九把衣料账、裁纸边和蓝灰沉淀分别封存，注明它们只能证明某批儿童曾被同一处发衣，不能证明七号仍然活着。身份不能靠缺失的一页自动长回来。

闻如晦听见后，终于承认当年曾在太史局见过七号短褂。他说那孩子在登记时拒绝回答姓氏，只在纸上画了一盏没有火的灯。记录官便把她列为“待补”，后来西库失火，待补栏全部改成空白。

“你当时为什么不留下画？”沈青崖问。

闻如晦看着第六枚黑蜡，声音仍旧平稳：“我以为没有姓名的图案不能成为证据。”

“所以你把它删了。”

“是。”

承认没有让他的决定变得正确。沈青崖把这句口供记入闻如晦个人证词，不与城墙蜡线混为一证。夜色渐深，五枚黑蜡已冷，城中有人选择带着一段陌生冷意回家，有人选择一无所知。剩下那一枚，在冷水里仍有微弱脉动，像一颗不肯替自己发声的心。
