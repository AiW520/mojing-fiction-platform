# 第四十章 晏九的第一张脸

白蜡上的脸不是晏九。

少年鼻梁更低，下颌较宽，左眉中段有一道缺口，嘴角旧裂延伸到唇外。蜡片只保存表面起伏，不能说明少年死活，也不能证明晏九方才摸向左眉是记忆所致。他可能刚看见缺口，也可能被沈青崖的目光提示。

沈青崖把蜡片转到他看不见的一面，让裴照川依次报出五个错误位置：右眉、鼻翼、下唇、耳后、左眉。每报一处，晏九便在纸人上点一处。前四次他的手随问题移动，最后听见“左眉”时，指尖却先落在嘴角。

白蜡少年真正更深的伤在嘴角。

反应可以重复，却仍不是身份。沈青崖让他停下，不再用更多提示逼身体作答。

第一块动作板标的是“认钱”。板后除了白蜡脸，还有七枚南陵旧税钱。钱币年份相同，铜锈轻重不同，其中一枚被锉薄了半分。裴照川混入三枚奉安钱，请晏九闭眼只凭重量分辨。晏九平日不会称钱，却连续挑出六枚南陵钱；最后一枚锉薄的钱被他归到奉安一侧。

“不是认图样。”他说，“手里觉得它应该更重。”

身体记得某种训练，记忆却只留下错误发生前的标准。这说明白蜡少年可能长期数过南陵税钱，也说明有人把他的操作习惯留在晏九身上。它仍不能证明两人是同一具身体。

裴照川派人去查南陵旧疫所的给药账。账册正本沉在县志楼，村中却保存着一份柴米副簿。承熙五十七年，疫所收过九名无籍少年，年龄六至十二岁。副簿不记姓名，只记饭量、旧伤和分配动作。第一号十一岁，左眉断疤，唇裂，负责辨认被磨薄的药钱。

年龄与井中鞋签不符。鞋签写第一双六岁，认钱；副簿却写第一号十一岁。说明动作、编号和鞋并非固定属于一个人，后来有人重新排列过九个位置。任何一件单独物证都不足以把第一号还原成一个孩子。

柴米副簿末页夹着一张赊账条。少年曾替疫所去村口买盐，少付一枚被锉薄的钱。盐商在纸上画了他的脸，并写：“阿枣，左眉破，欠一钱。”这不是官籍，只是一次欠账，却有日期、盐量和盐商后人的旧账连续支持。

阿枣可能是白蜡少年的称呼。

晏九看着那两个字，嘴唇动了一下，没有喊出来。他说自己忽然想起一只盛枣的竹篮，篮底破了，枣滚进泥里。记忆里没有人脸，也没有声音，只有一双手把最干净的一颗塞进他袖口。

“是他的记忆？”裴照川问。

“可能。”沈青崖说，“也可能是白蜡、称呼和旧钱共同诱发的补全。先找现实中的竹篮。”

盐商家后墙果然挂着一只旧篮。篮底补过三次，最早一次用的是疫所白麻。盐商之孙说祖父每年都在账上替一个叫阿枣的孩子留一枚钱，直到十八年前河水淹没疫所。旧账连续七年，阿枣的欠款没有增加，说明那次买盐可能是他唯一一次独自来村里。

现实材料只把白蜡脸与阿枣连在一起。至于阿枣如何进入晏九的动作和感知，答案仍在疫所空椅。

他们拆开分音匣。九枚簧片背面各刻一个字，不是姓名，而是人会使用的能力：钱、声、香、结、骨、路、数、诗、名。簧片末端粘着黑蜡，蜡量不足以保存完整人生，更像从不同记忆锚物上刮下的碎屑。九股细线最后汇入椅背的一枚空针孔。

“活锚。”沈青崖说。

正历需要有人保存被删去者之间的关系。纸会烧，官印会改，尸骨只能照一次；活人却可以带着动作行走。有人把九名少年的技能、气味、恐惧与关系碎片，经声音和反复训练压进一个承接者，使他成为能在各处认出锚物的人。

分音匣底部还有一张操作次序。最初版本要求每次训练前由受训者在圆孔旁按指，拒绝便停；后补的朱字却把“按指”改成“按位”，只要位置上有人，流程便可继续。一个字的变化，把人的同意改成了席位是否空缺。墨层检验显示，朱字晚于沈问渠司忆官印，却早于三年前“顾收”补刻，说明强制并非从最后一次启用才开始。

晏九问自己的指印是否在纸上。沈青崖没有让他立刻按手比对，只先拓下旧印。旧纸承载过多人触摸，贸然叠上新指印会污染唯一的原始材料。知道自己可能在其中，不等于必须当场交出身体来证明。

这不是九个人复活。也不是一个孩子拥有九条命。每一段记忆都带着原主的偏差，承接者仍有自己的身体、经历和选择。

“我是哪一个承接者？”晏九问。

疫所材料不能回答。第九槽混有三年前奉安白浆，顾不言也在三年前把棺材铺收件人的“九号”改作“晏九”。最多只能确认，现今晏九曾在三年前接触这套装置，或在那时被带到奉安。此前的身体来历、原名和是否自愿，仍无证据。

沈青崖没有把阿枣写进晏九的姓名栏。她新开一页，标题写“白蜡少年一号，村称阿枣”，下面列出左眉疤、唇裂、南陵税钱、盐账和竹篮。另一页仍写“晏九，棺材铺学徒”，记录他三年来亲手抄下的无名尸、修过的棺绳和今日选择停止测试的时辰。

“两页不合并？”晏九问。

“没有证据可以合并。”

“若以后找全了呢？”

“也先问你愿不愿意。”

晏九把两册黑册并排放在桌上。旧册中，阿枣出现过一次。不是姓名，而是一条十八年前的记录：无籍少年替疫所送回七枚错钱，拒领赏钱，请换一张可以写字的纸。记录者在旁批注“第一锚可用”。

那句话把一个孩子的善意改写成了材料性能。

晏九用自己的笔在批注下添了一行：“他要纸，是想写字，不是同意被使用。”墨没有褪去。两册黑册都安静地停在这一页，没有自行补出阿枣的脸。

他又在新册首页写下今日日期，声明在查明承接过程前，拒绝任何人以阿枣或九号称呼他。裴照川以巡夜司身份签作见证，沈青崖只记录他书写时意识清楚、未接触忘尘。三人的字并排留在纸上，使这一次选择不必依靠将来可能改变的回忆。

夜里，郎中完成白蜡检验。蜡中没有尸蜡，只有活人皮肤留下的油脂和少量忘尘花粉，说明面模可能在少年活着时制作。左眉凹痕内有一根短发，发根完整，却已无法与十八年后的晏九直接比对血缘；即便相似，也只能说明身体关系，不能说明记忆归属。

裴照川在疫所梁上发现九道刻痕。前八道旁各有一道斜线，表示已经送出；第九道旁没有斜线，只刻着“顾收”。顾可以是顾不言，也可以是河道旧仓的字号。刻痕新旧分两层：九个编号属于十八年前，“顾收”却是三年前补刻。

三年前，顾不言或使用顾字号的人来过疫所，带走了第九位置的承接者，也带走了两本被拆开的黑册。此人为何选择晏九、是否获得同意，仍然没有答案。

沈青崖把“顾收”拓片封存，没有告诉晏九应当恨谁。顾不言可能救了他，也可能延续了活锚试验；在找到三年前的路线与见证人以前，两种可能都必须保留。

晏九把白蜡脸放回木匣。他没有称那张脸为自己，只对着匣中少年说：“我先替你记着阿枣。等找到你愿意留下的名字，再换。”

这是晏九第一次拥有一张来自过去的脸，也是他第一次没有急着把那张脸戴到自己身上。

众人准备离开疫所时，第九块空白面板背后传来纸张滑落声。一页浸过药水的病历掉进灰里，上面并列九行脉案，每一行都写着相同结语：患梦者，逆流送回。

病历最下方盖着沈问渠的司忆官印。
