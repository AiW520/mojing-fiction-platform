# 第十九章 镜中供词

尸体的影子指向北门内侧一堵空墙。

墙后原本是条巷子。城工图上写着照衣巷，承熙大火后封闭，三年前北门塌墙时又被落砖填死。如今墙面完整，没有门洞，雨水却在砖上勾出一条街的轮廓：檐角、窗格、井栏，甚至还有一个撑伞人的淡影。

沈青崖把烧黑铜镜立在墙前。

镜中没有他们。

里面映出的正是照衣巷。天色比此刻更暗，雨从相反方向斜落。两个男人抬着木料穿过巷口，一个右肩抬不高，一个走路时习惯用左手扶墙。三名女人先后从同一扇门里出来，各抱着一个看不清脸的孩子。

守门校尉低声说：“镜子记得那条街。”

“镜子不记事。”沈青崖道。

她用纸遮住镜面上半部。照衣巷的屋檐随之消失，下面的脚步仍在移动；再遮住镜背刻痕，画面立刻偏斜。镜中景象依赖镜面分区和背后铜纹，不是一个完整记忆。有人把不同人看过的片段分层嵌入银膜，雨水和钟振一到，便拼出一条似乎连续的街。

这条街可以提供线索，不能作证。

沈青崖又做了两次验证。她让宋延的副手站在镜前举起三根手指，镜中人隔七码才抬手，举出的却是两根；换晏九站过去，镜中仍先出现那名副手的袖色。镜面不是即时映照，而会从附近锚物中挑一段最容易与眼前动作相合的旧片段。观看者越期待看见什么，银膜中对应的一层越亮。

裴照川命人凿开空墙最下方一块松砖。砖后确有空腔，探杆送入两丈才触到另一面木墙。杆头带回陈年油烟、稻壳和蓝色墙灰，与镜中屋门的颜色相合。照衣巷作为物理地点真实存在，但镜中撑伞人和三名抱孩子的妇人是否曾同时出现，仍无从证明。

他们在镜架四角各系一根细线，标出观看角度。正对镜心只能看见户籍吏，左移一步出现两名工匠，右移一步才有妇人。所谓一段完整供词，其实是七层互不相连的证言被镜片强行拼接。若不记录站位，同一个证人重复观看，也会得到不同答案。

三名女人被分别安置。抱孩子的女人已承认自己叫柳兰，却不记得住处；眉尾藏骨纸的女人坚持自己是许兰；门外提木盆的女人也叫柳兰，有槐安巷邻里和半枚青瓷扣可以核验。为免彼此叙述污染，裴照川让三处问话相隔两道院墙，由不同书吏记录同一组问题。

第一问：北门塌墙时你在哪里。

抱孩子的柳兰答，在家给阿满煮粥。许兰答，在墙下给丈夫送冬衣。槐安巷柳兰答，在工棚替伤者洗泥。

第二问：许望临死前说了什么。

第一人答“带孩子走”，第二人答“墙里有人”，第三人答“把木盆拿回去”。

第三问：不在场的人是谁。

三张供纸上都写了同一个名字：许成。

没有人承认先听过它。

沈青崖让书吏把供词折起，只保留落笔顺序。三人写“成”字时都先写了中间一竖，再补横画，和常规笔顺相反。她们不是各自想起同一个名字，而是曾看过同一份由左手书写的样本。

晏九在铜镜背面找到了这个字。它藏在北门方位刻线之间，被磨得只剩中央一竖。沿那一竖向下，是七个小格，格内分别刻着“夫”“妻”“母”“子”“长”“亡”和一个空白。

“这不是街图。”他说，“是关系格。”

沈青崖以薄纸拓下。七格的间距与百骨簿入口页相同，却没有姓名。镜子保存的不是谁住在哪间屋，而是谁被允许以何种身份记住另一个人。

他们把三份供词轮流放到镜前。

抱孩子的柳兰那一页出现时，镜中第一个男人回头。他右肩抬不高，嘴唇动了三次。镜面没有声音，晏九却从口形读出“阿满走”。许兰供词出现，第二个男人左手离墙，在雨里写了一个“柳”字。槐安巷柳兰的供词出现后，镜中两人同时消失，只剩一名户籍吏在门内盖印。

印落下的位置，正是“许成”二字。

裴照川问：“能认出户籍吏吗？”

三名女人给出三个名字。守门校尉又说是第四个人。镜面把观看者已有的印象补到那张脸上，与云来客栈那个不存在的客人一样。若他们凭多数抓人，只会抓到被最多人记住的替身。

沈青崖不再看脸。她看户籍吏落印的手。

左手袖口短了半寸，腕内有一道烫伤；印盒放在右侧，蘸印时需要跨过整张纸；每盖一次，拇指都会在桌沿留下半枚红痕。这些动作不会因观看者不同而改变。

户籍房有三十二名书吏。裴照川让人不报姓名，只取近三年值房桌案与冬衣尺寸。半个时辰后，巡夜卒送来一方旧桌角和一册衣物簿。旧桌右沿积着重叠朱砂指纹，冬衣记录中只有一名左手吏连续三年要求左袖加长、右袖减短。

此人名叫陈沐，四十岁，承熙大火后由太史局转入户籍房。

他没有逃。巡夜司在照衣巷封墙另一侧找到他时，他正坐在一间没有门牌的旧屋中，对着空墙誊抄供词。桌上共有四十七份，每一份问的都是同三道问题。回答者姓名不同，“不在场的人”却一律写许成。

陈沐的左腕有烫伤，旧桌朱砂纹与他拇指指腹十处细分叉相合。他承认三年前为北门塌墙案改过户籍，却说自己只是照抄镜中供词。

“镜子不会承担伪证罪。”裴照川说。

“可镜子比人稳定。”陈沐望着墙上的雨痕，“人今天说丈夫叫许望，明天便说叫柳渡。有人记得生过孩子，有人连自己是否成亲都忘了。官府总要选一个版本。”

“所以你选了最方便结案的？”

“我选了能让最多人活下去的。”

北门塌墙并非单纯事故。墙下压着两户参与修缮的匠人，名册却只准报一户伤亡。若报两名工匠，城工司私换承重木的事会暴露，整段城防都要停工问责。陈沐接到命令，把许望与柳渡的工籍合成一人，把两名妻子并成一个寡妇，再加一个已经夭折的长子，使两家的房契、抚恤和亲属关系能够在账面上闭合。

“抱孩子的人是谁？”沈青崖问。

陈沐摇头：“账上没有她。”

“那就是你删掉的人。”

“不是我。”陈沐第一次提高声音，“我只合并死者。活人是镜子自己补的。”

他说完便后悔了。

沈青崖把这句话记下，却不当作事实。她检查桌上供纸。最早一份纸龄十八年，边缘有太史局金粉；最新一份墨迹未干。四十七份并非陈沐三年内所写，而是从承熙大火前便持续积累。纸角都有同一种针孔，正好能固定在铜镜七格上。

每份供词背面还盖着一枚极淡的印：镜证不得独用。

太史局最初制定规则的人知道镜中所见不能成为唯一证据。后来使用它的人，却把警告藏在纸背，把镜像当成修改现实的底稿。

沈青崖问：“原始户籍和塌墙尸骨记录在哪里？”

陈沐看向自己左手。腕上烫伤突然渗出黑水，像有一行字从皮下融掉。他急忙用右手按住，仍有两个字在伤口边缘显出来。

长子。

“去查许成。”他说，“先证明他没有出生。”

墙上的照衣巷在这一刻亮起灯火。镜中每一扇门都打开，门后却站着同一个七岁男孩。

男孩没有脸，手里各捧一张写着不同父母的户帖。
