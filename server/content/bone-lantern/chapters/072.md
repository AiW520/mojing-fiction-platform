# 第七十二章 晏九作证

第三十二日午后，晏九第一次坐在义庄正厅的证人席上。

席位不是官署的高椅，只是一张与验尸案板等高的木凳。沈青崖把他的现用称谓、可撤回范围、身体状态和证物选择写在四张纸上。晏九看了一遍，说不愿被称作证人。他愿意作证，却不愿让“证人”变成一种固定身份。

于是宋延把标题改成“本人愿意说明的部分”。

来问的人有太史局书吏、刑部一名无署名记录者、三位街坊和昨夜承接三息的闻夫人。裴照川站在侧边，不坐审讯位。沈青崖先问晏九是否愿意让所有人听见。晏九说愿意，但每个人只能复述自己听见的范围，不得把他的动作、阿枣、七号或九号拼成一个原名。

第一件证物是九枚动作木片。木片上没有姓名，只有拒名、撤回、再问、停步、回头等动作槽。晏九说自己会把木片按顺序摆好，但不认为这些动作属于同一个人。有人问那九个位置是不是九名少年，晏九说他只能确认自己做过其中三种动作，不能确认每种动作的原始执行者。

他把“拒名”木片放到左边，手指在边缘停了三次。沈青崖问这三次停顿是否表示他犹豫。晏九说不是，他只是确认木片的缺口方向。这个回答被记录为动作说明，不被扩展成心理证词。

第二件证物是南陵旧疫所的九行病历拓本。拓本有沈问渠司忆官印，记录“逆流送回”的九个操作位置。书吏问晏九是否就是第九位置的人。晏九没有回答。他先问自己是否可以拒绝这个问题。沈青崖说可以，拒答会记录为未答，不会被改成否认或承认。

晏九说，他愿意确认自己曾在南陵旧疫所学过一种逆流动作：先把盛水的碗推向病人，再在病人回头前收回。他不愿确认动作属于“第九位置”，也不愿确认自己是阿枣、七号或任何病历中的人。书吏要求把这段话列为“身份待定”，晏九说他只同意“动作已确认，身份未确认”。两种文字分列。

第三件证物是晏九自己的小册子。册中许多名字只剩半笔，页边却有他每天留下的现用称谓。晏九说小册子可以公开看纸边、墨色和撤回线，不可以抄走任何已撤回的称谓。街坊中有人说，只要名字曾经写过，就不该让它消失。晏九看着那人，说写过不等于拥有，保存也不等于可以随时索取。

他翻到一页空白，指着页脚一枚小小的三角缺口。那是他三日前自己剪下的。他说当时有人要求把“原名不得归还”改成“原名待补”，他不同意，便将页角剪开，表示这条记录可被查看，但不能被补写。剪口本身没有名字，也不能证明是谁提出要求。

太史局书吏问：“你是不是害怕知道自己的原名？”

晏九看了他一会儿，说：“害怕和不愿意不一样。我可以害怕，还可以不愿意。”

这句话被问者本人同意公开。闻夫人将其重复一遍，先报自己的现用称谓，再说只复述原句，不替晏九解释。街坊之一想把“害怕”写进心理栏，晏九拒绝。沈青崖让他亲自划掉，保留划痕，不把划痕当成他否认害怕。

第四件证物是第七十章三息记录。记录中写着晏九流泪、未听见声音、蜡面左弯压痕和三息后恢复。书吏问流泪是否证明他承接了某个少年的记忆。晏九说不知道，也不同意别人替他把身体反应命名。沈青崖补充，流泪可以由气味、刺激、情绪或黑蜡残片引起，现有记录只能证明发生过，不能证明来源。

晏九却主动补充一件事。他说第三息时，他想起一只白碗，碗沿缺了半圈；这只碗可能来自旧疫所，也可能只是陶盒潮气让他联想到某个器物。他愿意把“白碗感知”列为本人感受，不愿把它列入九行病历。这个选择使证言更窄，却更可靠。

刑部记录者问他，若有人因为他的证言被追捕，他是否愿意承担后果。晏九回答，他愿意承担自己确认的动作、纸张和选择，不承担别人从空白里推出来的身份。记录者要求把“后果”写入责任栏，晏九说可以写“责任范围待本人再次确认”，不写成无限承担。

午后，街外又有人敲门。三下，停两息，再一下。晏九抬头，说这个节奏不像自己记得的旧疫所敲门。他愿意确认听见木门振动，却不愿确认门外是同一个送半片黑蜡的人。裴照川用指骨比对，发现振动从门板左下方传来，位置比昨夜高一寸。两次敲击不构成同一人证据。

沈青崖问晏九是否要停止作证。

晏九看向自己的小册子。他说愿意再说一件事：自己不是九个人的总和，也不认为自己必须从九个位置里挑一个原名。他可以拥有借来的动作、后来学会的字和今日选择的称谓；这些部分彼此相连，却不自动合成一个被删除的人。

正厅里安静下来。书吏想插话，闻夫人先说请等本人说完。书吏没有回答，沈青崖把他的停顿记作未答。晏九继续说，他愿意让未来的保管人查阅小册子，但每次查阅都必须留下目的、范围、期限和撤回方式；若查阅者只想知道“他原来是谁”，他不授权。

这段话由晏九亲自写下，又由三名在场者分别确认只见到他写字。没人替他补上原名。

作证结束时，晏九把九枚木片收回盒中，保留“拒名”在最上层。他问沈青崖，这样算不算把自己从旧案里救出来。

“不算。”沈青崖说，“你只是把自己能承担的部分说清楚。”

晏九点头。他把“晏九”写在证言末尾，旁边画出一条可撤回线，又在下一行写：撤回今日称谓，不撤回今日作证动作。墨迹未干，门外的敲击声停了。

没有人知道门外者是否听完。正厅里的每个人都知道，晏九已经在自己的范围内作证，并拒绝让沉默之外的空白替他命名。

沈青崖把晏九的证言抄成三份：一份留在义庄，限定查阅目的；一份交给晏九本人，可随时撤回未公开部分；一份封入三锁档案室，只有本人、独立保管人和经本人认可的审查者可以开启。抄写者的笔顺、页边缺口和墨色分别登记，任何一份都不能替代另外两份。

书吏离开前要求在封面加盖新正历印。晏九拒绝，并说明官印白化后仍可能保留事实，却不能替本人扩大授权。书吏没有回答。沈青崖将他的未答写在封面背面，和“拒绝盖印”并列，不把一个人的沉默压过另一个人的明确选择。

晏九在门口停了一会儿，问沈青崖如果有一天他撤回“晏九”这个称谓，是否还可以继续来义庄抄录别人的证言。沈青崖说可以，前提是每次先问当事人的查看范围。晏九便把这句话写进自己的小册子，旁边添上日期和“可撤回”。他没有把未来的自己锁在今天的名字里，也没有因为名字可能改变，就否认今天作证的事实。

裴照川把门外两种敲击节奏画在纸上，问晏九是否愿意判断它们是否来自同一只手。晏九说不愿意，因为他只听见振动，不知道手的形状，也没有看见门外者。这个拒绝被记录为证言边界。三人共同把门缝下的灰、石板位置和敲击间隔封存，等待下一次本人选择，而不是等待一个方便的原名。

晏九作证后的第一件事，是要求看三份抄本如何分装。他先核对每份纸的页码、缺口和墨线，再问保管人是否可以只读动作栏而不读称谓栏。义庄保管人回答可以，三锁档案室则要先写明目的、期限和归还方式。晏九说这两种限制都应写在封袋外，不能让后来的人以“已经封存”为由扩大查看范围。沈青崖照录原话，未把要求改成制度性的命令。

书吏指着其中一份抄本，说三份文字相同，查哪一份都一样。晏九摇头。他指出第一份保留了自己划掉的半个“怕”字，第二份只抄录划痕位置，第三份连划痕也要在本人许可下才能看见。文字相同只是内容层，授权范围并不相同。书吏沉默，闻夫人请他先说明是否愿意接受这个差别。书吏没有回答，沈青崖把未答写在抄本旁，不让未答变成默认。

晏九还要求把证言作废的条件写清：若抄本被私自补写、撤回线被剪断、查阅目的与约定不符，相关部分暂停使用，但已经发生的见证动作仍保留。有人问这是否等于让任何证据都可被推翻。晏九说不是，事实和授权是两栏；一栏受损，不应拖另一栏一起消失。沈青崖让他亲自选择“暂停使用”四字，他写完后又在旁边注明需本人复核，不把这句话扩成永久销毁。

午后，门外敲击再次出现，仍是三下、停两息、一下。裴照川把门板拓纸与上午的石板位置并列，发现木纤维受力点向右偏了半寸。这个差异只说明敲击点变化，不能证明门外换了人。晏九愿意确认节奏和位置，不愿猜测来者是否听见自己的证言。书吏问是否应把敲击列作威胁，晏九说他没有感到威胁，若要记录，应写“未说明性质”。

临近夜半，晏九在小册子最后一页写下今日的保留事项：不确认原名，不承接他人的恐惧，不授权以“救案”为理由扩展查阅；若日后改变称谓，今日动作仍可由三份记录核验。他请沈青崖在旁边写见证人的现用称谓，却不要求她承诺永远记住自己。沈青崖写下“沈青崖，见证范围限于今日”，闻夫人和裴照川分别写下同样的日期与各自范围。

晏九收好木片时，最上层仍是“拒名”，下面依次放着“撤回”和“再问”。他没有把“再问”交给任何人，只说下次是否继续，要等下一次本人选择。门外的灰被封进小袋，敲击没有被写成召唤，也没有被写成告别。正厅的灯油将尽，三份抄本却各自留在不同的人手中，谁都不能独自替晏九决定他是谁。
