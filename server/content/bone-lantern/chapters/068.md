# 第六十八章 第一次公开归还

第三十一日清晨，义庄的空白墙前摆了三张桌子。

第一张放物证，第二张放口述簿，第三张只放一盏没有灯芯的白灯。沈青崖让每张桌子之间留出两尺，任何人都不能拿一张桌上的东西替另一张桌上的人回答。墙上贴出新的说明：归还不是补写，公开不是强迫；愿意接收者可随时停止，拒绝者不因此失去原有证据。

这是奉安第一次把一个被刮去的姓名，当着街坊和三名不同官署记录者的面，交还给仍活着的人。

愿意接受归还的是西巷修伞铺的女儿。她前一日只让口述簿记下父亲按长短分伞骨的动作，拒绝把父亲与家谱相连。今晨她带来一只旧伞匣，匣底藏着半页修伞账，账上有一行被刮过的字。她说自己想知道那一行是不是父亲曾经使用的现用称谓，但不接受任何人直接告诉她答案。

沈青崖先问她要公开哪一部分。女孩说公开物证、检验过程和她最后的选择；父亲的旧名若不能由她本人确认，只能留在封袋里。她愿意让邻人旁听，不愿让太史局书吏单独带走账页。裴照川把这几项写成四栏，逐项让她按指印，而不是让她在一张含混的同意纸上签字。

修伞匠的遗骨并不在义庄。女孩从铺中带来他常用的磨刀石、竹片和一块沾漆的袖口。沈青崖先检查袖口。漆层三次叠加，最外层是近月的新青色，里层有旧黑漆和极少的红砂。磨刀石上有长短不同的平行刃痕，左侧三道、右侧两道，与女孩昨日描述的分堆动作相符，但仍不能仅凭刃痕确定姓名。

账页上的残字被水洇过，只剩左偏旁和一横。沈青崖用侧光照纸，发现刮痕下有硬压出的笔顺，不是白化导致的自然褪色。她取同批纸做盲试，确认新正历印灰膜会使表层墨色向纤维深处迁移，却不会留下这种硬压。刮字与灰膜是两种动作，不能归为同一机制。

第一名见证者是修伞铺隔壁的老妇。她说老人曾在三年前教她把短伞骨放左边，但不记得听过任何称谓。第二名是米行伙计，他愿意确认女孩每次进门都先摸左边木架，不愿确认她父亲是谁。第三名是奉命记录者，他的官牌署名仍白，愿意记录自己的动作，不愿让人把他的职位扩展成授权来源。

证据被逐一读出。老妇只读动作，米行伙计只读物件，记录者读时间和纸张来源。三者没有人读出残字。女孩伸手摸了摸账页边缘，问是否可以由她决定把残字与父亲相连。

“可以决定是否接收，不可以把不能证明的部分变成已证明。”沈青崖说。

女孩点头。她把旧伞匣放到自己的面前，先说出父亲在家中使用的称谓。那是一个她从小叫到大的称呼，却不一定是官牌上的原名。她说愿意把它作为今日归还的称谓，允许写入街巷口述簿，允许父亲的旧物与它建立一条“本人确认的关系”；至于账页残字，她暂不确认。

晏九把她的话写在公开栏，问她是否愿意让邻人复述。女孩说愿意，但每个人复述前必须先说“这是她今日确认的称谓”，不得说成祖名、官名或唯一姓名。老妇照她的要求复述，米行伙计复述到一半停住，说自己只愿确认听见，不愿承担解释。那一栏写成“听见，未代答”。

太史局书吏忽然要求把账页归入“已归还”，理由是女孩已经说出了称谓。沈青崖问女孩是否同意这个归档名。女孩摇头，说她只同意“本人确认的现用称谓”，不同意“旧名已归还”。书吏要求记下她拒绝归档，女孩说可以记下原话，但不接受“拒绝归还”的解释。两句话分列，书吏沉默。

第三张桌上的白灯没有灯芯，盏底却在女孩说完后出现一圈湿痕。宋延立即用木尺量距离，确认湿痕只在灯盏内沿，桌面没有水。沈青崖取来普通白陶盏做对照，发现义庄夜间湿气足以凝在釉面，白灯的灰痕颜色与西水关灯盏接近，却没有黑蜡膜。她把湿痕记为环境现象，不能用来证明归还成功。

女孩看着白灯，问若父亲真的愿意把称谓交还给她，他是否会因此回来。

“归还的是记录和选择，不是把死者带回。”沈青崖说。

女孩沉默很久，随后把手放在旧伞匣上。她说愿意接收父亲在家中使用的称谓，也愿意把三堆伞骨动作列为可重复证据；她不愿接收任何来自灯火、黑蜡或他人梦境的声音。她要求若三日内改变主意，可以撤回称谓与关系栏，但不撤回已经发生的检验。

沈青崖让她先写“愿意接收”，再写“不接收的范围”，最后写“可撤回”。三张纸分别封袋，女孩亲自将一张贴在旧伞匣上。没有官印，只有她的指印和两名见证者的现用称谓。归还过程完成时，墙上的空白没有缩小，门牌也没有恢复姓氏。

旁观的人开始询问自己的旧名。沈青崖抬手让他们先停。今天只归还一个人愿意接收的称谓，不以一个成功案例替所有沉默者作决定。闻夫人站在人群外，报出自己的现用称谓后，说她愿意作为见证者，不愿被列为归还对象。她的选择被单独记录。

午后，女孩把账页残字放回封袋。她说自己也许永远不确认那半个偏旁，但父亲分伞骨的动作已经足够让她在铺里继续工作。她不想让“没有确认原名”变成一种失败。

她还带来一只旧铜尺。铜尺边缘有五处凹口，是修伞匠每次量伞骨时留下的标记。沈青崖将凹口与磨刀石上的五组刃痕比对，四组方向一致，一组被后来的锈斑覆盖。这个结果支持铜尺、磨刀石和伞骨属于同一工作台，却不能把工作台推成官牌。女孩同意把比对结果公开，但要求把“同一工作台”写成“物件间可重复关联”，不写成“证明父女关系”。她又说明父亲最后一次使用铜尺只记得雨前一日，不记得时辰；这个回答被记作记忆范围，不被补成死亡时间。邻铺送伞账也不能证明修伞匠当日仍在铺内，证据链停在“工作动作可复核”。

人群里有人问，既然女孩愿意接收称谓，为何不把账页残字也交给她。女孩说，称谓是她今日愿意叫父亲的方式，残字是别人留下的笔画，两者不是一回事。她可以接收关系，不必接收猜测。沈青崖让这句话进入公开栏，先问女孩是否愿意被复述。女孩同意，米行伙计再次声明自己只愿确认听见。

沈青崖在公开记录最后写下：第一次归还只证明本人可以选择接收一段被保存的关系；物证仍要经过检验，称谓不自动升级为祖名，沉默与暂缓仍然有效。她把旧伞匣、磨刀石、账页、三份证词和女孩的选择分置五袋，白灯另封，不与任何一袋同柜。

归还结束后，三名记录者各自核对纸边。老妇发现自己复述的称谓少了一个笔画，要求加注“复述者书写错误”，不许撕掉错误纸页。米行伙计写下“我听见，但我不替她承担”。奉命记录者说明自己愿意证明交接时间，不愿证明归还对象的祖籍。太史局书吏要求带走拓本，女孩问拓本会不会并入大祭名单，书吏没有回答；她便撤回对官署复制的同意，只保留义庄、邻铺和自己三方查看。沈青崖将撤回写在交接单上，注明发生在复制之前，没人把书吏的沉默解释成答应。

裴照川问她，这样的归还要做多少次才能赶上城里正在变白的名字。

“不知道。”她说，“但每一次都要有人愿意。”

女孩收好伞匣，转身回到西巷。她没有找回官牌上的姓，却带走了自己确认过的称谓，以及以后可以说不的权利。空白墙上仍有许多未写的地方，第一次公开归还没有填满它，只在墙角留下一个由本人亲手按下的指印。
