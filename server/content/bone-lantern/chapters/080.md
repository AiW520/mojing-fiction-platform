# 第八十章 人间自有灯

第三十六日清晨，奉安城下了一场很短的雨。

雨水落在义庄新换的瓦檐上，沿着木槽流进三只不同的陶盆。第一只写着“可公开”，第二只写着“限本人”，第三只写着“暂不解释”。没有人把三盆水混在一起。沈青崖说，水可以汇入同一条沟，记录不能因为最后都要归档就失去来源。

第七十八章以后，照骨灯的灯身、灯芯硬结和铆钉分别存放。巡夜司双锁证物库重新封好，外封细裂留在原处，没有被补蜡遮住；窄轮车湿痕、灰线和交接簿各有编号，守库人的迟来说明仍分为所见、未答和待核。皇城骨层没有被宣告沉睡，也没有被宣告醒来。七枚黑蜡没有因此多出一枚，沈问渠最后的谎言仍有三种假设。

这些未完成并不等于制度失败。闻夫人的访问簿新增一页，页首写着“未答不是空白”。任何人来查阅，必须先写目的、范围、期限和撤回方式。若查阅者不愿写姓名，可以使用本人选择的称谓，但不能用物件、动作或官印替代。闻如晦曾在页边留下自己的现用称谓，三日后没有撤回；他也没有要求别人因此承认他的解释。

顾鸿保管第三套《百骨簿》目录。目录只写封袋编号、页码范围和授权状态，不写原页内容，不把“七处不得互认”改成一句容易执行的口号。义庄保管第一套，巡夜司保管第二套。三把钥匙分持，任何一把丢失都只触发停查，不触发强行开库。有人问这样是否太慢，顾鸿说，慢是为了让下一次错误有机会被看见。

辰时，他们按新规做了第一次查阅演练。来查的是一名只肯自称“承熙西库杂役”的老人，他想确认目录里是否有一只刻着桐叶的骨匣，却不愿说明骨匣属于谁。义庄先记录他的请求，巡夜司核对封袋编号，顾鸿只确认对应页码是否存在。三方各自看见一部分，没有人能单独打开原页。老人等了近一个时辰，忽然说今日不查了。

旧规会把这句话写成拒绝认领。闻夫人却在访问簿上记作“本人中止本次查阅，未说明原因”，并请三方当面封回已经取出的目录。老人走到门口，又回身要求保留自己来过的时辰，撤回衣着、年貌和声音描述。书吏问，一个连样貌都不能留下的人，日后如何证明来过。沈青崖把他手中的临时木筹翻过来：筹上只有请求编号、三处封记和归还时刻。它足以证明一次查阅发生过，不必替查阅者多保存一张脸。

演练中还发现一处漏洞：巡夜司副本把“限本人”误抄成“限亲属”。两字相近，后果却不同。顾鸿没有在原行上刮改，而是在三份目录后各添一张勘误页，写明发现人、发现时刻、旧文、新文和暂停过的查阅编号。老人没有因此被要求回来作证。错误被留下形状，制度才有可能证明自己曾经错过。

晏九把自己的小册子放在身前，允许义庄抄录两页，拒绝抄录第三页。他在抄录单上写：晏九是我现在愿意使用的称谓；若将来撤回，今日抄录仍保留为过去发生过的动作，不自动改写成别的名字。书吏问他要不要把“九”解释成九名少年，晏九摇头。他说，等有独立证据，或者有人愿意把那一段交给自己决定，再说。

这一回没人催他。

裴照川把裴家原簿公开副本送进旧刑部档案房。他没有要求先删去裴应焚簿、封锁和救人的任何一项，只要求档案上并列三种状态：已确认、本人不确认、仍待核。他失去了巡夜司里一部分旧职，却得到一张可以自由查阅的凭条。右耳仍听不见钟声，他便请人把每日报时改成三种方式：口报、木板振动和纸面时间。任何一种缺失，都不能假装另外两种已经完整。

普通验尸案的报告在午后送到府衙。府衙想把“提空麻袋者”改成“可疑男子”，卖炭妇人不同意。她拿着自己的证言副本，指出自己只说了衣色和方向，没有说性别、年龄和动机。书吏起初说公告需要一个易懂的称呼，闻夫人让他在旁边写下“本人不同意扩大描述”。书吏最后照写，公告改成“请持空麻袋者自愿说明昨夜北行路线”。

公告贴出后，有人把“自愿”二字撕掉一半。晏九发现时没有凭残纸猜是谁动的手，只在原处覆上一张透明薄纸，描下裂口，再将完整公告贴在旁边。府衙本想直接换新，裴照川却让旧纸保留到日落：删掉一个词也是发生过的动作，应让后来的人看见规则曾在哪里受过力。卖炭妇人看过描纸，允许记录裂口，不允许把它解释成有人威胁自己。她的限制与裂口一起入档，谁也没有替谁多说一步。

沈青崖看着那张公告，忽然想起第一卷开始时，自己曾把尸骨当作唯一可靠的证词。尸骨确实不会为了保全官位而改口，却也不会告诉她哪些痛苦不愿被公开，哪些关系只属于活着的人。如今她仍验骨、量伤、记水痕，只是不再把准确当成占有。一个结果若没有说明来源、范围和可撤回部分，便只是另一种粗糙的灯光。

闻夫人把普通油灯放到案台中央。灯芯是新捻的棉线，灯油掺了少量清水，火焰因此不稳。她问沈青崖是否要换成更亮的灯。沈青崖说不用，验尸需要的是角度，不是亮度；照见多少，不等于知道多少。

裴照川站在门口，手里拿着一只小木匣。匣内是两枚拆下的铆钉，属于照骨灯的灯座。他没有把匣子递给沈青崖，只说顾鸿要求所有经手人重新确认封袋状态。沈青崖伸手前先问他是否愿意让自己查看。裴照川说愿意，范围只限铆钉和封口，不包括他保管的裴家副本。她按他说的范围看完，写下“本人允许本次查看”，没有顺手多问父亲的旧事。

他们之间仍有一段被黑蜡取走的初遇记忆。裴照川曾承接那滴蜡里的情绪，却从不拿它要求沈青崖恢复什么。沈青崖也不以自己记得的部分逼他承认另一部分。两人有时会在案台两侧同时伸手取同一把尺，随后各自停一下，等对方先说明目的。这种迟疑并不浪漫，却给关系留下了选择的位置。

下午，义庄收到一封没有署名的信。信里只有一句：北官道的空麻袋不是最后一个。信纸纤维与前几次匿名纸不同，墨色也不同；送信人把它从门缝塞入，没有留下脚印。沈青崖将信分为纸张、文字和交接动作三项，不把一句提醒变成凶手自白。她在待核栏写下新的问题：还有谁在用不完整的物件传递未完成的关系？

闻如晦来过一次。他站在院门外，没有要求进屋，也没有要求查看目录。他说太史局愿意交出旧病历的抄本，但只能提供可公开部分，涉及仍在世者的姓名必须逐一询问。他承认这会使整理慢上许多年。沈青崖问他是否愿意承担慢的后果。闻如晦说愿意，并在门外的访问簿上写下现用称谓，注明“本人说明，不代表官署完成”。

他走后，晏九问，闻如晦是不是终于变成了好人。沈青崖说，人的行为可以改变，责任不能因为改变就自动消失。闻夫人又补了一句：审判不是为了给人换一张永远不变的脸，而是让每一次选择都能找到承担它的人。

傍晚，雨停。奉安城的街巷各自点灯。卖炭妇人把摊前的油灯移到檐下，方便来往的人看清脚下；修车匠在门口挂了一盏小纸灯，纸上写着弟弟罗重山的名字，下面另列“昨夜发生的事，仍待核”；东市车行把旧车牌擦干净，暂不把责任推给任何一个没来说明的人。那些灯并不照骨，也不照出记忆里的缺口，只让人看见此刻的路、门槛和彼此的脸。

沈青崖在义庄门口停了一会儿。她的左掌旧伤没有发热，灯焰留下的痕迹仍在，却不再要求她用遗忘换答案。她想起母亲的脸，只能记住一半轮廓；想起师父的声音，只剩下几个停顿；想起裴照川第一次把问题问短时的神情，也有一处空白。她没有向空白伸手。空白可以留在那里，直到有一天它自己愿意成为别的东西，也可以永远只是空白。

夜深后，义庄熄灭普通灯，留下门外一盏小纸灯。纸灯底下写着新的保管规则：先问本人，再记物证；证据分袋，解释分人；拒答、撤回、未答和暂不公开必须原样保存；任何人不得用秩序代替同意。

沈青崖把最后一行写完，晏九在旁边添了四个字：人间自有灯。

这不是说人间已经不会遗忘。奉安仍有白化的官印，皇城地下仍有未核的骨层，北官道仍有人提着空麻袋，七枚黑蜡仍在不同的黑暗里等待自己的持有人。只是从今日起，没有谁能把所有灯握在同一只手里，也没有谁能把别人的沉默解释成已经同意。

天将亮时，沈青崖合上普通验尸簿。她没有在最后一页写“终结”，只写：今日验得一具尸骨，确认一名死者，保留三项未答；明日若有新的证据到来，先问它从谁手里来，愿意走到哪里。

门外的纸灯被风吹得轻轻一晃，没有钟声回应。裴照川用指骨敲了敲门框，晏九在屋内应了一声，闻夫人问来者是否愿意留下称谓。门外的人说了一个名字，声音很低，却没有被任何灯取走。

沈青崖抬头，看见天色从灰变白。她知道这座城还会有尸体、谎言、删改和不肯被命名的人，也知道自己仍会在案台前一寸寸辨认骨缝、纤维和水痕。神灯已经熄灭，普通的灯还在；真相没有因此变得完整，却终于不必由一个人独自承担。

人间自有灯。灯光所及之处，先让活着的人决定自己愿意看见什么。
