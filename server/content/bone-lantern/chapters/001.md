# 第一章 雨夜无影尸

奉安城入秋后的第一场雨，是从一个死人睁眼开始的。

那人躺在永寿坊棺材铺门前，脸朝天，雨水盛在他的眼窝里。更夫敲过三更，木梆子的余音尚在巷口打转，铺门里便传出一声极轻的铃响。

不是招客的铜铃。

是棺材落地时，系在引魂绳上的那一枚。

晏九披着麻衣冲出来，先看见尸体，再看见尸体身下空空的青石板。雨从屋檐斜切下来，灯笼、门框、他自己的两条瘦腿，都在地上拖出乱晃的影子。唯有死人没有。

他在原地站了片刻，退回门里，把铺中七盏灯全点着，又一盏盏举到尸体旁。

仍没有影。

半个时辰后，巡夜司封了永寿坊。

沈青崖到时，雨势已经小了。她没有撑伞，深色窄袖衣上湿了大片，左手提一只旧木箱，右手戴着洗得发白的薄皮手套。巡夜司的人认得她，让开时却都不自觉屏住了气。

奉安的仵作不少，肯在半夜替无名尸开骨的，只有义庄沈姑娘一个。

“尸体动过没有？”她问。

晏九摇头，又想起什么似的指了指尸体的眼睛：“我把眼皮合上过。它自己又睁开了。”

“死人不会自己睁眼。”

“那就是雨睁的。”

沈青崖看他一眼。少年约莫十六岁，眼尾吊着，像只随时准备从墙头跳走的猫。他手背沾着新鲜松烟墨，拇指侧面有一道木刺划痕，麻衣下摆溅了泥，鞋底却很干净。

“你没走出檐下。”她说，“泥是搬棺材时溅的。尸体在你开门前就躺在这里，你没有碰他，只试了灯。”

晏九张了张嘴：“你怎么知道？”

沈青崖蹲下，没有答。她先摸死者颈侧，再以两指按压下颌。尸僵始于颌颈，尚未及肩，死去不超过两个时辰。死者是男性，三十五到四十五岁之间，指腹有细密裂口，右手食指与拇指内侧发硬，不像握刀或执笔，更像常年捻某种极细的东西。

尸体衣着普通。灰布长衫洗得发软，袖口留有一道被拆去的暗纹。腰间没有钱袋，没有路引，连鞋底都被人仔细刮过。

她又看尸体四周。青石板上的积水被后脑和肩背分成三股，说明人是在雨里躺下之后才逐渐被水围住，并非从干处拖来。可两只鞋跟外侧各沾一线黄泥，泥中混有碎螺壳，永寿坊附近没有这种土，只有西城旧水关的河滩才有。鞋底被刮过，鞋跟缝里却还留着。

铺前也没有搬运留下的长拖痕，只有门槛两侧四处浅水印。水印前端窄、后端散，是四个人曾同时踮脚落地；他们放下重物时刻意避开泥面，又在雨中站够片刻，等脚印边缘被冲散。尸体不会自己来到这里，抬他的人却希望旁人相信，他从雨里凭空出现。

沈青崖抬起死者左手。

无名指末节有一圈比周围皮肤更白的痕迹。他生前长期戴戒，却在死前不久被取走。不是寻常指环，痕宽而平，内侧压出一道浅浅齿印。

“像扳指？”巡夜司的人问。

“扳指戴拇指。”

声音从人群后传来。一个年轻男人穿过封锁的绳索，黑色官靴踩进积水，雨披没有系，肩头绣着巡夜司三足乌。他把一把连鞘旧刀随手递给属下，弯腰看那圈白痕。

“像修钟人用的护指。”他说，“捻游丝时防手汗，也防割伤。”

沈青崖认出他。裴照川，巡夜司校尉，奉安城里一半酒肆欠账簿上都有他的名字，另一半掌柜见他进门会先藏后门钥匙。传言他办案靠运气，升官靠一张会笑的脸。沈青崖不信传言，也不信笑脸。

“你见过？”她问。

“小时候拆过家里的西洋钟，被我父亲罚跪到天亮。”裴照川道，“那枚护指后来找不到了，他又罚了我一次。”

他语气轻，提到父亲时眼中却没有笑。

沈青崖将死者的手放回原处。雨水沿腕骨向袖内流，没有在衣料上洇开，而是像遇见一层看不见的油，聚成细珠滚落。

“衣服做过防水？”晏九问。

“尸体做过。”

沈青崖让人把白布屏架起，隔开围观目光。她解开死者衣带，灰衫之下没有外伤，皮肤却泛着不自然的青白。她用银针刺入肋下，拔出时针尖干净，针孔也没有血水渗出。

一个死去不到两个时辰的人，血仿佛早已被抽空。

她沿肋骨逐寸按压。第七肋处有轻微陷落，不是骨折，更像骨中被钻过一枚细孔，再以蜡封住。蜡色接近皮肤，雨夜里极难看见。

裴照川的手按上刀柄：“要开尸？”

“带回义庄。”

“不行。”棺材铺掌柜终于从门后挤出来。他年过五十，脸色比尸体还白，“晏九不懂规矩，这东西既然自己找上棺材铺，就该用镇阴棺封了，天亮前送出南门。不能抬进城中义庄。”

“他已经在城中。”沈青崖说。

“他没有影子！”

“没有影子不影响验尸。”

“会影响活人！”掌柜压低声音，“沈姑娘，你师父难道没教过？骨灯照人，影先死；无影尸进门，一门少一人。”

沈青崖的左手忽然疼了一下。

隔着皮手套，掌心那道旧伤像被细火舔过。她下意识蜷起手指。这个动作很小，裴照川却偏头看了过来。

“什么骨灯？”他问。

掌柜闭紧嘴，再不肯出声。

就在此时，尸体眼角的雨水动了。

不是流下，而是向上。

两道水痕沿着额角爬入发间。死者口中发出一声气泡破裂般的轻响，胸腹没有起伏，喉结却缓慢向上滚了一次。

巡夜司众人齐齐后退。有人已经拔刀，刀光在积水中铺开，所有影子随之乱成一团。

死者仍旧没有影子。

沈青崖俯身，一手扣住他下颌，另一手将薄木片压进齿间。死者舌下藏着东西。她用镊子夹出一小卷湿透的纸，纸薄得像蜕下的蛇皮，展开只有半个巴掌大。

上面没有字，只有一道墨画的圆。

圆缺了七码。

裴照川接过纸，对着灯看。纸纤维间有极细的金粉，边缘被某种齿轮反复碾过。

“太史局的历纸。”他说。

棺材铺掌柜膝盖一软，重重跪进雨里。

沈青崖看向他：“你认得死者。”

掌柜摇头，额头抵着地面。晏九却在门槛内翻找起来。他从一摞账册最底下抽出一本黑皮小册，飞快往前翻。册上密密麻麻记着姓名、籍贯、死亡时辰，有些字被水泡过似的，只剩淡痕。

他翻到最后一页，动作停住。

“今晚没有客人订棺。”他说。

裴照川道：“所以？”

“所以这口棺材不该在这里。”

众人顺着他的目光看去。铺子正中停着一口尚未上漆的薄棺，棺盖落在一旁，木屑还是新的。棺内空无一物，底板却积着一层雨水。

铺门上方有檐，棺材离门三丈。屋顶没有漏。

沈青崖走进铺内。她俯身闻了闻棺中雨水，一股极淡的铁锈气钻入鼻腔。水底沉着几颗比沙更细的白点。她以银匙舀起，对着灯焰轻轻一晃。

白点不是沙。

是磨碎的人骨。

棺底忽然传来“笃”的一声。

像有人从木板下面，用一根指骨轻轻敲门。

晏九脸上的血色霎时褪尽。他手里的黑册自行翻动，纸页哗哗作响，最后停在空白的一页。一行湿墨从纸背慢慢渗出来。

不是死者的姓名。

是三个字：

顾不言。

沈青崖看见那名字，掌心旧伤猛地裂开。血穿过手套滴入棺中，积水深处随即亮起一点苍白火光。

顾不言是她的师父。

也是三日前，由她亲手验尸、入殓、钉棺的人。
