# 第九章 城南骨市

奉安卖骨头的地方，不在义庄，也不在药铺。

在城南鱼市下面。

白日里，鱼贩把砧板架在排水沟上，鳞片与血水冲进砖缝。入夜后，第三排摊位会少一块青砖。买家从洞口下去，沿着鱼腥最重的暗渠走百余步，便能看见一串倒挂的白灯笼。

灯笼不写店号，只画骨头。

晏九知道这个地方。他曾替棺材铺掌柜送过一截无人认领的腿骨，换回三斤上好尸蜡。顾不言发现后罚他在义庄抄了七日验状，却没有报官。

“师父说，骨市不能靠封掉。”晏九低声道，“活人不肯给死者一个去处，死者的东西自然会找到别的价钱。”

第二日晚，沈青崖三人带着一只窄木匣进入骨市。宋延留守义庄，看管两具顾不言和照骨灯的备用钥匙。他仍无完整姓名，却开始用每一件做过的事确认自己。

木匣里装的是一根假的顾不言肋骨。

沈青崖选了拼骨棺中一根年龄相近的无名肋骨，以旧火熔砂擦入骨孔，再用药水在表面做出十五年土沁。她没有伪造顾不言的真实伤痕，只在骨面刻下一枚反写的“顾”字。

真正懂骨的人会看出它是假货；只对记忆锚物有兴趣的人，反而会因那个字追来。

裴照川换了旧布衣，刀藏在背篓底。他在入口停了片刻，听见四种脚步、两处呼吸和一只被铁链拴住的犬。右耳失聪让他避开了暗渠里的低沉钟振，左耳却仍感到耳膜发紧。

“这里也有钟。”他说。

沈青崖摸过墙面。砖缝每隔七码嵌一枚铜片，水滴落下时震动相连。不是用来报时，而是让进入者在不知不觉中放慢脚步。

骨市比想象中干净。

摊位上的骨头都用白布垫着，按头骨、齿、指节与长骨分类。卖家不吆喝，只在木牌上写用途：婴儿乳齿可替无子妇“借梦”，刑死者指骨能让赌徒梦见下一张牌，读书人的腕骨据说可使孩童开窍。

大多是假话。

有些却是真的记忆锚物。

真假不能用价格区分。最廉价的断梳可能留着一个人真实的一生，标价百两的名将腿骨却只是屠户从羊骨上削下的薄片。沈青崖逐摊看过去：有头骨的牙缝还夹着南方稻壳，摊主却称它来自塞北将军；一截所谓琴师指骨没有长期按弦造成的关节磨损，反倒带着织工捻线留下的骨面改变。骨市贩卖的第一件东西从来不是骨，是买家愿意相信的来历。

沈青崖看见一枚磨损的木梳。摊主说梳子属于十年前投井的女子，夜里握着它能听见井底唱曲。梳齿间留有灰白头皮屑与桂花油，背面刻着半个坊籍号。它未必能唱，却确实曾属于一个被官府以无名尸收殓的人。

“这些东西从哪来？”她问。

摊主用一只白翳眼看她：“姑娘买的是故事，还是来处？前者十文，后者要命。”

晏九把木匣放上摊：“我们卖来处。”

匣盖掀开一线。

白翳眼看见反写的“顾”字，立即合上匣子：“骨不对。”

“哪里不对？”

“想钓鱼，饵也得像活的。”摊主将匣子推回来，“顾不言的骨，骨市三年前就见过。”

三年前，正是韩策假死、巡夜司出现空椅的时候。

裴照川把一串钱压在桌上：“谁卖的？”

摊主不碰钱，只瞥向骨市最深处。那里挂着一盏没有图样的灯，灯下坐着个戴木面具的人。右手藏在袖中，左脚边放着五枚钥匙。

晏九呼吸一紧。

他们要找的人自己来了。

木面具人隔着三排摊位抬起左手，做了个验收证物的敲击手势。两短一长，与裴照川昨夜记起的一样。

随后他起身离开。

裴照川没有立刻追。他把一枚铜钱弹进暗渠，铜钱撞过七块嵌片，发出不同回声。第三处回声后还有一道极轻的脚步，不属于木面具人。

对方不止一个。

沈青崖提起木匣，朝相反方向走。木面具人果然停下，回头看了一眼。

假的顾不言骨是饵，追出去便是咬钩。他们真正要知道的是，骨市中谁在意这根骨头会被带去哪里。

三人分开。裴照川沿明路追木面具人，晏九留在摊间盯住白翳眼，沈青崖带木匣走入西侧窄巷。

第一个跟来的是个穿孝衣的妇人。

她没有兵器，怀里抱着一只孩童布鞋。追到无人处便跪下，求沈青崖把骨头卖给她。

“我不要顾先生的命。”妇人说，“我只想借他记得一个人。”

她的儿子五年前死于河堤塌陷，官府怕追究河工，把十七具尸体都报作外乡流民。她记得儿子的乳名，却开始忘记他的脸。骨市有人告诉她，只要买一段记性好的人的骨，和旧物一起埋在枕下，便能把记忆留住。

“你试过？”沈青崖问。

妇人抱紧布鞋：“买过三次。第一次想起他左眉有痣，第二次想起他怕狗，第三次……”

“第三次呢？”

“我想起他不是我的儿子。”

锚物把别人的记忆混了进来。她已经无法分清哪些细节属于死去的孩子，哪些来自陌生骨头的主人。

沈青崖没有把假骨给她，只让她把能被旁人复验的事写下：产婆是谁，孩子几岁换牙，邻居见过什么伤。记忆会变，发生过的关系还会在别人生活里留下痕迹。

第二个跟来的人没有开口。

他从巷顶落下，短刀直取木匣。沈青崖侧身避过，匣子故意脱手。那人接住便跑，却在转角撞上裴照川横来的刀鞘。

木匣摔开，假骨滚到湿地。

刺客看清反写的字，脸色骤变。他不是怕中计，而是失望。

“不是那一根。”他说。

裴照川将他按在墙上：“哪一根？”

刺客咬破口中蜡丸。沈青崖掐住下颌仍慢了一步，淡灰液体沿他嘴角流下。不是毒，是高浓度忘尘。他的眼神迅速空下去，连挣扎也停了。

裴照川搜出一张骨市收契。契上列着十三件货：顾不言右掌骨、邵准铜护指、裴应行刑前所穿囚衣，以及十件只写编号的旧物。

每件货后都有买价，也有“可取记忆”的重量。

沈青崖注意到十件编号旧物并非随意排列。编号首位对应奉安坊区，末位对应公钟序号，中间则是骨市成交年月。将七码副齿位置代入，十件旧物连成一条从太史局西库通往城南义庄的路线。三年前的买主不是漫无目的收藏，他在依照某份旧地图收回散落的记忆锚物。

其中第七码货物已经被朱笔划去，批注只有四字：本人拒售。

在一个靠欺骗取得手印的市场里，竟有人特意留下拒绝记录。

顾不言右掌骨标价最高，却在三年前被人买走。买主没有姓名，只按了一个指印。

与巡夜司夹道银盒旁的指印完全相同。

木面具人不是来买假骨，是来阻止其他人买。他故意现身，把裴照川引开，让这名刺客确认木匣真假。

“韩策在保护什么？”晏九赶来问。

沈青崖收起契纸：“不是保护骨头。是保护骨头里那段记忆不会落到不该拿的人手里。”

骨市深处忽然一盏接一盏熄灯。

白翳眼开始收摊，卖家们动作熟练，没有慌乱。有人在黑暗中敲了七码，所有入口同时落闸。

裴照川拉住沈青崖退到砖柱后。水声从暗渠上游涌来，带着浓重皂角与白矾味。有人要用洗尸水冲掉整座骨市的交易痕迹。

晏九却冲向白翳眼的摊位，抢下那枚女子木梳和一摞收契。

“救骨头做什么？”裴照川喝道。

“不是骨头。”少年把契纸塞进怀里，“是来过这里的人。”

水没过脚踝时，沈青崖看见暗渠底部露出一块被冲洗干净的青石。石上刻着一百零八个圆孔，排列与奉安钟楼分布完全一致。

其中一个孔里，卡着邵准缺失的另半枚铜齿。

骨市不是藏在城下。

它就建在那座让全城慢七码的机关上。
