# 第七十章 分担三息

敲门声落下后，义庄里没有人立刻去开门。

沈青崖让每个人先说自己看见了什么。宋延说门闩，晏九说门缝下的灰，闻夫人说门外有人停在第三块石板，裴照川用指骨感到木门传来三次短振。四种证词都没有包含姓名。沈青崖把门留一指宽，先请门外者报现用称谓。门外没有回答，只把一只小陶盒从缝隙推入。

陶盒上没有印，盒盖缝里塞着一段短麻线，打了三个相同的半结。盒内是半片黑蜡，边缘被灰泥包住，蜡面没有灯芯烧过的痕迹。晏九后退一步，沈青崖立即让宋延封住门缝，不许任何人伸手接触。第二滴黑蜡仍在三方锁匣中，第一滴残样也另存，这半片来源不明，不能凭颜色认作同一物。

门外人终于说，自己只愿让三个人各看三息，不愿交出姓名，也不接受任何人替他决定谁来承接。沈青崖问他是否知道黑蜡的规则。门外沉默。她把“未答”写下，再问是否愿意让盒子作为物证进入三锁档案室。门外人说愿意，但三息必须由接收者本人选择，任何人中途改变主意都可以停止。

这个条件不像归还，更像一次试探。沈青崖没有答应，先让陶盒停在门槛上。她取出普通灰蜡、旧蜂蜡和白灯盏做盲样，确认半片黑蜡外层有一层干涸的白灰，内层却保存湿润光泽。白灰成分与昨日墙灰有一处相似，黑蜡芯质未取样，不能证明来自七枚黑蜡中的任何一枚。

街外的暴动尚未平息。西巷的木牌有人继续敲，门内已有三名志愿者表示愿意承担三息的感知，但每人要求的范围不同：一人只愿感到温度，一人只愿看见物件形状，一人只愿承担情绪，不愿承接任何姓名或关系。沈青崖说，黑蜡若真的能转移残片，承接者同时承担原主情绪与认知偏差，不能把它切成安全的单项体验。三息不是把代价拆碎，而是让每个承接者知道自己可能承担什么。

第一个志愿者是修伞匠女儿。她刚撤回旁人复述父亲称谓，不愿把新的感知与父亲相连。她说愿意观看半片黑蜡的外观三息，只做物证观察，不愿让蜡火靠近皮肤。门外人没有答应，盒子也没有移动。这个“只观看”不是承接，沈青崖把它列为非承接选项。

第二个志愿者是闻夫人。她愿意承担三息的情绪是否与自己有关，但要求有人在旁记录身体变化，并且她可以随时拔掉门栓离开。第三个是晏九，他说愿意承担三息，却不愿别人把出现的动作叫作阿枣、七号或九号。三人都先说出自己的现用称谓，分别写下愿意、拒绝和撤回范围。

裴照川不同意立即开盒。他指着陶盒底部，示意那里的灰线正往门外移动。宋延用木尺量出灰线长度，每隔三息缩短半分，像盒内有轻微热源；普通灰蜡盲样没有同样变化。沈青崖要求把盒子移到石桌，并在石桌四角放上未接触黑蜡的纸片。移动由四人共同完成，每人只承担一个方向，避免单一动作被写成启动者。

陶盒放稳后，门外人再次敲门。这次是三下，间隔与盒底灰线收缩相同。裴照川用指骨确认振动来自门板，不是盒内传出。宋延在门外撒下红砂，敲击结束后红砂向门缝聚成细线，线头没有跨过门槛。物理振动可以解释一部分现象，不能解释人群刚才补出的声音。

沈青崖没有点照骨灯。她把灯仍封在巡夜司双锁证物库，说明三息不是照灯，不能产生灯火影像。若半片黑蜡确与记忆有关，承接也必须遵守本人选择，不可由门外人或调查者代替。

闻夫人先拔出门栓，确认自己能够离开；晏九把撤回线画在纸上；修伞匠女儿把伞匣放在手边。三人各自检查退路后，沈青崖才打开陶盒外层纸封，没有触碰黑蜡。盒内没有声音，只有一股潮湿的铁锈味。

第一息，闻夫人说自己感到一种被人等候的焦躁，但不知道是谁在等。晏九看见蜡面有一道向左弯的压痕，修伞匠女儿只确认蜡边的灰泥脱落。三人的描述没有重合成姓名。

第二息，闻夫人出现短暂眩晕，拔栓的手向后退半寸；沈青崖立即问她是否继续。她说继续，但不同意任何人碰她。晏九开始流泪，却说自己没有听见声音；修伞匠女儿说蜡面的压痕像被布包过，要求停止把它与伞匣关联。

第三息尚未结束，门外人突然说：“够了。”

沈青崖合上陶盒，三人同时退开。闻夫人的情绪在十息后恢复，晏九的眼泪停止，修伞匠女儿仍能清楚说出自己只看见灰泥和压痕。没有人获得姓名，也没有人承认那段焦躁属于自己以外的某个人。半片黑蜡表面多了一道细裂，却没有流出蜡液。

门外人要取回陶盒。沈青崖问他是否愿意留下三息记录、红砂拓图和三人的本人选择。门外沉默。她记作未答，不把他的沉默扩大成同意。修伞匠女儿要求把自己的观察记录公开；闻夫人只限义庄与自己查看；晏九要求保留撤回权。三份授权再次分开。

裴照川检查门外红砂，发现敲击者站在石板第三块，鞋印前掌窄、后跟新钉，与昨夜灰手套人留下的鞋印方向一致，却有一处钉痕缺失。相似不等同，物证只能说明两次来人可能使用过近似鞋底。等他们开门，石板上只剩一块湿布，布角缝着四短一长的线迹。

沈青崖把湿布、红砂、陶盒和三息记录分别封存。她在封条上写明：三息是一次经本人同意、可中止的接触观察；承接者承担的情绪和认知偏差不可拆分，未形成可归属的姓名；门外人的未答不构成授权。

晏九问，若以后必须让更多人一起承担，是否可以把三息分成三个人的每一息。

“可以共同看见，不能共同稀释代价。”沈青崖说，“谁承接，谁就要知道自己可能失去什么。”

门外终于传来一句：“那就先问每一个人。”

声音没有被谁认领。沈青崖把它记为门外原话，未答说话者，未把声音变成身份。义庄门仍留一指宽，陶盒在桌上，三人的选择各自封存。城里又响起一声不完整的钟，没人再抢着解释它属于谁的过去。
打开陶盒前，沈青崖让三人各自写下当前身体状态。闻夫人写右脚仍有拖步，晏九写眼睛发热，修伞匠女儿写手指握伞匣时会用力。三息后再对照，只有闻夫人多了短暂眩晕，晏九流泪，女孩手指没有新增动作。前后记录证明感受有变化，却不能把变化归属于某个死者或某枚黑蜡。

宋延在石桌下铺了三张不同纸浆的纸。灰线在普通纸上留下水痕，在南陵旧纸上不留痕，在新正历纸上出现一小块白斑。白斑边缘没有黑蜡膜，说明材料可能参与了表面变化，却没有形成记忆归还的独立证据。沈青崖将三张纸分袋，连同未接触过陶盒的空白纸一并封存，防止以后用相似颜色替代检测结果。

沈青崖把三息记录放在最上层，注明接触已经结束，后续任何人不得在没有重新询问的情况下复现。陶盒外的麻线由门外者提供，却没有留下称谓；它只能作为材料，不能作为授权凭证。她让晏九在封袋旁写下“先问每一个人”，再留出一整页空白，等明日来人亲自决定是否继续。

第二天清晨，闻夫人先检查门栓与退路，再问三人是否愿意继续查看。她自己的选择是只观察封袋，不触碰麻线；晏九愿意核对纸页，不愿再看陶盒；修伞匠女儿愿意确认伞匣位置，不愿听门外者复述昨夜原话。沈青崖逐项记录，未把“仍在场”写成同意继续。

宋延拿来一只未接触过黑蜡的旧陶罐，做气味盲试。三名观察者对铁锈味、潮土味和松脂味的判断各不相同，只有潮土味被三人同时确认。陶盒的气味因此不能直接指向黑蜡、旧疫所或某人的衣物。沈青崖把盲试结果留在记录后，不以多数意见覆盖少数人的不同感受。

裴照川复核门外湿布，发现布角四短一长的线迹并不贯穿布面，可能是缝补起针，也可能是故意留下的记号。线迹下面有一根断纤维，长度不足以与半片黑蜡外层麻线相配。相似材料被分列为“可比”，不列为“同源”。裴照川把湿布交回封袋，说明不愿以父亲习惯解释线迹。

日落时，半片黑蜡的细裂没有继续扩大。普通温度计显示陶盒内外温差消失，灰线也不再收缩。这个变化只能说明当时的热量或湿度条件改变，不能证明门外者已经离开。义庄在门边挂出公告：任何人可提出问题，但须先报现用称谓与查看范围；不报者仍可站在门外，不能因此获得盒内物件。
