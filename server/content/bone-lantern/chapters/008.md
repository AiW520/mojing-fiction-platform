# 第八章 第二具顾不言

伪造一枚官印不难。

难的是伪造它尚未出现的缺口。

裴照川的私印右下角在半年前追捕水匪时磕掉一粒米大的铜。三年前的调令上，那处缺口已经存在。纸龄、墨色、印泥渗透都没有后补痕迹，仿佛有人在三年前便知道这枚印日后会伤在哪里。

沈青崖没有把调令带出北狱。

“这张纸希望你相信什么？”她问。

“我将来会命韩策看灯。”

“你会吗？”

“不会。”裴照川答得很快，随后看向她，“至少现在不会。”

沈青崖把纸封进两层油布，请宋延在外封写下发现时辰与在场者，不写韩策姓名。既然名字会成为删除入口，他们便只记录物、动作和彼此可复验的过程。

这是宋延失名后教会他们的办法。

北狱囚犯无人记得空椅如何出现。有人坚持刚才走廊上站着一个右手残废的老人；有人看见的是年轻巡夜卒；最靠门的死囚说自己什么也没看见，只闻到一股义庄洗尸水的咸味。

顾不言再次被提起。

沈青崖正要复查旧刀，义庄方向忽然传来急锣。不是报丧的三慢声，而是仵作求援才用的两急一停。

她把照骨灯留在巡夜司双锁证物库，钥匙分别交给裴照川与宋延。黑蜡已失，灯本身不能再离开多人视线。随后三人赶往城南。

义庄门前停着一辆没有车夫的板车。

车上躺着顾不言。

不是刻着名字的骨头，也不是雨夜里模糊的人影。是一个有皮肉、有白发、有胸前缝线的老人。三日前沈青崖亲手验过的那一具尸体，连她缝合时在第七针打错的结都还在。

守庄老役坐在门槛上，双手发抖：“车自己来的。我听见轮响，开门便看见顾先生。可顾先生不是已经……”

“已经葬了。”沈青崖说。

也是她亲手开的坟。棺内没有这具尸体，只有一百零八根刮去姓名的杂骨。

她封门验尸。

顾不言身上的尸斑、尸僵与三日前记录基本一致，说明尸体一直处于低温。胸口贯穿伤仍是致命伤，刃从左前胸刺入，向后上方穿透心囊。凶手比他矮，出手时两人距离很近。缝线是沈青崖用的九股麻，针距也和验状相符。

可尸体有一处变化。

右手掌骨不再僵硬弯曲，而是完全舒展。

顾不言生前右手旧伤，第三、第四掌骨在二十年前愈合错位，握拳时总留一道空隙。这个特征使沈青崖在乱坟岗第一眼便认出他，也与历年医案吻合。如今皮肤上的旧伤疤还在，骨头却是直的。

她割开掌心。

疤痕只到真皮，没有深入筋腱。皮下曾被人塞入两小片弯曲竹篾，令手掌在生前保持无法屈伸的形状。尸体被低温存放三日，竹篾吸水软化，取出后，手便恢复原状。

所谓旧伤是造出来的。

沈青崖继续复验牙齿。顾不言左下第二颗臼齿缺失，她小时候听师父说，是年轻时替一具疫尸开棺，被棺钉撞掉。眼前尸体确实缺牙，可牙槽边缘锋利，没有多年愈合形成的圆钝骨缘。这颗牙是在死前不久拔掉的。

面容可以相似，疤痕可以复制，牙齿可以拔去。真正写在骨头里的年月却不能在几日内伪造。

三日前，她因悲恸与先入为主漏掉了这些。

她把三日前的验状重新铺开。当时每一项记录都是真的：疤痕位置、缺牙、手掌不能弯曲；错的是她把外观与原因写成了同一件事。顾不言教她“见伤先问伤从何来”，她却在他的尸体上跳过了最重要的一问。

悲伤没有让证据说谎，只让验尸的人提早停止追问。

沈青崖在验状原结论旁落笔：身份撤回。

墨迹尚未干，后坡传来晏九的喊声。

顾不言新坟仍敞着。那一百零八根杂骨已经移入义庄东验房，按部位与年龄分盘存放。晏九原本在逐根拓印刮痕，此刻正举着一段右手掌骨。

骨头属于六十岁左右男性，第三、第四掌骨陈旧骨折，错位方向与顾不言医案完全一致。骨折处形成的骨痂至少存在二十年，不可能伪造。

“还有这个。”晏九递来一颗牙。

左下第二臼齿，齿冠外侧有一道棺钉撞击留下的斜裂。牙根表面附着少量牙槽骨，说明它是在死者死后、软组织腐尽时自然脱落，而不是生前拔除。

沈青崖把牙与掌骨放在同一盘中。

一百零八根骨并非来自一百零八个人。她重新检查关节面、骨密度与泥土残留，发现其中十三根能够组成同一名男性的部分骨架：右手掌骨、两节颈椎、三根肋骨、左胫骨与部分下颌。每一处旧伤都与顾不言医案相合。

这些骨头在地下至少埋了十五年。

下颌左侧牙槽已经完全愈合，说明死者生前缺失那颗臼齿多年；脱落的裂牙却来自另一个与他骨骼特征相近的人。有人故意把真假材料混在一起，让任何一次简单比对都得到“顾不言”的答案。

裴照川站在两张验台之间。

左边是死去三日、有顾不言面容和缝线的尸体；右边是死去至少十五年、拥有顾不言真实旧伤的遗骨。

两者都曾被安排成顾不言。

“哪一个是你师父？”他问。

沈青崖没有立刻回答。

她先从新尸指甲缝中取出黑色粉末。不是泥，也不是忘尘，而是巡夜司公文用的油烟墨。死者临死前抓过刚写好的文书。左袖内侧还粘着一根极细红线，与北狱空椅上的调令封绳相同。

新尸去过巡夜司，或者杀他的人带着巡夜司文书。

旧骨则沾有火烧后的琉璃状砂粒。这种砂只有高温将太史局观星台地砖熔化时才会形成。顾不言若在十八年前死于承熙大火，骨上留下它并不奇怪。

可沈青崖清楚记得，师父在过去十五年里教她认骨、煎药、缝尸，冬日会因右手旧伤握不住热碗。他不可能既埋在火场地下，又在义庄陪她长大。

除非陪她长大的那个人，从来不是骨头原来的主人。

这个念头比尸体死而复返更冷。

她回到新尸旁，查看耳后。顾不言生前那里有一颗小痣，新尸也有。刀尖挑开后，所谓黑痣是一滴嵌入皮下的黑蜡。

蜡只有针尖大小，却散出她熟悉的陈旧书页气味。

不是从银盒失窃的那一整滴。只是被切下的一点。

沈青崖没有点灯，只把蜡封入瓷瓶。照骨灯的规则已经说明，黑蜡可以由他人承接。若有人把顾不言的记忆分给另一个人，面容、习惯和自述便都可能成为身份伪装的一部分；但死者的骨龄、伤痕与死亡时间仍会留下分界。

“旧骨更接近最初的顾不言。”她说，“这具尸体更接近我认识的师父。”

“两句话不矛盾？”晏九问。

“不矛盾。”

她说出口，才发现自己并不因这个答案轻松。若十五年来照顾她的人是一个承接记忆的陌生人，他对她的教养究竟属于顾不言，还是属于那个被覆盖了姓名的人？

门外有人叩了三下。

与第一章棺底的声音一模一样。

裴照川开门。门前无人，地上只有一只缺口茶碗。那是顾不言灵位旁的旧物，原本一直放在东墙。

碗底压着一张新纸，仍是顾不言的字。

青崖：你已经找到我的两具尸体。

下一行墨色较淡，像写字的人停了很久。

别急着选哪一个是真的。先问活着的那个，愿不愿意继续做我。

沈青崖抬头望向验台。

两具顾不言都已死去。

可纸上说，还有一个活着。
