# 第六十章 一滴不肯承接的蜡

第二滴黑蜡在锁匣里发出轻响。

声音极轻，像硬物在冷铁上碰了一下。宋延以为是匣内蜡滴移动，沈青崖却看见黑蜡边缘的声纹细线在水汽中收缩。裴照川没有听见，他只能看见匣盖的震动；晏九把掌心贴到桌面，确认震动每隔四短一长重复一次。

没人打开锁匣。

沈青崖先让三名见证人检查封记。第一道是宋延的冷铁压痕，第二道是裴照川的外封，第三道是她写下的“不得承接”。三道封记没有破损，水纹来自匣内温差或蜡面反应，不能被当作黑蜡主动呼唤。

他们把同样大小的普通蜂蜡、城墙灰蜡和第一滴黑蜡表层残样分别放在三只空匣中。三只匣子的铁材、温度和湿度一致，只有第二滴黑蜡出现四短一长的微振。振动经过桌面传到掌骨，不代表蜡滴具有意志，可能是声纹结构与铁匣共鸣。

他们又把四只匣子移到石桌、木桌和水盆旁。石桌上震动最清晰，木桌上只剩两短一长，水盆旁则出现不规则回声。宋延把匣底垫上麻布，震动完全消失；拿掉麻布后恢复。材料能够改变残片的可感程度，任何听见或摸到的人都必须同时登记所用桌面和隔振物。

沈青崖让三名不知黑蜡内容的记录者分别写下自己听见的节奏。第一人写四短一长，第二人写三短一长，第三人只写“有停顿”。他们看到匣子的震动后才补写解释，说明感知会被期待影响。三份记录保留原样，不取平均。

宋延随后将锁匣放进三种不同的布袋：旧麻、白绢和南陵青布。旧麻会放大桌面震动，白绢几乎不传声，青布在湿气中出现短促回弹。三种布袋都没有改变黑蜡本身的温度和重量，却改变了听者对节奏的判断。沈青崖要求把布袋材质写在每一份记录上，禁止把不同条件下的声音拼成一段“完整证词”。

她让裴照川用左手指骨、晏九用掌心、宋延用纸管分别判断最后一声是否存在。裴照川说有，晏九说像门框回响，宋延说无法确定。三份答案不一致，正好证明承接前必须保留个人差异，不能把一滴蜡变成所有人共同的记忆。

沈青崖要求宋延改换匣底厚度。匣底加厚一分后，第二滴黑蜡的震动变成两短一长；换成木底，震动消失；冷铁重新接触，四短一长又出现。现象可以由材料共振解释，却仍保留一项危险：这滴蜡保存的声音关系正在寻找能够传递它的结构。

“它不一定在找人。”裴照川说。

“可人会把它解释成找人。”沈青崖答。

她让晏九写下三个选择：打开、继续封存、由本人以外的人承接。晏九在第三项后面画了一个叉。裴照川选择继续封存，宋延要求增加一层隔振木板。沈青崖没有填写第一项。

第二滴黑蜡的表面裂开一道细缝，露出更深的黑色。缝中没有影像，只有一小段模糊的气息声。沈青崖听得出方向和音高，却听不出熟悉感，也无法判断说话者。她没有把这段声音写成顾不言、裴照川或闻如晦。

气息声的末端带有一次轻咳。宋延查阅南陵旧医案，找到七名有烟尘咳记录的人，其中三人已死、两人迁居、两人姓名被删。候选太多，且声音本身可能由铜簧模拟，不能据此建立身份。

宋延用纸管记录气息长度：短、短、长、停、短。裴照川用指骨感到的震动顺序与纸管相合。晏九则说最后一停像有人把手从门框上收回。三个人得到的感知不同，不能合并成一句完整的话。

沈青崖把声音标作“第二滴黑蜡的主观残片”，附上三份独立记录。她没有点灯，也没有承接黑蜡。若她把声音接入自己，可能会失去另一段与自身重量相近的记忆；更严重的是，她此刻已经无法凭声音识别熟人，承接只会增加一层未经复核的关系偏差。

太史局来使在门外要求开匣。

他说大祭名单需要确认七滴黑蜡的来源，若沈青崖继续拒绝，就会被列入“拒绝归还记忆”的名单。裴照川把裴家原簿拓本递给他，要求他先说明太史局借灯的清单、承接者的同意记录和黑蜡归还方式。

来使说这些都在正历总册里。

“总册在哪里？”

来使不答，只重复要求开匣。

沈青崖让门外的书吏记录双方原话。书吏想把“拒绝开匣”写成“拒绝归还”，她要求删去后半句，改为“本人拒绝在证据不足时开匣”。书吏不愿改，闻夫人送来的访问规则却被晏九挂在门旁：先问，等答，不替答。

书吏看见规则，最终照改。

匣内黑蜡又响了一次。

这次四短一长后多出一声极轻的敲击，像有人在问门内是否有人。沈青崖把指尖放在匣盖上，却没有打开。她让见证人轮流回答“在”或“不在”，每人只能回答自己，不得替蜡中的人回答。

宋延说“在”。

裴照川说“在”。

晏九说“我在，但不代它回答”。

沈青崖最后说：“我在，且不承接。”

声音停止。

普通蜂蜡、灰蜡和第一滴残样再次测试，均没有出现同样停顿。现象仍可以解释为匣内材料与桌面隔振变化，不能证明黑蜡理解人的话；但沈青崖的选择不需要黑蜡理解才成立。

她在锁匣目录上写下：第二滴黑蜡，主观残片可重复；承接风险已知；本人暂不承接；任何人不得以“声音停止”解释为同意。

她还要求目录增加“承接后不可逆损失”栏，先列出自己的熟人声音关系识别已经缺失，避免未来承接者把风险理解成短暂不适。宋延将此栏抄给三方见证人，每人确认已读，不要求任何人同意承接。

来使要求她签“拒绝归还”。

她签下另一句话：拒绝代承，不拒绝查证。

裴照川在旁边加注：拒绝承接不等于拒绝死者存在。

太史局的人离开后，晏九问：“如果以后有人愿意承接呢？”

“先让他知道会失去什么，也让他知道可以拒绝。”沈青崖说。

“那你呢？”

“我已经知道一部分。”

她把三方锁匣的承接说明重新读给晏九听：承接者须知道记忆来源、代价、可撤回范围和无法恢复的部分；须有至少两名不承担该记忆的人见证；须允许本人在开封前改变决定。晏九问能否把“拒绝”也写成一种承接状态，沈青崖说可以，但那仍不表示黑蜡已经归还。

宋延把这套说明抄成三份：一份随锁匣，一份放义庄档室，一份交给可能的未来承接者。抄本末尾留出空白签条，不要求现在签名。裴照川在签条旁写下“未选择，不等于待补”，以免后人把空白当成催促。

他把签条的空白裁成可撤回的窄条，留在锁匣外，不让任何人误以为已有承接者。

窄条编号与三份抄本相同，却不与黑蜡接触。

未来承接者可以看见说明，也可以不看。

不看不视为拒绝。

拒绝也不强迫承接。

两者均留痕。

留痕不等于强制。

记录先于解释。

解释另存。

目录不替任何人承接。

承接必须本人在场。

本人可随时退出。

退出不抹除记录。

记录仍可查。

查而不占。

她看向锁匣，没有说自己仍不知道那段声音曾经属于谁。

黑蜡安静下来，像一滴不肯被任何人替它决定的夜色。

为了确认白斑不是纸面返潮，沈青崖让宋延把三种纸放在同一块阴凉石板上，隔一刻钟交换位置。白斑只在新正历纸上出现，换位后仍在原纸纤维间，不随石板位置移动。这个结果支持纸浆差异，却不能证明纸被谁处理过。她把温度、湿度和交换顺序写在纸角，要求复核者不得只抄结论。

闻夫人提出把陶盒移到门外观察。晏九先问移盒是否会扩大门外者的查看范围，沈青崖回答会，因此必须重新询问每个在场者。修伞匠女儿说她只同意看盒底，不同意让陌生人碰伞匣；闻夫人同意移盒，不同意离开退路；晏九同意记录，不同意承接任何新增感受。三份选择都写入动作栏，移盒因此暂缓。

门外者留下的麻线被分成三段，一段做拉力盲试，一段封存，一段交给闻夫人保管。拉力盲试显示麻线受潮后会变软，结法方向容易改变；它与陶盒灰线的相似只说明材料可形成相近痕迹。沈青崖拒绝把“四短一长”解释成裴应家传暗号，裴照川也拒绝替父亲承认或否认。

陶盒最终没有再次打开。三息已经结束，任何继续观察都须另起记录。沈青崖把这项决定写成“暂缓”，让三人分别确认；修伞匠女儿补写“暂缓不等于拒绝”，闻夫人补写“拒绝仍可随时提出”，晏九补写“同意也不预先承诺”。三句话并列，谁也没有替谁解释。
