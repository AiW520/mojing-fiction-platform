# 第三十章 城墙上的黑蜡

黑蜡不是涂在城墙表面。

它被灌进砖缝，一层压着一层，从北城第七码垛口向东西延伸。外墙看不出异样，只有拆开灰缝，才会露出里面细密的黑线。每条线宽不足一厘，遇到体温便软化，遇冷又凝固，像藏在城砖之间的血脉。

守城营最初想用火烤化。沈青崖赶到时，火盆已经架起。她立即让人撤火。黑蜡一旦受热，里面的感知会同时释放；整段城墙若都是锚物，后果不是毁掉证据，而是让数千人共同承接。

她先取三块相邻城砖，在冷棚内分层剥离。第一块蜡中混有头发，第二块夹着衣线，第三块只有指甲屑。三种锚物来自不同人，排列却遵循同一方向：头发指向城外，衣线横向，指甲屑朝城内。

“不是一条名录。”晏九说。

“是三层路。”沈青崖道。

城外层保存来处，横向层连接关系，城内层指向归还对象。若三层同时受热，一个人的记忆会沿错误路线进入另一个人。镜城此前出现的同名寡妇、活人替身和群体梦行，都是小范围的错接结果。

裴照川命守城营测量黑线长度。东向止于太史局旧水沟，西向止于巡夜司北狱夹道，向下则进入前三朝骨层。七处门正好位于黑线交叉处。城墙不是边界，而是一只环绕奉安的巨大记忆锚物。

黑蜡的铺设年代也不同。靠内砖缝的蜡已脆化，至少十八年；外层有三年前补灌痕迹，最表面一线仍温，形成不超过一日。有人持续维护这套结构，并在昨夜无名船入城后完成最后连接。

宋延查守城修缮账。十八年来共有四十七次“防渗补灰”，每次都由巡夜司调路，承作匠人却来自慈安堂收容的无籍者。周谨盖过其中二十九次复核印，另十八次发生在他女儿被删之前。

周谨不是起点。他后来利用一条早已存在的路寻找女儿。

城砖灰浆里还有一枚五齿钥匙压痕，深浅与韩策腰间钥匙声、邵准药管封口一致。压痕只能证明同一组钥匙曾用于开启灌蜡孔，不能证明如今持钥匙的人仍是韩策。

沈青崖沿墙检查七码，发现每七码便有一块砖的烧结温度不同。敲击时，异砖会把振动传给下一段，如同倒钟铜管。邵准设计的副齿原本可以逐段切断传振；他留下两半铜齿，不只是为了西库门，也能拆开城墙网络。

“全拆？”晏九问。

“拆一段，先看哪一层断。”

他们选择一处没有住户、没有门影的废垛口。两半铜齿分别卡入异砖侧孔，反向转动。第一声轻响后，外层头发蜡线断开，城外雨界退了半步；第二声响，横向衣线没有断，反而把附近两扇门连接得更亮；第三声前，沈青崖叫停。

网络不能从任意位置粗暴拆除。断开来处却保留关系，会让记忆失去原主，只剩可被任何人承接的内容。

她重新封住侧孔，把两半铜齿分开保管。试验段的黑蜡被冷切成三层，各自编号。没有一人因试验当场恢复记忆，证明机械切断只改变传递路径，不会自动归还内容。

城墙内忽然有人敲砖。

声音来自一块没有门影的实心墙。守城卒钻孔，探杆只进两寸便碰到软物。拆下一块砖，里面不是人，而是一排封蜡小管，密得像蜂房。每管刻一个日期，没有姓名，最早始于承熙大火前七日，最新正是昨夜。

沈青崖数到第七排，找到与照骨灯壁第一滴黑蜡重量相符的编号。管口有银盒内曾留下的撬痕，五道钥匙划痕只到第四道，第五道被人故意磨平。

这管黑蜡很可能是裴照川失窃的那一滴。

裴照川问：“要我开吗？”

那滴蜡保存的，是沈青崖被灯取走的两人初见。按规则，他可以承接，却会同时承担她当时的情绪与认知偏差。眼下打开还能确认城墙归还路径，但也可能让私人记忆成为启动整墙的钥匙。

沈青崖说：“不开。”

她不是不想知道，而是不允许调查用一段关系迫使任何人承接。裴照川把蜡管封入冷匣，没有以共同当事人为由要求决定权。

其余小管中，一部分已经空了。空管封口没有破损，说明内容通过砖缝网络被抽走。最新七只空管的日期对应北门案、户籍房火灾、三百人梦行与镜城开门。每次异象都消耗了一部分储存在城墙里的记忆。

“它不是要把人关在镜城。”晏九道，“它在试着把这些东西送回来。”

“送给谁，由谁决定？”沈青崖问。

无人能答。

城内层指甲蜡线在此刻齐齐发热。七处门后的手同时离开门板，转而指向城中不同的人。有人叫出亡亲，有人叫出自己被删去的旧名，也有人捂住耳朵拒绝听。

沈青崖命各门守卒不得记录被喊出的名字，只记录谁主动应答、谁明确拒绝、谁失去意识。归还若不可避免，至少要先区分同意与被迫。

她与裴照川顺着最新黑线追到城墙最高处。女墙内侧嵌着一枚铜盘，盘面七个凹槽已经放入六枚黑蜡，最后一槽空着。槽边刻有沈问渠的旧印，铜盘下方却是闻如晦年轻时的记录官花押。

两人都参与过这套归还结构。一个想分散保存，一个相信可以统一控制。

第七槽旁写着一行细字：入口页持有者选择归还次序。

沈青崖掌中取出的百骨簿入口页，正是启动最后一槽的钥匙。

城下，七处门同时响起人声。数千段被压住的记忆已经沿城墙汇集，等待一次选择。

闻如晦站在太史局屋顶，隔着半城灯火望向她，没有靠近铜盘。

“今夜不归还，”他的声音由铜管传来，“明日它们会一起冲破。”

沈青崖没有回答是否相信。

她先检查铜盘。第七槽底部有一道新鲜血痕，掌纹只留下半枚，虎口处却没有她的灯焰伤。

已经有人用另一个“沈七”，试过这把钥匙。

她没有把掌心贴上铜盘。先让宋延取来细炭，在血痕外围拓下掌纹，再让三名不知情的书吏分别测量虎口、掌弓与无名指根的距离。三份数据差在半厘以内，足以证明留下血痕的人掌骨比例接近她，却不能证明那人就是沈照，更不能证明其同意启动归还。

裴照川沿铜盘边缘找到了另一组痕迹。那人右手虎口有旧茧，掌心中段缺一小块皮，像曾被烧过；落掌时没有把重量压在无名指根，而是以拇指和食指先触盘面。沈青崖的旧灯伤在掌心偏左，拇指根并无缺皮，两种伤不相同。

“他知道入口页在你手里。”晏九说。

“也可能只知道有人会来。”沈青崖答。她让他把血痕与西库六组孩童掌印、秦庐掌疤和城墙旧印逐一比对。掌纹有一处分叉像沈七幼年印记，却少了她后来形成的掌弓硬茧。那是一个年纪更小、或长期不以手工作的人。

铜盘下方的黑蜡忽然软了一线。城下有人喊出旧名，随即又有人拒绝应答。拒绝声没有被墙吸走，而是沿铜管传回，令最外层的头发蜡线短暂收缩。归还结构并非只会把记忆送出，也能记录不接受。

沈青崖取出入口页，隔着一层白布压在第七槽上。骨纸没有发热，说明钥匙不是纸本身，而是持有者的选择。她若按下去，六枚黑蜡会按某种次序打开；她若不按，闻如晦所说的“明日冲破”仍可能发生。无论哪一种，都不能让一个人替城中所有人同意。

“先拆外层来处。”裴照川说，“把会被送回的人和送回的方向分开，至少给每一处留出拒绝的时间。”

沈青崖看向六枚黑蜡。它们并非按日期排列，而按六名被救者在西库门外站过的位置排列。第一枚对应最靠近城门的人，最后一枚对应抱着孩子、从未回头的人。顺序本身就是一份证词，不能由她凭方便改动。

她命人把城下七处门的守卒换成不曾接触镜城的新人，门前各放一面白牌：愿承接、愿听取后再决定、拒绝。没有人能替他人举牌。闻如晦在屋顶看着这一切，第一次没有用铜管传话。

沈青崖仍未启动铜盘。她把入口页收回衣内，只留下六枚黑蜡的编号和掌痕证据。

“今夜先让证据归位。”她说，“记忆要归还，必须有人在场说愿意。”
