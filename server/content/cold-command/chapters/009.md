# 第九章 什长的第一顿饭

伙房门后的木板没有换新的。

顾沉舟让老邵把裂口周围削平，再用两根旧筷子从背面钉住。被砸掉的那一行没有补写，只在旁边添了一个空格，标注损坏时刻、发现人和木屑封存处。有人笑他连一块破板都要立案，他没有理会。板子可以破，规矩若只剩完整的字，下一次被砸掉的就会是经手人的名字。

天刚亮，苏晚棠便来报伤情。赵七膝肿未退，今日至少停工；韩魁左腕仍肿，原定三日停勤尚未满，也不能用长杆探冰；五名获救民夫中，老人高热，另两人脚底裂口，剩下两人能走，却不能搬重袋。医棚一夜用掉止血布六块、热姜两撮、清疮粉半匣，原本够三日的存药如今消耗得更快，必须补药布。

顾沉舟把药耗抄进粮册旁边，苏晚棠伸手按住他的笔。

“这是药账。”

“我只记今日要多拨的粥。”

“多拨五人，伤情不同。老人半碗温粥，能走的两人一人一碗，另外两人按医嘱分两次。”

她把份量写在自己的纸上，再让顾沉舟只抄口粮数，不把药名混进粮账。她说得很细，像是在防一场还没发生的争执。顾沉舟照办，顺手在最底下添了“粮与药分册，互校人数，不互代责任”。

辰时，陆承带着营门簿来伙房。他把昨日已核的五名民夫姓名逐一念出：魏大山、石顺、鲁五、陈六、许二。押车单上只有五个指印，民夫们说不清各自按在第几格，征夫棚原册只核出身份与未结役期，不能替他们说清谁在何处领过钱。

其中陈六听到自己的名字，脸色忽然变了。

“我还被报死过。那天押车的人拿着红纸，说我不能再回原村。”

门边的老邵停住手，陆承另叫旗手取来事故簿。上面果然有黑河滩陈六，押运途中坠冰，家属待报，报称时刻在夜哨之前。役册已结离营，事故簿又记坠冰，两处报得不同，昨日只查了役册，竟没看见这条。

陈六伸出手腕。绳痕还在，冻裂的皮肉边缘结着黑血。他不识字，却认得自己的名字被写在死册上，盯着那一行看了很久。

“我没有坠冰。”他说，“我和另外四人被领到南道，说是去搬粮。领车的说干完三日就给脚钱，后来把我们绑上车。”

顾沉舟没有立刻把死册说成假。他先问陆承：“这条由谁报？谁验尸？家属是否按过收尸单？”

陆承摇头。死册后面没有收尸单，只有一行潦草的“沿途失足，尸不全”。报案人写的是押运队，见证栏空着。

这是一项新的矛盾，却还不是结论。陈六活着，只能证明这条死录至少与事实不符，不能证明是谁把他写进去。顾沉舟让陆承把死册原页封存，把陈六的伤痕、口述和医官记录分成三份，再把其余四人的说法各自询问。五个人的记忆不能当五类证据，却能帮助确认押车单上的指印对应谁。

秦百户的亲兵在此时进来，带着一张领粮条：“东仓今日只放三百二十斤。仓曹说昨日缺额要从伙房自有余粮里扣。”

伙房里一下安静。三百二十斤比昨日实收还少，若按营兵、辅兵、民夫旧例分，先要扣守夜队、伤兵和五名新伤民夫，普通民夫每人只剩半碗稀粥。

顾沉舟把领粮条翻过来：“自有余粮多少？”

管事答：“昨夜分堆后，净麦还剩十八斤七两。三顿饭都要靠它补。”

“那就先称。”

亲兵皱眉：“秦百户说直接领。”

“他若只放三百二十斤，就把三百二十斤称清。十八斤七两是伙房余粮，也要单独封，不能被算成东仓今日发粮。”

陆承站在门外，没有替谁说话，只把营门的铜权送到秤边。丁二的原外借页与当班门哨已经核过，原物一直在门楼铁匣，丁三另属东仓，仍待查来历。顾沉舟先以丁二校白布秤，再请老邵和管事看秤。八袋净麦合计三百十九斤七两，比领条少七两；另把伙房余粮十八斤七两复称，不混入本日实收。

亲兵伸手要拿回条子。顾沉舟把一份抄本递给他：“可以送。原条由陆承带走，抄本给东仓。若仓曹要改，改动旁边必须留名字。”

亲兵盯着他：“你一个伙房文书，替谁发号施令？”

“我不发号。我只说明这三百二十斤从哪一袋出来。”

这句话让亲兵没法立刻撕纸。他若撕，便等于承认不愿留下重量。最后他收了抄本，冷声说午时再来。

午饭前，陆承把差条上十名搬粮辅兵叫到秤边，陈二领其中五人，另一组由老邵在灶口接。两名火夫照常看火，伤员与获救民夫不用。八袋一趟搬，每组四袋，均各约四十斤，袋皮另称，绳结挂甲至辛的木签；路线只走营内，不许靠近西墙。每过一处转角由一人报数，粮从秤旁到灶边不能散队。

陆承问：“你来领哪一组？”

“我不领人。我守中间的秤和总数。”

“那谁是头？”

顾沉舟看向一个在营中服役两年的民夫：“陈二，你借调来领头数袋，先不改役籍。东仓到伙房这一段若袋数对不上，先停，不追着人跑。”

陈二脸色发白：“我没有官牌。”

“所以只负责这一段，不负责发兵，不负责定罪。你若看见缺袋，把绳结和人名记下来。”

陆承在临时分工纸上写了“代领一段”，没有写正式什长。顾沉舟甚至不知道今日这顿饭能不能完整下锅。但十名辅兵和借调来报数的陈二在风雪里排好，没人再抢着去扛看不清来路的袋子，一支小队终于开始听同一个人的数。

午时，第一组粮袋送到伙房，少了一袋。

陈二没有追。他指着交接板：“东仓门口八袋，到转角还是八袋。火棚旁让开一辆柴车，再出来只剩七袋。少的是乙袋，出仓实称三十九斤九两。”

顾沉舟让所有人停下，先封住已到的七袋，再随陈二回火棚。辅兵鲁安承认自己让柴车时卸下过一袋，听见后面喊走便跟上，没再报数。棚旁留着一道拖痕、半截蓝线麻布与灰白草茎，柴车却已经不在。

秦百户终于现身。他看了一眼拖痕，说：“袋子可能自己滚进西墙。”

顾沉舟不在这里争是不是自己滚。他让陈二守住七袋，请陆承依换防权限查出门车册。门哨刚验过柴车，八捆柴，按往日的车辙深度，车身却沉得反常；柴在上面，未卸开看。车夫拿的是午后出门的柴票，此时午时刚到，正被挡在门洞。

陆承赶到门洞，先让门哨关住半扇门，自己站在车后。车夫不肯卸柴，说军灶等烧火，误了便找他们算。顾沉舟没去掀柴，只蹲下看轴，两轮沾的是棚下湿灰，车边拖落的蓝线还挂在木刺上。

“灶里火没断。”他抬头，“你票上出门在午后，柴却要现在往营外送。请门哨验夹层，不是伙房私扣你的柴。”

车夫一把攥住缰，牛往前拱，半扇门被撞得发响。陆承横矛在辕前，门哨拽住笼头。顾沉舟让到石墩后，没有拿伤手去拉牛。车停下，最下面两捆柴一抬，乙袋便露出来，木签仍系在原绳上。

袋子没开。白布秤重验，净麦三十九斤九两，封口的斜针与出仓画记相同。实物、木签与另一个门哨所验的车票对上，陆承才扣人，通知营官查他何时进火棚、替谁拉车。鲁安卸袋失职另记，不因为找回粮就免责。

七袋加追回的乙袋，仍是三百十九斤七两。顾沉舟让人按原数送灶，十八斤七两旧余粮本日全作补缺，没有再许诺明日还会有。午饭迟了半个时辰，至少三十九斤九两没有被一车柴带出营门。

本日可用净粮共三百三十八斤六两，按医棚、守夜队与各类军役旧额分配，三处灶口分批下锅。老邵最后舀了一勺，稠得立住半个勺面，递给陈二。陈二捧碗回队，先把那袋粮的木签挂回灶门，一排人跟着拿起了各自的碗。

饭后，陆承把临时分工纸递给顾沉舟：“营官看了，问你愿不愿意明日继续带这段。”

顾沉舟看向医棚。苏晚棠正在给韩魁换腕带，赵七坐在门边，五名民夫捧着碗，陈六还在盯那本死册。

“愿意。”他说，“但要把少一袋、五名伤民和死册矛盾一起报。只给我一段粮路，不给我替别人填空白的笔。”

陆承点头：“差条继续算。你领的是粮什，先学会让人不散队。那车夫归军法，不许你私问。”

远处东仓门内传来一声闷响，像有人把重物放下。顾沉舟回头，看见秦百户的亲兵从雪里捡起一块沾盐的黑硬皮，塞进袖中。

他没有追过去。那块皮若不能说明从哪辆车来，抢回来也只是另一件无人认领的东西。顾沉舟收起临时分工纸，在背面写下明日第一条：先查少袋去向，再查死册报案人；南沟样本未验，旧仓签与半枚印仍分开保管。

他第一次以“代领一段”的身份走回伙房，手里没有官印，肩上却多了三百十九斤七两粮、五名伤民和一条不能让人替他抹掉的路。
