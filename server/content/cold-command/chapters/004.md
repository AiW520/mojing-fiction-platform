# 第四章 第一车霉粮

天亮时，西墙下的两袋麦仍没有开封。

营门外已经排起了领粮队。有人裹着破毡，有人把空碗揣进怀里暖着，还有人咳得直不起腰。顾沉舟看了一眼队尾的赵七：他腿上换了干净布条，脸色仍白，木棍靠在肩边。苏晚棠带着药箱从营医棚赶来，先检查他膝上的肿胀，再问昨夜吃了什么。

“一碗稀粥。”赵七说。

“几更吃的？”

“戌时。”

“药还没领。先把伤腿抬高，今日不要搬粮。”

她说完便转向顾沉舟：“你记了伤情，没记他有没有发热，也没记昨夜换过几次布。伤兵册不是只记名字。”

“我没有医署的册。”

“现在这张就是。”苏晚棠把一页新纸放在他面前，“我记伤口和处置，你记口粮与经手。两册互校，不要替我判断伤势，也别把我的药耗写成粮耗。”

她说得很干脆，没有问秦百户是否准许。顾沉舟把纸接过来，发现页角已有她写的药名、剂量和库存数。她在每一行后留了签名格，连“缺药未用”也单列出来。

“药柜里够几日？”他问。

“按现有伤员，三日。若再有人受伤，止血散先断。”

“今日粮若不发，伤兵也会断炊。”

“所以我没叫你不发。”苏晚棠把药箱扣好，“我只要你别把‘发过粮’写成‘够吃’。”

这句话让顾沉舟停了笔。他原想在记录里写“按额发放”，现在改成“按现存三百六十斤实称分发，仍不足原定口粮”。

秦百户带着两名仓兵到了西墙。他先看车，再看顾沉舟手里的小册。“谁叫你扣着粮？”

“我没有扣粮。短签没有仓票、没有仓号、没有经手人。袋子还没开，若现在拆了，便无法确认里面是什么。”

“上头说是粮，就是粮。”

“那请您在短签上补明粮种、重量、出仓仓号和交接人。”

秦百户没有去看短签，只伸手要顾沉舟让开。守车辅兵下意识把路堵住，又很快侧开半步。他怕违令，也怕日后被说私改交割。顾沉舟没有拦秦百户，只把灯、木尺、封存布和空白回执摆到车旁。

“可以开。”他说，“请先记封线完整，开袋后取样称重。由您、伙房管事和守车人共同在场，三份各留一份。”

“我为什么要替你作证？”

“您不必替我作证。您只需证明仓曹接收的是什么。”

秦百户盯着他，半晌才把目光转向排队的人。队伍没有吵闹，但每个人都看着两袋麦。若他下令搬走，众人会记住是仓曹拿走了粮；若他留下，缺口便落在他自己手里。顾沉舟看得出来，他不是不懂这点，只是在算哪一种风险更小。

最后，秦百户让仓兵把短签按在车辕上，补写了“东仓转伙房，两袋，待称”。他没有写重量和交接人，只在旁边盖下自己的私印。

“这不是正式仓票。”顾沉舟提醒。

“我知道。”秦百户说，“够你开袋了。”

这不是认错，也不是许可，只是把一段经手写在纸上。顾沉舟让管事、守车辅兵和换防官各按一次指印，确认封线未动。短签上三种字迹挤在一起，不能替代正式仓票，却能证明这两袋粮的交割发生过。

第一袋被割开时，一股酸腐气涌出来。袋口上层是发黄的麦，下面却结成暗褐色的硬块。苏晚棠戴上布巾，用木片挑开一团霉结，又把几粒麦放在白纸上。她只说：“不可直接入锅。霉变不均，清洗也不能保证能吃。”

队伍里有人低声骂了一句。

顾沉舟没有顺着骂。他让守车辅兵把整袋倒在篾席上，先分出表层、中层和袋底三个样本，各自装纸包、写上位置、时刻和见证人。再把空袋过秤，记录袋重。第二袋照此办理。全程没有人离开，也没有人代替旁人签名。

两袋净重合计九十六斤。可用部分还要再筛，霉坏与虫蛀加起来近三成。若全扔掉，今日伙房缺口更大；若全煮，伤兵和民夫会先吃下风险。

“坏的挑掉，剩下的煮粥。”秦百户说，“总不能让人看着粮饿死。”

苏晚棠没有和他争。“我不能证明剩下的完全安全。若要发，必须单独标记批次，先给身体强健、已知情并自愿领取的人；伤员、幼弱民夫和发热者不领。另留一份样本，记录谁决定发放。”

秦百户皱眉：“军营哪来那么多自愿？”

“那就先不发。”

“你一句话，几百人都等着。”

“我负责说清风险，不负责把风险藏进锅里。”

两人的声音都不高。顾沉舟看着那堆麦，忽然明白这不是一道算术题。九十六斤里面有能吃的部分，也有尚不能确认的部分；如果他只报一个“可用六十斤”，那六十斤就会变成没人负责的命令。

他提议把两袋粮全部隔离，不以挑拣结果认定安全。伙房先向东灶借用昨日验过的净麦，借粮数量、出仓人和归还期限另立一张借据；霉麦只做取样，不进锅。这样今日仍会少一部分粮，却不会把病患变成验粮的砝码。

秦百户立刻问：“谁准你向东灶借？”

“没人准。”顾沉舟说，“所以借据上把决定人留空，您若不肯签，管事可以不借。”

管事盯着队伍里越来越多的空碗，咬牙道：“我借二十斤，明日午前补回。若仓曹不认，我自己去解释。”

陆承也在这时取来营门的旧验粮记录。上面记着昨日东灶余粮二十七斤，已有三名守夜兵按指印确认。顾沉舟将借粮数限定为二十斤，不许把所有余粮搬空，另留七斤给夜哨，并把借据交给陆承保管。

苏晚棠把霉麦样本封在医棚外，不准任何人以“试吃”名义打开。她说：“没有能证明安全的检验，就不让伤兵和民夫替仓曹承担后果。”

午时过后，筛出的四十一斤净麦仍只作待验物，不能混入常粮。秦百户在回执上写“霉变粮暂存西墙”，却拒绝在“责任人”一栏落名；顾沉舟遂把空白原样保留，又请陆承写下见证。管事接收二十斤借粮，注明归还日，不把借来的粮冒充今日入库。

二十斤借粮并没有让所有人吃饱，只让队伍少等了半个时辰。其他人的口粮仍不足，老邵把自己的那份分给病中的同伴，顾沉舟在册上记的是两人各自实际领到多少，而不是老邵“捐出”的粮。借据则由管事、陆承和借出东灶的守夜兵各留一份，谁明日不还，谁先被叫到营门。

这笔账没有漂亮的结尾。

傍晚，筛选粮的小样仍留在医棚外的木架上，尚未到苏晚棠愿意给出结论的时辰。她让人每日查看颜色、气味和虫痕，却不让任何人入口；清水和止泻药则先备在旁边，以防有人私自尝食。秦百户带走了霉粮样本的副封，营门换防官留了一份，顾沉舟把最后一份放进木匣。

车辙却没有留下来。午后的风雪压过西墙，原本两条窄辙只剩浅浅一道。顾沉舟赶在天黑前拓了轮距和印深，又从车辐上取下灰白草茎，写明由守车辅兵指出位置。草茎不像黑河滩常见的芦草，茎节更短，带着一股淡淡的盐碱味。

他还不能说这车来自哪里，更不能说霉粮是谁换进来的。短签只证明它被送到营墙下，封线只证明开袋前未动，称量只证明两袋里有九十六斤粮和近三成坏损。

这些证据把问题缩小了一点，却把新的责任推到了他们面前：二十斤借粮若明日不能归还，借出东灶、接收伙房和批准调拨的人都不能从账上消失；四十一斤筛选粮若被人擅自混入常粮，封存和看守者同样要说明去向。

夜深时，营医棚仍亮着一盏灯。苏晚棠把霉麦样本的气味、颜色和封存时刻逐项记下，又去看赵七的膝伤，把“未进食霉麦”写在伤兵记录旁。顾沉舟在旁边誊录，没有把“暂未试吃”写成“粮食无害”。

他最后在今日回执上写：第一车霉粮，待复验；筛出四十一斤，未入常粮；东灶借粮二十斤，明日午前归还；其余封存；发放不足额，缺口未补。

墨迹尚湿，仓门外又传来车铃。

这一回，车没有停在西墙，而是径直朝营门去了。
