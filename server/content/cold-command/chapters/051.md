# 第五十一章 让粮先过桥

正月二十卯初，桥南的横木裂到了榫头。

许木匠刮开覆雪，锤尖才碰上去，一块木皮便掉进水里。梁铁站在岸上，身后九个候工人已经带齐木锹，南驿的粮车却还没有出门。顾沉舟把昨天的停运回条翻过来，画了两条路：西旱路绕城，南渠桥通秤房。

“旱路多走七里。”陈二说，“日头一偏，北坡结冰，两辆车都得留在坡外。”

“所以修桥，不是催车。”顾沉舟蹲在裂木前，左肩只一动便发疼。他把锤递还许木匠，“这两根闸木别拆。桥借走了，渠明日又没有闸。”

梁铁已经伸手去解新闸木的盖草，闻言停住。桥和渠都缺木，两日前获拨的两根木料、四副铁箍只够修渠，不该凭一声急令变成两处都有。顾沉舟请陈二去县方修棚料场问干梁，自己与许木匠查桥石。

桥是石墩木面，坏的是南端引桥横梁，桥中两座石墩没有露出新裂。许木匠从岸上探榫口，陈二回来后另带县工曹小吏，从下游干滩看石脚。两边分别量过水痕、梁距与木头的朽口，才合在一起说：可以换南梁，不能在旧裂梁上抱铁箍硬顶。

县工曹有两根干梁，原拟修货棚，换到桥头便要另买棚料。邢良跟着车来，看见十个工人，先问谁认这笔损耗。

“县丞准你今日借料，只准桥，不准渠。”他把料单展在顾沉舟面前，“明日货棚还要开门，别把梁截短了，还我一捆柴。”

顾沉舟认下借用和返补的报请责任，不许诺军粮折木。许木匠选一根长梁替换，一根完整留岸作备用；拆下的旧梁单放，不混进还料。邢良看过尺寸，派一个县役跟着看，他防的不是空话，而是今天借出去的好木明日找不回来。

罗定昨夜针对停运回报补来的副令，由崔岳当众读出。崔岳与三名营兵护桥护车，两名院兵守南仓院门，独立仓兵仍守原有一百斤粮；南驿两车夫、两轻车转运四袋二百斤。护运另领饼四斤、水两囊、牛料十二斤，至桥南卸牛，以绳牵车过桥。木梁再响、水涨过榫口或出现持械堵路，便退南驿；伤者送驿，天黑不再上桥。

十名原试工者仍只做半日，今日改修桥头浅段，不下膝深水。梁铁和三人配木，六人清岸、铺退车板；许木匠另为技术匠，不挤进十人领工粮。顾沉舟负责车序，兵归崔岳，任何人不能拿新排程牌添第二班兵。

巳初，旧梁抽出来时，藏在梁腹里的黑水淌了半尺。梁铁本来想让众人站上桥压住另一头，许木匠却把人全部赶回石岸，先用两根岸上支杆承住空桥，再将干梁横送入槽。顾沉舟站在退车板旁报尺，右虎口的布结抵在袖内，始终没有下去托梁。

新梁入槽，桥面却仍有一处翘起。石满指着木板下面：“底下卡着东西。”

少年被留在岸上递短楔，不许钻桥。梁铁用长钩取出一只破草鞋，下面还有半截旧钉。木板落平，许木匠重新钉住板头，先以空车试行，再分次加上过秤的石块，直到与一百斤净粮加车身的重量相当。县工曹小吏看石脚，许木匠看榫口，各自报不沉不响，试车才退回岸上。

修桥半日实领工粮十一斤二两，由驿厨从此前余下的七十九斤二两工粮里支出，余六十八斤；十八斤八两旧预留仍未动。厨工今日另送二十斤续赈麦，专给五十七人，柳枝先给伤病和孩子盛粥。桥修好了，工锅与赈锅也没有因此合成一口。

试压的石头还横在井路边，何氏端着水桶过来，桶底磕上石角，半桶水洒进雪里。梁铁招呼人抬石，顾沉舟却先指向岸边的旧垫石堆。孟槐认出三块石的旧凿口，许木匠确认它们不是桥墩脚石，众人才沿原路搬回，留出取水的地方。何氏没道谢，只又提起空桶；顾沉舟看着她走远，叫陈二明日先查井路，再查车能不能转弯。

梁铁喝完粥还想留下牵绳，旁边两名工人也把绳圈搭上肩。顾沉舟拦住他们：“修桥的半日已经到了。下午护车是另一份活。”

三人听见有钱，先没有笑。一个问，若车没过桥，是不是又算没做成。顾沉舟请崔岳核看副令里的岸上助绳用工，驿书记确认杂役钱可付三人各半日；不以车到作为付钱条件，不追加工粮。梁铁这才重新接绳，余七人收工具回滩，谁也没有被一句粮急扣在桥上。

午后两辆粮车到桥南。四袋各五十斤，南驿仓兵与车夫认过封线，原留四百斤中二百斤发出、二百斤仍在驿棚。粮未抵宁川前，不加到秤房旧存的一百斤里。陈二核袋号，县方小吏只看桥，不替仓兵认粮。

第一车卸牛后，车夫拉前绳，梁铁与两名工人从岸上助绳。崔岳和一兵跟车，两兵分守桥头；顾沉舟与许木匠在岸边看轮距。车轮越过新梁，四下只有绳磨木的细响，北岸回声传来：“两袋到，车离桥！”

第二车刚上引桥，南端一块垫轮短板便向外滑了半掌。

不是梁断，是两车先后碾过，板下的薄冰被压化。右轮靠近板沿，前绳顿时斜拉。车夫本能地往前跑，梁铁却要向右拽，两个方向一错，车身猛地歪向水边。

“松前绳，不松后绳！”顾沉舟喊。

陈二已经把看客拦到岸后。崔岳没有让兵跳水推轮，一兵压住后绳，车夫把前绳放缓，梁铁退到岸上旧桩旁绕绳。重车停止向前，袋子仍在车板上，封线未触水；许木匠举钩够到滑板，却够不着车轮下面。

孟槐在北岸叫道：“东边有石肩，轮退半尺能踩上！”

顾沉舟看桥图，那里是旧石墩外伸的硬面。他让北岸车夫看准石肩，先报距，再让后绳缓退。车轮一点点滚回，板缘擦着轮皮落进水里，岸上众人都屏住了气。只要为了抢快再拽一次，车就会越过石肩。

崔岳蹲在车后，盾背挡住松袋，短短喊了三回停。右轮终于压回硬石面。许木匠从岸上送长板，让梁铁将板头落在石肩与新梁上，两端楔住，另钉防滑木。车没有倾覆，修补却又耗去半刻。

邢良在南岸看得脸色发白。他原想催车先过，见了这一回，亲自把待走商车移开，给粮车留下整段退路。那块滑板取不回来，木损如实报；没人把险情说成没发生，更没人替车夫写个“操作失误”就算了。

第二车重新牵过桥时，梁铁的手抖得握不住绳。顾沉舟让他退下歇息，换车夫接前绳，自己仍只报轮距。车过北岸，四袋全数离开桥面，崔岳才放下盾。

两车顺旧巷入南仓石秤房。主仓险梁下不走，六户井路不堵，独立仓兵会同驿仓复核人逐袋称净，四袋仍各五十斤，袋底干燥。木床原准十袋容量，现有两袋旧粮加四袋新粮，共六袋三百斤，封粮钥匙仍在仓兵手中，孟槐只掌房门。顾沉舟没有伸手接任何一把钥匙。

复核人写第三袋时，照着上一行又写了一遍袋号。陈二压住页角，没有急着喊满六袋，只请他把木床上的四个新号逐一念出。两只旧袋靠墙，新袋隔木条排在外侧，六道封线各在眼前；错页留在册尾，新页重新对完，车夫才肯松手。他一路看着这四袋，知道把号抄对与把粮称对一样，明日都能找到自己。

陈二将南驿二百斤余存、宁川新收二百斤、宁川旧存一百斤写在三个地方。车夫终于拿到收讫页，惊魂未定地摸着车辕说：“下次来，是不是还走这儿？”

“明晨复桥，没过检就不走。”顾沉舟答，“你今日的等桥脚钱照结，不叫你拿迟到赔粮。”

许木匠又摸了一遍第二车的后档。钉头被盾沿擦起，横档尚未裂，他叫车夫别装返货，空车慢行回驿，次晨由车匠换钉查轴；粮袋干燥，不等于车可以立刻重载。车夫将那处擦痕圈上白绳，省得回来被当成旧损。

梁铁右膝在换绳时碰石，肿了一小块，顾沉舟让陈二与一兵送他乘返驿车检查，余人不跟着起哄。驿医回条说膝挫伤，停搬重三日；其他九名试工者无新伤，周四仍停土工。新增医食由驿医另接，不能再回河滩领第二碗。

护运饼四斤耗二斤六两，水两囊耗一囊半，牛料十二斤耗八斤，余数随两车核回。干梁一根已用、一根原样还县，闸木铁箍仍留渠旁；长板和滑板损耗、等桥脚钱、梁铁伤工另报。新存粮三百斤一袋未开，白石旧借早已结清，不进今日收讫。

陈二与护送营兵在暮色里回到院门，带回梁铁的停工条，两辆空车和两车夫均留南驿。崔岳清齐原四名护运兵，另两名院兵没有离门。马六提着一盏灯来给仓兵照门。昨日他拿着盐还不知道明日有什么，今日却能看见六只实袋摆在木床上，没有一张票替它们占位。

顾沉舟收好回条，终于把排程牌上的“待过桥”划去。桥南空地还留着那两道险滑的车痕，他让许木匠明日先去复查，不许雪盖了就算无事。粮已经到了，下一步要有人能护住车、看住退路，不靠每一趟都临时喊人。

孟槐指了指秤房后面的破校场：“那边以前练车。你要教人，这块地先得看过。”
