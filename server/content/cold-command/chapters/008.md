# 第八章 旧驿道的水印

南沟的碑坑比顾沉舟想象的浅。

石碑埋了三年，根部泥土本该冻成一块。坑壁却只留下薄薄一圈冻壳，底下湿土新翻，旁边有两道拖曳印，向西隐入废井旁的芦草。

魏三站在十步外，指着坑：“碑就在这儿，我没有记错。”

陆承没让他靠近。此次出营五人，陆承带两名门哨，顾沉舟记路取样，魏三认旧地；往返南三里，日落前回营，携干饼一斤半、水两囊，不入废井，不追持械者，谁受伤便中止取样，由一名门哨护送。韩魁留医棚，苏晚棠不能丢下五名伤民随行。

顾沉舟先在图上画坑，再量拖印宽度。两名门哨分别留在路口与槽边，魏三站过的地方也用细枝标出。新雪未下，若有人跟来，至少能分清他们自己的脚印。

石槽塌了半边，里面的黑冰结得不匀。门哨先从上游净水处装了一瓶，再去下游取一瓶，顾沉舟用竹片刮取槽中冰屑，三项各写位置时辰。西墙黑硬皮留在营里，不能带到这里与水槽搅成同一碗。

魏三说废井盐碱更重，顾沉舟只在图旁记下待查。盐白圈能缩小范围，不能直接把一辆车钉在某一条沟上。

陆承忽然蹲下，指向槽边横着的一块旧木板。

板底有新刮痕，铁钉上挂着三道蓝线的麻布，另一头还压在冰下。与废渡口的碎片同为麻袋粗织，针脚却不完全相同。顾沉舟没有扯，先让门哨画位置，取下钉旁碎片，再割开周围冰层，将冰下那块另包。

“车停这里换过袋。”魏三道。

“也可能是垫轮留下的。”顾沉舟将两种可能都写下，“你以前来，有这块板么？”

“有板，没这道刮口。”

这句话归到口供，不替新刮痕确定年月。他把父亲残账拓本拿出来，烧断的水线与眼前旧槽仿佛同向，却缺去最要紧的一段。纸上的路可以是一处驿站，也可以是一条排水渠。

顾沉舟收起拓本。他来之前想得太快，仿佛那条断线会领他找到父亲没能走完的路。眼前冻土没有替他认亲。

芦草里忽然响了一声。

路口的门哨持矛转身，陆承将魏三拉到石槽后。一个汉子抱着麻绳从废井后钻出来，看见五人，先愣，随即掉头往坡上跑。

“别追！”陆承喝道。

门哨停在路边。跑的人弃下绳子，越过冻沟便没了影，只有芦草深处露出一截浅灰石头。

“碑。”魏三喘着气说。

陆承让门哨站定两边，自己用矛杆探过地面，确认不靠井口，才走近看。石碑横躺在草里，背面系着未拆的绳，绳子拖到沟边断了一截。底座有湿泥，碑面“景和十四”尚能认，下面刻的字被凿坏一半。

顾沉舟没有叫人把碑抬走。五个人抬不动，更不能让魏三带伤旁证搬沉石。他用纸贴着未破部分拓字，门哨在旁念出一行：“西仓七，转运歇脚……后三字毁了。”

丁七破鞋里那张旧油纸，同样剩着“西仓七、景和十六”。一个是旧路碑，一个是私藏纸，两物并非同年，却第一次把西仓七从口供里的三个字落到了实地。

“记错路的人不会让碑自己跑到草里。”魏三捏着衣角，声音终于稳了一点。

“你认对地点，不等于认出移碑的人。”顾沉舟道，“方才那人只看见背影，不写姓名。”

魏三点头。石碑留下原地，两名门哨分记发现位置、绳痕和拓字，陆承要等营官派人白日拖回。碑坑旁还有一枚暗铜屑，顾沉舟用竹夹另包，注明来源未明，不往半枚铜印上拼。

他们封箱时，东仓的两名骑兵到了。

来人携着秦百户口令，要求野外取回之物全部送东仓，由仓曹统一复验。陆承展开，日期竟写成尚未到的明日，落款无改记。

仓兵说是书吏写快了：“印是真的。你总不能因为一个日子误了军务。”

“误字能补。”陆承道，“谁补，写谁。你们先看清箱里几瓶几包，别到东仓又说只收了泥。”

顾沉舟把箱扣压住。此令不能仅凭错日子便认假，秦百户确有复核仓损的职权；可一旦不列物项交出，日后便没有人能说原物还在不在。

他当场写交接：两瓶水、一包冰屑、两片分取麻布、一枚来源未明铜屑，拓字只是抄证，石碑尚在野外。每一封都让仓兵看过，陆承负责押回营门，再请营官定复验的地方。

仓兵看见“石碑尚在”几字，目光终于越过顾沉舟，落向芦草。

“那个也算？”

“算地点，不算粮重。”

仓兵没有伸手抢。他们带不走碑，强拿小箱也不能抹掉两名门哨见过的字，只能催他们回营。

秦百户在东仓等着，门旁摆了铜权“丁三”。营门外借册写的却是“丁二”，陆承不许立刻拿来验白布秤。秦百户叫来罗老卒，说东仓自有另一件铜权，营门抄错不该怪仓曹。

顾沉舟将编号另列。他没有推翻先前白布秤的全部称量，也不许用未互校的丁三给旧记录倒补重量。两套器具的来历、借出日期，明日各拿簿子核。

争执被一个喊声截断。

征夫棚来的老里正站在医棚门口，指着一张役册，喊“人不是逃的”。随行旗手拿的是征夫棚原册，昨夜救回的五人，姓名、村居与领夫人都在。石顺与许二仍列在南道随运，另外三人却被营中抄册提前勾成“已结离营”。

顾沉舟看两册时，陈六站在门后，手握得发白。

“我说了，我没领钱。”

里正带来本村出工底册，既不属伙房，也不属押车队。民册、医官所记绳伤与押车单上的“自行离营”，至此才有了各自不同的出处。

营官周校尉被旗手请来。他听完昨夜救人的军令改记，又逐项问了五人的役期，不许五人合答。秦百户只说工钱归押运队发，不由东仓经手。周校尉没有当场把这话判作推脱，却让军法书吏写下待问的押运队名册。

“五人留医棚。原册上的离营结项暂撤，工钱记欠，不许追他们赔粮，也不许今日就派回南道。”

陈六猛地扶住门框。石顺攥着自己布牌，嘴唇动了几次，最后只挤出“记欠就好”。

两吊工钱还没到手，五人的人身去处先被保住了。

顾沉舟松了一口气，周校尉随即把新差事压在他面前。

“医棚新增五份口粮，明日由伙房与军需房另核。伤者不许抵搬粮额。你今日能把碑找回来，就别明日把人饿没了。”

顾沉舟接过差条。赵七不能扛袋，韩魁不能骑射，医棚的药又少去一截。十个原管搬粮的辅兵缺一名能算清的人，周校尉准他临代粮什，只领营内运粮这一段，既不授仓钥，也不许越级调兵。军籍、名号与功劳仍等军法复核。

老邵闻讯拿来十只旧碗，说新带人先得认得谁吃哪份。顾沉舟正要点名，伙房门后忽然传来一声脆响。

写着交割规矩的木板被砸裂了。

砸板的人不见，雪地脚印与来往军卒混在一起，认不出谁走过。顾沉舟把碎板捡起，没让陆承带人逐个搜帐。碑可以移，板可以砸，今夜医棚里却有五个活人，明早有十个等着他领粮的辅兵。

他将两根筷子钉到木板背面，再把新差条挂在裂口旁。

“碗留下。”他对老邵说，“明日先把人认全。”

老邵把十只碗逐一翻过来，在碗底用木炭写下甲到癸的记号，又把医棚五人的碗另放一排。顾沉舟看着那些粗糙的黑字，忽然明白临代粮什的第一道命令不是带人搬袋，而是先承认每个需要吃饭的人都在场。谁少了一碗，谁多拿了一碗，明早都得从这里追到出仓簿。
