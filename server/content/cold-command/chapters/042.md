# 第四十二章 贺兰兄案

正月十一，贺兰朔把一卷旧皮纸放到粮案边。

纸不是军报，边角被水泡过，墨迹只剩一半。最上面还能辨出“白石北坡，押运二车”，下面的人名被刀刮去，日期落在景和十五年腊月。

“这是我兄长贺兰真死前的押运单。”贺兰朔说，“军法档里记的是遇盗失踪，家属只领了一半抚恤。昨夜蓝线麻布从柳台皮囊里露出，我想先把旧案拿来比，不是要你替我翻案。”

顾沉舟没有碰纸。他让苏晚棠先看贺兰朔的右手。昨夜夺水口时，他虎口裂开一线，骑鞭处磨出血泡，今日不宜拉满弓。苏晚棠让他停骑半日，药耗一尺止血布，仍不准把伤情写进旧案证人栏。

“你若停骑，柳台的马印谁复核？”顾沉舟问。

“用我的旧图和副骑的现场记。”贺兰朔答，“人不能因为想证明自己没错，就把伤口藏进证据里。”

这句话让谢无咎抬了头。他拿来一张白石旧仓的副页：“景和十五年腊月，北坡确有两车盐麦失联，但转运司记为已入白石。押运单不在三关正册里，只有这张副页。”

顾沉舟将三样东西分开放：贺兰真旧押运单、柳台蓝线皮囊、白石转运副页。蓝线麻布尚未验纹，不能因同色就相认；旧单没有重量栏，副页也没有实际入仓人的名字。

罗定准查旧案，但要求先写范围：顾沉舟、苏晚棠、副骑和军需房一名书记四人进关内档房，贺兰朔留门外候询；只查雁回现存抄本与白石回执，不开南墙仓、不调黑河原件、不去白石抓人。半日内回守将房，口粮仍按关内日额，伤者由档房门哨接送医棚；发现有人强夺卷宗，停止翻查，守住现物并回报。谢无咎以转运使身份到场答询，不替原档经手人作证。

查档房里果然少了一页。缺页边缘留着三孔针痕，与白石旧副页装订孔不一致。书记从箱底找出一张借阅条：景和十六年有人以“贺兰真案复核”为名取走原卷，归还栏空着，借阅人只写“谢”。

谢无咎脸色没有变：“转运司里姓谢的有三人，不能拿一个姓定我。”

“那就查笔迹、时辰和经手柜。”顾沉舟说，“先证明谁借过，再谈是不是你。”

借阅条背面沾着一粒红砂。苏晚棠没有刮，她把整张纸平放进纸夹，标明红砂位置；顾沉舟又请书记查看同柜其他旧卷，未见同样的砂。砂何时沾上仍无法确定，更不能证明来自柳台骨牌。

白石副页上有两栏数字：麦四百斤，盐料六十斤。贺兰真押运单只写“二车”，没有袋数；军法档却写“二车失踪，六人遇盗，贺兰真当场身亡”。人数、盐料和主将名字互相咬住，却没有尸验和家属签押。

贺兰朔站在门口，手指按住弓弦。“我家拿到的只有半份。其余五家到底拿了多少，也该问一问。”

苏晚棠翻出军医旧册。册中只有五名伤者，无贺兰真的尸体记录；死者栏写“头部重创，无法辨认”，接收人一栏空白。她没有说贺兰真没死，只把“无法辨认”与“无接收人”列成两条缺口。

顾沉舟将缺口写在木板上：押运单缺重量，副页缺领受人，军法档缺原卷，医册缺接收，抚恤缺家属全额。五条各自成立，不能由贺兰朔一句怀疑合成谋杀。

书记刚把医册合上，柜后忽然传来一声急响。档吏抱着两捆废纸进门，手里还夹着一张火房领料条，说昨夜已点过数，今日得把受潮旧纸送去引火。

顾沉舟先看见纸捆最底下露出一截细红绳。不是官卷的装订线，而是贺兰朔旧皮纸上那种牧户结绳。他用左手按住纸捆，没有拉扯：“先放桌上，领料条给书记看。”

档吏不肯放：“火房等着，耽误开锅你来担？”

“火房还留着昨天的碎木。”副骑挡住门，没拔刀，“先查你领的是什么纸。”

档吏往外一侧身，纸捆撞上门框，最下头一张滑了出来。贺兰朔从门外接住，右手一紧，伤口又痛得发白。苏晚棠立即叫他松手，让副骑托住纸，他却仍盯着纸背那三个歪斜的字：“贺兰家。”

那是一张退回家属申诉的回条，落款景和十六年二月。正文写“亲属未赴复核”，边上却有雁回旧门房记的来访日：二月初九，妇人一名，同行幼女一名，候至申时。

“来的是我嫂子，孩子那年六岁。”贺兰朔说，“她说等了一整日，门房只告诉她人已不在这里。我当时在草场，回来还怪她没把话问清。”

声音到最后一句才哑下来。顾沉舟让他坐到门外矮凳，没有用这份回条去补尸验，而是叫书记取来二月门簿。簿上果然有同日妇人与幼女的记录，写着“候问押运死伤”，没有姓名，门哨旧押却完整。

两件材料由不同人留下，只能证明当日确有家属来问，与“未赴复核”存在冲突。要确认是不是贺兰真家人，还得问嫂子，不能靠贺兰朔认出三个字就算全证。可这次不是同色麻线勾起的猜想，而是一张曾被退回的纸与一日真正的候门。

罗定闻讯赶到，先扣下废纸捆。领料条写“无字破纸三斤”，捆内却有来访回条与旧役工凭据，至少不符合领料范围。档吏解释说上月收拾柜底时把它们错归了废纸，他不知贺兰真是谁，也从未见过原卷。罗定不许当场拷问，只让门哨看住纸捆和领料条，档吏交出柜钥候军法核问。

谢无咎伸手取过领料条抄本：“这张条是军需房出的，不是转运司。你们别借一捆错纸把三关的档案全封了。”

“只封这捆。”顾沉舟说，“其他现粮、役工和伤员的凭据照常办。错纸已经有实物和领料条互校，谁归捆、谁点数，今日就能问；旧案的原卷仍要等白石。”

火房没有因此停锅。陈二带来半车昨日剩下的刨花，炊兵用原有碎木引火，晚饭只迟了半刻。顾沉舟把刨花回仓量交老周核回，没有让救下一张旧纸的代价落到等饭的兵卒头上。

正午，军需房书记从旧柜缝里找到半枚铜印。印面只有“北”字一角，与贺兰真旧单右下方的压痕方向相反；可能是盖印时纸张折过，也可能是后补。顾沉舟让书记不要尝试拼印，将铜印交军法司押存。

谢无咎忽然提出：“若你们怕借调档再丢原物，可以停白石一班粮车，由押运兵专送旧档。但你们得自己承担这班延误。”

“不必停粮。”顾沉舟答，“柳台马印只到水槽，白石旧案在北坡；蓝线皮囊尚未验纹。白石先由原有驿递送卷目抄录，原卷怎么护送再请军法定令。先保留水路，另发调档文给白石，要求查出景和十五年腊月北坡出入簿，不动现粮。”

罗定准了调档令，却把责任压给谢无咎：“白石若拒交，先由转运使承担延误，不准顾沉舟私派兵。”

谢无咎接令时，手指在纸边停了半刻。他没有再提封仓，只要求把贺兰真案列为待核，不许写成旧案已破。

下午，苏晚棠完成蓝线初看。皮囊里的麻布只有一条蓝色经线，色泽被油浸过，暂时无法与黑河封存样本比对；借阅条上的红砂颗粒较粗，夹着似铁屑的细点，骨牌槽内砂仍未刮取，无法据此确认同源。两项结果都不足以把柳台皮囊接入贺兰真案。

贺兰朔听完，竟松了手。他把旧押运单重新折好：“至少现在知道，不能拿相似颜色替我兄长定死。”

“也不能拿旧案替今日水口定罪。”顾沉舟说，“但借阅条、医册缺口和白石副页已经改变查法。今晚先保水，明日让白石交档。”

傍晚，北水槽恢复七成水量。昨夜夺回的石片被留在原地，裂木没有拔。贺兰朔停骑，副骑接替巡水；两名营兵守槽尾，新增夜哨干饼两斤、灯油半升。医棚车夫伤口缝合，停拉绳一日，脚钱不从水口损耗里扣。

顾沉舟把今日账证分成四栏：水口恢复七成，溪水仍不用作饮水，马印与木桩待查；贺兰真旧案出现借阅条、医册、抚恤与候门回条缺口；白石现粮不停，调档文已出，三日内先回卷目，逾期报延误而不先判拒交；车夫与贺兰朔的伤情各自列册。顾沉舟自己的肩伤和虎口旧伤仍未销，他今日只查纸，没有搬柜。

罗定看着四栏，问：“这算不算替贺兰校尉讨回第一笔账？”

“只算找到了账被撕开的地方。”顾沉舟说，“真正的账，还要有人把缺页送回来。”

夜风掠过北水槽，槽尾没有再响鼓。远处白石方向升起一线灯火，像有人收到调档令后，终于想起一卷被借走多年的旧案。
