# 第四十一章 夺回水口

正月初十，北水槽在卯时断了水。

不是山溪枯了。上游木管仍有水声，到了槽尾却只剩一股贴着冰缝流的细线。昨夜封存的裂木还插在原位，管口外的松油水样已经送进医棚验看，谁也没有先拔它。

顾沉舟到槽尾时，先看见两辆水车停在墙影里。车夫不敢靠近，门哨把出入簿递给他：昨夜子时之后没有车辆出关，今晨第一辆取水车按时出门，却在石台前发现水量骤减。

“槽尾有人动过？”罗定问。

“先看水位。”顾沉舟蹲下，没有碰裂木。他让老周沿木管外壁量冰层厚度，又让陈二在上游石台和槽尾各插一根标杆。两处水面高度相差不到半掌，断流不是上游截水。裂木靠东，黑砂在下风口，松油薄膜却浮在西侧，三件物证没有落在同一条线上。

贺兰朔带两骑从柳台回来，马蹄上裹着湿泥。“柳台空车还在。六只空袋袋口朝下，昨夜没有人取走。两根削短木桩少了一根。”

“少的那根呢？”顾沉舟问。

“在水槽北侧，插在冰缝边，像临时撑过车轮。”

贺兰朔把木桩位置图摊在雪上。桩尖沾着红砂，和骨牌槽内的红砂颜色相近，却不能直接相认。顾沉舟让门哨从桩尖取样，骨牌继续封存，水槽泥也另装一包。

谢无咎赶来时，先问的不是水，而是今日粮额：“没有水，伙房还能照额开锅吗？”

“人粮不减，锅灶和医棚优先，现役马先用内井水，两匹备用驮马延后一轮，不许拖过午前。”顾沉舟报出分配，“内井由留关脚夫挑水，每趟两囊；四名营兵护送两车夫去上游石台，半个时辰一轮。两路挑水合计增加八人次役时，预留灯油半升，马料不折水价。”

谢无咎盯着他：“北水槽是军用水口，为什么不把柳台空车拖回来，拆木取水？”

“空车尚未核明，拖回便毁现场。今日取水可以走上游石台，车辙、人数和时刻先留下。”顾沉舟指向军令，“若水量不足，再申请夺回槽尾，但不能拿一辆来历不明的车换一条未经验明的管路。”

罗定准了临时取水令：四名营兵、两名车夫、两辆水车，沿墙影到上游石台，半个时辰一轮，日落前四轮；六人仍按今日伙食领粮，每轮带温水两囊，留一车空位接伤者。冰裂、三名以上持械、木管断裂或车轮陷沟即退，伤者由两兵护回医棚。医棚留两名守卫，南墙半队不动，仓门不抽人。

第一轮水车只装了半车。水面浮沫被苏晚棠取走，她看过昨日松油样后说：“来路不明，不能饮用，煮过也不能当作安全。伤口、人饮和马饮都用内井水。上游另取清水样，只能暂供洗器、冲地，伙房不拿它开锅。”

顾沉舟让陈二把井水与待验溪水分栏。内井连汲六轮就得停半刻，等井底水位回升并检查绳股。两辆水车因此不能全去槽尾；马厩用干净井桶接足备用驮马饮水，取消下午运木任务，把少跑的一趟和照料役时另记。

午前，柳台方向传来一声木响。贺兰朔没有带骑冲过去，只带一名营兵走到旧堤边缘。风吹开车辙上的雪，露出一片压扁的草结。草结里夹着黑砂，却没有袋纤维。另一名营兵在旧车旁发现一枚铜钉，钉头平，像从车板上拔下。

“铜钉与柳台窄车的铁钩不是一件物。”老周看过后说，“钉身短两分，旧锈也不同。”

顾沉舟让两件物证各自封好。木桩、铜钉、草结、黑砂、水样、空袋六类证物分柜，谁取谁落印。谢无咎在旁边看了许久，突然把一张转运副条递来：“三日前，西墙有一批旧木桩领用，领受栏是空的。”

副条纸角与雁回营门簿上的纸角相同，墨色却比水口木牌新。顾沉舟没有把它写成同一批木材，只请军需房查领用日、经手人和实际去向。若副条能对上柳台木桩，才有资格进入水口案。

午后第三轮取水时，上游石台突然落下一块冰板，砸裂水车左侧挡板。车夫腿上被木片划开一道口子，郑衡先让两兵把他护回医棚，水车不为取满而停在原地。苏晚棠报伤口浅、需缝两针、停拉绳一日；顾沉舟把一名原役脚夫调来顶车，役期和脚钱另记。

少一名车夫，第四轮只剩一辆车。罗定不许抽南墙半队，也不从仓门借人，只准原护水兵分两班继续运水。粮案边没有足够人手开新袋，顾沉舟就把第四袋的记录锁回小匣，不在夜里继续查它。

入夜前，贺兰朔在柳台旧堤看见两道新蹄印。印子绕过空车，直奔北水槽，再折回西墙方向。印深只能确认一匹马来回两次，不能确认骑手。可他在折返处捡到半片旧皮囊，皮囊内侧缝着一小段蓝线麻布。

顾沉舟看见蓝线时没有伸手。他让营门把皮囊连雪一起装入木匣，标明发现位置，不与黑河旧案的麻布样本拼接。陆承留在黑河，不能替雁回验物；若要比对，须等正式押运。

罗定最终准夺回槽尾，但只准七人：贺兰朔与两名边骑，郑衡与三名营兵，顾沉舟留门内，苏晚棠留医棚。路线从上游石台到槽尾，半个时辰往返，带空袋四只、木楔两根和遮风灯一盏；七人从今日日额分领干饼三斤，净麦折耗由伙房另记，温水两囊，坐骑不出门，不新增马料。不拖柳台空车，不拔裂木，不追过旧堤。有人受伤，由两兵护回医棚；发现三名以上持械或火光封路，立即退上游。

贺兰朔出门前把缰绳交给副骑，自己走在最前。“夺的是水口，不是一个人的判断。”

天色已经压成铅灰。郑衡把遮风灯留在最后一个人手里，前头六人只凭石台边的白灰认路。到第二个弯口，一支箭忽然钉在木管外侧，箭杆颤了两下，尾羽便被风吹乱。

“伏下！”贺兰朔一把压住身后的营兵。另一支箭越过他们，扎进雪坡。柳台外的低坎后亮起两个头影，接着有人喊：“回关去！再来便射！”

贺兰朔没有立刻还箭。两人的弓能压住槽尾，却射不到上游石台；他们占的低坎两边都是软雪，未见第三人，也未见截断退路的火。郑衡依照军令清点七人，手指向上游，随时准备退回。贺兰朔贴着石壁绕出两步，看见水槽背面的泄口被冰封了，积水顶起一块薄石板，石板恰好压弯管身。

关楼上，顾沉舟只看得见灯，没有办法替他们认箭路。他请罗定让楼哨照旧盯柳台，把白日量出的高低差喊给郑衡：“先松泄口，不从正面顶管！”那是量水留下的数，不是隔着风雪猜出的军令。

郑衡传话，贺兰朔向一名边骑指了指背面，两人趴着爬进石台阴影。守在低坎的人又放一箭，箭尖撞上石头迸出火星。第三名边骑张弓压住坎顶，不追人，只在对方露出肩头时放了一箭。坎后立刻缩回，两道脚步声沿旧堤退远。

泄口的冰比想象中硬。贺兰朔用短刀柄轻敲，一名营兵以木楔护住老管，郑衡压着空袋接落冰，不让它砸到下面的槽口。最后一块冰脱开时，贺兰朔右手滑过管缘，虎口划开细缝。他把手藏回袖里，仍被郑衡看见。

“换人。”郑衡不等他答，叫另一兵接刀，“你去看退线。”

水从泄口猛地落下，石板失了托力，斜着沉进泥里。弯管却没有自行复直。两兵用木楔从未裂的一侧撑起管身，留下裂木和石板旁的蹄印不动；贺兰朔把断下的一片旧车板装进空袋。水声由细响变成一阵低啸，七人没有因此多留半刻。

两刻钟后，北墙外传来三声短哨。门哨依令不开闸，直到墙哨认出七人，才放他们回门。贺兰朔带人回到木桩，空袋装回一块被石板压住的旧木片。木片上的刻痕与水槽裂木不合，倒像旧车底板的残片。郑衡另报两名持弓者退向旧堤，双方各有放箭，未见对方中箭，不报斩获；七人齐返，贺兰朔右手新伤，其余六人无伤。

“槽尾能取水了？”顾沉舟问。

“能，冰封泄口把石板顶起，压住了管身。”贺兰朔答，“两名持弓者拦我们查水，但不能因此说堵水也是他们干的。石片旁有新踩的马印，只有一匹马。我们没有追。”

上游石台重新放水后，今夜只能恢复半数水量。溪水仍待查，内井继续供应伤口、人饮和马饮，医棚新增一名轻伤车夫和贺兰朔的虎口伤。苏晚棠准贺兰朔步行，不准次晨拉弓骑巡。顾沉舟把夺回水口的结果写成“水路恢复、证物新增、遇箭退敌、未有斩获”，没有写成破获劫粮。干饼三斤耗两斤半，余半斤回伙房；温水耗一囊半，灯油耗半升，木楔两根仍撑在槽边，不能算作回收。

谢无咎收走副条抄本，罗定收走军令，贺兰朔收走马印位置图，苏晚棠收走伤情页。四个人各自带走一份责任。

夜深时，顾沉舟再看北水槽。裂木还在，空车还在，少掉的木桩却把两条路连出一个缺口。有人想让雁回相信水口被人夺走，也有人只是在利用坏掉的木管。明日要查的，不是那匹马去哪儿，而是谁有权领走西墙那批空木桩。
