# 第六十三章 兄长顾明夷

二月初九，接问棚还没开门，北廊里先响起了拉弓的声音。

弦只响了半声。一个新兵右臂抬不起，箭头便垂到前排同伴的背上。教习伸手去扳他的肘，顾明夷从廊口踏进来，扣住弓背，先把箭卸了。

“他肩上有伤。”

“没入医册，只说昨日摔过。”教习道，“今日看的是能不能站齐。”

顾明夷将弓放到兵器架上：“站齐以后呢？一起把箭射到前面的人身上？”

顾沉舟停在东院外。兄长昨日在母亲屋里穿的是旧短袍，今日袖口束紧，腰牌却仍收在内袋。他手里的空木牌不是借来的官威，上面一个字都没刻。

北廊有十七名待验新兵，两人手臂肿胀，另十五人挤在狭地上试弓。京营主簿要在辰时收齐春练名单，校场西半边又正在验马，教习只好把弓手赶进廊里。每个安排单看都有理由，合到一起，却让前排的脊背成了箭靶。

“弓都卸箭，箭入架。”顾明夷对自己营中的教习说，“十五个人分三组，先去东院练步与引弓，不上真箭。两名伤兵交医佐看，不填成已验。”

教习不肯：“东院午前要摆问询案。”

“只用辰前半刻。半刻到，收弓让院，不把查粮的人赶出去。”

兄长真站到了院口。他让第一组五人拉开距离，后两组沿墙候着。一个高个新兵把手伸得过猛，弓梢撞上同伴的帽子，顾明夷没喝骂，将自己那张弓取来，放慢做了一次；脚先落稳，肩沉下去，肘才顺着弦走。第二遍，同伴不再躲他的弓梢。

顾沉舟看着兄长左手虎口的磨痕。昨夜他只以为那是搬家留下的，此刻才知道，顾明夷教人练弓并不只靠一句口令。

医佐领走两名伤兵时，主簿到了。他翻着名单，先找顾沉舟：“北原押送副使，在这里？”

“粮路什长。”顾沉舟答。

主簿将公文抖开，正文确是粮路什长，旁边添了一行“可代押运”。他解释京营统收时需定归口，称副使不过方便问话。

“可以定归口，不可以替军镇授官。”顾沉舟让许简指出原来封号，“补注是谁添的、哪一日添的，请留着核。问我经手的粮，不必先给我另一顶帽子。”

许简没有把整匣抱来，三包核过副页仍在外库。今日先照接问令借出第三包，外封由库吏与守卒共验；二十七页交割副本的总目录仍留库中，三张图另有编号。崔岳与一名护兵陪顾沉舟，另两兵守外廊，冯九留驿照看车骡。七人没有因京营点名便改了所属。

主簿在补注旁记下待核，将副使称谓划去，却又向顾明夷递了一张调补令。

“北廊还缺三十七名弓手，文案房也缺人。你弟弟识算，四名护兵又走过北原，先留下顶三日。查粮就在这里，误不了。”

顾明夷将令放在架上，没有塞回主簿手里：“他们有返程护卷的军镇令，不是拨给京营的兵。文案缺人，也不能从弓手缺额里补。”

“那你三日怎么报满？”

“报不满就是报不满。”

主簿压低声音：“缺额挂着，你营里领箭、领练食都得按实际来。别人先验足了，军械余弓未必还给你。”

顾明夷看向院中那十五个人。他不缺懂得利害的聪明，可兄长若为了保住领料位置，把北原四兵塞进去，下一次真要护卷启程，谁肯把已经入册的兵放走？

他提笔，在自己尚未交出的验兵页上写十五人能练、两人待医。三十七名待补仍列在另一栏，没有拿十七名眼前新兵抵掉缺额。

主簿把验兵页压在掌下，没让军械吏立刻接：“那就按未验齐报你。补员迟滞，算在你营里。”

教习看向顾明夷。这个评语一旦交上去，下次领备用弓的次序就会落后。十五个新兵本来还握着自己的弓，听见退料，纷纷将手收紧。高个子低声说，若把那两名伤兵算上，数会好看一点。

顾明夷把他扶着的弓缓缓压下：“多两个名字，不能替你挡箭。明日真拉满，伤的人先脱手，旁边是谁？”

高个子望向刚才被弓梢碰到的同伴，没有再说。教习从廊里取来旧草靶，想用三张真弓留在东院练到午后，顾明夷仍没准。他将十五人分给两个教习，练步的一组先归营，另外两组各记已经做过的动作；缺场地便改徒手，不用查粮院子顶一张完整春练回条。

“未验齐可以报。”顾明夷向主簿道，“这十五个已经验过的别一并抹去。两名待医是谁领入、谁催他试弓，也请医佐写亲见，不要把今日新发现的肩伤倒算成北原来人挡了操练。”

主簿抬头看了顾沉舟一眼，终于把两队所在的案号分开。兄长没有免掉自己补员的责任，也没让弟弟的问询变成京营春练误时的由头。两名伤兵离开时，一人回头想拿空筐，被顾明夷拦住；空筐给军械吏收，他们只带停练条去医棚。

“今日十五人的箭料照十五人领。少的归库，请军械房给我一张归数。”

主簿脸色不好看，终究叫来军械吏。顾明夷失掉了先占满额弓料的便利，却保住了这批人明日不用举着伤臂再演一场整齐。他带两名教习逐束清点领出的练箭，多领部分当面退回，不让教习在点验之后私下借给邻营抵人情。

半刻一到，十五人收弓退出东院。有人还想留着等午饭，顾明夷让教习领回本营领食。军驿问询不是添给他们的一锅，北原来人的驿食也不该因为两队站在同一院便少掉一半。

接问吏搬案入院，顾明夷退到廊外。亲属不进弟弟的问答，他自己的京营待核页由主簿另收，两边的事终于不再挤在一张桌上。

粮曹第一问便指向宁川三百斤。

“你统筹转运，为什么雁回收粮不是你押？”

“宁川到南驿，两轮轻载，我核封、排车、看交接。南驿到雁回另有接驿令和四名护兵，不是我领的队。”

“那你能不能保证二百斤到雁回？”

顾沉舟打开获准借出的副页，指向两处不同的押记：“我亲见南驿收讫三百斤。转雁回二百、留驿一百，依据是谢使正式调拨；雁回仓曹与灶头的袋号是后收到的副页，请向接收人核。我不能把他们的秤搬进自己的亲见栏。”

粮曹又推来一张抄录，事故粮被写成了余下一百斤。

“甲九、甲十合九十九斤四两，是另一批事故粮。甲七、甲八污染隔离。这四袋与宁川六袋不是同一次出库。”顾沉舟将两张袋号目录放到案上，先让吏员找原号。

吏员连找两回，才发现抄录只按整数排了三百、一百和二百，没列甲字袋号。若顾沉舟顺着答一句“余粮百斤”，两处干棚便会同时多出或少去六两，还会把真正留驿的一百斤吞进事故粮里。

“分开。”粮曹道。

这次不用顾沉舟再讲半页道理，抄录的人自己换了一张纸。数字被压回该在的位置，第三包封线由许简重新核验，库吏随后收回，问询没有变成顾沉舟保管京营原卷。

收卷时，那吏员还想把顾明夷的验兵页放到同一夹内，省得再走一次主簿房。许简伸手停住，将两个案号念了一遍。顾沉舟看见兄长在廊外等着，却没有叫他进来帮忙；库吏取第二只夹，京营新兵页送回本营，宁川粮证归外库。两个人站得很近，他们的担子却从这里各自走开。

户部来人最后才问顾长河。顾沉舟只答原件仍在黑河营官处，由陆承照原封存看守；腊月二十七、一百二十石麦，是家中残账能辨的旧记，不能拿今天的近案副页替那车粮认收。

“你认定他被人害了？”

“我有疑处，没有定案。请先调押运单和灾记，别先调我的一句认定。”

廊外，顾明夷正在替伤兵领回医佐的停练条。他听见父亲名字，手指顿了一下，却没有走进来。

傍晚两兄弟在军驿后廊吃面，顾明夷的袖口又添了一道弦磨。他说三十七人的缺额仍要补，今日拒掉的只是错误的人，不是京营的责任。

“你把他们的弓退了，明日未必领得回来。”顾沉舟道。

“所以我得去找真正能来的人，不能借你四个护兵让纸先好看。”

他把自己的待核页收好，没有请弟弟替京营算这一笔。顾沉舟也没递父亲残账的抄页，让兄长凭校尉身份先带去打听。

“明日户部先查北原乙七春拨卷。”顾明夷道，“我经手近年的京营领粮，只见过两类总账的目录，旧卷没看过。听说第三处是军法封案，若要联核，还得另请文。”

“乙七是哪年的？”

“景和十一年三月。不是父亲那张腊月残账。”

顾沉舟放下筷子。先从北原转运旧账找归档的路，并不等于先从那里认父亲的车；这两件事，他必须分得比京营近案更清。

夜间调卷牌到驿，准次日辰时去户部看乙七京存卷及已收的驿传副抄，父亲押运原件仍待军镇调送。许简记下送牌人和封号，三包外封逐一点回，初问的十日期限没有增加一天。

顾明夷临走，将空木牌塞回袖中。白日若刻上一个北原护兵的名字，便能替他省去许多争执。

如今牌仍是空的。他回营去领那十五人的明日练食，没有带走弟弟的一个人。
