# 第五十九章 旧城有主

正月二十八，宁川东门外多了一道拦车的木栅。

顾沉舟的空车在栅前停住。车板昨夜换过，旧裂板另存，车夫已试过空轴；四名护兵领的是罗定的护路令，崔岳领队，另两名独立仓兵在南仓等候。车上只有复检工具、两副待用铁箍和今日路食，没有可拿来买路的军粮。

栅后站着七个人，手中有棍，没有兵刃。领头的是个穿灰袍的中年人，自称宁川旧典户韩守义。他将一张泛黄的契纸举到车夫面前，指着纸上的“南院东地”。

“军粮借屋，到今晚就该撤。你们修桥、开沟、练车，哪样不是踩我的地？这条路今日起收地钱，一车二钱。”

崔岳没有拔刀。他先让车夫松缰，四兵分两侧护住人，不去拔栅。军令准护送至秤房、遇持械聚众退南驿，县方争界由县差处理；这里还没有人挥棍，不能拿护粮令当征地令。

顾沉舟看见栅脚下三块石头，一块的湿面朝上，另两块底部还粘着新泥。韩守义说它们是祖辈留下的界石，他却没急着反驳，先问：“你要收的是院租，还是官道地钱？”

“路就是院外的路。”

“契上有没有路宽？”

韩守义把纸收了半寸：“县里旧册都烧坏了，问也白问。你今日不付，车就别过。”

孟槐从井路赶来，身后跟着何氏。他认得韩守义，却只肯说自己见过韩家收南院东侧空地的租，不肯替他认整座旧城。何氏怀里抱着昨日搬回屋里的门闩，站在栅边，脸比雨天还白。

“他昨夜让人量到我灶台，说要先拆半间。”

韩守义冷笑：“你住了五年，付过我一文么？”

何氏没有争五年。她把屋主续借秤房的回条递给梁文，手仍紧紧抱着门闩。顾沉舟这才明白，栅不是只拦今天这一车。若军方花钱认下二钱地费，韩守义下一步便能说军镇也认整段路是他的，六户住屋与井道都得重新向他求情。

可不付钱、干等县图，宁川的六袋粮就可能在借期终了后找不到接车的路。

顾沉舟让车退三丈，没跟韩守义再吵。他先请孟槐通知仓兵，今日不发粮；叫一名县役去请邢远，另请梁文带两名老人沿栅外找旧排水石槽。自己与车夫走到东门北侧，看昨晨水痕留下的硬土线。

那里绕行要多半里，过窄口只能容一辆轻车，北墙五步仍禁入，旧练车地的七日期限也已届满，不能借旧牌再占。梁文拿探杆逐处试土，县役从门洞旧石墩找到一道磨平的车痕，车夫量过宽度后摇头：“空车能走，挂一百斤，转角得有人控尾。两车不能相遇。”

“先不挂粮。”顾沉舟说，“也不拿何家的屋檐作靠板。”

他们从县方料场租四块干垫木，花钱请六名健脚工清出转角碎石。孟槐不搬重，只挨户问沿线借地；一家准车过门前半丈，另一家要求下午晒柴时留路，他们就把车序移到早晨。借路有时辰，不因为屋主点了头便算永久官道。

韩守义见空车往北侧挪，带着两个棍手走过来：“绕了半圈还是韩家的地！”

梁文将探杆横在地上：“这里是不是你的，县图未到。你若还有契，拿出来。先别踩我刚量的软口。”

对方伸棍去挑垫木，崔岳上前隔开棍头，两兵护车夫后退，另一个守住孩子往井边的路。顾沉舟让人把空车停在硬地，县役将挑木的人姓名记下，请韩守义回栅前候问，没有替县方锁人。

韩守义不是不懂。他知道自己那张契只能压住路口，压不住独立量路。若绕道真的能接粮，二钱就收不到，先认地后议钱的筹码也没了。他于是转向何氏：“今夜租期一过，我来收屋。”

何氏忽然将门闩放下，指向他脚边：“你踩的石墩是井栏旧脚，前年县役修井时放这里，孟伯陪着来的。祖坟界石不会有铁桶磨出来的圆沟。”

顾沉舟蹲下看石面。圆沟里有旧锈，新泥只附在底面，但他没有据此宣布移界。他请县役画形，请孟槐和修井老人分别说搬石时辰、来源，再等县方工料簿。石头的位置可以量，搬过的事实需要另一份证据。

午前，邢远带来了县署留存的旧图副页和前年井修领料簿。旧图有缺角，南院东地仍能认出二十七丈长、六丈宽；契纸印号与典簿相合，韩家确有该处典租权。但门外车道另画六尺，两户井路归公用，不在二十七丈内。领料簿记三块旧井栏垫石移置东门，形状、磨沟和两位老人分别说的地点相合。

邢远让县役拉绳复量。韩守义没有争印号，转而提出契里还写着“附便地”，六尺官道年久无人维护，理应归他的院边管理。

“维护过几次，花了多少？”邢远问。

“这些年……谁还留得齐。”

梁文拿出去年县役补门洞的料页，何氏与另一户各说自己出过两日清泥；三处记录不同，却都指向路仍由县方和住户共护。邢远只定今日可定的事：契内租权保留，公路和井路不得收费，三石移位的责任另问；不能凭“附便”驱赶图外六户。

韩守义盯着那根六尺量绳，面孔一点点沉下去。他本想用真正的旧契撬动旁边没有主人出面的地，却没想到军粮没有成为肯付钱的第一辆车。

县役拆栅时，七个人仍站在旁边，没人被绑到粮车后。顾沉舟也没有走韩家院里那条更宽的路。契内半丈确实属于韩家，早晨清路时误堆进去两筐石，他叫健工移回，按半日占地给租钱，不让赢了官道便省掉真租。

“你不认整城，倒肯认这半丈？”韩守义问。

“你有的，我不抢。你没有的，也别拿来卖。”

空车重新过门洞。车轮压过转角时，后轮蹭住一块旧砖，六健工按练过的前牵、后控、看轮分开站位，车夫停牛，梁文在硬地补楔后才退车。没有人用掌伤者去挤轮，顾沉舟只报前后距，左肩没碰车辕。

下午，两独立仓兵当着车夫复核六袋封线与袋底，封线未动、袋底干燥，沿用原验收净重三百斤，今日不拆封重称；试车以等载石先过，不把粮拿来试路。两副铁箍补在已装闸木的松口上，梁文验箍，仓兵不替他报渠已竣工。水只走浅槽，井路仍留高边，盐货不能通船。

南驿医佐带来复查页：赵麻子右踝肿未退，仍停走停重；董成左掌裂口不出血，却不能握重。陷腿工今晨能站，仍观察一日，不入六健工。许木匠只指点板接法，不算搬木；梁铁膝伤、周四掌伤及旧医转各按原条续查，没因为路开了就召回抢工。

今日清路、垫木、误堆半丈租钱合一两三钱，县方验实后从修路款付，余二十六两三钱。六健工实领工粮四斤，余二十三斤二两；旧十八斤八两不动，五十七人的二十斤赈粮另发。随队饼六斤耗三斤四两、余二斤六两，水三囊余一囊，牛料八斤耗五斤余三斤，车夫自带行粮另记，回驿核退。

太阳落在残墙上时，何氏将门闩抱回屋。孟槐用粉笔在井路两边画了两条细线，没把屯田局的名字写在民屋上。邢远准公路清出的安全段明日接车，北侧临借绕道只留作空车退路；屋主另议秤房续借，今晚先不改期限。

谢无咎的脚使在门洞外看了半天，最后带走的不是一纸“旧城归军”，而是一张路宽、时辰和实际费用图。顾沉舟叫他添上韩家真正的典租地，免得关内有人把拆栅说成夺城。

孟槐望着第一辆顺利回头的空车，问：“这地方以后算谁的？”

“房里住的人有房，韩家的地还是韩家的，粮在仓兵手里。”顾沉舟将图卷起，“明日只让该走的车走，不用先找一个人做整座城的主人。”

门外最后一段泥路已经映出淡红的天光。顾沉舟知道自己没有夺下一座城，却夺回了让粮车不必求一张私契放行的路。三百斤封粮终于有了出门的地方；至于三处该各走几袋，他必须在明日日落前把这张图变成真实的车轮声。
