# 第六十五章 三本总账

二月十一日辰初，户部西库的门槛还带着夜潮，乙七箱已经从檐下移到阅案桌边。

顾沉舟没有先翻总账。他让值库员把昨日留下的两张核见摘要摆在左边，又请裴同取出移卷簿、箱签和一支未用的朱笔。四样东西分开摆好，谁都不能拿一张摘录替另外三处作答。

裴同压住乙七箱的旧铜扣，待另外两处进门；乙七与乙十七分列原格，没有因为联核再次混号。

库吏取来三份目录。春拨总账记景和十一年三月，一千二百斤分四车发出；京存仓领抄记甲一、甲二入仓六百；补运页另记付讫三百，却没有承领仓号。三页的墨色、纸幅和装订孔都不同，收卷日也不一样。

许简沿着装订孔数过去，念出页码。顾沉舟只在对应栏边写下“原页见”“副抄见”“尚待第三处”，没有把三百斤写成已经进过某座仓。

军法司梁录事与转运司押册吏韩度各抱一只窄匣进门，先对调卷牌，再核桌边封号。

“军法司带押运封案。”梁录事把窄匣放在桌角，“只开乙七，不开父亲旧案。”

“这是两件事。”顾沉舟答，“请在案边另列封号。”

韩度把转运司原支领册抱紧了些：“乙七春拨没有原始出库秤，只能按转运票核。补运三百的承领号在脚价册，不在粮册。”

“那便先核你亲见的页。”顾沉舟让许简递去桌面空白纸，“谁经手、哪一页、何时收卷，各自写清。不能因为缺一杆秤，就把整笔数字抹掉，也不能用脚价册添一车粮。”

梁录事打开封案。封皮内有两张京存押运副抄，编号一为甲一、甲二，编号二只写乙一、乙二随火损失。押运人栏盖着驿传小印，领受人栏空着。原押运单尚待调出，今日不能把副抄当成原单齐备。这里没有顾长河的名字，没有腊月二十七，也没有一百二十石。

顾沉舟的右虎口在袖中收紧，左肩也跟着发酸。他没有伸手去接副抄，只让许简在纸上记“京存副抄二张，领受人空，姓名未见，原单待调”。

“你父亲的案子，不在这里。”梁录事说。

“现在只能说名字未见。”顾沉舟道，“原单是否全，仍要等封案目录合对。”

梁录事把封案压回匣边，请库吏核封线，原物没有交给顾沉舟。

三处带来的册子终于摊开。

户部春拨总账中，四车各三百斤，甲一、甲二收六百，乙一、乙二报火损六百；附卷京存仓支领抄写支一百八十、余四百二十，支项按三日分成三笔。转运司总账将粮值、脚价分栏，军法司封案总目则列副抄来源与未齐的原单。三本互校，不是三处都写一个相同的数就算查完。

军厨留抄仍独放一边，三日各五十，共一百五十，领受人是旧灶吏周岑。梁录事把一枚镇纸放在空白领受栏旁；韩度压住脚价册；裴同守着春拨卷。顾沉舟看见的不是三个人肯交给他的权力，是三道他不能越过的桌边。

顾沉舟让韩度把转运补页放到旁边：“补运付款三百，先只看付款。”

韩度翻到脚价册后页。三百斤对应的银数分成麦值和脚价两栏，合计付讫，承领号是驿交号丙十九。丙十九在驿传册里只记“代收折价”，没有仓门、车号和入仓时刻。

“所以这三百可能是粮值，也可能是折价？”裴同问。

“数目对应三百斤的价，不等于三百斤实物到仓。”顾沉舟看向粮曹，“今日若要京营补粮，需另报现粮缺口，不能把付讫盖章当成入仓凭据。”

粮曹正等在门边。他手里又带来一张京营缺粮单，今晨实余、点名人数和应补数都列得很整齐。三百斤缺口不是他虚报，问题是户部想从旧账里找一笔看起来已经补过的粮。

“京营今日不能等一场旧案查完。”粮曹道，“你说不算入仓，那现粮从哪里来？”

“我只核这三本账。”顾沉舟把缺粮单推回去，“现粮申请另走度支。若把旧账的三百先扣北原下一拨，今日少的就是能落进锅里的麦。”

粮曹盯着他：“你站在北原那边。”

“我站在每笔粮都要有来源的地方。京营缺三百，先证明缺三百，再找现粮；旧账付三百，不证明谁收了三百。”

裴同抬手让吏员把“补运三百”另贴黄签。那一栏不再并进京存余四百二十，也不从户部现仓中划出一车。黄签上只写付款凭据、承领号丙十九、仓入未见。

军法司录事这时指向军厨页：“仓房支一百八十，军厨领一百五十，差三十。你要不要把差额先写成军厨短领？”

顾沉舟把三日日期逐一对上。仓房三笔各六十，军厨三笔各五十，支领日相同却不是同一经手人。医棚、门哨和途中工食的独立领料页尚未取来，三十斤只能写成用途未核。

“不能先扣军厨。”现任灶吏从门外进来，脸色发白。他带来周岑交下的灶单存册，今日差事就是核这些旧页：“军厨只认一百五十，若把三十压到我头上，我拿什么找那年的老灶吏？”

“没有要你替旧人背。”顾沉舟道，“把你接到的灶单拿出来，今日只问纸，不问你没见过的锅。”

灶吏把册子摊下，指甲在一条短行上停住。三月初九，杂役供食三十斤，领受处只写器械房，未具人名。他以为找到差额，立刻将这页推向仓房的三笔日支。

“器械房，就是它了。”

顾沉舟没有让许简落笔。仓房的三十是连续三日各差十斤，这张灶单却在一天记三十，还没有仓房对应出门条。

“有用途线索，不是闭合。”他让两张纸离开一寸，“军厨的一百五十含不含这项？器械房另领，还是灶房转供？先核原小计。”

灶吏翻向下一页，脸上的血色又退了。末行合数恰被虫蛀掉，谁都不能从一个三十，直接说两边已经相平。

裴同叫库役取木框，把脆页平托起来。韩度本想指着那行说北原少领已补齐，见纸背还有一道未断的旧栏线，又把话咽回去。他要求查器械房领食簿，不肯让转运司凭半页灶单认掉责任。顾沉舟点头，将新线索另列在摘要背面。

库吏去取门哨、医棚与工食副页，暂未找到对应领条，三十斤仍待核。

顾沉舟看了看那道潮裂的驿灾副册：“南坡空车翻覆和北坡乙二粮车焚毁，还是不能并成一辆车。”

梁录事翻过封案目录，点了点头。目录写南坡车辕裂、次晨清路，乙二灾册写粮车焚毁，车号都空。两处没有车夫姓名，也没有伤者转送记录。

“你不问车夫？”韩度问。

“要问，但先问各自经手。两处只有日期相近和空车两个字，不能拿相似字样补上车号。”

午前，三处核出三栏：补运三百付款未见入仓，仓厨差三十用途未核，乙七火灾与南坡空车车号待找。

粮曹的现粮申请被裴同重新封入公文袋，另送度支。那三百没有从北原下一拨扣掉，也没有当场变成京营的麦。粮曹走出门时回头看了顾沉舟一眼，眼里没有服气，却也没有再把抵扣页压过来。

午后，三处按各自亲见将摘要核回。顾沉舟赶在准定的交核时限前交出两张摘要，新增杂役供食条另附，不拖到申时才算完差。库役收好原卷，他同许简、崔岳及另一护兵先返驿；两名护兵仍守军驿，冯九照车骡。七个人没有被这趟联核多用出一个来。

军驿邻墙后响起一阵木架倒地声。顾明夷的十五名新兵正借狭院练步，两个待医者坐在廊下。运器械的空匣车从侧门转进来，车夫为了让开积水贴墙行，右轮撞上碎砖，车上箭架猛然倾斜。

“卸弓，退墙根！”顾明夷叫道。

高个新兵还想伸手托架，被兄长一把拽回。车夫抓住骡缰，教习与器械吏从车后扶住架腿，崔岳只按主人招呼将一块车楔踢到轮前，没有拔刀接管京营的门。

四束练箭滚到干地上，幸而都缚着，没有散进人的脚下。顾沉舟让许简停在门外，自己也没有用伤肩去顶车。先退人，再止轮，再扶架；等木架稳住，顾明夷才让器械吏逐束捡回。无人受伤，断掉的麻绳另放一边，不能照原样再捆。

车夫连声认错，想把四束箭全搬进教习怀里，空出车板好赶下一趟。顾明夷挡住他：“本营领多少便收多少，多出的不留。空匣、箭束和架子各交各的经手。”

“今日先借，明日点名再退不成？”

“明日缺的三十七个不是靠多领四束箭补的。”

十五人按组站回去，两名待医者连空匣都不提。顾明夷没有借弟弟的护兵填满队列，只让他们退回原差。器械吏核好四束，其中两束另送他营，一束归备用，只留下本营的一束按实练领用。损绳换新由器械房接，不从北原车绳里借了便忘。

许简看着车上的空匣，低声问那三十斤杂役供食，会不会也送给过这样的搬箭人。

“可以问用途，不可以认这辆车。”顾沉舟道，“今天的器械房，不能替七年前的人作证。”

申初，京营点名吏到驿送明日校场时辰。顾明夷接过副页，十五名可练、两名待医、三十七名缺额仍在。他将车绳损耗交给器械房的回条收好，没有递给弟弟核签。

“明日你也去？”兄长问。

“按问询令去，不入兵册。”

顾明夷点头，领十五人回营吃他们自己的练食。院里安静下来，顾沉舟想起窗下的三本总账，也想起那只倾斜木架。纸上只差一个栏，车上只缺一道绳，人便可能替这些空处付命。

今日守住的是北原现拨不被旧款抵扣，拿到的是三处分别可问的页号和杂役供食线索；不是父亲的下落，更不是京营补齐了三十七人。他将两案分夹，三十斤暂未核平，南坡空车仍没有可相认的车号。

他把两张摘要的核准抄页及附记分夹收好，准备明日点名。
