# 第二十八章 雪崩之后

云层在半夜压低，营墙外像多了一堵灰墙。

顾沉舟被一声闷响惊醒。不是军鼓，也不是营门梆子，声音从西北高地传来，沉得像整面山往下坐。紧接着，墙外有人吹了一长两短。

陆承先到门楼，贺兰朔已经牵马站在雪地里。

“烽墩还亮着。”骑手说，“人没回齐。”

周校尉很快下令查验救援：六名营兵、八名护运民夫、两名骑手，共十六人；带一辆空车、两头役牛、八斤干饼、四囊温水、两盏遮风灯、两根长绳和四匹马料，沿西北高地至烽墩，先救人再看粮，半个时辰回报。冰裂、二次雪滑、三人以上持械或车轴受损即撤，伤者由两兵和一匹马护回，空车和散落物可弃。苏晚棠在北门设临时伤棚，不让赵七、韩魁和医棚五名伤民出队。

顾沉舟听见“八名民夫”，立刻问：“护运筹办牌上昨日的轮换，有谁已退役？”

陈二把名册摊开，八人里有两人今晨原本要去雪场搬石，另一个民夫昨日手指裂口未愈。若全数出队，雪场少三车石料，医棚的软食搬运也无人接。周校尉要补人，顾沉舟没有把伤民填进空位，而是从营内在役民夫中换三人，原役期和脚钱分别保留。

“救人不是把责任推给没得选的人。”他说。

雪地很快吞掉车轮。高地入口的断芦已被新雪盖住，昨夜木板留下的压痕只剩两条浅线。贺兰朔不让骑手走最陡的北坡，带队沿风背面绕行；陆承让两名营兵用长绳相连，民夫跟在绳内，不得踩出新线。

行至半坡，第二声闷响传来。

雪层从高处推下来，先是白雾一样的碎雪，随后卷着冰块越过旧石坎。贺兰朔大喝伏低，前排骑手把马拉向岩坎，陆承让所有人就地伏绳。顾沉舟没有往下跑，身后就是一段昨夜车走过的窄坡，跑乱队形只会把人推下去。

雪流擦过半坡，埋住一盏灯和两丈绳。等声音过去，队伍少了三个人。

陈二先报人头：“陆承、贺兰朔、顾沉舟、六名营兵，三名民夫，一名骑手，共十二。”

“另四人呢？”

“在前边烽墩方向。”

没有人把少掉的人写成失踪。顾沉舟让一名营兵沿绳摸过去，手下碰到木板，下面传出闷响。两名民夫被雪压住腿，另一个营兵抱着昏迷的骑手卡在石缝旁，正用肩顶住滑板。

苏晚棠不在现场，顾沉舟不能替她判断伤情。他让人先清口鼻周围的雪，再用备用布包住骑手颈侧；陆承和另一名营兵从侧面挖，不拉腿，不让石板二次下压。贺兰朔将自己的马缰系到长绳上，马向后缓退，牵开一条能够拖人的窄道。

第一名民夫腿上有木板压痕，能说话；第二名冻得发抖，左脚无知觉；骑手头部撞石，呼吸尚在。三人的伤情分别写入临时纸条，不能等回营后再凭记忆补。

坡外忽然传来马嘶。

一匹备用马被雪流冲脱，缰绳缠在倒树上，离队伍已有十丈。那不是敌人袭击，也不是马匹丢失；贺兰朔让骑手先救人，不追马。马匹可以登记为待回收，人不能拿来换牲口。

顾沉舟看见雪层里露出一只麻袋角。不是他们昨日送到西墙的两袋，也不像沙沟四袋的旧封线。袋角沾着黑色盐碱硬皮，旁边压着一块断木牌，木牌刻着半个“歇”字。

“先救人。”陆承说。

顾沉舟点头，没有伸手去掏麻袋。他让陈二在远处立一根短杆，标明发现位置、风向和雪层高度。若现在把袋子拉出来，雪面会被踩乱，断木牌与袋角的先后位置也会消失。

四名伤者被分两路护回。两名营兵抬伤腿民夫，一名骑手牵备用马，陆承护着头伤骑手；顾沉舟和陈二带两名民夫沿绳收尾。贺兰朔留下两名骑手守坡，直到确定没有第二次雪滑，才带缰离开。

回营时已过约定半个时辰。周校尉没有因超时先罚人，先问有没有再损伤；军法书吏则把超时、雪滑和弃置马具另列。两名受伤民夫送医棚，头伤骑手由苏晚棠接手，左脚无知觉者先保温、再查脉，不许灌热酒。赵七、韩魁留在原铺位，医棚没有被救援队挤空。

“雪下面有袋子。”顾沉舟对周校尉说。

“是谁的？”

“尚未查。袋角、盐碱硬皮、断木牌和位置各自封存，不能先写成转运粮。”

周校尉没有命人立刻挖。他让西北高地暂封，先派两名熟雪工和军法书吏明日同往；若雪层仍动，先用绳探，不许民夫徒手下坡。救援队今日带回三名伤者、四名幸存者和一匹马，不能因为发现一只袋子再把人手押回危险处。

苏晚棠出来时，袖口沾着雪和血。

“头伤骑手能说话，但不可连续询问。左脚民夫疑似冻伤，今日不能走；另一人腿挫伤，需两日停工。护运名册上的三人都要从雪场和车队除名，不得拿‘只是擦伤’补空。”

顾沉舟把新增停工期限写进粮什册。两名民夫的工食照发，脚钱按实际出队结算，不能因受伤便记成未出工；雪场少三车石料的责任，另由营官重新调配。升起的不是一支队伍的威势，而是四张新的伤员、马匹和役期单。

原本替他们补岗的三名民夫也没有白占一日。周校尉命书记把三人的雪场脚钱、救援脚钱和回营后的清雪工分开，不能因为救人便把原役期抹掉。顾沉舟在车序表上划掉两个已受伤的名字，改由魏三和马老汉各领一轮轻车，重车暂缓；这会让西墙下一次补给少一辆车，但不拿冻伤的脚去填一张看起来完整的名单。

午后，贺兰朔带回被雪冲开的马具。鞍袋里没有军令，只有一小截蓝线麻布和两枚结硬的盐碱颗粒。蓝线与沙沟麻袋相似，盐碱颗粒也可能来自旧驿道。骑校尉没有把这两物交给顾沉舟直接并案，而是让陆承封存，军法和军需各留抄本。

顾沉舟再看手里的残账拓本。烧焦的第三列旁有一条被火燎弯的细线，方向正指向“歇”字木牌的半个刻痕。它提示旧驿道可能有另一处转运点，却没有告诉他袋子的主人，更没有告诉他雪下的人是否已经遇难。

傍晚，西墙送来新的回条：昨夜第二袋二十斤一两已经用去十七斤，余三斤一两封在换岗棚；火房没有多领，守卒也没有把两袋合并。真实粮耗终于留下了两段可复核的重量。

这点回报不够让人庆功，却让顾沉舟在周校尉面前争到一件事：西墙今后的补粮，不再用一张总条覆盖两顿，必须按火房和换岗棚分袋、分领受、分实耗。周校尉准了，秦百户没有再笑，只要求护粮筹办承担多出的麻袋、封线和往返人手。

顾沉舟接下这笔责任。多两只麻袋、两名复核人和一趟回程，看起来都是小数，到了断粮时却可能是唯一能证明谁还剩一碗的人。

夜里，高地暂封的木杆在风里轻轻摇。雪下那只袋子没有被挖出来，断木牌也没有被拼回旧账。

但黑河营第一次在一场雪崩之后，保住了三名伤者、没有丢掉一匹军马，也没有让一只来路不明的袋子替活人承担结论。

顾沉舟把今日救援队的实耗算到最后：一盏灯埋失，两丈绳留在雪里，空车右轮多了一道裂纹；八斤干饼用去六斤三两，温水只余一囊，马料按实喂记，不把未吃的料直接报损。三名伤者的口粮从救援留量里转拨，明日起纳入医棚册，不扣原有十人的软食。陈二写完这些，才发现今日带回的不只有伤者，还有一支队伍知道怎样停下、怎样退回、怎样把活人优先于袋子。顾沉舟没有让他写“无损救援”，只写“人全回，三人伤，物料缺项待补”。
