# 第二十章 逃牛案

牛棚的门没有坏。

顾沉舟到时，养牛的马老汉跪在雪里，手里攥着半根断绳。四头役牛剩三头，空着的槽边有一串蹄印，一直走到柴垛后，才被来回推车的痕迹搅乱。逃的是花额老牛，拉过那辆夹带乙袋的柴车，如今车夫钱二扣在军法帐，牛却还归军需房用。

“它自己挣的。”马老汉说，“我喂完就去添水，回来只见绳子断了。”

仓丁拿着一张赔牛条，催他按印。老汉不敢接，脸上冻出的皱纹里全是雪水。一头牛值多少，他没见过那个数，却知道家里两间屋加起来也不够。

顾沉舟蹲在槽边。断绳的一头起毛，另一头却整齐，粗麻纤维向同一侧翻着。挣断与刀割都可能留下不齐的断口，他不先认，但门闩没有顶歪，槽里的豆料也没翻，牛并不像受惊冲出去。

“开棚的时候，门往哪边拉？”

“往里。”老汉指着一道冻痕，“外头积雪顶着，推不开。”

门后一道扫雪痕刚被薄雪盖住。陆承让仓丁停在棚外，把断绳交门哨包起，再取军需役牛册。册里四头牛有角纹、耳剪与领用人，花额牛右耳缺一角、左角有旧裂，今日没有出棚条。

赔牛条上却写“役牛暴病，折肉支军灶”。

马老汉看清顾沉舟念出的字，猛地抬头：“我没说病！早上还拉了两车柴！”

仓丁道：“找不回就是损失。填失踪、填暴病，最后都要折钱。”

“钱要谁出是一回事，牛去了哪里是另一回事。”顾沉舟站起，“先把肉留在你自己的嘴上，灶里还没见到一根骨头。”

陆承收住赔条，叫门哨报周校尉。老邵从伙房赶来，手里带着今日灶耗：没有领牛肉，也没有额外用盐。役牛册与伙房领料对不上，已经足以暂缓报损，不足以抓养牛人。

老汉抹着袖子站起来，先去喂剩下三头牛。顾沉舟看见他的料桶底只剩一把草，问了才知，仓丁让他停喂，等四头一起点过才记今日损耗。少一头牛，就要让其余三头也跟着饿。顾沉舟没有开东仓，只从原有豆料已发部分拿出当日应给的数，请老汉先照旧喂。

“这头没回来，我还能当差么？”老汉问。

顾沉舟把赔条的抄记压在槽沿：“先查牛，别让别人的那一行字把你也牵走。”

天将黑，牛走过的地方最多再有半个时辰能看见。顾沉舟提议查西南旧渠，不是因为见过麦壳土便认偷牛者，也不是追那辆尚未查清的粮车，而是牛棚外有一段被拉出的湿草，蹄印走向西墙排水口。排水口不能过牛，旁边只有通旧渠的柴门。

陆承却摇头：“旧渠沟边冻薄，追进去，牛找回来，人回不来。”

顾沉舟把勘渠图铺开，用左手按住土坎位置：“不下沟。沿高地绕到石闸，只走两里。牛若被牵去换车，石闸旁是最近能转辕的地方。再远就不追。”

周校尉赶到，听完后批八人：陆承与两名门哨执械，顾沉舟记路，陈二、鲁安、魏三和马老汉带绳。各从当日已领份额留半斤干粮，合四斤，两囊温水；沿高地至石闸，往返一个时辰，夜鼓前归。伤员不出营，空车只在柴门待命；冰裂、三名以上持械、通路被堵或有人不能自行回返，立即撤，由两名门哨护伤者，余人收队。役牛不能牵回便留绳标记，不拿人换牛。

顾沉舟只接过粮袋。陆承领队，不是他腰侧的一块粮什木牌便能让八个人走夜路。

韩魁倚在门边，腕带还没拆，指了指风：“牛顺风闻得到棚味，背风走，多半有人牵。”

魏三补了一句：“到了土坎别先摇铃，牛会回头。先看绳在谁手里。”

他们从柴门出去。陈二仍报人，不报粮袋，八个名字过门后复数一遍。顾沉舟走在陆承后面，用昨日上午的木桩定位，地形没有凭一张新地图忽然变得好走。

石闸还没到，背风坡下传来牛的鼻息。

两个人立在空车旁，一人拖牛绳，一人往车底塞厚毡。车上已经有柴，柴下露出一只旧麻袋角，牛颈的铃被蓝布裹着。陆承举手让众人停，魏三伏在土坎后，马老汉咬着袖口，一声没喊。

“右耳缺角。”老汉低声道，“左角裂的那头。”

门哨也看见左角裂口。顾沉舟在雪里指了指旧渠木桩旁的窄路，那条路只容一辆车，车辕要转，必须退到石闸；他们若从两侧同时喊，牵牛人便会把牛赶进沟。

陆承先领一名门哨绕高地占住退车处，另一名守归路，剩下的人不越土坎。到位后，他才亮出营门牌。

“黑河营役牛，领用条拿来。”

牵牛人没有装傻。他将一张湿条举过肩：“转运棚雇车，仓丁交给我们的牛。花额、左角裂，写得清楚！”

条上确有牛的特征，末尾压着仓曹小印。若顾沉舟只认一枚印，牛便能从失踪变成合法外借。陆承没有冲下去夺纸，只叫他把牛放在原地，把条压到车辕上。

另一人忽然掀毡，想拍牛往前冲。顾沉舟看见鲁安下意识要扑绳，立刻喝住：“别扯牛！挡车轮！”

鲁安抱起路边一根冻木，楔住靠高地的后轮。门哨用矛杆压下车辕，陆承跨到车侧，刀鞘击开拍牛人的手。牛猛一挣，马老汉却从下风口叫了两声，声音像平日添料的短哼。花额牛偏过头，没有往黑沟里跳。

牵牛人望着两处堵住的车轮，慢慢松了手。

另一个人却伸脚踢冻木。车轮震了一下，鲁安刚伸手又缩回，木刺已划破手背。陈九扶住土坎上的石头，想跳下去帮忙，被魏三拽住后领；三名门哨都在眼前，这不是六个民夫围一个人就能算赢的仗。

陆承将刀拔出一寸，雪光亮在那人胸前，声音压过牛的喘息：“松手，站上来。再推车下沟，便按拒捕。”

那人看一眼归路的矛尖，终于举起双手。他们认识这条绕营门的便道，原想趁短哨换更把车赶走，没料到这回追来的队伍先占住了能转辕的高地。手里的借条仍是他们最大的依仗，刀却没有必要为那张纸流血。

“我们拿的是雇车钱，没偷牛。”他说。

陆承让他退到高地，双手空着，不先认偷，也不准碰车底。魏三与陈二帮老汉换上备用绳，鲁安在原地捡回脱落的铃布。顾沉舟只看纸，不拼旧案：借牛条写今日午后，门册却没有这头牛出门，牛棚也未见领用人。

“从哪一门出的？”

“柴门。门边那人叫我们别走正门，车回去再补条。”

“谁？”

牵牛人摇头，说夜里认不清。顾沉舟便不逼他把名字说出来。借牛条、役牛纹、未登记出门和现场车子，足够交军法核查；一句“仓丁给的”还不能把秦百户写成主谋。

车底旧袋没有装满。陆承只在两名门哨见证下开外毡，不拆袋口，称重回营再办。八人带牛、带车、带两个待问人返回，刚到柴门，夜鼓便响了一声。

苏晚棠先看鲁安手背。冻木刮出一条口子，不深，清洗包扎，明日不能抬重袋。顾沉舟在耗材栏认下这块药布，没有把救牛写成无人受伤的小胜。

车在营门复称，旧袋净麦十斤，袋上只有转运棚缩号。数目恰好等于今日缺额，却不能因此认作同一笔；粮先封，等转运出仓簿、车夫领料与西墙收粮票互校。马老汉牵着牛站在旁边，直到军需役牛册补上“实物归棚”，腿才不再抖。

仓丁拿来的暴病赔条被军法收走，报损暂撤，老汉无需先卖屋赔牛。周校尉让人给柴门挂锁，往后役牛出入按正门登记；那条捷径省下的一刻，差点赔掉全营一头拉粮的牛。

秦百户听见借条有自己的小印，亲自来认。他没有承认放牛，只说该印专用于仓内交割，若被盖在借畜条上，须查印匣与经手簿。顾沉舟不拦他去查，先请军法保留旧条，再令仓丁指出今日从哪一本簿里撕的赔纸。

两张纸由不同人拿来，一张借牛，一张报死；究竟是冒印、越权借出，还是有人想先把牛变成肉账，仍需原簿。牛活着回来，至少让所有解释都得面对棚里的一声鼻息。马老汉站在牛角旁，头一次敢当着秦百户说：“它今早没有病。”

顾沉舟正要回灶，周校尉叫住他，将六份勘渠半日脚钱放在桌上。不是军功赏，是今日查清工食未结脚钱后，从营中役钱柜先付的旧欠。魏三拿到铜钱，捏了许久，才塞进腰袋。

“明日还去？”他问。

“不去旧渠。”顾沉舟指着牛棚外的车，“先把能拉粮的人和牛编起来。路上有人敢拿官印牵牛，我们就不能只让马老汉一个人守。”

魏三把绳绕回肩头，站到了陈二旁边。

这一次，不用谁先催他按印。
