# 第四十七章 流民登记

正月十六午后，宁川河边的风比城墙上更硬。

上午送粮的牛车在秤房门外停了半个时辰。昨夜贴在墙脚的油布没有再起水珠，许木匠查过木床和梁脚，孟槐才开了房锁。南驿十袋只取原号甲、乙两袋，仓兵与驿厨在出发前分别称过五十斤；崔岳带两兵护车，车夫不走昨天塌梁前的石阶，绕西侧平地入院。

车到门前，门槛却比木床高半尺。押车吏催人把粮抱上去，顾沉舟让车夫先卸牛轭，许木匠用两块厚板搭缓坡，两人一袋沿板传递，不让人肩上压着五十斤跨高门槛。第二袋落床时，陈二喊出封线记号，独立仓兵复称，合一百斤；南驿原五百斤余四百斤留棚，旧城只记转存，不记新增调拨。

押车吏还想把余下八袋赶在天黑前全拖来，孟槐把锁扣到腰上，顾沉舟指着仍封着的险梁房：“五日借房不是全院交仓。两袋过了一夜再说，明日墙脚返潮，先换垫木，不用更多粮压住问题。”

崔岳将一兵留下补院外哨，准原留守三兵中的两兵随查民册，再加自己带来的一兵，秤房仍有两兵与独立仓兵守着。他给顾沉舟的副令只到河堤，沈三的身份若有线索也不许追出旧城。顾沉舟接过一斤路食，先把右虎口的布重新缠紧，孟槐带路，没人为了赶天色让他去扛登记桌。

顾沉舟带着三名护场营兵、陈二、孟槐和许木匠下到河滩时，先看见的是一排倒扣的陶碗。碗底压着红角粮票，票纸被潮气卷起，像一片片冻僵的舌头。

河堤下挤着二十多顶草棚，棚与棚之间没有路，只有被脚踩黑的雪。有人见军兵下来，立刻把孩子往身后拽；也有人拿着票迎上来，喊得比风还急。

“说好修渠就有粮，票在这里，今天却没人认。”

顾沉舟没有伸手接票。他先让陈二把队伍人数报出，再让三名营兵站在上风口，不靠近棚门。军令写的是查明流民住处、人数、已领粮和可出工者，带路食一斤、温水一囊，申末回秤房；遇冲突退回堤口，伤者由两兵护送，不强拆棚屋，不以红角票换粮。

“谁发的票？”顾沉舟问。

最先答话的是个瘦汉。他说自己叫马六，手里有七张票，票角都画着红三角，背面写着“修南渠，按户给麦”。他说三日前有个穿青短褂的人在河边登记，收了每户一枚铜钱，承诺今日开仓。

孟槐接过一张票，只看了一眼便摇头：“不是旧城军需票。旧票要有仓号、经手人和日期，红角这里什么都没有。”

“可那人说是转运司的。”马六不服。

“他说什么，先记在口供栏。”顾沉舟让陈二抄下，“票只作物证样式，不能作已经发粮的凭据。”

他们没有把人群叫到一处。顾沉舟让孟槐按草棚编号，从靠河的第一棚开始，一棚一棚登记。每户先报姓名和原籍，再由同行人互相确认；报不清的，记作待核，不用军兵一句话替他补齐。

第一棚住着寡妇柳枝和两个孩子。她说秋后从北渠村逃来，家里原有四口，丈夫死在冻雨里，手里只剩半袋炒豆。顾沉舟看见她棚角的破麻袋，袋底确有豆壳，却不能把豆壳当半袋存粮。他让陈二记“现有粮不称”，又把两个孩子的咳嗽写进待医栏，不能拿人数去换更多粮票。

第二棚是三名木匠，年纪最大的叫梁铁。他们有斧、有短锯，能修渠闸，却说青短褂的人先收了两枚铜钱作领工押钱，叫他们等票。梁铁拿出一枚磨亮的铜钱，说是那人摸过又退回的零钱；钱面沾着红色粉末，和票角的颜色近，却没有人能证明两者来自同一包颜料。顾沉舟把铜钱和票分开放入纸袋，注明来源，不让相似颜色把钱和票并成一件证物。

登记到第七棚时，河堤上忽然有人吹了声短哨。几个年轻人从后坡挤出来，手里拿着扁担，喊着官兵要抓人。三名营兵立刻把盾立在棚外，没有拔刀。顾沉舟让陈二继续报数，自己退到能看见两边的位置。

“我们不是来抓人的。”他对那群人说，“但也不会拿一张没有仓号的纸给你们变出粮。愿意登记的留下，不愿意的退到堤口，别把孩子推到前面。”

一个高个子青年把扁担横过来：“登记了就要征夫，上一回登记完，脚钱没拿到，人倒被拉去修城墙。”

“上一回是哪一日，谁领的你？”

青年答不上来，只说领队是个胖子。顾沉舟没有逼问。他让陈二记下“口述有领工人，姓名待核”，又让孟槐去看堤边是否有旧役棚。孟槐很快带回一块裂木牌，上面还剩“南渠三日”的半行字，背面没有官印。

木牌比高个子的怒气更有用。顾沉舟把它放在登记桌上，愿意候问修渠的人自己在牌旁报名；不愿意的只登记住址和人数，不把沉默写成拒役，更不把报名候问写成已领工粮。

登记完最后一棚时，陈二报出一个数字后停住：“二十三户，五十七人，可出工的二十九人，伤病、老人和未满十二岁的儿童二十八人。红角票十七张，另有两张只有半角。”

顾沉舟看着这份名册，心里没有升起轻松。五十七张嘴不是五十七份能立刻发下去的粮，二十九个能出工的人也不等于二十九个可随军搬袋的脚夫。伤病、孩子、老人都要有自己的份额，登记之后反而把欠粮变得更清楚。

河滩尽头传来争吵。一个穿青短褂的男人被两名流民押了过来，手腕上还缠着一圈红线。他自称沈三，是南驿脚行的伙计，票是替人送来的；那人只说“上头要收工”，没有给他仓号。

沈三想把票抢回去，孟槐用旧矛挡住他的手。顾沉舟没有让营兵搜身，只让陈二当着众人记下票数，再请三名流民分别说出交钱、领票和约定的日期。三人说法并不完全一致，有人说交了一枚铜钱，有人说是半斤旧米，还有人说只按了手印。

“你们听见了。”顾沉舟把三份说法分栏，“票的来路、收取的东西、约定的工期都不一样。沈三可以回南驿，但要在驿长面前说明替谁送票；你们也不用把他的话当成已经发粮。”

沈三脸色变了：“我若不回，东家会扣我脚钱。”

“那就把脚钱也登记。欠谁、做过几日、谁在场，明日一并问。”

沈三解下手腕红线，说是发票时用来扎纸的，自愿留下样线。顾沉舟让一名营兵陪他到堤口会合崔岳，既防人群再围住他，也不把一个待核的脚行伙计当成罪犯押回去。另一名营兵给柳枝的孩子递去温水，水囊耗去半囊，不能从五日驻粮里另算；孟槐把裂木牌和红角票分别装进两只油纸袋，封口由他和陈二各按一指印。

天色暗下来，马六忽然问：“那我们今晚吃什么？”

顾沉舟指向名册：“今晚按实际住户报给南驿，能核出多少先供多少。没有称过的豆子不写成半袋，没查清的红票不换成麦。若南驿只肯认军粮，不认河滩上的人，我会把人数和缺口连同原票送回去。秤房一百斤是过路军粮，不能擅开，也不能拿给你们看过就算领过。”

他让许木匠先带两户人到堤上看可住的破灶房，不动南仓六户门板。屋顶漏了半角，梁脚尚稳，孟槐找到房主，愿借一夜，军需付修漏草料。柳枝把两个孩子移上来，梁铁用自带的短锯修了窗挡，花了半个时辰，记作安置实工而非修渠工。

南驿回条由崔岳亲自送到，驿厨从另拨的赈急粮中称出二十斤，供五十七人今夜薄粥，明晨续额待报。不是从一百斤试转军粮里挪，更不是兑换十九张红票。驿厨的伙计随车送到堤口，马六带两人接粮，陈二在界内复认，粮分两锅，伤病八人的软食先盛，余下按实际人数分。工钱尚未兑现，至少第一锅不再挂在陌生人一句承诺上。

等锅不是明日口粮有着落了，可人群的喧哗慢了下来。马六把七张票交出六张，留一张给自己作副样；他不信官府，却愿意让纸上至少留下一个出处。

申末前，登记完成二十三户。实住人数五十七人，暂可出工二十九人，其中木匠三、挑土工十一、能看牛车者四，其余十一人只可做轻活；伤病八人，儿童十三人，老人七人。数字由孟槐按棚逐户复念，陈二按名册复算，三名营兵只见证人数，不在粮额栏签名。

回秤房的路上，许木匠问：“真要修渠，二十九人够不够？”

“先看渠宽、淤深和要换的闸木。”顾沉舟说，“工役要有日数、口粮、脚钱和伤员停工栏。没有这些，征夫只是把饥民换个地方挨饿。”

孟槐把旧矛扛在肩上，望着河滩上那几盏微弱的灯：“红角票不是粮，可有人拿它把人骗到这里。明日查渠，先查谁承诺过什么。”

顾沉舟点头，将十七张整票的逐张抄样、两张半票、裂木牌、红线、铜钱和五十七人的名册分开编号；马六留的一张原票注明未收，其余原物分别封存。一斤路食耗七两、余三两，温水余半囊，查册三兵与顾沉舟等人回秤房，沈三随崔岳返驿。夜间军镇复文抵驿，准原借调期满后延留三日，只办南线转存与交接，黑河另有留营人手，不将延留写成永久驻城。秤房已收两袋麦，宁川也多了一笔必须兑现的账：谁能出工，谁先吃饭，谁受伤后由谁送医，都得在修渠前写清。
