# 第二十五章 缺口在西墙

受伤弩手醒来时，天还没有亮透。

苏晚棠先看伤，不看他是谁。箭头从右肩外侧擦入，卡在皮肉与筋膜之间，未穿胸骨；头侧撞在沟石上，左耳后有一片肿青。她让药童量脉、记呼吸，又把止血布的尺数写进药耗册，才允许顾沉舟隔着帐帘问三句话。

“能说自己的名字吗？”

那人喉咙干得发响，只吐出一个“严”字，后面的音便散了。

“短牌从哪来？”

他闭眼摇头。苏晚棠立刻让顾沉舟停下：“第二句已经让他用力。你要证词，先让他活到能重复。”

顾沉舟退到医棚外。短牌被放在药柜旁的空盘里，没有与箭、白砂和沙沟四袋的封包相碰。那是一块薄铜片，边缘有两道旧磨痕，正面刻着“西墙乙三”，最后一笔被刮去一半；反面只留一个浅凹，像曾经压过小印，又被人用砂石磨平。

贺兰朔站在棚外看了一眼：“骑军不用这种牌。”

“营门也不该让它离开西墙。”陆承说。

这句话不能当结论。陆承把短牌送去营门旧档，自己不拿钥匙开匣。顾沉舟去找西墙门簿，秦百户则被周校尉叫到军议房，未许他先看证物。

门簿有三份。

第一份在营门，记每次换防、借牌和归还；第二份在西墙，由值守军士按时辰抄写；第三份是转运棚交接副本，只记粮车和随车人，不记短牌。三本互不由同一人保管，正好可以互校。

腊月二十九三更，西墙门簿写“乙三出，押车一辆，向沙沟”；营门簿同一时辰却只有“乙三借出，持牌人空缺”；转运棚副本写的是“甲车，未载粮，向旧坡”。同一块牌，三个去处，不能凭其中一本把谁钉死。

陆承指着营门簿上的墨迹：“这一行是换班后补的。前后墨色不一样，纸角还有冻裂。”

顾沉舟没有把补写认成造假。他先查门哨名册。值第三更的门哨是两名新换防兵，交班时一人病退，由一名老哨临时顶上；老哨在证词里只记得“看见短牌从西门出去”，不记得牌交给谁。三人都不是同一经手人，口供也只能解释一段时辰。

西墙值守的老卒很快被叫来。他认得牌面刻法，却说乙三原本有完整的“三”，刮痕是旧年留下的。他记得一件小事：那夜押车的人没有粮袋，车轴上却挂着一只空麻套，套边沾白砂。

顾沉舟让老卒把当夜的火盆、门栓和车辙位置重新画在墙上。老卒说车是从西南斜上来的，车轮在第二道石坎处打滑，押车人下去垫木，回来时空麻套已经不见。这个细节没有写进门簿，因为值守人只负责开闭墙门，不负责车上杂物。陆承当即叫来两名换岗兵复看旧墙根，那里只留下一段被冻泥压平的绳印，不能证明套袋归谁，却能证明车曾在墙内停过一刻。

白砂与沙沟坡下的砂层颜色相近。顾沉舟让药童从空麻套、壬袋外缝和受伤弩手袖口各取一撮，分装三包，写明位置和时辰。三包砂都不能直接证明同一辆车经过，因为西墙到沙沟之间有一段旧道本就铺着白砂；只有再对车辙宽度、封线磨痕和门簿时辰，才能缩小范围。

沙沟四袋也不能被短牌吞掉。甲袋四十九斤九两，乙袋四十九斤八两，己袋五十斤，壬袋四十九斤七两，合一百九十九斤四两。顾沉舟让陈二把壬袋另列“封线稍松、待二次复称”，少掉的六两不许冲进西墙十斤缺口，更不能拿结霜三袋的干湿变化去抵。

秦百户午后才从军议房出来，听见顾沉舟报完三本簿子的差异，先问：“受伤那人招了？”

“苏医官说不能再问。”

“那一块铜片也能算证据？”

“能算他身上有过一块牌，不能算牌从你手里出去。”顾沉舟把三份抄本推开，“东仓的出粮记录也要对上，不能因为西墙有缺口，就把十斤和壬袋六两并成一笔。”

秦百户盯着短牌，脸色不变：“仓曹只领粮，不发门牌。西墙的牌，找陆承。”

陆承没有回嘴，只让门哨把旧牌册抬来。册中乙一至乙六共六块，乙三在景和十六年冬天有一次“边角磨损，换新牌”的记载；新牌铸号应在反面，眼前这块却只有磨平的凹槽。换下的旧牌按规矩应熔掉，未记去处。

旧牌去处是一个新缺口，仍不等于秦百户指使。顾沉舟把“旧牌未销、乙三补写、空车带白砂、受伤弩手持牌”四项分开，分别交给营门、军法、伙房和医棚留存。他自己只留一份抄本，连短牌上的铜屑也不刮取。

下午，苏晚棠说伤者可以喝两口温水，能回答一句重复问题。

顾沉舟再进帐：“牌是不是有人给你的？”

弩手睁开眼，手指在褥子上抠了两下，艰难道：“灰帽……说，挡车，不开袋。”

“灰帽是谁？”

他又闭上眼，脉搏骤快。苏晚棠立刻把人挡住。顾沉舟只让药童记下原话、说话时辰和伤势，不把“灰帽”写成姓名，也不把“挡车”写成劫粮命令。

可这句话解释了一个动作：沙沟袭击者为何先射辕、再逼退车，而不是当场割袋。动作与口供互相照见，却仍缺少给牌者和完整路线。

入夜前，西墙送来一封急条，说今夜三更要从东仓补出二百斤净麦，送往西墙，理由是“守墙缺口、旧粮受冻”。急条盖着营门公印，纸边却没有周校尉常用的骑缝，落款处的“陆”字横脚向上挑，与陆承留在营门的两张真令不同。

陆承拿起急条看了许久，没有撕碎。

“先封纸，先查墙。”他说，“明日再问是谁送来的。”

顾沉舟看着那一行二百斤，知道西墙的缺口终于从账上走到了今晚的雪里。若是真的，拒运便会让守墙的人断粮；若是假的，开仓便会把四袋刚追回的粮再送进一条看不见的沟。

周校尉把军令纸扣在案上：“顾沉舟，你只管封粮、核袋、报差。出营查墙，由陆承定兵额。”

顾沉舟点头，把二百斤拆成四袋待运、每袋五十斤，另列封泥、净重和领受栏，暂不从东仓提出。他没有替任何人签发，也没有因为短牌在伤者身上就把急条判成伪造。

门外的雪落得更密。旧牌、空车、白砂和一封没有完整骑缝的急令，被分在四张桌上，谁也不能单独替另外三张桌子说话。

西墙真正的缺口，或许不在墙上。

顾沉舟临睡前又去看了一眼封存处。四袋粮旁挂着四张白纸，分别写着“袋号”“称量”“经手”“去向”，没有哪一张可以用另一张的空白替代。陈二问他为何还不把门锁上，他说锁只能挡手，挡不住有人把西墙的旧缺口挪到沙沟，也挡不住有人把沙沟的白砂写成东仓的损耗。明早复核之前，所有数字都只能待在原来的格子里。

他又把西墙门簿的三份抄本用麻绳分开系好，营门那份交陆承，转运棚那份交军需房，伙房只留空白索引。这样即便夜里有人撬开粮棚，也只能拿走袋子，不能顺手把三处记录改成同一个答案。做完这些，顾沉舟才让陈二落锁，自己到医棚门口听了一刻呼吸声。

帐外的伤民没有人问短牌，只问明早是否还有热粥。顾沉舟把这句也记在心里：案子可以等复核，口粮不能等嫌疑落定。记牢。
