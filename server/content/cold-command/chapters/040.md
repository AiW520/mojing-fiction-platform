# 第四十章 伤员先行

正月初九清晨，白石返关的空车停在雁回侧棚，轮上的冻泥还没有化。

车和六名护送人员都是昨日回来的。顾沉舟把初七白石实收二百斤、初八六人返关和今日核付费用分成三栏，再叫仓兵取出那张三斤热食票。车夫与白石军厨的回条都确认六人初八出发前吃过热食，初八雁回日额因此只需实拨二百七十七斤，另三斤结付白石，不再给六人发一份回程粮。

“旧借还清，回程也结了。”陈二说。

“车轮和脚钱还没有。”顾沉舟让他把最后一格留着。二百斤不能因为又核一次票便重新装车，白石返关的人也不能被写成今日才出发。

谢无咎带来一张随车名册。今日南驿有后续官粮到站，他想让雁回医棚一名伤脚夫随接车队过去，核认白石旧车的轮箍，顺便少占关内一份软食。

苏晚棠接过名册，只看伤情便摇头：“右脚肿胀，夜里发热。他看不清车轴，也不能替旧债作证。”

“只是坐车，不是拉车。”谢无咎说。

“路上的槽口会颠。他若二次伤到骨头，医棚要多养半个月。”

南驿医棚地势低、屋里暖，有空床能接观察伤员。转医本来可办，却不能与认车、接粮绑在一张单上。顾沉舟请罗定把两项任务分开，苏晚棠独立判断能否转医，接车队只认粮和车，不带伤员填见证栏。

罗定沿图标下两路。接车队四名营兵含郑衡、两名原役车夫，共六人，用昨日返关的空车到南驿，迎后续一千二百斤净麦官粮；分载于来粮原车，空车只作换轴备援，不让一头牛硬拉全部。两斤干饼从今日已领份额留出，温水三囊、牛料十二斤另拨，午前到站，日落前归。遇塌石、敌骑封路或车轴断裂退南驿，伤者由两兵送驿医，不进野沟追人。

医转另用一辆关内空车、一名受训药童和两名健康脚夫，三人护一名伤脚夫到南驿，沿西墙影晚半刻出门。携软食两斤、温水两囊、退热草一包、清疮布一尺，口粮从医棚原额分出；三人份额仍属今日在役人粮，不增加军籍。有人持械封路、车轴裂或病人高热便退最近墙影报关，不能因接粮队在前就追赶；日落前报接收，伤员能否留驿由驿医决定。

苏晚棠再查脚背和肿胀，准用垫架坐车，每半个时辰停下抬高伤脚。她把右臂擦伤骑手的名字划回停骑栏，他今日不能骑马押送医车。税棚右掌浅裂的脚行也不碰绳，两名护送脚夫都从健康在役人中选，不挪四名伤脚夫填空。

辰时，老周蹲在返关车轮旁，指出一道从外向内的新刮痕。轮缘受过侧压，车轴却未断。他以木尺量榫缝，顾沉舟在一旁报距，肩膀没有抵上车辕。

“像被窄口的木头顶过。”老周说。

“昨日有没有听见木响？”郑衡问车夫。

车夫说侧坡转弯时响过，另一人却记得是在驿口。两人口述分列；税棚旧木屑、轮缘木粉另装两包，不能拿“像木桩”直接证明有人拦车。老周确认车能轻载，把备用楔塞入车底，六人才出门。

医转车在半刻后过闸。伤脚夫怕误工，想把脚架放低。药童按住毡垫：“你只管告诉我哪里疼，车怎么走由他们管。”

两名脚夫先探墙影浅槽，再牵牛向硬土移。苏晚棠没有随车，她留关接另一名发热伤脚夫，交接页由药童带去。四名旧伤脚夫中一人转医，不是少了一份责任，只是接手的人换到南驿。

接车队在坡弯听见北水槽一声短哨。郑衡没有调头，两兵护车贴内侧，另两兵望归路。墙楼回报无火、无新影，他便按原令前行。那一声哨没有把六人从接粮任务里拆走。

医车随后遇到冻裂浅槽。前面的商车想借它的两块垫木，领头人说拿一袋豆料换。药童拦住他：“木在伤车下面，搬走，病人的脚就得落沟里。”

商人不肯松手，两名脚夫却没有同他拉扯，先让牛停稳，一人守车，一人去喊驿卒。顾沉舟随关内验路人步行到墙影转角，看见商车左轮已压塌冰面半掌。他只在两兵能接应的范围内查槽，未把自己添进出营接车兵额。

若医车先走，左轮会陷入水沟。老周由接车队退到转角帮看，脚夫用木杆探底，发现沟中埋着旧铁片，边缘有新刮痕却无车号。驿卒收铁片，门哨另画位置，先不归柳台空车证物。老周用短木搭斜面，医车退半丈，伤脚夫的脚架始终没落地。

这一刻多耗了一刻钟。商人看见冰下露出的黑水，自己放开了木，转去取本车备用板。他能等，受伤的人却不能拿骨头替他的车试路。

医车抵达南驿，驿医确认伤脚夫无明显骨裂，仍需留一夜观察，夜间若高热便先处置、报雁回，不继续送白石。药童交出药食，驿医逐项接收；两名护送脚夫与医车日落前回关，药童留驿看护，到次晨再随原驿递回。软食余量由驿医接，不能因车回关便写成全部吃净。

药包开封时，退热草有半撮粘在布缝。药童与驿医分别报开包时刻，将散草收回洁纸，核的是药物实存，不把这点差额塞进粮耗。驿医先签接病人，药耗另待晚间复核。

接车队在南驿看见来粮原车三辆。转运票写二十四袋净麦，各五十斤，合一千二百斤。六人认车号和封线，由南驿书记查出站页，郑衡护粮回关，空车不用换载，带回原号。护送两斤干饼耗一斤六两，余四两回伙房，牛料耗八斤，余四斤退马棚，温水按实耗核回。

日落前，二十四袋在雁回干棚逐袋复秤。两袋各少一两、一袋多二两，合重一千二百斤，差数仍分别保留，不靠总数相抵掩去袋差。军厨与仓兵按干湿、虫痕、袋底和封线查验，另留各车样本，没有用试吃验粮。新拨登记在初九一栏，初七首拨第四袋和八袋未开粮仍各自核验，二十斤旧待验粮不添进可用仓。

谢无咎盯着那辆没用上的空车：“带了一趟，还是得付脚钱。”

“途中断轴有它接。”郑衡说，“今日没断，不代表明日可以不留。”

军需房按实际行程结旧返车费与今日接车费，医转另列。白石二百斤旧借、初八三斤热食、初九新拨一千二百斤，终于没有一张总票能把它们互相吞掉。

贺兰朔从柳台外围回来，只交昨日倒扣窄车的现场图。六只空袋、削短木桩还在，车辙有一段朝旧堤弯，尚无仓票或脚行名册对应；现场木屑与返关车轮的木粉深浅不同，不能认作同物。顾沉舟将图样交营门，没有把那一趟查路写成接粮的见证。

晚间医报送到，伤脚夫在南驿仍发热但未加重，右臂伤骑手继续停骑，税棚脚行今日未拉绳。苏晚棠在旧四名伤脚夫中注明一名转南驿，不在关内重新加一人，又认下驿医所需的退热草一包。

罗定问：“今日还欠什么？”

顾沉舟指向四处：备用车脚钱刚结，医转明日要接药童，水槽裂木与松油仍待验，初七首拨第四袋还差四两。新粮到了，只能把锅续上，不能替旧证物补出答案。

关外夕阳落下，柳台旧堤的浅痕像一条被人试过的近路。顾沉舟收起车序图，先把明日备用担架留给医棚，再去北水槽看灯。
