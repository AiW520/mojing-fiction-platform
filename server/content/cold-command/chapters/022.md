# 第二十二章 沙沟伏击

第十二只袋子的木签还没系紧，石头就从坡上滚了下来。

马老汉先听见声，侧身将花额牛往内牵。石头擦过车辕，撞在沟边，冰壳碎得像一盆倒扣的瓦。原车左轮猛地一沉，最外两袋麦几乎同时滑向冻水洼。

“退到车侧！”陆承喊。

顾沉舟来不及收起点袋板，用左肩顶住陈二，把他从辕头带开。他右手虎口尚未全合，刚才一撑车，药布里便渗出血；十二袋的数却已经喊完，谁也不能让此刻的乱替那六百斤消失。

今日是接粮，不是出兵。转运棚把下一批六百斤净麦送到营北三里沙沟，十二袋，各五十斤，另有两袋豆料待马料交接。黑河营带来一辆备用空车与两头役牛，原想接过载粮车，留空车让转运夫回去。

周校尉批四名营兵，陆承在内；八名民夫，包括马老汉、陈二、魏三、陈九，另有顾沉舟，共十三人。干饼六斤半、温水三囊、牛草十二斤从当日份额支出，日落前回营。遇冰裂、三人以上持械、路被堵或车轴折断即弃货撤，伤者由两名营兵护回，不准民夫顶刀。鲁安伤手，留灶看绳。

谁都知道这条令，谁也没料到危险来得这样快。

转运车夫交完十二袋，已经步行去西侧驿棚等领空车。接粮的门哨刚在副条落名，石头便下来了，封签还在车上，兵卒却无法再靠一张交割纸让坡上的人停手。

东坡响一声短哨，西坡又应一声。

陆承不拿两声哨当敌数，只让一名兵卒上高处看路。顾沉舟看到东坡黑石后露出一截弩臂，紧接着，旁边又起两副；西坡两人持猎叉，堵的是车往后退的转口。

“弃车！”陆承下令，“上东侧高地，别下冻水洼！”

魏三一脚踩住向沟里滑的甲袋，手背青筋绷起来。顾沉舟按住他肩：“袋留，先给牛解辕。”

“六百斤！”

“牛掉下去，谁拉下一车？”

魏三松手。他没有把粮踢进沟，只将袋子推回原车内侧，顺着马老汉递来的短刀割掉受压套绳。花额牛挣出辕头，另一头役牛被牵到高地，蹄子在冻土上滑了一下，终于站稳。

第一箭射在原车木辕上。

箭离陈九耳侧只差一掌，尖羽擦破了皮。他弯腰抬袋的动作顿住，耳边滴出两点血，顾沉舟喊他撤，他却指向高地：“空车在那里！”

来时的备用车离原车不足十步，中间有土坎遮住西侧弩口。陆承看过距离，让一名兵卒用盾护住转口，六名民夫在土坎后轮抬，马老汉管牛，陈二报袋。能转多少算多少，不准从车外侧伸手。

顾沉舟抱着点袋板退上高地，挨个圈掉已移的袋号。他没有在箭下重新补封，也没有让伤者为一点漏粒停下，练过的报数声急得像喘息，却比事后凑口供可靠。

丙、丁、戊、庚、辛、癸、子、丑，八袋。

甲、乙、己、壬，四袋留在原车。两袋豆料也没动。

两头牛套上备用车，陆承催最后一组撤。西坡持猎叉的人冲下土坎，一叉勾住车后绳，想把高地上的车再拖回沟里。魏三还没扑过去，陆承已用刀鞘压住叉柄，旁边兵卒横盾，逼那人放手。

对方不傻，明知四名兵卒护住了短路，便不再拼刀，抛叉往芦沟退。东坡弩手又射一箭，箭钉进盾缘，护绳的兵卒退得肩头一震，没有追。

“别管叉！”陆承喝道，“跟车走！”

顾沉舟低头，看见土坎下有一枚磨平的铜片。他本能伸脚去拨，听见车轮响，又将脚收了回来。那东西究竟在袭击前就有，还是刚掉下，没人看全。他若蹲下取它，车后便少一个报人的。

备用车驶出弯口，八袋麦没有再少。四名兵卒一前两侧一后，民夫走在车内线，谁都没有把这支初编队伍喊成冲阵的兵。

退过三百步，陆承才让停。

十三个人全到，陈九耳侧擦伤，顾沉舟右手又渗血，没有死人。花额牛肩上旧痕磨开，渗出一点血；另牛无伤。八袋粮在车上，四袋净麦与两袋豆料留原车，原车辕有弩箭，轴边受撞，暂时不能拖。

“还回去吗？”陈二问。

陆承望一眼东坡：“不回。先到能看见营门的地方。”

魏三没有说自己不怕，只把绳收紧。今日那支箭擦着陈九耳朵过去，昨天在校场站得齐整的十二个人，头一次知道短哨不是练队的声。

到了路外高地，陆承留队休息，自己带一名兵卒从遮土处远望。坡上人影散了，原车仍在；四袋麦与两袋豆料看得清，封线看不清。他不下沟，不捡铜片，只在路图上标出原车位置，随即带队回营。

周校尉听完，看了很久点袋板。

“转运夫呢？”

“已到驿棚。”陆承说，“他没遭截，回执只写交车，没写哪条路有人守着。”

“人影散了，为什么不追？”

“看见五个，不知坡后还有几个。追进去，车队的护卫便散。”

周校尉没有责他胆怯，叫军法登记遇袭令。八袋麦去袋皮复称，与接粮实称相符，四百斤先入营粮；余二百斤暂留，不能直接销作被抢。六百斤不是一批全部实到营，而是四百已回、二百在沟，两处位置分明。

秦百户看着这两栏：“今天派十三人，明天又占一队兵。为了留四袋，倒比损掉还费。”

顾沉舟将受箭盾缘递到桌前，没有给他纸。

“若按损掉报，下一次那条路仍算畅通，还是同样的人去接，同样的车去拉。”

秦百户抚过盾上的凹口，不接这句话。那不是凭一粒白砂便能争论的东西，箭确实射到了人边上，转运司若还用旧路程催报，营官得先解释一次。

苏晚棠清洗陈九耳伤，令他停重活一日；顾沉舟换药，仍不准提袋。花额牛归马老汉洗净污痕、报兽医，至少停役一日，不为拖车提前套轭。伤与牛都有代价，不能写成护粮无损。

当晚，魏三想把自己的脚钱分给陈九。陈九没收，反倒问顾沉舟：“明日还让我去？”

“不去。你看路线图，明日让别人认一次路。”

“别人没有听见箭声。”

“所以你得把看见的讲清。”

陈九望了望破盾，终于把今天哪一箭先来、哪一声哨后响，分别说给另两名民夫听。不替任何人认名字，也不把自己记不清的坡后写满。

周校尉拟出次日拖车令，又听北坡急报：东高地落冰，役牛不能再过。拖车改期，先由骑哨勘路，不拿新增发现越过撤退条件。陆承把“未出营”写进原令背面，留在营门。

四袋粮还在沙沟，不可能靠一句批准立刻回来。

顾沉舟将地图挂到灶门旁，标了原车与两条撤线。魏三端着碗站在下面，盯着自己先前画的那条顺路，忽然用炭划了一道横。

他还把八袋入营粮的木签逐一交回陆承，把四袋留车的编号另抄一份，注明未开、未称、未入锅。陈九的耳伤、花额牛的肩痕和顾沉舟虎口渗血，也由苏晚棠分别留在伤情单和兽医待办上；护粮队没有因为人和牛活着回营，就把这三处损耗写成没有发生。

“这里不止能走车，也能等车。”

顾沉舟接过炭，把划过的旧路保留，再画新线。民团带回来四百斤，没能带回来整车，却把全营以前看不见的一个弯口带回了墙上。

下一次，他们不会再从同一声短哨里才知道，坡上已经有人。
