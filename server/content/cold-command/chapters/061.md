# 第六十一章 诏入京

京营内封拆开时，灯花爆了一声。

来文最后一项写着顾长河旧押运案。顾沉舟的指节停在纸边，罗定却先把军镇核令压到他面前：“父亲的名字不会给你多一把仓钥。你到京，只答经手的粮，原卷由军镇按调卷文书另送。”

两份文书的封号、来使名录和驿递回条都合得上。军镇准他赴京，京营问询暂限十日，自抵京报到起算，往返路程另计；逾期要另发留人文书。出行预计八日，雪封、断桥或有人不能自行退回，就止于最近军驿报信，不抢民车，也不拿伤员补护兵。

谢无咎将一只窄木匣推来，里面是三关调拨与宁川转运的核过副页，没有原印匣。他仍留北原，不随行。

“京里有人等着你说我错了，也有人等着你说我没错。”他道。

“我先说粮到了哪里。”

“这句话会让两边都不满意。”

顾沉舟把副页取出来逐张看。他不能替谢无咎开脱，也不能为了父亲的名字把雁回二百斤、南驿一百斤写成失粮。父亲残账原件在黑河营官处，由陆承照旧看守；他带走的只有核过的抄本、封存编号和自己经手的三处图。

这夜没有告别酒。罗定叫雁回灶头、当值营官和南驿来人到案前，顾沉舟将已收回的三日牌交空。县役接车序，仓兵接封粮，驿医接伤工；孟槐仍管房与民册，梁文仍管桥渠，不是谁接了他的图便接走别人的钥匙。

南驿来人报工粮余十七斤二两，旧十八斤八两独立；修路款余二十四两五钱，旧医欠和借梁返补仍未结。五十七人的每日二十斤赈急，照旧另领，不准因查粮人离开便停锅。借屋只到二月初五日落，期限快到，县方须先办续借或撤存，不能等京里来信。

顾沉舟将这项圈给罗定，没有给房东许一个自己无权许的长租。

黑河的交接页由驿递送回：老邵守伙房，新队书记核西墙，陆承守营门，许医佐接赵七、韩魁、周文和五名获救民夫。那些人没到雁回，更不会随他进京。陈二留下做轻活，左臂复查前不抬箱，不替新书记认黑河的数。

苏晚棠在医棚拦住他，将两卷换伤布塞进小袋。

“到京不要借这个求免问。也不要怕被说软，硬搬卷箱。”她指着他的左肩，“禁重还是禁重。虎口若又裂开，叫驿医，不许拿墨止血。”

顾沉舟试着抬了抬手，牵到肩上，便放下。她没再安慰，只在伤情页写明可行车、不可负重，交军镇书吏保管。

二月初一，七人从雁回南门启程。崔岳与三名健兵共四名护兵，另有军镇书吏许简、驿车夫冯九和顾沉舟；一辆轻车、一头驿属骡，按八日行程赴京城北门。两名旧伤护兵没入名单，不把能走几步算成能连续押车。

路食为日用干饼二十一斤，够七人三日，每日七斤；另封应急饼十四斤，只在断驿时拆。骡豆料二十四斤供前三日，草束另记，后段由沿途驿站凭七人一骡的给付条接续。路费十二两，既不出宁川修路钱，也不动南驿周转粮。清水四囊沿驿补换，不把同一囊装满八次记成只喝过一次。

副页匣绑在车中，封绳由许简保管，护路归崔岳。顾沉舟腰间仍挂粮什木牌，木牌不会让沿途营兵听他的令。

出关不久，车轮就慢了下来。

昨夜上游落雨，石汊桥的低板道没入水中，旁边摆渡又被两辆急递车占了。桥吏举着县方的封桥牌，叫他们等到明日。水边一辆载盐的民车却已经走到半道，右轮陷在板缝里，老车夫抱住牛头不敢动，盐袋外皮正往下滴水。

急递车的押骑催得很紧，船上载的是药箱，午前不到前驿便要误军医接药。他要先拆民车尾板，取梁铺船，桥吏也肯给一张损车待赔条。

冯九看了一眼，低声道：“那车挡的是下游泄口。拆尾板，盐袋会散，板道也会跟着走。”

押骑听见了：“不拆，你替我把药送过去？”

顾沉舟没有伸手拦马。他走到县方水尺旁，看刻痕上的新泥，又请桥吏打开昨晚的验桥页。水尺涨了三寸，验桥页却只写低板禁车，上面石拱的人行脊还留着两尺宽，马车过不了，人可分担药箱过去。那条脊的两端各有一根旧绞桩，不是临时拿民屋门板能补出来的东西。

“先让药过人行脊，再退陷车。别拿药急，逼这辆车替你沉。”

押骑摇头：“六箱，没人。”

崔岳接过话。他的四兵可护驿道险处，但不能分出一队去送药到别的驿。他请押骑留在桥头，药由对方两名脚夫与县桥役搬过人行脊，护兵只守两端，不出此处范围；一旦石脊晃动，立即退高台。

桥吏让人敲过脊石，石根没有松响，才准人走。

第一箱刚上石脊，脚夫便停住了。箱子宽，照平路的办法前后抬，后手看不见脚下，箱角又撞上护石。水声盖住了前手的提醒，后手一步踩偏，鞋底擦过石边，半只脚悬在急水上。

“落箱，别抢步！”崔岳喝道。

前手蹲住，箱底压回石面，后手抓住护石，才把脚收回来。押骑的马在桥头打转，他抬手要催，顾沉舟指向箱底：“你这箱过不了窄处。催一步，药和人一起下去。”

押骑翻出药单。箱中是分扎药包，并非必须连箱护送的瓷瓶；他却不愿拆外箱，六只完整箱子是他交差的凭据。

“你守开箱，我在对岸接包。”一名桥役把空担筐放下，“药没少，箱留后运。不然我们背着空木头，人只能贴水走。”

押骑看了看那只湿鞋，终于下马。他亲自解第一箱，按药单将内包分放担筐，不拆药包封口；另一脚夫核数，桥役先空筐走到窄处试步，再背小载过去。崔岳让岸边等候的人退出绳路，顾沉舟站在高台报停，不伸伤手去接筐。

到第三趟，押骑不再催快，只在每包落岸后举手回数。六箱药全部接到对岸，空箱分批后送；急递车空载沿高堤绕回，不再压这段板道。押骑守到最后一箱落岸，才冲顾沉舟点了下头。那名脚夫坐在护石后倒出鞋里的水，手仍在抖，却终于能笑着骂一句这桥太窄。

民车却在此时又沉半指。

牛鼻喷出一股白气，绳套勒进颈肉。老车夫慌忙往前拽，右轮反而把横板顶斜了。顾沉舟退到高台，叫他先解车轭，别用牛去拔卡死的轮。冯九带桥役牵牛，崔岳让两兵护人上岸，另外两兵把退车绳绕过上游绞桩。县方桥役往轮下塞长楔，绳的受力点换到车轴，不把力落在腐尾板上。

“拉到楔头就停，不要一口气拖。”

第一拉，绳骤然弹直。横板裂了一角，车夫本能要跳回去扶袋，被护兵按在高台。顾沉舟报出右轮离楔的距离，声音压过水声；冯九不等他碰车，便以探杆拨正长楔。第二拉，车轮越过板缝，整车向岸边偏回半尺。

那半尺够了。三名桥役垫上县料的干板，护兵分守退路，车一点点上了石台。老车夫坐下时，手还维持着拉缰的样子。牛未伤，车轴却新添一道裂纹，今日不能再载盐走桥。

盐袋表层湿了两只，车主与桥吏移到干棚分货留样，湿盐不混回售袋。顾沉舟没有替它称赔价。他从路费支付本队等渡、借绳和垫木钱四钱，另四钱是桥役协助挪本队轻车的实工，损车争议归县方和货主，不混成京营路耗。

本队轻车也未强过板道。副页匣由许简与一兵分段抬过石脊，三兵分别守车、骡与桥头；人匣全到高台后，冯九牵骡绕高堤，空车另借渡船，等到申时才会合。四护兵从没离成两支看不见彼此的队伍，顾沉舟更没把父亲抄本交给急递车先送。

晚宿石汊军驿，七人、骡、车、三包副页点回原数。借绳磨损由驿卒验记，日用饼支七斤余十四斤，应急十四斤未开，豆料耗八斤余十六斤。水补两次，原四囊随队，草另由驿簿记一骡当日实领。没人新伤，顾沉舟左肩痛到只能伏案，许简代他抄出桥名与停留时辰，由他核口述。

崔岳把白天那根湿绳晾在屋檐下：“你若拆那车，药早走了，我们也早走了。”

“后面的人就没桥了。”

“京营未必问后面的人。”

顾沉舟看着驿厨分给七人的饼，没有再讲大道理。今天他们只救下一辆车、按时送过六箱药，晚了半日，剩下七日便须早起，不许为了赶京里的门再走一段禁路。

他将停留原因随驿递先报。军驿给了次日官道复检后的通行回条，没有封赏，也没有添兵。能够继续上路，且让民车、药箱和副页各归其主，就是这一天的回报。

临睡前，顾沉舟又看了那封点名文书。父亲的名字仍在最末，他这回没有多看，先把明日要走的桥画在纸上。

京里要一个结论。他必须先把能抵达京里的七个人带到。
