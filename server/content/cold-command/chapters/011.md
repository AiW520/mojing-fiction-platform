# 第十一章 账房失火

账房的火是在三更后起的。

先听见的是铜盆落地声。守门的门哨以为老鼠撞翻了水，推门进去，火舌已经舔到北墙。墙边堆的不是粮，是入库簿、营门借册和各队领条。账房小窗被人从里面拴住，烟沿门缝往外钻，门哨一脚踹开，才看见桌脚下有一只翻倒的油盏。

顾沉舟住在伙房后间，听到梆子跑来时，火已经烧穿一角窗纸。

“先救人！”陆承喝道。

账房没有人回应。值夜书吏周文被发现伏在案边，后脑撞出一片血，手还压着半页纸。陆承没有让人把他拖过火门，先命两名门哨用湿毡盖住桌面，再由顾沉舟和老邵从侧墙钻进去。顾沉舟右手不能提重物，便将一只铁匣踢到门边，老邵和门哨轮换抬出；每抬一件，陈二在外面报名。

“入库簿一册！”

“营门借册一匣！”

“未盖印领条三束！”

“旧簿拓副……”

顾沉舟刚喊到这里，火梁便从上方掉下。陆承一把拽住他的衣领，将他拖出门槛。火星落在他药布上，虎口一阵剧痛。

“你的纸呢？”苏晚棠在外面拦住他。

“还在里头。”

“你先把手给我看。”

“还有一匣纸……”

“先止血，你已经让人看不住了。”

她将顾沉舟按到雪地旁，把药布重新缠紧。顾沉舟没有再冲门。他看着陆承带人把第二只铁匣抬出，里面是待互校的旧簿拓副。母亲交给他的半页原账仍包在衣襟内，自己的拓本在伙房；火若只烧掉账房，他还能指出缺页原来的位置，却不能用私纸顶替官簿。

火被压住时，北墙已经黑了一半。周文被抬到医棚，苏晚棠先查呼吸和瞳孔，再让药童把他与韩魁、赵七分开，不能因账房伤员挤掉更重的伤者。周文醒不过来，只能先记为受伤证人，不能靠昏迷时的一句梦话定谁纵火。

顾沉舟站在门外看火痕。油盏落在桌脚，桌面却没烧穿，油如何流到矮柜旁仍说不清；门栓从里面合，窗纸破口向外卷，可能有人从窗离开，也可能是救火时弄破。雪地已被踩乱。火势最重处靠近放领条的矮柜，那里只剩一片铜扣和半截绳。

陆承用木棍拨开灰烬，露出一个小铁钉。钉上缠着两道蓝线粗棉，颜色与南沟麻布相似，线头却被火燎硬，不能直接认定来自同一袋。

“你看出谁了？”陆承问。

“只看出有人知道哪一柜纸最值得烧。”

“账房每日进出的人不少。”

“所以先不看谁有理由，先看谁知道柜号。”

顾沉舟让门哨把账房四面围出一圈，不许任何人翻灰。火没有烧净所有纸，灰里可能留着封泥、铜印粉和纸页边缘。老邵搬来三只空木箱，按“原物、灰烬、现场杂物”分开装；取灰的门哨与封箱的门哨不是同一个人，时间也写在木牌上。

秦百户赶到时，火已灭透。他先看周文，再看黑墙。

“账房失火，明日便要报损。你们若把每片灰都捡回去，军粮何时能发？”

“今日的粮已按新簿发。”顾沉舟答，“烧掉的不是明日一锅，是前几日的经手链。”

秦百户望着他：“原入库簿还在吗？”

“半册湿了，封泥未全毁。营门借册、伙房抄本和东灶借据也在铁匣。若要报损，先点出原物、残物和缺页。”

秦百户没有立即争。他叫仓兵去取东仓副簿。顾沉舟注意到那名仓兵没有进火场，而是回头看了一眼周伍长常站的营门方向。

周文醒来前，顾沉舟把火场记录分给三个人看。陆承只核门窗和守哨，苏晚棠只核伤情，周校尉派军法书吏核纸页，不让任何人把“闻到油味”写成纵火结论。

书吏清点到第三束领条时，忽然报：“缺一张。”

缺的是追回乙袋当天的出仓抄单。原件在东仓，抄本原本压在账房矮柜。顾沉舟记得自己昨晚把它放在铁匣外层，方便明晨与木签互校，如今铁匣外层烧黑，纸却不见。

秦百户抬眼：“一张抄单，值得你们把火定成冲着它来？”

“我没有定火因。我只记少了它。”

这一刻，顾沉舟感到残账纸纹给他的提示又变成了代价。烧毁或丢失的纸不会自动告诉他谁动过，只有还在的三种记录能把缺页压回事实：东仓木签、门哨柴票和伙房当日实称。若缺页永远找不到，他明日便要用三类独立物证重新补记，而不能把空白填成猜测。

周校尉决定把待查账册移到两个房间：东仓副簿由秦百户保管，营门簿和伤民民册由陆承移到换防室，伙房抄本交管事。顾沉舟另将母亲原账取出，请营官在两名门哨面前封收，自己只留拓本。每份纸都有不同的保管人，谁要取，先报时辰。

这个决定把顾沉舟手里的纸分了出去，也把可疑的口子分了出去。

“你不怕我拿走你的原账？”周校尉问。

“怕。”顾沉舟说，“但一只手护不住四处的火。让它离开我，才知道谁要伸手。”

周校尉看了他一会儿：“你还没有官职，话倒像个管事。”

“我只管纸和粮，不管兵。”

“明日给你两名门哨，看守账房灰箱。粮什的代领不撤，火里的缺页要你补记。两件事都做好，才能谈什长。”

这不是升任，反而是新债。顾沉舟点头，先问：“周文若醒，谁来问？”

“军法司先问。我不许你拿受伤书吏作证据。”

苏晚棠从医棚出来，手上还有血：“周文颅后裂伤，今夜不宜问话。若强醒，可能留下昏厥，证词更不可信。你要查，去找今晚守门和今日领条。”

顾沉舟把这句话记进伤情册。医官没有替他挡案，反而把证据能不能用说得清清楚楚。

天亮前，钱二没有等到领新票。

周伍长的跟班果然从南门进来，手里拿着一张“柴车误入、乙袋已回” 的补条，要求账房销掉钱二的夹带记录。补条上的墨色新，纸边却压着昨日旧仓封泥的印痕，像从一册撕下来的空白页。

门哨按住他的肩。他没有拔刀，只从袖里摸出周伍长的牌，说自己奉命领票，不知道火。

顾沉舟没有当场把他绑进火场。他让陆承收走牌与补条，问：“你昨夜几更在什么地方？”

“门外。”

“谁看见？”

“周伍长。”

“他现在在哪？”

“北坡押车，辰时回。”

前后两个名字又连在一起。顾沉舟将“奉命领票”和“昨夜门外”分别记为口述，不把一张补条当成不在场证明。补条由门哨封，跟班留在营门，不许进账房，也不许碰灰箱。

太阳升起时，东仓按减额先送来今日三百斤净粮。陆承监督过秤，顾沉舟把本日转运交给陈二，自己带两名门哨去看灰箱。十只旧碗按甲至癸摆好，医棚五人的碗另列，周文新增口粮从普通锅按医嘱转拨，不多算一人。韩魁换了腕带，赵七仍不能站久。

木板上的裂口还在，旁边新挂的差条被风吹得哗啦作响。

火烧掉了一张抄单，却没有烧掉一袋粮的重量；烧掉了一间账房，却把更多人的目光逼到同一张纸上。顾沉舟站在黑墙前，等周伍长从北坡回来。

陈二忽然叫住他。雪地上有一枚被踩扁的木楔，楔口沾着账房窗框的黑漆，另一面却粘着伙房常用的白麦粉。陈二说昨晚搬柴时见过这东西，原本卡在火棚的车轮下。顾沉舟没有把它写成纵火工具，只让门哨封住木楔，另记发现位置、发现人和时刻。它说明有人可能从火棚带东西来过，却还不能证明那个人进过账房。

顾沉舟回到伙房，把缺页目录与乙袋木签、柴车票和营门值守册对照。柴车提前到门是前日的事，跟班今晨才入营，都不能冒充昨夜纵火的目击证据。他在灰箱旁写下火因未明，守住余纸，再去查补条是谁递来的。

他要反查押运队，先问的不是谁最像贼，而是谁在每一次失粮之后，都恰好有一张补条等着盖印。
