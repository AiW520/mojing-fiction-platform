# 第三十一章 调往雁回关

景和十八年正月初二，黑河营门上的旧历被风撕下一角。

送调令的人没有拜年。他在门楼下换了匹马，把带北原军镇印的竹筒交给周校尉，便去火房烘那双冻硬的靴子。雁回关南面的长坡断了两次车，三关下一批粮要在那里分流，军镇要一个能管住护运队的人。

周校尉念到顾沉舟的名字时，秦百户正将仓钥收进袖里。

“借调粮路什长，十五日。到了关城，听罗定守将节制。只管接车、分段护运和交接，不掌关仓，不私改三关粮额。”

顾沉舟先看了归营日期，又看兵额。他刚接下的西墙粮路不能空着，黑河的伤民也不能因为他走了，就从锅边消失。

“十名辅兵留营。老邵排伙房车序，新队书记核西墙两顿交接，陆承掌门禁和旧案原物。”周校尉已经划好留营的名字，“每日缺额送我案上。你把不能拖的事留下，不要把整座黑河营搬走。”

顾沉舟拿出两张纸。第一张是伤员口粮，第二张是役期和脚钱。陈六的名字仍夹在死亡记录与活人名册之间，葛六仍在医棚待审，沙沟弩手没有补出姓名。陆承接过纸，将父亲残账的封箱号另写在背面。

“原件留我这里。去关城只带核过的抄本。”

顾沉舟点头。腰间新牌还没磨暖，路已经往北延了四十二里。

苏晚棠奉医务调令同行，却迟迟没有收药囊。许医佐在床边逐个说伤情，她听到韩魁时打断了一次，听到赵七时又打断一次。

“腕能动，不等于能拉弓。膝不肿，不等于能踩重车。复查前都不补队。”

许医佐重新安排药童换布。周文由他观察，五名获救民夫和雪崩伤者分床留治，葛六与无名弩手各有看守。药柜两把钥匙分别交医佐和药童，结晶药酒仍封着，不随药箱带走。苏晚棠直到许医佐独立做完一次清创，才系紧自己的囊口。

出营前，贺兰朔还去了旧泉。

两匹牧户壮马的三日租期已满，兽医查过蹄、背和食水，由阿鲁牵回。四根木管已经接上，余八根还堆在木匠欠料单上，周校尉指定军需管事继续催料，牧户主槽仍不准军马进入。

阿鲁没有接一句“回头补上”。他让管事把余下木料、租马钱和照料钱分开报了一遍，才解开马缰。

贺兰朔回门楼时，八匹战马已经备好。军镇随调令另配四骑，与黑河抽出的四骑合队；留营余骑由牟副尉接管，借领箭马的页册没带出来。新配的骑手领自己的箭马，不将军镇拨付写成黑河旧有。

陆承在营门点人：八骑含贺兰朔，六名营兵由郑衡领队，八名民夫含报数的陈二，再加顾沉舟与苏晚棠，共二十四人。两辆牛车，两头无伤役牛，两匹营属驮马；花额牛留棚养肩。六百斤新拨净麦分十二袋，供雁回接收，另带三日路食四十八斤、马料九十六斤、牛料二十四斤，路途草料另束在车底，药箱由医官独立领受。

周校尉给贺兰朔的护路令准许在官道与柳沟备道间择路，过二道梁后不得再改。初三日落前抵关；遇落冰、敌骑封住两翼或车不能拖离险段，退柳沟驿。伤者先入备用驮架，苏晚棠随护，四名营兵护送，其余守粮不追。过期不到，驿站向两端报信。

“你能停车，不能让骑兵替你赌路。”周校尉对顾沉舟说。

顾沉舟用左手拉了拉车尾备用绳。右手虎口结痂，被冷风一吹仍有针扎似的疼。

车队午前出了北门。

头十里路顺得异常，雪面上只剩几条冻硬的车槽。过二道梁前，前哨折回，指向东侧山脊：两骑跟着他们走了半里，始终不落坡。贺兰朔没有派人追，只把尾骑换成前后错行，两名骑手绕到能看见柳沟口的位置。

郑衡看了一眼天色：“绕柳沟要多走六里。”

“官道也未必省。”贺兰朔蹲下，折了一根沟边的芦茎。雪下有湿意，前方车槽却被人重新铲平过。

顾沉舟让第一车停在石桩后，陈二与老车夫下去看。坡腰铺着一层新雪，雪下却是亮冰。侧沟冻堵，融水漫过路面，重车一旦上去，后车根本刹不住。

他们还没有回到车边，梁上便传来鞭响。

一辆从北面下来的空车转过弯，赶车人显然也看见了他们，急拉牛头想避，左轮却先滑出车槽。车上三捆回运绳索甩向沟口，牛横着扑倒，车辕将一个年轻脚夫压在坡边。

车夫拼命拉绳，反把车轮拉得更斜。

“松牛绳！车别往回拽！”顾沉舟喊。

郑衡拦住要冲过去的民夫。冰坡下面还有一道深沟，踩着救人，只会再添几个。贺兰朔把四骑压在坡口，另两骑盯山脊，余两骑看回路；六名营兵中的两人守粮，四人带木楔上前。

顾沉舟趴到石桩后，让陈二把长绳绕桩，两名车夫用备用横木架住绳身。空车还在一点点向沟里滑，木辕下的人没声了，只能看见一只手在刨雪。

“先卡轮，别抬辕。”

第一块木楔碰冰便弹开。郑衡咬住短刀，在硬雪上刨出槽，另一个兵将楔头压进去，绳立刻绷成直线。倾斜的车终于停了一瞬。

顾沉舟伸手去指辕底，虎口被绳结擦破，血滴在账袋上。他缩回右手，改用左臂压住横木，把自己的肩推上去。

“架撑！人从沟侧拖！”

苏晚棠伏在安全的石沿后，让受压脚夫先应声，再示意营兵托住他的髋和腿。辕木抬起不到半尺，两名兵便把人拖出，随即撤木。空车轰然侧翻，三捆绳索滑进沟里，役牛留在坡上，鼻孔里喷出白气。

年轻脚夫的小腿肿得很快。苏晚棠用木片固定，不准他试站。车夫姓丁，说他们是雁回关卸粮后返南取车的脚户，昨日在坡下还走得过去。

“今晨有人清过沟吗？”顾沉舟问。

“清过坡，没清沟。催我们下去，怕堵住后头的车。”

谁催的，丁车夫说不清，只说穿关城脚行的短褂。顾沉舟没有把这句口述当成设伏证据。漫水是实物，车夫是另一路人，山脊上的骑手则还没辨出身份。

贺兰朔回头看了粮车。若直接冲冰坡，十二袋粮就会像那三捆绳一样落下去。

“走柳沟。把伤者带上。”

郑衡指了指备用驮架：“加两个人，四十八斤路食要重新分。”

苏晚棠答：“他不能嚼硬饼，我先留两份泡软。车夫今夜护牛，明晨自己吃自己的行粮；短缺由到关后报，不从原队伤食里扣。”

丁车夫车上的行粮袋挂在车尾，没落沟。郑衡用长钩取回，交还给他，粮路没多出一份凭空的供给。

柳沟入口有一道低坎，车轮进去容易，满载出来却会啃住泥底。老车夫提议拆四袋减重，顾沉舟先去看驮架：伤者占了一匹，另一匹也背着药与行粮，不能把救来的人卸到雪里腾位置。

贺兰朔让两骑下马护侧，郑衡将尾绳绕过沟边粗柳，八名民夫分两班压住车身。第一车过坎后留在平地，将空回绳接到第二车，牛不猛抽，人也不站轮前。轮缘咬进硬泥时，顾沉舟只叫停，不催第二头牛。

他们刮去坎沿冻土，再填两块垫木，天光已经偏向西边。第二辆粮车终于缓缓抬起前轮，车上的袋口一根都没拆。

老车夫吐出憋着的气：“多走六里，还费这些工。”

“明日有车，今晚才有地方装粮。”顾沉舟靠着柳干喘息，肩头疼得发木。省下的不是六里脚程，而是两辆能继续走的车。

当晚车队在柳沟驿停下。两辆粮车没有拆封，驿卒先牵牛入棚，另给伤者腾出靠灶的矮床。那两骑一直没下梁，也没再出现；贺兰朔留半队轮哨，没有为了探清身份把人扔进夜雪。

驿卒却对顾沉舟说了一句：“雁回来粮，冬天总在长坡换车。”

“换什么车？”

“南边轮宽，北边轮窄。各走各的路，不换就上不去。”

顾沉舟看向窗外。北来的空车右轮铁箍缺了一小角，翻倒前在冰上留下一道断续的细痕。他让郑衡记下车辆主人和停放位置，没有回险坡取轮，更没把这道痕认成黑河旧站的车。

初三午后，雁回关终于从风里显出来。

城墙不比黑河营高多少，墙根却挤着两列等卸粮的车。第一辆车的牛还在，第二辆已经换成四个人拉辕。兵卒沿车边走，听到袋子碰木板的声音就停一下，像在听锅里最后一把米。

罗定守将亲自到关门接车，先让苏晚棠带伤者入医棚，再问六百斤能否卸。

顾沉舟答：“十二袋，途中没开。到仓再核，路食和马料另算。”

罗定没有嫌他慢，命仓兵腾出一片干地。六百斤接收完，顾沉舟才知道守将为什么亲自等在门口：当晚守城两班的热食，已经要用明日的份额。

他的交接职责从此落到这道关门上，黑河旧案仍留在原地，关城的新缺口却已顶到眼前。

转运棚里挂着三块牌，雁回、黑河、白石各写一千斤，期限都是五日。

牌下，雁回军厨来催粮，白石来的车夫来催返程，黑河的递报兵也在等下一趟仓票。三个人的靴底，一个挂着长坡的冰，一个沾着石屑，一个结着盐白的泥。

顾沉舟在三块牌前站住了。

同样的一千斤，要走的显然不是同一条路。
