# 第十章 断炊前的军议

军议还没开始，周校尉先把一只空碗放上案。

“今日锅里能放多少？”

秦百户递上东仓簿：“三百斤。北坡雪道封了，新粮最早后日到。”

老邵站在帐外，听见三百斤，拇指慢慢掐进木勺柄。昨日十八斤七两余粮已经全部补进三百十九斤七两的净麦，一日用了三百三十八斤六两，晚饭收锅后连锅底都刮干净。今天再少三十八斤，锅里便不能只加一瓢水了。

顾沉舟打开小册，没有先报昨日追回的乙袋。

“三百旧名册已含赵七、韩魁和营中原有病员，新添五人，共三百零五口。十八斤七两旧余粮昨日已尽，不能再借。九十六斤霉麦未解封，筛出的四十一斤仍不能进锅。”

周校尉看向苏晚棠。

“还不能吃？”

“我只能说不能确认安全。已霉变的同袋粮，挑出好看的一层，危险并不随霉粒一起去掉。”

“若晚上没粮呢？”

“请先分净粮。伤员分批进食，不少其医嘱份额。若您坚持放霉粮，就把决定写下来，不要等腹痛时让伙房说是煮坏了。”

周校尉手压着空碗，没再问。他昨夜才把五名伤民留下，不能天亮便用封存霉麦喂他们。也不能只为保住一句禁发，任整个营到晚间绝炊。

帐外的换防梆子响了一下。陆承进来，身后跟着被扣的柴车夫。

那人叫钱二，双腕有绳，脸上没有伤。陆承没把他推到秦百户面前，径直让军法书吏领到隔帐。车上乙袋三十九斤九两已经追回，车票写午后出门，却在午前到门，门哨分别作证；鲁安私卸粮袋的失职，也另报了一条。

“他认偷么？”周校尉问。

“认夹带，不认偷。说火棚有人托他带出营，到南道换一份新仓票，货主是谁，他不知。”

秦百户放下仓簿：“换袋是仓内常事，旧袋坏了，新袋才耐雪。”

顾沉舟从封袋中取出乙袋木签的抄记：“换袋不必带着三十九斤九两净麦过营门。若仓内有正式换袋单，请拿来。”

“那就继续问车夫。”

“军法问。”陆承截住话，“仓曹不能私领人。”

钱二在隔帐喊起来：“我只是赶牛！你们问火棚，别只问我！”

顾沉舟听见，指节敲了敲桌。他没有跟进去逼供。这个人能说明哪一段车路，也能把别人名字随口丢出来，必须再查进棚时辰、交物人和另一个车夫所见。

周校尉将空碗挪开，把南沟拓字铺在案上。

“西仓七，转运歇脚。谁知道这个旧站？”

秦百户看完：“前年撤了。碑旧，路线也旧。查它能查出一锅粮？”

“昨日碑还没找到时，两名仓兵拿您的口令来收样。”陆承道，“怎么偏在这条废路上着急？”

“粮损归我核。你若查到官仓外地，带回的都是仓证，当然要交。”

周校尉让两人停下。秦百户的职权并非假的，陆承的交接顾虑也有道理。若将查粮变成营门与仓曹互扣物件，下一批转运票到营也没人肯接。

“样本在营门，复验在军需房，仓曹派一人，门哨派一人。所用器具先互校，粮照发，查照查。”

顾沉舟起身，将丁二外借页放到两套铜权记录中间。原物已由当班门哨确认未离门楼铁匣，丁三是东仓拿出的另一件，出处仍待核。他们今天只用原丁二校白布秤，不拿丁三给旧称量倒补数。

秦百户承认东仓有另权，却不同意营门据此说他改过秤。顾沉舟在旁边写下未定，没有继续争。三百斤不是从两枚铜权的字里称出来的，仓门不开，数字再准也要饿人。

秦百户将仓簿翻到最后。

“东仓存量只够原额两日半。我还有北坡骑队的马料要保，军需房却把五个伤民的口粮一并压来。今日三百斤之外，一斤不出。”

“原额两日半，原额是多少？”顾沉舟问。

“四百斤。”

“实物一千斤？”

“连同待报损的部分。”

顾沉舟望向周校尉：“不能拿待报损的霉粮算能撑两日半。请点净粮，坏粮分列，否则后日新粮没来，晚一日才发现仓已经空。”

秦百户顿了顿，把另一张小纸压住，那里本列着破袋和潮粮数。他没有再说四百斤原额够几日，只道净粮需下午复点。

帐外忽然传来争吵。北坡传令兵撞进来，靴子拖着雪。

“两袋豆料少了。前哨马不能空腹再跑，今晚谁去换？”

周校尉没让他把话说成骑队催粮，只问距营几里、多少人马。北坡哨八里，六人六马，旧料到今夜用尽，再不换，旧哨连回营也要走慢。

顾沉舟拿起炭笔，在校场图上点了两个地方。旧渡北坡哨的回程，与南沟废井根本不同向，不能为了省一趟把巡哨绕去搬碑。

“哨照换。陆承只查南沟，不动北坡六骑。医棚的五人不抵搬运劳力，韩魁不骑马，赵七不扛粮。”

周校尉盯着他：“你只会把人划出去，谁去干？”

“昨日十名辅兵都在。鲁安今天留营给军法问，不让他单独经手粮袋；另外九人分两组，陈二带四人运净粮，另四人在灶口接。我在中段。少一人就少搬一袋，不让队伍散。”

“九人能守住三百斤？”

“昨日是八袋，转角让柴车时散了。今天改六袋，每袋五十斤，三轮转运，两人一袋，一个报数。柴车与粮队不同时过火棚，先清道。谁没听见回报，不许走下一轮。”

陆承望了他一眼，没有说这是军阵，却在图上替他划出避车位置。顾沉舟第一次主动改变路和队，不再只等一袋粮少了才追。

周校尉下了准令，又让书吏把本日配粮数写清。

三百斤中十二斤交医棚，包含五名新伤民和原有重伤者当日医嘱份额；二十斤留守夜队在夜间发，其余二百六十八斤按剩余人员各档旧例比例分到两顿。医棚与夜粮不再重复领普通锅，普通份额比正常日粮减近三成，任何人都不能把这次短发写作“足额”。

有人在帐外骂了一句。周校尉亲自掀帘，端着那只空碗站到门口。

“我的亲兵也领普通锅。我今日不另开灶。后日粮不到，我向军镇报断炊，不让伙房替我签够吃。”

这句话没有填满一只碗，却让营门旗手敢把短发数写到告示上。秦百户还坐着，半晌才拿钥匙起身，今日三百斤必须先出仓。

午前，六袋净麦在白布秤旁逐袋称妥，实重三百斤二两。多出的二两单列封留，不暗添锅。粮队往灶房移动，火棚路口果然又有柴车伸出来。陈二抬手，五人站定，未让开队形。

“粮队先过，车等下一梆。”

车夫骂了半句，看到陆承在路口，收住缰。六袋过三轮，一袋不少。顾沉舟报最后一数，老邵在灶边回应，十只旧碗终于摆在同一条长凳上。

那不是将领检阅新兵。辅兵们穿着杂色短袄，手上都是扛绳勒出的痕，碗里也只半份热粥。陈二拿着自己的碗，先把鲁安那份留在窗边。

“他失职，要罚。”他看向顾沉舟，“但问完也得吃。”

“留着。罚与饭另算。”

鲁安从军法帐出来，见碗还热着，站了一会儿，低头坐到最末。顾沉舟没有给他讲规矩，等他吃完，才让他下午站在转角练报数，不再单独碰袋。

陆承出营前，军令另写齐：他带三名门哨，魏三指路，南三里至废井外侧；往返限定一个时辰，任务只测路、取样，不入井、不追车；四名军卒携一斤干饼、魏三半斤，水两囊，伤者由一人护回，其余立即收队。遇三名以上持械者、断冰或通路被堵便撤，不以新发现越过时限。

这些口粮另由营门当班储备支出，不从已分出的三百斤再扣。顾沉舟留下灶口、韩魁留医棚，周校尉派另一队在日落前拖碑，另立行程，不混到取样人数里。

太阳偏西，南沟队终于回来。

陆承的刀没有血，手里却多了一片被土压住的木牌。牌上写着“歇车五，转出二”，背面是景和十七的旧站查验印，印角有一道缺。

丁七旧油纸的仓号在前，景和十四碑刻的地点在中，现在又有一块本年有人继续使用的歇车牌。路线还没闭合，废站撤去之后有人仍借它转车的事实，却再不能只用“碑旧”二字盖掉。

顾沉舟正要接拓副，军法书吏跑到门前。

钱二供出了火棚交物者：周伍长的跟班。明日辰时，他会来账房领新票。

顾沉舟望向账房那排木窗。父亲的残账拓本和伙房抄记不在同一匣，原入库簿却一直等着在那里互校。

他把今晚粮册交给管事，请陆承先换账房门哨。

灶火还在烧。另一个地方的火，却未必还会等到天亮。
