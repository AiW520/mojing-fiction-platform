# 第四十五章 风雪封路

正月十三日入夜，雁回南门外的界石消失了。

送急报的驿卒韩七伏在门洞里，嘴里还咬着缰绳。他的马从碎石岭下来便跛了，只能牵着走。最后半里，他看不见城墙，全凭西墙每隔半刻敲一次的梆声才摸到门前。

南驿的四车新粮还在棚下。官道塌雪两处，最深的一处连车辕都埋住了，驿长不敢放车，先让人拆下牛轭，免得牲口冻死在车中。韩七带来的出站页没有收粮押，纸上那八百斤只能记作在途，不能填进雁回余仓。

罗定叫人给驿卒拿热水，转身看顾沉舟。

“明早的锅呢？”

“医棚和墙哨留得出。午后的全额发不齐。”

顾沉舟没有翻父亲的残账。他手里是今夜仓兵与军厨一起盘过的实数，待验粮仍关在另一间棚里。西灶那四袋也不是多出来的粮，早已列在总余里；昨日开过的粮、今天做成的饼，不能换一个地方再算一遍。

谢无咎把地图向他推近：“六十名兵，轮着踏雪，先抢两车回来。岭上走不了，就沿柳台旧道。”

“柳台北面今日还有敌骑退路。”罗定道。

“所以带六十人。”

贺兰朔在灯下指了一处：“六十人踩上风口，前面停，后面还在走。雪檐裂了，兵多也不能把山扶住。”

他伤手裹得厚，指路用的是左手。谁也没有叫他带队。

谢无咎并非不知道塌雪。他要用人数换时辰，可一旦压塌山口，损失的便不止四车。顾沉舟把韩七的行路图摊开，问他马在哪里跛的，往后哪段能牵着走，哪段必须挨着石壁。

韩七用指甲在纸上划了几下：“官道这段不成。驿后旧灰窑往下走，到南墙低堤，路窄，车过不了。水沟冻实了，马牵得过。没有上坡雪檐，但东边是深沟。”

“你走过，不能当整条路已经可走。”顾沉舟让陈二拿来关防图。

图上旧灰窑确有一条运柴小径，南墙换哨簿还记着前日两名樵夫由低堤进关。路图与韩七的亲行不是同一份来源，只能证明有路，余下的要踏实了再说。

顾沉舟用木片挡住官道：“不拖车，拆成小载。先接三百斤，用关内两副修好的拖橇。南驿的人把粮运到灰窑，我们只走低堤这一段。”

“两段交接，少一袋谁赔？”谢无咎问。

“先报在哪段少，不让第二段替第一段按足额。三百斤只是明日缓急，不是把八百斤报成全到。”

罗定没有马上准。他让南墙副哨长带两名营兵到低堤石弯看路，三人从夜食留下干饼一斤、温水一囊，只查墙哨视线内的近段，携两根探杆，摸不到底、哨火看不见或有人受伤便退，伤者由另二人护回。半个时辰后，三人回门：近段雪下是硬地，沟边有两处虚盖，远端灰窑灯火能见，仍须由南驿一侧对向确认。干饼原样带回，水耗半囊，没有将踏路写成护粮功。

韩七在暖棚休了一个时辰，旧马留关查蹄。他与熟道哨兵共用驿递备用的一匹健马，一人走一段、一人骑一段，携回信去南驿；只走已探低路，见杆便认，到了未探段下马沿墙脚试路，不能确认便停。两人携干饼一斤、温水一囊、马料四斤，寅前须回石弯；一人受伤则另一人用马护回，不再赶驿。罗定不派他们押粮，只送交接条件，若灰窑到驿棚也断，回报而不是硬闯。

子后，灰窑亮起约定的三盏灯。传信二人在低堤石弯把回条交给接应哨兵，南驿另一名押粮兵独立报告旧柴路通到窑前，粮已从四车中挑出六袋，各袋复称五十斤，驿厨留样，封线由原车夫当面重新记号。两个方向的路，终于接上了。

驿长另有小条：若军队只认到关的三百斤，窑边六名搬运人会少半夜脚钱。顾沉舟让原转运费用拆成驿棚到灰窑、灰窑到关两段，已做的工照结，后段未完成的不预写完成；两段总额由谢无咎核上限，超出先报，不许押车吏从麦袋里抓粮抵工钱。邵平愿意留下对驿单，这条路才有人肯在下一夜继续走。

罗定准九人出门：副哨长带三名营兵，四名健康脚行管两橇，车匠老周看绳，顾沉舟留在门内排接收。各人干饼五斤取自已经领出的夜食，温水三囊，麻绳四丈，两副拖橇；只到灰窑，丑末前归。若灯火灭、横风看不见第二根杆、探杆落空或出现持械堵路者，退石弯；伤者由两兵护回，不让脚行去追。

陈二在门内把人数念了两遍。四名脚行中一个想拿伤耳辅役顶替，顾沉舟指了指医棚的停搬页，那人便自己绑紧草鞋，没有再争。

第一副空橇滑过南门时，雪打在人的眉上，顷刻结出白壳。两兵交替探路，脚行只沿杆内的足迹走。绳不是绑死在人腰上，前端用活扣，一旦橇偏，先脱扣，不能把人拖进沟里。

在石弯，前橇突然陷下半个木掌。带头脚行以为只是积雪，想加力，老周却听见底板下细细的流水声，立刻叫停。虚雪旁边仍有早先探过的硬地，可中间一块沟盖在一夜间化松了。

副哨长没有喊九个人一起拉。他让后橇停在两根杆间，兵卒卸下盾铺在硬地上，两个脚行从侧面用长木托住橇头。空橇轻，抬到安全侧即可，没必要拿人的脚试那块白雪。

到了灰窑，六袋粮没有堆在露天。南驿车夫用旧瓦片垫起干地，一袋一袋喊原号，老周看拖橇是否能受载，四名脚行每橇分三袋。怕压坏袋口，他们把绳绕在橇架上，不在麦袋中腰勒紧。

驿兵催他们快走：“后面风又起了。”

副哨长望向低堤灯，仍能认第二根杆，才发回程口令。三百斤从车变成了两副低橇，代价是走得慢、交接两次，四辆大车却不必冒塌雪。

归到石弯时，第二副橇右侧滑向沟沿。一名脚行松扣慢了半息，被绳梢带倒，左膝磕在冻土上。前面的兵立刻举灯，后队按令停住，没有人越过他去抢袋。

老周叫脚行别朝上坡蛮拉，把绳绕过硬地木桩，改成横向牵引。三个人稳绳，一人垫橇脚，粮连橇一点点移回杆内。那名伤脚行试着站起，膝盖立刻软下去，副哨长把他扶到空出的盾面上，用两根绳结作拖架；回程由两兵护，余兵守前后，不再让他抓绳。

风里响起另一声梆，三下挤在一起，比墙上的约定急。后队有人伸手指向沟外，像看见一盏比灰窑更近的灯。副哨长没有向它改道，先让前兵对回原来的两根杆，再鸣关内规定的短哨。墙上回了一长一短，方向在他们右前方，沟外的灯却没有应声。

那灯可能是樵夫，也可能是别的车队，谁也没看见人。老周将后橇收近，队伍按原路走，直到那点光被雪遮住才重新放开绳距。不是每盏灯都要认成敌人，也不是每盏灯都能把九个人带回关门。

丑末，门内的陈二先看见两点灯，随后看见三道低影。

“多一副？”他问。

“一副载人。”副哨长答。

门哨先认口令，再放开侧门。九人全到，六袋逐袋进干棚。仓兵、军厨复秤，合三百斤，袋底干，封线和灰窑交接页相合；绳磨掉的是橇脚一角，不是粮袋。顾沉舟看着军厨把可发牌翻出来，才让炊兵揭锅。

伤脚行先到医棚。苏晚棠查过没有骨折，左膝挫伤停拉三日，明早复查，脚钱照实际出工结。五斤干饼余一斤三两回伙房，水余半囊，麻绳一丈磨损单列，盾面刮坏由军械核修，不让伤者赔这趟粮。

顾沉舟的肩伤使他连卸橇都帮不了。他只能站在秤边报袋号，喉咙被冷风割得生疼。直到三百斤写在实到栏，他才发现自己一直攥着左拳。传信二人也按时返关，干饼耗六两、余四两，水余半囊，马料耗二斤、余二斤退棚；韩七的旧马继续停役，不能因为信送到了便换成一匹完好的驿马记账。

清晨，北楼换班的兵接到热饼，伤腿兵的软食也没被削去。谢无咎来得很早，看过袋底，令南驿剩下五百斤仍留干棚，不能凭这次接通便开官道放四车。

“这条低路一天能走几趟？”他问。

“先让人睡够，再算第二趟。”顾沉舟答。

谢无咎看了一眼停工页，把要发的催程牌收回，另拨两副橇的修料。他还要三关供粮，却已经不能拿车数代替能走的人数。

罗定在晨议给顾沉舟加了一项差事：谢无咎与守将联署后，先准雁回雪期筹办南线临时转运点，运料、脚行轮换和伤工先报由他承担，护兵仍由营官下令。借调期满后延留三日的请文送军镇与黑河，未获复文前不写作已经续准。

“去宁川旧城看南仓。”罗定把南驿附来的仓图交他，“驿棚容不下下一批车，不能天天拿人去替路。”

顾沉舟接住那张图。北门没有降，三关旧借没有被雪吞掉，第一趟粮也穿过了风口。可他得到的不是一张能无限领粮的仓票，而是南驿五百斤在途粮、一个受伤脚行，以及一座等他修成的转运点。

雪还压在山上，锅却已经响了。卷到边角的旧城仓图上，有一条通向南仓的路，线外画着几十间仍有人住的残屋。
