# 第五十二章 破败校场

正月二十一，顾沉舟在校场门前捡到一截断箭。

箭杆朽了，箭头还在，埋在冻草里，正对着孩子昨日拖柴的脚印。他把孩子叫回巷口，让陈二去请孟槐。校场北墙缺角，东面半排箭靶歪倒，西边的旧车台已经成了盐车抄近路的地方。

“练十个人，不难。”崔岳看着场子，“难的是别练着练着，从脚底下少一个。”

他领三名营兵随同查看，两名院兵仍守南仓，独立仓兵看六袋三百斤粮。罗定的副令只准查看旧校场、教现有护兵和六名自愿车工做牵车避险；四军人、六车工，另有两车夫和一名县方测地吏随场，粮额饼六斤、水三囊，半日后止。伤者送南驿，墙裂、地陷或牛惊便退东门，不能借练车扩兵、发械。

顾沉舟未让愿来的人排成军队。六名车工里有马六，有昨日帮牵绳的两人，另三人会看车。梁铁膝伤留驿三日，周四仍停土工，都不补人数；石满只在巷口递短绳，不进车台。六人今日领的是获准练车勤务食，原九十斤渠工粮余六十八斤不再扣一次。

孟槐带来旧地契。北角两间破屋属寡妇何氏，东沟为六户共用井路，西车台属县营旧界。测地吏另拿县图量界，先将两间屋基和井路留出来。邢良跟来看，问若校场归军用，税棚缺的护役能不能调两人。

“今日只练退车，没新护役。”崔岳说，“要人去棚，拿县役钱招；我这四人还要护下一趟粮车。”

邢良没有吵。他把西车台指给顾沉舟：“商车抄这里，少走半条街。封了它，空场出口就窄，今日盐车已经来了两辆。”

这确实是个问题。邢良在车边验货，不再抓工人，可商人也不会因为军方要练车便愿意多走路。顾沉舟让两车夫先走一遍替代出口，确认东巷能错开空车，满载车则必须回西缺口；没找到路之前，不封唯一出口。

许木匠从桥头赶来。今晨新梁未响，长板两端未松，复查回条已送秤房，他这才有空察看校场。空车在西台碾出一条浅槽，许木匠捅进铁杆，杆身竟陷了半尺。

孟槐脸色变了：“底下是老练车坑，填过。”

县图只有“练车台”，没有填坑年月。测地吏取下层泥样，许木匠在槽外开小口，露出一根朽空的横梁。实物与旧图对上，这里不是可供满车反复走的硬地。顾沉舟让人立绳，绕北墙五步和西台两处禁线，练车改到东门外硬土，井路留三尺不占。

“这点地方也练得成？”一名车工低声问。

崔岳没有答他，先叫车夫松轭，把牛牵到巷外。空车停在硬土上，绳各一端，谁听见停令，先说轮距，再放前绳、压后绳。第一次牵行，六人全往前用力，车轮只走三步便偏向井路。

“停。”

崔岳把他们拆成前牵、后控、看轮三组。马六想站在两组之间传话，顾沉舟让他只看右轮：“每个人都管一头，不要三个人都以为别人会喊。”

第二次，前组怕冲，绳一松便松到底，后组又压得太急，车辕顶住泥坎。陈二在纸上记的不是谁笨，而是绳结位置、停令时机和轮距。两名车夫各自纠正牵车姿势，兵也下场做一遍，没人只是举着刀教旁人卖命。

两名车夫今晨从驿里推来轻空车，昨日第二车的后档已换钉，车匠查轴无裂才放行；换钉所费归修车，不摊到车夫脚钱里。马六却总往车尾看，绳一绷便向后缩。他昨日没有上桥，只从岸上看见那只轮滑出去，此刻仍像听见垫板落水。

崔岳拿掉他手中的绳，让他站在轮侧两步外，只报木条上的三道白线。第一回马六喊早了，车还离线一尺；第二回他等得太久，车夫先喊停。没人笑他，后控组按每一声停都压住绳，第三回轮皮抵近白线，他的声音才跟脚步合上。顾沉舟不夸胆大，让他认清哪处站得住，哪处一脚踩下就没了退路。

到了第三次合练，车轮逼近标线，马六报出半尺，前绳慢放，后绳渐紧，车稳稳停下。崔岳拿两块木楔，让看轮者先塞楔，再换绳；顾沉舟绕到队后，只问一句：“若我不在，谁叫停？”

马六张口想说崔营官，旁边车夫却先答：“谁先看见险，谁叫。官没看见，也得停。”

顾沉舟把纸合上：“再走一遍。”

校场外忽然响起牛叫。

两辆盐车正绕替代出口，前车轮陷进薄冰，后车赶得太近，碰上车辕。前车夫顺手拔掉挡轮楔，想让牛把车拖出坑；后车牛被碰撞声惊得斜冲，车夫原先捆在车尾的留车绳未吃住，满车盐篓便沿斜坡往校场旧台滑来。

西台禁绳挡不住车。一个孩子还在绳外捡柴，闻声愣住，手里的短枝全撒了。

“先带孩子！”顾沉舟指东巷。

陈二跑过去抱人，自己左臂被枝尖擦了一道。崔岳带一兵挡住看客，另两兵绕向车后，不去抓惊牛。马六已经拎起练车的后绳，刚跑两步便想冲到轮前，被车夫猛地扯住后领。

“后边！轮前不是站人的地方！”

那句训斥把马六从昨日险桥的惊惧里拽了回来。他绕到右后，与另一名车工把备用后绳套过车尾横档；两名营兵压住绳尾，车夫领前组沿坡侧退，不与牛硬拽。车还在走，盐篓最上边一只已经开始倾斜。

顾沉舟没有往车底钻。他看见东侧有一段低土坎，立刻让前组将车头缓引过去，后组只减速不横扯。马六盯住右轮，喊出一尺、半尺，喊到最后声音劈了；许木匠从侧面送木楔，等轮速慢下来才让人推楔。

车轮撞上土坎，木楔吃住，满车斜停在朽台外。最上面的盐篓跌落，篓口松了，白盐散在冻草上。惊牛被原车夫牵到巷外，孩子已经到何氏家门前，没有人追着牛跑进人堆。

邢良赶到时先看盐，顾沉舟却请他看轮印。轮停处离朽梁小口只有两尺，满车若再向西一偏，梁断之后无法靠几条绳抬起来。邢良摸了摸一名车工磨红的掌，终于没说这是军方封路所致。

盐铺伙计要把散盐扫回篓，陈二拦住他：“掉地上的先分开称，别把泥也卖回去。”

完好盐篓按原货号仍归商人，落地盐另称、留样、报污损。邢良核税与事故车辆，两名车夫分别说明前轮陷冰和后车碰辕，许木匠量坡度，不能只用一句“牛惊”盖住拥车、松楔和路面三件事。顾沉舟不定谁赔钱，但要求事故没查清前不把押金全扣到一个车夫头上。

半刻后，盐车倒回硬地。邢良主动去空场放开一次只出一车的出口，满车绕西缺口，空车走东巷，朽台彻底停走。商人嫌绕路远，他让他们看那道刚停下的车痕，没人再把篓拖到绳上赌近道。

孩子伏在何氏膝上，半天才说出自己的名字。何氏把那截断箭放到孩子掌边，让他看看箭头有多尖，随即收走，没再让他去找柴。陈二袖口湿了一片，直到抱人的手松开才觉出刺痛。他想把血蹭在衣内继续抄页，顾沉舟抽走笔，叫测地吏替写车停的位置：“你眼见的照说，伤臂别再撑。”

六名车工坐在硬土边喘气。马六左掌擦红，驿方巡诊医佐查过，无裂口，明日先复查再拉绳；陈二左臂浅擦伤，洗净包布、停抬重一日。孩子只有惊吓，未撞伤。医佐由驿长安排来查昨日桥工回条，苏晚棠仍在雁回关；药布两片与巡诊路食另归驿医账。

午后止训，十名护兵车工饼六斤耗四斤二两、余一斤八两，水三囊余一囊。两车夫自带行粮不重复领，未搬粮、未开仓。顾沉舟将练车半日的实勤送驿结钱，绳磨一尺、木楔一块裂损独列，不叫众人因为救了一辆盐车就免费补半日活。

驿厨送来今日独立续赈的二十斤麦，柳枝照五十七人原名册分薄粥，梁铁和周四的留医食由驿医接转，不在河滩重领。有人望着秤房六只粮袋，问为什么还不能多添一勺。顾沉舟没有说库里空，只把续赈锅底翻给他看，又请书记带回明日缺额。粮就在门后，却有守关的人等着；眼前的饥饿也不会因这句话消失。他留到最后一碗分完，才去见县丞。

邢远得报后赶来，县图、朽梁和新轮痕都在。他准东门硬土作七日临时练车地，北墙与西台停用，县工曹两日内报修料；何氏屋基、井路仍不动。许可只够现有护粮勤务练车，不能借七日换军籍，顾沉舟的借调延留仍到明日日落。

罗定的回条也到了，确认石秤房今日三百斤转存量和原仓兵的收存职责，主仓险梁不得入人。军镇肯认这一个转运点，却要求两日内补上返车车次、候工钱与伤员医转缺口，否则下一拨粮仍留南驿。

顾沉舟把两份回条并放。桥能走，粮能存，车工也终于能在没有他喊每一步的时候停住一辆车；宁川第一次有了不依靠某一人硬扛的短路段。回报却紧跟着来了：七日租地、修墙钱、驿医巡诊和工钱，全都要有人催、有处出。

孟槐收起断箭，望着东门硬土上新钉的木楔：“旧营在时，十个人也没停住过那种车。”

崔岳没有说这是新军，只把六人领回井路旁，再让他们认一遍退路。顾沉舟看着三组人各站自己的位置，给罗定的续请不再写“望多拨粮”，而是附上现有人数、可走车次和实存粮，申请由军镇、县方共同筹办屯田转运。

他没拿到一城的钥匙，但明日来宁川的人，已经有了一条确实走得通的路。
