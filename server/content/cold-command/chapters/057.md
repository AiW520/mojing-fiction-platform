# 第五十七章 城中第一场雨

正月二十六夜尽时，雁回关下了开春后的第一场雨。

顾沉舟是在北门换岗时听见雨声的。雨不大，落在墙砖上却密，像有人拿细砂不停敲门。雪水从垛口往下淌，昨夜还硬着的车槽很快变成一层黑亮的泥。

他刚把宁川交接的现场页递给罗定，南坡便传来急报。宁川的驿卒从夜雨里赶来，肩上的蓑衣全湿透，鞋底还粘着渠边的青泥。

“南仓外屋进水，六户井路塌了一段，三百斤封粮没开，但秤房门下已经有水。”

驿卒说得急，顾沉舟却先问：“谁在门里？水从哪边进？”

“孟槐带人守住，县工曹梁文在清沟。东墙排水口堵着一块旧木板，谁放进去的不知道。水是从渠口倒灌，不是屋顶漏。”

罗定拿过湿报，没有立刻许顾沉舟再下南线。他看了一眼顾沉舟的右虎口和左肩：“你的延留令昨日日落就到期。”

“我知道。先请县方报水位和伤情，军粮不开门。”

顾沉舟没有往马棚走，先让驿卒把报文拆成三栏。水位、人员、粮袋，各自注明观察人。只凭一句‘封粮要湿’，不能让仓兵在雨里把门打开。

孟槐的第二份急报很快接来。东门硬土尚能走轻车，南渠旁的低路已没过脚背；何氏屋基没有进水，破灶房的后墙被雨打掉一块泥。赵麻子的右踝仍停走，董成左掌包布未拆，二人没有被派去搬袋。三百斤军粮六袋，封线和袋号都在，水痕只到木台下沿。

顾沉舟把报文摊在罗定面前：“人没伤，粮没开，先修排水。外头没有第二座干台，贸然搬出去，袋底先沾泥。请仓兵盯水尺，水逼近台面就按应急令转移，不能死守。”

罗定准他领一辆空车、四名当值营兵和两名原役车夫，沿官道经南驿到宁川，只查雨水、屋基和粮台。县方急报另准六名自愿修沟工领实工钱，不从原试工组加征。军县两边共同续顾沉舟雨灾交接一日，限今日日落返关，不开仓、不增额；发现水过车轴、持械阻路或伤者不能自退，立即退南驿，伤者入医棚。

这一纸令的兵额没有多出一个。四兵里郑衡领队，旧擦伤未解禁重拉，只指路警戒；崔岳留雁回看北门，陈二仍停抬重，在门内核车。苏晚棠不在南线，由南驿医佐接伤。随车领饼六斤、水三囊，牛料另领八斤；饼从今日路食内划，不再重领。顾沉舟只列雨灾交接，不签发宁川军令。

雨里的南路比夜里更难认。雪被冲开，旧车辙全露出来，低洼处的水沿轮印聚成细沟。两名车夫先下车探路，发现桥头横木并没有断，断的是桥外一块临时垫板。梁文不让人把板直接丢掉，先请县役量桥脚，证明木板不是南仓的征木。

南仓外，水已经绕到秤房门槛。孟槐握着借屋门钥，独立仓兵另管粮锁。屋主刚当面续空屋、秤房借期至今日日落，昨夜续借的桌子不能替两间屋续期。再留粮须另议，顾沉舟也未接任何钥匙。

“水从东沟进来，先漫空屋，后才到秤房。”孟槐指着墙脚，“旧木板卡在泄口，板后还有一层碎石。昨夜谁都没开仓。”

顾沉舟没有伸手拔板。他让梁文沿沟边插三根木尺，一根在上游，两根在秤房外，分别记录水深。县役把堵板、碎石和沟底泥分袋取样，木板上的新钉孔另画位置。新钉孔不能证明有人故意堵水，堵板也不能因为贴着泄口便算作偷粮工具。

何氏带着邻户赶来，最先问的不是粮，而是井路：“雨再下一阵，井边的石阶要塌。”

“先护井路。”顾沉舟让郑衡把两名营兵放到石阶上，另两名守秤房门。民夫只搬岸上干石，不能踏进被水掏空的低洼。几户人自己带来的门板先垫住屋基，屋主逐块报出来源，县役不把民屋木料算作军需耗用。

水势在午前突然增了一截。上游一段冻土塌进渠口，黑水带着碎枝冲来，旁挡木被撞得向外偏。梁文想跳下去顶木，顾沉舟用杆拦住：“水线没有量清，先退到硬地。”

他们把县工曹送来的短撑横在岸上，用旧绳从背水侧牵住旁挡，不动已经安装的两根闸木。绳端打滑时，护兵先钉木楔，郑衡压住退路，没人把肩膀送到水里。孟槐沿六户屋门点数，何氏将井桶和鸡笼先移到高处，老人和孩子没有被叫来运石。

可水没有立即退。背水侧的碎石一松，细流便从门板底下钻了进去。一个搬石工的腿陷到小腿，试着拔脚，身边那块冻土却跟着沉。井边有人喊，把何家的门板拆过来，多铺一层就行。

何氏挡在门前，声音发抖：“这块拆了，孩子睡的屋就没有门。”

梁文望了望车上的短料。再撑一处，泄口就少一处支护；若放开旁挡，水会直打井阶。雨声中谁都知道两边不能兼得，一名工人已经伸手去扯门闩。

“别动她的门。”顾沉舟站在硬地，让空车退到沟外，卸下车上可拆的挡板。车夫验过板背，指出只能承一人，不能承满筐石。郑衡拦住挤来的邻人，两名健工绕绳、铺板，另一个在硬地接应，一个守旁挡，最后一个看短撑。五人救一人，六工没有同时压在薄岸上。

陷腿者急着拔脚，板头又下沉半寸。顾沉舟喊他先松鞋带，将身体贴向板面，别再蹬沟底。两名工人拉绳，他用膝慢慢挪上板，鞋却留在泥里。人拖到硬地时，刚才的落脚处整个塌了，浑水卷着旧鞋冲进槽底。

没人再提拆门。梁文趁水退的一瞬，从上游分开两股细流，余下五工轮着搬干石填住板下空隙。直到水尺降了半指，才移回挡板。车夫验出板边一道新裂，只准空车回程；这辆车明日不能直接挂上满载军粮。顾沉舟肩膀一直没碰绳，右虎口却因握笔太久又疼起来，换了宽笔杆才继续报水尺。

旁挡终于回正，水退向无人居住的低石槽。秤房门下的水只留下两指深的泥印，六袋军粮封线完好。仓兵在门外核封泥外观，不拆袋，不把袋底待查写成粮食已经受损。六袋暂留原台，雨停后由独立仓兵检查袋底和复秤。

有人在泄口边捡到一枚红角票的半边。纸已泡软，字只剩“二段”两个残笔。沈三的票样还在封匣，顾沉舟没有拿来比对。他让县役把半票连泥一起封存，注明发现位置和时间；雨水能把纸从上游冲来，也能把旧票从屋缝带出，来源未明便不能替周敬或任何粮行定罪。

雨势稍缓，盐铺伙计赶着两头牛来求开水渠。他说盐货怕潮，愿意出钱请人把渠口再放一指。顾沉舟让他看泄口旁的井路和封粮：“现在放水，盐车能保，六户井路先没。你要申报货损，留下货号和重量，不能拿钱买一条未经核准的水路。”

伙计咬牙把盐篓往高处挪。两名健脚工帮他垫石，实工另报，没有从渠工粮里扣，也没有把盐篓当作赈急物资。

申时，南驿医佐报来三件事：一名县役脚底被碎石划开，停涉水半日；陷腿工膝部发冷，今夜留驿观察；赵麻子踝伤无加重，董成掌伤需次晨复查。顾沉舟把新伤、旧伤和雨中役时分开列，没用“无大伤”遮掉医布和诊费。两名旧伤者没搬石，也没因隔岸看见险情就算进六工工钱。

修沟队带回一段断板和三袋泥样。断板的木纹与屯田局余料不同，不能直接认成有人偷拿闸木；三袋泥分别来自上游、秤房门槛和东门硬土，颜色相近却未合样。顾沉舟把证物交给县役和仓兵，自己只留交接抄本。

日落前，雨停了。六户井路保住，空屋后墙需补泥，六袋军粮未开。两根短桩、短撑和一条旧绳来自县料，退料待查磨损；六工实领四斤工粮，经罗定批准从余三十一斤二两中出，余二十七斤二两。旧十八斤八两及每日二十斤赈粥另存。随行饼耗二斤六两、余三斤四两，水耗一囊、余二囊，牛料耗五斤、余三斤，均核回；车夫脚钱另结，不能因雨退便写无工。

顾沉舟回到雁回时，谢无咎正在转运棚里等他。案上放着一份新文书，没有印，只有三行条件。

“雨一来，宁川的水、粮、工钱都要有人接。”谢无咎抬眼，“你想继续接，就先看完它。”

顾沉舟没有去拿文书。他先把六袋封粮未开、井路保住、断板待查和伤情四栏报完，才看向纸面。

第一行写着：南线临时排程，三日一报，水粮分栏。

第二行写着：旧欠未清之前，不得动下一批军粮。

第三行写着：出了人命、塌桥或失粮，先问顾沉舟。

雨后的关城亮着湿灯。谢无咎说：“这不是升你的官，是给你一把会割手的尺。你还要不要？”

顾沉舟看着那张没有印的文书，知道第一场雨冲掉的不是泥，而是所有人想把责任写在别人栏里的念头。
