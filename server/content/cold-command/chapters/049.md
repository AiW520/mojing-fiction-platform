# 第四十九章 盐票的价格

正月十八辰时，宁川旧街上终于有人揭开了盐篓。

白盐只铺薄薄一层，底下还压着盖篓的木板。摊主报每斤十二枚铜钱，买半斤也得按整斤的价算。马六摸出昨日试工所得，又塞回腰里。他家锅里还能领粥，盐却已断了七日。

顾沉舟从他身边走过，没有替他还价。今早另拨的九十斤工粮已由驿厨实领，两根闸木、四副铁箍也到桥头；十人半日试工照令进行，梁铁只在石岸配板，不让人再入昨日滑石处。顾沉舟若拿全城的急需去压一只盐篓，便是在逼摊主替没到的盐付钱。

崔岳带两名营兵护他到旧街，陈二、孟槐和沈三同行，七人只问盐货与送票出处，午前回秤房。带干饼两斤、水一囊，遇持械围堵即退南仓；第三名护场营兵守桥，两名院兵守门，独立仓兵仍专守封粮，没人因看热闹把秤房空出来。

驿厨今晨另送来二十斤赈急麦，仍只供二十三户五十七人分两锅薄粥。昨日续赈的二十斤已耗尽，今日这一袋由厨工与马六当面复称，单据不经过周敬的粮行。柳枝领了伤病软食，两个孩子蹲在灶旁等热气，梁铁把工锅与赈锅的舀勺分开。他们终于没有饿着上工，可这样的粥只能撑住眼前，不能算作一城的存粮。

沈三停在一间挂着破鱼灯的铺子前：“周掌柜就在这里。”

铺门没有关。里头坐着个四十多岁的男人，棉袍干净，右手扶着算盘，身后两名伙计正给盐篓换绳。他先看崔岳腰间的刀，再看沈三，神色却没有慌。

“周敬，平安粮行的经纪。”他起身道，“我没冒转运司的名。票上也没盖官印。”

“所以你才只印红角。”顾沉舟说。

周敬笑意淡了。他拿出一份工约，三日出工二十斤麦，末尾另有一行：南渠开通、商船得泊后给付。沈三送到河滩的纸上没有这一行。

“谁裁掉的？”

“不是裁，是便条。正式约在我这里。人来了，再认约。”

“人饿着来了，才知道三日之后也不一定有粮。”

周敬将算盘推开：“渠不开，我凭什么白给麦？宁川连泊船的地方都没有，做买卖也要有人担险。军爷昨日修了渠，今早盐就能进街，这不是空话。”

顾沉舟看向门外。盐车进的是西面旱路，轮上粘着碎砖，南渠试板仍靠在石桥旁，一只船也未泊过。周敬把两桩同时发生的事接成了因果，听来像真，拿来要钱却多出一段。

他让陈二去请门口两名车夫，各自说清入城路线；孟槐领一兵去桥头取今日水位回报，不动试板。两辆盐车卯初从西缺口进城，桥头回报仍为浅淤半段、水量未测，不具泊船条件。两边的人没有领过周敬的送票钱。

周敬看完回报，收起了“因修渠而进盐”的话，却不肯收回工约。

“旧街四家铺子，只有我拿到了县盐铺的兑货凭。你要盐，就得问我。今日十二钱，明日雪再封路，还会涨。”

他把一张长票放到桌上，注明兑盐二十斤，背面另押着脚行担保。顾沉舟没有认那张印。他请崔岳让驿卒携票号去街东盐铺核对，原票仍在周敬桌上，自己只抄号。

等回报时，门外车夫已经换完绳，准备把另一车盐拖回去。周敬并非只会坐着叫价：宁川今日买不起，他便送去南驿；亏的是脚行多走半日，他却不会把全部盐压在破城。

顾沉舟拦住想追车的马六：“人家有货，能走。我们要的是让下一车愿意来，不是扣住这一车。”

他转向两个车夫，问回驿要过哪一道坡、空车是否也收棚钱。车夫说盐车每车收六钱，进旧街还得租周敬的垫板；若连买货都要赊，担保人又得是他。盐价里没有一项叫“独占”，却每项都把人带回这张桌子。

孟槐忽然说道：“西缺口那块空场，是我和陈家看着的，没借给他。”

周敬盯住老人：“雪地能卸盐？脚陷了，谁赔？”

“不能卸，才得先铺。”顾沉舟答。他没有说军队会无偿替盐车干活，只请孟槐带车夫看那块空场，核地皮归属、坡度和现有砖料。旧仓险梁房不动，六户门板不动，两家自留的碎砖愿出租，车夫自己报卸车人手与钱。

崔岳没有随他转场，留在铺门前候盐铺回条。军兵只护人，不替商人占地。

空场比粮行窄，却能错开两辆车。两名车夫用探杆找出冻土硬处，一人指着地上的浅坑说雨后要填，今日先卸篓尚可；租砖、搬篓和扫雪全算下来，比绕回南驿少一半脚程，钱却要买卖双方当面议。

“这处能否长用，等屋主和县里认。”顾沉舟说，“今日你们愿意停，是商人租地，别把我的名字写成永不收税。”

车夫笑了一声，终于解下第二车篷绳。篓底的木板被抽出来，白盐下面并没有藏粮，顾沉舟也没借查票去翻别人的货。

盐铺吏很快到场。他带来兑簿副页：周敬的二十斤兑货凭是真，今日已兑完，不能再持原票领第二次；车上另六十斤属盐铺托售，由车夫凭载货单结款，周敬只有十斤代售约，不独占整车。盐铺吏又带来前日结价，一斤出铺六钱，租脚费另议，旧街十二钱是经纪报价，并非县定价。

周敬跟到空场时，两名车夫已同马六、陈家屋主各自谈价。孟槐在砖边摆了一块小板，写租地实收，不挂军旗。原本等在粮行门口的人陆续转来，却没人去抢篓。

“你把我的生意拆了。”周敬低声道。

“你那二十斤仍是你的。”顾沉舟说，“代售十斤也认你的约。但剩下五十斤，不该先把担保交到你手上才能买。”

周敬看了看车轮。回南驿的成本还在，两名车夫却已找到了不用他垫板的卸货处。他若继续十二钱，便只剩自己买断的二十斤留在冷风里。

他重新报了价：实盐八钱一斤，不搭渠工，不要新役担保。

顾沉舟没有替全城答应。他让有钱的人自己买，赈急厨工另拿盐铺的托售货，只领两斤，十六枚铜钱由驿长批准的炊用杂钱支付，不从九十斤工粮折色。盐粒干燥、篓封与货单相符，厨工留样再按日用下锅，谁也不靠尝一嘴认货。

那只盐篓第一次从马六面前经过时，他买了半斤，只付四钱。另半日的工钱还在身上，他摸着钱串，忽然笑了，不是被人施舍，而是同样的手上功夫，终于能多留下几枚钱。

沈三一直站在场边。顾沉舟将红角票抄样递给周敬：“盐价谈完，还有送票和押钱。”

周敬不再否认雇过沈三。他认了送票一趟，取出自己的支钱页，六钱脚费未付；两枚铜钱是另给的送票杂费，不算流民交钱。驿长所留欠工簿与这页互校，六钱当场交沈三，日期为何相差一日仍分别记录，不改成同一日。

但收过多少押钱，他只肯认三户。马六报的是一钱，梁铁说交过两钱，另有人拿半斤旧米换票。顾沉舟不让人拿嗓门压过簿页，请三人分别说交物时谁在场，再找沈三辨认自己亲手经办的部分。最后能互证的是两户三枚铜钱、一户半斤旧米；其他诉求另留待核。

周敬退回三枚铜钱。旧米已混进米袋，不能拿一捧新米假称原物，他按那户本人同意的价另付两钱，收件人在旁看着，不用红票冲销明日工食。三户将退回的钱分装，各自拿走，没人被要求签“其余一概无欠”。

其余票在顾沉舟手里仍是一件没有结清的事。周敬把工约递来，试图买下明春南渠的泊船先用权，愿先给五十斤麦。

“五十斤确实能让今晚多一锅。”顾沉舟看着约上的排他一栏，“但我只办三日转存，卖不了一季水口。”

他让周敬带盐铺、脚行和船户另议公开租用；谁有粮就称粮，谁有船就看船，不用饥民今日的饥饿替未来所有人押印。周敬没有再抬价，折好工约，带着未售盐篓回铺。这个人还会回来，他手里有商路、有货，顾沉舟也没有把他当成打倒一次便消失的敌人。

午前七人回到秤房，干饼耗一斤四两、余六两，温水余三成，护兵全回，无新伤。桥头十人半日实领工粮十斤八两，九十斤新拨余七十九斤二两，仍归驿厨；昨日起试工预留十八斤八两另结，未加进这笔新额。周四仍留驿治疗，不补今日工数。

下午，一辆只装盐篓的商车沿新租空场顺利掉头，两名车夫约次日再来。南驿也准备把原留四百斤军粮再转四袋二百斤，等桥路复查后才发。

顾沉舟以为今天至少让一条小商路活了过来，崔岳却从西缺口带回一张告示。县里要按旧征发令，将所有过宁川的货车收进城外货棚，并调二十名役夫先修棚墙。纸上的印是真的，日期也对。

孟槐看见落款，慢慢把手从地租板上收回来。

新空场刚卸过第一篓盐，第二道令便到了。
