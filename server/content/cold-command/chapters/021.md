# 第二十一章 第一支民团

清晨的牛棚前，多站了七个人。

不是顾沉舟征来的。魏三带陈九和四个领过勘渠脚钱的民夫来，马老汉站在最前，把花额牛的缰绳重新编成双股。昨夜借牛条还在军法匣里，牛已经吃上草，棚外的空车却没人愿意再单独押。

“你说编起来。”魏三道，“怎么编？”

顾沉舟没有先给他们发刀。他让陈二取六只空训练袋，鲁安坐在旁边报木签。药布缠住鲁安的手背，苏晚棠说他今日不能抬袋，他便只穿绳，不从队里消失，也不装作没有受伤。

第一轮只推空车。六个民夫分左右，马老汉控牛，陈二报停。走到柴门转角，一辆柴车横在路中，前面的人看不见后面，魏三便下意识去拉车辕。

“停。”顾沉舟说。

魏三松手：“昨天就这么挡住的。”

“昨日挡的是空车后轮，今日你站在牛前。牛受惊，先撞你。”

老汉牵牛退半步，陈九将后车轮楔住，前面两人空出通道，其余站到高处。动作笨，足足花了半刻，顾沉舟没催。他右手虎口尚未全合，只用左手指位置，不靠自己冲进去替他们完成。

第二轮过转角时，谁也没站在牛角前。

许校尉来取复称结果，看见这一幕，问：“你练的是搬粮，还是私养兵？”

顾沉舟把空袋抖开，雪沙落在地上：“今日只是退车。若要出营护粮，须营官另批，陆承领兵。民夫不因此改军籍，也不能被我带出去追人。”

许校尉看向魏三：“不改军籍，你们图什么？”

“图脚钱不被写成吃过粥。”魏三答，“图走出去能带回来。昨天那牛若没回来，马老汉要先赔，车上谁受伤也没有名字。”

话说得直，许校尉却没有恼。他把新队的西墙交接副本放在车上，交给顾沉舟看。昨夜封存的三只结霜袋，外层霜已化，仓吏、老邵和门哨逐层检查后，内袋干燥，没有结团、霉色或腐味，现可与其他袋分批交灶；原袋号仍在，留样未动。

顾沉舟将这批粮从待验移到可发，不挪动那十斤缺额。旧渠空车追回的十斤仍封着，今日也不能先下锅。

“能动的粮够两日。”许校尉说，“但转运棚还有下一车。北坡不稳，他们要改走沙沟。”

“谁先看路？”

“边骑的人。贺兰朔正在北坡巡哨，今日不能回来。”

许校尉抬头看向六个民夫：“你真想把他们带上路，先算少一个人会怎样。”

顾沉舟当天便算出了代价。六人离开雪场，原定修墙的石料少搬六车；马老汉若随车，牛棚要补人喂草；陈二出营报数，伙房须另找识字人看交料；鲁安伤手不能代替任何一个空位。一支护粮队不是在纸上多添七个名字便能生出来。

周校尉在午前开议，只准试编十二名民夫，六人搬运、三人管车绳、两人看前后、一人记人头。魏三与陈九各领一组，陈二借调教报数；配四名营兵，由陆承领队，不归顾沉舟私调。先练营内，再做一次有限短运，未经复核，不准称作战兵。

“外头有人已叫你们民团。”周校尉道，“叫可以，牌先不发。谁入谁退写清，原役期照算，粮按工食，脚钱每日结。遇敌先回，不许把民夫放前头顶刀。”

魏三把手缩进袖口：“若退了，算逃役么？”

站在后排的一个民夫先退了半步。他家在黑河滩，昨日托人送来的口信说母亲病重，只想把这几日脚钱拿回去。魏三回头，差点骂他临阵缩头，顾沉舟却让陈二划掉护运试编那一格，留下原役籍和归村请条。

“这里不缺一个怕死的，也不能靠扣人凑十二。”顾沉舟说，“你怕，我们先把路查过；你得回家，照原册请假，别让试编成了第二张征役牌。”

空位由营中原已在役、愿意随车的民夫补上，不招新口。那个请假的人离开前把一根好绳递给陈九，说自己没用过，能省一根旧绳。顾沉舟当面记下借入和归还期限，不把那点迟疑讥成胆小。

“回营撤编，不算逃役。出营当值时私走，另问。”

顾沉舟又问抚恤。周校尉让军需书记把受伤停工、亡失核验、家属通知各留一栏，不准预先按成自愿殉役。许校尉在旁认了新队借出的四名营兵，也认下替补岗，不让原门哨因为护粮少四个人。

十二名民夫到校场时，四个新来的先问今日是否有饭。顾沉舟指向老邵送来的食筐：“按今日名册给，没来的不替他领。你们没改军籍，今日的粮仍从原份额拨，不是添十二张嘴。”

食筐里有干饼和热汤。魏三把自己的那份吃完，才去摸第一根练绳。顾沉舟让两组轮换，一组推车，一组做阻路者，只放雪沙，不装净粮；兵卒教短棍护头与退步，民夫不学冲阵，也不拿真刀互砍。

午后的第三轮，许校尉忽然叫一名兵卒从车后抽走一只训练袋。

前组没发现，后组的陈九却喊停，指向绳结：“乙签还在，袋没了。”

兵卒把袋子往披风里一掖，问他敢不敢搜。

陈九没有扑过去，先让马老汉退牛、魏三守住五袋，自己转向陆承：“袋在他身后，只看见拿走，没看见打开。请领队验。”

陆承取回袋子，木签核上，雪沙没少。许校尉点头，终于不再问顾沉舟是不是私养兵。

“你把人教会了停。”他说，“还得教会他们什么时候不停。”

这句话很快有了用处。

军需房催伙房去北门接两包药，县库的止血布与退热草提前到了，车却停在营门外坡，积雪堵住轮子。若等清路，入夜药箱再冻一遍；若十二个人全去，训练袋、牛棚和灶口同时空掉。

顾沉舟让陈二去请苏晚棠验药，向周校尉申了一趟短运：四名营兵、六名民夫、马老汉、一头役牛和空车；陆承领队，顾沉舟只核物项。北门外半里，日落前回；十一人携当日口粮中干饼共五斤半、水两囊，牛草六斤。冰裂、路口持械阻拦或伤者不能自行走，立即收队，留两名兵卒护伤者，药箱可弃，人不可弃。

韩魁想跟去认路，苏晚棠直接拦下。短运走的是门外熟路，不需要拿他的腕伤去换一点熟练。

雪坡上，车夫已把两包药卸在旧毡上。苏晚棠当场核县库封记、实物尺数与包数，再看回执；止血布三十尺、退热草二十包，清疮粉仍缺，不因为另外两样到了便销掉整张催药条。

民夫一左一右抬箱，上车后用两道绳分系，不让药箱挤在牛辕上。回程坡陡，轮子向后滑了一下，陈九及时垫住冻木，魏三没有抢拉牛角，而是从侧面扶车。四名营兵守前后，谁也没有为抢一份搬药的功劳冲散队形。

两包药在日落前入医棚，十一人全数回到营门，没有新增伤员。苏晚棠另骑医棚驮马随行验货，马在坡内等候，回营后由药童点回，不混入十一名护运人的口粮。老邵把剩下的干饼与牛草收回，各按实耗记，不从“训练物耗”里凭空消掉。

花额牛卸轭后，马老汉没有立刻走。他把牛肩的旧擦痕指给顾沉舟看，昨日另两人套的绳偏高，回棚还好，长路再磨便会破皮。护运队若只会点袋，不会看役畜，十个人搬不动的一车，仍得靠一头牛熬过去。

顾沉舟让他明晨先教十二人如何放轭、如何让牛停。校场会叫口令的人不少，认得这道旧痕的人却只有他。老汉应了一声，把上路前检查牛肩写进木板，字不会写，便画牛角，陈二在旁替他注了姓名。

苏晚棠拉开药柜，将新布放进最空的那格。赵七坐在棚门看了许久，低声问魏三：“你们真能出去？”

“能回来才算。”魏三把绳放到门外，没带进伤员铺位。

当晚，十二份当日脚钱按名单发出。顾沉舟的分项表与陆承点名簿互相核过，工食不抵钱，试编不抵旧欠，五名伤民仍在军法待核，不被拉进新队顶数。

周校尉在粮什牌旁另加一块小牌，写“护运筹办”。顾沉舟可安排营内车序、报数、绳具与民夫轮换，出营兵额仍归陆承，仓钥仍归秦百户。牌下面挂着一张新的责任单：役牛每日查体、绳具逐次验、退队役期复核、伤亡先报家属。

顾沉舟接牌时，指节酸得几乎伸不直。权限多了，雪场欠的六车石料也在等他还，他不能只把今日顺利的半里写成自己的功。

魏三在灶门下等他，递来一截细木。木上刻了两条岔路，是沙沟的入口。

“盐车以前走过。”他说，“上坡能看清下面，下面看不见上坡。押粮要走那里，不能光看车轮。”

顾沉舟把木片放在短运令旁。今天这支队伍带回两包药，没有少一个人；下一车要走三十里，他们没有能随叫随到的边骑，也不可能靠这次空车练习，就把沟上的人全变成看得见的敌人。

他先去找陆承。

民团的第一件事，不是等粮车来了再出发，是先让那条路不再只剩魏三一个人的记忆。
