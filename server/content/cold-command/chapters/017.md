# 第十七章 屯田旧渠

旧渠在黑河营西南两里，原本是给屯田地引水的。

渠口被一块塌下的石闸堵住，闸旁立着景和十二年的屯田碑，碑文列着三十六亩官田、二十户佃户和每季应缴的粟额。三年前黑河改道，水渠断了，田地改成荒草坡，碑却没有倒。

顾沉舟拿着准条到渠边，身后是六名民夫与陆承带的两名门哨。周校尉只批半日勘渠，营西南两里，午后回营；三十斤净粟预留六人今日工食，陆承等三人携门哨当日干饼一斤半，两囊温水、两把铁镐、一辆空车。伤员不入队，渠壁塌落、冰裂或有人受伤即撤，由一名门哨护伤者回营，其余收工具同行，不留人守土样。

六名民夫中有魏三。他没有再站在队尾，而是主动指向一处结霜的浅沟。

六个人的役期并不相同。魏三和陈九是半日勘渠，另四人原本登记在雪场搬石，调来之前没有人改役册。顾沉舟先让周校尉的书吏在差条背面写明“今日借调半日，脚钱按半日结，回营后不得以修渠名义追加夜工”，再让六人逐一按指印。这样一来，他们搬的是营里的渠，不是把自己的役期凭空延长；若有人在冰下受伤，责任也能追到下令的人。

昨日七十八斤净粟仍在伙房。三十斤虽挂在勘渠名下，却只带三斤干粟饼与九人同用，余二十七斤留灶分早晚，不让六个人半日吞掉三十斤。其余四十八斤属于全营补量，不跟车出去。顾沉舟将三斤饼写成当日工食的一部分，不能在回营之后再给六人重复领一份。

“水不从闸走了，往那边渗。”

“你以前看过？”顾沉舟问。

“我替屯田户运过盐。那里有一口废井，井水比南沟咸。”

魏三的话只能引路。顾沉舟让陈九带一名门哨从上游找渠痕，自己与陆承留在闸边，两边始终看得见。两条路线若汇合，才值得开挖；若只凭魏三说，修错半里便白费六人半日，还要拿稀缺的粮去赔力气。

陈九在荒坡东侧找到一截埋在土里的石槽，槽宽与碑上旧图相符。两处渠痕相距二十余步，中间却被后来的雪土填平。顾沉舟让两名民夫各量一段，记深宽，不许把“看见石头”写成水能通。

午前，周校尉派来的书吏送到一份旧屯田册。三十六亩官田，景和十四年仍收粟一百二十石；景和十五年收成栏空着；景和十六年却写“水毁免征”，盖的是秦百户仓曹私印，不是屯田司印。

顾沉舟把册子递给陆承：“水毁需要水灾现场、田户名册和上级批文。只有仓曹私印，不足以证明免征有效。”

书吏压低声音：“旧册一直由仓曹代管，屯田司在关城，来一趟要三日。”

“那三十六亩现在谁种？”

“没人种。”

荒地不等于无粮。顾沉舟让六名民夫先把渠口淤泥清到一尺，再看水势，不许先承诺今年能收多少。铁镐落下，冰壳一片片裂开，下面露出黑色盐碱硬皮，与南沟样本相似，却没有直接相触。苏晚棠不在场，顾沉舟不把颜色相近写成同源。

他让陆承在渠口立一根临时木桩，刻下开始时刻、雪线高度和水位。若下午水线退回原处，便能知道是渗水还是渠底真正通了；若有人后来把土坎挖开，再把今天的水痕说成旧渠常年有水，木桩上的刻痕就是另一类独立证据。陆承问他是不是把一条荒渠当成案发现场，顾沉舟说：“只要它可能影响粮，就不能只靠记性。”

石闸后的水终于渗出一线。水不多，带着白色沉积，沿断渠向东流了不到三丈便停住。魏三立刻说废井方向更低，顾沉舟让陈九重新测坡。陈九用木尺和水碗比高，发现魏三判断方向没错，但渠底被一道后修的土坎截断，土坎上有车轮压痕。

“有人把渠改成车道。”陈九道。

土坎两道车辙的间距比西墙霉粮车的拓样略窄，边缘挂着一缕蓝线纤维。顾沉舟没有让人追车，只量轮距、画土坎，另取线头，再让民夫挖开一掌。下面不是渠底，是一层被压实的麦壳土；土坎与车辙留在原地，不能装进证物包冒充一辆车。

六名民夫的反应不一。魏三先看车辙，再看石槽，陈九则蹲下捻了一点麦壳土，指出其中有一截被碾扁的芦苇。另四人只说自己在这里见过车，却说不清车上装什么。顾沉舟把四人的话记作“见车不见货”，没有为了凑齐六个人的口供，硬把他们写成押运见证。

六名民夫都停下了。

麦壳土不是普通车道会有的东西。若有人把粮袋在这里倒过，麦壳会混进泥；若只是旧屯田户晒粮，也可能留下同样的壳。顾沉舟问魏三哪一种更常见，魏三说不敢认，只能认出压实方向与车辙不合。

两类口供互相限制，反而比一个肯定答案更可靠。

顾沉舟让人收好土样，不再深挖。六名民夫干了半日，两囊水只剩一囊，空车还要拉工具回营。再干下去便超过准条，伤员处置、工食与夜粮都要另算。

“收工。”他说。

民夫们愣住。眼看水线已经出来，没人甘心只挖三丈。

“再挖半日，渠可能通。”魏三道。

“今日只准半日。再干得先有热食、有脚钱，不能让你们吃一句可能。”

魏三没有再劝。他把铁镐靠在石闸旁，先帮陈九把土样封好。

回营后，秦百户果然来要屯田册。

“旧渠属于仓曹代管。你拿一页旧册就去挖渠，谁准的？”

“军议准条。”顾沉舟把副本递给他，“只准勘查和半日清淤，不准改变田籍。旧册原件仍在您处，我只拿抄本。”

秦百户翻到景和十六“水毁免征”那一页，手指停住。

“今年雪大，渠通不了，免征也合理。”

“合理不等于谁都能写。若要沿用免征，请屯田司补批；若要复耕，请先核田户、种子和水权。仓曹不能用一枚私印把三十六亩田的收成抹掉。”

秦百户没有发怒，反而把册子合上：“你现在管粮，又想管田？”

“我管三日口粮，田是三日之后的事。”

这句话传到周校尉耳里，营官让书记把旧渠列入次日军议。三十斤工食仍从昨日七十八斤里扣，脚钱另报，不许把吃过粥写成领过钱，也不许用今日勘渠让六人的役期凭空再长一天。

六名民夫回营时，每人领到半份温粥。魏三看着碗底，问：“渠要不要再挖？”

“要。但先问谁有田契，谁有水权，谁拿种子。”

“没人愿意把水让给荒田。”

“那就不是一把铁镐能解决的。”

陈九拿来一张收条，写着“六人半日，领粟三十斤，已结”。顾沉舟让陈二指向最后两个字：“结的是工食，还是脚钱？”陈九顿时缩回手。书记重开条，写三斤路食、二十七斤早晚灶粮，脚钱待付。仓丁来取原条，陆承按住纸角：“未付的钱不能带一个已结走。”

仓丁退开后，魏三在实际领饭处按下手印。他不肯为麦壳土指认车，却愿意证明三斤路食确实分过，早晚灶粮也没有少发。顾沉舟望着那双冻裂的手，才觉得今日六个人挖过的三丈，不全是白挖。

苏晚棠从医棚送来新消息：周文能认人，却仍不能连续说话；韩魁可以活动手指，不能拉弓；赵七的膝肿退了一点，若三日内不搬重物，有望不跛。五名获救民夫中，陈六坚持要看事故簿，石顺则问脚钱何时发。

顾沉舟把这些都写进什长日报。升任后，他不能只报粮的去向，还要报伤员能否回队、民夫是否愿意留下、旧渠能否提供下一季的粮。

夜里，谢无咎的回信终于送到。

转运使没有承认信角盐碱硬皮来自南沟，只写：“粮有三种：仓中之粮、路上之粮、账上之粮。你若只守锅，不必过问转运；你若要问转运，先拿出黑河营三日真实耗用。”

周校尉看完，把信递给顾沉舟。

信末附昨日调拨表的确认副页：按原定日，尚余两日，黑河营应接净麦八百斤，交接仍在西墙；领受人秦百户，复核人还是空的。

顾沉舟读完，把“复核人留空”圈出。

谢无咎应了营里的粮，也给了秦百户一条更硬的路。两日后若复核栏仍空，顾沉舟即使找出少袋，也只是在别人完成交割之后补一句异议。

他把屯田旧渠的土样、转运调拨表、三日口粮表放在同一张案上。

第二卷第一道真正的难题不是有没有粮。

是粮来了以后，谁有资格说它真的到过。
