# 第十九章 伤兵名单

清点后的第三日，西墙的车轮声最终没有进营。

来报的是一名冻得嘴唇发紫的驿卒。他说转运棚的车队在北坡停了一刻，车上有一袋封泥松动，领车人要等仓曹验过才敢继续。八百斤净麦没有少报，也没有实到；在车进营门之前，它只能算调拨表上的应到数。

周校尉把报信人安置在火棚，老邵先递温水，苏晚棠查看冻伤。驿卒右脚趾已失去知觉，不能再站在雪里。他是转运来客，不并入原有十名伤员；顾沉舟从访客储粮拨一份软粥，陆承记到营时刻与空袋来处，袋上官印不能替粮车认重量。

“粮没到，伤兵名单先定。”苏晚棠说。

她把医棚十人的伤情牌铺在长桌上，又取出旧队、新队、获救民夫和押运队四份名册。名单不是把名字抄一遍，而是要回答三件事：谁能回到原岗位，谁需要停工，谁的死亡或失踪尚未被证实。

顾沉舟让陈二按姓名描红，不按队伍颜色。赵七在旧队名册中，韩魁在门哨簿中，周文在账房值守簿中，五名民夫在征夫棚原册中；若只看军籍，五名民夫会被当作“已离营”，若只看事故簿，陈六会被写成死人。

第一项是赵七。

苏晚棠按膝盖肿胀、行走距离和复查结果给出停工两日，第三日复查，不能搬粮、不能上雪场。赵七听见“不能搬粮”时脸色发白：“我不搬，脚钱谁补？”

顾沉舟从伙房责任簿里取出一张空白抚恤待核条。“停工不是自愿退役。你的军籍粮照发，脚钱按伤情和经手任务另报。若有人把你写成偷懒，我拿这张条去找营官。”

赵七没有立刻按印。他问：“若三日后还缺粮呢？”

“先从普通锅的临时加餐和未核预留里找，不能从你的最低份额里找。”

苏晚棠看向顾沉舟：“你替营官承诺？”

“我承诺把分项写出，营官承诺由他签。”

周校尉正好走进来，接过话：“我签。”

赵七这才按下指印。名字旁边多了三行：伤情依据、停工期限、复查人。它比一句“照顾伤兵”重，因为三日后有人必须面对这张纸。

韩魁的左腕已经能转动，但握弓会疼。边骑校尉贺兰朔派人来问，北坡换哨缺一骑手，能否让韩魁只看路不拉弓。

苏晚棠答：“看路可以，骑马要看缰绳受力。先做空手握缰试验，疼痛超过旧线立即停。”

顾沉舟将这项试验写入名单的“可执行任务”栏，不写成“已复工”。韩魁在空地握了一刻钟缰绳，手腕没有立刻肿，却在松手后发抖。贺兰朔的传令兵想说这不算伤，苏晚棠把他的手按回药包上：“不算伤，为什么要抖？”

韩魁自己把“暂不骑射、可做短时观察”写进栏里。顾沉舟让陆承在门哨簿上补同一句，避免医棚一份、骑哨一份，各自把他写成不同的人。

第三项是周文。

他醒着，能辨认苏晚棠和顾沉舟，却无法连续回答三个问题。顾沉舟没有问火起时谁在门外，只让他看三张不相关的木牌：东仓、营门、医棚。周文认出了两张，第三张看了很久才摇头。苏晚棠立即停止测试，把结果写为“可辨物，不可供述”。

账房失火案因此没有得到新的口供，伤兵名单却多了一项责任：周文每日需要两次复查，若营官要把他调离医棚，必须先有医官签字。顾沉舟把这一项抄进粮册附页，防止有人以“账房已经重建”为由提前收回他的口粮。

第四项是五名获救民夫。

魏大山退热，但脚力不足；石顺脚伤换布，不能搬重；鲁五和许二能走，可役期未结；陈六坐在棚角，手里攥着事故簿抄页。

“这里写我坠冰死了。”陈六说。

苏晚棠没有夺走那张纸。她让顾沉舟把事故簿、征夫棚原册、押车单和陈六本人分别列为四栏。陈六能证明自己活着，却不能证明谁把他写死；押车单能证明有人这样填过，却不能证明实际收尸；民册能证明役期未结，却不能替事故地点作证。

陈六问：“那我到底算什么？”

“算活人，算临时留置，算一笔待核的役期。”顾沉舟说，“在军法结项前，口粮照发，脚钱不能销，家属抚恤不能写成已结。”

陈六盯着他：“若你们最后说我只是名字错了呢？”

“那就要有人解释为什么事故簿没有收尸单、为什么押车单写工钱已结、为什么你现在还在这里。”

这句话没有给他洗清冤屈，却让他第一次愿意在名单旁按印。魏三站在后面提醒：“按的是活着，不是认那张死录。”

“分栏按。”顾沉舟说，“每个人只证明自己看见的事。”

五名民夫此日仍从医棚领料，不另领普通锅补量。脚钱与抚恤写在旁册，均是待核未付，不能冒充口粮已经结清。三种东西若写在一行，最后一定会有人说已经付过。

午后，周校尉让顾沉舟把新名单带到营门。陆承拿出换防簿，指出一个名字：许三，昨夜从南坡回来，今日却被新队书记写进“可调车辆”栏。

许三昨日在雪场扭了脚，伤情尚未复查，不能押车。顾沉舟先把他划到“待医复查”，不因他前些日能押空车就认今日也能走。许三脸色难看：“只是扭了一下，歇一夜就好。”

苏晚棠让他走十步。第七步时，他的脚踝明显向外偏。她没有争辩，只在名单上写“步态异常，停工一日，明日复查”。

名单越写越长，能干活的人越少。秦百户在营门外看着，讥讽道：“按你们这么列，营里只剩纸能走。”

顾沉舟没有抬头：“纸至少不会把活人写成死人，也不会让伤兵为了半份脚钱去搬一袋粮。”

秦百户走近一步：“那八百斤到了，谁搬？”

“名单上可走的人搬，伤员旁观，门哨见证。若人数不足，先改军令，写明兵额、粮额、行程、伤员处置和撤退条件。”

“搬一车粮也要军令？”

“西墙不是伙房门。车要过营门，便有路、有哨、有伤员，也有撤退条件。”

秦百户不再说话。

傍晚，北坡终于传来第二次车铃。陆承派两名门哨去接，却发现来车只有七百九十斤净麦，另有一袋封泥松动、三袋表面结霜。转运棚复核人是一名新队书记，领受人秦百户，营门尚未落印。

周校尉没有让车进仓。顾沉舟将伤兵名单放在秤旁，先让苏晚棠确认医棚留量，再由新队书记、陆承和秦百户三方看袋。七百九十斤不是八百斤，少的十斤不能先归霜损；结霜袋要另取样、另封存，不能靠拍袋子判断能否入锅。

秦百户说：“十斤算转运路耗。”

顾沉舟把调拨表翻到末页：“表上没有路耗栏，只有净麦八百斤。请转运棚补说明，或按实到七百九十斤接收，十斤另案。”

新队书记看了看秦百户，最终在“实到七百九十斤、缺十斤待核”处签名。陆承在营门簿留一份，顾沉舟在伙房留一份，周校尉封原表。

当夜，三袋结霜粮暂不入锅，未见受潮霉变的袋子先验先发。普通锅仍按减额，医棚没有少一口；三只封袋算已到营，不算已可食，七百九十斤便不能整笔写进灶耗。

伤兵名单挂在伙房门内，最下方新增一行：西墙净麦应到八百，实到七百九十，缺十斤待核；结霜袋三只，待取样；复核人已补，秦百户仅领受。

顾沉舟收起笔，听见营内有人急喊：“牛棚少了一头！”

名单上的许三刚被划出搬运栏，营中却又少了一项能换粮的东西。逃牛案的第一道追查，必须在天黑前决定追哪条路、带多少人、给谁留粮。
