# 第五十五章 以工代饷

正月二十四晨，丁六堵在屯田局门前，掌心的红角纸被汗浸软了。

“钱也交了，还不能排在前头？”他向梁文伸手，“伙计说，买了票就有粮有工。”

旁边的赵麻子攥着另一张半票，想替他说话，被孟槐带到墙另一头。两个拿票的人不必站在一处把话越说越齐。丁六说卖票人穿西口短褂，袖口补了灰布，自称粮行伙计，他付了三钱，却没问姓名；赵麻子说他替邻户取票，只收一钱跑腿费，买票钱没有交到他手上。邻户还未到，两说各留，不能替他们补一个共同卖主。

票上写着南渠第二段，偏偏那段尚未开放。纸上没有仓号，丁六交过的三钱也没有退回来。他望着门边的工日牌，眼神渐渐变凶：“若是不能用，你们拿票做什么？”

“留它追收钱的人，不是凭它开锅。”顾沉舟指向候工册，“你报过清淤，今日身体也能做。按活排你，不因票多给，也不因买了票把你赶走。”

梁文将丁六名字填入八名浅渠工，又核了赵麻子。另两人只在岸上挑泥，共十人。梁铁右膝仍停重，周四掌伤未获复工条，马六只可看轮，陈二左臂做轻活；这些人没有被挪来填十人名额。许木匠手背伤只能指料，渠里的锹不交他。

有人嫌半日钱少，说宁可替盐车跑一趟。梁文没劝，问清谁愿做今日半日。顾沉舟让退出的人在岸边等下一次报工，不把自愿候工册改成必须到场的役籍。最后十人点齐，八人下浅槽，两人往岸上接泥。

崔岳连三名护兵分守桥头和退路，两名院兵仍留宁川门，仓兵独立守三百斤。晨令只准原浅段，水过试板、岸土裂开或有人受伤就停，医佐在驿口接转。护兵另带饼四斤、水两囊，渠工从五十八斤工粮支用；旧预留十八斤八两与今日二十斤日赈都不在这口锅里。

两根闸木已装在槽上，一根主挡，一根旁挡，三副余铁箍收在料棚。顾沉舟看见木上昨日水痕没有涨，才让梁文开工。八把锹从已清过的地方往前移，不为了赶出漂亮的长度跨进深淤。

丁六刚下去便被淤泥吸住靴底。他先想用力拔，旁边老工教他扶住杆，转半圈再抬脚。第一筐泥送上来，里面除了烂草，还有一块压在旧木边的铁片，锈边下缠着青线。

许木匠用钳子挑开旁边浮泥，没扯线。他说铁片能卡住小轮，也可能只是旧修料，不能从颜色认出南驿断旗。县役记下所在石缝，铁片、线、附近泥分留；旧木位置保住，等查用途，不拿回局里与其他证物摆在一起比。

西口这时来了一辆盐车。车夫看见桥旁空地，以为能从清淤人背后挤过，牛鼻几乎碰到退路索。崔岳横杆拦住车头，没有拔刀。盐车夹在路中，后面的空车夫也大声催促，泥筐停在工人肩上，八个人要退，却发现岸口被牛占住。

顾沉舟让工人先把筐放稳，两名护兵引牛到空场，留出短板与索端。盐车的货不扣，车夫须到划好的候车处等；县役和车夫各自记开始等候的时刻，梁文报料车还有多久，别把延误全算到清淤人的头上。

“我这盐再等就潮了。”车夫说。

“潮货报损，退路不能拿来抵。”顾沉舟让他看岸下那八双鞋，“人上来，你的车才过。两边都别添一笔假的。”

车夫不服，却见候车位有硬地、没有让他付新的过桥钱，终于牵牛过去。退路刚空出来，北侧浅岸落下一小块冻土。赵麻子本想接同伴的半筐泥，脚下一滑，右踝扭过去，整个人向沟壁倒。

他攥住退路索，却没有力气站起来。崔岳让桥头两兵固定索端，两名工人伏在短板上送去绳环，其余人往后撤。顾沉舟在岸上指明能撑板的石肩，不让人一拥而下。赵麻子抓住板边，右鞋被泥吸脱，泥水已经漫过他脚背。

“鞋不要了，先松膝！”

两人缓拉，赵麻子终于趴到板上，随着短板退上岸。崔岳逐人点了八个名字，丁六最后上来，额头一片冷汗。无人落水，少了一只鞋，一筐泥也没再算完成。

医佐从驿口赶来，查右踝后让赵麻子冷敷固定，停走、停重一日，次晨复查。他没用“歇一会还能干”搪塞。医布、诊车费另报南驿，赵麻子已做的实工照算，转医后的医食接过去，不在河滩再领一份赈粥。

赵麻子痛得咬牙，先问的却是脚钱。梁文将他上午做的筐数报给县工曹，并把停工原因写在另一页。今日八名浅渠工实领十一斤二两，两名岸工一斤八两，合十三斤；工粮从五十八斤减到四十五斤。丢鞋和板损另报，旧预留不拿来填材料。

下午不再下渠。两名健脚工愿意在岸上压板、搬干垫石，梁文另报时钱，未再发一次工粮。许木匠坐在干石上指榫口，别人锤钉，他用左手扶住自己的伤手，没靠一天熬过就把旧伤抹掉。

风从空渠口卷起，岸上几块垫石沾了泥，压下去便滑。一个工人把板往前推，想一气盖过软口，许木匠急忙用脚跟抵住板尾：“底下空着，盖住也是空。”

那人不肯收手：“多走一趟，钱又不会多。”

梁文摸出县工曹准的时钱页，今日只够两人在岸上做到申初，不能把整段铺成的价许出去。顾沉舟蹲在硬地，拿一根细杆伸进板下，杆头轻轻一压便没入泥里。他把板撤回半尺，让工人看见真正能承重的石沿。

“钱只够这一截，就保这一截。别用你们的脚把下一截赊出来。”

他让梁文把原本要运到前头的干石留在岸口，先护住上人的落脚处。两名工人一人翻板，一人从背水侧塞石，丁六在候工处看了一阵，自顾拿起泥筐。梁文拦住他，说他的半日已结，再做要另报钱，不能看别人忙就当他白帮。丁六把筐放下，改为指给县役看自己上午踩过的软缝，不再下岸。

板尾重新压实，盐车过时没有向渠里歪。先前嫌少做的工人用脚踩了两回，才肯把工具交回棚里。他向梁文问的仍是余下那段何时有钱，语气却不再像讨一笔永远追不到的旧欠。梁文只答明日未准，不拿今日这包现钱替县里许一个空数。

盐车在浅槽撤空后过桥，车夫取回自己的候车记。等候不是没发生，顾沉舟让驿方按原约核是否有等车钱；他既不免掉修渠人的工钱，也不把盐车延误算成车夫蓄意阻粮。

到了申时，梁文抱来一个小布包，里面是县工曹核付今日实工的钱。不是旧欠结清，也不够给所有候工者开工。丁六拿到自己的那份，先数了两遍，忽然把红角票拍在桌沿：“不用这纸，也真能领？”

梁文说他的名字、今日活和实付钱都对得上。丁六没笑，把钱放进腰袋，站到门外等县役。他原先以为丢了三钱，便只有再交一次押费才进得了这口锅；如今至少今天的活不受那张纸挟持。

赵麻子被扶到驿棚，县役问邻户住址，不逼他在痛时把所有事一次交代。追票费走县案，两张新半票分存，不凭纸折、麦壳、青线就认平安粮行或周敬。孟槐回河滩找那个邻户，若证言不同，明日再逐一核。

雁回回条在日落前到。铜牌号与旧领用册的一项相合，归还记录却还未找到；它的来路有一处可追，不代表周全有现行领粮权。转运司尚未回验急条印样，谢无咎是否说过北坡接粮，也还等正式复文。顾沉舟没有凭一个缺口把铜牌叫作伪牌，更没有编出一张备用官印解释急条。

两名愿意留驿的脚夫各看了自己的问询页，没有被迫挑一个地点改口。周全已带空车离去，县役只记去向和收物回条，不写成在押。南驿四袋事故粮仍分别验存，宁川三百斤封线未动，两条粮账没有因好车来过就合成一笔。

崔岳把今日护兵饼袋放到秤边，耗二斤六两，余一斤四两，水余半囊。顾沉舟才发觉自己从早上一直压着虎口，旧皮被绳子磨得发热。他松开手，没把疼当成可以再硬顶一趟的证明。

屯田局的凳子上摆着三件事：赵麻子的医转条、四十五斤工粮的余数、丁六待追回的三钱。今日十个人拿到了实工回报，明日能下去的人却少了一个，粮也又薄了一层。

孟槐归来时，河滩的人已不再围着卖票处排队，几个健脚工自己来问次晨先搬什么料。顾沉舟让他们先等水线，再核人手。他赢到的不是一句肯听他的口号，而是有人愿意把下一天的活交给能付钱、也肯停工的人。
