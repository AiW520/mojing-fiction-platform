# 第五十八章 谢无咎的条件

正月二十七，雨后的雁回关仍在滴水。

转运棚的檐角一夜没干，水珠落在三关分拨板上，把“雁回”“白石”“黑河”三个旧字洇出毛边。谢无咎的无印文书放在板下，三行条件旁没有经手名，也没有生效日期。

顾沉舟先问：“谁让你写的？”

谢无咎答：“我自己。印要等罗守将和县丞各认一栏，免得你拿一张纸去调一城的粮。”

罗定随后进棚，身后跟着雁回仓兵和昨夜轮值的门哨。谢无咎把文书推到三人之间，意思很明白：顾沉舟若接南线排程，就必须接受三日一报、旧欠不冲和出事先问三件事；若不接，宁川雨灾归县方，雁回只等正式粮车，不为一座废城拆兵。

顾沉舟没有先说愿不愿。他让仓兵报昨日余粮：雁回现有可用粮扣除日耗后，仍需等下一批首拨；宁川三百斤封粮六袋未开，南驿事故粮甲九重四十九斤八两、甲十重四十九斤六两，合九十九斤四两；甲七、甲八隔离待检，不能把四袋恢复为二百斤净粮。仓兵和医佐的两份页没有互相替代。

“三日一报可以。”顾沉舟说，“但报什么，要先写清。”

他拿出雨中记录，逐项列出水位、袋号、伤情、役时、实耗和未结欠。雨灾不只是一张损失单，县方修沟、脚钱、住户泥墙、伤工医费和军粮封存都在不同栏里。谢无咎若只要一句‘南线平安’，那便不是排程，是让人替他遮住缺口。

谢无咎看了半晌：“可以添一栏证物。”

“还要添经手人。谁量水，谁开袋，谁付工钱，不能只留我的名字。”

罗定抬手让仓兵取来空白交接页。谢无咎没有阻止，反而指向第三行：“出了人命、塌桥或失粮，先问你。这一条不改。”

“责任可以先到我这里，权限和物资也要先到。”顾沉舟把笔搁在文书边，“我不拿仓钥，不替县方收税，也不替你改三关额。但我要两名独立仓兵、四名可轮换护运兵、南驿医佐的伤情副页和一笔已经核准的修路钱。没有这四样，出了事问我，只能问出一张空纸。”

谢无咎没有恼。他从木匣里取出一张旧拨款页：“修路钱只有三十两，来源是雁回关内杂役余项，不是新税。四名护运兵可由罗定调，不能从南墙第二班抽。独立仓兵由仓曹点名，不归你私用。”

罗定点头：“兵我能给，军令仍由我签。顾沉舟只排车和交接，遇持械人先退，不许拿排程牌出城追。”

顾沉舟又问：“旧欠呢？”

“南驿四袋事故粮、宁川工钱、伤工和借屋修料，分别列清。”谢无咎说，“三日内先付已核实的实工与医费，争议部分留案；没有凭据的旧米折，不得从军粮里折。”

“那第二行该改成‘旧欠分栏核付，不得冲抵军粮’，不能拿待核的欠压住该付的钱。”

谢无咎看向他：“你要给拖欠留下口子？”

“证据未到的欠，不该先结；证据已到的欠，也不能拿未核的一栏拖住。你把两种都写成未清，最后会是谁都拿不到钱。”

梁文正好带着雨灾后的县工曹清单赶来。昨日补泥、清障、井路补石与新伤医布分别有金额和经手人，赵麻子、董成旧医欠留在另页。盐铺请求水损赔付，没有货号和复称，暂不列应付。

顾沉舟把清单按已核、待核、拒收排开。昨日实工和修料一两六钱、新伤诊费医布八钱，六工逐人核役时、料商核县料出入，医佐另证实用，实付二两四钱，三十两余二十七两六钱。此前已结工钱不再支付，旧征木、票押和旧医欠仍待各自凭据，红角票不兑军粮。

钱不是倒进一个袋里便算结了。陷腿工的弟弟来领钱，梁文只让他接获准代领的那一份，另五人仍按各自实工领。那名划伤脚底的县役扶着门框，拿到医费回条时先看医佐的字，才将县差催他下水的口信退回去。他今夜不必再涉沟，这比多领两枚钱更有用。

顾沉舟随梁文走到修料棚。车上借去救人的挡板横放在地，裂缝从板边伸进一掌。车夫要求照整块新板赔，料匠却指出旧钉孔两侧早有毛裂。两人争到准备把车推走，顾沉舟叫停明日挂粮，让他们各看昨晨出车时留下的板背画样。画样上的旧裂只有两寸，救援后的新裂另量，换板与旧损各算，不把整车翻新塞进雨灾费。钱付出去，车便必须交回来复检，不能既收换板钱，又让粮车用裂板赶路。

谢无咎忽然问：“你昨夜为何不把三百斤粮搬到高处？若雨再下半个时辰，封线一样会湿。”

“院外没有干台，路也没查。仓兵盯水尺，水逼近台面便转移；当时台下还有余地，先疏泄口，比搬六袋更快。人守封粮，工队护井路，两处没有互相等。”

“你宁愿看粮受潮？”

“我不赌粮受潮。旁挡若压不住，疏水那组就撤，车夫接应转粮。”顾沉舟指向门槛泥印，“这次水在台下退了，袋底另由仓兵验。险情和实损都要报，不能少一栏，也不能捏一栏。”

谢无咎没有接这句话。他让仓兵开出一只备用空袋，现场称皮重，再把昨日三百斤封粮的六个袋号抄在两张不同的页上。第一张由仓兵留，第二张由罗定押存，顾沉舟只拿副本。新条件里加了“同日双页，次日互校”，却仍没有把仓钥交给他。

午后，雨水再次沿北坡下冲。南墙外的商车想趁泥路未干进关，押车人说自己带的是盐铺托售货，愿以一篓盐换四名护运兵开路。罗定让门哨先收旧商税，顾沉舟则查看车轮。车上八篓盐，货号、篓皮和实重尚未复称，不能用一篓交换军务。

“开路不是卖兵。”顾沉舟对押车人说，“你可以等，或者把货号和损耗页留下。护运兵只护军粮与伤员，不替商货穿过未验的泥沟。”

押车人骂他不通情理，牵牛硬往坡上走。右轮刚过横木，泥槽便塌半掌。门哨没有去拽牛，先让后车停住；四名护运兵按罗定军令把商车退回硬地，老周从侧面量槽，不把盐篓摔下去。

商车后头还跟着两辆空车。盐车若倒在坡上，回关的医车也得被堵在雨里。顾沉舟让门哨先退空车，护兵只守通道，不给盐铺推轮。押车人仍要硬赶，牛蹄一滑，车辕顶住横木，他自己也被绳勒得踉跄。车夫终于松缰，借坡下料商的两根垫木，另雇两名健脚工，从侧面一寸寸退出泥槽。

垫木租钱与推车脚钱由盐铺当场付，料商不把这笔再报关内修路。车退回硬地，医转车才沿另一道上坡；押车人看着让出的车道，没再说用盐换兵，只求排在复检之后。

他最后交出货号和待复秤条。八篓盐内重未核，不能先报全损；四名护兵警戒一刻钟，从今日已领路食耗饼半斤、水半囊，不扣修路钱。外来八篓与周敬旧托售六十斤也分开，不凭一个盐铺名字就并货。

谢无咎在一旁看完，低声道：“你把每个人都逼到要留下名字。”

“不留名字，雨一停，欠账就会换一张脸。”

傍晚，邢远到转运棚核县方用工与借屋复文，罗定才在第一行下落印：顾沉舟获正月二十七至二十九日落的南线临时排程权，可排已批车序、修料和役工，要求仓兵、医佐副页；不可开仓、改粮额、征兵、收税或越界追击，护兵每趟另领罗定军令。邢远当面落县印，注明已核欠先付、争议待证，不折军粮。谢无咎签第三行，责任加上车桥与雨灾伤工，不含未经核的盐损。

这不是升官的热闹场面。顾沉舟得到的是四名可轮换护兵、两名独立仓兵的复核协作、三十两有出处的修路钱和三日排程权；同时，他要每天交水位、袋号、车序、伤情、实耗和未结欠，出了塌桥或失粮，第一个被叫到案前。

孟槐的回报在入夜前到达。屋主昨日日落已另续空屋、秤房至二十九日落，六户井路仍通，三百斤封粮袋底干燥；闸木需补箍，余两副尚未领用。赵麻子今晨复查仍停走一日，董成次晨再查，新伤县役停涉水半日、陷腿工留驿观察。已付雨修与医耗回条齐备；雨沟半角票来源未明，泥样分存，周全铜牌、急条原物仍在南驿等复验。

顾沉舟把这份回报抄成三份。一份给罗定，一份给谢无咎，一份留在自己手里。过去他怕别人改数字，如今更怕只有自己看过数字。

谢无咎收起自己的那份，指向关外湿黑的官道：“二十九日落前，我要你把宁川、南驿、雁回三处的粮车排成一张能走的图。图上不能只有粮，还要有桥、伤员、车夫和谁来付钱。”

顾沉舟看着门外尚未干透的车辙，答道：“那就先把明日的车，按今天的泥来排。”

文书上的墨迹慢慢干了。三日权限从此生效，封粮仍封着，旧案仍待核，顾沉舟却第一次拥有了在不拿仓钥的前提下，叫一辆车停下、让一名伤员先走、再把每一笔代价送到该去的桌上的权力。
