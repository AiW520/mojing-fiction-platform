# 第二十四章 贺兰朔的箭

箭出弦前，顾沉舟只看见西坡那只手抬了起来。

手里是弩。弩臂向下，瞄的不是骑兵，而是土坎下抬粮的魏三。顾沉舟喊声还没出喉，身侧弓弦已经一震，羽影斜过冻草，坡上那人猛地跌回石后。

“继续抬，别看！”贺兰朔说。

箭中了哪里，顾沉舟看不清。他只看见抬粮的两个人没有散，四袋粮正在一袋一袋上车。手里的点袋板压在怀中，右手不负重，那道未合的伤口不允许他再靠扑上去替民夫抢命。

两个时辰前，队伍从北门出来。

拖车令改过一次，原拟次日取粮因落冰未执行，今日骑哨确认西侧绕道可行，才重新开令。陆承与五名营兵、四名民夫、顾沉舟和药童，共十二人；另加贺兰朔与两名骑手，共十五人。两头健康役牛拉空车，花额牛停棚，陈九耳伤、鲁安手伤留营，不入抬运队。

军方干饼七斤半、温水四囊，三马草料十八斤、两牛草料十二斤，来自当日拨量。营北三里沙沟，绕西高地往返，午后前归；冰裂、桥塌、三名以上持械或出现弩阵即撤，两兵护伤者回营，留粮不留人。新队补骑哨两岗，北坡未空。阿鲁租来的两匹马与贺兰朔自用马，都记在出门牌背面。

贺兰朔没有先问能立多少功，只用鞭指图上的一个折口。

“昨日弩是在这里高起来的？”

陆承点头。顾沉舟把箭落在盾缘的位置给他看，没把远处五个影子写成五个姓名。

贺兰朔不争人数，问的是木辕受箭时车头朝哪。顾沉舟画了车的方向，他便在图上点出西坡一条看得见车辕、却看不见高地的细线。

“粮车走底，我走它看不见的地方。你们别为等我把车停在坡下。”

一支队伍不是每个人都站到同一条线上才叫齐。陆承答应让骑哨先绕，两名骑手一前一后守坡口，既不越界追敌，也不离开车队呼应范围。

沙沟的原车仍在。

甲、乙、己、壬四只木签挂着，两个豆料袋在辕后，受箭木辕与坏轴留原样。远望不能认封线，陆承让三名步卒上坡看，确认近处没有埋伏，才由魏三、陈二和另两个民夫两人一袋转装。

顾沉舟在空车旁逐袋记。原签未断，袋皮仍有雪痕，不因留在野外便认作已经足称；回营再验，不能在沟里拿来历不明的石头作权。

第三袋刚过土坎，西侧传来一声轻响。

贺兰朔先看见石后露出的弩臂，骑手也举出警示。他们没有凭草动就放箭，直到那人将弩口转向魏三，另一人抱刀从石后起身，才确定是两名持械威胁，不是过路牧人。

弩手抬臂，弓弦一震。

那是顾沉舟此前听见的第一声。

贺兰朔从侧坡借石遮身，一箭射向弩手躯干，不拿远射去赌能挑掉一只手。弩手向后跌，弩箭偏落土坎，抱刀的人立刻伏下，沿黑石后退。

“别追！”陆承喊。

贺兰朔没有第二箭追进石后。三人以上持械须撤，两人已确认、是否另有藏人未明，他也不凭一箭就喊尽歼。前坡骑手守住退车口，后坡骑手盯原路，陆承催最后一袋离开。

魏三咬紧牙，手没有从绳上松。陈二报壬袋，车尾另一人复报，最后一声淹在役牛鼻息里，顾沉舟还是听见了。

四袋全到备用车，两袋豆料另放手车格，不挤人粮。

坏轴和受箭车辕也可拿，却须把原车抬到石后，少两名兵便少两处护线。陆承只让人从安全侧取受箭辕的断段，旧轴标记留待另一趟，车留在沟边，不能让证物优先于活人。

撤到高地，贺兰朔最后下坡。他带一名步卒从遮处看弩手，地上有血，那人仍在喘，另一人已经逃。药童先看呼吸，箭在胸侧不能胡拔，固定箭杆，包扎可处理的出血处。

伤者被兵卒约束双手，抬上空出的手车位。没有因为他刚才射过民夫，便让他躺在冰边等死；也没有因为救了他就先除掉袭击记录。

“多一人。”陈二报。

“写押回伤者一，未问姓名。”顾沉舟说，“护运十五人，一个不少。”

回营路上，贺兰朔没有谈自己的箭。马老汉未随这趟，另一个管车的民夫照昨日教的办法检查套肩，租马回程也没有被逼着越坡追人。两匹马不是战后奖励，用坏了须赔阿鲁的马，不因挂上军缰就成无主财。

北门看到车，先响一声梆。

老邵从灶门跑出来，摸了摸四只袋口，忽然拍在陈二肩上。陈二喉咙干哑，没报功，只将壬字木签摘下来递回陆承。

那二百斤在地图上留了两夜，如今终于到了能烧火的地方。

四袋用丁二校过的秤复称，甲四十九斤九两、乙四十九斤八两、己五十斤、壬四十九斤七两，营内十两一斤，合一百九十九斤四两，比交接二百斤少六两。壬袋外皮受潮，另封待验，其余三袋经仓吏检查交灶，不把全部已到营都写作已可食。

秦百户看着差额，提出归作车损。

顾沉舟没再围着纸争半刻，让新队书记当面称四只空袋，把湿皮的重量另列。沙沟暂留牌、出交实称、今日净重各有数，差在哪一步仍要补转运原记；六两留为复称差，不是预先写成失窃，也不是凭坏轴自动消掉。

两袋豆料另称入马料簿，旧的北坡十二斤缺额仍待军法查，不混这一车。

贺兰朔把带回弩放在军法案前，又交今日射箭的记录。他本人认射一箭，兵卒认亲见持弩瞄人，药童认押回伤情。一个伤者、地上的血与亲见动作证明的是这次袭击，不证明他就是前次五个人中的谁。

“不认前次？”周校尉问。

“遮着脸。”贺兰朔说，“弩相像，认人得另查。”

苏晚棠留下伤者，不在他喘不过气时问押运。军法将人、弩、刀鞘记和箭分存，旧铜片仍未取，旧泉白砂箭也仍另封。

周校尉再问粮队：“谁先跑的？”

魏三看着他的手：“先牵牛，再抬袋，最后兵卒护后。没有谁私走。”

顾沉舟补报变更：十五人出、十五人回，押回伤者一，四袋麦实到一百九十九斤四两，两袋豆料另交，原坏轴未取；新增医棚与押守口粮，从访客留量转拨，不能让伤民分少。

周校尉在护运纸上认下有效运粮，不认未经查清的斩获。军法复核仍在后，但今日十二名民夫试编的脚钱如数发，出队四人另认搬运工，未出队的人不代领。

贺兰朔领箭回营，不曾碰过粮秤。他只在骑哨到位、射箭与租马归还栏落名，也肯将三日前的箭借领页交来核。页上短弩箭领六回五，少一支的骑手有东墙值守记录；顾沉舟收副页，不据此把己方骑手写成沙沟内应。

顾沉舟问：“今天为什么来？”

贺兰朔看着灶门。陈九耳边缠布，站在门里听陈二说两骑如何绕坡，没被叫出去再搬一袋。

“你昨天没拿伤员给我凑人。我今天也不拿民夫给我的箭当饵。”

这一次，顾沉舟没有马上落笔。

他把沙沟地图上暂留粮那一格划去，保留出事的弯口。四袋粮、一个活着的俘虏和两匹未伤的租马，都不是谁一句善意换来的，路、物料与人手各有来处，贺兰朔那一箭才有落下的位置。

新队书记正要合册，陆承从押守室回来，说弩手袖里搜到一张西墙出入短牌。

粮回来了，沙沟与营内那道墙之间，终于多了一件能查来处的东西。
