# 第二章 残账三列

伙房里的火烧到半夜，顾沉舟仍没有在那一行写下“四百斤”。

管事把手按在账册上，声音压得很低：“新来的，别把自己当钦差。黑河营的账不是你一个人能改的。”

“我没改。”顾沉舟说，“我只是拒绝替没见过的粮签字。”

管事盯着他，像在判断这句话值不值得一刀。最后他把账册扯回去，改成“待复秤”，又在旁边按了自己的指印。“明早仓曹来问，你自己解释。”

顾沉舟点头。

他没有因为躲过一笔假账而轻松。伙房里有三百多张嘴，明日若仓曹不发足粮，这些人会先把矛头对准记账的人。拒签不是胜利，只是把责任从纸上推到一个更冷的清晨。

天亮前，伙房管事让他去东仓取秤。东仓在营墙内侧，仓门被两道铁链锁着，封泥却只有一枚。守仓老卒姓罗，瘸着腿把钥匙递来，第一句话不是问来意，而是：“别碰第三把秤。”

顾沉舟看过去，三把仓秤并排挂在梁下。第一把秤的横梁乌黑，砝码磨得发亮；第二把秤新一些，秤钩上缠着红线；第三把秤最旧，木杆被火燎过，刻度从三十斤开始便少了一格。

“为什么不能碰？”

“坏了。”

“坏秤还挂在仓里？”

“营里东西多，没地方放。”

罗老卒回答得很快，却不看他的眼睛。顾沉舟没有继续逼问，先让他开门。

门轴发出涩响，霉味和麦香一同涌出来。东仓里堆着六排粮袋，每排十袋，袋上写着收仓日期。顾沉舟走到第一排，逐袋看封口：有两袋封线重新穿过，针脚比旁边粗；第三排靠墙处的袋底沾着黑河灰砂，和昨日陷车那批相同。

罗老卒催他：“伙房等着。”

顾沉舟问：“昨日入库多少？”

“账上是一百二十石。”

“实物呢？”

“仓曹称过了。”

“我问你看见了多少。”

罗老卒沉默了。

顾沉舟从木匣里取出入库簿。封泥一揭，里页边缘露出两种纸色。前十页用的是熟纸，后面却夹着一页发黄的草纸，页码仍接得上，墨色也故意调成同一深浅。草纸右下角盖着景和十六年的封印，印泥裂纹向左，说明盖印时纸已被折过；新纸上的十七年印却没有折痕。

这不是简单的旧账混入，而是有人把不同时间的东西拼成一册。

他把那一页取出，放在掌心，纸背有三列压痕：入仓、发营、耗损。右侧数字被刮掉，左边只剩“百二十”和一个半截“七”。顾沉舟想起母亲交给他的残页，残页左列也是一百二十，第二列却只有七十。

两个数字单独看，什么都说明不了；同样的纸纹、同样的缺口和不同年号的封泥放在一起，才足以证明账册至少被拆过一次。

他没有把纸带走，只在自己的小册上画了三道线：原账、补账、待证。

“仓曹何时来？”

罗老卒说：“午时。”

“午时前我要复秤。”

“没有批条。”

顾沉舟将伙房的待复秤账摊开。“管事已经按了指印。若你不让我称，我就把‘东仓拒绝复秤’写进今日军需回执。”

罗老卒第一次正眼看他。他的瘸腿像被什么旧伤牵动，过了片刻才说：“只称第一排，别动封袋。”

第一排十袋，每袋看起来都是五十斤。顾沉舟先检查秤砣，再用第二把秤与第一把秤互换砝码。两把秤差了半斤，第三把秤则在四十斤处少一格。罗老卒骂他折腾，顾沉舟让伙房送来一袋新米，作校准用的标准物。

校准结果让旁边看热闹的两名民夫都闭了嘴：第一秤多报一斤，第二秤少报半斤，第三秤在三十斤以上少报两斤。

“三把秤没有一把准。”顾沉舟说。

罗老卒低声道：“以前也这样。”

“以前是谁签的？”

“仓曹。”

“仓曹用哪一把？”

罗老卒看向第三把旧秤，没回答。

顾沉舟让民夫把第一排粮袋逐袋移到第二秤上。十袋总数比账面少七斤半，霉损占了三斤，剩下四斤半没有解释。少得不多，却刚好接近第三秤每袋少报的差额。

他把结果写成三栏：实称、账称、差额。每一栏下方都注明时间、经手人和秤号。最后，他要求罗老卒按手印。

“我只是守仓，不是仓曹。”

“所以我只让你证明你看见了什么。”

罗老卒的手在纸上停了很久，最后按下一个模糊的指印。

午时，仓曹秦百户带着四名兵丁来到东仓。他年近五十，腰间挂着一串铜钥，见到顾沉舟的三栏记录，第一句话是：“谁准你动秤？”

顾沉舟把批条递过去。“伙房管事的指印，军需回执上也有。”

秦百户撕掉那张纸。“民夫的指印不算军令。”

“那就请您重新称。”

秦百户没有接秤。他看了看第一排粮袋，又看向罗老卒：“昨日入库一百二十石，今日发营四百斤，账面没错。”

“实际只有三百六十斤。”顾沉舟说。

“少的算霉损。”

“霉损没有入库检验，也没有军医或仓门见证。”

秦百户的脸色沉下去。“你还懂军法？”

“落榜前读过。”

伙房门外聚来了人。有人是看热闹，有人是等饭。顾沉舟闻到伤药味，回头看见一个年轻兵卒扶着腿站在墙边，裤脚被血浸透。那兵卒手里攥着一张伤兵名册，名册上他的名字被划掉了。

“你叫什么？”顾沉舟问。

“赵七。”

“伤在哪里？”

“左膝，昨夜搬粮摔的。”

“名册为什么划掉？”

赵七看了秦百户一眼，没敢答。

顾沉舟忽然明白，粮账与兵账不是两件事。少报一个伤兵，就能少发一份口粮；少记一份药耗，就能把责任推给摔倒的人自己。

他将自己的三栏记录翻到背面，把赵七的伤情、时间和见证人写下，又把名册上被划掉的墨痕拓在纸上。

“今天先不争四十斤。”他说，“秦百户，请您在这里签字：东仓三把秤校准不一，第一排少粮七斤半，赵七伤情未入名册。若您不签，我把记录交给营门的换防官。”

秦百户看着他，忽然笑了。“你以为换防官会替一个伙房文书得罪仓曹？”

“我不知道。”顾沉舟说，“所以我会把原账、复秤记录和伤兵名册各抄一份，分别交给三个人。只要其中一份还在，今天这笔账就不会只剩您的说法。”

风从营门灌进来，吹得纸角发响。

秦百户没有签。他命兵丁封仓，转身离开时却留下了一句：“下午发粮，按三百六十斤煮。谁饿了，去找顾文书。”

人群里响起压低的骂声。

顾沉舟把笔放下，走到灶台前，对伙夫说：“把三百六十斤按三百人分，先扣除伤兵和守夜队，再把每锅实耗写清。剩下的人每人少一口，不少一碗。”

伙夫愣住：“这样也不够。”

“所以今晚我要进西仓。”

“西仓不是你的账。”

顾沉舟看向门外雪地上的车轮印。那车轮比昨日陷车更窄，印子一直通向营墙西侧。

“现在是了。”

他把半页军粮账从衣襟里取出来，只看了一眼便重新收好。残账第三列被火烧掉了，但第二列“发营”旁边，仍留着一个不完整的车轮形压痕。

第一道裂缝已经被他按开。

接下来，裂缝里会不会流出粮，或者流出血，要看他能不能在夜里拿到第二类证据。
他又让一名没有参与搬粮的火夫取清水，将两枚封泥分别浸湿。旧封泥一入水便散出暗红粉末，新封泥却只在边缘裂开，印面仍完整。封泥配方不同，意味着两次封仓至少不是同一批泥。顾沉舟把水盆、封泥和取样时刻一并写在记录上，连火夫的名字也没有漏掉。

“这些小事能证明什么？”火夫问。

“单独什么也证明不了。”顾沉舟说，“但以后有人说两次封仓是同一日、同一人、同一批粮，这盆水就能让他说不完整。”
