# 第十六章 三日口粮

谢无咎的信没有在当天回完。

周校尉只把信封压进营官柜，先把三日口粮的清点令递给顾沉舟。换防后黑河营名册变了三次：旧队三百人，加五名获救民夫，共三百零五口；新队实到四十七人。能不能按三日发粮，不能只看东仓簿上的“在营五百”。

“先清人，再清袋。”周校尉说，“三日之内不许借霉粮填数。”

顾沉舟接过令纸，正式的“什长”木牌还挂在腰上，第一次被人用官称叫住。他没有因此挺直腰，先让陈二把两本名册分开。

旧队三百人中，营兵一百八十六，辅兵九十四，其余二十人照原役册逐名归灶；赵七、韩魁、周文都已在册，不另加人。五名获救民夫另列，合成三百零五口。新队四十七人中，营兵三十一、辅兵十六，两个冻伤者从营兵栏转医棚，不添两份。曹六、许三仍在旧册，不重复计入新队。

陈二算了两遍，抬头道：“赵七、韩魁、周文加五个民夫，旧医棚八人已在三百零五里；新队两人转来，医棚十人。软食要另煮，人数不能再加十个。”

苏晚棠把伤情册放到桌上：“医棚十人按伤情分级，不与普通锅重复领。五名民夫尚未结役，口粮由押运案先垫，不能因为军法没结就让他们绝食。”

顾沉舟将人数写成四栏：普通营兵与辅兵、医棚伤员、临时留置民夫、新队独立伙房。每栏后面列三日份额和责任人，不把“预计会有人离营”先扣掉。写完，他才去看东仓送来的清单。

他先把旧额摊开：营兵每人一升，辅兵七合，再用昨日各灶实称耗用与今日减额令复算，不能把容量直接当重量相加。新队虽另起伙房，三日内仍从这批粮结算；医棚只转锅，不添名。陈二用木片记数，第三遍算到末尾时，冻僵的手指已经捏不住笔。

“还有夜哨。”陆承提醒，“今晚两队门哨交班，二十斤夜粮不能从明日的普通锅里临时拿。”

顾沉舟把夜粮单独列在最右一栏，写明领队、时刻和归还的空袋。守夜的人不能因为看不见灶台，就变成账上的无名损耗；同样，空袋也不能证明粮已经足额，只能证明有过一笔交接。

清单上有净麦九百斤，豆料三百斤，粟米一百二十斤，另有待报损麦八十七斤。秦百户在最下方写了“可发三日”，却没有把每种粮折成同一口粮标准。

“不能把豆料和麦一斤抵一斤。”顾沉舟说。

秦百户坐在东仓门旁，手指敲着钥匙：“军中折色向来如此。马料、粟米、麦，到了锅里都能填肚。”

苏晚棠摇头：“豆料不能按普通粥粮发给伤员。粟米要看去壳和霉损，药耗也不能拿来抵粮。”

顾沉舟把清单翻到背面，请秦百户补出净重、袋号和出仓时间。秦百户没有拒绝，却提出一个条件：只许复秤九袋，剩下的按旧簿数量承认。

“为什么是九袋？”顾沉舟问。

“人手只有这些。你新任什长总不能让全营等你称到晚上。”

“那九袋按类别、日期和仓位抽取，不能由仓曹挑最整齐的袋。”

秦百户看了他一眼，叫罗老卒取来东仓排架图。净麦十八袋，仓单写的是五十斤一袋。顾沉舟把十八袋分为新袋、旧站转运袋、临近报损袋三组，各点三袋，共九袋。点袋人临时抽木签，秦百户不得换位；差额超过两斤的组须续称，未称部分仍待核，不由九袋替整仓背书。

周校尉批准了这个方案。营门、东仓、伙房三处各出一人，苏晚棠只在粟米和医棚口粮处见证，不替仓曹认粮。

第一袋新麦净重四十九斤八两，第二袋四十九斤九两，第三袋四十八斤六两。按营内十两记一斤，三袋合计少一斤七两。旧站转运袋三袋少四斤二两，其中一袋底部有盐白硬皮；临近报损架的三袋封线重穿，净重比账面少七斤。八十七斤报损麦另封，未混入九百斤净麦。

秦百户脸色终于变了：“重穿封线不等于少粮。”

“当然不等于。”顾沉舟把三类数字分开，“它只说明这三袋需要查经手。今日三日口粮不能拿它们当足额，也不能直接写成侵吞。”

这一次，他没有因为数字落差而兴奋。九百斤清单已发现十二斤九两差额，未称袋还不能认足。按减额后全营每日三百四十斤的安排，医棚、夜粮和新旧各灶都列在其中，账面也只够两日半稍多。若把报损粮与豆料一并算进来，纸上就能凑够三日，锅里却得由伤员替这笔数受罪。

周校尉问：“你给方案。”

顾沉舟把木板转向众人：“第一，净麦按两日半发，第三日留出夜粮与伤员份额；第二，粟米一百二十斤先去壳、筛杂，苏医官确认可用于普通锅后，只给营兵和辅兵，不给发热和脚伤者；第三，豆料三百斤只记马料，不与人粮混账；第四，三日内修旧渠，若能从南沟引水，先救屯田，不许把未长成的麦苗算成现粮。”

秦百户冷笑：“你已经开始画地了。修渠要民夫，民夫要吃粮。”

“所以第三日口粮另立借支，不从医棚扣。修渠若无水，白吃的不是民夫，是整营将来的粮。”

许校尉站在门边，问：“谁带修渠？”

“我只负责粮路，不负责征夫。请营官另下民夫差条，写明人数、工期、脚钱和伤员处置。若要我给粮，我只按已签名册发。”

周校尉点头，让书记把修渠列为明日军议，不在今日口粮令上混写。

午后，仓吏与老邵筛粟米，逐袋看干湿、虫痕与壳杂；苏晚棠在旁盯住报损架，不许将霉粒倒来掺数。这批粟没有霉变迹象，去壳筛杂后，一百二十斤剩七十八斤；筛选只是核出重量，不是让人试吃验毒。结霉的麦仍封着，绝不因挑过外表就下锅。

筛下的四十二斤杂壳分别装袋，写明原批次，免得日后重新倒回净粮。七十八斤留作次日各灶补量，尚未下锅，其中三十斤暂列勘渠工食，余四十八斤留营。新队由书记领料；医棚十人的粥由苏晚棠分级，顾沉舟只认交料，不替她认伤。陈二终于把四栏合回三百五十二口，一人未漏，也一人未多。

七十八斤救不了三日，却能让普通锅少挪一顿净麦。顾沉舟把这项回收写成“筛后可用、限对象”，不写“粮已安全”。

夜里，周文终于醒了一次。

苏晚棠只让他看灯，不问火。周文喉咙干裂，第一句话是：“柜……不是北墙……”

她立刻让药童记下，却没有追问。等周文再次昏睡，苏晚棠把那句口述标成“意识不清、不可定案”，顾沉舟没有把它抄进火案证据栏。

三日口粮的清点在亥时结束。净麦抽样差额、粟米筛后七十八斤、豆料三百斤马料、待报损八十七斤，各自归档。秦百户在抽样栏按印，拒绝在“整排复称”处签字；顾沉舟把拒签事实留在纸上。

他又把谢无咎调拨表抄出两份，一份交周校尉，一份交陆承封进营门簿。表上写着三日后西墙交净麦八百斤，领受人是秦百户，复核人却空着。顾沉舟没有擅自把自己的名字补上。复核人空缺，意味着粮车若在西墙少一袋，秦百户可以说是转运司的责任，转运司也可以说是营门未验；若他此时把名字填进去，便会把尚未看见的八百斤全部背到自己肩上。

“那你不接，谁接？”周校尉问。

“先由营官补一名与领受人无关的复核人，再由营门、伙房和转运棚各留一份交接数。”顾沉舟说，“若三日后仍无人补栏，我只负责把缺栏写明，不能用自己的名字替制度遮住空白。”周校尉点头让书记把这句话写进军议待办。空着的栏位因此变成了明日必须解决的责任，而不是等粮车到了再互相推诿的借口。

正式什长的第一道成果不是多出一仓粮，而是让三百五十二名在营人知道未来三日哪一碗粥从哪一类袋子来。顾沉舟把三日配粮表钉到伙房门上，普通锅减额、医棚份额、民夫借支和新队独立伙房都写明。

雪又落下来。门外有民夫来问明日修渠是否算役期。

顾沉舟没有先答。他把问题记进明日军议栏，随后回头看东仓架图。旧站转运袋的盐白硬皮，与谢无咎来信角落那一粒颜色近似，却仍未接触、未合并检验。

三日口粮只算清了两日半的命。

剩下半日，要靠路上的粮。旧渠救的是下一季，不能拿来敷衍眼前一口锅。
