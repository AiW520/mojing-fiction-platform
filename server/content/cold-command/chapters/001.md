# 第一章 落榜入营

景和十七年的第一场雪，落在放榜日的第三更。

顾沉舟从贡院门口走出来时，榜墙上已经挤满了人。有人捧着报喜的红纸，有人拽住报录人的袖子问名次，还有人跪在雪里，把额头磕得通红。只有他两手空空，袖口沾着墨，鞋底被人踩掉了一层泥。

他没有再回头看那张榜。

第三次乡试，第三次落榜。不是名次太远，恰恰是太近，近到他知道自己差的不是文章，而是那几个能让阅卷官记住的名字。顾家在城南只有两间漏雨的屋，父亲顾长河死在驿路上，官府说是押运军粮时车轴断裂，连尸骨都没运回来。母亲靠给人浆洗过冬，昨日托邻居捎话，说家里米缸只剩半斗。

顾沉舟把落榜文书折成四折，塞进怀里。纸角硌着胸口，像一片没有磨平的骨头。

他本想去典当那方砚台，巷口却先响起了木梆。

“景和十七年征役牌，北原黑河营补民夫一百二十名。凡二十至三十，识字、会算者优先充文书。三日内不到，按逃役论。”

宣读的人穿着县衙皂衣，身后跟着四个持棍差役。巷口的人群像被冷水浇过，瞬间散开。顾沉舟没有动。他盯着那张贴在墙上的征役告示，先看年号，再看落款，最后看押印边缘。

告示说黑河营缺的是民夫，落款却用了兵部转运司的半印。半印压得太浅，右上角还有一道毛边，像是从旧纸上揭下来的。

差役头子注意到他的目光，朝他走来。“识字？”

“识一点。”

“会算？”

“会一点。”

“那就不是民夫，是伙房记账。进去以后管三百人的米，不用上城墙，不算亏。”

顾沉舟问：“三百人的米，每日定额是多少？”

差役愣了一下，旁边的年轻人笑道：“还没进营就想吃多少？进去自然有人告诉你。”

顾沉舟没有笑。他见过父亲留下的押运单，军粮从仓到营，沿途要扣车耗、霜耗、破损耗，最后一石粮往往只剩七斗。若连入营定额都不公开，账上少的便不是损耗，而是人命。

“我去。”他说。

差役把一块木牌扔给他。木牌上刻着“黑河营伙房记账，顾沉舟”，名字最后一笔刻歪了。征役牌背面另有一行小字：腊月二十七前入营，逾期自负。

顾沉舟收牌时，指腹摸到木牌边缘有一粒细砂。不是城里河砂，是北原黑河滩上的灰白石砂。牌子已经在营里待过，差役却说是今日才发。

他没有当场指出，只问：“从哪条路走？”

“西门集合，走官道。”

“官道昨日封雪。”

“那就走驿道。”

“驿道的桥昨夜塌了。”

差役脸色一沉，抬棍便要敲他的肩。顾沉舟侧身让开，棍梢擦着衣领过去。“我只是问清楚。若粮车也按这份路程走，到了黑河营，账上会多出一日霉损。”

巷子里一下安静了。

差役头子看了他一会儿，冷声说：“书生脾气别带进军营。明日卯时，西门外。”

顾沉舟回到家，母亲正在灯下缝一双旧布鞋。她没问榜，只看见他手里的木牌，手指停在针线之间。

“黑河？”

“伙房记账。”

“你父亲就是从那边回不来的。”

“我知道。”

母亲把针插进鞋底，半晌才说：“你去查账？”

“先活下来。”

这句话说完，他自己都不信。

父亲死后，县里送来过一张烧掉半边的押运单。上面写着黑河营，腊月二十七，麦一百二十石。顾沉舟一直以为那只是父亲留下的遗物，直到今日看见征役告示上的半印，才想起押运单边缘那道同样的毛边。

母亲从床脚取出一个油布包。里面没有金银，只有半页被火燎黑的纸，纸上三列数字只剩下左半边：入仓一百二十，发营七十，耗损……

“这是你爹死前托人送回来的。”母亲说，“那人后来也不见了。”

顾沉舟把纸放在灯下，先看纸纹。纸纤维里有细小的麦壳，不是官仓用的熟纸；墨色一深一浅，右侧被火舌舔掉，但左列的“一百二十”仍能辨出。数字下方还有一道短横，不像记号，像是有人在抄写时停过笔。

他没有把纸带走，只用炭笔将剩下的字拓在旧书页上。母亲问他为什么不拿原件，他说：“军营里人多，原件要是丢了，谁也证明不了它原来是什么。”

母亲听不懂账，却听懂了后半句。她把那半页纸重新包好，塞进他衣襟内层。

第二日卯时，西门外已有两辆雪橇车和三十多个征役者。顾沉舟被分到最后一车，负责抱着一个木匣。押车的伍长姓周，手里握着一根黑漆短鞭，车上装的不是兵器，而是封存的入库簿。

雪橇出城后，周伍长把木匣踢到他脚边。“到了营里交给仓曹，别乱看。”

顾沉舟问：“入库簿为何不跟粮车走？”

“粮车有粮车的路，账有账的路。”

这回答太顺了，像早已说过许多遍。

他没再问。车轮压过积雪，走到西坡时，前方一辆粮车陷进沟里。车夫掀开油布，露出七八袋麦。袋口扎得很紧，表面却已经鼓起霉斑。周伍长命人换车，不许开袋。

顾沉舟下车帮忙，手掌按在车辕上，闻到一股酸味。他看见粮袋底部沾着和木牌上一样的灰白砂，车轮印却比官道车辙窄半寸。

“这车从黑河滩过来？”他问。

车夫不答，周伍长的短鞭啪地抽在雪地上。“伙房文书只管进锅，不管车轮。”

黑河营在傍晚露出墙头，城垛上没有旗，只有一面被雪压垂的旧布。营门旁立着两块木牌，一块写入营时辰，一块写今日口粮：营兵每人一升，辅兵七合，民夫五合。

顾沉舟看了一眼，没有立刻进门。他低头对照木匣封泥，发现封泥上是景和十六年的旧年号，而征役牌和今日军令都写着十七年。

他把这个发现记在心里，随后跨过门槛。

黑河营的第一顿饭已经在锅里翻滚。汤里有米，却没有麦；灶旁的伙夫说今日只发了三百六十斤，账上却要记四百斤。新来的伙房管事把毛笔递给顾沉舟，指着空白的一行：“写吧，别让大家等。”

顾沉舟接过笔，先问：“四百斤从哪一仓领出？”

管事说：“东仓。”

“东仓今日封泥是什么年号？”

“你一个记账的，问这个做什么？”

顾沉舟把笔放下，看向锅里稀薄的麦汤。“因为三百六十斤只能煮出这些。若我写四百，明日缺的就不是账，是四十斤粮。”

管事脸色变了，帐房里有人笑，有人悄悄把门关上。顾沉舟伸手摸向腰间的半页账纸，却没有拿出来。

他知道自己还没有兵，没有印，也没有足够证据。

但他已经看见了第一道裂缝。
伙夫把勺子递到他面前，勺柄上全是油垢。顾沉舟没有接着舀，而是让人把锅底的麦渣捞出来平摊在木盘上。霉粒沉在最底下，数量不多，却集中在同一批麦里。若只是受潮，霉粒不会这样分层；有人在装袋时把坏麦压到袋底，等开锅以后才会混进汤里。这个判断还不能写进账，他便只记“霉粒集中，待取样”，并让伙房管事在旁边看着。

管事想骂，看到门外等饭的兵卒，又把话咽了回去。顾沉舟第一次明白，军营里最硬的不是官印，而是三百个人同时盯着一口锅时，谁也不能把锅里的东西说成别的样子。
