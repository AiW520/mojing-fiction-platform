# 第四十八章 修渠与征夫

正月十七卯初，宁川旧城南渠的冰先裂了一道细缝。

顾沉舟没有让人踩上去。他带着昨夜登记的木匠梁铁、两名营兵、陈二、孟槐和四名自愿出工的流民，沿渠岸走了一遍；其余人留在河滩棚外，由一名营兵看守登记板。苏晚棠仍在雁回关，无法替他现场判伤，顾沉舟便在军令里把“伤者送南驿，停工由医官复核”写在最前。

这支查渠队共十人，带两斤路食、一囊温水、两根探杆、一把短锯和四条麻绳，半日只查南渠第一段，不搬土、不破闸；见冰面空响、渠壁坍塌、有人持械或伤者不能自退，立即退到旧石桥。孟槐和梁铁各持一份路线图，陈二记实物，营兵只护人，不替工匠判断工程量。

渠口距旧城不到半里，冰面下却传出水声。梁铁用探杆从岸边试了三次，第三次杆尖落空，整段冰壳往下沉。一个流民少年刚要探头，顾沉舟一把扯住他的衣领，把人拉回石岸。

“看见水，不等于能走。”他说。

少年脸红：“我叫石满，能干活。”

“能干活先记在名册，不拿脚底替渠验冰。”

陈二在纸上写下石满姓名、年龄十四、可做轻土活，未满十六岁，不列抬木和入冰栏。石满不服，却被孟槐按住肩膀。老人指着渠壁：“这里塌过两回，第一回死了一个挑土的，第二回才立了这根旧桩。”

旧桩上还挂着半截红线。顾沉舟没有把它和红角粮票直接相认，而是取下连泥的那一段，单独放入竹筒。红线来自登记票的样式还是旧渠役棚，须等纤维比对，不能因为颜色相近就把骗票人与塌渠案绑成一人。

查到第一道闸口时，渠底露出一块黑木板。木板边缘有斧痕，旁边散着三枚生锈铁钉。梁铁说闸板曾被人拆走换柴，孟槐却说去年征木时，南驿的人已经把旧闸列作“可修”。两人都只是见过，不能代替木板尺寸和役工记录。

顾沉舟让陈二量闸槽宽度，自己在图上标出水位、淤泥深度和可进人的位置。第一段渠宽七尺，淤泥最深处超过一人膝，若要清通，至少需要三十六个工日；闸木要两根长木、四副铁箍，木匠能做，铁料却要从南驿军需房领。

“三十六个工日，若二十九个人都能做满工，两日似乎够。”陈二算到这里，自己停住了。昨夜名册里有十一人只可轻活，工日不能仅按人头相除。

“不能把二十九个人全压在一处。”顾沉舟答，“大工先拟八人挖淤，六人运土，四人看绳，两名木匠做闸木，剩下九人轮换和照看伤病。那是粮料齐了才办的数，今日仍先报十人半日。儿童、老人和伤病不补空。”

午前，沈三被南驿驿长带到渠边。他昨夜已交代，红角票来自一个自称“周掌柜”的粮行中人，周掌柜让他把票送到河滩，承诺按三日工发二十斤麦；沈三只收过两枚铜钱，不知道粮在何处。驿长另带来一页脚行欠工簿，上面确有“沈三，南渠送票一趟，欠脚钱六钱”的记录，日期却比流民所说早一日。

顾沉舟没有因为簿上有名就把周掌柜写成主使。他让沈三在欠工簿旁按手印，说明自己亲见和听人转述的分界；又让驿长把欠脚钱从军粮账里单列，不许用红角票折抵。

修渠的第一场争执，出在粮上。

南驿试转的两袋一百斤昨日已入秤房，仍是封存过路粮，不准拿来抵工食。驿长另从军需批给的试工粮中预留三十斤，却要求把五十七名流民全部写成南仓役夫，理由是“人既登记，就能按军令调动”。昨日二十斤赈急粮已做粥分给各户，今日试工粮不能冲掉明晨续赈的缺口。

顾沉舟把名册摊开：“登记是为了知道谁活着、谁能做什么，不是把民夫一笔划进军籍。三十斤先按十人半日试工核拨，剩下的要等军需回文。工食、住户口粮、伤病软食三栏分开。”

驿长皱眉：“修渠若只给十人粮，渠什么时候能通？”

“那就把要修的长度缩到十人能承担的范围。不能先把没到的粮写进锅里。”

孟槐第一次在驿长面前开口：“旧城的人愿意出工，但不替一张空票背债。”

两边僵住时，梁铁从渠边抱来一截旧闸木。木心已经发黑，内侧却有新刨痕。他说只需一根新木便能先做临时闸板，另一根可拆南仓倒塌的废梁，但废梁归屋主孟槐看管，不能军队自取。

顾沉舟让许木匠去量废梁，孟槐叫来六户住户共同见证。主仓落梁仍留原处待军需查验；两名住户合有一根拆下作柴的旧梁，愿卖作试板，四户不同意动自家梁木。能用的军需按木料价付，不能用修渠名义白拆住户屋。顾沉舟把同意与不同意分别记下，不让多数人的饥饿替少数人的屋顶作主。

崔岳核了图，另签午后半日试工副令：十名自愿役工、原两名营兵护场，只清石桥旁一丈半的浅淤，不入膝深段；三十斤只是预留上限，实领由厨工报数，伤者两人医转，水涨过岸边刻线全停。清出渠岸探杆的通路后，木匠在上游土坎外留了泄水槽，众人能沿石岸退回桥头，才准落第一筐。

午后，十名试工者按名册分组：四人挖浅淤，每次两筐即换；两人运土，两名木匠量槽和配板，一人看绳，一人递料。两名营兵另守桥头和退路，顾沉舟负责报距离和换组，不碰重木。少年石满只在岸上递短木，不能下冰；孟槐本想一起抬木，手抖得抓不牢，便退到晒绳处，不占十名试工名额，也不替军兵作役工结工钱。

第二筐淤泥刚吊到岸上，南渠下游忽然传来水响。冰下的水冲破旧土坎，绳桩被带歪，一名挑土工脚下一滑，右手撑在碎石上，掌心裂开。营兵没有把人拖着继续干，先用绳圈固定，再由陈二按原路护到南驿。顾沉舟让梁铁停下清淤组，木匠只在桥上看闸口，不准为了赶半日进度再添伤。

伤者叫周四，原属轻活组，按令每筐不装满，仍因滑石受伤。送医栏有人先写“自愿挑土”，顾沉舟把“自愿”划掉，改成“分组安排后受伤”，并记他已运一筐半，不让一句自愿替工伤结案。陈二与一名营兵护送，原路食随三人分出六两，包含在两斤内；余一兵带九名未伤役工退桥头，沈三和驿长仍在桥上，两人不补原十名役工。

崔岳赶到时，水还在冲土坎，没人敢再靠近闸口。顾沉舟让梁铁用长杆从石桥上挑开泄水槽里堵住的两块苇根，两名工人守绳，旁人离开绳圈。水从槽里冲向空滩，不再顶着那块碎冰；桥边泥水退去，担架终于能沿石岸走，不必爬上流民住的高坡。

驿长这才看明白，顾沉舟停工不是为了少报两筐土。若硬催十人下渠，水会把人挤到棚前，粮车也走不进城。他将原想延到明日的脚钱匣打开，在桥头先付已核实的半日钱，周四的那份另封，随医转回条交本人。没人用一张红角纸换掉这次铜钱。

试工的马六接钱后没有立刻走。他与另外两人把倾倒的绳桩搬到岸上，按梁铁指的位置另打两根，离渠边多退了三步。石满在旁边递木，见有人想抢着下泥，第一次主动拦住：“先认刻线。水到这里，谁喊也不下。”

顾沉舟看着那孩子手指的地方，没有夸他胆大。绳桩站稳、退路留开，是今日比一丈半淤泥更值钱的进展；明日来的人若看不见这条线，今天花过的粮和铜钱就只买了半日。

这一停，反而让梁铁找到了渠底的旧木楔。木楔上刻着半个“南”字，和旧役棚裂木牌的字形相似，却缺另一半；顾沉舟把木楔、红线、红角票、黑木板分四袋封存，未凭刻字相似认定同一批人。

申时，试工只清出一丈半淤泥，临时闸槽能落下从废梁改出的试板，水流比早晨稳了，却远未达到可引水入田的程度；废梁买价由驿长现场付给同意出售的住户，不让口粮抵料钱。试工粮实领十一斤二两，厨工煮给役工与护场勤务人，三十斤预留余十八斤八两仍在驿棚；查渠路食两斤余六两，温水余四成，麻绳磨短一丈，铁钉一枚折断。伤工回条确认周四右掌裂伤、停土工三日，受治人已在南驿，不在夜间点名重复领驻工食。

罗定的回文在傍晚送到：接下三日准南渠试修，次晨仍限十人半日；另拨净麦九十斤、木料两根、铁箍四副，脚钱与伤工另列，准五十七人分户登记但不得改军籍。修渠每晚报实工、粮耗、伤情和次日所需，超过九十斤或新增兵员须重报，今日三十斤预留账另结，不重复加进新拨。顾沉舟的三日延留已获军镇复文，但只办南线转存和交接；崔岳仍掌现场，顾沉舟不凭延留令接管旧城兵额。

这道回文没有让渠一夜变通，却给了顾沉舟一条能落地的边界。孟槐带两户收好废梁价单，梁铁把试板靠在岸边等次晨复看，河滩上的二十三户第一次知道明日该来几个人、能领多少粮、受伤后往哪里走。

顾沉舟把九十斤拨粮写进“待领”，没有提前加进秤房余仓。他看着红角票和南渠木楔各自封好的纸袋，知道宁川的第一笔补给网络已经露出骨架：粮要经过秤，工要经过人，伤要经过医官，谁也不能拿一张票替另外三项签押。
