# 第五十六章 黑河开春

正月二十五，宁川南渠边的冰先从石缝里松了。

顾沉舟踩到岸上，听见水下碎冰相撞，声音细而密。这里的水来自本地坡沟融雪，黑河隔着山和驿路，不会一声裂冰就冲到宁川；可南渠只有刚立的两根闸木，一点涨水，也足以把六户人的井路毁掉。

孟槐拿起昨日退路索，尾端比领用时短了三尺。断纤维长短不齐，绳身还有磨白的一段。守东端的护兵说没见人靠近索桩，他的眼睛只看东端，不能替整个夜里作证。

昨日洗索的工人承认发现过磨口，以为再缠一圈就能用；料棚取出的旧索也没有重新通检。顾沉舟将湿绳停用，换完整绳，在磨石处垫木包布。少三尺须查，人为割索却不能靠少三尺就坐实。今天若先围着找“贼”，退路还是那根会断的绳。

晨令准八名自愿工人全在岸上送桩、搬石、铺板，崔岳连三兵守桥和退路，两名院兵留宁川，独立仓兵仍看三百斤。饼四斤、水三囊归护兵，工粮另算；水过新试标、撑木失控或岸土裂便撤，伤者送南驿。顾沉舟本人延留只到今日日落，不得以修水为由越坡追人。

赵麻子停走，不在八人里。田七、赵贵仍停重，许木匠只指导，马六只看轮。八个健脚者在岸上各接了一件活，董成搬长杆，丁六往硬地铺短板，没有让一个伤者戴着包布来凑整齐。

辰初，雁回急脚送来陆承的原报。原报发于二十三，二十四在雁回换马，今日到宁川。黑河旧渡向阳浅湾已经开冰，阴面河段仍厚，两处桥哨的观察与魏三沿岸所见各记在旁；旧便道暂停通行，不可当作全河能行舟。

老邵附言说欠的八根木管仍未补，三十六亩旧田需重测，种子尚待领。顾沉舟读到这里，把宁川种子空栏又折起来。旧营那块田不是眼前这段坡沟，报个开春不能替两边都添上收成。

急脚要再上马，却发现后蹄铁松动。驿长留他修蹄，报送延误一并记明。陆承没有亲来宁川，顾沉舟只把回复交驿传，不将一封信写成援兵已到。

闸口先涨了两指。旁挡前有一片碎冰斜竖，背后细枝越积越多，水不再走旧石槽，沿土坎向井路推。许木匠用长杆量过，发现主挡还坐在榫口，危险是旁挡受顶，不是两根木同时坏掉。

“松哪边？”梁文问。

顾沉舟望向旧泄口。那里昨日留着开口，正对无人住的低石槽；直接抬主挡，积水却会整股奔向井阶。

“先让六户离低阶，井桶也收。旁挡只松一指。”

孟槐沿屋门拍过去，何氏抱着空桶上硬地，另一户还想回去牵鸡。孟槐帮他提笼，不催人跨水。六户点齐之后，两名工人在岸上缓松旁挡，董成与另一人从背侧送杆，推掉卡住的枝冰。崔岳守退路，不准谁拿肩膀去顶木。

旁挡刚退一指，水猛地钻进泄口。冰片转了半圈，一截粗枝反弹，董成手里的长杆向上翘。他若握死，手腕便要跟着折过去；他撒手退了一步，左掌被粗木擦出一道浅裂，长杆滚到岸边。

“别捡杆！”顾沉舟喊。

丁六已伸出去的手立刻收回，两名护兵将杆拨到背水处。董成上了硬地，医佐洗去木屑，包好左掌，判停握重、抬重一日，次晨复查。他做过的活照付，医布与诊费另报，不从他的脚钱里扣。余下七人接岸活，不偷偷再添一个未登记的人。

水终于沿旧泄槽落下，井路仍有浅漫。许木匠请梁文取两根短桩，把旁撑移到不会被冰顶中的背侧，再用一副余铁箍压住木撑。锤子交完好工人轮流用，他坐着看榫位，伤手一次也没去接锤柄。

顾沉舟站在退路索外，左肩酸得往下坠。他能指哪块石该压，不能替董成补一个劳力。他让第一轮搬石的人退下歇息，等稳桩再换第二轮，宁肯少做一车，也不让七人硬赶八人的数。

午后又来了两片大冰。一片擦过新撑，另一片撞在主挡前，水线涨了一刻便落。短桩未松，箍口没转，许木匠仍让人隔着岸再看一轮，没因一次撑住就喊渠成。

梁文想先把料车拉过桥，顾沉舟让驿方取等载石，在秤房复称后装车。第一车试压，轮落到旧坑边，短板轻翘，工人停住，补平垫石才重新走。两次空车和等载石车核过，桥头保下一丈半硬路。县工曹与驿方复看，只准次晨轻载通行，满载还须另查，不能拿今天这一车替所有粮车作保。

候在空场的车夫挽起裤腿走到轮边，看着硬路上的印子，问他能否把明日搬料接下来。顾沉舟让梁文按已准轻载议价。车夫不再要求先拿一张全载凭条，今天亲眼看见那块会翘的板，知道少一袋装载也比坏一辆车强。

可车夫回头一望，又皱起眉。轻载一趟的脚钱，若连返程都空着，牛料便要吃掉大半。他把车辕摆向空场，宁肯再等别的生意，不愿就这么应承。

顾沉舟没有让护兵催车。他请梁文把次晨已准的搬料点指给车夫，来时搬干垫石，回时只带岸上挑出的废枝，卸到驿外指定地，不把待验粮袋捎上。两程分别议价，合不过车夫的牛料和车工，他仍可不接。

车夫拿树枝在泥上画了一道轮距，自己量了两处转弯。窄口只能走这辆小车，别家的大车进不去；他把那道轮距留给梁文，说先请驿长确认废枝的去处，明晨再定。顾沉舟看着他把载石逐块卸下，没有把一句愿意议价当作已经有车可用。

七个工人也趁卸载轮换休息。丁六搓着酸胀的腿，望见董成包着手坐在硬地，主动将自己旁边的空板推过去给他坐。董成没有回去搬石讨回面子，只用右手扶住板头，指着刚才粗枝弹起的位置，提醒接杆的人站后半步。这一回，吃过的亏没有变成伤者再受一次伤的理由。

清出的废石原先散在浅淤里。孟槐带县役核过，不属六户旧墙石，也不在军需册里，才准流民取去补破灶房门槛。两户人抬走头一筐，井路口第一次没有被新搬来的石堆堵住。

何氏把桶放到井沿，还想试着打一桶水。医佐拦住她，先取样。水看着清，也可能混了沟泥，未核前不能让人直接喝；今日清水由驿里送来，车脚费报县方，不让六户因救了井路反而白出一趟运水钱。

她望着落回石槽的水，说：“这个闸，明日谁看？”

顾沉舟没立即答应。他今日日落要交现场，借屋、借秤房也只核到今日，屯田局立十五日却不是他个人有十五日的留任权。若现在说还是自己看，明早不是违令，就是让她在屋里等一个已经走了的人。

罗定的复命函恰在这时到，催他按原令交接后返关。顾沉舟请孟槐先定县方明日值守，经梁文接修料与工钱，护兵轮换另向罗定请令；仓锁与粮封不交局务经手。借屋到期，须问屋主续借或迁桌，不能因为临时牌还挂着便占下去。

何氏听到迁桌，反倒把桶提走：“桌可多放一夜，我得等县里来个人认。别替他答应看水。”

顾沉舟将她准许的一夜另报，不把秤房也搭进去。宁川终于有了能接下一天活的人，交接也比他亲自在场复杂：哪里能行车、哪里不能饮水、谁停重、谁拿料钱，每一处都得让下一人亲眼看见。

傍晚复称，八名岸工上午领九斤六两，午后四斤二两，合十三斤八两；四十五斤工粮余三十一斤二两。旧预留十八斤八两未动，宁川三百斤军粮仍封，今日二十斤日赈由驿厨独账接医食，不多领伤者份额。

护兵饼耗三斤二两、余八两，水余一囊。两根短桩、一副铁箍实用，余两副封回料棚，湿索停用，长杆擦损另报。董成的手伤、赵麻子的踝伤、车轴待修和粮袋待检没有因为水退而消失，续粮缺口也只剩三十一斤二两挡在明日之前。

顾沉舟把黑河回信交给修好蹄铁的急脚，报旧便道不能用，木管和种子仍待补；没有把宁川这一丈半硬路称成一州通路。他走到局门前，摸了摸门槛上新垫的废石，几个工人已经能踩着它不陷进泥里。

董成用完好的右手接过实工钱，问明日停工是否就从册上划掉。梁文指着医佐留的复查条，让他先治手，候工栏还在。丁六在旁边把空泥筐翻过来晾，没再拿红角票问能否抢先。

晚风里，宁川的水终于走向了石槽，车轮也有了可以试行的硬地。顾沉舟听见有人在屋里算补门槛还缺几筐石，第一次不是算要再付多少押费。

他能带回雁回的仍只是现场页，不是一座已经属于他的城。可当罗定问这趟留驻得了什么，他已有东西让人来看：人肯干下一天，粮不必随假旗走，水涨时也不必用伤者去抵。
