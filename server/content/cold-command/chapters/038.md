# 第三十八章 逆风出骑

第二声短哨落下，北门内的空车没有加快。

郑衡让两名营兵压住车尾，自己与另一兵护在车夫侧面。车上两袋草包没有粮票，也没有封泥，只为试行。四兵先停稳再推回，车匠保留关内轮痕，不能与墙外的槽印混写。

顾沉舟沿关内浅槽走了十步。槽底有碎冰，边缘留着新削木屑，铺木车夫还没找齐，暂时不知道是哪班修的。木屑带着旧松油味。他没有把它与旧车道新楔合并，只让陈二画下位置，取一小片交给北门哨长暂存。

“墙外有人看我们查车。”贺兰朔从北楼下来。他只叫来一名边骑，牵出灰马与另一匹营骑坐骑，“水槽两次响哨，旧堤却见伏身影子，可能是分路探关。”

罗定问：“几个人？”

“看不出。风把脚印吹平了，能确认的是两处伏身压雪，一处在旧阵地外，一处靠柳台。”

“那就不出骑。”谢无咎说。

贺兰朔没看他，先看向顾沉舟。顾沉舟知道这不是谁胆大谁胆小的问题。北水槽若有人盯着换岗，粮车若不出关，敌人只需继续让马印绕水，便能把雁回的兵耗在门内。可若贸然出骑，粮、马料和伤员处置都没写明，第一箭落下后谁也不能替军令补齐。

罗定命人把内坡的地图铺在车板上。顾沉舟先把今日的粮额写上：北门试行仍是两袋空草包，不动仓粮；若转为侦骑，另拨六斤干饼、两囊温水、八斤马料，返关前不得拆用余仓首拨。军医苏晚棠在旁边补了一行：若有人冻伤或坠马，轻伤入北门医棚，重伤由两兵护送，不让受伤骑手单独回马厩。

“兵额？”北门哨长问。

贺兰朔指了四个同伴：“我与一骑，郑衡带两名营兵。顾沉舟留门内，不随骑。”

顾沉舟没有争。他左肩不能硬撑，虎口也刚换过布，跟出去只能增加一个需要保护的人。可他把路线接过来，在图上圈出三处退路：水槽下游木管为第一收束线，柳台东侧旧堤为第二线，北墙外三百步木桩为最后回门线。任何一处被三名以上持械者堵住，或风雪让两队失去视线，立即退到上一线，不许为取泥印越过旧堤。

谢无咎看着五个人的名字：“五人能带回答案？”

“不带答案。”顾沉舟说，“只带回能复核的路线和人数。”

军令由罗定签出：五人，两骑三名步兵，干饼六斤，温水两囊，灰马和营骑各一，马料八斤另附草束；出北门沿西墙影至水槽下游，再转柳台东侧硬土，半个时辰内返北门。见三名以上同时张弓、发现车路被截、冰面裂至马蹄或任一骑手受伤不能独骑，即弃取证物，按第二退线回门；伤员由未伤骑手护送，郑衡与两兵接入医棚，顾沉舟只在门内复核人数与物件。返门须报三声短哨，再由墙哨认人，不能只凭声响开闸。

北门哨长在门簿上留了出门时刻。苏晚棠把两卷止血布交给郑衡，却没有把清疮粉算入这次路耗。药物各有去处，不能因为一趟骑巡便把医棚的缺口写成军需损耗。

五人出门时，风从北坡压下来。贺兰朔没有走昨夜马印最深的地方，而是先沿冻硬的车槽绕过水槽。那道选择让他们慢了半刻，却避开了风口中最容易被看见的白地。

顾沉舟站在门楼下，盯着两枚火把。火把没有举高，只在墙影里一明一暗。罗定没有调第二队出门，南墙的半队仍在岗，仓门和医棚各留一名见证。关里看似少了五个人，实际上没有为五个人再拆出一层空缺。

水槽下游先传来马蹄声，随后是短促的两声弓弦。门哨有人要开闸，顾沉舟抬手拦住。

“不是回门信号。”他说，“三声报回，墙哨还得认人。”

第三声没有来。北门外的风把声音卷走，远处却有一匹马嘶叫，叫声只响了一半便断了。

顾沉舟的虎口在木栏上渗出血。他没有去抓门闩，只让陈二把门内备用缰绳、担架和两盏遮风灯摆到顺手的位置。苏晚棠在医棚门口等着，先让药童烧水，不问伤势会不会出现。

片刻后，三声短哨从木桩间传来。郑衡步行冲进第一道木桩，腰间挂着一截断箭，两名营兵紧随其后。贺兰朔牵着两匹马落后几步，伤骑手伏在营骑马颈旁，右臂垂着。

“关门！”郑衡吼。

门哨落闸前，柳台方向又亮起三点火光。不是追兵的火把，更像有人在风里试着点燃湿草。罗定没有开弩，他先让两名营兵把伤骑手抬入医棚，另两人护住郑衡和贺兰朔退进门影。门外的灰马撞着缰绳，蹄铁边缘留下新鲜的白色刮痕。

苏晚棠剪开伤骑手的袖口。箭没有入骨，右臂外侧擦开一道长口，血已被冻住；若在马上再颠半刻，伤口会撕开。她报出止血布两尺、清水半盆、停骑至少两日，未报军功，也没有让伤员自己按印。

贺兰朔把一枚铜片放在门板上。铜片不是昨日骨牌，边缘刻着半道弯月，背面沾有松油和黑砂。他们在柳台东侧发现一辆倒扣的窄车，车底没有粮，只有六只空袋和两块削短的木桩。车旁浅槽指向水槽，和午前试行所见的轮距相近；但中段被风抹断，车是谁的、空袋何时装上，尚无仓门或民册能对上。

“追吗？”郑衡问。

“不追。”罗定答得很快，“先救人，封车，明晨带两类证据再查。”

顾沉舟接过话：“眼下只能确认柳台有人伏击侦队，是否故意诱我们过去，仍要查。车、空袋和木桩先留原位，铜片与断箭已带回。门簿能核出入，不能替空袋证明装过什么。没有车夫口供、仓票或沿途民册，不能写成劫粮。”

谢无咎走到门板前。他看见伤骑手被抬进医棚，也看见五人只带回一截断箭和一枚铜片，脸色比出门前更沉。“你们没有抓到一个人。”

“也没有让他们抓走一车粮。”顾沉舟说。

这句话不算战报。战报要等苏晚棠的伤情、关门哨长的门簿和贺兰朔的路线复核。顾沉舟让陈二先记六只空袋的发现位置，明晨安全复查再取，袋内残留的黑砂不倒出；老周先量关内浅槽，墙外车的轮宽由郑衡另记估值，不因尺寸相近就写成同一辆车。铜片交营门，断箭交骑军，伤情单留医棚，三处不由同一个人保管。

午后清点时，五人全返，两匹马齐；干饼耗四斤，温水一囊半，马料尚余六斤、草束未动，先前只在出门前喂过两斤。一名骑手右臂擦伤停骑两日，另四人无新增伤；灰马左前蹄轻微磨损，停役一日复查，营骑无伤。贺兰朔报称柳台火光三点、空车一辆、伏身压雪两处，不报敌人数目。

顾沉舟把未用的两斤干饼、半囊水和六斤马料交回原栏，未动草束退马棚。六斤干饼所用净麦已从今日二百八十斤日额拆出，不再额外扣仓；吃下四斤，退回两斤熟饼留作夜哨食。伤员的停骑不是少一个名字便少一份口粮，苏晚棠仍按伤情留出软食和热水。罗定在军令边上加写：两日内不得以伤骑补北门巡哨，替代者由内坡轮换，不从医棚抽人。

申时，谢无咎要求把白石回程票、首拨第四袋四两差和柳台空袋合成一份“外敌扰粮”急报。

顾沉舟把三张纸推回他面前：“白石收讫是已实收的旧债，回程三斤是新路食，四两是待查的袋差，空袋用途尚未核。几件事都在粮路上，却不是一笔账。”

谢无咎沉默许久，最终只取走柳台火光和伤骑军令的抄本。

关门外，风还在逆着墙吹。雁回没有追出去，北水槽也没有再响短哨。

可顾沉舟知道，真正的阵已经摆完。下一次若有人从风里来，想取的未必是粮，可能是关里每个人愿意相信的那一栏数字。
