# 第十四章 黑河营换防

卯时的号角比往日多响了一声。

黑河营北门外，旧队的旗杆已经降了一半。四十七名换防兵从雪坡上走来，六匹驮马在后，马背上不是粮，是军械、药箱和交接簿。带队的校尉姓许，年近四十，脸上有一道旧刀痕。他没有先向周校尉问候，而是先看营门两侧的雪痕和门哨人数。

“换防兵四十七，辅兵十六，民夫不随队。六马，药箱两，军械七架。”传令兵报。

许校尉抬手：“再报一遍，伤员几人？”

传令兵愣住。他手里的纸上没有伤员栏。

苏晚棠从门内走来：“伤员两人，都是冻伤，能行走，不能骑马；药箱一只封泥松过，另一只完整。昨日药耗另有一页，不在换防总簿里。”

许校尉看向她，接过药耗页，没有责她越级。周校尉走到旁边：“北原军医官苏晚棠，伤情和药耗由她独立签，不由营门旗手代写。”

许校尉点头，让传令兵把伤员和药箱补进交接纸。四十七名换防兵中，两人随军医入棚，剩下的人不许先去领粮。军营换防最怕先吃一顿再查人数，顾沉舟已经见过“人数少一名、粮却少一袋”的账。

陆承带门哨查旧队离营册。旧队本应四十九名换防兵，实际点名四十七，少的两人一个叫曹六，一个叫许三。周伍长说他们昨夜押送军械，稍后从南坡回；许校尉的名册却把两人列在“随队未到”，没有行程，也没有伤情。

顾沉舟站在一旁，没有把这两个缺名与陈六死录相连。军械、粮车和民夫不是一笔账，先确认人去了哪里，才能判断是否影响交接。

“旧队少两人，东仓今日的粮额按四十九还是四十七？”许校尉问。

秦百户答：“按军籍额。人没到不代表粮额能减，回来还要吃。”

苏晚棠皱眉：“伤员不能按军籍额抵普通锅。若两人途中受伤，医棚要预留药和粥；若他们已转调，继续算在黑河营便是重复。”

顾沉舟把这句话写到交接纸旁。粮额不能只随一个名册走，营门去向、军医伤情和军籍调令至少要有两份互证。

许校尉看向顾沉舟：“你是伙房的？”

“临代营内一段粮路。”

“那你告诉我今日该发多少。”

顾沉舟没有报一个总数。他先问人数：旧队留营三百零五口是否包含五名获救民夫，韩魁和赵七如何计；新到四十七名换防兵是否已入军籍；两名迟到兵是暂留旧队还是转入新队；医棚五名民夫的口粮是否由旧队承担到军法结项。

许校尉没有不耐烦，反而让书记把各项写成四栏：在营可食、伤情单列、临时留置、待核去向。这样一分，今日普通锅人数比旧额少，却多出新队的四十七份；总量反而不能按“旧队交、新队接”一笔冲掉。

秦百户把东仓出粮牌递过来：“今日三百斤，另给新队四十斤军饷粮。马料先不算在伙房。”

“新队四十七人，一人不足一斤？”许校尉问。

“交接日先按半额，明日再补。”

许校尉没有立刻接受：“半额是谁定？”

秦百户指向仓票：“转运旧例。”

顾沉舟看票。纸上的“交接日半额”与正文年号同墨，骑缝印却压在另一处，像是后补条款。它可以是转运旧例，也可以是秦百户为省粮留出的空口。顾沉舟没有说假，只请许校尉让书记查新队前一日的领粮记录。

新队来的十六名辅兵表示，出发前已领过一顿干粮，但每人只拿到半份，且没有按指印。负责发干粮的火夫不是随队来的，而是雁回站的人。这个口供不足以推翻半额规则，却说明“已领”并不等于“足额”。

许校尉让人把半额票暂列待核。今日新队先按四十七人实际到营、伤员分级和守夜需求发，缺额写在交接纸上；若后续证明雁回站已发足，黑河营再从明日扣回，不许用今日伤员份额冲抵。

秦百户脸色微沉，却没有阻拦。新队的带队校尉不是黑河营旧部，他若当众争，便等于承认半额票没有完整依据。

换防第二项是军械。旧队交出七架兵车，车轮一新一旧，其中一架车底沾着灰白草屑。新队的押车兵说那是北坡草场，旧队却说军械从南门来。顾沉舟没有把草屑直接并入粮车侵吞链，只让陆承在交接单上加“来源待核”，并按兵车编号封存一小撮。

贺兰朔尚未出现，边骑的草场知识仍由别人补不上。韩魁站在医棚门边看那车，左腕不能拉弓，只用下巴指了指车辙。

“北坡的草茎短，南沟的带盐。”他说，“这截没有白圈。”

顾沉舟记下韩魁的观察，却列作骑军口述。草屑实物、兵车路线和门哨车册要另互验。

临近午时，旧队的两名迟到兵终于回来。曹六是营门外伤了脚，许三则押着一辆空车，车上没有军械。两人都说昨夜奉周伍长令去南坡接人，却没有同一份口令。

曹六的脚只是擦伤，苏晚棠当场包扎；许三腰间有一枚旧铜片，半面“转”字已经磨平。顾沉舟看见铜片，没有伸手拼丁七的半枚印。他先问许三从哪得到，许三说是周伍长发的押运牌，领车时用来换空袋。

周伍长立刻道：“那是旧牌，营里多的是。”

“旧牌有编号吗？”顾沉舟问。

“无。”

“那就只能证明你们曾用过一块旧牌，不能证明它与丁七铜片同源。”

许三脸色变了，像没想到自己带回来的护身物也不能替他洗清。顾沉舟让军法书吏将旧牌、丁七半枚铜片和火场纸边分开封存，三方各写发现人。许校尉看着这套做法，第一次正眼打量顾沉舟。

“你们营里，一个伙房文书能碰这么多账？”

“他不能碰所有账。”周校尉答，“只能碰到他经手的粮和有人愿意让他记下的事。”

换防到午后才完成。旧队交出营门簿、东仓副簿、医棚药耗、军法留置和火场灰箱；新队各派一人见证。秦百户只交东仓副簿的抄页，不交原簿，理由是原簿属于仓曹。许校尉没有强夺，只在交接栏写“原簿未交，副页已交”。

这一个空白让新队的人都看见了。旧队没有因此停粮，许校尉也没有当场夺钥匙，但东仓不再能说“所有账都已换手”。

顾沉舟将自己的代领差条交给新队书记。明日六袋粮仍由他领，陈二继续报数，周顺不能取票，鲁安只做场边登记。新队四十七人加入之后，队伍不再是原来的十人两组，他必须重新安排搬运、火棚让道和夜哨干粮。

“你愿意继续？”周校尉问。

顾沉舟看向营门外。旧队的旗已收，新队的旗还没完全立直。许校尉没有把他当旧队的人，秦百户也没有把仓门交出来，苏晚棠的药柜又少了半匣清疮粉。

“继续。”他说，“但新队的粮要新队书记签，旧队欠额要旧队留下名字，五名伤民在军法结项前不能被两边推来推去。”

许校尉接过话：“我签新队的。伤民若是从旧押运案来，旧队先负责，军镇另核。你只管把两本名单分开。”

顾沉舟点头。第一次有人主动把责任写在自己名下，却也把新的四十七张嘴、两名伤员和一支陌生队伍交到了他面前。

夜里，换防后的第一声鼓从营墙传来。营门簿已经换了封，东仓原簿还在秦百户手里，火场灰箱则由军法书吏、医官和门哨三方看守。

顾沉舟站在伙房门口，忽然发现木板裂口旁多了一行新字，不是他的笔迹：

“先认人，再认袋；先认袋，再认路。”

他问老邵是谁写的。老邵摇头，说新队来的一个辅兵看了一晚搬运，拿木炭补上的。

顾沉舟没有擦掉。规矩若只能由他一个人写，换一个营官便会断。有人肯在裂板旁添一行，说明粮队开始把这件事当自己的麻烦。

他在新字下补了三格：书写人、见证人、实际执行。

第一格暂空，第二格由陆承按印，第三格写“明日六袋，三轮，普通锅减额，医棚十二斤，夜粮二十斤”。

雪夜换防完成，营中没有升起新的官旗。可顾沉舟知道，明日的粮若能在旧人、新人、东仓和医棚之间完整走一遍，周校尉才会有理由把“临代”写成正式两个字。
