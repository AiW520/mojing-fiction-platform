# 第六十二章 顾家门槛

二月初八午后，京城北门外的车队排到了石狮后。

盐篓、柴担、征马车各占一列，顾沉舟一行站在没有铺草的风口。八天里，七人吃完出关日用饼二十一斤，又凭驿条接了三十五斤，日用实耗五十六斤；应急十四斤封袋未开。骡豆料出关二十四斤、沿驿补四十斤，八日用尽，草、水按各驿实领记在旁边。人没少，骡没换，轻车右轮添了一枚新钉，钱从十二两路费里付。

石汊等渡借料实工八钱，后段驿粮、豆草补给一两八钱，补轮四钱，顾沉舟第五日肩伤复查、换布两钱，共三两二钱，余八两八钱。官定接续虽准领，实物仍凭驿回条结价，不是拿一张京营召书一路白吃。

门校翻到石汊停留那页，问：“急递药过去了，你们为什么没跟它走？”

“它走快马，人和轻车走官道。”崔岳答，“没有另令让它接卷。”

门校不再追问，把七人名录递回，叫他们到北城军驿，不许护兵混入京营兵册。城里已有校尉以为来了北原补兵，站在一旁等领人；得知只是查粮护送，皱眉走了。顾沉舟看见他腰间挂着一排待补军籍的小牌，忽然明白这里也有人缺兵，只是缺额写在另一套纸上。

驿馆接卷的青衣吏递来一张收条，标题是“北原查粮原卷”。

许简抱着木匣没有放下。

“是三包核过副页与封存目录。”顾沉舟说，“原卷还在北原。”

青衣吏解释，京营收卷先统编，明日问询再拆分。这里每天几十件卷袋，若逐件改标题，门外的人就要等到闭驿。

顾沉舟没有争标题本身。他请对方在收条背面加上三包的页数、外封编号，并写明未收原件。许简当面报数，库门守卒核封，青衣吏只需添两行便能放行。木匣进入文卷外库，两名护兵留守外廊，许简存接收副条；其余人进驿卸骡车。

不是所有麻烦都来自有人设局。有时一个懒得改的标题，就能让没到京的原账被写成已经收过，再让没有交账的人替它的失踪负责。

明日辰时到接问棚，先核名单和副页，十日问询自今日报到起算。顾沉舟记下这两项，才问能否到家人住处看看。

青衣吏翻出另一张便条。顾明夷前日来驿馆留了城南新住址，请弟弟抵京后转告。顾沉舟认得兄长的笔，地址却陌生。

“顾校尉说，你母亲已接来，旧家不在这里。”青衣吏道，“探亲可以，须报去处，戌初前返驿，两名护兵陪同，不携卷。”

顾沉舟将地址交崔岳。四护兵中，崔岳与一兵同行，另两兵仍守外库；许简留驿核副条，冯九照看骡车，共七人各有去处，没人替他从京营多要一队兵。原封应急饼十四斤交军驿核收，不带去家中。

城南旧坊的房子挨得密，一条湿巷走到底，才见到便条上的小门。门槛比老家那两间屋高，门上没有顾家的字，只挂着房东的退租木签。顾沉舟伸手敲了两下，里面响起盆沿碰灶的声音。

母亲开门时先看他的脸，随后看军服，最后看手。

“又破了？”

“没新破，路上换过布。”

她用湿手在围裙上擦了很久，仍没敢碰伤口，转身去盛面。顾沉舟抬脚过门槛，旧肩牵了一下，母亲立刻扶他肘下。他想说自己能走，话到嘴边，却只低声喊了一句娘。

屋里还摆着故乡那只缺角木盆。

腊月底被征走到现在，只隔了一个多月。正月中旬，顾明夷托人把母亲接来，为的是身边能照看；原城南两间屋没有卖，屋门交邻人照看，旧箱也随车带进京。顾沉舟不知道这场搬家。母亲的口信跟随北原驿递绕过换防，送到的是旧营，不是他所在的雁回。

“你哥说等你来，一家人再吃一顿。”母亲把碗推近，“可没说你要来答什么问。”

顾沉舟吹了一口面汤。他在路上已想好怎么答京营，看到木盆和母亲起皮的手，反而不知道该先问哪句话。

母亲给人浆洗的湿衣晾在墙边，新坊客少，挣得不如故乡，屋租却贵。她从床下摸出一张房钱条，想问京里有没有将洗衣钱押半月再结的规矩。顾沉舟刚要看，顾明夷从后院进来，按住了那张条。

“今日我会付。别让他第一次进京，就从家里替人算起。”

兄长披着京营旧短袍，腰牌是校尉的，靴尖也有湿泥。他比顾沉舟记得的瘦，手背一道新磨口，显然不是坐在暖屋里等弟弟回来。院外青篷车尚未卸，车夫正在核一筐菜与两袋家用炭，没装军粮。

顾明夷把一吊钱搁到母亲面前：“房租是我接你来时答应的，不用多洗衣补。沉舟的军饼也不能拿回家。”

顾沉舟看了那吊钱，问：“从哪笔出？”

“我的月俸，领过了。”

兄长从袖中翻出个人支钱记给他看，没有恼。顾沉舟也没拿它抄进查粮卷，只将房钱条还给母亲。家里缺钱是真的，军饼不是可挪的赏钱，这道门槛若跨错，明日就有人能拿一碗面让他替整车粮闭嘴。

饭吃到一半，坊里的催役人拍门。门外有人说顾校尉住在这里，这户便应先领两副运炭担架，明晨出两人到京营车场。对方拿的是坊总分下来的役签，分户姓名却没写，显然只知新住了一户顾姓人家。

顾明夷去门边，开口便要报京营身份。顾沉舟拉住他的袖子，将母亲的浆洗盆推回灶边。

“先问领的是哪户。”

催役人说坊内还缺六人，新搬来的先补。母亲见哥哥穿军袍，又见门外护兵，下意识要说自己能挑一担。顾沉舟先挡住她：“没人问过能不能做，别先把肩膀许出去。”

顾明夷将新户登记条取给对方看，现居一名老妇，两个儿子各在军籍，京营与北原所属分开；是否应役，要坊总按现住人口核，不是把两名今天陪同来的护兵也算进顾宅。催役人不肯收回空签，担心回去要自己顶。

“你带我们到坊总门口问。”顾明夷说，“该领的领，不该填的别填。你若只少一个回话的人，我陪你走。”

他真把袍子系紧，陪催役人到了巷头，没有让崔岳去抓人。顾沉舟站在门内，看母亲慢慢放下扁担。她习惯先答应活，怕一拒绝就失了住处；京里换一条巷，担子却还是能落在她身上。

半刻后，顾明夷带回役签的更正小页。坊总核过新户名录，暂不从这户补两名军籍儿子；缺额仍要另查，催役人也没被逼着自己顶。顾明夷把更正页放在家里，没有借亲属免役宣布全坊无需出工。

“边军里也这么问人？”兄长问。

“先问人能做什么，再给担子。”

顾明夷没有笑，坐下把已经凉的面吃完。顾沉舟看着他手背的磨口，第一次把这位兄长同京营那排待补兵的小牌连在一起。顾明夷要守的是城门，要付的是眼前房钱，并不是一句先保王朝便能替他办完。

临走前，母亲打开旧木箱，找出顾沉舟当年典掉砚台前留下的布套。布套下面压着一截旧车牌，受潮发黑，只辨得“黑河”两字。

她说不清何时入箱，也不能肯定是父亲放的：“搬家的人把散木也收在里头，你爹在家时，箱角就常有旧木。”

顾沉舟没碰。顾明夷说自己只在搬箱时见过，不知此前来源。两人的见闻不能补成完整年月，崔岳只从门边看见它今天在箱底。顾沉舟记位置，不取物，更不把木上两字接到父亲押运单上。

母亲见他退手，将布套单独递来：“这个总可以拿吧？”

他接下，放在自己的衣袋里，不与副页同装。这次没叫许简封存，布套没有被拿来证明谁的罪，只是母亲留给他的一件东西。

申末离家时，顾明夷送过门槛，问他要不要明日由自己陪到接问棚。顾沉舟没有急着答。兄长帮母亲付租，替新户核役，都是实事；但明日若让他替北原答问，这些好意便可能变成双方都收不回的债。

“你可以来。”顾沉舟说，“你的京营话，你自己答。”

顾明夷扣好腰牌：“我本来就没打算替你答。”

顾沉舟在戌初前返驿，崔岳复点，许简报三包外封仍完整。北城驿医按原伤情页查右虎口和左肩，限重不解除；苏晚棠还在雁回，没有一夜赶到京城替他挡问。

他把新住址、离返时辰、家中待核旧木分别记入自己的见闻页，没放进三关粮证。窗外有人为次日点名练喊，声音一遍比一遍整齐。

明日那张桌上，也许人人都有一半实话。他不能因为跨过家门，就替兄长补另一半。
