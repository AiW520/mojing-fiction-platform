# 第十二章 反查押运队

周伍长午后才回营。

他带回北坡六骑的马料回执，却不带钱二的领票。出仓记录写得很漂亮：补送豆料六十斤，北坡六马，八里往返，余料四斤。传令兵却另写了一行：实际到哨四十八斤，回程空袋两只。连这次补送也少了十二斤。

顾沉舟先看回执，再看空袋。袋底没有霉，绳结是双结，和西墙麻袋单套活扣不同；少掉的十二斤豆料不能直接接到粮案上。军法书吏把它列为马料案，暂不并入押运队。

“你倒会分。”周伍长把鞭子挂在腰后，“粮少一袋，火烧一间，若每样都分开，查到明年也查不完。”

“分开才知道哪一笔能互相证明。”顾沉舟答，“你先把北坡马料签清，再问账房火。”

周伍长没笑。他把押运队名册摔在案上，第一行是自己，下面六名押车辅兵，丁七在末尾，周伍长跟班周顺排在第五。顾沉舟发现名册上的墨色分成两段：前四人是旧墨，后三人刚补，周顺的名字压在一道折痕上，像临时添进来。

“这份名册何时补的？”

“丁七逃役后重抄。原册泡了水。”

“原册呢？”

“在押运车上丢了。”

“哪辆车？”

“南道那辆。”

“车在哪？”

“车散了，车夫也换了。”

每个回答都像一扇关上的门。顾沉舟不急着撞。他让陆承取营门离营册、征夫棚原册、押车单和事故簿，并排摊在桌上。丁七的出门条写“南道随运”，押车单五个指印没有名字，征夫棚原册写五名民夫仍在役，事故簿却把陈六写成坠冰。

周伍长指着事故簿：“尸体不全，谁知道活着的是哪个？”

陈六就在门外。他听见这句话，整个人晃了一下。苏晚棠没有让他进来，只隔着门问：“死者伤痕与陈六腕伤是否相同？”

“死者没留伤情。”周伍长答。

“那就不能拿死者身份替陈六认尸。”苏晚棠说。

她把医棚记录递给顾沉舟，记录上有五人的绳痕位置、冻伤程度和先后处理时间。五名民夫的伤虽相近，老人脚伤与石顺手腕伤并不一样。医官的记录不能说明谁写了死册，却能说明这五个人在夜哨救回时都还活着，并非一具不明尸体。

顾沉舟将医官记录和押车单分存，不让周伍长拿“人证”一词把两类材料揉成一句。

“你们押车从哪里接粮？”他问。

“东仓。”

“东仓哪一门？”

“西门小仓。”

“东仓有西门小仓？”

周伍长一顿，随即改口：“西墙外转运棚。”

秦百户在旁冷声道：“仓曹每日出粮的地点不止一处，文书不懂便别问词。”

顾沉舟没有看他。他让陆承取东仓出仓簿。簿上“西门小仓”只有三笔，均标粮袋四十斤，出仓人栏盖的是半枚私印，仓票栏没有正式号。两笔早于那车霉粮抵营，一笔就在乙袋出仓当天。

这个结果比一句“秦百户偷粮”更难处理。它证明一处不见于营门地图的出粮点确实存在，不能证明每一袋都被偷。顾沉舟请周伍长指出押车路线，再让魏三只看图不听他们互问。

魏三在南沟与西墙之间画了两条线。一条沿旧驿道，一条绕废井。他摇头：“运盐车走旧井，粮车若真从西门小仓来，应该先有黑河滩灰，不会从东门绕去南沟。”

“你亲眼见过这支押运队吗？”顾沉舟问。

“见过两次。一次是景和十六年，车上有盐票；一次是这月，天没亮，我只看见车尾和草茎。”

“你看见的是谁？”

“周顺在后面赶车。周伍长在前头骂人。”

魏三的话可以核周顺是否在车队，却不能证明他动过袋。顾沉舟把“看见车尾”“看见赶车”分开写，旁边注明光线和距离。

周伍长忽然笑了：“一个民夫看车尾，也能当证人？”

“不能单独当定案证人。”顾沉舟说，“但他讲清了自己看见多少，反而比一句‘我全看见了’有用。”

这句话传到门外，原本不愿进来的石顺也开了口。

“我们被绑上车前，周顺来过。他说脚钱已经从押运队结了。后来押车的人把我们的役牌收走，叫我们按空单。”

周顺脸色变了：“他烧糊涂了。”

顾沉舟问石顺：“你看见周顺的时候，什么时辰？”

“天黑一半。火在车头，照到他左手。他手腕有一道红绳。”

周伍长的跟班周顺下意识遮住袖口。苏晚棠却先问石顺伤势，不让一条红绳压过营医记录。石顺说完，顾沉舟才记“颜色、时辰、距离”三项，写上“待他证”。

陆承带来火场灰箱的清单。灰里两道蓝线粗棉，一枚烧裂铜扣，半截纸边。纸边残着一个“转”字，不能与丁七半枚铜印拼接。铜扣背面有押运队旧纹，纹路磨去一半。丁七被押回时肩甲缺扣，但营中许多旧甲也有坏扣，必须先查领用簿。

周伍长终于不笑了。

“押运甲扣旧了，换过很多。纹缺不代表谁穿过。”

“所以我不拿它单独认人。”顾沉舟把铜扣交陆承，“请军法书吏核谁领过旧甲、何时换扣。”

秦百户伸手：“铜扣是押运队军物，应由仓曹收管。”

陆承按住铁匣盖：“火场原物先由营官定保管。你若要领，写明物项、时辰和验后归还。”

秦百户看向周校尉。周校尉从帐外进来，先看顾沉舟的伤手，再看灰箱。

“原物分三处。铜扣给军法，纸边给营门，蓝线交医棚做纤维比对。顾沉舟只拿抄本。秦百户若要复验，明日辰时三方到场。”

苏晚棠没有把纤维比对说成能认出某人。她只说能比较粗细、染色和针脚，若样本太少，最多排除相同，不能证明同源。

顾沉舟听完，把“能证明什么、不能证明什么”分别写在纸角。周伍长看着那两行，脸色越来越沉。他没想到一个伙房文书会把每句话拆成半句，让他连喊“胡乱攀扯”都找不到完整的口子。

复核名册时，军法书吏在营门日册找到乙袋出仓当日的记录：“周顺辰初入营，奉周伍长令取空袋。”这只能证明柴车案当日上午他在营内，不能证明他昨夜进过账房。陆承将今晨的补条、前日的入门记录与钱二口述分别归档。

钱二的口供、周顺的领票、门哨柴票和乙袋实称，四项材料终于落到同一张图上：有人让一袋粮借柴车出营，失败后补条要销记录；但幕后是谁，仍需查周伍长、秦百户和转运棚的票根。

周校尉没有立即下令抓人，只撤周顺的领票权限，把他调到雪场搬石，仍按军法留下姓名和时辰。秦百户的仓门钥匙不收，东仓照常发粮，只增加陆承一名门哨在西墙值守。处罚不能替代查账，查账也不能把全营的粮停掉。

顾沉舟走回伙房时，陈二已经把明日六袋粮的路线画在地上。火棚清出一条直道，柴车改到午后，甲至癸的碗底字还在，没有谁用泥抹掉。

苏晚棠把一张新的药耗单递给他。

“韩魁的腕伤要再停两日。赵七的膝若三日内不消肿，可能留下跛。五名伤民里，老人退热了，但药布用掉两块。”

顾沉舟把医耗单和粮路单分开收好。他本想说好消息，却看见账房黑墙上残留的一缕烟痕。

火没有烧成大案，反而逼出一条旧出粮点、一份补写名册和一个已经被限制领票的人。可营里明日仍只有三百斤，押运队仍握着南道路线，周校尉也没有把秦百户的钥匙交出来。

他在伙房门后的木板新格里写下四个名字：钱二、鲁安、周顺、周伍长。旁边又写“待问，不定罪”。

陈二看见了，问：“要抓他们吗？”

“先让他们各自说清自己碰过哪一袋、哪一张票。抓人容易，粮路不能因此停。”

“那明日谁领？”

“我。”

顾沉舟把代领差条压在木板下。以前他只想把账上的少数找回来，如今却要把一支不信任他的粮队带过火棚，经过东仓、西墙和营门三道都有人能改字的地方。

外面传来门哨带周顺去雪场的脚步声。他尚未定罪，手上没有铁镣，领票牌却已留在军法书吏桌上。东仓有人看见，慢慢关上了门。

顾沉舟抬头看向黑河方向。父亲当年押的那一车粮，也许曾在同一处旧站停过，也许只是另一条被烧掉的路。残账没有给他答案，只把下一处矛盾推到眼前：转运棚的票根，明日会不会比账房的灰更早消失。
