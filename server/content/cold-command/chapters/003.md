# 第三章 伙房立规

秦百户离开后，东仓门上的铁链多挂了一把锁。

那不是封仓的锁，是防着顾沉舟再进去的锁。

午饭的锅却还要烧。伙房管事把三百六十斤麦分成三份，亲自守在秤边。守夜队先领，伤兵次之，剩下的按营兵、辅兵、民夫的旧例分。每个人端到手里的碗都浅了一截，没人说这分法公平，也没人能说出另一种分法为何更公平。

赵七拄着木棍站在队尾。他的膝伤已经肿起来，裤腿上结了一层暗红的血痂。苏晚棠还没来，伙房里没有能替他看伤的人。管事怕他倒在锅边，让人搬来一张矮凳；赵七坐下时，先把自己的碗推给旁边一个比他更瘦的民夫。

顾沉舟看见了，却没有把这一幕写成“赵七让粮”。他在记录上只记了发粮时刻、每锅下麦数和锅中可见的霉粒，另起一行记伤兵候诊。善意不能变成军需定额，否则下回管事便能说伤兵愿意少吃。

“你写得倒细。”管事瞥一眼小册，“能把粮写出来么？”

“不能。”

“那写这些有什么用？”

“明日再少一把，我能知道少在哪里。”

管事的嘴角抽了抽，没再接话。

顾沉舟把三口锅的余粮分别称过。第一口锅添水最多，霉麦浮在面上；第二口锅先熬了守夜队的稠粥，锅底粘了一层焦糊；第三口锅因火弱，比前两口晚了半刻。若只看锅数，三锅像是均分，实际到嘴的粮却差出许多。他将火候、加水和出锅时间也记上，伙夫看得直摇头，说他连烧火都要算账。

“账上不写火候，明天就会有人说是你们煮坏了粮。”顾沉舟说。

灶边沉默了一会儿。一个叫老邵的伙夫把烧黑的木勺放下：“前几日就有人这么说。说我们偷吃，才叫锅里没粮。”

“谁说的？”

老邵看了一眼门外，没报名字，只说是巡仓兵。前几日每锅领粮时，领条上写的是两斗，伙房拿到手的木斗却浅一指；他当时以为是旧斗磨损，没敢说。

这算不上证据。老邵既经手领粮，也可能记错。顾沉舟让他把所见写在纸上，注明是口述，不作为复秤结果，只请他在旁边按了指印。

有人问：“你这么记，能把少的粮讨回来？”

“不能。”

“那你还记？”

“至少能让下一次少粮，不再只剩一张嘴对着另一张嘴。”

傍晚，营门换防的旗手来取回执。顾沉舟将三栏复秤记录、伙房耗粮册和赵七伤情记录分开装入三个布封。封口各自盖了墨印，又请三名不同的人按指印：伙房管事、看锅的老邵、没有参与搬粮的民夫陈二。原始入库簿仍留在木匣，霉粒样本则以纸包封存，写明从哪一袋、哪个位置取出。

陈二不肯按印。

“按了，仓曹会记恨我。”

顾沉舟没催。他把布封推回桌中间：“你只证明今日日落前看见我封了这三份，不替粮账作证。若你不愿，另找一个没看过的人。”

陈二盯着那道墨印半晌，最后伸手按下指印。“我只作见证，不替谁说话。”

“正该如此。”

三份记录各有去处：营门换防官收一份，伙房账柜留一份，顾沉舟自己抄一份。抄本纸张不同，页边还记着原件封口的形状。要是某一份被拿走，另外两份不能冒充原件，却能证明原件曾存在。

他不相信自己能守住所有纸，也不再把希望押在某一个愿意说真话的人身上。

晚饭前，仓曹秦百户派人送来一张便条：次日辰时，伙房须按旧例领粮，不得自设新规。便条没有印，也没有来人的姓名。管事看完，脸白了几分。

“你看，规矩立了又如何？”他说，“他一句话就能让你明天照旧。”

顾沉舟把便条放在桌边，没有撕。“所以明天照旧领，但把每一斗都称给三个人看。新规不是不让发粮，是让发出去的粮留下数。”

“秦百户若不让称呢？”

“那就记他不让称。”

管事苦笑：“到时他们说你抗令。”

“那一行也一并写上。”

他没有权力命令仓曹，也没有正式批条。他能做的只有在锅、秤、领条之间建立一条小得可怜的线，让每一次经手都落在人名上。它不能立刻填饱所有人的肚子，却能拦住一句“向来如此”把缺口盖过去。

顾沉舟又把这条线拆成四个最简单的动作，写在伙房门后的木板上：领粮先看封，开袋先称重，入锅先记批次，出锅再对碗数。木板不写“不得违令”，只写谁在何时做什么；每一项后面留三格，一格写操作者，一格写见证人，一格写实际数量。

管事看完，皱眉说：“若三个人都在忙，谁来填？”

“忙不过来，就先停一袋。”

“停一袋，队伍要等。”

“等半刻，总比把缺口煮进三百人的肚子里强。”

老邵拿着木炭补了一句：若秤坏，先用标准米袋校准；若封泥碎，另取布封，原样不得扔；若见证人中途离开，离开时刻也要记。伙夫们起初嫌麻烦，真正照着做了一次后，却发现锅边争吵少了，因为每个人都能指出自己只经手到哪一步。

顾沉舟还让管事把当日剩余粮单独堆在墙角，不与新领粮混放。这样做会占地方，也会让伙房看起来更乱，但明早若少了一袋，至少能知道是昨夜的余粮少，还是今日的新粮少。管事没有同意得很爽快，只说若仓曹问起，便把这堆粮算在顾沉舟名下。

“可以。”顾沉舟说，“但要注明是我建议分堆，不是我私自添粮。”

管事怔了怔，第一次认真看他一眼。军营里许多人愿意担责，是因为能把功劳记在自己名下；顾沉舟却先把可能的误会写进纸里。他不知道这样能不能换来信任，至少不会让一堆来路不明的粮在夜里变成某个人的口供。

夜里，营中忽然吹起三声短哨。顾沉舟刚把抄本藏进木匣，老邵便从灶房跑来，说西门又进了一辆粮车。车上盖着新油布，车轮窄，辐条上挂着一缕灰白色的草茎。

换防官陆承此时才来送回收讫。他没夸木板写得好，先拿过领条，问四十斤差额究竟是秤错、粮少，还是两者都有。

“现在分不开。”顾沉舟答，“新米袋也不是官定砝码，三把秤互相验，只能看出不一，不能定谁准。我要借营门验军械的标准铜权，再验一次。”

陆承盯着他：“刚才还说少粮，现在又说不准？”

“先前的七斤半要标明所用秤，不能拿它定罪。锅里少发的四十斤，也要重验领粮记录。”

伙房管事脸上发烧。顾沉舟却将小册摊开，划掉“已定”二字，改成“待铜权复验”，旧字留在纸上可见。陆承看了片刻，叫旗手去取铜权，自己站在门边等。

铜权放上秤盘，三把秤都偏。顾沉舟和老邵用横梁校准第二把，连续换轻重两枚铜权，复验后才给它扎上白布。陆承只许这把秤用于伙房收粮，铜权不得私留，每日由门哨送来复验。

他在收讫背面添了一条：伙房交割可复秤，差额另报，不得停发已有净粮，不得擅开东、西仓。签字后，他把纸递给管事，不给顾沉舟。

“你用他算，就担起这口锅。文书若算错，你一起报。”

管事接纸的手抖了一下，终于把木板挂到领粮窗口旁。顾沉舟拿到了能用的秤，却没拿到仓门钥匙。明天他写出的每一个数，第一次有了人肯收，也有了人能追问。

“谁押的？”

“看不清。车没进东仓，先停在西墙下。”

顾沉舟没有立刻出门。他先让管事点清锅边余粮，请陈二把门口的领粮队引开，又把封存样本交给换防官代存。等这些事情落定，他才取了灯和一把木尺。

西墙边的车已经卸下两袋。车夫不在，守车的是个年轻辅兵，手里没有仓票，只有一张写着“交伙房急用”的短签。短签纸上压着转运司的半印，墨迹未干，落款却没有经手人。

顾沉舟没碰粮袋。他先量车轮宽度，再量两道车辙间距，随后把袋口、绳结和落地位置画进小册。

那名辅兵说：“都是粮，你还要量多久？”

“等一个能证明这车从哪来的人。”

“我就是送来的。”

“你能证明你把车送到这里。你不知道袋子从哪一仓出来。”

辅兵不耐烦地偏过脸。墙外风雪把车辙吹得发浅，灰白草茎却压在轮辐上，像从河滩一路带来的。

顾沉舟将这道新痕记下，没有写进账目结论。

他知道明早会有更多人催他把粮下锅。也知道只要一袋粮进了锅，袋口、封线和车辙就可能再也拼不起来。

这一次，他必须在开袋之前，把证据和吃饭的人都安排好。
