# 第六章 黑河夜哨

日落前，顾沉舟把丁七指出的北路画进值守图，递给陆承。

他没请求追逃兵，先指出一个空当：旧渡距北门八里，营哨换更时，前哨返营、新哨未到，中间有一刻无人照见废渡。

陆承看了很久，叫来韩魁。

老卒在边骑待过十余年，看图第一句话便是：“一刻够一辆车过，不够一支骑队过。要动，也是两三个人。”

“看车，不追远。”陆承定了范围。

夜哨四人，他领队，韩魁引路，老邵认袋，顾沉舟取证。营门另留正常守卒，不能为了查粮拆空北门。四人干饼共两斤，两囊水；驮马草料六斤，提前称装，归来补记余料。沿北岸至废渡，最迟子初回营。见三名以上持械者、冰裂或有人不能自行退回，立即回撤。伤者由驮马送回，苏晚棠在北门接诊。

军令由陆承签发。顾沉舟只在图和补给数后落名，没有把领队的位置写给自己。

老邵本不在哨卒名单上，陆承问他敢不敢去。

“打仗我不行。”他将火石收进怀里，“认咱伙房袋子的补口，十丈外也行。”

苏晚棠给韩魁一小包止血布，把顾沉舟虎口上的药布换紧，告诫他不要用这只手提重物。丁七留在医棚，两名门哨换守，既看伤也防跑，没人许诺今夜回来就能替他销罪。

戌初，四人出北门。

雪没有停，韩魁用短杆探路，叫他们踩自己的脚印。旧驿道旁有一条刚冻的浅沟，车辙进去后又上了岸。顾沉舟量轮距，找见左辙每隔一段便少一块浅印。

“缺口轮。”他说。

韩魁摸摸辙边冻壳：“可能同车。别只认轮，一辆旧车换轮不难。”

顾沉舟记下轮距与缺印，没有写车号。要认营门窄车，还得再看辕上油布的磨痕。

到废渡时，风压得河面低低作响。

渡口木桩上有新绑过的绳印，旧栈桥的板被拆下两块。韩魁没有上冰，只沿北岸找能走的硬土。老邵在木桩根找到一角麻袋，补口夹着三条蓝线，针脚斜，像驿站货袋，不像东仓惯用直缝。

顾沉舟用竹夹取出布片，由陆承封起。他们没有带半枚印来，营内原物仍由门哨与医棚交守，免得夜里丢了连根证据。

亥时，南面亮起遮风灯。

一辆车沿同一侧的河岸过来，离废渡二十余丈停下。两个人，一个控马，一个走到木桩前查绳。空铃被布裹住，只在车身震动时响一小声。

韩魁用手势压下众人。顾沉舟趴在雪窝里，看见左轮的缺口，又看见车辕油布上的斜裂。与今晨入门那辆一致的两处特征，终于在同一个物件上出现。

车上盖着厚毡，下面至少有三个人形隆起。

老邵低声道：“不是粮袋。袋子没这么长。”

走在前面的男子左耳缺口，头上缠蓝布。他从怀里取出牌子，递向控马人。两块铜片碰在一起，发出清脆一下。

丁七的口供对上了一项。

还不够。缺耳的人可能只是领车人，顾沉舟甚至不知道车上是活人还是尸体。

下一瞬，厚毡下面传来咳嗽。

控马人一掌拍向车侧：“闭嘴。”

陆承抽出刀半寸。韩魁按住他的手腕，指了指那只灯。灯油顺着壶口滴在车边，火苗被风一吹，已经舔到垂下的油布。

领车人也发现了火。

他没扑车，先夺灯，转身踢翻了车辕旁的木楔。车在斜坡上往河边滑，控马人想攥缰绳，被他一把拉开。两人往南跑，厚毡下的人开始叫救命。

陆承立即出声：“韩魁截车，老邵拿绳！”

不能追进林沟，却不能看着车落河。军令的限制没有替他们做这个选择。

韩魁绕上游抛绳套辕，马后退，绳猛地绷直。顾沉舟冲到车侧，先把毡子掀开。车上五名民夫手腕缚在一起，其中一个老人脸烧红，腿被捆在车架上。

老邵将空袋覆在火上，陆承割绳。老人挣了一下，车轮又滑半尺，冰缘响起细裂。

“别动！”顾沉舟按住老人肩头，“先松你脚，别人向岸上爬！”

他用完好的左手抓起车板，抬开卡住绳子的横销。陆承将老人拖上岸，另外四人顺着绳爬到韩魁身后。最后一人的脚才离车，韩魁左腕被绳拽得一折，脸色瞬间白了。

顾沉舟看见绳下还有两张纸，压在铁匣盖里。

他只取了能从岸侧够到的那张，没去够车底另一张。陆承喝令放绳，老邵一刀割开，半边烧黑的车滑进浅水。轮轴卡住河石，没沉，却再也不值得上冰取。

南边不见灯影。两个领车者熟悉河岸，已脱离视线。韩魁试着握拳，左腕抖得握不住杆。

“收队。”陆承说。

没人争着追。原定四人回营，如今带上五个冻伤、受缚的民夫，水和马都得先给伤者。老邵将自己的干饼掰开，分给还能吞咽的四人，老人不能进食，只用布裹好送上驮马。

顾沉舟的右手药布被挣开，血滴在纸边。他将救出的纸贴在胸前干处，用外衣挡雪。

韩魁走在后面，仍不断回头。顾沉舟要接探路杆，他没给。

“你能记路，不能探冰。杆给陆承。”

回程比来时慢。陆承换着扶人，将一名走不稳的民夫背过浅沟。到营门已经过子初两刻，门哨先问口令，再看五个新面孔，立刻敲响医棚的小梆。

苏晚棠在门内接人，先看老人呼吸，再看韩魁手腕，不等顾沉舟讲车和铜片。赵七被安置到靠里的铺位，没有被赶出去腾床。

“五人，一人高热，两人足伤，一人绳伤最深。”她向药童报，“韩魁腕部固定，三日内不许骑射。顾沉舟换布，放最后。”

老邵把剩饼、半囊水和两斤余草交回。粮耗按实际用了多少记，不要求救回的人再吐出吃过的饼。陆承将超时两刻、临时救回五人和韩魁受伤写入军令后，另报营官解释为何由侦查转为救人。

五人不能仅凭一句被绑就释放，也不按逃役打。他们由门哨分问姓名、来路，由苏晚棠留伤痕，再去对民夫册。

顾沉舟等手包好，才在灯下铺开那张救出的纸。

纸面有两道斜印，正文没有填一个名字，末尾却已有五个指印。上栏写“自行离营，工钱已结”，下栏列着役期三日、脚钱各两吊。

“人还在车上，钱就结了。”老邵喃喃。

其中一个年轻民夫忽然抬头：“那是我们按的。说进营领钱，先按押车单。我们不识字。”

顾沉舟没有急着写五人全供。他先让陆承把纸封住，今夜救人的事实与纸上结钱的事实分开去查。

可这一夜已不再只有一辆跑远的车。

五个活人带回来了，未填姓名的结钱单带回来了，缺耳领车人与铜片交接也有两人看见。车暂时卡在河石上，天亮才能由营官另派人安全拖取。

顾沉舟望向医棚里的灯。陆承走到他身边，把夜哨图交回。

“明早他们会问，你凭什么改了任务。”

“因为车上有人。”

“这句由我答。你把那五个人的粮先算出来。”

顾沉舟点头。新添五份口粮、医棚药耗、韩魁停勤，全都落到了明日，而那张已经结清的工钱单，必须在明日之前找到活着的证人。

回到伙房后，他没有把五名民夫直接记进“获救”一栏。老邵按门哨分问的姓名抄了两遍，一份交医棚，一份锁进伙房账匣；苏晚棠把每个人的冻伤位置、可行走距离和所需药布逐项写明。那名老人醒来后只认得自己的村名，认不出押车者，顾沉舟便在押车单旁添上“身份待核、伤情已核”，不让一张带指印的空单替五个人说完一生。

陆承还带回一个细节：车辕内侧刻着半个旧驿站记号，刻痕被新漆盖过，只有在火边才看得见。顾沉舟把它记入待查，不与铜片拼接。今晚救人换来的不是结案，而是五名伤民的口粮、药耗和一张必须找到对应民册的纸；每一项都要有人明日签收。
