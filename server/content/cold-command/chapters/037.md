# 第三十七章 破阵前的复秤

正月初八，白石驿棚的回车在日出前进了雁回关。

四名营兵冻得嘴唇发白，两名车夫把牛缰交给门哨，先递上白石仓曹和军厨的收讫页。二百斤旧借粮，四袋各五十斤，白石实收栏、复称栏和封线栏都有人按了印。粮已经留在白石，回来的只有空车和票。顾沉舟请罗定叫来仓兵、军厨和返关车夫，三处一起核回执，不把票面数当作又一批入仓粮。

“四袋交入白石仓时封线齐全。”车夫说，“今晨白石先给了六人的热食，三斤算在回程路食里，随空车回条结付。”

他把一张小票摊在车辕上。三斤麦，出白石驿棚的热锅，不是白石还给雁回的旧粮。顾沉舟在余粮栏旁另画一线：回程路食，三斤，未入仓，随今日二百八十斤日额核销。

谢无咎站在一旁，看着他把白石的票与雁回的借粮页分开。“你若把三斤并进二百，就能少写一张票。”

“少写一张，明日就会少一条路。”顾沉舟说。

谢无咎没有反驳。他让白石车夫先去军需房领脚钱，自己转身问贺兰朔：“水槽旁的马蹄印，昨夜有没有人动过？”

贺兰朔把一只裹着雪的木盒放在桌上。盒里不是箭，是从北水槽外取下的四块泥印。两块印边缘完整，蹄铁前端有一道新磨平的缺口；另外两块只留后蹄，深浅不一，像有马在原地绕过一圈再离开。

“六匹？”罗定问。

“只能确认至少三匹马经过，另外三道是同两匹马重复压出的。”贺兰朔答，“雪面风向从北转西，印子被风吹薄，不能拿深浅直接算马数。”

顾沉舟抬头看他。昨夜急报曾估作六匹换过蹄铁的马，如今泥印复核后，六这个数被收回了一半。贺兰朔不拿估计充军情，反而让人更难受。

雁回北门哨长把出入簿摊开。昨夜子时到寅时，取水车、送草车各进出一次，均有门哨见证；没有从关门去柳台的车辆记录。三名门哨的交班口供互不相同：一个听见马铃，两人只看见黑影。没有一份能单独证明骑手所属。

“他们若是来探关，为什么只绕水槽？”陈二问。

“因为水比门更容易叫人松懈。”顾沉舟答。

他翻开雁回水车的行路页。北槽接山溪，槽尾原有一截木管，关里水车只在墙哨照得到的石台装水。黑河那张轮水条远在另一座营，管不到这里。昨夜印子停在槽尾，没有踏上装水台，像有人专挑守军能看见的位置绕行。但也可能只是避开薄冰，单凭蹄印不能认定用意。

谢无咎用指节敲了敲案角：“那你要拿三道马印去发兵？”

“不。”顾沉舟把泥印推回北门哨长，“它只能证明有人探过水路。真正要查的是，今天运粮的车会不会被它引到北门。”

日头刚过墙垛，南坡的十二袋新粮开始复秤。六百斤首拨昨天入棚时，仓兵只抽了不同车上的四袋看干湿、虫痕和封线，其余八袋按交接条入干棚，尚未拆封。顾沉舟让罗定调来不经手昨日收粮的两名门哨，由军厨和仓兵三方开袋，每袋先在带白布的第二秤上称，再拿标准铜权校一次。

第一袋四十九斤九两，第二袋五十斤一两，第三袋四十九斤七两。第四袋刚挂上秤，袋底便漏出一小撮黑砂。

仓兵立刻说是北坡泥，车夫却说车板一直铺着草。顾沉舟没有用手捻。他请苏晚棠取洁净纸托住砂粒，记录袋号、位置和落下时刻，再请门哨把干棚门槛的泥样另取一份。黑砂与袋底湿痕分开装，不把颜色相近写成同源。

第四袋实称四十九斤六两。账上五十斤，少四两；若把黑砂当作损耗，便能顺手把这四两抹掉。顾沉舟让军厨拆开袋口内的缝线，发现外线是新补，里线却用过旧麻，针脚比同车其余十一袋密一倍。

“有人开过？”罗定问。

“只能证明袋口被重新穿过。”顾沉舟说，“还不能证明少的是谁拿的。先验袋，再验车，再查封存时刻。”

三类证据很快分开。仓门记录证明首拨六百斤于昨日巳时入棚；白石车夫和军厨的票只能证明二百斤还粮；干棚门哨则证明第四袋入棚后没有单独出门。黑砂的来源仍待验，四两差额列为待查，不许冲成护路损耗。

顾沉舟让人把第四袋原地立起，没有立即将散砂倒进样盒。袋底靠右的一片麻布比其余地方硬，像曾经沾过水又冻干；他先用木尺量出湿痕的长宽，再让仓兵从同一辆车上抽取一根未拆的草绳，放在旁边比对颜色。草绳上没有黑砂，袋底麻布却有两颗砂粒嵌进纤维，说明砂不是从干棚门槛一路滚上去的。这个结果只能把疑点缩到运输和装袋之间，不能直接认定有人换袋。

门哨说，昨夜首拨入棚时，他只看见十二袋同时下车；军厨说第四袋曾在车尾停过半刻，车夫则称那是为了让牛喘气。三个人的记忆互有差异，顾沉舟将停顿时刻另列口述栏，要求他们各自在自己说过的句子旁落印，谁都不替旁人补全。谢无咎看着这层繁琐，问他何时才肯下结论，顾沉舟只答：“等装袋、运车、入棚至少有两路能在同一处相遇。”

谢无咎看着一旁的余粮板。初四一千四百八十斤，四日已领一千一百二十斤，首拨票面六百入棚，归还白石二百，账面留七百六十斤。顾沉舟把“账面”圈住：旧粮一百六十斤可发，新批只认逐袋核验结果，第四袋隔离，其余续称，不能把七百六十全写成可用。今日二百八十斤内已留白石回程三斤，仓内实际需拨二百七十七斤；三斤另行结付，绝不再扣一次日额。

“账能对上，车却未必能走。”贺兰朔说。

他把另一块泥印翻过来。印边有一道细长的压痕，像是马蹄旁拖过车轮。那道痕直指雁回北墙外的旧阵地，不是水槽。

顾沉舟立刻让陈二去找车匠老周。老周看完旧阵地的地形图，只说北墙外三百步有一片冻硬的浅洼，车轮能过去，人在上面却容易被风雪遮住脚印。若敌骑先把马印留在水槽，再从浅洼绕向车道，守军便会以为他们仍在下游盯水。

罗定没有因此下令全关戒严。他让北门哨长把换岗提前半刻，水车照旧走西侧墙影，粮车则停在内坡，不出关。今日只做一次短距试行：一辆空车、两名车夫、四名营兵含郑衡，带两袋空草包，走北墙内侧三百步，测车辙和风口；不带真粮，不追蹄印。

准条写得很短：四兵两车夫，步推空车，不用役牛；在关内半个时辰，六人不误午饭，口粮仍在今日日额，带温水一囊，草包两袋只作载重。车轴断裂、外敌攀墙、风雪遮过标桩或有人切断内坡退路，立即弃车撤回。若有人受伤，先由两兵护入医棚，车夫不得折返取物。

顾沉舟看见自己的名字被列在“复秤与车辙记录”一栏，心里没有轻松。今日他既要盯余仓，又要保证试行不把人送到敌骑眼皮下。两件事都不能交给一句“应该没事”。

午前，四名营兵推着空车出内坡。贺兰朔没有随队，他留在北楼看风向，只让一名骑手在墙影里接应。车轮刚过第一根木桩，远处水槽方向便响起一声短哨。

北门哨长按住门哨的刀柄，没有开门追。顾沉舟蹲在车辙旁，看见风吹散一层薄雪，下面露出两道车槽。这里在墙内，昨夜的马印却在墙外，中间隔着关门，不能顺手连成一条路。

“车来过。”老周说，“而且不是一辆。”

顾沉舟伸手摸了摸冻土，指尖刚碰到泥，北楼上第二声短哨便响了。

他抬头望向水槽。那里没有马影，墙哨却指向一道被风拉长的黑线，正从槽尾指向关门。

“试行停，车撤回内坡。”他向郑衡报出车序，“先别让门外的哨子催乱我们。”郑衡复核罗定的准条，领四兵把空车推回，门闩始终未动。

空车回到内坡时，老周用炭条标出三个不同深度的轮印。第一道被晨霜盖住，第二道带新削木屑，第三道是今日试行留下的。三道印不能拼成一条路线，只能确认关内车路也曾修整。顾沉舟让车匠先问昨夜铺木的人，墙外浅洼则由北楼另画，不能因为都见木屑便当作敌人已潜入关里。

他回到干棚，把第四袋四两差额和木桩新痕分在两张纸上。粮袋的实物证据由仓兵封存，车辙与木屑由营门押存，白石收讫页则交军需房，三份材料不能因都指向北门便合并为“敌袭”。谢无咎最终在复秤栏旁写下“待查”二字，暂不准任何人用护路费或霜损冲销。
