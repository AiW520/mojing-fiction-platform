# 第十八章 苏晚棠的药柜

三日口粮清点后的第二天，医棚先断的不是粥，是药。

苏晚棠把药柜的抽屉一格格拉开，旧牌写着止血布七尺、清疮粉半匣、退热草九包，眼前的东西却铺不满半张桌。两瓶药酒已经结晶，她另摆在窗边，没有把空抽屉关上。

“药酒还能用吗？”顾沉舟问。

“能擦，不给内服。结晶不是凭口鼻能判断的，先封存。”

她把两瓶药酒放到桌上，又把一张药耗册压在瓶旁。册上记录着换防两名冻伤兵、赵七、韩魁、周文和五名获救民夫，共十人，前三日用药已经超过旧例一倍。不是医官多开，而是旧例把冻伤、颅伤和脚伤都写成“一般擦药”，一匣清疮粉便能在账上同时消失。

顾沉舟没有先问缺多少。他看见药柜旁挂着一张新写的伤情牌，十个人的名字分成四列：可走、停工、需观察、不得转运。陈六的名字单独压在最后，旁边标着“事故簿死亡、本人在棚”。

“今日药从哪一栏出？”他问。

“药从药柜出，不从粮锅出。”苏晚棠道，“你若把药耗混进伙房日报，我会把那一页撕下来。”

“我只想知道三日后八百斤粮到了，医棚要留多少。”

“那就先把能吃多少和能走多少分开。赵七若再搬粮，膝会留下旧伤；韩魁若强拉弓，腕骨会裂；周文醒着不等于能作证。你要的是口粮表，我要的是他们别因为一张表提前回队。”

顾沉舟点头，让陈二把医棚名单抄一份，只抄姓名、伤情等级、预计停工日和每日口粮，不抄药方。抄到“陈六”时，陈二的笔停住。

“这个人既写死又活着，算哪一栏？”

“两栏都不能算。”顾沉舟说，“先列临时留置，口粮照发，役期和抚恤另立。”

苏晚棠抬眼看他，第一次没有立即反驳。她拿出一只细秤，将止血布、清疮粉和退热草分别称量。止血布实际只剩六尺七寸，比药耗册上多写了三寸；清疮粉少了半两，退热草少一包。差额不大，却足以让军医署在三日后说“自然损耗”。

“你也要查我的柜？”她问。

“我查的是交接，不查你的医术。”

“药柜钥匙在我手里，谁都可以这么说。”

“所以要两个人见证。”

苏晚棠叫来药童和一名没有领药的门哨。顾沉舟不碰药，只读她报出的品名、单位和存量。药童按指印，门哨在封条上写时刻。结晶药酒与少出的退热草分别封存，不能因为数量刚好对不上，就把责任推给送药的县库。

门外传来脚步声。秦百户带着一名仓丁来取“伤员退粮折色”，手里拿的是一张没有医官签押的便条。

“换防日按半额，伤员的粮也该按半额。”秦百户说，“医棚少吃的，抵药柜的短缺。”

苏晚棠把药柜门一关：“伤员不是折色。”

秦百户看向顾沉舟：“你是什长，你说。”

顾沉舟把便条推回去：“伤情由苏医官列册，口粮按册发。药柜差额另查，不能拿人的一碗粥去填药材的半两。”

“那医棚的粮从哪里来？”

“从今日三日口粮表的医棚栏来。八百斤调拨若没有复核人，我会把医棚留量和新队普通锅分开写，谁要改，先签自己的名字。”

秦百户的仓丁伸手想拿药耗册，陆承从门外进来，掌心按住册角。“营门见证未到，原册不能出医棚。”

秦百户没有硬抢。他收回手，淡淡道：“顾什长，粮袋可以分栏，药材可没有第二座仓。药若断了，伤员还是要吃粮。”

“所以更不能把药账藏进粮账。”顾沉舟说。

秦百户离开后，苏晚棠把一小包退热草递给药童：“去找周校尉，请他补一张县库催药条。不是求药，是报存量和缺口。”

顾沉舟看见催药条上要填“预计伤员人数”。他提醒：“周文尚未醒，陈六的役籍未结，人数不能按死亡划掉。”

“我知道。”苏晚棠说，“医官的难处不在少药，而在有人希望我先把人写少。”

她把十人的伤情牌重新排过。可走一栏只有两名冻伤兵和许二；停工栏有赵七、韩魁和石顺；需观察栏有周文、魏大山和鲁五；陈六与陈六的事故簿分在两张纸上。每一栏都写了下一次复查时刻，不能因为今日退热便把明日的风险抹掉。

顾沉舟在伙房日报只记医棚十人、药柜缺口待补，另附苏晚棠的存量副页，不把药方混入锅数。那副页写止血布六尺七寸、清疮粉比旧存量少半两、退热草实存八包，两瓶药酒待验。缺口还可能是漏记领用，不能写成已经有人盗药。

午后，周校尉召集小军议，讨论西墙八百斤净麦的复核人。众人还没坐齐，苏晚棠先把医棚伤情牌带来，放在顾沉舟的配粮表旁。

“新队四十七人里两人已转医棚，旧册里还有八人。若西墙粮少一袋，先减谁？”她问。

秦百户答：“按旧例，各队均摊。”

苏晚棠摇头：“均摊会让发热者和冻伤者先少一口。先减临时加餐、再减未登记的预留，不能碰伤员最低量。”

顾沉舟把她的顺序写进军议纸，却补了一句：“这不是医官单方面定粮。若普通锅要少，必须让新队书记、旧队伙房和营官共同签。”

周校尉让军法书吏补上三栏：粮车实到、医棚留量、普通锅可动量。复核人暂由许校尉推荐一名新队书记担任，秦百户只能领受，不再同时复核。营门、伙房、转运棚各留副本，原表由周校尉封存。

苏晚棠看着新写的三栏，问顾沉舟：“你把药柜也放进制度里了？”

“没放。药柜归你，伤情归你。我要做的只是让别人不能用你的药耗去改我的粮额。”

“那就记清楚。”她说，“医棚的责任不是让伤员尽快回到搬粮队，而是让他们能在不被当作数字的情况下活着离棚。”

夜里，药童从县库回来，带回一张催药回执：止血布三十尺，退热草二十包，最快两日后到；清疮粉暂缺。苏晚棠把回执钉在药柜旁，又让门哨在旁边写下“未到，不得预支”。

她还把两瓶结晶药酒的封条换成双层：内层写取样时间和瓶号，外层由门哨记封。药童问为什么连一瓶不能内服的药酒也要这样麻烦，苏晚棠说：“今日不能用，不代表明日不能查。药材若没有来处，到了能用的时候也没人敢给伤员。”顾沉舟将这句话记进医棚与军需交接栏，免得有人把暂封写成废弃，再把瓶子从账上抹掉。

顾沉舟回到伙房，将医棚留量从十二斤改为十四斤，新队普通锅扣回转出的两斤。两名冻伤兵昨日只分次饮食，今日开始加软粥，这不是添两个人，而是改两人的锅。苏晚棠报伤情，陈二对名册，陆承核交料，三百五十二口的总数没有变。

顾沉舟在日报末尾写下：药柜存量已封，药耗与粮耗分账；伤员口粮按伤情调整，调整责任由苏晚棠报、顾沉舟发、周校尉签；陈六不以事故簿死亡冲销。

写完，他把笔递给苏晚棠。

她没有替他改字，只在医棚责任栏按下指印。

门外，西墙方向传来车轮声，却没有粮车入营的号子。八百斤净麦还在路上，药柜先用一张回执把两日后的缺口钉住。

顾沉舟看着那张回执，忽然发现自己已不能只守住秤。少一段布，会有人流着血等药；少一份软粥，会有人带着伤重新扛袋。这些人都在他的粮路上。
