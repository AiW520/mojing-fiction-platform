# 第三十五章 草原斥候

正月初七，天还没亮，北门守卒便来敲粮棚。

昨日顾沉舟在石岭上看见的三点灰影，今晨移到了柳台。离关只剩两里，三匹马沿一道旧堤散开，马背没有旗，右侧的骑手却把鞍袋摘下，伏在雪上看关门。

贺兰朔上楼，只看一眼便放下望筒。

“左边看南坡车口，右边看水槽。中间那个在数换岗的人。”

他没有说对方是哪一部，也不凭皮袍样式认敌。牧人会等门开，商骑会找避风地，这三人换了两次位置，始终把自己藏在门楼旗角下。关内人转身，他们便探头。

罗定要遣骑，顾沉舟却先去看门下。昨日借给白石的空车正候着入关，车板只有归车交接条，两名脚夫守着车，牛在冻地里跺脚。若边骑全从北门奔出，外头的人能数清马，也能趁门口变空探近车队。

“别让他们替我们选出门时辰。”顾沉舟说，“先把车收进侧门，核验队再走。”

白石押车人不愿下辕，怕入关后又被扣去拉粮。顾沉舟让陈二取还车条，当面核车号、轮箍与借出日。车匠老周看过轴榫，确认没有新裂，车仍归雁回，白石归还的是车，不是两百斤粮债。归车人领回自己的绳具，才放心让开。

这一刻，贺兰朔没有催。他盯着望筒，发现伏在雪上的骑手抬了一次手。外头确实在等门口动。

罗定批出八人：四名营兵含领队郑衡，两骑含贺兰朔，陈二与顾沉舟随行。温水两囊、当日份额中的干饼四斤，两马料六斤，草另束；到两里柳台，不越北侧旧堤，一个时辰回关。发现三名以上同时张弓拔械、归路受堵或冰层开裂即撤，不下背坡追人；伤者由两兵护回，陈二收人，物件可弃。顾沉舟只负责报距与车路，领队是郑衡。

苏晚棠替顾沉舟换了虎口的布，手指压着他左肩。

“今日拿杆可以，撑车不行。关里二十七名军伤、四名伤脚夫还等热水，别又借我的医车出去。”

顾沉舟点头。韩魁、赵七都留在黑河，雁回的伤脚夫也不补队。新伤若有，另记临时救治，不能凭一个人进棚就将四百四十八名在籍兵再添一遍。

八人过门，陈二报完名字，才把四斤饼挂到肩上。

柳台下面有一条浅沟，冬日行车绕其东岸，走人则可借旧堤省路。三骑正守在这两条路相交处。贺兰朔走上西侧硬土，另一骑守归路，郑衡让步卒沿木桩内侧前进，不把八个人排成给弓手看的长线。

为首骑手见他们来，先将马移到台背。另一人用马蹄踢掉了雪面上一根短枝，枝下露出三道平行的划痕。

陈二想过去看，顾沉舟用短杆横住他。

“台上没人，台后未必没人。”

三骑又动。左骑沿堤向东，右骑反向往西，中间那人仍盯着郑衡的步卒。不是逃，是要让两骑追两边，把步卒留在低处。

贺兰朔没有分马。他停在能看见归路的位置，把弓拿出囊，弦却不拉。郑衡将白布系上杆头，喊话问来路，要求三骑停在堤外。

中间的人抬手，帽边一束灰草结被系到弓梢上。

“阿赤部的停战结。”贺兰朔道，“认样式，不认奉命的人。”

对方用官话说自己从北草场来，来找旧水口。耳下白疤露在皮帽外，他又举出一块骨牌，正面半个月牙、三道短线，背面压着换水的凹印。

郑衡问姓名，那人只报一个“巴”音，又报腊月二十九曾在北坡旧泉换水。顾沉舟没有从随身抄本里替他补答案。黑河的水册原件不在这里，日期只是待查线索，不能因说得像真便让他进关。

“找水，为什么数门卒？”郑衡问。

那人不答，目光却移向他们背后。

关外西侧忽然响起木橇刮石声。一个老牧人拖着两捆草，正从沟下回走。北风吹得他看不见白布，直到左骑绕到前面才停。左骑用马挡住他的路，伸手要他腰间的木牌。

贺兰朔低声道：“那是雁回外棚的领草人。昨夜我看见他来领绳。”

认识人不等于能冲进三骑中间抢人。郑衡立刻向右移盾，令两兵占住旧堤入口，另外两兵护着陈二和顾沉舟。贺兰朔走硬土，马头始终不越桩，喊牧人把草橇停下，从台内侧走。

老牧人舍不得草，拖一步，木橇便卡一下。左骑见两侧都有人堵住，不再伸手，反而推马贴近木橇，想逼牧人绕到堤外。

顾沉舟看见橇绳绕在老人手腕上。

“松绳！不要拽着草走！”

老人还在犹豫，郑衡的盾先遮住他。顾沉舟用杆尖拨起橇绳，让他从绳圈里脱出；左肩没有抵上木橇，陈二接住老人，用自己的身体挡着他往内侧退。

三骑的弓终于同时离囊。

“撤！”郑衡喝道。

贺兰朔没有迎着三张弓向前冲。他的马横在步卒外侧，弓箭指向为首者胸口，归路骑手也张弓掩护。四名步卒两人面外、两人带牧人退，既不抬草，也不去取雪上那根枝。

对方得不到分散的目标，便没有放箭。中间那人望着关墙，似乎在等门里更多马出来；罗定始终只令门楼弩手备射，没有开门增骑。两边隔着旧堤退开，谁也没拿第一箭去赌第二箭。

回到半里木桩，陈二报八人都在，另带牧人一。老人手腕被绳勒出红印，没有破皮，能自行走。他一边喘一边要回去取草，顾沉舟指着两骑守住的硬土线：“人先入门，草另候。”

他把两捆草记作留台物，不先写被夺，也不说全关替老人赔净。郑衡认了今日救人的事实，罗定回来后还得决定如何回收和补偿，不由一名粮路什长随口给钱。

三骑没有追。他们从台后取回鞍袋，向北坡撤去。为首骑手临走，把骨牌抛到硬土上，伸出三根手指，再指旧水口。顾沉舟只让陈二画动作，不替这三根手指解释成三车或三百人。

西侧骑手走出十余步，又调转马头，沿沟向他们归路靠。那不是回来看牌。他若抢到木桩后，带着牧人的步卒就得横过低沟，脚慢一点便全露在弓下。

郑衡没有等对方到桩前，叫陈二与老人先走，两兵随护，另两兵用盾遮住沟口。贺兰朔向内侧移马，箭指着来骑的胸口，仍不脱手。另一骑手绕到木桩背面，握紧备用缰，没有冒进与人拼马。

顾沉舟瞥见桩下有冻裂的细线，陈二正想从那里省步。他用杆点向左侧硬土：“走车槽，别走白面！”

陈二换了三步，身后薄雪果然塌下一小块。老人腿一软，两兵扶着他继续往门影走，谁都没回头看洞有多深。左骑见归路已被护住，再贴沟只会面对两张弓，终于撤马。他不是不敢打，而是今日这点人手无法在雁回墙下拖住步卒，还要防门楼来箭。

等马影彻底离开柳台，郑衡才让外侧两兵收盾。八人的次序没有散，草橇和鞍袋都没能把人诱到台后去。顾沉舟想起黑河那次空车遇箭：这一次，谁先退、谁留后，已经不用等第一箭落下才争。

贺兰朔看了好一阵，确认三骑越过北堤，才和郑衡沿撤回线取牌。其余人在木桩内等，两人不越旧堤。郑衡用木夹收牌，牌槽里附着细红砂，连牌暂包，不在风里刮取；灰草结仍随骑手离去，只留外观记录。

他们回关时，门楼刚响第一次晨梆。八人出、八人回，牧人另列，干饼耗两斤，水一囊，马料回棚实喂五斤二两，余八两交回。没有新战伤，顾沉舟虎口在握杆时渗血，下午不准拿重物。

老牧人的领草牌由外棚管事核上姓名。他能证明左骑拦路索牌，不知道三骑所属，也没见鞍袋里装什么。关门观察的位置、三张弓的动作与他的亲见分开记录，足以列为斥候试探，不足以定整个阿赤部来犯。

罗定没有将三骑写成被击退的骑军。他让北门换岗改在门楼遮处点数，水车出门先走西侧墙影，外棚领草人暂停走柳台。草暂留，老人今日工食从外棚原额照发，不扣成没交物便没饭。

外棚管事还想扣老人的草钱，说东西没到就是没交差。郑衡把盾往柜前一放，先问今日是谁催他在开门前走柳台。管事答不上来，罗定便令暂缓扣钱，等木橇收回再核。老人不必先拿自家的羊换那两捆草，才敢把刚才哪一骑索牌、哪一骑绕路重新讲清。

谢无咎看着这三项改动，问：“派八人出去，只带回一块牌？”

“还带回一个人，也没把八匹边骑的数给他们。”顾沉舟答。

贺兰朔将望筒放回桌上。他不为没射箭辩解，只把三骑如何分向、如何等增援说了一遍。罗定当场留下北门半队作关内机动，没有让草原上的三个人替自己把兵调空。

晨光落到关门下，南坡已经能听见车铃。白石的空车收回，两百斤粮尚待送还；北门没有乱，今日入关的首拨粮却还在车上。

顾沉舟抬眼，看到税棚外新竖起一根横木。

昨日那里只有一张验票桌。今晨，多了一只收钱的斗。
