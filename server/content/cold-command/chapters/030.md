# 第三十章 立下军规

黑河营没有因为河坡小胜就多出一粒粮。

清晨复称，八十斤净麦实到七十九斤八两，车板雪水渗进袋皮，少下的二两暂列湿损；留在河坡的外袋仍有三十九斤九两，袋口被割、木签在侧，不能与营内七十九斤八两直接合成一百二十。周校尉让顾沉舟把三笔数写在同一张图上，却不准抹掉各自的地点和时辰。

“四十斤今天取回。”陆承说。

“取粮队几个人？”顾沉舟问。

“六名营兵、四名熟雪工、两名民夫，贺兰朔带两骑。你随队复核。”

苏晚棠在旁边摇头：“昨天陷雪的民夫不去。六名营兵里有手背伤的，也不能抬袋。”

陆承重新点名，补进两名在役营兵，另让两名民夫只负责绳具和标记，不碰粮袋。军令随即写明：八名营兵、四名熟雪工、两名民夫、两名骑手，共十六人；净麦三十九斤九两、空袋一只、长绳两根、木铲三把，带干饼五斤、水三囊和马料八斤，沿昨日退路到河坡，先救袋再查车辕，午前回营。冰裂、二次雪滑、三人以上持械或有人受伤不能自退即撤；伤者两兵护送，粮可留，空袋和铲具可弃。

顾沉舟听完，把两名只做标记的民夫从“抬粮”栏移到“证物”栏。他们没有资格称量，却能证明雪层被谁踩过、木签在何处。魏三被安排留营，负责把昨日退路画给熟雪工看，不能因为他熟路就把他再推上冰面。

河坡的灰烟已经散了。留袋的麻绳被冻在一截芦根上，附近有四种脚印：营兵旧印、袭击者短靴印、熟雪工昨日留下的深纹，还有一双只到河岸便折回的窄底鞋。窄底鞋不能直接认成持盐票的人，顾沉舟让军法书吏分别拓印，先取最外圈，再取袋旁印，避免踩乱。

外袋没有再被动过。刀口从侧面划开，麦粒散在雪下，已被水汽打湿，不能整袋背走。顾沉舟让两名营兵先从未受刀口的一侧套上备用袋，把散粮用木铲分成湿损、净粮和夹杂冰粒三堆；每堆都称，湿损不入常粮，冰粒等融化后再复称。没有人为了凑足三十九斤九两，把沾盐的麦粒硬塞回袋里。

“净粮三十七斤六两。”陈二的替补民夫报数，“湿损一斤九两，盐硬粒四两，剩下二两找不到。”

顾沉舟让他再报一次，听清后写下三十七斤六两。旧袋原实称三十九斤九两，差额两斤三两，不能直接说被抢，也不能全算雪水；袋口被割、麦粒散落、河坡雪层都要另待复核。

取粮队回营时，周校尉把三十七斤六两单独送进伙房，湿损和盐硬粒交军需房，木签、刀口麻绳和四种脚印交军法。八十斤营内净麦、三十七斤六两河坡净粮、四十斤原交接数终于有了三个位置，短缺不再只剩一句“路上损耗”。

与此同时，医棚里的袭击者已经能坐起。

他自称葛六，黑河滩盐户，去年冬天替转运棚赶过两次车。盐票牌是他从旧盐场捡来的，灰烟是同伴点的，不是他发令。军法问他为什么拦粮，他说今冬盐道被封，村里欠着军镇的折色，抢一袋粮能换盐，也能逼营里把盐道打开。

这不是一句供词就能结案。盐票牌的来源、同伴身份、旧盐场的出入簿和河坡脚印还没互上；葛六的伤情能证明他被押回，不能证明他说的每个名字。陆承把他的口供分为“亲见”“听说”“自辩”三栏，顾沉舟只取亲见部分抄入路线图。

贺兰朔把两枚从河坡取回的盐硬粒放在案边：“盐户说的是盐道，不是粮道。”

“两条路会交。”顾沉舟说，“但交点在哪，要看车辙和票。”

午后，周校尉召集营内各管事。不是为了让众人背一段口号，而是因为过去四次护粮中，没人知道什么时候该停，谁能叫停，停下以后谁补人、补粮、报伤。

顾沉舟把空车板竖在案旁，先说最短的一条：“见粮先认袋，见路先认人。未称不入锅，未核不出门。”

秦百户皱眉：“这算给仓曹立规矩？”

“给经手立规矩。仓曹有仓曹的钥匙，营门有营门的门簿，伙房有伙房的锅。”

陆承补上第二条：“出营车队必须有兵额、粮额、路线、时限、伤员处置和撤退条件。途中改路，原令不抹，改动人另签。”

苏晚棠没有站到顾沉舟身后。她把药柜前的三张停工单铺开：“伤员不补空。能走不等于能抬，能抬不等于能骑。伤情由医官定，口粮由伙房发，脚钱和抚恤由军需另算。”

贺兰朔在空车板上敲了一下：“骑哨只认风向和敌数，不替粮袋称重。护粮的人不能拿骑军的箭当自己的证。”

周校尉让书吏把这些话拆成四张执行牌，分别挂在仓门、营门、伙房和医棚。每张牌下面只留三格：经手、见证、实际数。没有写满“忠勇”两个字，却把谁能做什么、做错要报什么写清。

顾沉舟本以为自己只会得到一块新牌，周校尉却把西墙护粮筹办的木牌取下来，换成一块带营印的“粮路什长”牌。

“从今日起，营内东仓到伙房、西墙补给和护运民夫轮换，归你统筹。”周校尉说，“你仍不能开仓、越级调兵、改粮额；但车序、绳具、备用袋和交接副本由你先排。护粮出事，先找你。”

顾沉舟接牌时没有抬头：“西墙两顿粮的复核也算？”

“算。医棚新增伤员的口粮，也算。”

“雪场欠的石料和三名补岗民夫的脚钱？”

“也算。你若只管粮袋，不管粮袋旁的人，牌我今日就收回。”

这不是只增加权力的升任。顾沉舟的手里多了营内车序、民夫轮换和护运副本，也多了西墙断粮、伤员欠粮、役期和抚恤的先报责任。秦百户仍握仓钥，陆承仍掌营门兵额，贺兰朔仍掌骑军箭马，苏晚棠仍能因伤情驳回他的队伍。

顾沉舟把新牌挂上腰侧，先走到医棚。左脚冻伤的民夫今日不能搬，腿挫伤者停工两日，头伤骑手继续观察；赵七、韩魁和五名旧伤民夫没有被重新编进护粮队。苏晚棠把三日药耗单交他看，顾沉舟只核人数与口粮，不碰药性判断。

随后他去仓门，要求秦百户把待报损麦、结霜三袋和二百斤伪令待运粮分成三栏。秦百户没有立刻答应，只问：“你拿着营印，便能进仓？”

“不能。我要你按三栏报给营官。”

秦百户盯着新牌片刻，叫仓兵取来空白分栏纸。东仓钥匙依旧在他腰间，但待报损和待运的数字从今日起不能再混进总损耗。

傍晚，周校尉下令封存西北高地旧袋、盐票牌、葛六口供和河坡三十七斤六两的取样。军法司尚未复核，不许以今日小胜先换田、换官或私放欠饷。军功只记护粮、救人和追回粮的事实，等本人、营官、军法三方签押。

顾沉舟站在黑河营门，看见雪地上的车辙被新雪抹平一半。

卷二没有给他一支能随意调动的军队，只给他一条更长的粮路、四张会留下名字的牌和一批必须继续养活的人。西北高地的旧袋还没说明旧案，葛六的同伴还在河岸外，谢无咎的转运副条也没有消失。

但当夜换岗时，西墙火房和换岗棚各自报出余粮，营门、伙房和军法三份副本对得上。

黑河营第一次在风雪里守住的，不只是八十斤粮，而是一条有人能复核、有人敢叫停、有人必须承担后果的路。
