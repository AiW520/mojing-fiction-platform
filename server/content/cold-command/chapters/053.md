# 第五十三章 立屯田局

正月二十二卯初，南仓的门还没开，顾沉舟先在东门硬土上看见一排湿脚印。

脚印从井路拐出来，绕过何氏屋基，落到新钉的练车木楔旁。孟槐蹲下量了量，鞋底沾着黑渠泥，昨夜巡门的军兵都没有走过这里。他没叫人追，只让陈二记下位置，另取一撮泥封进小袋。

“有人在看这块地。”崔岳按住腰间刀柄。

“看地不等于要抢地。”顾沉舟站起身，“先把人和脚印分开。”

罗定的续留回条在他袖中，准到今日日落，只办桥路修护与转存交接。昨日他把申请一并送出，请军镇和县方共同筹办屯田转运，没想到县丞邢远一早带着县工曹、民册吏和一名印房吏赶到。邢远没穿礼服，靴边还带着泥，手里夹着三张空白公文纸。

“共同筹办可以。”邢远把纸摊在秤房门槛上，“但你不能另立衙门。宁川没有多一间屋，也没有多一份粮。”

顾沉舟点头：“立十五日临时局，只借人、借桌、借一间能见秤房的空屋。十五日后，按实耗撤牌，不留新印。”

邢远看他：“叫什么？”

“屯田局。职责只有清渠、试水、申请种子、记录工钱、维护转运路。不得征兵，不得占屋，不得改军粮额，也不得替县里收税。”

县工曹的吏员梁文把眉头拧成一条线：“清渠要人。河滩上五十七人，原先报可出工二十九个，如今还有停工伤者，脚钱和伤工谁出？”

顾沉舟把流民名册翻到伤病栏。二十九只是最初候工数，今日须减去停工、复查的人；伤病八、老人七、孩子十三不能补空。梁铁的名字旁还压着驿医的停重条，他把那条递给梁文：“先看活人还能做什么，再排活。医费先报南驿，工钱由县工曹和驿方各核已批的那一段，不许新局立一张总单就算付了。”

孟槐把两间破屋和六户井路的界线图压住：“住户界线由我管。谁要借屋，先问屋主；谁要挪井路，先让六户在场。军粮秤房的门钥匙还在仓兵手里，我只保屋门和民册。”

崔岳接过另一张纸：“连我四人，仍是罗定拨给的护粮勤务，不因屯田局多出一名。两名院兵留南仓，独立仓兵看三百斤转存粮。想添兵，另向营官报。”

苏晚棠不在宁川，南驿巡诊医佐由驿长安排。顾沉舟在纸上给医转单留出一栏：“伤工送南驿，医食另记，不从工粮里扣。梁铁右膝停搬重三日，周四旧掌伤仍停土工，这两笔不能由新局签成‘已复工’。”

邢远看完，把印房吏刚端来的印匣推回去：“先核借屋和料钱，没议完不落印。”

顾沉舟没催。他让陈二把四项账摆在同一张桌上：军粮、赈粮、工粮、种子。四本册子纸色不同，封线也不同，旧预留十八斤八两的工粮单独放在最下，不许拿来填今日续赈的缺口。

梁文问种子该报多少，顾沉舟却将空栏折起。宁川田界、水权尚未查清，黑河营三十六亩旧田的册子不能拿来填这里。他先请梁文拿出今天能运来的闸木，种子晚报，总比领来之后无处下地好。

正说着，盐铺的伙计从巷口钻进来，递上一张短条。纸上盖着一个宁川县印样，写着“南渠先放水，急洗落地盐二十斤”。伙计说盐车午后要过东门，洗盐的水若不先放，今日就要赔货。

邢远拿过短条，脸色沉下来：“印样像，文号没有。谁领出去的？”

顾沉舟把短条迎着光看了看。印泥边缘新，纸纤维却有旧折痕，落款处少了经手吏名。印样尚未验，内容也没核出处；盐铺说的是货急，不能把一张短条变成水权。

“先问印房。”他说，“落地盐带泥，不能洗白了就当好盐卖。货交县方另验，南渠也还没有能稳定放水的口。你说急，我先去看你们摆在哪里。”

盐铺伙计急得跺脚：“周掌柜说这是县里答应的！”

“周掌柜的口头话不入水账。”孟槐收走短条，“你若要申诉，留下姓名、货号和押金。”

伙计没有退。他带他们到渠边，已经搭了一道草帘，两个盐工把散盐装在破篓里，等着开闸。一名工人脚上的黑泥湿鞋印与东门那排近似；他承认清晨绕井路探过水口。孟槐只记本人认路，不凭鞋底就断定那张短条是他造的。

下游何氏家的井桶还摆在石阶边。盐工把篓往水里一倾，顾沉舟立刻叫停，梁文从岸上探水，发现浅槽尽头的旧堵板只剩半边。今日若强放，泥浆会先冲进井旁的低洼地，渠里有一点水，远不等于能替盐铺洗货。

伙计蹲下看那条低沟，终于把篓搬回。他原想保住落地盐的钱，如今知道若污了井水，赔的就不只一篓。邢远让县役封存盐样，派印房吏回查用印簿；盐铺留下货号和经手人，未核前不得出售。顾沉舟不用夺盐立威，先把六户人的取水路保住。

午前，邢远把公议结果带回：屯田局十五日，借用秤房旁空屋一间；军方由顾沉舟负责交接、粮路核对和缺口先报，县方由孟槐管民册与住户界线，县工曹管修料与料钱，崔岳管护兵，南驿负责伤工医转。每项都要有经手人，不能用“屯田局”三个字把人藏起来。

顾沉舟将临时牌挂上空屋门，却没有把它挂到南仓。县工曹从原候工册核出十名今日能做浅渠活的人，梁铁、周四、马六不在其中。陈二只报数，左臂不抬重。崔岳连三兵护桥与退路，另两院兵守门；罗定晨间补令准十人半日，饼六斤、水三囊，水漫过试板、墙土松动立即停，伤者送南驿。两辆空车暂不进场，闸木、四副铁箍按原修渠用途领出，不新增役额。

孟槐带六户井路见证人来查看。顾沉舟让他们从井口走到渠边，确认清淤线没压过屋基，也没把何氏的取水口圈进军方木桩。何氏看见界线留着，仍冷着脸：“借五日不是买下。”

“账上也只写五日。”顾沉舟答，“修料若损坏，县工曹另报；谁把借房写成军占，我第一个退牌。”

午后，清渠人从岸上取出堵板，浅槽里一股黑水突然往下窜。木匠已经安好一根闸木，另一根暂作旁挡，却被水冲得移了半寸。顾沉舟站在岸侧指向下游旧泄口，许木匠让工人缓抬旁挡，把水分往无人住的石槽；崔岳截住想跳下去顶木的青年，只准用长杆送楔。

水绕石肩退下，井旁低地没有被冲开。梁文量得浅水通过两丈，后段淤泥仍厚，不可进人，今日只算试出一段可控水路。两根闸木、一副铁箍已用，三副铁箍留料棚，河滩人亲眼看着水停在该停的地方，才肯把锹交给下一班。

一名木匠喝粥时伸开手，虎口没裂。他问明日是否还能来，顾沉舟请他先认今日半日工钱的经手人。午后实勤逐人报梁文，渠工粮从六十八斤支十斤，余五十八斤；旧预留十八斤八两未动，四兵另领的饼耗三斤六两、余二斤四两核回，水余一囊。县工曹没有多出一个空名字，也没让水走通两丈就算全渠竣工。

今日续赈二十斤仍由驿厨独立送到五十七人名册上，留医者接驿医份额，不在河滩再领。何氏先端桶从保住的井路过去，回来时才把旧凳借给空屋；临时局得了第一件家具，不是征来的。

罗定在申前补来回文，准顾沉舟延留至正月二十五日落，负责这段试水与转运，十五日局务不等于他能留十五日。空屋与秤房的借用分别续核到二十五日，住户界线不变，粮钥匙不交。新增的药布、闸木返补与工钱缺口，他须今夜先报；过期换人，不能拿局牌挡回营令。

申末，南驿急脚冲进空屋，脚下全是黑泥。他把一截折断的青旗放在桌上，旗边的针脚还挂着线头。

“有人打雁回关旗，拦了粮车。”急脚喘着气，“南驿赵贵受了伤，两袋粮被拖走，两袋陷进沟里。对方还喊军需借道！”

顾沉舟看了一眼屯田局的临时牌，又看向桌上的四本账。

天色已晚，罗定针对南线险情留下的副令只准现有护兵接应至南驿，不许夜里越坡。顾沉舟让崔岳先核伤员去向、传急报，自己将急脚带来的断旗交给仓兵封好。陈二留秤房，他不许宁川先填一张足额收粮页来掩住缺口：“今晚护住人和车。明晨天亮看现场，先记未交接，再谈旗是谁的。”
