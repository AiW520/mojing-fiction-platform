# 第二十三章 以水换马

贺兰朔进营时，没有旗，只有三匹喘得冒白气的马。

其中一匹黑马垂着头，骑手将水囊凑到它嘴边，它却只舔了两下。骑校尉从北坡下来，四个同来的兵留在门外换岗，自己把一张冻硬的马料单拍在伙房窗口。

“沙沟的车先别去拖。北坡坡口落冰，马也上不去。”

顾沉舟抬头。原拟的拖车令已经标成未执行，四袋麦和两袋豆料仍在沟边；陈九耳伤停重活，花额牛停役，若借北坡骑哨护车，还得替他们补岗。

“路封多久？”

“午后能从西侧绕，但要骑手先看。”

“有几匹能走？”

贺兰朔望一眼黑马，没有立即答。

马老汉牵它进避风棚，手背搭在颈上，查蹄、查套痕，最后看水桶。“不是缺那一把豆。今天喝过什么？”

“化雪水。北坡运水车陷了，旧泉不让军马靠。”

黑河营的豆料按马粮存着，不是人粮。给它多添两斤，不会凭空少掉伤兵一碗粥，也不会解决一整队马喝不上水的问题。顾沉舟把新添的饮水缺口写在草料旁，问旧泉在哪。

贺兰朔指营东一里半，牧户主槽冬季三日轮水，军马踩坏冰沿，后面数十只羊便不能喝。

“你们以前怎么借？”

“一桶一桶担。借多了，羊户要先补水。”

“那就先问能不能另开下槽。”

贺兰朔看着他：“我缺的是能巡路的马，不是又一张水图。”

“没有水，骑手借来也是半日。我要你的人替粮车看坡，你的人也得有地方饮马。”

周校尉召来牧户阿鲁。老人带两名年轻牧人，一进棚先看黑马口鼻，再看门外冻泥。他认识贺兰朔，却没有因为认识便把主槽让出来。

“一匹军马下去，十只羊都得等。你们明日要追人，主槽踏坏，后日找谁？”

顾沉舟把旧渠的尺图收起，不用另一条渠替这里认水。贺兰朔用马鞭画主槽与坡下的距离，问阿鲁可否接一条木管。

阿鲁指图下方：“那里有旧分水口，但冻住了。先掘出来再说。掘通也只能取轮到我们家的那一份，不夺其他户的。”

只借水还不够。边骑等不到木管全修成才能巡哨，阿鲁家却有两匹常喝泉水的壮马，冬天闲在棚里；营中六匹边骑马里，黑马与另一匹需要停重役休息，尚可照料，不能立刻跑长路。

顾沉舟提出换养三日。阿鲁将两匹壮马租给边骑，营方承担租价、草料与归还；两匹军马暂养阿鲁棚，仍按军马名册记，照料钱另付，绝不把有恙军马冒充同价好马。贺兰朔先让马老汉看两匹军马，需兽医复查，不强交牧户。

阿鲁沉默片刻：“你们取我的水，借我的马，拿什么还？”

“十二根旧木管，挖槽半日工，一日接管的脚钱，军马三日照料钱。租马的数请军需当面核。”

顾沉舟指向尚未到账的物料栏：“我不能拿明年屯田粟付你。今日营官批多少，就做多少。”

周校尉开军需柜，只拨出已实存的修管木料和一部分役钱，限额不足便不扩大开槽。雪场今日再少八人，石料要延一天；营方承担这笔欠工，不延民夫役期替它抹账。

勘水令随即写下：贺兰朔带四名营兵、八名民夫、药童与阿鲁父子三人，共十七人。六斤半军方干粮含八人三斤粟饼，牧户自带一斤半，温水四囊、两把镐、一辆手车；营东一里半，半日回，阿鲁不许便停挖，冰裂、壁塌、持械阻拦或有人伤重即撤，两兵护伤者回棚，其余收队。不带军马踩主槽，也不以羊马试饮证明水安全。

顾沉舟留营核领料，陈九和鲁安都未出队。魏三带八民夫其中一组，午后便从药童带回的话里，知道这趟活没想象的容易。

旧分水口冻成一团。阿鲁让人先清外层浮雪，再用木杖探冰下石沿。镐落下不到一尺，冷水便顺石缝冒出来，下面却同时滚出碎石。

一名民夫想趁水出来把堵冰全敲掉，贺兰朔按住镐柄。

“先退。那块石头不靠冰，还靠什么？”

阿鲁用杖点点外沿，两名营兵铺木板，魏三系绳。人都站到高处，才从侧面缓慢清淤，旧石槽露出半截，水线转向下坡，不再顶着羊群饮水处。

活到这里必须停。半日准条已满，木管尚未接，不许八个人因为差一尺便干到天黑。药童给一名手指旧裂口渗血的人洗包好，注明今日起不能抬重物，不拿轻伤抵工钱。

贺兰朔记下裂口、原水位和下槽尺寸，把工具与人一齐带回。

阿鲁后到营门，牵来了家中两匹壮马。马老汉看牙、看蹄，走了两段平路，没有隐跛。营方给租期三日、租价和草料，阿鲁认自己的水份不挪给旁户；若木管接成，军马以后饮下槽，主槽只供羊，毁槽赔羊价与修复工，赔付未发生不提前写已结。

两匹休养军马暂留营棚，阿鲁派长子来照料，兽医未看前不转移。军需书记将这笔照料钱与租马钱分开，马匹的所有者也未改变。

顾沉舟在脚钱桌前逐人报数。八个民夫各拿半日工钱，工食不抵役钱，镐磨损另记；魏三把钱数完，替手指受伤的人把绳卷好，没有再劝他忍一忍。

“换到了？”他望向两匹壮马。

“租到三日。接管的木料也出了柜，水还不能随便取。”

魏三看着原来只挂粮袋木签的门柱，头一次觉得护粮不止是十二个人。牛要休息，马得有水，牧户不肯挪自己的份，也不是故意与军营作对。

傍晚，阿鲁的次子带来一支旧箭。清分水口时，它压在石缝里，短杆削尾，箭头上粘白砂。

贺兰朔让他亲自说发现位置，再交陆承收封，不把它当沙沟弩箭。旧泉和沙沟相距数里，有砂的箭并不等于从同一只弩里射过；医棚所收上下游水样也只比沉积，不替箭认主人。

顾沉舟还在抄水份条，贺兰朔已经将新租的马试走一段，回来把缰交门哨。

“明日我带两骑，先上坡。”

“换哨的人呢？”

“新队补两岗，许校尉已准。别拿我一个口头说法，去把原门哨拆空。”

顾沉舟看他，才发现这人不是不知道调兵要粮，只是过去没有人愿意把同一张纸摊开问两遍。

贺兰朔将箭的副记留在案上：“水你要查，箭我也要查。别让人把我的马和别人的弩一并算进一笔仓损。”

夜里，营棚多了两匹能走的马，少了两匹被催着立即上路的马。今日六百斤接粮仍是四百入营、二百暂留，旧渠仍不通，牧户主槽仍未划给军方；事情没有全部解决，却有一笔交换真正落到了实物上。

阿鲁临走前又回头确认木管料。营方拨出的十二根木管只够先接四根，余八根要等雪场还料；他不许书记把十二根全写成已经架完。贺兰朔便在水权条上补了两行：四根先接下槽，取水量限两匹备用马和羊群轮次；余八根在材料到营后再接，期间不得把主槽改成军马槽。阿鲁按下手印，贺兰朔按下执行栏，顾沉舟在粮路旁记“水权尚在履行”。

两匹租马也不能立刻算作边骑战力。马老汉按每匹的肩宽、蹄温和旧伤记了三项，苏晚棠的药童在旁看有没有冻裂；贺兰朔只领三日巡哨权限，若兽医复查不合格，租马退回，不准拿租期剩余去凑军令兵额。阿鲁收了第一日照料钱，第二、第三日留待实照后再付。

顾沉舟把租马条、木管料单和八名民夫脚钱摆在同一张桌上，却没有合成一个“换水成本”。木料是实物，脚钱是役钱，租马是牧户交易；三笔都要找得到经手人。陈二核完后抬头道：“这样慢，明天沙沟的马也许还没水。”

“慢一夜，至少知道缺的是哪一项。”顾沉舟说，“快一夜，三样全能变成一句军需已结。”

顾沉舟将租马条压在沙沟地图边。

明日那两骑上坡，不是他喊来的奇兵。是木料、脚钱、水份、三日照料与四匹马各自的来处，一项项换来的。
