# 第六十四章 户部旧案

二月初十辰时，户部西库的第一辆移卷车已经套上了骡。

顾沉舟到门前时，只见车上木箱一层压着一层，最底下那只旧箱的铜扣歪着，半幅纸签贴在箱侧。典簿裴同正催守卒收门，见调卷牌来，先看日期，再看军籍。

“乙七卷要移往北夹库。今日看移卷目，原账改日。”

调卷牌昨夜才到，问询十日已经过去两日。顾沉舟若在这里等一趟改日，京营便能拿户部总账的旧结语先问罪，等他看到凭据时，答错的话未必还有地方收回。

他不许护兵去拦骡，只请许简把牌交到值库员手中：“请核到库时辰。移卷已经办完，我按新库去；还没办完，请把乙七送到阅案处，其他箱照常移。”

裴同四十余岁，袖口磨得发白。他指向屋檐上的湿痕：“昨夜漏了半间，四十六箱都得换地方。你要是占着一箱不放，后头谁替我看潮？”

“只要一箱。不拆其他封，不占干屋。”

值库员核过移卷簿，乙七确在今日清单，出库押尚未落。裴同没有谎称已经运走，他要的是把整车一次交清，不愿中途重新点箱。顾沉舟又看向车侧的纸签，上面写北原乙七，移卷簿对应的那一格却是乙十七。

“两只箱，还是一个号？”

裴同先没答。他绕到车后，发现夹在上层的纸签也写乙十七，铜扣和旧库存图相合。两个号在抄移时少了一笔，今日若照整车数交，北夹库会收两个乙十七，乙七则成了已经交出却谁也找不到的一箱。

车夫此时一催骡，车轮滚了半圈。底层歪扣撞到车栏，盖缝张开，一张潮纸从里面滑出来，被轮后风卷向排水沟。

“停车！”值库员喊。

顾沉舟旧肩撑不起箱，只退到柱后，让许简从干砖道上压住纸角，不往沟里扑。守卒塞好后轮楔，车夫牵骡退到另一侧，两名库役从上往下卸箱，没有在最底层抽出乙七，让其余木箱一齐落下。

潮纸接回时未沾沟水，边上已裂了一寸。裴同认出那是乙七随卷的旧驿灾册副抄，叫值库员摊到油布上。原封缺口、铜扣旧损和今日纸裂分别看验，今日裂口不写成旧卷本就缺页。北原护兵始终守在门边，没有接过户部箱钥。

裴同让其他四十五箱先上车。乙七另置檐下阅案，值库员与一名未经手抄移的库吏共同点页，两个相似的号终于各自有了去处。

“你救下来的是我的移卷差错。”裴同道，“不是你的旧案。”

“所以先把差错核完，再看旧案。”

箱里有春拨总账、转运补页、京存仓领抄卷和随案驿灾副册，军法押运单只有封案登记，没有原件。顾沉舟把父亲家中残账的日期写在另纸：腊月二十七，麦一百二十石。今日这箱是景和十一年三月春拨，一千二百斤，两者日期和单位都不同。

他不能因为看见黑河和失火，就把父亲塞进这一辆车。

户部总账写四车，各三百斤，拨出一千二百；甲一、甲二抵黑河，共六百；乙一、乙二随火尽，共六百。转运补页又列火后补粮三百，旁边只有付讫小印，没有承领仓号。

裴同看他停在补粮处：“旧年核作灾损，后来补过。今日若还要追回，先问谁欠。”

“先问补过的三百到了哪一仓。”

值库员展开京存仓领抄卷。入仓六百，车号甲一、甲二；同一记账区间，仓房支出一百八十，余四百二十。军厨留京的领料副页却只认一百五十，领受日期与仓房的三笔日支相同，差三十。

顾沉舟把两页推到一起，仓房三笔各六十，军厨三笔各五十，日期都在三月初八至初十。不是用整月领粮去比三日余额，也不是把余仓四百二十写成少掉的粮。医棚、守门和途中工食是否另领，那三十仍要查用途，今天只能说两处支领没有相合。

许简写完这一个缺口，裴同才肯取出原归档索引。春拨出车、补粮付讫、军厨留抄分别由不同人交库，三类页的收卷日也不同。三本总账若要联核，还缺军法司保管的押运封案及转运司原支领册，不能靠这一箱京存抄页就称三账齐全。

门外一名粮曹等不及，带着京营春练缺粮报数进来。他要户部先把旧补三百从北原下一拨中抵回，调给京营；调来新粮比另找商粮快，也能说是替旧案保住欠项。

裴同已经拿起付讫小印，准备将补粮那栏摘出。

顾沉舟问：“三百是尚未领，还是已领待追？”

“旧案总要有人接。”粮曹道，“京营今日缺的是真粮。”

“已领待追，就没有三百现粮在这间库。北原下一拨是现役兵食，先扣它，断的是今天的锅。”

粮曹并不傻。他将京营缺额页摊开，领食人数、今晨实余和应补都在，三百需求确有来源，不是自己多添的数字。问题在于他找不到新拨，只能从看似已经补过的旧项下手。

“你不让抵，从哪儿出？”

“那是今日拨粮的问，不是乙七旧账的答案。我不能替户部找三百，但可以证明这项不能算两次。”

顾沉舟请值库员把同案付款存根翻出。存根写的不是三百斤新粮，而是按当年麦价给付补运脚价及粮值，合算折粮三百；承领人只有驿交号，仓入粮仍空。总账的“补粮三百”因此不能直接读成另一车三百斤已经装在某处等京营来领。

粮曹捏住缺额页，许久没说话。裴同放下摘录印，叫吏员将现粮申请另送度支，保留京营今日三百缺额，不挂到北原现拨上。申请并未当场换来麦，可北原也没有因顾沉舟一句怕事的认可，被先扣掉还没出仓的一顿饭。

阅案处忽然暗下来，移卷车的篷布挡住了光。裴同催值库员收箱，那张刚救回的驿灾副册还没看。顾沉舟请他再留半刻，将册页与转运补页放到同一案面。

补页记三月初八“北坡乙二粮车焚毁”，灾册同夜记南坡空车翻覆，车辕裂，油灯碎，路面次晨清通。两处一北一南，一写粮车，一写空车，驿灾册未具乙二车号，不能证明是在说同一辆，也不能被总账概括成已经核明的那场粮火。

“灾册只管路，不清点军粮。”裴同道。

“所以拿它问地点和车号，不能拿它证粮多少。两页不合，先找各自经手。”

副册没有车夫姓名，也没有伤者转送、尸验或后续家属记录。顾沉舟没有往空白里补父亲的名字。那张腊月残账还在另一张纸上，今日春拨的空车仍只是空车。

他提出三件限期可办的事：留住乙七原箱与移卷改号记录；查补运款驿交号的承领凭；请军法、转运两处次日各携能出示的京存总账联核。不是给他库钥，更不是让一个北原什长去抓旧年经手人。

裴同想了想，给值库员叫来管库官。改号差错有两只箱签、移卷簿和独立点验，旧支领缺口有仓房与军厨两类页，调卷请求不再只靠顾沉舟怀疑。管库官准乙七留阅案库三日，今日不再搬往北夹库，明日联核文由户部发出。

顾沉舟也接下限制：次日午后前交出两张核见摘要，一张列数量与支领，一张列灾记日期、地点、卷号；漏抄、错抄由本人复问。原卷全部归库，他不带走完整账册，不能因此延长十日问期。

留箱的库役要把潮纸重新摞紧，裴同伸手挡住，让他先取两块平板。外面晒纸架还湿着，旧册不能搬出去吹雪，也不能靠炭盆烘。值库员在干台上拆开原有夹板，只将松开的纸平放，装订线不动，另把那张裂边的灾册垫在净布上。

纸背露出两处旧缝孔，与补页的孔距不同。许简正要记成后来插页，顾沉舟让他停笔：“可能另装过册，只记孔，不认何时。”

裴同望了他一眼，叫库吏取旧装册记。今日找不到，就留到联核问，不能因为顾沉舟替西库找出一次错号，便相信他此后每个猜测。那只歪扣也未拿锤敲平，先按旧损画下，再换外匣护住，原箱仍留。顾沉舟看着库役逐层接好，终于不用猜明日来的另外两处，会不会只看见一份已经摞成同样厚度的答案。

许简按准许范围誊出两张复核页，值库员逐处对原页。顾沉舟右虎口酸得握不住笔，最后三项由许简代写，他逐句口述核回，没有让肩伤换来少核半页的便利。

申初出库时，移卷车已经走了，乙七却仍在阅案库里。顾明夷在街角等到弟弟，将一只装热水的自用竹筒递来，没送一盏要军驿替他归还的公灯。

“有父亲的名字么？”

“没有。今天是春拨，不是腊月那车。”

兄长点头。顾沉舟饮了一口，将竹筒还回。他没有拿到父亲生死的答案，却从四十六只待移木箱里保住了该查的那一箱，也挡住一笔会让今日边军先饿的抵扣。

北城军驿的三包副页仍在外库，今日两张摘要另夹。夜间，户部联核回文到了，军法与转运各答明日携京存册到案，原押运单是否齐全仍待开封查验。

顾沉舟将两张纸放在空案上，第三个位置留着。下一次，不能再由一本总账替另外两处把话说完。
