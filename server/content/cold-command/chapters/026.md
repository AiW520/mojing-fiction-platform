# 第二十六章 伪军令

急条送到营门时，送信的人已经换了两次马。

他自称西墙传令卒，腰牌是真的，牌上名字却在换防副册里排到了五日前的旧队。陆承没有因为腰牌真就让他进内门，先叫门哨核身、搜出一枚冻硬的蜡丸和两张叠在一起的路条，再把人留在门房喝温水。传令卒急着说墙下有冰口、守军缺粮，越说越快，反倒让陆承把每句话按时辰拆开记。

顾沉舟在伙房里没有动四袋待运麦。二百斤净麦按四袋五十斤暂列，袋号、封泥、复秤人和可能领受人各空一栏；东仓来的净粮、医棚的软食、守夜人的二十斤夜粮仍分账。若急条是真的，缺口是西墙的军粮；若急条是假的，四袋一旦出门，西墙的门簿就能把它写成已经接收。

“你不出车？”秦百户站在粮棚外问。

“没有独立核令，也没有西墙回执。”顾沉舟说，“我只能封袋，不能替营官调兵。”

秦百户看向四袋麦：“墙上真出事，谁担？”

“所以要先问墙。”

这句话传到周校尉那里。周校尉准陆承派小队查验，但令上写得很细：两名营兵，陆承不随队，由老门哨带路；携一盏遮风灯、一根十五丈绳、两斤干饼和一囊温水，沿北沟外线至西墙，再从冰坎内侧返回，半个时辰内回报。不得带粮，不得追逐陌生人；发现冰裂、三人以上持械或伤者不能自行退回，立即退至烽墩，吹一长两短，等营门接应。若有人受伤，一人护伤、一人回报，放弃灯和绳也不能丢人。

顾沉舟把这份查验令抄在粮什牌背面，标明无粮出营、无新口粮消耗。两名门哨走前，苏晚棠给他们各缠一圈布条，药耗记作门哨查验，不并入医棚十人的伤情。

传令卒留在门房，听见没有粮车，脸色变了一下。他说西墙守军只有三十七人，今早冻坏两袋旧粮，二百斤少了便撑不过明日。

陆承问：“西墙值守有多少人？”

“四十七。”

“你刚才说三十七。”

传令卒张了张嘴，说自己听错。陆承没有据此判他作伪，只在口供旁写上两种数字，另请营门书记核换防册。数字一差，不能只靠脸色定罪，却足以让一封急条不能直接开仓。

半个时辰后，查验小队从北沟回来。两人鞋底结着白霜，灯油只少了一指。西墙守卒正在换火，冰口没有新裂，粮垛也没有塌；值守老卒说昨夜确实报过旧粮受冻，但只请补八十斤柴炭和四十斤净麦，军需副条在他的手边，未写二百斤，更没有“今夜三更”四字。

西墙的四十七人还在，急条上的三十七人却无处可数。

陆承把副条上的印拓、纸纹和送信急条分别包好，连同查验令的回执交给周校尉。顾沉舟没有因为四十斤真实需求就把二百斤急条全部说成假。他让陈二把四十斤列“待核补给”，把剩下一百六十斤留在封存栏，连西墙值守老卒的姓名也写进领受待签，不让一封假令抹掉真正的缺口。

秦百户的脸沉下来：“既然有四十斤缺额，为什么不先发？”

“因为西墙旧粮受冻的实物还没送回。”顾沉舟说，“先看袋况、实称和封线，再决定从哪一仓补。二百斤不能代替四十斤。”

他把三袋结霜粮的样本单独搬到案上。外层霜已化，内袋干燥，苏晚棠说可以分批复验，但壬袋六两差仍未解释。结霜袋、沙沟四袋和西墙十斤缺额有三条不同时间线，任何一条都不能替另一条签字。

夜色刚压过墙头，西门外忽然响起车轴声。

没有粮袋，只有一辆空车。车前四名营兵，后面跟着六个护运筹办的民夫，原本是陆承为查验小队准备的回收车，听见西墙无险后正要把空车带回。车走到北沟转弯处，坡上射下一支短箭，钉在车辕上。箭尾削过，羽片只剩三根，与沙沟封存短箭的形制相近，却不能凭形制认成同一支。

“停车，靠内线！”陆承喝道。

四名营兵立即把民夫收进车后，没人追坡。陆承让两人护住牛具，一人看西侧沟口，一人取下短箭；民夫只负责压轮和报人头，不许捡箭，不许越过冻坎。空车退回营门，路线改为北沟内线，半刻内到门下。受惊的役牛擦破一块肩皮，苏晚棠在门内接手，民夫无伤，护运名单按实回报，不把箭袭写成无事。

坡上没有第二支箭。攻击者知道车上无粮，射一箭便退，像是在试探营门会不会按急条把粮推出去。陆承派一名门哨远看，只看见三道脚印在沟口断开，脚印旁有一小片灰帽呢料。他没有追入黑处，命人用木桩标位置，等天亮再取样。

门房里的传令卒听见箭声，忽然承认急条不是他写的。他说自己在旧驿道遇到一个戴灰帽的人，对方给他蜡丸和急条，只让他把话送到，没说要害谁。灰帽是否同沙沟弩手所说的人，仍只有两段口供，不能合成一个名字；蜡丸里没有毒，只有一粒磨碎的黑盐硬皮，与南沟样本颜色相近，也可能来自路边盐碱地。

周校尉下令封存急条、蜡丸、灰帽呢料、短箭和查验回执，分别交军法、营门、伙房和医棚。传令卒暂留门房，先按送信役期供饭，不能因为说出灰帽就抵消他越级传令的责任，也不能把他写成袭击同谋。

顾沉舟重新点四袋麦。四袋仍在棚内，封泥未动，二百斤没有走出营门；四十斤真实缺额另立补给条，由西墙值守老卒、营门和军需房三方明日复核。东仓今夜没有开门，秦百户的仓钥也没有被搜走，谁也不能把阻止一份急条写成已经查清东仓。

周校尉还让人把四十斤补给拆成两份二十斤，标明一份给今夜守火、一份给明早换岗，避免把“西墙缺粮”重新写成一只没人负责的总袋。西墙老卒在领受栏旁按了手印，营门门哨在押运栏签名，军需房则把实际出仓日期留空，等三方明日当面复核。顾沉舟看着那三个空白，知道军令真正难的地方，不是写满，而是把谁还没做的事留在纸上。

陆承站在空车旁，看着车辕上的箭：“他们知道我们会按令配车。”

“或者他们只知道营里遇到墙上急报就会乱。”顾沉舟把箭包好，“伪令不是凭空造出二百斤，它借的是换防、霜粮和西墙十斤缺口。真事越多，假令越像。”

贺兰朔从北坡回来，带着两名骑手的风向记录。他看过灰帽呢料，又看空车上的箭痕：“今晚风从西北压坡，射手站在沟外，退路在盐白地。若追，马会先陷蹄。”

顾沉舟把西墙短牌、伪令和短箭摆成三列，没有把它们拼成一张认罪状。

“明日先复核四十斤，再查旧牌为何未销。”他说，“只要粮还在，敌人就得继续借我们的簿子行事。”

这夜，四袋二百斤在三重封记下留在伙房外棚。顾沉舟的右手虎口重新裂开，苏晚棠命他停写一刻；他让陈二代笔，自己只按左手印。没有一袋粮被劫，没有一个民夫被推去挡箭，可西墙的真缺额、旧牌的去处和伪令的受益人，都变成了新的账。

雪直到三更才停。营门外的脚印被风盖住一半，剩下一半正好通向西墙。

那半行脚印没有被写进粮耗。陆承只在地图上画了一个待查的叉，等天亮让门哨、骑哨和军法各自看一遍，再决定是否取土。顾沉舟把这件事记在伪令之后：急令可以封存，脚印也可以消失，真正能留下来的，只有不同经手人都承认过的那一小段事实。
