# 第三十四章 旧车轮的方向

正月初六，雁回关的雪停了半个时辰。

顾沉舟没有先去催雁回还粮车出关。他随郑衡领的六名营兵，带陈二和一名车匠到柳沟，贺兰朔与一名骑手护路。谢无咎所批只限查断铁箍、翻车沟和雁回至碎石岭的旧车方向，罗定另签勘路军令，日落前回关，遇三人以上持械、雪坡再滑或伤者不能自退立即撤；伤者就地固定，由营兵护返柳沟驿报关。

兵额六人含郑衡、骑手两人含贺兰朔、车匠一人、陈二一名，加上顾沉舟，共十一人；带干饼六斤、水两囊、木楔四块、空袋一只和一副备用绳。两匹战马出发前已吃关内晨料，马背各束半日草料，不拿人的路食喂马。没有粮车，不带仓钥，不把勘路写成押运。顾沉舟把这几项念完，两骑才分向前后。

柳沟的冰已经裂开细纹。初二救脚夫留下的木楔还在车槽边，翻倒空车被驿卒拖到高处。昨日送到关里的断铁箍由车匠带回核位，其余轮箍拆下后放在油布上。车匠老周先看断口，摇头说不是一撞便断，是内侧先吃了砂，铁箍在长坡上反复咬轮，最后遇到横冰才脱。

“砂从哪来？”顾沉舟问。

老周分别从车槽和铁箍内侧取泥，用不同纸包收好。车槽泥湿黑带碎冰；铁箍内侧的泥灰黄中有细白颗粒，像盐，却不能只凭颜色认成盐碱。

陈二拿出旧车夫的路线口述：“丁车夫说，车是从雁回回南，先下长坡，再到碎石岭。”

贺兰朔蹲在翻车处，没有接话。他用马鞭沿车槽量了四处印深，又指向东面一条被雪压住的窄沟。

“这里有第二道轮印。”

那道印比官道窄，车辙只在沟口出现，往东绕过一片乱石，便断在背风坡。若从雁回下南，车应沿长坡直走，不会先向东折。

顾沉舟让老周从车槽内、铁箍内侧和东沟三处分别取泥，标上位置，不许合在一包。他又让陈二去问柳沟驿卒，昨夜之前是否有窄轮车停过。

驿卒老赵说，初一深夜确有两辆车来过。一辆装空桶，车轮宽；另一辆没进驿棚，只在东沟停了一盏茶时间，车上盖着黑油布。车夫没有报关门牌，给了半块盐票，问东面旧水口怎么走。

“你看清人了吗？”

“只看见灰帽，个子不高。盐票半角缺口，我留下了。”

老赵从灶后取出一片旧票角。纸上有盐白硬粒。顾沉舟记得黑河葛六身上的南字盐票，但原件由陆承押存，随身抄记不足以比缺口。他只让老赵确认此物来源，把票角单封，留待回关查票号。

“为什么留票角？”郑衡问。

“车夫拿它付过路，不代表他押的是粮。”

“但他问了旧水口。”

“问路的人很多，先看车轮和水口有没有对应。”

东沟比长坡窄得多，车轮压过冻草，留下的印子时深时浅。贺兰朔与同行骑手在前，顾沉舟等人沿沟侧走，遇到一截被雪埋住的旧木桩。木桩上没有军印，只有一道横刻，像是给车夫记转弯用的。

木桩后面是废弃水口。石槽已经冻死，槽边却堆着三块新垫木，垫木上的雪被踩化过。老周试推其中一块，下面露出一道车轮刮痕，方向朝东南，不是从长坡来，而是从旧水口向外拖。

顾沉舟沿痕迹走了二十步，看见一处塌掉的矮棚。棚内没有粮袋，只有空麻绳、两个断木楔和一只被火烤黑的铁钩。铁钩钩尖粘着灰黄泥，和断铁箍内侧的泥色相近；相近不等于同源，顾沉舟让老周另取样，再把铁钩留在原位。

棚外忽然传来马嘶。

同行骑手从东面折回：“沟口有人。”贺兰朔随即勒马，先看退路。

不是草原骑军。四个身影在雪线外推一辆窄车，车上没有旗，轮子裹着麻布。见到骑手，他们没有冲，只把车头转向一条背坡小路。贺兰朔没有追进乱石，先让郑衡把勘路队退到木桩后，顾沉舟则盯住车轮。

“他们不是来抢我们。”陈二低声说。

“也不代表不会撞上我们。”郑衡把木楔握在手里。

四人中的一人扬声：“过路车，借道。”

“雁回关外军务勘路，车停在原地。”郑衡答。

对方没有停。窄车突然加速，两个推车人压住车辕，另两人从侧面掀起一块旧木板。木板下面没有箭，却露出一圈盐白泥和几捆空麻袋。

贺兰朔抬弓，箭搭上弦，却没有射。车后的两人见营兵靠近，猛力扯动牵绳，想把车头拖回背坡；车匠忽然喝住众人，指向侧轮底下的空雪。

“别挤！那是沟沿！”

窄车右轮先陷下去，前头的灰帽人被车辕带倒，半个身子滑向水口。顾沉舟伸手抓绳，右虎口立即渗血，左肩也撑不住。他放开短绳，踢出一块木楔，让陈二将备用绳绕在木桩上。郑衡留下两兵压车，另外两兵从沟侧拖人，贺兰朔下马拦住想跑的另一个脚行。

灰帽人被拉出时，第一句话仍是“车不能丢”。顾沉舟没有叫兵把车硬抬回来。先卸空袋，再用新垫木铺出轮槽，六名营兵分两侧稳住车辕。窄车退到实地，只裂了一块底板，四人没有摔伤；刚才还闷头推车的脚行这才肯松手站开。

他们没有持刀，两名领车人腰间各挂一枚短木牌。木牌没有关城印，只有“转”字半边。郑衡依军令检查他们是否携械，顾沉舟再把牌子、空麻袋和盐白泥分开收置。灰帽人自称脚行，不承认推过粮，只说替旧盐场运空袋。

“旧盐场在哪里？”

“东面。”

“那为什么从废水口出来？”

“水口近。”

这句话与驿卒口述能对上路线，却不能证明他们运过粮。顾沉舟让车匠检查窄车。车上只有空袋、铁钩和两块湿木，没有能还原重量的粮痕；袋底沾着盐白硬粒，亦可能是盐场旧物。

贺兰朔从车底取出一枚木楔，楔面有新削痕，与柳沟翻车断木不同。它只说明这辆车近期被修过，不能把四人和雁回破轴车合成一伙。

郑衡依勘路令的遇可疑车辆处置条款，带另三名营兵护四名脚行和窄车先返营门，注明“无兵器、无粮物、待核路线”，没有先写成劫粮犯。顾沉舟不替守将定罪。余下两名营兵、两骑、车匠、陈二与顾沉舟七人只复查木桩以内的东沟，不追窄车以外的同伴，随后也须回关。

太阳偏西时，东沟尽头露出一段旧车道。车道旁有三块倒石，一块刻着“水”，一块只剩半个“歇”，最后一块被人凿平。石下没有粮，只有一小撮麦壳混在冻土里。麦壳颜色偏深，年代不明；顾沉舟取样封存，没有与黑河旧渠麦壳土直接合并。

“车轮方向是东南。”贺兰朔说，“从水口出去，绕过关门，再接碎石岭。”

“这条路能避开什么？”

“关门税，或者关门盘查。”

“还可能只是避风。”

贺兰朔看向那三块倒石：“避风不用把车压进旧水口。”

回关路上，顾沉舟重新看断铁箍。铁箍内侧的灰黄泥、东沟硬土和窄车袋底盐粒被分在三只纸包里，不能凭相似颜色连成一条线；可四个脚行、半块转字木牌和东沟新垫木，已经足够证明雁回关外存在一条绕门旧车道。

谢无咎在转运棚等他。

顾沉舟先报人，再报车，最后报物：十一人勘路全数回关，四名无兵器脚行待核，窄车一辆，空麻袋六只，盐白泥两包，半木牌两枚；驿卒票角、车底新楔、断铁箍和各处泥样另封，塌棚铁钩留原位已标记。没有新增停工伤员，他自己的虎口重新渗血，仍须医官换布。耗干饼三斤二两、水一囊，剩余按实数回库，战马草料另报。

谢无咎听完，问的第一句却是：“你有没有把他们的车算成粮车？”

“没有。车空，袋空，重量无法还原。”

“有没有把东沟的麦壳算成旧案证物？”

“没有。只有发现位置和土层，不能证明来自哪一批粮。”

谢无咎这才拿起两枚半木牌。

“明日关门税开征。若这条旧车道真在绕关，先查的是车，不是人。”

顾沉舟看着木牌上的半个“转”字。谢无咎把勘路的权限收回一半，又把关门外的车路责任交给了他。

“我需要营门簿、盐票和旧水口的关防记录。”

“给你副本。原件由罗定押存，我的书吏留核过的副册。”

“还要一辆能走旧道的窄车。”

谢无咎沉默片刻：“可以，但车坏了算你的调度失误，车上若有粮，先救人再报损。你还要走吗？”

顾沉舟看向关外那道东南车痕。风雪正在把它填平，远处却有三点灰影贴着石岭移动。

“走。”

谢无咎收起木牌：“那就准备明日的关门税。”
