# 第三十九章 一夜三次鼓

正月初八入夜，雁回关北水槽先响了一声鼓。

鼓声不在关墙上，而在槽尾木管旁，闷得像有人用湿皮蒙住了面。北门哨长刚带人赶到，西墙外又亮起一点火。火光只闪了三下便灭，旧堤方向紧接着传来第二声鼓。

罗定没有让所有人奔向旧堤。他先把地图压在粮案上，问顾沉舟：“报数。”

顾沉舟看向门簿：“关内可动营兵六十七，南墙半队二十四，北门当值十二，仓门与干棚见证四，医棚守卫六。今日首拨十二袋已拆三袋，第四袋隔离，余八袋未开。白石二百斤已实收，返关只有空车和收讫页。”

“粮额？”

“今夜不动首拨余粮。北水槽查验队带干饼四斤、温水两囊；医棚照苏医官的热食和药耗另列。若需加灯，灯油从夜哨耗项出，不从粮袋里抹。”

“路线、时限、伤员处置、撤退条件？”

顾沉舟用炭条在图上划出三段：“郑衡带一名营兵和北门哨长的两名门哨，沿内侧墙影到北水槽槽尾，只查到木管止，不越旧堤。半个时辰回报。有人受伤，两兵护回医棚；冰裂、三名以上持械、火光逼近墙脚，立即退到北门木桩。南墙半队不动，仓门和医棚各留守卫。”

郑衡领命时，第三声鼓从西墙外传来。它比前两声更近，像敲在关门的铁环上。

罗定没有开西门。贺兰朔带一名边骑上北楼，只观察风向和墙外火点，不把骑军拆出去追。苏晚棠则点了医棚的伤员名单：右臂擦伤的骑手停骑第二日，四名伤脚夫仍不得抬重物，税棚脚行右掌浅裂，停绳两日；旧伤兵的软食和热水照旧，不能因为外头响鼓便减一顿。

郑衡一行出的是关内小门。门哨只开一尺，先认脸，再认腰牌，木门随即扣回。顾沉舟留在仓门和医棚之间，右虎口的布刚换过，左肩也不许用力。他让陈二守粮案，自己负责听三处回报，不替郑衡指挥兵。

北水槽的水声被夜风吹碎。郑衡走到槽尾木管，发现管口旁插着一截裂木，木上刷过松油，油痕还没有干透。门哨在裂木边找到半只鞋印，鞋底钉痕只有外半圈，无法判断是军靴还是民鞋。另一名营兵从槽下捡起一撮黑砂，砂粒粘着细细的松油。

“带回去？”门哨问。

“原位封样。”郑衡答，“砂先不刮，木片和鞋印各画位置。”

他们没有追向旧堤。那里正有火光第二次亮起，火光后还传来一声马嘶。贺兰朔在北楼看见那匹马，却只见到背影，不能据此写成六匹换蹄马再临。

关内的鼓声忽然从西墙传来。顾沉舟听出鼓点比刚才快了半拍，像有人故意把三处声响排成一条线。他没有让北门哨长调兵，只请罗定把干棚门旁的两名仓兵换到粮案边，医棚再添一名不带刀的守卫。

“他们想让关里自己把守点搬空。”顾沉舟说。

罗定点头，却不问他是不是敌袭。“守点不动，查证物。北槽那队若半个时辰不回，才按堵路处置。”

远处传来短促的喊声。苏晚棠已经让担架停在医棚门口，烧水的人把火盆挪到入口，却没有派药童出关。伤员的处置先留在关内，不能把救人的人也送进黑暗。

郑衡一行终于回到小门。北门哨长先报四人无伤，郑衡再把裂木、半只鞋印的位置图和黑砂封袋交给营门。黑砂封袋外写“北水槽槽尾，正月初八戌初，郑衡、门哨同见”，没有写来源判断。

顾沉舟展开位置图。裂木靠水管东侧，鞋印在西侧三步，黑砂却落在木管下风口。三件物证相近，却不是同一只手留下的证明。鼓声、火光、马嘶也只能确认有人制造了分散压力，不能直接认定有人准备劫粮。

“旧堤要不要查？”谢无咎站在粮案旁问。

“今晚不越界。”罗定说，“火光已经灭了，越夜追只会让人把我们引出撤退线。”

谢无咎望向窗外：“若他们趁我们不动取水呢？”

顾沉舟把北水槽的图纸推过去：“取水车今晚照旧走墙影，只到石台，不去槽尾。车有门簿，水有经手人。真有人动过管口，明晨能用新鲜痕、木管内壁和出入簿三处互校。”

谢无咎没有再催。他让军需房把灯油余量报来：今夜两盏遮风灯耗油一升半，另有一盏备用未点；损耗单独列入夜哨，不从首拨第四袋的四两差额冲销。

丑时，旧堤最后一次亮火。火光贴地掠过，像有人拿着湿草从雪上拖行。贺兰朔在北楼看见两道影子沿柳台退走，距离太远，只能报两人，不报坐骑数。罗定仍不出骑，只让门楼弩手保持半箭上弦，南墙半队继续轮换。

天将亮时，顾沉舟去看仓门。第四袋仍在原处，封存线没有断，黑砂和差额各在小匣里。六只空袋和倒扣窄车也没有被转移，封存木牌上的时刻未改。仓兵冻得手指发僵，仍把未拆的八袋逐一数出袋号，没有因为一夜鼓声便提前开袋。

苏晚棠从医棚出来，报右臂伤骑手无裂伤，仍须停骑两日；税棚脚行掌伤未渗血，今日不能拉绳；四名伤脚夫一人夜里发热，药耗退热草一包，软食另拨。她把药柜的减少量写在自己的册上，要求顾沉舟只签领料交接。

顾沉舟在夜哨页末写下结果：北水槽未失水，仓门未失粮，医棚未抽空，南墙未撤班。代价是灯油一升半、干饼两斤、四人夜查役时，以及一名伤骑手继续停骑。没有追击，也没有把三处火光写成一场已经结束的胜仗。

夜查队的靴底还带回一层薄泥。郑衡先在门槛外停住，让门哨把四人的鞋底分别拓印。北水槽附近的泥偏灰，西墙内沟的泥带细砂，二者没有一双完全相同。若把鞋印擦在一张纸上，便能人为造出“同一队人三处来回”的假象。顾沉舟让营门把拓印和位置图分柜存放，连门槛上落下的泥也不扫，等日出后由车匠辨认是否是昨夜新落。

郑衡又报，裂木旁的鼓皮碎屑只有三粒，鼓槌没有找到；北水槽下游的水面浮着一层松油薄膜，宽不过两指，可能来自裂木，也可能是旧木管渗出的油。苏晚棠取洁净瓷片盛样，封口写明水面位置和取样人，不让顾沉舟把油膜直接算作有人下毒或堵水。水车今日仍需取用，罗定命人先在上游另设临时取水点，等军医验过下游样本再恢复槽尾。

这一下让今早的水量少了半车。顾沉舟重新计算伙房和医棚用水：锅灶不减，清洗伤口的水优先，马厩只给现役马饮用，备用驮马延后一刻。贺兰朔听完没有把马料挪来换水，而是让骑手去内井挑水，脚钱和役时分开记录。没人因此多拿一袋粮，关里却要付出两队人半个时辰的搬运。

罗定看完，准明晨查验柳台倒扣窄车。查验队须带两名营兵、一名门哨、贺兰朔和顾沉舟，兵额、路食、路线、伤员处置与撤退条件另行列令；顾沉舟只做粮袋、空袋和车辙复核，不越旧堤，不动外车。

天光穿过墙垛时，北水槽恢复了水声。槽尾那截裂木仍插在原地，像有人故意留下的一根钉子。顾沉舟看着它，没有拔。下一次要先把钉子周围的雪、车辙和人的脚印都留下，才知道谁想让雁回关在一夜里听见三处鼓声。
