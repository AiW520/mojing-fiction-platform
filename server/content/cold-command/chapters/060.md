# 第六十章 一州粮路

正月二十九卯时，宁川秤房门前摆开六袋粮。

顾沉舟没有站在第一辆车旁，而在门洞转角看昨夜水尺。浅槽水退了半指，六尺路中间仍有一条软泥，昨日等载石试过的硬边能走，窄口不能会车。梁文查闸木与补箍，县役查借路时辰，两名仓兵各拿一页袋号；四名护兵领罗定新令，崔岳领队，三兵分前后警戒。

两车夫牵来两辆复检车，一辆换了裂挡板，一辆旧钉伤已修。六名自愿健脚工只控坡、看轮，不成新军籍。今日每车至多轻载一百斤，共运宁川三百斤，分两轮出；第一轮四袋先入南驿干棚，空车折返接末两袋。遇水过轴、弓手或桥脚裂响即退干台，伤者由南驿医佐接，护兵不追坡外。

仓兵剪开的是今日获准调运的封线，不是顾沉舟的排程牌。六袋逐袋查干湿、杂物、封泥与净重，三百斤可用麦重新分两袋一组，旧封样单存。另一项甲九、甲十合九十九斤四两仍在南驿，单号不同；甲七、甲八继续隔离，不用新袋遮掉泥污。

谢无咎昨夜另下正式调拨：宁川三百斤入南驿后，其中二百斤转雁回，一百斤留驿作已核接车周转；事故可用粮九十九斤四两单存待调，不混作四百斤整数。雁回不是凭这二百斤吃满五日，它只是今日首段补入，后续各站仍须报实际余粮。

第一轮在晨雾里过了门洞。昨日日光下好走的路，此刻表面结着薄白霜，车夫用探杆敲碎硬边，健工先铺粗草防滑。顾沉舟将第二车压在门内，等前车尾绳出了窄口才放行，没人喊着赶吉时。

韩守义站在自己的地边，没再架栅，却叫了一名伙计来问何时准商车走。他不肯认输得毫无收益，既然路不能收钱，便要趁粮车证明安全，抢第一辆商货。

“两轮军粮之间空车要回。”顾沉舟告诉他，“你若压住转角，两边都不能动。申时以后县方复检，商车按货号另排。”

韩守义看着车上的两袋麦，终究将自家牛绳挪到界内。他有典地，可以等货，不能再拿一张真契把整条粮路吞进去。

午前，头轮二百斤到南驿，仓兵独立复称足数，留两袋作转雁回，另两袋暂置已核干台。回车刚过桥头，北坡来了一辆窄车，车旁三个人，前头那人举一张急条，要求先领周转粮。

不是周全。这个人穿短褂，自称转运脚行接手，急条上的地点却还是北坡；他要领一百斤，却没有今天的调拨号。南驿驿卒认识其中一个车夫，正是前日自愿留问的脚夫。脚夫摇头说自己只被雇来赶车，不知这张条的来处。

顾沉舟让仓兵守门，请短褂人到侧棚等复核，没有扣车。对方看见轻载回车便笑：“你们两辆车来回磨，一袋袋过，今日能送多少？我的车能载三百，少走两趟，谢使君等得起？”

“今日该去哪里，有今天的令。”

“牌是真的，粮也是真的，还核什么？”

他将一枚铜牌拍在桌上。驿卒看过牌号，脸色变了，想把旧牌与周全留存原物拿来叠在一起。顾沉舟拦住，两物分别留位，由县役画牌号，仓兵另查本次出库页。牌是真是假要验，今天有没有领粮权却不必等牌色磨完。

复核拖住的不只是对方。两辆回车已到桥头，顾沉舟若把四兵全围在棚里，宁川最后一百斤就得无人护运；若先走，短褂人可能趁仓门交接抢闯。他让驿卒当众关粮棚门，独立仓兵留守，护兵仍按原令护回车，不为一张旧牌扩出新兵额。

短褂人忽然推开问话的县役，向棚门冲去。他身后一人伸手拉车辕，想用窄车顶门。崔岳先将县役拖离轮前，一兵用盾隔开推门者，另一兵守住车夫；第四兵拦退路，让旁观的两名孩子先走。没人追进北坡。

窄车右轮压上沟边，车夫见地软立即收牛，短褂人却拔出一把削绳刀，割断驿卒刚拴的挡绳上股，下股被拉得吱响。顾沉舟退到柱后，喊车夫松尾，别往车前拽。尾绳一松，车辕偏向空场，不再正顶棚门；崔岳用盾压住持刀手，另一兵卸下刀，短褂人被按在硬地。

县役右肘擦破，一名护兵小腿被车辕撞青，没有人死。自愿脚夫主动离开牛头，将缰绳交车夫；他没有跟着冲门，也没因此被绑成同伙。三人的动作由不同位置的人分别说，刀、绳断口、铜牌、急条各留原物，不能拿冲门事实替代旧旗案结论。

邢远的值役随后接持刀者与涉推车一人，车夫先候问，未定其知情；伤者到医棚，停当日推拉，替换护兵由南驿请罗定准一名现役营兵轮换，兵额仍为四。没有替换到令前，回车停在硬地，顾沉舟自己不补进护兵数。

转运棚回验在这时抵驿。牌号属旧批借领，周全原牌归还记录仍待查；本日该号无新增调拨。谢无咎的真实新令只准三百斤按宁川、南驿、雁回路线走，未准北坡接手。县方以冲门持刀现场和今令、出库页互校办新案，不凭一处残字把周敬、周全和雨沟半票全连起来。

顾沉舟看着那张旧号急条，终于看清这一次争的不是一百斤值多少。只要粮棚认旧牌不认新去处，一百斤离了门，便能在下一站变成另一张“已收讫”，路上还会有人拿同一号再领。自己给出的图要能抵住这种车，才算粮路，不是彩墨画出来的愿望。

轮换兵到令后，两空车返宁川。末轮一百斤在申时入南驿，六袋复称足三百。两百斤转雁回的车早已依罗定接驿令另派四兵及车夫，不从返宁川队再抽人；其余一百斤留独立干棚，伤医车优先出窄口。顾沉舟等到南驿收讫，再随核回空车返关。

到雁回时，二百斤麦已经摆在西灶后棚，仓曹与灶头各认袋号。罗定没让顾沉舟报“一州粮足”，只问：“下一场雨来，今天的图还走不走得了？”

顾沉舟摊开三处图，硬路用实线，待复检用断线，北坡争牌与污染粮都标在图外。孟槐管房与民册，梁文管桥渠，仓兵管封袋，车夫轮换、南驿接伤、每日二十斤赈急各有去处；缺木、旧医欠、借梁返补与种子则仍是未结项。

“雨前先查水尺，窄口不能会车。两辆车坏一辆，就减半轮，不征伤工顶上。宁川不是整城军仓，险梁仍封。”他说，“这条路能送粮，但不能把没走通的地方写通。”

今日两轮工粮六斤，余十七斤二两，旧十八斤八两独立。六健工、垫料、修绳实费一两五钱，新伤医费三钱，修路款余二十四两五钱；借梁返补与车板争议不在这笔内。路饼八斤耗六斤二两、余一斤八两，水四囊余一囊，牛料十二斤耗九斤余三斤核退。五十七人赈粮与医食按原册另出，没拿军粮收讫充领粥页。

罗定把图推给谢无咎。谢无咎看过三处实秤与门簿，终于划掉提案上的“以城抵军粮”，改成“借节点转运”，允已核屋租由原转运杂项另拨，不强令韩家或六户拿地抵粮。屋主、孟槐与县方各核续期至二月初五日落，借屋有了下一段期限，顾沉舟本人却没有自动多出七日权。

他的三日牌在案上被收回。罗定准新粮路提案报军镇，待核后才能升任；今晚他仍是什长，不掌州印。但南线排程不再等他的私人口信，由县役、仓兵和当值营官照已核图接下，每日交接错一项，下一轮先停。

顾沉舟第一次觉得收回一张牌也是回报。明日若他不在，六户不会再靠他守门，伤工不用追他要钱，车夫也不必问他一人该去哪里。

夜更时，一骑从南门入关，驿封外写着京营查粮。谢无咎先看封号，随后将未开的内封推到罗定面前。来使只点名顾沉舟，须待军镇核令后启程，携南线图及三处副页赴京。

罗定没有当场让他上马。顾沉舟也没伸手拿原粮簿，先把手里的路线副图放回案中。

城外最后一辆空车正过关，轮声清楚，车后没有被征来的伤工。谢无咎低声说：“你让他们不用再找你，却让京里开始找你了。”

顾沉舟抬头望向那道未开的驿封。宁川、南驿、雁回的三处粮，今天终于各自到了该到的地方。可北原只是大雍的一条边线；他若想看清父亲当年那辆烧毁的粮车，就得去见那些从来不用在泥里推轮的人。
