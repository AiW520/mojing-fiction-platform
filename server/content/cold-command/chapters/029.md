# 第二十九章 黑河小胜

天刚亮，西北高地的风还没有停。

周校尉没有让人直接去挖雪下的袋子。他先把两名熟雪工、两名军法书吏、陆承、顾沉舟和贺兰朔叫到门楼，按昨夜木杆的位置重新看风向。雪面外软内硬，若从袋角往下掏，整片斜坡会再滑一次；要取物，必须从下风侧打横槽，先探绳，再开雪。

“七个人，带两根长绳、三把木铲、一盏遮风灯、四斤干饼和两囊温水。”陆承念令，“只到木杆处，不带粮，不带民夫。一个时辰回，二次雪滑、冰裂、三人以上持械或绳断即退。若有人受伤，两人护回，其余弃铲等候。”

顾沉舟问：“木牌和麻袋分谁保管？”

“军法书吏收木牌，你收粮袋和麻袋。”

“我不收麻袋。”顾沉舟指向陆承，“发现位置在西北高地，证物先由营门押存，等军需、军法各取副本。”

陆承看了他一眼，点头修正。谁都不想让一只来路不明的袋子变成顾沉舟私藏的证据。

高地的雪比昨夜硬。七个人用绳连成两段，木铲先刮表层，再用竹探杆测深。挖到一尺半，露出的不是麻袋口，而是一截被冻黑的车辕。辕木外侧有旧火燎痕，车轮铁箍已经脱落，旁边压着一片盐白硬皮。

“先别动。”顾沉舟说。

陆承让雪工停手。军法书吏把车辕位置、木纹、铁箍方向和雪层厚度写在纸上，顾沉舟则看见车辕底下还有一道细细的蓝线。那不是护粮队昨日的封线，线头被泥冻成硬结，像是多年以前麻袋破裂时留下的。

他们继续横挖，终于取出一只旧麻袋。袋里只有结成黑块的陈麦和两块木牌，一块写“歇车五”，另一块只剩“转出二”的半边。袋口没有封泥，重量无法还原，陈麦也不能食用。苏晚棠不在现场，顾沉舟没有让任何人试闻，更没有让人剥一粒入口。

“可作旧站物证，不作粮。”军法书吏念道。

顾沉舟用油纸将袋内黑块分层包好，标出袋底、袋中和木牌相邻处；车辕和铁箍另包，盐白硬皮交陆承。旧牌上的字与第十章找到的“歇车五、转出二”相同，却没有景和十七查验印，说明旧站曾长期使用，不能说明昨夜谁把它埋在这里。

回程时，贺兰朔在高地边缘停住马。

“南侧黑河有火。”

不是烽火。三点灰烟贴着河面，间隔很稳，像有人在冻河下风处烧湿草。陆承立即让队伍伏低，不追烟。他让一名书吏回营报高地证物，自己带顾沉舟和贺兰朔沿北沟观察。远处一辆粮车从黑河旧渡方向驶来，车上挂着西墙补给的白布条，车后跟着八名民夫。

那不是他们的车。转运棚今晨送来一百二十斤净麦，因雪场清路，周校尉准由北门外短路先转一半到营，另一半午后再到。押车队由陆承临时抽调六名营兵，八名民夫，顾沉舟负责交接；贺兰朔本来只留两骑在高地，看到河下灰烟后赶来。

周校尉传来的军令已经写明：六名营兵、八名民夫、顾沉舟和两名骑手，共十七人；净麦一百二十斤分三袋，每袋四十斤，干饼六斤、水三囊、马料八斤，沿北门至黑河旧渡再折回营，午后前完成首段，发现冰裂、三人以上持械、车轴损坏或路标被换即弃粮撤，伤者两兵护送，剩余粮由营门接回。伤者不能由赵七、韩魁和雪崩停工的民夫顶替，另派两名在役民夫补缺。

顾沉舟听完，盯着河面上的三点灰烟：“对方等的是这条路。”

“也可能只是牧户烧草。”陆承没有认定，“先让车停在北坡背风处。”

车队停下时，河道下方果然传来短哨。第一支箭没有射人，钉在最外侧的空车板上；第二支箭射向中间的粮袋，却被贺兰朔从侧坡放出的箭逼偏，擦着袋角落下。陆承立即把三袋粮推到岩坎后，六名营兵分成前后二线，八名民夫退到绳内，不追坡，不散车。

“几个人？”陈二问。

“看见四处火，不能数人。”陆承答，“按三人以上持械撤。”

撤令刚出，南侧便冲出六名持短弩和猎叉的人。他们没有直扑人，先割最外袋的绳，显然知道粮车只要乱一次，袋子便会被雪坡拖走。顾沉舟让两名民夫把空车横在车前，另两人把绳绕过车轴，剩下的人抬中袋退向岩坎。分三袋的意义此刻显出来：外袋被割开一处，另外两袋仍在两名营兵护下。

贺兰朔没有追上坡。他带一骑绕至西侧，逼退想从后面割绳的人；陆承以盾压住一名冲近者的猎叉，另一名营兵用短棍击其膝弯。顾沉舟没有拔刀，只指着车轴：“先压轮，别让车滑河！”

冰面传来闷裂声。车前那名民夫脚下一空，整个人陷到雪洞里。陈二把备用绳抛过去，顾沉舟和两名民夫同时拉，没让他继续往冰下掉。粮车少了一个推车人，二袋粮便无法同步退。

顾沉舟当机立断：“弃最外袋，护人和两袋！”

外袋被割过，封线已断，四十斤净麦滚下半坡。陆承没有派人去抢，先让六名营兵护住两袋完整粮和受伤民夫。贺兰朔一箭射断追来者脚边的绳扣，逼其退到河岸；那人翻滚时露出腰间一块盐票牌，转身钻进芦苇。

冲突只持续了不到一刻。对方带走不了完整粮袋，便拖走外袋的一角，六人分散退入灰烟里。营兵没有追过黑河弯口，只在原地救出陷雪民夫、封住两袋粮。被陆承击倒的那人右腿骨裂，仍活着，短弩落在雪上，猎叉断了一齿。

回营时，首段实际带回净麦八十斤，外袋四十斤留在河坡，不能写成全车被抢；六名营兵一人手背擦伤，陷雪民夫左膝扭伤，顾沉舟虎口旧伤再裂。被押回的袭击者由苏晚棠先看伤，再由军法问身份，不能因为他拿盐票便直接写成转运棚的人。

盐票牌上只有一个“南”字，边角压着黑色盐碱硬皮；短弩箭羽削法与沙沟短箭相似，却少了两道旧刻。三件物证分别封存。顾沉舟把河坡弃袋的木签、车轴绳痕和营门出车副条一起交给陆承，实物、门簿和押运口供三类证据各自有经手人。

周校尉在营门听完，没有先问斩获。

“一百二十斤，回来八十，四十留坡。六名营兵、一名民夫受伤，一名袭击者活着。”

“是。”陆承答。

“你们守住了两袋，也丢了一袋。”

“先救人，才保住两袋。”顾沉舟说，“若追坡，三袋都可能下河。”

周校尉看了他一会儿，让军法书吏把“弃粮撤退”四字留在原令旁，不许改成临阵丢粮。八十斤净麦先入营复称，四十斤留坡待明日由熟雪工和营兵取回；伤员、马料、车轴裂痕和民夫役期分别列账。

这不是一场吞掉敌人的大胜，却是黑河营第一次按新护粮规矩打完一仗：没有追进不明烟火，没有拿伤民补队，没有把留坡的粮写成凭空消失。

顾沉舟走过医棚时，苏晚棠正给陷雪民夫固定膝部。

“两日不能搬重物。”她说，“你若把他写回车队，我就把你的手也包起来，让你明日只看账。”

顾沉舟看向门外的雪河。四十斤粮还在坡上，南字盐票和旧站木牌互相望着，却还不能合成一个主使。

“明日先取粮，再问人。”他说。

苏晚棠点头，先封葛六伤口。
