# 第三十六章 关门税

晨梆刚落，收钱的铜斗已在税棚响了三次。

南坡来的三辆粮车停在横木外。车头车夫把官粮牌举得很高，税吏却指着斗，说今日每车另收护路钱，不交便不能入关。后头六辆商车压着坡脚，牛身上冒白气，车轮边的水已经开始结冰。

顾沉舟还没走到棚口，就听见“使君新令”四个字。

谢无咎就在城门内。税吏知道他在，也不躲，说封盐道以后商税不足，今日护路、验车、修坡都添了人，不能让雁回替别关白出工。手里一份补费条盖着转运棚小印，旁边旧税额只有过市商货的定额，没有官粮护路钱。

“修坡用了谁？”顾沉舟问。

“脚行。”税吏指向东面，“现在还欠他们钱。”

昨日四名脚行押着窄车回来，尚待核问，不可能替今日坡口干过整班工。顾沉舟没有当场说是假条，先请门哨去找清坡领工的人，自己回仓。

仓门前摆着白石的四袋还粮，二百斤足秤。旁边实时余仓三百六十斤，顾沉舟叫仓兵再核一次。初四盘仓可用一千四百八十斤，初四至初七按每昼夜二百八十斤已领一千一百二十，今晨普通锅、医棚和当日出队路食都在已领数中。待验二十斤仍封着；旧护送的八斤路食另有拨项，不塞进这张日耗表。

白石的二百斤若现在发走，雁回只余一百六十斤，连明日的减额都不够。谢无咎定的下一批首拨六百斤已经到门外，其中二百补入先还的借额，却正被一只铜斗挡着。

顾沉舟让陈二暂不落还粮车的发令栏，拿仓余去找罗定。他不能自改初七还粮时限，更不能拿“新粮到了门口”当作粮已经入仓。

罗定看完，只问谢无咎：“这六百斤，你让谁收钱？”

谢无咎取来补费条，没有撕。条上确实是转运棚的印，写的却是获准核报本月护路耗用，不是获准在关门按车征收。

税吏也有自己的难处：“没实收，脚行不会再垫木。昨夜有人连备用楔都拿走了。使君让我核耗，关里又不肯开钱柜，只能先拦车。”

“所以让送官粮的人付钱？”谢无咎问。

“他们入关最快，也肯先垫。商人只肯照旧额交。”

邵平在旁边低了低头。关内若给一张空回执，就能拿回粮；脚行拿到的却是又一张等候。税吏借了谢的条，但欠工钱不是凭空编的。

铜斗旁忽然响起鞭声。首车的车夫等得不耐烦，拉牛绕横木走侧坡，车上六袋麦压着窄轮，右轮先落进化开的雪槽。后车还在往前推，前牛被套绳扯得转头，两辆车之间只剩不到一臂。

“后车停！”郑衡喝道。

车夫忙去拽牛，顾沉舟却先让陈二跑到坡脚。最危险的不是已经歪下去的一车，是后头六辆商车不知道这里停了。

老周抱着备用楔赶来，四名营兵中的两人拦住后车，另两人从车侧压住辕头。顾沉舟不能用肩撑车，只沿安全侧报轮缘距离，让车夫先松急拉的缰，别把牛头横扯到车轮前。

税棚的一名脚行扑向横木，想搬开让粮车直走。木头下面的铁栓冻住，他用力一抬，掌心就被毛刺撕开。苏晚棠的药童在门内招手，郑衡让另一人接木，伤者先退，不能带血手去拉绳。

前轮终于被卡住，车夫解下最外两袋，转到旁边完好的雁回空车上。六袋仍是六袋，两袋移车不等于另拨；陈二逐签报过，原车卸轻，牛才从斜槽退到平地。

顾沉舟蹲在木楔旁，看见那道槽的垫木被撤了。木底留下两枚旧钉，钉头上还有破麻绳。他叫老周别先凿沟，先认垫木去处。

清坡领工恰在这时过来，是雁回当值车夫，不是那四名待核脚行。他说昨日垫木是老周挑的，今晨另一队脚行撤走，理由是工钱不付，木便不借。

一个穿短褂的领头人从商车队尾出来，肩上扛着三块木。他没有跑，也不说自己没拿。

“那是我铺子的板。借了两夜，纸上没一个钱。你们说不许拦路，我就撤自己的木。”

顾沉舟让老周核钉孔，三块木与槽下旧钉位置能对上；门哨清坡借物页另记了铺名和借入时刻。两路经手不同，能确认借木与撤木，却不能因此认定领头人要翻粮车。昨晨许下的租木钱确实未付，旧税条也不能授权税吏另向官粮车取钱。

“钱该付，路不能这么拆。”顾沉舟指着刚被扶走的脚行，“你拿回了木，受伤的是替你抬横杠的人。他那份伤工要有人接。”

领头人看向棚门，脸硬着没答。

谢无咎令邵平取实存杂役钱，先核昨夜已经用过的垫木租价与清坡脚钱。不是允一个新总额，门哨借物页、老周领木数、各人实出工逐项相对，领头人不能替没来的人拿一整班钱。

税吏要将斗里收的钱并入役钱，罗定按住铜斗：“这不是你的开钱柜令。收错的先退，经手仍要问。”

已经交钱的两辆商车各领回多收的护路钱，原过市税照旧，由税册和车夫手中收条互核；六百斤官粮未交费，不补一张虚假的免税赏条。谢无咎撤了税吏临时拦官车的权，仍让他把实收数交清，不用另一名管事替这笔错费遮住来源。

领头人拿到昨日实欠，扛木回坡。顾沉舟没有让他立刻塞进轮下，先把两车都移开，老周重铺槽口、压住木脚，再清侧沟。融水有了去处，商车只能一辆一辆上，不许又挤成刚才的样子。

木归位后，首车车夫亲手把鞭收进腰间。他只以为多花半刻是在跟税吏争气，刚才轮子一沉，才看见后车的牛角就顶在自己背上。

谢无咎没让这场破局只留在门口。他准罗定将有军令的官粮分到靠墙验车道，商税在外桌照旧收；顾沉舟排车，邵平核票，门哨认入关时刻，谁都不能兼替下一处签收。修坡工、借木、伤工分项从已经核准的杂役钱出，不再混成一笔按车收的钱。

代价落到了顾沉舟这里：两道车序都由他排，今日午后还得给清坡队补一轮，车匠老周随军不能再替商行修轴。罗定准从关内当值车夫轮换，不抽南墙第二班，不让伤脚夫起床顶工。

六百斤首拨在巳时入干棚。十二袋各五十斤，由不同车各抽袋查看干湿、虫痕、封线，交付部分再逐袋净称，仓兵与军厨独立看验；外皮霜与粮心分开核，没用试吃证明能发。三百六十加六百，实余九百六十；白石四袋二百斤单独装车，发出后留七百六十。明日二百八十斤和当夜已领的口粮都没有再挪给这笔债。

郑衡看着粮车能走，才取出罗定早晨待发的护送令。仍只用四名营兵，不抽墙哨；一辆健康牛车送白石，两名原在役车夫随车，六人路食三斤从当日已领份额留出，温水三囊，牛料十二斤与草另拨，不扣人粮。沿白石官道，日中在南驿换递，日落前送到；遇塌石、敌骑封路或车轴断裂即退南驿报关，伤者先入驿棚，不越野沟追人。营兵仍随粮至白石，不把南驿落条当白石收讫。

午后，苏晚棠送来税棚脚行的伤条：右掌浅裂，停绳工两日，原役期不延，今日实工脚钱照结。顾沉舟另报伤工和用布，不把它写进官粮损耗。四名东沟脚行及窄车仍待核，六空袋、两半牌和灰帽口述都在原处，不因同叫脚行就挪来填今日工钱。

日落前，白石递骑持关仓收讫页回到雁回。四袋净麦二百斤，由白石仓曹、军厨复核，原借额二百全还，不与新拨六百重记。护送四兵和两车夫按令留白石驿棚过夜，次晨才回，归返时限由白石与雁回两端报过；没有把他们已经回关写进点名簿。

白石愿意供六人明早的热食，罗定却没再开一笔无期限的借粮。回关路食改由雁回预留三斤，列在次日二百八十斤内；白石先出三斤，随次晨空车回条结付，不冲今天已还清的旧二百斤。七百六十斤中三斤只是预留，尚未出仓，不能又写成已经耗掉。牛料余量与水囊要随车回来复点，驿棚补水单记，不拿领出数充当吃净数。

罗定将“已发”划在左栏，右栏留下“实收二百”。关里没有多出一笔横征，白石也没拿到一张空票。

顾沉舟回棚时，晨间的收钱斗已取下，横木留在坡口，只有一车过后才抬。领头脚行正在用完好的手教新来的人铺木，没有再把工钱问给赶车的陌生人。

北门却又响起急促脚步。

贺兰朔带一骑登楼，手里是西侧水车刚带回的断绳。水车尚未受袭，柳台以北却出现六匹换过蹄铁的马，印子绕着水槽走了一圈。不是今晨那三骑留下的旧浅痕。

顾沉舟望向墙影里的粮车。门口通了，仓里有粮，草原上的人便不会再只数一次换岗。

他让陈二把空车先留在干棚外。明日要查的不止每袋有多少，还得看这些车能不能在风里护着人退回来。
