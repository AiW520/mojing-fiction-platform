# 第四十四章 雁回关不降

正月十三卯时，北楼的定风灯被第一支箭射灭。

守卒听见钉木声，立即低头。第二支箭擦过垛口，后头才传来马蹄。昨日三个试门的骑影已经散开，西坡有十余匹马压住旧堤，浅洼里另有二十余步影，四架长梯一齐抬起。

罗定到楼时，没有先叫人放箭。他让北楼与西墙各报一遍：北楼估十八骑，西墙只能看见十四；步卒北楼估二十六，西墙报不少于二十。数字互不抹去，能确认的是四梯、弓手和贴地推进的盾，没有旗能认部属。

“他们要墙脚。”贺兰朔从低楼报，“骑手遮两边，抬梯的人走浅洼。”

顾沉舟昨日看过那张车路图。浅洼能遮脚印，也能让梯队逼近，堵水的人留下的裂木不能证明属于这支队伍，眼前张开的弓却不需要等一张旧票才承认危险。

罗定封北门，南墙二十四人不动，仓门四人、医棚六人照旧。北楼十二名当值兵加关内机动十六人，由郑衡领，另八名守内门，余人听传令，不一口气堆到梯脚。西灶两百斤四袋只作守城临拨，由仓兵、军厨复秤领出，今天全关日额仍二百八十斤，墙兵不重复领两锅。

顾沉舟拿勤务牌到井廊，先撤推水车，再把昨日空出的路留给担架。两名备用车夫不能登墙，负责医棚接伤；陈二守西灶报袋与饭数。罗定准二十八名北楼兵半日换班，十八斤净麦作早饭、四囊井水送上，物料从守城库领长杆四根、沙桶六只，日中必须清点。

军令写得短：不出门追，墙上受伤立即沿井廊送医，两兵护架，不拿伤者补下一班；一段垛口失守便退内层木栅，梯脚不可守则守内门，火逼粮棚即移已验粮到西灶。顾沉舟不领墙兵，他能叫停交接车，不能用勤务牌替罗定改战线。

第一梯搭上西侧矮垛时，敌弓手先射灯架，再射递水的人。守卒不能只把头藏住，北楼两张弩必须有人上弦。郑衡让盾手贴垛横移，一人遮弩，一人遮水，弩手只射梯首和露出的拉绳者，不朝远处的马影乱耗箭。

梯子第一次晃动，底下的人立刻换手，第二架又贴到旁边。对方不是来白撞墙，他们知道旧修垛低，盾下还带了钩绳，先拉松墙沿的散木，再让梯首攀上。

“长杆不到！”一名守卒喊。

西灶旁的粮车正挡住物料转角。顾沉舟没有叫车夫把粮推上墙，只准车退一丈，四袋号牌原样挂着。陈二留车，另一名辅役把杆沿内墙传上，六只沙桶由两人接力，不从井廊穿行。昨日多清的半班工，今日变成两条互不撞人的路。

贺兰朔右手仍不能拉弓。他站在低楼，叫副骑看梯脚的脚步，不盯梯上那张脸。第二架梯每受一下推力，底下四人都向同一侧偏，木脚没有钉稳。副骑向郑衡报，郑衡却没有立即倾全队去推，他让弩手先压住旁梯，四名持杆兵才同时挑向松脚。

梯头掀出半尺，攀上的人抓住绳，未坠。第三梯后又有人扛起横木，沿浅洼直奔北门。门外原有空车被他们推起，车辕抵着横木，想用轮子送撞门木到闸前。

顾沉舟在门内听见轮声，脑中不是柳台案的名字，而是老周昨日量过的坡口宽度。空车只能走中间直槽，两侧冻沟容不下轮；关内若向外开门取车，就会把横木送进自己手中。

罗定令内门八兵守闩，弩手在门楼压车夫。长杆推梯不能挪来拦车，顾沉舟让老周报门后撑梁是否稳，只让两个健康辅役添侧楔，不动大闩，不出一人。

撞木第一次顶门，铁环震得墙灰落下来。第二次却歪了：外车右轮陷进冻槽，后面步卒忙抬车，盾不能同时遮住楼上。两名弩手各放一箭，一个抬辕者倒在车旁，另一人拖着他往浅洼退。谁也不能隔着雪说他死了。

北楼忽然传来铁器刮石声。梯首已跨上矮垛，一柄短刀砍在盾沿。郑衡没有独自迎刀，两兵靠盾压窄垛口，第三人用矛逼住对方落脚处。他们守的是一人能上、两人难站的口子，不是比谁敢跳到梯外。

那人退了一步，盾后又有第二人探头。敌弓手改射推杆者，郑衡左臂被箭划开，盾却没落。他叫后排接盾，自己退到梯道，不藏伤继续顶班。替兵填上，弩手压第二梯，长杆四兵同时向外顶。

第一梯木脚终于拔起。两名攀梯者滑下去，坠在盾队后，脚下有人扶，有人挣扎，不能计成两颗首级。余下三梯也收，抬梯队沿浅洼退开，骑手向两翼展开遮撤路。

罗定没有开门。关内热饭送到第二班，北楼兵已经站了半个时辰，弩箭也耗掉一截。若此刻出骑追，贺兰朔的伤手不能引队，墙兵却得再少一班。

号角忽然从北水槽响起。四名骑手沿槽尾疾驰，一人俯身射火箭。火落在木管旁的草堆，黑烟贴着墙脚卷上来。他们想把楼兵的视线引向水口，另一梯队停在旧堤后，并未走远。

“槽尾不出兵！”罗定令北楼报火向，“先守梯线！”

顾沉舟把沙桶从余留物料中分两只到关内管口，老周断开通入关内的空木槽，堵住引火草绳。外头木管可以损，火不能顺着干木进棚。六名执行者只在关内，守火半刻，两囊井水供灭火，不开闸；火越内槽即退西灶，伤者入医棚，木料可弃。罗定亲准，顾沉舟才让辅役动手。

一块烧断木片砸到脚边，脚夫抬手挡，手背起了一条燎痕。药童把他领出，老周接杆，沙与井水一起压住内槽火头。管外裂木、松油和旧脚印已经受火破坏，位置图仍存，不能因为火来了就补写凶手。溪水本就不供饮用，关内井没有断。

第二次梯队靠近时，敌弓手还想先射新换的灯。罗定不再补同一根灯架，弩手换到两侧暗垛，射界照昨日报距。敌人得不到第一次的空灯架和固定人影，推进慢下来，却并非突然忘了搭梯；他们移盾找侧角，北楼也用长杆换位，不追到墙外。

日上垛口，浅洼里的步卒收梯，骑手护着伤者向北撤。两处墙哨都看见四梯退离，马数仍不统一，罗定只记敌攻停止，关门未破，不报全歼。门外留下撞木、坏车轮和箭十余支，等雪势、敌影与军法查验，不为抢物先开闸。

医棚接进四名新军伤：郑衡左臂擦伤，一兵腿中箭，一兵额角裂伤，一兵肩部挫伤；另有一名燎伤脚夫。苏晚棠先止腿血，再清郑衡臂伤，停工与用布分别记。旧二十七军伤仍在原册，新四人属于在籍军兵，不往四百四十八的总数上再加四；旧四伤脚夫中一人在南驿，燎伤者另列第五名受治脚夫，不补粮运队。

北楼十八斤净麦已做饼，十八斤全计今日二百八十斤内；送去四囊水尚余半囊，灭火另耗两囊，熟饼余一斤四两移第二班，不再领一锅。守城弩箭实发四十、射二十八、余十二，长杆一根裂、沙桶六只耗四只，代价没有写成“无损”。

谢无咎亲自去北楼，摸了一下完好的门闩。他早晨备过一张移粮内退条，此刻收回，改准守城库补十八支弩箭、两根长杆。没有从伤员软食里挪钱，也没因此答应查清贺兰真旧案。

罗定把郑衡的盾放到案边，让当值副手接北楼：“这次守住，靠你们照令换人，不靠一只伤手撑到底。”

顾沉舟的勤务牌添了战后修廊、补井绳和四名新军伤口粮先报责任。派谁去水口仍归守将，仓钥仍归仓曹，军功由周判官据值哨、军令、伤情和实耗核后再结。他没有在墙没破的当日换官，却终于让两百斤粮和一条空廊用在了真正的箭下。

贺兰朔望着北撤的马影，低声道：“兄长那时，是否也等过关门开？”

顾沉舟没有拿今日敌骑给旧案补答案，只把白石回执交他。昨日原驿递回来的卷目载明旧卷仍须查库，未带原件，三日答复期限未过。能翻案的路还长，今日守住的门不能替谁遮那份缺页。

午后风转，北坡白线压下来，南驿急报雪开始封官道。罗定令两端先报车位，不许接粮车冒雪赶回。雁回旗还在墙上，门闩完整，火没进棚；下一场风雪却不需要弓箭，也能把粮路割断。
