# 第十三章 雪夜练队

下午的雪下得密，火棚前的路不到半刻便白了。

顾沉舟没有把粮队拉到校场。六只训练袋放在东仓门外，里面装的是雪沙，往伙房只有一条窄路，途中要经过转角、火棚和营门内侧三道障碍。若再按白天的报数走，雪一落，后面的人看不见前面，柴车一横，袋子便能从队里消失。

“今夜练三轮。”顾沉舟对陈二说，“不是练搬重，是练停、报、看、交。”

陈二看着他：“练完要多吃一碗吗？”

“练完若少一袋，大家一起少。若一袋不少，夜粮照军议分，不因练队另开锅。”

这句话先让辅兵们泄了气。雪场操练常有加餐，伙房练搬粮却没有。鲁安站在队尾，手上的领票牌已经交回军法书吏，只能随队听令，脸色比雪还白。

周校尉没有给顾沉舟正式军令，只让陆承在旁见证。陆承带两名门哨，一人守东仓，一人守火棚，自己站在营门内侧。周校尉准条写明：九名辅兵、借调民夫陈二、火夫老邵，共十一人，顾沉舟指挥不负重；六只雪沙训练袋，每袋四十斤，两人抬一袋；东仓外至伙房三百步，三轮，每轮两袋；半个时辰内完成，无额外口粮，从各人本日已领份额留水两囊。若受伤立即停，陆承派一名门哨护回医棚，其余收队；有人持械干涉，由门哨处理，不追出营。

苏晚棠看完那张纸，补了一行：“赵七、韩魁、五名获救民夫不进队。若雪伤或扭伤，先送医棚，不能让粮袋占驮马。”

顾沉舟点头，把行程再缩短到营内三百步。运粮不是出营，却同样有撤退条件。

第一轮开始。两人一袋，木签挂在绳结上，陈二在最前，顾沉舟走在中段。每过一处，搬袋的人要报“甲袋、两人、未开”，接袋的老邵复报“甲袋、已到、未开”。声音被雪压住，火棚那头几乎听不清。

“再来。”顾沉舟道。

第二次，老邵不再站灶门，而是站在转角，先看袋号，再让火夫接。火棚与灶口中间留一丈空地，柴车不许进。鲁安被安排拿一根短杆，专门探雪下的绳结，不许碰袋子。

第二轮走到半途，一只麻袋忽然滑落。搬袋的辅兵忙伸手去抱，袋口却被雪下的木刺勾住，绳结松了半圈。

“停！”陈二喝道。

有人骂他小题大做。顾沉舟蹲下看绳结，没有伸右手去提。麻袋外皮被木刺划开一道细口，雪沙漏了一小撮，露出袋皮原有的麦壳。若继续拖，口子会越来越大；若当场换袋，则要把破袋、漏粒和经手人一起记明。

老邵取来空袋。陈二先记原袋号，鲁安报出木刺位置，另一名辅兵将掉下的雪沙拢到一边。换袋后，原袋拿回缝补，木签改挂到新袋，换袋时辰照搬粮时一样记。

“若里面真是粮，少多少？”鲁安问。

“回秤边重称。”顾沉舟说，“损耗单列，不能用剩下几个满袋替它遮。”

辅兵们没再笑。夹带的乙袋才追回，眼前一撮雪沙，让他们看清绳子松一次会怎样。

第二轮换袋后，队伍重新出发。火棚外那辆柴车被陆承提前移到侧墙，车票和车夫都还在营门，不能让车与粮队同过。军营里有人骂门哨死板，陆承没有解释，只让门哨把冲突时刻记在值守册。

第三轮刚开始，东仓门内便响起三下短叩。

守仓老卒罗七从门缝露头：“秦百户要取一袋旧余粮。”

顾沉舟走到门口：“取多少，做什么？”

“他没说。说仓曹口令。”

陆承接过口令，纸上只写“取袋一，补仓损”，无仓号、无重量、无经手人。秦百户本人没有到场，亲兵站在门内等着。

“今日领粮已经过秤。”顾沉舟道，“要取旧余粮，请把袋号、重量和去处补在口令上。练队先停在东仓外，不开袋。”

亲兵冷笑：“一袋余粮也要问？”

“训练袋全是雪沙。粮在仓里，要取就另开仓单，别叫搬粮的人替您认一个不知道重量的旧袋。”

“你个代领粮路的文书，管到东仓了？”

顾沉舟没有回嘴。他转身让陈二把六只训练袋按木签重新点一遍，两名辅兵一人看袋、一人看门，老邵在火棚报数。六只训练袋全在，更换过袋皮的那只仍与原木签相对。

秦百户的亲兵在门里站了片刻，最终把口令收回。陆承没有让他离开值守范围，要求他留下“口令未补项”的记录。亲兵不签，陆承便写“当事人拒签”，旁边由门哨作见证。

雪越下越大，火棚的火被风压低。顾沉舟让练队退到东仓外的避风棚，将六袋靠墙分列。陈二按照甲到己重报，十一个人各自说出经手到哪一步，只有鲁安的声音抖了一下。

“我碰过乙袋，新袋换绳时在旁边。”

“你没提袋？”顾沉舟问。

“没提。”

“记录。不是认罪，是认经手。”

鲁安咽了口唾沫，在乙袋旁按下指印。上一次他卸下乙袋时没有记名，今夜不得再把自己的手从袋上擦掉。

三轮练完，旧袋拆线缝合，原来不齐的补口又浪费一根麻绳。顾沉舟将袋皮一处破损、麻绳一根记入练队物耗，陈二去领针，鲁安留下缝袋，不从医棚拿药布补洞。训练袋卸空归还，没有一斤可食粮用于反复拖练。

苏晚棠路过时看见他们拆袋，问：“这口子谁补？”

“鲁安学针脚，老邵看着。麻绳在军需耗材里记一根。”

“不许剪医棚药布。”

“不用药布，也不用粮袋往雪里填麦。”

“那就把修补的人留下，别缝完又记成一只完好的旧袋。”

顾沉舟将修补的袋号登记，鲁安捏针捏得笨，陈二在旁替他穿线。十八斤七两早已耗尽，练队要靠每日半个时辰渐渐练成，不能再借一顿加餐让人硬撑。

周校尉在雪夜里看完练队记录。他没有夸队形，只问：“三轮少了一袋吗？”

“没有。废绳一根、修袋一只，鲁安已经在补。”

“值不值得？”

顾沉舟看向六只卸空的训练袋，鲁安补过的那只，针脚从歪斜渐渐排得整齐。

“队伍以后能在火棚停下，值。”

周校尉把练队纸折起：“明日换防，别让新来的人把你的报数当私规。”

顾沉舟知道这句话比夸奖更重。夜哨会换，仓曹不会跟着换，营门上的值守簿也要重新交接。练出来的队形若没有人接手，不过是顾沉舟一个人记得的姿势。

夜深时，韩魁从医棚出来一趟。左腕还固定着，他看见雪里一排脚印，问：“明日有骑哨？”

“你不能骑。”

“我问的是有没有。”

“有。北坡六骑换更，另有营门换防。”

韩魁沉默片刻：“换防时看马料。少两袋，马先知道。”

顾沉舟把这句话记在木板旁。营兵看粮袋，骑兵看马料，医官看药耗，民夫看自己的指印。若要把整座营的缺口拼起来，不能只盯一只袋子。

雪停在三更。顾沉舟回到账房黑墙外，看到周校尉留下的换防通知：卯时新队入营，旧队交营门、东仓、医棚、军法四处簿册；顾沉舟作为临代粮什，必须在伙房交接前报明今日损耗和明日欠额。

他把那张通知压在木板裂口旁。

老邵把破袋挂到柱旁，陈二把“粮队先行，柴车等下一梆”的次序抄在火棚门柱。鲁安补针扎了指尖，一滴血落在白线边，他没藏，把缝到哪一针也报出来。顾沉舟收起名单，终于可以把目光从袋子上移开片刻。

明日，真正的队伍会到。
