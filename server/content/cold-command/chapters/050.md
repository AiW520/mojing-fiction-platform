# 第五十章 一城两令

正月十九天未亮，宁川西缺口先竖起了一排木栅。

四名县差将绳索横到路中，绳外停着昨日卸盐的商车。车夫敲着辕，不肯把盐拖入城外货棚；货棚屋顶漏雪，仓板也未垫，进去一夜，湿盐算谁的，没人答得出。

顾沉舟到时，税棚管事邢良已将孟槐的地租板扣在案下。他拿出的不是假令，而是县丞十日前签的征发文：宁川暂作沿途货物留验处，地方役夫先修外棚，商货须过棚核税。

顾沉舟手中另有罗定准南线转存与南渠三日试修的回文。一个要把人拉去砌墙，一个要让十人半日修渠；同一段路、同一批能干活的人，纸上都没有第二份。

“军粮可过。”邢良指向堤坡，“盐和工粮进棚。工人下了渠，总不能还说自己在打仗。”

“试修粮由军需拨，未发之前不变成商货。”崔岳把手放在刀鞘上，没有拔刀，“我的人只护粮，不替你抓夫。”

邢良显然算过这一层。他没碰军粮封袋，只命县差把租来的碎砖拉走，说两户砖料既供商车卸货，就先列修棚征用。两户住民追上去，梁铁带着四名试工者也赶来，双方撞在窄口，盐车的牛开始甩头。

顾沉舟立刻叫梁铁退回渠边：“今日不落筐，先留看水的人。停工由我报，不让你们拿木锹去挡县差。”

邢良笑了一下。停渠，正好给了他征夫的理由；只要把人赶到棚前，罗定的试修就剩一纸空文。

顾沉舟却没有退回秤房等批条。他请崔岳按护场副令带三名营兵，其中两人只护西缺口至院门，一人守桥；两名院兵合守院门，独立仓兵专守一百斤转存粮。护场带两斤饼、两囊温水，商人起械即隔人退院，遇牛惊先卸轭；伤者送驿，任何人不追出西缺口。

“不抢他的印，先把车和人分开。”他说。

陈二跑去南驿报停：待发的四袋二百斤原粮先留，没认桥路不出车。带半斤饼，搭驿方现有递信车，回来仍归这半斤结，不另领一份。马六领一兵把盐车旁的孩子和看客带到墙内，车夫将牛拴在背风处，顾沉舟左肩不能拉缰，只报退车距离，让许木匠塞木楔。

他们每退一步，邢良便少一处可以借乱抓人的地方。盐篓卸在车上，租砖留原位，买过盐的人把手里的收条交给盐铺伙计，货从哪儿来、谁已买走，先同尚未卖出的篓分开。

一名县差等不及，扯住压篓的绳往棚外拖。木楔挡住车轮，绳骤然反绷，将他甩倒在砖堆边。牛惊得抬头，另一名县差举棍要打牛鼻。崔岳用盾隔开棍子，两兵护住车头，车夫迅速松轭，空辕砸进雪里，没有撞到后面的住民。

邢良喝令再上，崔岳把盾压低：“倒的人先抬出去。你要验税，我不拦；你要连牛带车拖进人堆，先问县丞敢不敢认这条伤。”

倒地县差左腕肿起，驿医未到，没人说只是小伤。邢良看着他的手，终于让余下三差退半步。顾沉舟借这半步，请住民把西缺口的散砖清到边上，盐车轮旁留出一条可走人的窄道。

他没有把县差的新伤记到修渠役工里。崔岳另派递信人通知驿医，护场饼里分出二两给医转勤务，待县方接人后核回，县方先担药费，不从伤工周四的份额里扣。

午前，县丞邢远骑骡来到旧城。

邢良迎过去，先报军兵阻令，却没料到顾沉舟不争这一句话。他把人群引到能看见货棚的位置，请县丞先走一遍从西口到棚门的路。

棚门前是两道深车槽，门槛下有水。邢远踩上旧板，板尾立刻翘起，冻泥冒出半个足印。他抬头看见盐车高篓，脸色变得难看。

“这里以前能收三车。”邢良说。

“以前是哪日？”邢远问。

邢良报腊月。那时尚未塌过旁边的檐，门外渠水也未从新裂口漫来。他手里旧征发令没有作废，地上的承载却已经变了。

顾沉舟没有要县丞因为一块烂板认罪。他让许木匠以空木箱试压，孟槐另领县来的书吏看六户井路，两边不经邢良递口供。板下冻泥、屋檐新落砖、住户挑水脚印与十日前绘的货棚图相对，证实旧图漏掉了现水口和两户井路。

县丞把图收起，问顾沉舟：“不进棚，税从哪儿来？”

这不是一句能用清廉答过去的话。县里也欠棚卒粮，若税断三日，邢良明日便有理由向住户再征。

顾沉舟请盐铺伙计取来昨日货单。买断二十斤、代售十斤、余货托售五十斤，所属分开，已卖与未卖分别列。县税吏可以在车边核既定商税，军兵不碰税钱；屋主照收短租，租地不豁免商税，官粮则仍凭军需令过路。

“今天改的是验货地点，不是把税取消。”他说，“军需工粮未出厨之前也不变成盐铺货。要征夫，先认原役册。已做过半日工的人不能今日再补一个整日，周四的伤手也不能拿来砌墙。”

邢远看了看铺吏。对方昨日并未替顾沉舟担保，此时只认兑簿和货单，答得极短。两户屋主拿出砖租价单，拒绝把砖写作无主废料；那排被邢良扣下的散砖，终于有了谁该付钱的边界。

邢良没有低头认错。他说临时摊场一开，逃税小车便能混在人群里，自己若不拦，县丞查下来仍会责他。

顾沉舟指着空场两头：“单口进，单口出。税吏验货，屋主认租，车夫只交自己载的货。不让人四面散卸，明日若空场返泥，商车暂停，别拿军粮去补税。”

县丞让邢良带两差先验现车，自己带书吏重新量通道。不是一张新纸把旧令推翻，而是原来堵人的四差拆成验货、点人、医转三处，再也不能拿一根横绳兼做所有事。

马六在墙内等了半上午，听见准验车，立刻招呼车夫把篷绳重新扎好。许木匠将两块垫板移到空场入口，顾沉舟站在侧面报轮距。车轮越过原横绳处时，人群没人喝彩，却有人主动把箩筐挪开，不再挤在牛头前。

第一辆车核过原商税，将尚未卖出的托售盐留场，另把要运往南驿的货装回车。盐铺伙计按货号复称剩货，扣去昨日已卖与今晨交付的实数，再由两名车夫分别认留场和出城的重量，不拿篓数抵斤数。周敬买断的二十斤及十斤代售约仍另结，不变成县里新收的盐。税钱由县吏收，车夫拿回通行小牌。邢良握着牌夹，仍不高兴，毕竟他今后不能再靠“先进棚”一句话多压半日货。

陈二带驿长回报赶到：四袋二百斤未发，封线未动，原四百斤仍全在驿棚。旧石桥南端一根横木冻裂，载盐的轻车走西口，载二百斤的粮车却不能借它已经走过便算过桥安全。顾沉舟立即报罗定，桥先补，粮后过，误时是自己的交接责任，不让车夫背作迟到。

申初，罗定前夜收到盐路与征发急报后所签的回令抵达。军镇准借调再延至正月二十二日落，只办桥路修护、转存交接；罗定另给顾沉舟宁川转运排程牌，可排现有车夫和已批役工先后，暂停危险交接，不能征新兵、开仓或增拨粮。

邢远当场认了军需范围，县方三日不从原十人试工组另征整日役；愿接修棚短工的住户自行报名，人数与钱未核，今日不动工。商货在空场暂验两日，邢良须每晚报实货和税额，不得将住民家粮并作商盐担保。

梁铁领人回桥时，已经错过半日试工。九十斤工粮昨日领十斤八两，余七十九斤二两今日未发，不把停工写成做满；奉令候工的十人给候工钱，驿长从役钱先付，明日不用他们白补今日半日。十八斤八两旧预留仍单独归驿，无人挪成候工饭。

赈锅却没有跟着停。驿长带来的另一袋二十斤麦是今日续赈，厨工在堤内复称后才开袋，给五十七人做薄粥，伤病与孩子先盛；周四留医的食物仍由驿医接，不到河滩重复领。马六端碗回来，见梁铁拿着候工钱没动，便把碗塞给他：“今天没下渠，不等于你家不用吃。”梁铁这才收起木锹。顾沉舟让两人把新闸木盖好，不开工、不冒水，却也不能让今晨送来的好木再泡坏。

护场两斤饼连医转勤务共耗一斤七两、余三两，两囊温水余半囊；陈二的半斤耗三两、余二两另退。县差由县方接送南驿，驿医回条称左腕扭伤停持棍两日，军兵与试工者无新伤。顾沉舟右虎口布湿了，回院换布，不拿新排程牌当肩伤痊愈。

天暗下来，孟槐把归还的地租板挂回墙边，第一次有人在下面问明日哪时卸货。崔岳去看院门，独立仓兵报两袋一百斤原粮仍封存，没拿一袋去替县里平息争执。

顾沉舟将排程牌放在桥图旁。今天他保住了修渠的人和过路的货，却也接下了新的硬账：正月二十二日前，桥要能承载，二百斤粮要有去处，县税不能断，五十七人的明日口粮仍须另催赈额。

一城两令没有变成两队人在雪里打起来。可若明日粮仍过不了桥，今天让开的这条路，就会比堵着的时候更难交代。
