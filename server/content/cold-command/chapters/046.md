# 第四十六章 废城南仓

正月十五，宁川南仓的门还没开，门前先横了一柄旧矛。

握矛的是个右耳残缺的老卒，灰棉袄下露着一截褪色军衣。他没往顾沉舟身上指，只把矛横放在门槛：“进去可以，先看你们要拆哪间屋。”

南驿送来的仓图里，这里是一片空白旧院。眼前却有烟，有冻在绳上的小衣，有个抱着陶锅的妇人从破厢房里出来。一个小孩站在她身后，看着军兵腰上的刀，没敢出声。

顾沉舟把“废城”两个字从心里挪开。墙可以废，住在墙下的人不是废物。

这次十二人奉罗定军令来查看转存点：六名营兵含领队的南线副尉崔岳，两个车匠、两个车夫，陈二与顾沉舟。昨日午后十二人携八斤路食、四囊水步行低堤，入南驿宿一夜，晚锅由驿厨按交接页另供六斤净麦，不与查看路食重复。今日才按驿长借领页接两辆空车、两头经查无伤的役牛，牛料十六斤和另束草，沿南面缓坡来此，不走封闭山道。军令限申前回南驿，伤者送驿医；屋梁异响便撤出危险范围，先护出伤者，沿路敌影或桥板塌裂则全队退驿，不自行拆门取旧物。雁回的郑衡、贺兰朔和新伤人员均留关。

苏晚棠没有同行，她把停重物的医嘱写在顾沉舟出行页上，由崔岳看着执行。顾沉舟能排人、量车距，不能为了让别人相信自己能干就去扛梁。

昨夜低路只复查，未再领运，南驿留着的五百斤继续在原车棚下。宁川这座南仓与三关日常领粮的现用南仓不是一处，旧图只有屋址，既没有可发粮数，也没有新的调拨票。

老卒叫孟槐，原在宁川守门，废城停驻以后留着照看两口井。他让妇人进屋，指着院东：“图里要清的柴棚，六户人家住着。你们要把粮摆进去，先把他们搬到哪里说清楚。”

崔岳看了一眼转运司随文，眉头皱起：“此院官仓，可临时征用。”

“我不拦官粮。”孟槐把旧矛抬开一寸，“去年征木的人也这么说。拆掉门板，留了一张条。老人冻死，条还在。”

他从衣内取出一张折得发脆的领木凭，右下有军需旧印。顾沉舟没有把它当全院所有权，却也不许崔岳先拿“不识仓籍”压住老人。他让陈二照样抄下，原件仍还孟槐；征木旧欠、今日借院是两回事，不能用一趟军粮顶掉。

“先看无人住的那间。”顾沉舟道。

孟槐领他们过院。南仓本房地基高，石阶三级，临河一墙却裂出一道缝。门后不是粮堆，而是七捆烂席、碎陶、旧木枕和一块废磨盘。车匠从外面试梁，第一锤落下便敲出空响。

崔岳抬手，刚要叫人退，顶上已经掉下一层细土。

一个瘦工匠从屋后钻出来，肩上扛着新砍的短木。他想给主梁补柱，孟槐却喊他不要进。工匠没听见，梁端又一响，半根折木压住了他的腿。

营兵冲到门口，崔岳立刻把人拦在石阶：“不能六个人一起进去！”

顾沉舟看见折木尚有一端搭在旧磨盘上，重量没有全压下，便叫车匠看这端能不能支。车匠老陶绕到窗外，以探杆推开一片烂席，确认承重位置后，让两个兵把车上的硬木垫在安全侧，先撑住没落下的梁。

顾沉舟站在阶外报位置，陈二把绳从窗下送进。崔岳与一兵贴地进入，不去抬整根梁，先用短撬把压腿那端稍稍起开，外头两人将木枕推进缝隙。工匠痛得咬住袖口，仍伸手护着自己那根新柱。

“木头留下，人出来！”崔岳喝道。

他们将人拖到窗边，车夫接住肩膀。梁在下一息落下，木枕砸得粉碎，屋里扬起一阵灰。孟槐把小孩一把拽到院外，军兵也全退过石阶，没有人为救七捆烂席再回头。

工匠右小腿被压伤，脚趾还能动。崔岳不替医官断骨，只让军兵固定小腿，两名车夫用原空车送往南驿；一名营兵护送，车匠老陶同去说明压伤经过。十二人拆作四人医转、八人留院，原路相同，粮与伤者没有挤一辆车。

工匠说自己叫冯石，是来换柱抵房钱的。谁让他独自进屋、为什么没有支撑架，待他受治后再问，不能在疼得说不完整时让他按“自愿冒险”。

崔岳盯着塌梁，终于收起随文：“主仓不能用。”

“这半边不能用。”老陶的同伴许木匠在窗外敲了敲墙根，“西侧是独立石屋，没借这根梁。先查它。”

孟槐带他们绕到后院。石屋原是存木权的秤房，只有两窗，屋顶低矮，空了多年。顾沉舟没有凭它干净就认能存粮。他让木匠从外查看梁脚、墙裂，陈二把不同位置的湿土分开刮取，又问孟槐昨夜漏水到哪。

老人指的是东墙，地上却没有水痕。木匠扒开墙外积雪，发现旧排水口被烂席堵住，水浸在墙脚而不是屋顶。四名营兵在外清口，孟槐和陈二看出水方向；水退后再验屋内，没有把“能扫干净”说成“已经干燥”。

顾沉舟将剩下的空车停在石屋前。门窄，整车不能进，卸粮必须在阶下两人传递。他用小石标出车位，担架路留在另一侧，两户人家的井桶道不占。木匠先搭了两架离地半尺的垫粮木床，只能放十袋，至少等地气与墙脚复看后再收粮。

“才五百斤？”崔岳道。

“五百能认到人。要堆两千，湿粮是谁担？”

崔岳没再催。主仓险梁不是纸上能多写一行便修好的，他带来的六名兵已有一人随医车走。午后他将两兵派去南驿报可用范围，余两兵守院外和井边，自己看门；留院三兵与许木匠、陈二、顾沉舟共六人，不去拆东侧住屋。

孟槐却仍站在木床前：“你们留下兵，下一批人来了，还会不会认今日这句话？”

顾沉舟没有只许一句好听的。他把两户井路、六户住屋与秤房界线画在同一张院图，报请只借秤房五日；柴棚不拆，取井水先按原轮次，兵灶另搭在西院，不能拿住户门板烧火。报图副本与孟槐持有的院图各留一份，转运司若要扩借，须另报安置与修房费用。

旧领木条另外递军需查库，不混进五日借院。他们能立刻做的是让这六户今晚仍有门，而不是把还没查过的钱许成明日一定到账。

孟槐摸了摸纸上的井线，终于把横在门前的旧矛靠到墙边：“秤房那把锁在我这儿。你们要用，我到场开。屋里少什么，先问我，不许问孩子。”

顾沉舟没有接走钥匙。空房由孟槐开，军粮由仓兵守，两种权限不能因为画在同一院就落到一个人身上。

未时，两名报信兵护南驿书记回院，原队在院重新点得八人。书记带来原车清单与驿医回条：五百斤在途粮来源仍是昨日四车余下的十袋，转存尚未发生；冯石已经受治，右小腿压伤待消肿复查，工钱与医费分列，派人留在驿棚看护，不用住户赔此次医转车。

书记愿意次晨试转两袋，先看短路、秤房墙脚和离地木床；余八袋仍留驿棚，不冒险全押一处。罗定收到了院图后，以原驿递回文准五日借房与次晨试转，顾沉舟负责交接与役工安排，护兵归崔岳，封粮仍由独立仓兵执行。

回文刚展，东厢的妇人抱来一卷苇席，想铺在木床上。她说收两枚钱便给兵做饭，再搬几袋也成。顾沉舟谢过她，却让许木匠先挑出湿席。席卷外层干，里面冷潮，压在粮下会把墙脚没退净的水气留住。军兵将干燥木条横铺，孟槐从自家取一小片旧油布试贴墙脚，不碰待运麦袋，暮前若又起水珠就不接粮。

妇人看着被退回的半卷席，有些恼：“你们又要屋，又不要我们干活？”

“能用的付用料钱，湿的别算你的错。做饭要几人、多少柴，明晨来问。搬袋得先查手脚，不让你拿一个价替全院的人领役。”

她把陶锅放到井边，叫来另外两户商量。军队在旧城开灶确实是生计，可谁供柴、谁供水、谁不能出工，得由各家自己说。顾沉舟只记了三个愿意候问的名字，没有让孟槐替六户按一道总印。

八斤路食合计耗五斤二两，医转四人领去的份额包含在其中，余二斤八两退南驿。牛料耗十斤、余六斤留原料袋核回，木枕碎损两根、救人绳磨坏三尺，军需先记救援修料，未摊到冯石房钱里。

申前，顾沉舟、陈二、崔岳、许木匠与一名营兵回南驿，原队另三兵留守，换班另有罗定回令，不把原十二人写作全返。四名医转人员早已在驿棚，借来的两车两牛均核归。留守三人的工食另由驿厨按换班页领，八斤原路食不充五日驻粮。顾沉舟肩头疼得只能将小册放在腿上写，陈二替他将明日要搬的两袋号牌挂在棚内，不能让第二班把试转变成十袋全运。

仓还没有粮，今晚却先有人能安心关门。孟槐送到院口时，说旧城河边还住着别的逃荒人，前几日有人给他们发过带红角的粮票，承诺修渠即可领粮，票上却没写哪一仓。

顾沉舟收下他带来的空票样，注明只是样式，不记成已经发粮。明日不仅要认十袋麦，更要认拿票的人、住的屋、能做的工。

他回头看宁川屋脊。雁回关给他的差事原是一座转运点，落到眼前却是六户人家、一名压伤工匠和一条等待开春的旧渠。要让粮在这里过一夜，他得先让这里的人过完这一夜。
