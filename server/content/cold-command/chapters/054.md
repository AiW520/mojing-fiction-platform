# 第五十四章 山匪借旗

正月二十三天亮，顾沉舟先到宁川秤房。六袋三百斤麦仍在干台上，封线没有移位。昨夜送来的断旗单独放着，仓兵没有拿它去碰粮袋。

急报里说粮被拖走，顾沉舟只在旁边添了“来人转述”四字。夜色、惊牛、伤者，哪一项都能让人把沟底看成坡外。如今要补的是现场，不是一张顺着急报写足的失粮单。

罗定晨令准他与崔岳连三名护兵到南驿接应，只查事故沟，不越北坡。陈二左臂仍不抬重，留宁川报数；孟槐照看民册和井路，两名院兵守门，独立仓兵看粮。顾沉舟带饼六斤、水三囊，伤者由南驿医佐接转，见坡土松动或持械人再现便退到驿口。

出门时何氏问：“今日渠不修了？”

“先救车上的人。闸木不动，工粮也不领。”

她没再拦，把挂在借屋门上的凳子搬进去，免得风雪把新牌砸倒。

南驿口，两名原押车车夫和三名健脚工已等着，其中一人会修车，总共十人沿旧路往沟边走。赵贵左肩缠着布坐在医棚，田七的小腿肿得穿不进旧靴，许木匠手背擦破，另一名车工也留医。医佐只准问一刻，不许为了找车让伤者走回去。

“旗是青底白边，举旗的人喊谢使君急调。”赵贵说，“我们没停，他的箭钉上车辕，牛就惊了。车翻下来，两袋被人拉过草根，我看不到坡下。有人喊粮抢了，我也跟着喊。”

顾沉舟让他指明最后看见袋子的方向，没问他山匪有几个。赵贵眼前当时是牛腹和翻倒的车，他能说清的，比凑出来的一支匪队更有用。

驿丞取来粮棚簿：原存五百斤，先转一百，后来再转二百，宁川已收三百；棚里最后二百斤是甲七至甲十这四袋。昨日押车组将它们移去外棚候修，没领到北送的正式凭据。顾沉舟看过门哨换更记，又问留下看棚的人，两个来源都指向搬棚途中惊车，不是宁川接粮之后再出库。

“那就先从这里找。”他将四个袋号写在木片上，揣进袖里。

沟口盐泥冻成薄壳，箭斜钉在断辕上，车轴一头悬空。崔岳挡住要下去的车夫，用长杆试了两处落脚土。第一处看着平，杆尖却陷到手掌深，底下有流水掏空；他们换到石肩，把短板铺实，再系上退路索。

草根下面露出甲九的袋角。两个脚工沿板靠近，一人托袋底，一人移开压住它的枯枝，先把袋子送上岸。封口未开，袋外湿，复称净麦四十九斤八两，与原五十斤相差二两，差额单列，不用潮布的重量补上。

甲七、甲八在车下。一袋沿缝撕开，另一袋被轴头割破，散麦混进盐泥。车夫俯身抓起一把，急得说：“晒一晒还能吃，报两袋坏了，我赔不起。”

顾沉舟把他的手从粮上移开：“先装隔离袋。账上没说两袋全坏，也没说这把能下锅。”

他们分开收起袋内粮、地上散粮和泥样，注明各自位置。湿粮待晾检后再称可用净重，今日不能给四袋凑一个总数。车夫的赔责也没定，箭、路况、装载和车轴都还要查。

甲十没有在车下。第三名脚工蹲在石肩，指向冰壳下面一条窄缝。袋口卡着草绳，水正一点点冲掉底下的土。

一个车夫解开腰带就要下去。崔岳一把揪住他：“你踩碎这层冰，袋子跟人一起走。”

会修车的脚工从岸上看了地势，让人把长板沿两块大石搭过去。顾沉舟旧肩不能扛袋，便站在上端报板头的位置，用长杆把绳环送到袋身下。脚工俯身套索时，冰面忽然响了一声，裂线一直跑到板边。

“退半步，别拉！”

三人停住，麦袋随着水沉了半寸。顾沉舟等裂冰顺流转开，才让岸上两人缓收绳。袋子离缝时一块碎石崩下来，擦过长板。他们没有伸手抢，先把人撤上石肩，再将袋子拖到铺好的草垫上。

甲十封线擦松，口仍闭着，净麦四十九斤六两。两袋已验合九十九斤四两，甲七甲八仍隔离待检。昨夜那句“两袋被抢”至此只能改成曾被拖移，搬袋的人是谁、有没有粮出了沟，尚无证据。

驿丞派来的县役在岸上画现场图，箭和青白布片分装，盐泥、红票角、裂轴样另存。那枚票角贴在翻车板底，只能证明此处有红纸，不能凭它认定与河滩空票同源。崔岳把落箭角度给县役看，指明坡上两处能站人放箭的地方，却没有带兵去追。

沟边一名车夫指着倒伏的青旗，忽然说认得那针脚，关里军旗也有这种白边。他愿意带路上坡，看对方是不是藏在旧草棚里。顾沉舟问他草棚离这里多少步，车夫说不清，只说追上便知道。

崔岳把剩下的退路索收紧。坡背看不见，箭只找到一支，敌人有多少、是否还留着，都没有独立回报；为了给借旗的人添个姓名，眼前十人就得丢下坏车和湿粮。顾沉舟让车夫把曾走过的路画给县役，报军镇另查，不准拿自己的伤和赔钱恐惧去换一趟无令追击。

车夫蹲了下来，过一会儿伸手扶住隔离粮盆。田七不能抬重，他这趟若再陷坡里，连能把坏粮搬回棚的人都少了。他没再说追，只问这些粮是留南驿还是再往宁川走。驿丞指着隔离架，给他一处能亲眼盯住的地方。

十人把隔离粮和救回的两袋送进驿棚。车夫想把窄车也立起来，会修车的脚工用杆敲了敲轴裂口，摇头。粮能抬，坏车不能再套牛；南驿少了一辆能用的车，明日的搬棚钱和替车钱都要重新找。

午后，一辆完好的窄车停在驿门。驾车人周全带两名脚夫，车轮干净，牛也不喘。他递出旧雁回铜牌和一张急条，开口便点宁川秤房的三百斤。

“谢使君知道你们没车，我正好带来。粮上车，我送到北坡接运点，你们今日就能回关。”

顾沉舟扫了一眼车轴，榫头完整。车来得及时，不代表人有权领粮。他请驿丞看急条，纸上没有军镇调粮编号，交粮地点也不在罗定给他的路线内。

“你从谁那里知道秤房和粮数？”

“押运圈里哪有秘密？误了操练，你这小什长担不起。”周全把铜牌敲在桌上，“认牌便是。”

崔岳没有伸手扣他，只站到驿棚门边。宁川两名院兵始终未离门，周全拿一辆车来，不能替远处的仓兵开锁。

驿丞取来一块写着本次调运地点的木牌，让周全自己读。周全读到宁川便停了，急条写的却是北坡。两处相隔不远，交接的经手人完全不同，他若送错，下一张粮单便会只剩三百斤的空数。

周全说他不识公文格式，只受托拉粮。顾沉舟请两个脚夫各自说出装车前听到的地点，一个说宁川，一个说北坡草棚。他们没有被迫改口，县役分别记下。急条的印样须送转运司核，铜牌须请雁回查旧册，谁也不能在驿里替谢无咎承认或否认这道命令。

“车我肯借，先把粮装上再说。”周全握住牛缰，“一辆坏车要修几天，你算过没有？”

顾沉舟望了眼料棚里折断的轴。修车确实耗时间，五十七人的粥和渠边的脚钱也不会等。但若把封粮交给没有现行凭据的人，眼下的一天省下来，后面可能断掉整个宁川的粮。

“借车另议车钱，取粮等复文。”他把急条推回周全面前，“你要让我们核，就留下原物，驿丞给你收物回条。车和人现在都能走。”

周全迟疑许久，最终留下铜牌、急条，拿走驿丞回条。没有拘票，顾沉舟不扣人，也不让院兵押他；两名脚夫愿意留驿分问，周全带空车向西去了。崔岳望着车轮印，低声说这人连粮数都知道，回去必须加看粮门。

“加警觉，别加不存在的兵。”顾沉舟说，“把原守门的人交代明白。”

申时，罗定转来的短函到驿，确认宁川封粮不动，正式调运复文待转运司回。顾沉舟把今天少掉的车、四名留医者、两袋隔离粮都报上去。宁川那三百斤并没有因此增加，南驿可用粮数也不能写回二百斤。

回程十人点齐，饼耗四斤二两，余一斤八两，水余一囊；板面擦损、短索磨一尺分别交还。没有一个伤者被硬塞进返程队，也没有用四袋的原重填平湿粮缺口。

天黑前，宁川守门兵看见他们空手回来，先问粮呢。顾沉舟指着封在县役箱里的现场页：“粮在该留的地方，明日等检。今日救回两袋，没替一面借来的旗开门。”

渠工粮五十八斤未动，旧十八斤八两仍另存，今日二十斤日赈由驿厨独送。屯田局门前几个等工的人看着他的空车位，脸上没什么喜色。救粮没有立刻变成他们的饭。

顾沉舟把明日能做的岸工排给梁文，先付已核脚钱。他摸了摸被绳索磨痛的旧虎口，知道宁川最缺的不是一张能盖满印的牌，而是不用冒领也能持续运来的下一车粮。
