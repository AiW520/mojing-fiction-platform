# 第四十三章 军功三方签

正月十二，军法司的周判官踏进雁回关，靴上冻着南驿的黄泥。

他随常例巡关驿递而来，没有带黑河原物，只带军镇核准的结功文和一张南驿补料票。两名押递兵把文匣交罗定，随即去领热饭。周判官先问医棚在哪，见过停骑伤兵，才到守将房落座。

谢无咎已经把一份急报放在案上：夺回水口，退敌两人，雁回粮路畅通。

“水恢复七成，溪水仍不供饮用。”顾沉舟将水车页压在旁边，“两人放箭后退走，未见中箭，也没查清堵水是否出自他们。”

周判官把“粮路畅通”折到纸下：“能结的今日结，不能结的不要借军功销案。”

贺兰朔站在门边，右手不能拉弓。他本来以为还要等一季才轮到自己的队伍，直到周判官点出七个名字，才让副骑替他把昨日行路图摊平。

夺水七人各报亲见，郑衡的军令、北楼值哨、水口实量和苏晚棠的伤情互校：七人齐返，泄口打开，木楔两根留槽，半数水量当夜恢复，昨日增至七成。敌人受伤无人见到，斩获栏空着，撑管、护回和受伤分开结。

顾沉舟只认路食、工具和关楼量水回报，不把七人的箭下动作收进自己名下。各人确认亲手所做，罗定签营官栏，周判官签军法复核。三方签押不到半刻，便把“退敌两人”改成“遇弓阻射，保全队伍，复开槽尾”。

奖银从关内已核军赏钱拨，七人各二钱，实取一两四钱，不碰人粮和医耗。留关量水、排车的顾沉舟与陈二按勤务记功，不分骑军射箭赏。旧借护送的功由军镇另核，没有人因为名字漏在一个大总条外便被抹掉。

一名营兵拿到银，第一句却是问木楔算不算他丢的。

“不算丢。”老周指着槽边，“它还撑着管。用料归修缮，不从你赏里扣。”

银终于能揣进他自己的腰袋。郑衡叫他去吃饭，他走到门外，又回头把同伴那一份交给伤手的贺兰朔。不是谁私赏谁，而是这趟没人因救水口白担一笔旧欠。

贺兰朔没有立即走。他把嫂子的申诉回条放到周判官前，没再拿蓝线皮囊当证明：“贺兰真案的原卷借走未回，医册无接收人，家属曾候门却被写未赴。能否正式复核？”

周判官看过独立门簿和废纸领料条，只准两件事：废纸捆停止销毁，白石查卷要报经手与归库记录。借阅人一个“谢”不能认成谢无咎，医册缺尸验也不能认作生还。

“你要的是把案子打开，不是让我替你兄长指定一个凶手。”

“打开。”贺兰朔答。

正式复核文盖下印，原案不得再用“家属未赴”退回申诉。家属补录先由原驿递联络，不逼妇人带孩子冒雪赶关；抚恤全额仍待核，不从当日奖银抵扣。贺兰朔把回条收回时，伤手没有握紧，只用左手压住纸角。

响了数日的哨子第一次没有盖住他兄长的名字。

午前，仓门突然传来争执。谢无咎的随员邵平让两名车夫把四袋已验净麦移往北门内坡，准备来日水槽堵住时直接领出。两百斤粮一出干棚，医棚门前的转弯便只剩半车宽。

顾沉舟赶到时，第一辆车已经架在坡上。粮袋封线齐，票也是真的；问题是邵平按官粮总数排了车，没有给井水和伤架留路。

“北门要预粮。”邵平道，“不在坡口，急时怎么拿？”

顾沉舟用木尺量两轮间的空隙，陈二从医棚推来空担架。担架到第二个弯就卡住，药童侧身仍过不去。邵平看见那只架，脸沉了下来，却不肯让四袋退回：“调一次车又多一次差额。”

“袋不拆，号不改，转去西灶后棚。你亲自核一次。”顾沉舟指向另一条路，“北楼接粮走内墙，井桶走医棚廊，不用争同一个弯。”

西灶后棚堆着柴，若清空要另付半班役钱。罗定不许抽南墙，只准四名当值辅役加两名车夫挪柴，郑衡和一兵守内坡，顾沉舟与陈二核袋号；八名执行人员仍在关内，口粮照今日已领额，不新增路食。一个时辰清出干燥垫木，伤者由药童接棚；起火、架木塌或外哨告急即停，粮留原处，兵先归岗。

邵平握着原票，跟四袋一起移车，没有用换一张签掩掉旧位置。老周验过垫木，发现靠墙的一根已空心，叫人换下。用料三根、役工六人半班，军需核价从修缮役钱出，不摊在奖银上。

最后一袋刚过转角，西坡猛然响角。

两名车夫下意识拉牛，车头横转，右轮一下越过垫木。内坡余雪下面有水，车辕向医棚滑去。陈二握住袋号牌，后背撞上门柱；顾沉舟举杆挡住要扑绳的辅役：“别钻轮下！卡后轮！”

郑衡把矛交给同伴，叫两人抱木楔贴安全侧。老周压住辕尾，车夫先松紧拉的缰，牛头不再被扯向坡沟。邵平没有扔票跑开，他蹲在粮袋另一侧喊号，确认袋还在车上，没有被惊乱的人顺手卸走。

木楔碰到轮边时，一根干柴折断，飞起的尖头擦过辅役耳后。药童立即把他拉出车线，另一人接楔，四袋终于停稳。没有人用一声角把车赶进医棚，也没有人为保两百斤让一个人钻进轮底。

罗定登楼，传下口令：外头只有三匹无旗马，不开门。南墙不动，北门十二人照原岗，郑衡二人不出内坡。

顾沉舟让陈二再报四个袋号，军厨在西灶接报。两张票对得上，袋没破。苏晚棠先包扎耳后浅伤，停搬一日，药布半尺；人粮照发，半班已做工钱照结。新伤算在辅役，不再添入四百四十八名军籍。

邵平看着医棚门前重新空出的廊道，收起那张预粮条：“角再响一声，我刚才就把它们全推下去了。”

“留一条人能走的路，车才退得回。”顾沉舟把木尺放下，右虎口疼得指节发白。苏晚棠不准他再握杆，下午只能查票。

谢无咎过来，先问四袋是否还在，再问多耗多少。他承认西灶可供北楼临时领粮，却要求一旦改作北门守城粮，必须由罗定另定兵额，不能让顾沉舟借两百斤发出兵令。

罗定同意，给顾沉舟一块临时关内勤务牌：“今日起，北楼、西灶、井廊三处的车序与备用担架由你先排。邵平照粮票供物，郑衡照我令带兵。谁堵了救伤路，先来问你。”

不是屯长，也没有仓钥。顾沉舟可以直接叫停关内交接车，不能抽墙兵；换车、修廊和误送的费用却必须当日先报。两个夜班、两名备用车夫的轮换也压到他这里，他先把伤耳辅役从明夜班划下，叫罗定从当值班补人，不延旧役。

下午周判官验过新车位，签认这次挪粮没有改粮额，事故与停工另记。顾沉舟的勤务记功落了三方押，实际获得的是三处停交接权和一张更长的值班表，不是把别人名字吞下的总功。

南驿回报那名转医伤脚夫仍在观察，药童已经按原驿递回关。旧四伤脚夫仍有一人在外，关内人数和驿医份额不重复发。初九后续一千二百斤已验净麦逐日扣领，首拨第四袋四两差仍锁着，没有谁拿新粮到来替旧袋销账。

将晚，北楼值哨看见西坡三匹马后又有步影。

贺兰朔不用望筒认衣服，只看它们停在哪里：骑手没有继续吹角，步影却绕到内坡车口的正对面。第二班墙哨独立报到同一处，人数尚不能数清，背上长物至少四件，像梯，不能认作粮车。

罗定把勤务牌往顾沉舟手里一推：“把井廊留出来，北楼的饭送到墙根。今夜不让他们用我们的车开门。”

顾沉舟先叫西灶熄掉朝坡口照的灯，再让陈二送热饼。他的奖没有一座空田，只有四袋摆对位置的粮和一条不再堵人的廊。可当北楼兵接到还烫手的饼，墙上那一班没有少一个人。
