# 第十五章 一纸升任

换防后的第三日，转运棚的票根终于送进黑河营。

送票的人不是周顺，也不是周伍长，而是一个戴灰帽的老吏。他把一只油布匣放在校场案上，说票根受潮，先由仓曹核验，再入军需总簿。匣中共有七张票，编号从景和十七腊月二十一到二十七，唯独二十四日缺一张。

秦百户将匣子压在手下：“缺票是转运棚的事，不是东仓的账。”

顾沉舟站在案边，没有去碰匣子。他先让陆承把营门出入簿、押运队名册和旧站木牌摆出。七张票中，三张写“西门小仓”，两张写“西墙转运棚”，一张写“南沟歇车五、转出二”，剩下一张只有半个仓号。木牌上景和十七的查验印，与其中一张票的骑缝缺口相合。

老吏赶紧解释：“同一套票，路上换过几次，印缺很正常。”

“那为何二十四日没有票？”顾沉舟问。

“或许夹在别匣。”

“谁交接的？”

老吏报出一个名字：严四，转运棚押票人，三日前病回县城。周伍长听见后，脸色微微一动。顾沉舟没有立即看他，只让门哨把老吏的口供记下，注明他只负责送匣，不负责二十四日缺票。

周校尉让人取来军需房的旧收条。第4章西墙两袋霉粮的短签、第9章乙袋木签、第10章歇车木牌，三者都没有直接的正式仓号，却分别出现了“西门小仓”“西墙转运棚”和“歇车五”。路线开始重叠，粮的重量却始终少一段。

顾沉舟把七张票按日期排开。二十一日，西门小仓出粮四十斤；二十二日，西门小仓四十斤；二十三日，西墙转运棚四十斤；二十五日，西墙转运棚四十斤；二十六日，南沟歇车五转出二；二十七日，西门小仓四十斤。若每张都是净麦，六日应有二百四十斤，可伙房实收、霉损、少袋和补差加起来，少了近八十斤。

秦百户冷声道：“你拿不同日期的票相加，怎知不是军械、马料或地方折色？”

顾沉舟没有急着反驳。他让老吏辨票纸。六张票用转运司熟纸，一张二十七日的“西门小仓”却是粗草纸，边角有麦壳，与父亲旧账残页的纸纹相似。纸纹只能说明纸料相近，不能说明是同一人写；票上墨色也有两种，一种偏黑，一种发灰。

苏晚棠把医棚药耗和五名民夫的押车单带来。第6章救回的人中，石顺记得车头火边有周顺；陈六事故簿被写成坠冰；丁七旧油纸记“西仓七、景和十六”。三类材料仍不能单独定案，却都指向押运队使用过一处旧站，并在票根中留下了对应的名词。

许校尉问：“能不能把这些写成侵吞八十斤？”

“不能。”顾沉舟说，“能写的是：七张票对应六日，缺二十四日票；票上仓号与营门地图不全相合；实物净重不足票面总额，差额包含霉损、乙袋被夹带和仍未核明的损失。要定侵吞，至少还要找到出仓人和转运棚的原簿。”

这话说完，校场上没人立即出声。一个落榜书生把最大的数字拆成四个还没闭合的缺口，听着不像爽快的胜诉，却让秦百户无法用一句“损耗”把它们抹平。

周校尉命军法书吏把七张票、乙袋木签、旧站木牌和押运队名册分别封存。秦百户必须在东仓簿旁补写“二十四日票根缺失、原簿待核”；周伍长要在押运队名单上说明周顺的补名来源；转运老吏则暂留营中，等严四的病报送到。

三方签押写得很慢。周校尉先签营官，许校尉代表换防队签交接，军法书吏签封存。顾沉舟没有把自己的名字写进定案栏，只写“复秤与记录经手”。

秦百户看见那一行，忽然笑了：“你不是最爱让人留名？怎么轮到自己，反倒不敢认功？”

“我认经手，不认尚未查清的罪。”顾沉舟说。

秦百户收起笑。他没有被抓，也没有被夺钥匙，却必须把一张缺票写进东仓账。这一笔责任会留在他名下，往后谁要改簿，都要先解释为何改的是一条已被三方看见的空白。

午后，周校尉把顾沉舟叫到账房黑墙前。火痕已经被石灰压住，周文还在医棚昏睡。营官手里拿着一张军令纸，没有印章，只有营门公印和军法书吏的见证栏。

“营中临代粮什顾沉舟，景和十七年腊月三十起，正式任黑河营伙房什长，领营内粮路一段，辖十名辅兵与借调民夫名册；可调两名门哨作交接见证，不得开东、西仓门，不得越级调兵，不得擅改粮额。每日须报实发、缺额、损耗、伤员口粮和民夫役期。军法复核前，功劳不换田、不换官。”

顾沉舟看着“十名辅兵”几个字，没有立刻接纸。

“换防队四十七人呢？”

“他们有自己的伙房记名。你只在营门到灶房这一段接手，若他们加入夜哨或搬运，另立名册。”

“伤员？”

“赵七、韩魁、周文和五名民夫，由苏医官独立列册。你负责按册拨粮，不负责改伤情。”

“抚恤？”

周校尉停了一下：“陈六等人的役期和脚钱待军法结项。若查实被虚报死亡，押运队要补工钱与家属抚恤；在此之前，伙房不得从他们的口粮里扣。”

这不是一纸只写“升任”的好消息。顾沉舟接过军令，手上增加十名辅兵、两名见证门哨、五名伤民和一笔尚未结清的脚钱责任。周校尉把一枚木牌递给他，牌上只刻“粮什”，没有官印。

“什长不是仓曹。”周校尉道，“你要是把粮路守住，军法才会在卷宗里留下你的名字。”

顾沉舟将木牌挂在腰侧。他没有把旧青衫换成军服，先回伙房把军令摊给管事、老邵、陈二和新队书记看。陈二问：“以后你说停，就真能停？”

“能停我经手的那一袋。东仓不听，我只能把拒绝写出来。”

鲁安站在门边，雪场搬石后肩膀酸痛。他问：“我还能搬吗？”

“能。但每次先报袋号，不能单独去火棚。”

鲁安点头。周顺的空领票牌还放在军法桌上，没有人把他的名字从名册抹掉。惩处留下，粮路也得继续。

苏晚棠送来新的伤情册。赵七膝肿稍退，仍需停工两日；韩魁腕伤可慢慢活动，三日内不能骑射；周文尚未醒；五名民夫中老人退热，石顺脚伤需换布。药柜里的止血布只够一日半，军医署要从县里调药，最快后日到。

顾沉舟把军令上的“每日报伤员口粮”圈出来。

“我会报，但伤情以你这本为准。”

“你终于学会说这句。”

她把册子收回，转身去看周文。两个人都没有谈升任，仿佛新的木牌只是一件多出来的工具。

傍晚，第一份什长日报写完。顾沉舟列出今日三百斤净粮、六袋三百斤二两初称、练队二两损耗、普通队伍减额、医棚十二斤、夜粮二十斤、旧队与新队分账、失票一张、押运队待问三人。最后一栏写明：明日三日口粮按新队、旧队、医棚三册分别报，缺额不得以霉粮填补。

他让陈二和陆承各看一遍。陆承在见证栏按印，陈二在执行栏写“明日照此报数”。

夜鼓响过，伙房门外来了一个陌生人。

那人穿着转运司的深灰短袍，手里没有仓票，只递来一封给周校尉的信。信封上的火漆完整，落款是北原转运使谢无咎。

顾沉舟没有拆。他只看见信角压着一粒细小的黑色盐碱硬皮，和南沟车底取出的样本颜色相近。

谢无咎还未进营，信先到了。

周校尉拆信时，顾沉舟把那粒硬皮封进纸包，没有说它来自哪里。新任什长的第一天，军令写得比昨日更完整，敌人的层级却也从营内仓曹，伸到了掌盐引与商路的转运司。
