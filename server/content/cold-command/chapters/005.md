# 第五章 逃兵的半枚印

第二日天还没亮，营门口便有人喊抓逃兵。

顾沉舟抱着借粮回执跑过去，看见昨夜敲响车铃的窄车横在门洞里。车上只有一卷油布，辕下蜷着个人，左肩披甲少了一枚扣，右脚的草鞋已经磨穿。两名仓兵拽住他的腿，正要往外拖。

“丁七，欠役三日，盗营甲一件。”

押车的周伍长把鞭梢绕在手腕上，认出顾沉舟时，目光停了一瞬。

“又是你。”

顾沉舟没接话。他先看车。车轮左缘缺了一小块，油布边上有新的磨破痕，和昨夜西墙的车不同。人是从营外押回来的，不是从隔离霉粮旁跑出去的。

“粮车呢？”他问。

“什么粮车？”

“西墙那辆。”

“还在西墙。你真想查，自己去看。”

顾沉舟让赶来的老邵去核袋数。九十六斤霉麦取过样，筛过的四十一斤另封，其余连原袋隔离，封线完整。老邵回来报数，他才把目光落到车辕下的人身上。

丁七仰起脸，嘴唇冻得发青，却将右拳死死缩在腋下。

周伍长蹲下：“伸手。”

丁七不动。

短鞭抽向他的手背。顾沉舟伸出回执挡了一下，鞭梢卷住纸角，将他虎口擦出一道血口。

“这是东灶借据。”他说，“打烂了，二十斤没人认。”

“我抓逃兵，你管什么借据？”

“他是谁，门册能核。你要罚，先把入门搜身交给换防官，别把他手里东西打没了。”

陆承从门楼下来，接过回执看了一眼，又把鞭梢从纸上解开。

“你把人送进来，归我点验。要拿回去，带军法条。”

周伍长退了一步。他没有争，只把押役牌丢到陆承脚边：“丁七，三日前离营，没归。牌、甲、人都在，别让他跑第二回。”

丁七这才展开拳头。

掌心是一块断开的铜片，印面只剩左半边，能辨出一个“转”字的偏旁。铜片嵌在皱巴巴的皮条里，断口把掌心割得通红。

“我没偷粮。”他望着顾沉舟，“我押的车，到营外少了。”

周伍长冷声道：“车夫把粮卸了，你人却跑了，还不是你？”

“我没跑。我去找领车的人。他拿走役牌，说送到南沟就算归队，等我回门，他们说不认。”

丁七想爬出来，脚刚着地就摔倒。苏晚棠带着药箱进门，没有问铜片，先剪开他脚上的破鞋。脚趾还会动，右脚外侧却磨出一片溃口，布袜已与伤处粘住。

“冻伤、磨伤。先别走。”

她把热水壶推给老邵，嘱咐只温不烫，再让他用干布包住丁七的脚。丁七仍扭头看陆承，仿佛只要说慢了就会挨棍。

陆承叫旗手找来离营册。丁七确在三日前出门，去向写“南道随运”，预计当日返。出门条上有仓曹小印，并非私逃；只是归门格一直空着。

“只说明准出门。”周伍长说，“不说明准你三天不回。”

“所以要查。”陆承将册子合上，“暂押医棚，门哨轮守，不先按逃兵行刑。”

丁七把头重重磕在门槛上。顾沉舟蹲下，问他铜片哪来的。

“领车人把一块印牌拆开，这半块系给我，另一半他拿着。说交完车拿半牌来换役牌。到了南沟，他叫我搬下两袋，说是换坏粮，转身就没了。”

“谁领车？”

“不知道姓名。左耳缺一小口，用蓝布包头。”

“给你的时候，铜片就断着？”

丁七点头。

顾沉舟没有拿父亲残账去比。破铜与烧纸拼不出一个人。他只让陆承收铜片，连皮条与掌血一起封存，再把“左耳缺口”记在口供后，等另一个见过的人来核。

周伍长说自己只押他回营，不认南沟领车者。陆承照样写了，未强留周伍长。人可以离开，押回的时刻与军籍册却已经留下。

天边泛白时，秦百户来领昨夜短签。

他拿着一张新结粮条，要伙房承认四十斤差额已由西墙霉麦补齐。管事跟在后面，嗓音发干：“他说领了就是领了，不能挑。”

顾沉舟把结粮条放在白布秤旁。

“四十斤是净粮补差。送来九十六斤霉麦，不能拿重量多来算已补。”

秦百户没有发火。他指着入库簿：“粮到营里会损，有人要记。你不接，损就在仓里；仓里一日多记一次损，下月总粮额就会扣。三百人的锅，吃的正是这笔总粮。”

这是顾沉舟第一次听他把理由说全。

“所以要让伙房替仓里吃损？”

“所以别把一口锅当天下。”

“那就请在这张条上写清：坏粮抵净粮，决定人秦百户。今日我把它交军需房，照您的说法算。”

秦百户看着他，手指在钥匙上慢慢收紧。给残损补账和签认坏粮抵净粮，是两种完全不同的责任。

顾沉舟又将东灶二十斤借据摊开。借粮午前归还，三名守夜兵在场确认过；若缺口真的已补，仓曹便应拨出净麦，让伙房还债。

陆承把短签、医官封粮条、结粮条排在一处。他不替顾沉舟指控偷粮，只向秦百户要一件事：结粮条上的四十斤，交到白布秤上验。

“你们要查西墙，就还我仓票。”秦百户道。

“给您抄副，原签送军需房。”陆承答。

秦百户沉默片刻，收起结粮条，叫仓兵从东仓提出一袋净麦。

袋子过秤，去了袋皮，正好四十斤。老邵沿上中下取了三次，没有酸气，没有结团，苏晚棠看过后才准接收。顾沉舟与管事各留实收数，秦百户在出仓栏盖印。

四十斤落到篾席上，伙房里竟一时没人说话。

老邵伸手抓起一把麦，攥得很紧，半晌问：“真能下锅？”

“二十斤先还东灶。余下二十斤补今天，不改昨天缺额。”

老邵低头笑了，笑着笑着又咳起来。

管事亲自扛粮去还，三名守夜兵验过重量，把借据折在掌心。粮债结清，没有拿一斤霉麦顶进去。顾沉舟在门后的木板上划去欠项，留下借出和归还的两日。

午饭时，粥面比昨夜稠了一层。

民夫们端着碗，看见仓兵从白布秤旁走过去，第一次没有急着躲。魏三用勺子在锅底刮了一下，刮出麦粒，抬头问：“明日还这样？”

“明日的粮，明日再验。”

“不写四百、只给三百六十？”

“给多少，写多少。欠的另追。”

魏三没有道谢，把那勺麦压回自己的碗里，给顾沉舟让开半个身位。

顾沉舟走过灶门，虎口疼得一抽。苏晚棠用药布给他包好，说：“会算账也得留住拿笔的手。别再拿纸挡鞭。”

丁七还在医棚，脚伤不能下地，逃役嫌疑也没除。顾沉舟给他送了一碗新煮的粥，等他吃完，才让他在画好的简路上指出卸袋的位置。

丁七没有指向废渡口，先点了旧驿道南沟，又沿河向北划了一段。

“车走这里。领车的说今晚还要再接一辆，赶在河哨换更之前。”

陆承正站在帐外，听见这句便掀帘进来。

“他如何知道河哨换更？”

丁七的手停在图上，想了很久，摇头。

顾沉舟看向北墙。换更时辰在营门值守册，不在车夫手里。这块半印仍不能指认谁，却让营内的粮账和营外的夜路，第一次交上了口。

丁七吃完最后一口，忽然把碗沿转向灯下：“那领车人不是只拿了两袋。他先叫我看袋底，再把一张写过字的油纸塞进车缝，说若有人问，就说车在南道翻过。”

顾沉舟没有伸手去掏他的衣襟，只让苏晚棠先看伤口，再请陆承按军法登记搜检。油纸果然夹在破鞋底，字迹被汗水洇开，只剩“景和十六、西仓七”几个断字。陆承将油纸与半枚铜片分开封存，注明发现时辰和经手人。顾沉舟盯着那几个字，心里发沉：旧仓签的年份，比今日的粮单早了一年，说明这条路未必只走过一次。
