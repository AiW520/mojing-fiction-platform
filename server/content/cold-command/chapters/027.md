# 第二十七章 守粮不是守仓

天亮后，西墙送来的回执先到了，四十斤净麦仍在墙内。

不是二百斤。军需房的副条写得很窄：旧粮受冻，补四十斤，分守火二十斤、换岗二十斤；领受人是西墙当值老卒，复核人暂空，实出日期待三方当面补。那三个空白像三根没有拴紧的绳，稍一用力，整条粮路就会滑开。

周校尉把副条递给顾沉舟：“今日送过去，不能再等。”

顾沉舟看向窗外。昨夜北沟遇箭的车辕还靠在门边，役牛肩上的擦伤刚上药，四袋待运麦仍封在棚里。要送的四十斤不能从那四袋中拆，得由东仓另出；可东仓要开门，就必须让领受、复秤和护送三件事同时有名字。

“我只带粮路，不领出营兵。”顾沉舟说，“请陆承领队，贺兰朔给骑哨。西墙的四十斤分两袋，每袋二十斤，袋口用新封线，旧牌不随粮走。”

秦百户冷笑：“二十斤也要另封？到墙上再分碗，岂不是多一层麻烦。”

“两袋对应两顿。若合成一袋，夜火用了多少，明早便没人说得清。”

周校尉准了。东仓出粮前，秦百户、顾沉舟和西墙派来的老卒共同看袋。白布秤以丁二校过，第一袋二十斤一两，第二袋十九斤九两，合四十斤；多一两和少一两分别记在两袋，不在纸上直接写成整齐的二十。

军令写明：陆承领四名营兵，顾沉舟随队核交，六名已在役民夫负责抬车和轮换，贺兰朔带两名骑手在西北高地看坡；携四斤干饼、两囊温水、六斤马料，沿北沟内线至西墙，午前送达，午后返营。冰裂、三人以上持械、路标被移或车轴受损即撤；伤者由两兵护回，粮可留，不能把人留在墙外。受伤弩手继续留医棚，两名门哨照看，不计入出队兵额。

顾沉舟听完，补了一句：“西墙回程不走来路。若北沟有箭，改走南侧旧石坎，退到烽墩再报。”

陆承在撤退栏上落名。秦百户没有反驳，只把仓钥交给仓兵保管，自己在出仓栏签字。顾沉舟没有碰钥匙，先看两袋新麻套的针脚，确认没有旧牌留下的刮痕，再让陈二把袋号写在车板内侧。

队伍出门时，魏三站在车后，手里捏着一截新绳。

“昨夜那条坡路有人看过。”他说，“今天别只看车轮，先看雪有没有被人踩实。”

陆承让一名营兵探路。北沟入口的雪面果然有三道被风抹平的浅槽，槽宽不够车轮，旁边却有新断的芦杆。贺兰朔从高地打手势，示意西侧没有人影，顾沉舟仍让车停了一刻，取下断芦杆，不把它当成敌人留下的记号。

走到旧石坎，前车轮突然向下陷。

不是冰裂，而是一块垫在雪下的木板松了。木板边缘有旧车轴擦痕，板底却钉着一枚新铁钉。陆承让所有人退到内侧，两个民夫先用绳拉车，另两个压住后轮。顾沉舟没有命人把板拔出来，先让陈二量出木板位置，再把车移过半丈。

“有人昨夜在这里垫过车。”陈二道。

“有人用过，不等于昨夜有人动。”顾沉舟说，“旧道本就有车。”

西墙老卒蹲下看雪，认出木板是旧分水槽拆下的。他说两年前也有人用它垫车，钉子却是后补。时间仍未闭合，顾沉舟把木板和铁钉分别包好，交给陆承押回，不让它们跟粮袋放在一起。

真正的麻烦在墙外。

西墙门下没有箭，只有一辆倒伏的空车。车辕朝内，车轮朝外，像有人在半道上突然卸掉套绳。老卒说这是昨夜值火时看见的车，车上没有粮，却停在补给路旁；他原想天亮再报，没料到急条先把二百斤写进了门。

顾沉舟让两袋粮先停在门内石台，不把袋子直接交给守墙人。西墙四十七人列队，值火的十二人先来，换岗的十二人后到，剩下的人仍在墙上。老卒把两袋分别抬到火房和换岗棚，军需书记、门哨和顾沉舟各看一次封线。

第一袋拆前，老卒问：“你信我吗？”

“我信你在场。”顾沉舟说，“所以要让你在场时称。”

袋口割开，净麦十九斤九两，少一两；第二袋二十斤一两，多一两。两袋合四十斤，差额相抵，却没有被写成两袋都足额。第一袋当夜下锅，第二袋留在换岗棚，领受、开袋和实耗分列三栏。老卒、门哨、军需书记三方落名，西墙没有再出现一个空着的总数。

贺兰朔在门楼上看了南侧旧石坎一眼：“回程有人动过车。”

斜坡下，一截麻绳挂在倒车的轮轴上。绳结不是护粮队所用的双股结，结尾却有一小段蓝线。它与沙沟旧麻袋的蓝线相似，只能说明纤维相近，不能直接认成同一只袋。陆承把绳收起，命门哨先封车，不许军夫凭口头把空车拖走。

四十斤终于进了墙，但回程比来时更慢。贺兰朔让两骑压住高地，陆承带四名营兵走前后，六名民夫空手推车，顾沉舟把两张交接副条贴在车板内侧。有人从墙内喊“粮已够”，顾沉舟没有回头；守粮不是把袋子锁住，而是知道袋子走过谁的手、为什么停过、回去时从哪条路撤。

回到烽墩时，北沟上方落下一片碎雪。

贺兰朔立刻举拳。骑手先看坡，不追、不喊。碎雪落完，露出一道新鲜的斜纹，像是雪层自己滑开的口子。没有人能从这一道纹上说出它何时形成，更不能把它写成昨夜敌人撤退的脚印。

午后，十二名出队者全部回营，役牛无伤，民夫无新伤。四名营兵轮换登记，马料实耗五斤二两，余料交回马棚；干饼用三斤半，温水一囊半，均没有从西墙四十斤中扣。顾沉舟的右手虎口又裂了一线，苏晚棠给他换布，命他下午不准搬袋。

周校尉听完回报，没有说这次护运大胜，只把“护运筹办”牌往前挪了一格。

“以后凡是西墙补给，护粮筹办先看路线，营门和骑哨各留一份。你可以排营内车序和民夫轮换，但仍不能开仓，也不能调兵。”

顾沉舟点头。他得到的不是一把钥匙，而是一段必须每天重新证明的权限。

陈二把那截带蓝线的麻绳放在桌边：“明日还送吗？”

顾沉舟望向墙外越来越厚的云层。

“明日若还送，先看雪。”

夜里，西墙的两顿粮一顿已经入锅，另一顿还在换岗棚。黑河营没有因为守住仓门便安稳，反而第一次看清：真正会断粮的地方，往往在仓门之外。

顾沉舟回到伙房，又把今日的两袋空麻套逐一翻过。第一只袋底有三粒白砂，第二只袋口留着新封线的毛茬，分别记在空袋耗用和封存材料栏。他让陈二把六名民夫的脚钱按实际出队结清，再把垫车木板的半日杂役另开一栏。秦百户看见后问为何把一块旧木头也算进去，顾沉舟只答：“明日若有人说车是自己滑走的，至少知道谁曾在雪里把它垫住。”这不是给木板请功，而是把救车时耗掉的时间和人手留下来。

老邵在旁边把两只空袋翻到火光下，发现袋底各有一处细小磨洞。他没有说是鼠咬还是车轮磨破，只叫顾沉舟把位置画下。两处磨洞会影响下一次装粮，若直接交回转运棚，便可能让人以为四十斤少在路上。顾沉舟把旧袋暂列“不可复用”，又从仓曹领回两只完好的备用袋，备用袋数量、领受人和归还期限另记，护粮筹办的责任随之多了一层。
