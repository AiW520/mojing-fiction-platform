# 第三十二章 三关同额

正月初四天未亮，雁回关的卸粮场先响起了车夫的争吵。

南仓新送到三千斤净麦、六百斤豆料，十二辆车堵在转运棚外。分拨吏邵平把三块关牌压在案上，每关五日净麦一千斤，豆料两百斤。日中以前放车，过了时辰，白石关的押车人就得在风口再熬一夜。

顾沉舟刚走近，便被邵平挡住。

“你是黑河借来的，核本关那一份。别碰总票。”

“我先看袋。路上报净麦，到这里还是不是净麦？”

邵平把秤房门推开，让他自己看。南仓这批粮有入棚车序，押运封泥完整，不能因为黑河少过粮，就说北原每一辆车都在偷。

顾沉舟与雁回仓兵先校铜权，再去四辆不同车上各抽一袋。干粮净重无差，另两袋袋皮结霜，他们换干袋核皮重，霜只在外层，并未灌进粮心。罗定随后派人把交付各关的整批粮逐袋过秤。

一千、一千、一千，确实是三千斤。

顾沉舟将这一行先写清，邵平脸上的戒意稍退。

“既然数没少，就按牌卸。”

棚外忽然有人吹了两声短哨。南墙第二班要接岗了，带队伍长却还在伙房门口催锅。两个兵抬着粥桶从场边经过，桶里稠薄看不真切，提杆却压得很低，几名守车兵闻到热气，都转头看了一眼。

顾沉舟没有去尝。他跟到伙房，看见军厨正在把一只小麦斗翻过来，斗底只落出几粒。

昨日送来的六百斤在哪里，他先问这一件。

军厨拿出领料页：晚食和夜岗已用一百五十斤，今晨领一百二十斤，医棚单领三十斤；三百斤仍在关仓，不算新批分拨粮。顾沉舟带仓兵去看余袋，数与页对得上，却不够关城撑完下一个五日。

“守兵多少？”

“问点名官。锅边天天有人换，光看领粥的人，伤兵会算两遍。”

顾沉舟回到关门。点名官把今日换岗筹码倒在桌上，四百四十八名在籍守兵里，二十七名住医棚，名册、岗次和实际出门各有一页。军厨接着报出五日常食需求：守兵、辅役与在役民夫合计一千四百斤，按现行减额，不是足额。

他又去医棚，苏晚棠把二十七名军伤和四名伤脚夫分别列出。昨晚带回的年轻脚夫只是其中一人，不能再添一次。病食细粮已包含在那一千四百斤里，药、柴和热水另外欠，豆料不能掺进人锅凑数。

三百斤旧存加一千斤新分，差一百斤。

顾沉舟没有立即找罗定。他先把关门点名、关仓余粮和两处锅耗互相核了一遍，再问后五日的新粮什么时候到。

仓兵说：“看长坡。坡通就到，坡堵就等。”

昨夜压在辕下的腿，此刻比任何一句等候都重。

棚里，白石押车头正准备落栓。他姓姚，回程要走碎石岭，两辆旧车每辆只能稳载四百斤，余下粮得用备用小车。豆料的两百斤若压上去，牛在坡顶就得停。

邵平说：“三关同额，谁也不能少。你们白石兵少，分得不少了。”

姚车头把车上的绳扣砸在案边：“人少，坡不短！少一车，我们后天怎么来？”

顾沉舟这才伸手按住待卸的木签。

“我不改你的票。车还没出棚，给我半个时辰看白石的回执。”

姚车头以为他也要扣粮，正要骂，顾沉舟已走向守在火房外的白石递报兵。递报兵携关印封筒，里面不只有要粮条，还有上次收到七百斤的回执与医棚领料副页。顾沉舟让关门点名官开验，没经姚车头递手。

白石在籍兵二百九十六名，关内辅役和民夫另册；五日减额需求一千零四十斤，关仓尚有二百八十斤可用，已扣出不得动的待验湿粮。纸上足够，车上却装不下，更怕窄轮小车在碎石岭折轴。

黑河的递报兵也在。他带来的最新余粮条有周校尉营印，军厨耗粮副页与新队书记抄记分开装筒。黑河五日需一千一百斤，可用旧存二百三十斤，不含霉粮、待报损麦和未结差额。新拨一千斤能续锅，不能让旧欠自动销账。

三关没有哪一关是假饿。只是同额粮下去，有的剩在仓里，有的困在路上，有的连当夜都等不得。

顾沉舟在车板上排出袋数。邵平看了一遍，低声说：“转运使定同额，是为了谁也别先抢。改成按各关自报，谁报得狠，谁就拿大头。”

“所以不凭一张要粮条。”顾沉舟把点名筹、仓余和独立耗粮副页放在一起，“今天只补已经核过的缺口，余下按原票走。不是给谁开一张永远的口子。”

罗定进棚时，白石车夫已经牵牛到出口，雁回的军厨也堵在粮袋旁。两边都等不得，一个怕风雪封路，一个怕夜里断锅。

顾沉舟向罗定报了最短的办法：一千斤仍归雁回，再从白石的一千斤里借拨两百斤，白石八百斤配二百八十斤旧存，能满足五日一千零四十斤需求，留四十斤机动。雁回旧存三百加新粮一千二百，满足一千四百斤需求，留一百斤。黑河一千斤不动。

“借拨，不销白石的额。下一批先还两百斤。白石递报兵须先确认余粮条截至今晨，没有把路上的粮算进仓；若有变，就停借拨，重新报军镇，不能逼他们再减一次。”

递报兵取出临行补条，白石仓曹写明前夜实余，医棚另报清晨领用，扣去这一笔，恰是二百八十斤。两页不是同一只手写的，仓号和领用时辰也对得上。

姚车头仍攥着缰绳：“我们的两百斤要是还不上呢？”

“先停雁回的机动粮，再议别的。不能让你拿一张新空票回去。”罗定将随身小印压在借拨条上，又指向军厨，“今日晚锅按原减额，不因多留两百斤就加一勺。后头还债要从这里算。”

军厨将已经提起的添粮斗放回去。守将也不能吃完了新增粮，再让白石替他饿着。

罗定看向姚车头：“八百斤，你两辆旧车能拉？”

“能。但豆料得跟小车。”

“小车还能跑吗？”

姚车头犹豫了一下，带众人到车尾。右轴榫已开裂，只用铁丝箍住。顾沉舟蹲下，碰了碰裂缝里的新木屑。姚车头没有故意装坏，是下长坡时咬坏了轴，再往碎石岭走，车和料都可能留在半山。

罗定准换一辆雁回空车。关内自己的回运便少一辆，顾沉舟主动接下明日合车调度；白石借车有归期，不能把关城备用车送出去就不管。

邵平仍不肯拔木签：“你们都答应了，转运司总票谁担？”

“我担临时借拨，雁回存粮作偿。”罗定说，“你在原票旁留差，不替我抹平。”

事情到此才真的变。顾沉舟没有资格一句话让三关转粮，是仓余、耗用与回程车况逼出了一个可执行的选择，守将也把追责接在自己名字下。

借拨的两百斤尚未下车，场外突然响起牛蹄乱踏声。

出口那辆旧车的牵牛受了惊，倒退着撞向卸粮木坡。姚车头扑去扶辕，另一人急着拽缰，反把车头扭向雁回那四袋借粮。若粮袋滚下坡，今日每个数都要重来。

“人退车侧，别挡轮！”郑衡喝道。

顾沉舟看见牵绳扫向木签，立即用脚拨开空垫木，不去抓重袋。陈二和两名民夫按护运练过的动作拉住尾绳，郑衡带兵从侧面压辕；贺兰朔上前蒙住牛眼，沿着牛颈缓缓顺下手。牛终于停止乱蹬，车轮卡住了新楔。

惊牛的缘由很快找到：旧轭内侧裂起一根硬刺，扎进牛肩。赶时间不能成为让牛带伤再跑一岭的理由。姚车头拆轭，换上棚内备用木轭，兽医清理伤处，判可轻载慢行，不许打鞭催坡。

换车、换轭耽误了半个时辰。罗定另令四名营兵护白石车至碎石岭南驿，姚车头仍带原队，不添伤民。去程十里、日落前交驿即回，路食八斤、牛料十二斤另拨；遇塌石或敌骑拦岭，退雁回，不绕野沟。伤者用新空车底的折架运回，不留坡上。

这笔护送耗用由关内另外承担，没有悄悄挖掉白石那八百斤。

日中过后，车终于出了关。

顾沉舟站在粮坡上，看着白石两辆主车过门，借出的空车载豆料跟在后面。雁回的两百斤先入干棚，军厨没有自行抢袋；复核接收后，当晚两班守城的锅有了确定来源。

邵平把三块同额牌重新挂回去时说：“你补了一百斤缺口，也欠了白石两百斤。人知道粮是谁留的，谢使也会知道。”

“两百斤不是我的功，是雁回的债。”

顾沉舟把欠额写进下一批首拨的位置，不与黑河西墙十斤、沙沟六两或河坡损耗并在一起。三关暂时能续五日，不等于长坡修好了，更不等于马料、柴药都已足额。

暮色里，南墙换岗的伍长拿着空桶走过，脚步比清晨稳了些。他没道谢，只问顾沉舟：“五日以后呢？”

顾沉舟看向长坡方向。明日合车、排水、还车、确认白石余存，一件都不能等。

关外这时进来一名驿骑。官筒交到罗定手上，邵平读完只说了四个字。

“谢使明到。”

顾沉舟没有撤掉车板上的分拨数。粮已经进锅，借车已经出门，他得拿着做成的事和未还的债，见那个定下三关同额的人。
