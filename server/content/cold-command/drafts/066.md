# 第六十六章 京营点名

二月十二日卯正，京营校场的雪还没有扫净，点名木牌已经立在北墙下。

顾明夷先到。他没有把北原护卷的四名护兵带进校场，只让崔岳和一名护兵在外廊等候，另两人留在军驿守车骡。京营主簿站在木牌旁，手里捏着一张补员令，像是专门等着有人把缺额填得好看。

“今日点弓手，十五人可练，两个待医，三十七个缺额。”顾明夷把昨日验兵页摊开，“按这个报。”

主簿看着空出的三十七格：“你弟弟带来的四人会骑会护，先挂弓手名下，今日领练箭，明日再撤。”

“不挂。”

“只挂一日。”

“一日也会变成已入营册。”顾明夷把补员令压回去，“他们有返程护卷军令，不是京营兵额。”

主簿冷笑：“你守着三十七个空格，校场就能射出箭？”

“空格不能射箭，伤兵也不能。”

点名吏按木牌唱名。十五名可练的新兵依次走到白线内，每人报姓名、昨日练弓时辰和领箭数。两名手臂肿胀的兵站在医佐旁边，没有被叫到队尾充数。顾明夷让医佐当面写停弓一日，明日复查，不把休息写成逃训。

一个名叫赵戈的弓手偷偷把右手藏在袖中。教习递来空弓，他咬牙抬臂，弓背刚离架，手腕便颤了一下。

“放下。”顾明夷道。

赵戈低声说：“我能站，不能再少一个。”

“你今天少的是一日弓，不是一个人。”

赵戈仍不肯松手。顾明夷走近，先看腕背肿胀，再让医佐按压两处。赵戈吸了口冷气，医佐便在停弓条上添了一行“轻伤，今日不得引弦”。一名教习想把他改成步训，顾明夷也没有答应：“步训可以，弓料不领，明日复查后再定。”

主簿在旁边提醒：“少一人，练箭就少一束。军械房不会按十五人多发。”

“按十五人发。”顾明夷说，“赵戈今日不领，他的那份归库，不能拿未领的一份去填另一人的手里。”

军械吏搬来四束练箭，封签上写着东墙营、北廊营、外校场和备用。主簿指向最后一束：“既然缺三十七，备用先给你们，明日补员再算。”

顾明夷没有接：“四束各自封存，先核领用。”

他让军械吏逐束念封号、箭数和领受人。东墙营已领一束，北廊营已领一束，外校场一束，备用一束。三束封签有军械房朱印，备用封签却少了一个交接时辰。

“少时辰的备用束不能发。”顾明夷道。

“只是漏记。”军械吏道，“弓手今天等不起。”

“正因为今天要用，才不能让漏记的箭先离架。”

他让许简从外廊进来。许简没有带乙七原箱，只带了顾沉舟允许的三张摘要，其中一张写仓房支一百八十与军厨领一百五十的差三十。顾明夷看一眼，没把粮账和箭账混成一案：“箭束另记，粮账等户部回文。”

主簿却抓住了这句话：“你弟弟不是来查京营么？既然能查粮，也该顺手查军械。把他留在校场，今日两边一起办。”

顾明夷看向外廊。顾沉舟站在那里，右虎口缠着新布，左肩衣襟比昨日更硬。他没有越过白线，只等京营决定是否让他入内。

“粮证已在户部案上。”顾明夷对主簿道，“点名是京营自己的事，不把他的问询拖成军械经手。”

顾沉舟隔着廊门说：“若要我看箭束，请先给经手页和封签，不要把一张京营缺额令当成查粮授权。”

主簿脸色微沉。京营想让北原来的人同时背下粮、兵、箭三项责任，顾明夷却把每一栏的经手人挡在各自门内。

点名继续。十五人分成三组，每组五人，先做步法、空弓和短距离引弦。没有真箭，校场少了声势，却能看出谁肩稳、谁腕抖。赵戈被安排在步训线后，医佐每隔一刻看一次肿胀，不让他用一只手撑住另一只手装作无事。

第二组一个高个弓手问：“那三十七个缺额怎么办？今日少了，明日还会少。”

“我报缺。”顾明夷答，“补员由京营找，练箭按实到领，伤兵按医条停。三十七个空格不能靠四个护兵遮住。”

高个子抿着嘴。他知道这样报，京营可能少发弓、少给练食，甚至把补员责任压回本营。但顾明夷没有给他虚假的满额，也没有把责任推给校场下的十五个人。

一刻后，备用箭束的封签终于查到。军械吏承认它昨夜被搬到器械房，早晨才移回架上，中间没有交接时辰。顾明夷让它继续封存，另取三束按十五人的练数拆领。

“三束够十五人。”军械吏道。

“每束拆出的余数回库，领受人逐组签。”

他不让军械吏把整束交给教习再自行分配。教习逐组点数，赵戈那份空缺单列，剩余箭支封回小匣。没有人能把赵戈的停弓条撕掉，拿他的份额补给一名熟人。

午前，京营主簿送来补员回条。三十七名缺额仍在，十五人可练、两人待医，另列四名外来护兵不得入册。顾明夷在回条上签“已见”，没有签“已补”。

主簿递笔给顾沉舟：“既然你也在场，户部三十斤用途未核，不如顺手把京营今日粮领签了。仓房说一百八十，军厨说一百五十，你认哪个？”

顾沉舟没有接笔。他让许简把户部核见摘要送到京营粮曹手里：“我只认见过的页。今日京营领食，要看今日仓门、灶单和实际领受人，不能拿昨日三本总账替今日开锅。”

粮曹皱眉：“你们一个个都要独立页，缺粮时谁负责？”

“经手的人负责。”顾沉舟道，“缺粮先按现有实余申请，不能把没见过的入仓数写成我签过。”

顾明夷把京营点名回条收回自己案夹：“弓手缺额我负责补，今日少领的箭我负责报，伤兵停弓我负责复查。粮账不是我的经手，我不替弟弟签。”

兄弟两人没有互相递笔。京营想把缺额、粮差和军械漏记压在一个上午解决，最后只得到三份分开的回条：十五人可练、两人待医、三十七人缺额；四束箭中备用束封存待查；今日粮领另按仓门和灶单核。

申初，赵戈的腕肿退了半分。医佐允许他随队走步，不许摸弓。赵戈站到队尾，看着十五人把拆出的练箭送回器械房。他没有因为停弓被抹掉名字，也没有因为缺额被当成已经补齐。

顾沉舟回到军驿时，户部联核回文已到。乙七、乙十七两箱继续分开，军法司明日携原押运封案，转运司携支领册，京营则要交今日点名与领箭页。三十斤用途还未找到，四束箭的备用封签也未复原。

顾明夷站在驿门边，看着那张三十七人缺额回条：“主簿说我报得太直，会让京营少一季箭料。”

“他没说错。”

“可若我把四个护兵写进去，明日你押卷回北原时，谁来守车？”

顾沉舟没有回答。他看见兄长手上的弦磨，又看见自己夹层里三张互不相认的摘要。今日点名没有让任何一项变得好看，却把该由谁承担的责任留在了谁的桌上。

夜色落下前，京营器械房送来一张补注：备用箭束昨夜确曾离架，搬运人、时辰和归还人明日再问；京营粮曹另请户部协核三十斤用途；军法司的乙七原押运单尚未开封。

顾沉舟把补注分别夹入军械、粮账和乙七三栏。父亲腊月旧案仍在更远的地方，三十七名弓手仍缺，京营的刀却已经开始在账房里磨响。
