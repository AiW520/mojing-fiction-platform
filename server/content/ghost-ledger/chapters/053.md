# 第五十三章 一具没有功劳的尸体

停职后的第三日，北镇西墙外的冰渠塌了一段。巡渠卒先发现一只露出水面的手，手背没有军籍纸，指甲缝里却嵌着白蜡木屑。贺停舟依规让两名无涉案医官先下渠，陆昭站在白线外，只记录他们报出的尺寸和位置。罗衍把收尸车停在上风口，车轮没有压过渠沿的旧痕。

尸体被抬上来时，脸朝下，腰间挂着一枚空木牌。木牌背面只有半个“弥”字，刻痕被冰水磨平，正面原有的编号已经削掉。许青棠没有急着喊出曹弥的名字，她先检查腕骨、牙列、旧伤和衣料，再让阮遐把水渠沉积物分成三袋：白蜡木屑、青白砂和黑色细粉各一袋。

“死亡不是功劳。”她对围观的书吏说，“先验尸，再谈他是否曾经替谁完成过什么。”

陆昭在白线外听见这句话，手指无意识摸向拇指旧茧。停职告示规定他可以提出事实异议，却不能触碰尸骨，也不能单独决定尸体进入哪一柜。贺停舟问他是否要参加验尸见证，陆昭点头，但让罗衍先报尸体编号，自己复述编号，不作身份判断。

第一轮验尸确认尸体已死至少两日。肺内有细沙和冰水，舌根没有黑粉，颈部有一圈不连续的浅压痕，压痕右侧深、左侧浅，不能仅凭形状判为绞杀。右腕有旧烧伤，左小腿外侧有十七年前的骨裂愈合痕。衣襟内缝着一小片油布，油布上写着“北坡，三日”，有真实笔压，却没有姓名。

许青棠将油布移入纸盒，说明“北坡，三日”只能证明有人写过这句话，不能证明死者是谁，也不能证明他要去北坡。贺停舟看见旧烧伤时脸色变了，问是否与乙巳年粮仓火案有关。许青棠没有回答，先让医官测量烧伤边缘的疤痕宽度，再把旧案材料调来比对。

旧功单很快被贺停舟从双钥柜里取出。单上记录的军需官只写“曹”，没有完整姓名；第三户撤民栏旁留有一枚指印，和尸体右手指纹的弧线相近，但指纹拓样来自不同纸面，且尸体手指泡水变形，不能直接认定同人。司空烬的院吏要求把“曹弥”写入尸体编号，贺停舟拒绝，陆昭在异议栏补上“半字木牌与空栏存在待比关系”。

第二轮核验来自水渠。冰层下找出一只白蜡木箱，箱角有两道平行车痕，宽度六尺一，与无人村车痕接近；箱内没有粮，只有三枚铅封、半张接收回单和一截黑麻绳。半张回单的“已”字有笔压，“收”字被水泡开，接收人一栏完整空白。黑麻绳的一端打三道半结，与早年车夫尸体上的结法相似，但纤维带盐霜，不能据此并案。

司空烬站在中门外看完物证，问陆昭：“如果这具尸体就是曹弥，他临死前未完成的事是什么？”

陆昭没有回答身份先行的问题。他指出目前只有半字木牌、旧伤和空栏三组关系证据，尚无牙列、家属、本人旧印或同僚见证形成独立身份链；即便身份确认，也不知道死者是否想让谁接收粮、撤民簿或揭出空栏。功簿第一步都未完成，不能凭掌院一句提问记录未结之功。

司空烬没有发怒，反而让书吏把“未能回答”记在公开栏。贺停舟接着问，既然尸体没有功劳，为什么会出现在封存水渠。院吏从半张回单上拓出一枚旧印，印文只有“北镇粮”三字，印泥边缘有刮擦。许青棠指出刮擦方向由外向内，可能是回单被揭下再压回，也可能是水泡导致纸纤维回缩，无法指向操作者。

罗衍在渠底发现一块薄铁片。铁片一面有白蜡木箱的木纹压痕，另一面有细小针孔，针孔间距与第50章总表留下的三孔不同。陆昭只能提出应分柜，不能说铁片来自功簿院或关后无人村。贺停舟让人把薄铁片、木箱、回单、绳端和尸体衣料分别封袋，所有封袋由两名接管人同时按印。

尸体的胃里没有粮食，只有少量烤麦壳和一种苦涩药渣。许青棠让医官比对军医署甲三药袋，结果药渣盐分较低、树脂比例不同，不能写成许青岚用过的药。她又检查死者右腕旧烧伤，发现伤疤底部有一条与铁环相合的弧形硬结，像曾长期佩戴窄环，却没有磨断的皮肤。窄环被谁取走、何时取走，仍缺现场证据。

下午，北坡来了一名老人，自称曹弥的叔父。他带来一把旧铜钥匙和一份家谱，愿意辨认牙列，却只同意把“曹弥可能失踪”记录进家属见闻，不同意把尸体功劳交给任何人。老人说曹弥当年负责验粮，曾在乙巳年冬夜带回一只没有编号的白蜡木箱，之后便与家中断了联系。钥匙的齿口与水渠木箱锁孔不合，家谱上的出生记载又缺少官府印，无法单独完成身份确认。

陆昭听取老人选择，逐字复述为“同意辨认牙列和记录家属见闻，不同意代领功劳，不同意把失踪写成死亡结论”。他没有签收结果，只让贺停舟和许青棠共同见证。老人按印后，黑簿仍无变化，尸体没有因此获得未竟之事。

司空烬却在傍晚拿出一张密封的西关回执。回执上有曹弥的全名和一枚与旧功单相近的指印，日期正是乙巳年封门后的第三日。接收栏写着“本人已验，暂不入功”，下方却被红线划掉。掌院没有把回执交出，只让陆昭隔着玻璃看了一眼，便重新封回袖中。

“这是我的筹码。”司空烬说，“若你们承认尸体身份，我可以让西关原件入北镇复核；若仍坚持半字和旧伤不足，我就按无名尸处理，曹弥的家属和旧功单都不能进入同一审计案。”

陆昭看着那枚模糊指印，知道掌院说的是程序，不是虚张声势。可一张未交出的回执也不能替本人选择，更不能把没有功劳的尸体写成有功。停职告示让他失去开柜权，却没有夺走指出证据不足的资格。

“你可以把回执列为存在过的证物。”陆昭说，“但在原件、来源、指印和本人选择都没有公开前，它只能是筹码，不能是结论。”

司空烬收起密封袋，答应把回执的编号和封存时刻写入审计板，却不承诺立即交付。北镇西墙下，尸体被送入无名柜，柜外暂不写曹弥。油布上的“北坡，三日”被压在编号下面，像一条尚未找到接收人的路。

夜深前，许青棠复测陆昭左手。失痛没有恢复，浅裂边缘因寒气发白。她让他辨认三只封袋，陆昭将“水渠木箱”和“白蜡车痕”交换，立刻停口，请贺停舟复核。停职并没有让反噬消失，反而让每一次错误都必须由更多人承担。

黑簿在无名柜旁显出一行极淡的字：无功，不等于无事。陆昭没有伸手触碰，任由那行字在灯下慢慢褪去。尸体尚未有功，案件却已经把旧案、家属和掌院的筹码拴在同一张空白回单上。

临封柜前，许青棠又要求补做一项排除。医官把尸体衣襟内的油布与曹弥叔父带来的旧粮票放在不同玻璃片上，先看纤维，再闻油脂。油布有冰水浸泡后的酸味，粮票却残留松烟；两者都来自北境常见的粗纸，不足以证明同一笔交易。老人想把油布上的“北坡，三日”认作曹弥字迹，许青棠让他先写一行同样的字，结果字口相近而收笔不同，只能记录为家属印象。

曹弥叔父听见“家属印象”四字，问是否连亲眼见过的旧字也不能算证据。许青棠解释，亲属见闻当然可以进入证据，但必须写清它证明的是“曾见过某种写法”，还是“此物确由某人书写”。老人愿意接受前一种范围，拒绝后一种替代；他在选择栏签字，并要求三日后若找到旧账本，自己可以重新提出比对。陆昭把这一项期限写进复核单，承认本人选择可以改变，但不能被旁人提前扩大。

药吏随后称尸棚木门曾被人擦拭，可能造成衣襟油布位置移动。贺停舟让两名守尸卒分别说明最后一次开门和封门时刻，发现一人只看见门栓，另一人只搬过火盆。两份见闻没有重叠，不能拼成“油布一直在衣襟内”。许青棠因此把油布的原位改记为“封柜前可见”，并保留“此前位置不明”，不因新一轮排除而补写缺失时序。

没有功劳的尸体被放进单独尸棚，任何人都不得因无功而少一层验尸。医官确认身份候选、死亡时序和伤口范围，却没有找到相关活人接收对象。陆昭把差役工钱、尸体保全和未竟之事分账，问司空烬是否愿意让无名尸继续占用粮油。掌院答应基础保全，但拒绝把保全费用包装成结功，这个选择本身成为制度记录。

贺停舟因此把无名柜的状态改成“三重待核”：尸体身份待核、死亡原因待核、未竟之事待核。每个待核项旁边写出下一步负责人和截止时刻，却不写“等待掌院裁决”。司空烬的院吏提出删去最后一句，陆昭在白线外提出异议，贺停舟保留原句。停职后的陆昭不能开柜，但仍能阻止程序把证据空白写成上级意见。
