# 第八十三章 九镇共证

九镇共证会没有设在皇城的正厅，而是在北镇外仓与旧驿路交界的验物厅。厅门朝北，窗纸被风吹得一张一张鼓起，桌上没有悬挂大胤九镇的总图，只摆着九块大小不一的木牌。每块木牌背面都刻着本镇的封签号，正面留着四行空栏：事实、证物、本人选择、后果承接。

前一日，第四镇记录队交清南汊村副册后，卫岑持两镇通行签把陆昭接回北镇。第四镇原件留本镇，同行只有经本人同意转抄的数字和拒收范围；陆昭在路上两次下车核对里程，不能独自判断方向。返城时贺停舟重新验了他的停职牌，准其在白线外听会，不准因此恢复印权。

司空烬坐在最末一席，面前只有一盏冷茶。他没有把院印放在桌上，反而让秦衡将印盒封在木匣里，交给三名不同镇的文吏共同看守。贺停舟看见这个动作，慢慢抬起眼：“掌院今日不盖总印？”

“总印只能证明院方在场。”司空烬说，“不能证明九镇已经同意同一件事。若有人需要调粮、撤民或封门，按本镇四行分别签，不得把我的在场写成你们的承责。”

陆昭坐在白线之外，面前是一块写着“事实观察”的薄木牌。他的左手裹着新换的布，裂口不痛，指尖却像隔着一层霜。记录吏先读了一遍边界：不得开三钥柜，不得触碰黑簿原册，不得查看尸骨，不得用听骨，不得替缺席者复述选择。陆昭点头，随后又问：“我能纠正别人把空栏读成拒收吗？”

“能。”贺停舟回答，“但你只能指出字面和证据不合，不能替他们补上另一种意思。”

第一块木牌来自第二镇。阮遐没有亲到场，由药房文吏带来她的副册，副册外有两层封签，分别写明抄录时刻和复核时刻。文吏报出九袋粮的损耗：六袋有旧路条，三袋接收栏空白，其中两袋曾换线。半袋损耗发生在撤民分装，已有一名伤员签领，另一条路线仍缺接收人。

顾衡把北镇底粮账摊开，与第二镇账面并排。两本账上都有“三日”两个字，却分别指北镇留存期限和第二镇搜寻队的实耗期限。有人试图把两项加成六日，陆昭低声说：“这是两个时段，不是一条延长的粮线。”

文吏停笔，请顾衡和第二镇来人各自重述。顾衡承接北镇拨粮与实耗，第二镇文吏承接回城伤员的领取时刻，谁也没有把八名未归者写进领取栏。那名自行回药房的伤员通过阮遐的签押，只选择承接自己的擦伤和回城路线，拒绝替废井无名尸选择身份。第一块木牌的“本人选择”因此只写下一人，空白处保留，不用横线填满。

第三镇的木牌浸过水，边缘卷曲。贺勉将三船归航的巡河册、倒扣摆渡船的缆绳拓图和两张未完名册放在桌上。他只承接亲眼看见的船数、缆绳断口的位置和酉时水流恢复普通方向，不承接“七船未归”的推测，也不承接黑蜡陶罐里是否装过人的结论。

一名院吏指着名册说，三船归航、两船待核，正好可以填成五船已核、两船失踪。贺勉没有争辩，只把三张不同时间的名册摊开：“这一张写的是未完成登记，不是出航总数。你要填七，先找出七从哪一页来的。”

许青棠从皇城发来的复核函在这时拆封。她将黑蜡陶罐的植物茎、河岸芦苇和第四镇浅水沟的黑蜡分成三类，注明目前只能证明颜色与触感相近，不能证明接触、操作者和时间顺序。函末还写着她右肩牵痛未缓解，今日只主持盲验，不签认任何死亡结论。

第四镇的木牌由小岚的母亲亲自送来。她只愿在本人选择栏写下女儿的小名和出生物件索引，不同意把梦中听见的陌生大名写进户籍，也不同意由旁人替她确认祠堂白牌上的空缺。接生婆尚未到镇，红布包仍封在药房，不得打开。那名母亲说完，自己在后果承接栏写了“愿按小名领药，不承担大名核验之前的户籍责任”。

司空烬看着这句话，许久没有落笔。他原本准备的统一格式里没有“只承接一半”的选项，秦衡只得另取一张空白副页，注明这是临时扩展栏，扩展理由由院方承担，不由第四镇承担。

第七镇、第八镇和第九镇的证物随后依次打开。白粉、木屑、湿木、半个“回”字木楔、旧镇名铜钱和空匣，每一件都先报来源，再报封签，再报是否允许盲验。第七镇车轮白粉与北镇石槽白蜡颗粒在显微下出现相近的亮点，却在盐分和熔点上分开；第九镇空匣内壁有一圈擦痕，不能凭“空”字认定有人取走过功簿。

第五镇与第六镇带来的并非奇物，而是迟到的签领单。第五镇两辆药车只到了一辆，另一辆停在封路桩外，押车人承接停靠地点，接药人只承接到手的一箱。第六镇换班烽台有三处空缺，守台卒愿意承接自己代守的一更，却拒绝替未到岗者写“临阵退逃”。司空烬让两镇把这些不整齐的数字放在木牌正面。若为了凑成九镇同灾，把迟到的车和空缺的岗都写作诡物所为，救援次序当晚就会被改错。

验算员逐块量取木牌湿痕，发现九道痕的起点高度并不相同。两道来自木牌底边，三道落在封签旁，另四道只在搬运者手指可触的背面。秦衡提出是不是封柜时沾了水，锁匠便取同批未使用木牌作对照，又查九名搬运者的手套。对照木牌干燥，九人中只有一人的手套受潮，而且沾水位置与湿痕不合。这个结果排除了一种偶然解释，却不能把九道湿痕合成同一个接触者。

当九块木牌并列时，厅内没有出现想象中的共鸣。铃绳没有收紧，门槛蜡膜也没有变厚。只有陆昭听见墙外排水槽深处传来三下闷响，间隔并不等同九镇回报的时刻。他抬头想说“第三段石槽在应答”，话到嘴边，先看向记录吏：“这是我的听见，不是方向判断。是否记入，由在场各镇选择。”

贺停舟同意记在异常现象栏，司空烬要求标明未作同源推断，第三镇文吏则要求把声响与河灾分开编号。三种选择都写下后，墙外闷响停止。没有人因此宣布九镇共诡，更没有人把九块木牌合成一张总功单。

会盟最后只形成三项共同事实：九镇都出现过材料无法立即解释的异常；救命物资在不同镇发生过可核对的损耗；各镇仍有缺席者、待核者和拒绝被代认的活人。司空烬在院方栏写下“承担统一格式的迟到与补页”，贺停舟在北镇栏写下“承担外仓、粮仓和三钥柜的实际守护”，卫岑写下“承担封线和撤民调度”。

会散之前，许青棠又送来一封短函，要求所有被总表引用的伤情都回到原镇复核。北镇巡骑耳道出血、第二镇麻绳擦伤、第三镇水卒撤回的口述、第四镇炭笔男子的水泡，不能因为列在同页就变成同一场反噬。她把自己的右肩牵痛也填进署内值守记录，注明代掌医官已接过抬箱职责。司空烬看完，命院吏把“九镇伤者”总数后的句号改为分号，附九个仍可撤回的来源编号。

陆昭的薄木牌没有新增功劳。记录吏问他是否承担九镇共证的复述责任，他看了一眼九块分开的木牌：“我只承接我听见、我复述并被两名在场人复核的部分。其余八镇的事实，由各镇自己带回去。”

夜深时，秦衡收起九块木牌，发现每块背面都多了一道极细的湿痕，像有一扇看不见的门在木纹里开过又合上。湿痕没有笔压、没有指印，也没有通向任何一镇的方向。司空烬要求原样封存，禁止用总表覆盖。

九镇共证会没有让九镇共同同意，而是让九镇共同看到彼此的缺项。第二镇报粮损和待搜人数，第三镇报船和缆口，第四镇报小岚撤回的大名，其他镇报迟到签领、空缺烽台和样本温度。院方总印只证明木牌在场，不能证明内容获认可。陆昭把“九镇共证”写成会议事实，不写成结功条件；每镇都能在七日内提出具体页号反证。

北墙旧基下再次传来回响，这一次是九声，快慢不一。贺停舟没有敲铃回应，只命人标出时刻与温度。九镇共证没有替天下人作答，却让每一块证物都保住了自己的来处，也让每一个拒绝被代认的人仍保有下一次选择。

回响后的第一次清点，北墙守卒少报了一声，原因是他在第六声时咳嗽，手中的水漏翻倒。卫岑没有用另一名守卒的记录去填补，先让两人分别画出听见声音的位置和漏水位置。水漏的铜底撞石能发出短响，但声长与第六声不同；这只能排除一种替代解释，不能证明其余八声来自墙内。守卒愿承接自己的咳嗽和漏水，不愿承接九声的来源，原栏保持待核。

秦衡把九镇共证卷拆成两层：会议发生的事实留在院方柜，木牌、空铃和样本仍回各镇。一个文吏提议把九块木牌的湿痕拓在同一张纸上，方便比较；许青棠的复核署回函提醒，拓印会改变边缘受力，最多只能作为复制样，不可替代原牌。秦衡遂让每镇先各自拓样，再互换编号和方法。拓样的纸耗、晾干时间和误差由院方承担，原牌拥有者不因此承担中央比较的结论。
