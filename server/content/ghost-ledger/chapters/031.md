# 第三十一章 纸城崩塌

第七仓的第四袋粮被重新封回去不到半个时辰，北镇的街巷便开始长出纸墙。

先是仓门外的告示被风卷起，贴到东墙上。接着，昨夜宴席用过的木签从空匣里自行滑出，一张压一张，沿着地面铺向北门。纸张没有墨香，边缘却带着白蜡屑，遇到砖缝便立起来，折成半人高的墙。墙面上不是字，而是一格格空白的姓名栏、接收栏和责任栏。

陆昭赶到北门时，纸墙已经围出三条窄巷。城门簿房、粮仓和医棚被纸巷隔开，巷口每隔十步便竖着一块写有“已到”“已交”“已证”的纸牌。纸牌没有笔压，牌底却压着细红线。百姓只要在牌前停一下，纸墙便会向那人倾斜，像在等一个名字。

“先封人，不封纸。”贺停舟拄杖站在门洞下，“把不愿被写的人带到空地，别让他们为了躲墙跑进另一条巷。”

陆昭让城防卒拉出三道无字木桩，按姓名、证物、责任分别标记。木桩没有刻字，纸墙对它们的反应却不同：靠近第一道桩时，空白栏微微发热；靠近第二道桩时，红线缩回；第三道桩则让墙面折痕加深。许青棠记录变化，声明这只是受控接触，不等于发现纸妖的心脏。

秦衡带人赶到，第一句话便要把纸巷划为功簿院临时封域。陆昭问他愿意承担什么。秦衡说可以负责封域文书，不负责把墙内百姓姓名写入核验册；功簿院书吏也选择只记纸牌移动，不读取空白栏。贺停舟听完，才让城防卒把两层绳桩向外移，给纸巷留出退路。

陆昭先检查纸墙与地面的接触。纸墙底部没有泥，也没有被雪水浸软的边，只有几处与粮仓麻袋同色的细粉。许青棠用镊子取粉，发现其中有麦壳、白蜡和极少量铜屑，三种物质的比例在不同墙段并不相同。她将东门墙段、粮仓墙段和医棚墙段分别封袋，声明麦壳只能说明纸墙经过粮物附近，不能证明纸妖由粮袋养成；铜屑也不能直接指向城门铃架。

贺停舟查看三条纸巷的转角，发现每个转角都对着一处能让人停步的地方：粮仓的封条柜、城门的姓名簿房和医棚的领药桌。纸牌只在有人停下读字后才向外折，若行人不停留，纸墙便维持原形。陆昭让两名城防卒沿不同路线通过，记录脚步、停留和纸墙变化。实验只进行两次，未触碰纸牌，也没有把士卒姓名写进纸面。

纸墙深处传来铃声，两长一短。周梅在外圈听见后选择不进巷，只指认声音来自第七仓方向。她不把铃声认作周循的回信，也不让人把她的指认写进接收栏。陆昭让书吏将“听见来源方向”和“确认周循在内”分成两行，纸牌上的“乙十七”因此没有完全合拢。

陆昭沿第二道木桩走。纸巷里的地面铺着昨夜宴席木签、七仓纸条和北门急报的拓本，纸与纸之间以红线相连。每走过一处，墙面就换出一条新的空粮路。三段有旧签押的路条被折成门，四段空接收栏被折成桥，桥下却不是水，而是一层叠着一层的“功成”。

“它在用我们看过的东西筑城。”许青棠说。

“不只是看过。”陆昭指向墙根，“还在用我们是否回应过它。”

第一面纸墙旁，石七的腰牌被红线牵着。石七已经退到城防外圈，仍不敢看自己的名字。陆昭让他先说选择。石七同意把腰牌作为军籍证物封存，不同意让任何纸牌代替他的接收。话说完，红线松开，腰牌落进空盘。纸墙却没有倒，只少了一块砖。

陆昭让严鹤、杜乙和顾衡分别复述第七仓开封时承担的步骤。严鹤只说锁，杜乙只说封条，顾衡只说旧签押；三人都不说粮已交。墙面上三扇纸门同时塌了一角，露出后面的砖路。秦衡看出规律，承认纸妖只能把“被说成结果”的责任折成墙，不能凭空补出没有人选择的责任。

纸城忽然震动。第七仓方向传来一声沉闷的撞击，第四袋粮的纸条从封匣中飞出，贴向城门簿房。许青棠抬起药钳，先报右肩牵痛没有加重，再选择夹住纸条边缘。她没有拉弩，也没有把夹纸动作申报为功。纸条上“先送北门”五字裂成两半，露出背面的三点朱砂。

三点朱砂与废驿木匣的四点排列不一致。陆昭让秦衡记录差异，不许将少一点解释成被纸妖吞掉。贺停舟用木杖压住通往户籍柜的纸墙，承担杖下砖路的封路责任。陆昭则把三点朱砂拓在无字木板上，沿着红线回到墙心。

墙心没有妖身，只有一只叠成城门形的纸匣。匣内装着十张东市假功单的空白背纸、七张雪沟底稿的拓本，以及一小段从旧模板上刮下来的“功成”。这些材料纸纹各异，却被同一根红线穿过。陆昭没有把它们混成一只纸妖，而是让许青棠分别取样、秦衡分别封袋。

纸匣背后贴着一行新字：“谁先承认，谁就进城。”

陆昭用无字木片抵住纸匣，没有翻开。纸匣外层有三种不同的折法，第一层像东市假功单的右下回折，第二层像雪沟底稿的左上折痕，第三层则与旧模板三道折痕相反。秦衡承认这只能证明纸妖收集过不同格式，不能证明三种文书来自同一制作人。许青棠在匣角找到两枚针孔，孔径一大一小，和周循空铃、马鞍皮针孔都不完全一致。

陆昭又让周梅、石七和罗衍分别读出自己的选择，不许读纸牌上的“已到”“已交”。周梅拒绝替弟弟接收，石七拒绝接受任何功，罗衍只确认城门没有开闸。三句话被记录后，纸墙分别退开一掌宽；可当一名好奇的粮户忍不住念出“已证”，面前纸门立即合拢。贺停舟及时把人拉离，却没有责罚他，只让他本人选择是否接受医署检查，避免把惊慌再写成一笔责任。

陆昭没有让任何人承认。他叫来罗衍，把城门簿房的实际封条、急报传递和门缝纸屑逐项读出；罗衍选择只确认北门没有开闸，不确认纸妖从哪一辆车进入。每一项有限选择都让纸墙变薄一层，却没有立即崩塌。

灰袍人的普通黑墨忽然从纸匣底渗出，沿红线向北门爬。陆昭让城防卒只封住墨迹可能经过的砖缝，不追民巷，也不将灰袍人定为纸妖。墨迹遇到第二道木桩便散开，显出一段被折断的路线图：北门外、旧渡、再向西关。

路线图没有标出人名。陆昭把它列为待核路线，不能当成灰袍人的口供。可纸城不再等待，所有纸墙同时向内折叠，空白栏、接收栏和责任栏像书页一样一层层合上。

“都退到木桩外！”贺停舟喝道。

许青棠先撤药钳，周梅拉石七离开，秦衡让书吏抱走封袋。陆昭最后看见纸匣心口的红线仍连着一枚写有“乙十七”的木牌。他没有伸手去抢，而是让周梅在木桩外再次说出选择。周梅说：“我只确认这块木牌曾属于我弟弟，不确认他已经进城，更不替他接收任何粮路。”

木牌上的“乙十七”自行褪成空白。红线断开，整座纸城失去最后一面承重墙，纸巷向内塌成无数薄片，落地后只剩纸纹、朱砂点和白蜡屑。没有人被纸割伤，陆昭却发现左手浅裂处又渗出血，失痛仍在，说明他没有因为斩断红线而免除身体代价。

崩塌后的证物被分成四组：纸城材料、七仓纸条、灰袍人黑墨路线和乙十七木牌。黑簿在陆昭掌下浮出一句话：

“纸可成城，不能成名。”

纸城崩塌后，残纸片上留下三种折痕。第一种来自模板，第二种来自被人踩过的门槛，第三种只是雪水收缩。陆昭请三名不同人盲分，结果有一人把收缩痕误认成折痕，他把错误也封进报告。许青棠说纸妖最大的诱惑不是把假话写真，而是让人相信自己不会看错；他们只能靠复读和承认不确定来对抗。

北镇保住了粮仓、户籍柜和活人选择。可通往西关的无名路线也被留下，像一道比纸墙更硬的门。

纸片落地后，城防卒先用无字木夹夹取靠近粮仓的一层，医棚一侧则由药吏负责。两人都在夹纸前更换手套，并把手套本身列为耗材，防止蜡屑被一双手带过三处现场。秦衡想把所有残片送入功簿院统一比对，贺停舟要求先留三份原位影像；司空烬最后承接增设副本柜和往返驿费，却不替北镇决定是否拆开纸匣。

周梅离开木桩外圈时，重新确认她只认木牌，不认“乙十七”曾经承担的粮路。石七则要求把自己说过的“拒绝接受功”读回一遍，发现记录吏漏了“任何纸牌”四字，立即拒绝签名。更正并未让纸墙再长出一层，反而使现场的人看见，活人的选择并不只在妖物出现时才有效，漏写同样会制造一面新的墙。

陆昭把灰袍黑墨路线的三处断点标在地图背面，分别注明“亲见”“听报”和“纸匣显现”。他没有把三种来源涂成同一色，也没有因为纸城崩塌就宣布路线失效。贺停舟承接今夜封线，秦衡承接副本送达，许青棠承接残片的伤害性检查；三人的签字旁都留着拒绝范围，北镇因此没有得到一张看似完整、实际无人负责的胜利告示。
