# 第八十一章 三日粮线

北镇城内的异常停止增加后，司空烬给出三日限期。三日不是结案期限，而是药、粮、灯油和证物复核必须重新排出的最低时间。司空烬把限期写在院方见证表的最下方，承认逾期由功簿院承担解释和补给责任，不准把“三日内查清”改写成“三日内结功”。

贺停舟先从粮仓开始。他让粮吏把昨夜两袋粮和今日新入仓的六袋分开称量，押运人、仓吏和发放见证者各自选择承接一段。第一袋少了三合，封泥无破，车板有一条新刮痕；第二袋足额，麻绳却比入仓时湿。六袋新粮足额，但有两袋接收栏空着。粮吏只报称量数，押运人只报路上停靠，见证者只报开袋时刻，三人的记录没有合成“粮线安全”。

顾衡从第二镇传回实耗表，九袋旧粮中六袋有旧路条，三袋接收栏仍为空。第二镇今日只发出四袋半，余粮未交接；九名未归者的搜寻队领走半袋干粮，却没有任何人替他们签收失踪结果。顾衡把半袋粮列进搜寻账，不列进功劳账。北镇粮吏看到两地都出现接收栏空白，想把它们并作灾诡取粮，顾衡拒绝，只在备注写“同类空栏，时序与纸材待比”。

药房的消耗更快。阮遐在第二镇复测伤员擦伤，确认两名骑卒的伤口没有黑砂、牙印或异常蜡膜，止血粉少了一包是按本人同意拆用，不是无名尸或井底铁环造成。许青棠在皇城复核署收到这份记录后，要求北镇药吏把药粉、包扎布和伤员本人选择分三栏。有人愿意接受药，有人只愿意接受伤情记录，不愿意把姓名写进九镇灾册；药吏不能把两种选择合成一份救援功劳。

城内的门槛蜡膜在清晨重新变薄。贺停舟没有立刻判定异常退去，而是让四名看守分别测门槛宽度、蜡膜厚度和最近一次开门时刻。药房门开过三次，粮仓门开过一次，证物房没有开门，北墙小门只开过供药车的窄缝。蜡膜最厚的地方不在开门最多的药房，而在证物房门内侧。文吏因此要求把“开门次数”和“蜡膜厚度”分开，不允许用一个解释替另一个。

中午，白粉带在排水沟中断的位置出现了一道新水痕。水痕只宽半指，向粮仓后墙汇去。卫岑派两名巡骑沿水痕查验，二人一人承接排水沟长度，一人承接墙根见闻，不承接水痕通向何处。墙根下找到三块湿木，木纹与第80章门内湿木不同，木块之间夹着一点青白砂和半截麻线。青白砂没有统一断口，麻线也没有石槽黑麻的盐粒，三块证物分袋封存。

司空烬的见证官提出，如果水痕通往粮仓，就应立即封死粮仓。贺停舟问他愿不愿承接封仓后药粮中断的责任。见证官只愿承接提出建议，不愿承接三日内的发放差额。司空烬没有逼他签字，而是让卫岑、粮吏和药吏分别填入能封的范围、不能封的时刻和必须保留的通道。封线于是被拆成后墙观察线、粮袋搬运线和药车通行线，粮仓没有被整座封死。

下午，北镇外来了十七名候路流民。三人有伤，五人带着家属物件，九人只携衣物。贺停舟把他们分成三组问询，不让一名代表替全体决定。有人愿意进城领取两日粮，有人只愿在门外等亲属，有人拒绝记录临时称呼。卫岑承接门外秩序，药吏承接伤情，粮吏承接实发，文吏承接物件封存。每人都可撤回尚未执行的选择，撤回不被写成拒绝救援。

一名少年带来一块刻着“回”字的木楔，说是在旧驿路边捡到。他愿意说明拾取位置和离开时刻，却不愿说木楔是否属于失踪者。木楔的刻痕与第77章第九镇木楔只有半个直线相似，断面却更湿，不能合并。锁匠将木楔放在无字台上，旁边摆旧功副页和黑布匣，却保持三尺距离。白粉没有再次落下，说明接近并不自动产生异常，也不能证明昨夜白粉来自木楔。

入夜前，贺停舟把三日粮线画在城防图上：第一日保住药房、老人和守线人，第二日保证搜寻队与撤民队，第三日预留返回和封仓试验。顾衡按实耗计算，每日必须留下两袋不能被任何人提前签领的底粮；粮吏若发现封泥破损，只能先停一袋，不能把整仓写成失守。司空烬在图上补了院方拨粮的时间，却没有取得北镇粮仓的代收选择。

陆昭从第四镇记录队复述回传。他把“第三日预留返回”读成“第三日预留撤回”，记录吏立即纠正。许青棠在远程回函中要求把错认时间、纠正人和陆昭未见原件写入同一页。陆昭没有触碰任何样本，只承接复述已由本人签认的数字和时刻。左手失痛没有恢复，浅裂结痂又因寒冷裂开一线，疼痛仍不明显，药吏依照外观而非他的自述加了护布。

夜半，证物房门内侧的蜡膜忽然剥落一小片。剥落处露出木门旧漆，下面有两道平行浅痕，方向从门轴指向门缝。锁匠用竹片量出间距，确认它与任何一辆车轮不同，也不像人手指甲。文吏愿意承接拓印，锁匠承接间距，卫岑承接门外巡查；三人都拒绝把浅痕称为“诡在开门”。

司空烬把三日记录收进院方副本，补写“粮线尚可维持，异常尚未定性，撤民选择持续有效”。他没有删去两袋空接收栏，也没有要求北镇为三日限期预交功劳。贺停舟让最后一盏灯留在证物房门外，药车从窄缝进出，粮仓后墙观察线由两名巡骑轮换。城内没有恢复平静，却有了一个可以逐日核对的秤、门、伤口和选择。

天亮前，第二镇传来新报：九名未归者中有一人自行回到药房，只愿承接自己的擦伤和回城路线，不承接另外八人的生死。顾衡立即把搜寻账改成八名待核，原有半袋干粮不退回粮仓，而是记为已发生实耗。贺停舟听完，知道三日粮线真正要保住的不是数字，而是每一笔数字都能找到愿意承担的人。

贺停舟让粮吏把新账算给门外候路的人听。第一日的底粮两袋只供医棚、老人和守线换班，已经领走的三合不能从第二日的搜寻份额里倒扣；第二日的两袋留给撤民队与回城者，若无人返回，仍要到日落后由两名见证者共同决定是否改作热粥。第三日的两袋封在内仓，只在前两日实际损耗核完以后开封。有人问既然粮够，为什么不把六袋都发下去。粮吏指着空着的两份接收栏，说粮在仓里，不等于已经有人愿意承担它送到谁手上的责任。

外仓的流民中有一名会修车轴的老匠，听完后指出运粮车板上的新刮痕更像抬袋时铁钩留下，并非雪路颠簸。他愿意演示铁钩的角度，却拒绝认定押运人说谎。锁匠取同材旧板作试验，铁钩确能留下相似宽度的痕迹，深度却比原刮痕浅。两种解释仍在，押运人的路线见闻也没有因此作废。贺停舟把试板另袋封存，给老匠一份只写演示动作的回执。

许青棠收到粮线副本后，要求把药粉的临时拆用计入第二日最低用量。她右肩抬臂仍牵痛，没有亲手搬运药箱，只让代掌医官核药重、让阮遐从第二镇报伤员复测。两份数据对不上时，她发现一包止血粉已拆给北镇门外的少年，发药吏却误记成第二镇调拨。更正后两镇库存分别减少一包，损耗总量未变。这个小小的错栏若不改，第三日便可能凭空多出一包“已送达”的药。

三日粮线首先核的是实耗。北镇两袋旧粮三合缺额、六袋新粮空接收栏和第二镇半袋搜寻粮分别入账；九名待核者中一人回药房，八人仍待搜。司空烬把三日定义为补给与复核期限，不是结功期限。陆昭退出一轮井底判断后，别人按他留下的路线图继续搜寻，路线改变处由卫岑签见。没有人因为粮线紧就把空栏改成已收。

夜巡更替时，卫岑让两名巡骑各自复述观察线的起点与终点。一人说到粮仓后墙，另一人说到排水沟第三段；两条路线只在墙角相接，不能互作全程见证。卫岑把空缺的半丈交给自己，注明只承接今夜，不追认昨夜白粉带的来源。贺停舟同意，三日粮线因这半丈多出一名守线人，也多出一份夜间热粥和轮换的实耗。所谓稳住城，不是图上画一条直线就能省掉人的脚步。

第二日卯时，粮吏发现昨日登记的半升缺额在空袋底部粘成薄层。袋口封泥未动，袋底却有三道平行磨痕，像曾被木板拖过。顾衡先称袋中残粮，再称袋布和磨下的碎屑，结果只差两撮，远不足补回半升。押运人愿承接拖袋动作，不愿承接缺额由谁造成；仓吏愿承接入仓时的秤，不承接押运路上的重量。两种责任分别写入损耗单，功簿院补粮仍按最初差额，不拿新发现抵扣。

阮遐从第二镇回报，归来的那人同意复查擦伤，却拒绝让搜寻队用他的回城路线替八名未归者画路径。顾衡删去原图上由他口述延长的半里线，只保留本人亲走的路段。删线使地图看起来更短，却使搜寻队必须多派一人沿河堤探查。粮吏计算多耗的热粥和马料，顾衡签下调度责任；归来者则在选择栏写明只承担自己的脚印。陆昭复读时把“删去延长线”听成“删去回城线”，让两名文吏重新核对，错听和更正同时留档。
