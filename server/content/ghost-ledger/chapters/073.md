# 第七十三章 许青棠的选择

许青棠是在伤亡复核署的第三间偏房里，读到三镇分栏回批的。

桌上共有四份抄本。第二镇送来的风沟伤情表，第三镇的落水水卒记录，第四镇的炭笔水泡与失名选择表，另有一份功簿院要求她在半日内签发的“九镇灾情综合伤亡预估”。预估表把擦伤、旧伤牵痛、惊厥、失名后的短暂失神和撤民途中跌伤列成同一列，末尾写着“可据此优先调兵”。许青棠看完没有落笔，只把四份材料按采集人、采集时刻和本人授权重新排开。

她右肩在抬臂时仍有牵痛，痛处不深，却会在弩弦拉到一半时突然发紧。医吏建议她休息两日，由别的医官暂代复核署主笔。许青棠没有立即拒绝。她先问代掌医官是否愿意承接三镇材料的原件保管、是否能接受家属撤回见闻、是否有权拒绝把预估表写成死亡人数。对方只愿承接伤情汇总，不愿承接家属选择和证物退回条件。许青棠于是把主笔印放回盒中，说明自己可以暂时交出执笔，却不能让复核署失去拒收不实结论的权限。

司空烬的回批在这时送到。他准许复核署独立出具三镇伤情分册，但要求在册尾加上“灾源尚未确认”六字，并把调兵建议拆成守线、护证、撤离三项。使者秦衡还带来一封口头转述，说皇城需要一个能在半日内判断“哪里最危险”的人。许青棠问危险由什么决定，是受伤人数、证物破坏风险，还是本人愿意撤离的户数。秦衡回答，三者都要，但功簿院的调度表只能容下一项优先级。

许青棠拿出一张空白药方，在背面画了三条线。第一条标“正在流血的人”，第二条标“可能被再次损坏的证物”，第三条标“已经作出选择但无人护送的人”。她对秦衡说，伤情复核能证明第一条，封存记录能证明第二条，第三条必须由每镇本人说出。任何一条都不能替另一条签字。秦衡承认这会让调兵名单变长，却不能保证中央粮械增加。

午后，第四镇文吏从边驿送来小岚母亲的补充选择。母亲同意让医官记录小岚梦醒后的脉搏和惊惧，不同意让复核署把梦中陌生大名写进异常样本。她还要求若有人来取红布包，只能在接生婆到场时开封。许青棠读完后，在材料首页盖了“本人限制有效”的小印。这个印只证明选择被收到，不证明小岚失名已找到原因。

第二镇药房同时回报，一名搜寻骑卒在井边擦伤处发热，要求把伤口列入“风灾咬噬”。阮遐附上伤口拓图、麻绳纤维和换药时刻，说明伤口边缘是交叉绳磨出的平行擦痕，没有牙印、撕裂或异常颗粒。许青棠先把病人列入观察，不接受“风灾咬噬”四字。她要求骑卒本人选择是否把伤情用于调兵依据，对方只同意记录治疗，不同意替九名未归者证明井中有妖。

第三镇的两名水卒也发来补充。两人手臂擦伤已经结痂，其中一人愿意把落水位置标在水图上，另一人撤回了关于“水下有人推船”的口述。许青棠把撤回后的空栏保留，不让早先抄本覆盖新选择。她在复核署章程上添了一条：同一人可以修改自己的见闻，但不得被要求解释为何撤回；修改只改变本人一栏，不改变其他人的证物编号。

秦衡看着她忙到入夜，提醒她右肩的牵痛可能因持续抬臂而加重。许青棠把药包递给他，让他按时辰替她记下服药与活动范围，自己则把弩放回墙边。她没有把受伤仍工作的事实写进功分表，也没有把拒绝拉弩写成失职。她选择留在皇城，继续主持复核署，却把现场调度权交给各镇本人，只保留退回不合格伤情结论和要求补证的权力。

这个选择很快遇到第一个代价。第八镇送来的急报说空门再次出现，守门人只写“有人受伤”，没有人数、时辰或本人印。功簿院要求复核署先按三镇比例调出药箱。许青棠退回急报，要求第八镇补上伤者本人是否同意公开伤情、药箱由谁签领、封门由谁承接。秦衡说这样会错过救治时机，她便批准一箱基础止血粉先走，却在领用栏写明“物资先行，不作为伤亡功劳”。

夜深时，许青棠复测右肩。抬臂至胸口高度出现牵痛，未见肿胀，指力与脉搏正常。她让医吏在记录中写下“可执笔，不宜连发弩；可复核，不宜单人搬运”。随后她将自己的选择告知三镇：复核署不代镇认名、不代家属收功、不把梦话和传闻写成灾源；愿意接受伤情记录的人可以撤回，愿意承接证物的人必须说明保管时刻。

陆昭的回信在子时抵达。他没有评价她该留皇城还是去现场，只复述北镇贺停舟地图上标出的守线空缺，并提醒自己仍不能判断第三镇铃声和北镇铜铃同源。许青棠看完回信，在复核署总表上补了一栏“复述者限制”。她知道陆昭的错认会让证据变慢，但慢并不等于无效；只要限制被写清，错误就还有被纠正的入口。

天亮前，她把三镇伤情分册、本人选择分册、证物转运分册和拒收记录分册各自封存。四柜由四名不同的人保管，钥匙不交给同一官署。功簿院可以调阅编号，不能直接取走原件。许青棠将主笔印交给代掌医官一日，又在交接条款中写明：若代掌者把预估表改成死亡或功劳结论，复核署有权暂停印章使用。

她终于承认自己的选择并不漂亮。留在皇城意味着不能亲自看见河水、黑砂和户籍柜，右肩也不会因为坐在案前就痊愈；可若离开，复核署可能被一张总表接管。她选择留下，不是为了证明自己比别人更懂伤口，而是为了让每个伤者仍能决定伤口被如何使用。窗外传来新的急报声，许青棠合上药箱，先问送报人：“这一次，你亲眼看见了什么？”

交接并不顺利。代掌医官第一遍抄写时，把第三镇两名水卒的落水位置误写成“沉船位置”，许青棠当场用朱笔划开，要求他回看原始口供。对方说只是为了让调度官看得更快，许青棠回答，快读若改变了证据，便会让下一支船驶向一个不存在的尸体。她没有夺回主笔印，只把更正责任写在抄本边栏，由代掌医官本人签名承接。

同日下午，一名从第三镇来的船工家属请求复核署开具“未亡证明”。他只带来船主常用的湿布包和一张未完成名册，承认没有看见船主离岸后的去向。许青棠没有满足这个要求，也没有把请求退回成无效诉求。她提供了两种可选记录：家属可以确认物件来源，或只确认最后见面时刻；两项都不等于死亡或生还。家属最终选择后者，复核署给他一份写明限制的副本。

副本送到家属手中后，他指出册页上“最后一次见面”后面多了一个“归”字，原话并未说船主归来。记录吏立即收回副本作废，保留错误件和更正过程，不把错字归给家属。许青棠要求代掌医官把这次更正也登记为复核署责任，免得后续抄录把“见过”变成“见归”。

许青棠面对复核署是否独立时，先提交自己右肩牵痛的验伤记录。她拒绝让下属把她的口述写成最终结论，要求副署医官复核弟弟身份、九镇伤情和药粮损耗。她同意查许青岚，却不接受任何人代她认领功劳；她同意建立伤亡署，却不把署印变成结功印。司空烬试图争取统一回传，她要求保留原件在地和本人选择栏，双方只就程序签字。

许青棠的右肩在连写三页后出现针刺样牵痛。医吏要她把笔交给别人，她便改用左手口述，由皇城记录吏代写，且在页尾标明“口述者为许青棠，执笔者为复核署记录吏”。她不把执笔者写成意见人，也不把自己暂时不能抬臂写成缺席。复核署的章程因此多了一条现实限制：伤情记录必须同时记录谁观察、谁书写、谁承担更正。

入夜，副署医官送来一只从第三镇转运的湿药箱。箱盖封泥完整，内里的纱布却比出库单少一卷。押送人记得在渡口给落水者止血，不能说出伤者姓名；若直接填作“救治已结”，复核署便会平白多一个病人。许青棠让押送人画出渡口台阶和递纱布的手，另请当班水卒只确认看见箱子开过，并不要求他推定谁受了伤。少的一卷先记救急耗用，药材由皇城补发，病人那一栏留白，待第三镇寻到本人再问是否愿意留下伤情。她肩痛得连药箱扣也扣不上，便让医吏操作，自己只读封签号。

代掌医官问，若那人永远不来，复核署岂不是永远有一卷纱布对不上人。许青棠把押送人的实耗单与空白伤情页分夹：“药可以按事实补，命不能按药推。”第二日送往第三镇的副本只附渡口位置、时刻和可询水卒，不附猜出的姓名。独立不是署印比功簿院更重，而是即使查到这里，仍准许伤者拒绝把伤口交给任何人的功劳簿。
