# 第八十四章 天下诡门

九声回响之后，北镇的夜色像被一只看不见的手从中间折了一下。外仓门缝下先渗出一线水，随后又干成白霜。守门巡骑没有拔刀，他们按贺停舟的安排先报门、报人、报能否后退。四名巡骑中一人选择留在门外守线，一人只承接照看伤员，两人退到第二道墙后。没有谁因为站在最前面就自动成为镇诡卫的功臣。

陆昭隔着白线看见霜线在地上延伸，经过九块木牌时却分成九股。每一股都停在木牌边缘，没有越过封签。秦衡脸色发白：“它在找门。”

“先说清楚什么叫门。”司空烬没有看霜线，反而看向桌上的四行空栏，“门是石槽的通道，还是一份被写成结果的文书，或者是有人愿意替别人承担后果的关系？不先分清，所有门都只是形容。”

北墙旧基下传来细碎的石屑声。锁匠带着第三方验算员到场，确认未拆的石槽段并未移动，城基也没有裂缝扩大。水线却从墙下绕出，贴着地面朝九块木牌爬来。验算员要求把木牌全部抬离地面，贺停舟拒绝：“抬动会改变接触条件，先固定三份原状样本，再决定是否移动。”

九镇文吏各自封下木纹上的湿痕。第一份用无蜡纸托，第二份用干燥陶片，第三份只拍下位置，不取样。三种方法由三人承接，任何人都不承接“水线来自同一源头”。霜线因此在第七块木牌前停了片刻，随后改向门槛。

北镇粮吏把门槛前最后一袋粮移往干燥处，先称重，再核封签。袋重与傍晚入仓时一致，外麻却比内麻潮。顾衡不许用“没少粮”三个字结束记录，因为湿麻可能改变次日的霉损，也可能使封签脱落。他另开保管单，承接今夜翻晒的工时和若需换袋的损耗；粮吏承接不得在换袋时补写原接收人的空栏。药吏则把仍留药床的伤员逐人复问，确认夜间搬动意愿没有被白天那张撤民册永久锁住。

门槛上的蜡膜忽然浮出一行极浅的字：开门者，接天下未结。

有人想把这句话抄进共证卷，陆昭立刻出声：“没有笔压，没有书写者，也没有本人选择。只能记作无笔压字面异常，不能记作命令。”他说得太快，尾音把“命令”错成了“承命”。记录吏提醒他复述有误，陆昭主动要求删掉错词，在旁边写下“已纠正”。左手的裂口仍不痛，他却能感觉到布条被血浸湿了一小片。

许青棠的远程回函在此时抵达。她要求检查陆昭伤口，不许用“本人不觉疼痛”判定反噬减轻；同时指出门槛蜡膜与第八镇空匣擦痕的熔点不同，不能凭同一行字把两案合并。她在函末写：“若有人把天下写成一个受害者，第一件要做的不是开门，是找出谁被迫站在门后。”

司空烬让秦衡取出院方的封路令。封路令仍按九镇分栏，中央只承担发布、撤回和逾期解释。可当纸面靠近门槛时，霜线突然向纸边聚拢，像在等待一个接收人。司空烬没有把令纸往前递，而是当众撕下“统一接收”四字，换成“各镇本人选择后回传”。撕下的纸条另行封存，不能与无字湿纸片并案。

霜线短暂后退，门槛字迹却又多出半句：无主之门，先收无主之功。

这一次没人说话。贺停舟看向陆昭，像是在问他是否能从这句话里听见功簿的声音。陆昭摇头：“不是黑簿原册。黑簿没有在这里，功簿也不会用一句话替死者和活人作选择。”

司空烬承认这一点，却提出更危险的可能：九镇的异常并非一只妖物从外面撞门，而是有人把各镇未完成的责任拼成一扇门。只要有人承认自己能替天下接功，门就会获得一个真正的承接者。这个推测有制度上的依据，却没有妖物身份、操作者和接触时序的完整证据。因此他把它写在“待证假设”栏，而不是事实栏。

北镇外仓忽然传来哭声。那名先前只承接药粮领取的流民，发现自己的粮袋封签上出现了一个陌生大名。他没有撕封签，也没有让旁人替他读完，只请求药吏把袋子移到灯下，核对重量、麻线和签押。粮吏愿意承接重量，文吏愿意承接封签，流民本人拒绝承接纸上姓名。三项责任拆开后，大名自行褪去，只剩一条没有笔压的黑线。

流民说自己幼时被卖过两次，曾用过别人的姓，纸上即使碰巧写中其中一个，也不能证明他愿意再被那个名字领走。药吏给他重新包扎脚踝，问是否愿把旧姓交给复核署。他拒绝，只同意记录当下伤情和今夜站过的位置。文吏把“拒绝提供旧姓”写在选择栏，另在事实栏写“封签上曾出现字迹，已褪”。他要求再看一眼，两行仍各在各的位置，没有被谁合成“已认领”。

贺停舟命人把黑线连同麻线一起封存。两者粗细接近，断口却一个平整、一个纤维外翻。锁匠又取来石槽短黑麻比对，仍不相同。材料证据把三条看似相连的路拆开，门槛霜线却没有因此消失，只从粮袋退回到外仓门。

卫岑带回北门消息：城外三十步的旧驿路上出现九个浅坑，坑底没有脚印，只有各镇木牌背面湿痕同样的冷凝水。九个坑的位置并不等距，最北一个靠近废渡，最南一个贴着封路桩。无旗黑甲骑兵没有出现，灰袍人也没有留下新的纸条。卫岑只承接测量、封线和回城时刻，不承接“九门已开”的判断。

司空烬站起身，将院印盒推回木匣：“天下诡门这个名字，可以作为案卷标题，但不能作为结论。今夜先做三件事：第一，九镇木牌分别回柜，任何镇不得带走别镇原件；第二，门槛异常留原状，第三方验算在两刻后进行；第三，所有活人重新确认自己愿意承接的栏位，撤回仍有效。”

贺停舟补充：“第四件，粮和药照发。谁要把救命物资停下来等门开，先在责任栏写自己的名字。”

司空烬看了他一眼，没有反驳，拿起笔在院方栏写下逾期补给和封路解释责任。笔尖落下时，门槛霜线向后缩了三寸。那不是妖物被斩，也不是功簿结算，只说明一项明确承责暂时改变了异常的牵引幅度。

陆昭在远处铜铃余音里产生黑簿翻页的错觉，又立刻停住。他没有把这感觉写入事实栏，只让记录吏记下“本人听觉疑似异常，未取得原件，未作方向判断”。左手的布条更湿，错认的阴影在眼前掠过，他把复述牌交给贺停舟，退出下一轮门槛观察。

第三方验算员在两刻后复测城基，九个浅坑的位置由两组不同人员独立测距。第一组以北门为基线，第二组以旧驿碑为基线，换算后有两处相差半尺。差值落在旧碑倾斜造成的误差范围，却使“九坑正对九镇木牌”的说法站不住脚。卫岑要求保留两套原始数字，明日再以固定木桩复测；司空烬同意继续封路一夜，但必须由院方补足耽误的药车。贺停舟则把多守一夜的火油写进实耗，不许把油耗称作诡门的祭品。

天将亮时，九块木牌各自回到封柜。门槛上的字褪成一片无笔压湿痕，九个浅坑仍在，霜线却不再向内生长。北墙第三段石槽没有挖开，城外旧驿路没有追骑，所有人都知道这不是胜利，只是把一扇可能由责任拼成的门暂时关在证据之外。

司空烬在共证卷末写下新标题：《天下诡门，尚无主》。贺停舟在旁边加注：“无主不等于无人负责。”

天下诡门在卷尾仍只是案卷标题与待证假设。九个浅坑、九道湿痕和门槛无笔压字面有可重复观察，却没有共同操作者、共同接触链或妖物本体。陆昭没有碰黑簿原册、尸骨和封功刀，远处翻页被复核为听觉错觉。司空烬承担统一格式、补页和封路补给，贺停舟承担守线与三钥柜，许青棠承担独立伤亡复核；三人的责任不能合成一项天下功。

陆昭没有签功，也没有签罪。他只在自己的停职记录上补了一行：下一步，查清谁曾把未结之功写成天下所有人的门；在查清以前，任何人不得替另一个人开门。

这行字送入停职档前，记录吏问陆昭是否愿意把“查清”改成“协助查清”。陆昭承认自己没有印权，也不能把九镇的后果全揽在肩上，于是把下一步拆为复读、报错、封签和申请复核四项，另写明不承担认名、开柜、斩妖和结功。改动后，句子少了几分像誓言的锋利，却多了四个可以被别人追问的动作。贺停舟在旁边签下守柜责任，提醒他连“查清”二字也不能替未来保证。

同夜，第四镇小岚母亲送来一块空牌，请求把女儿临时称呼留在本镇，不纳入天下诡门卷。秦衡问她是否同意影像交换，她只同意交换牌面尺寸和封签号，不同意交换刻痕细节。院方接受限制，并在共证卷边写出“不足以复核刻痕”的缺项。司空烬没有用九镇共证的名义逼她让步，反而拨了两名驿骑补做本镇保管见证。空牌仍可能重要，但重要不等于有权越过持有者的边界。
