# 第八十章 城中有诡
城中有诡的传闻先被拆成门槛蜡膜、铃绳白粉、湿木和无字纸四条证物线。分段封闭只持续两刻钟，粮、药、证物房和外仓各有放行人。陆昭听见远处翻页声，却记录为听觉错觉，不以失痛后的异常当妖物口供。司空烬不许用“城中有诡”替活人认名，贺停舟不许守门人私自调走黑簿，许青棠则把伤者先救后问的程序写进夜班单。


旧功撤项后的第一夜，北镇城内没有下雪，城墙上的霜却从门外向门内长。最先发现霜线的是北镇药吏。他愿意承接发现时刻、药房门槛的长度和自己走过的路线，不愿把霜线解释成诡物爬行。贺停舟让他把药房、外仓、证物房三处门槛都测一遍，三处霜线各自封样，不能因都朝城内就并成一条线。

卯时，城门铜铃在无风时响了一声。守门巡骑只看见绳结向内收紧，没有看见人拉。他愿意承接铃声时刻和绳结状态，拒绝承接“城中有诡”的结论。卫岑把门外雪、门内石板和铃架底座分成三袋，锁匠检查金属磨痕，文吏记录每袋开封者。铜铃第二次响起时，门外巡骑已退到三步之外，绳结仍向内缩了一寸。

这一次留下了可复核的物理痕迹。铃绳内侧有一层薄蜡，蜡下粘着两粒细白粉；铃架底座却只有旧油和砂砾，没有黑麻纤维。白粉触感接近第七镇车轮样本，颗粒中没有第三镇黑蜡陶罐的植物茎。许青棠的复核署要求先做盲验，再决定是否把铃绳与旧驿石槽联系。贺停舟同意，禁止任何人以铃响替活人报失踪。

辰时，外仓四门同时出现浅白斜痕。斜痕高度不同：粮仓门在膝上，药房门在腰侧，证物房门接近肩头，北墙小门却只有半尺高。痕迹都没有木屑翻起，只有薄薄蜡膜。四名负责看守的人各自选择承接一处，拒绝替另外三处解释。卫岑承接北墙小门的守线，药吏承接药房门的封样，粮吏承接粮仓门的擦拭时刻，文吏承接证物房门的拓印。

贺停舟没有马上让人擦掉斜痕。他先把城内道路画成五段，每段标出门槛、排水沟和旧车痕。旧功副页和黑布匣留在外仓，不允许靠近四处门。两名见证者沿不同路线检查，发现药房门到粮仓门之间有一条断续白粉带，宽度不足一指，在第三段排水沟处中断。白粉带没有脚印，排水沟内有一小片湿木，木纹方向与石槽侧壁不同。

午前，城中一名卖炭妇人敲响守门鼓。她说夜里听见有人在自家后门报丈夫的旧名，可她丈夫三年前已离城。妇人愿意承接声音出现的时刻、门闩状态和自己是否开门，不愿把声音认作亡夫，也不愿将丈夫姓名交进异常名单。药吏检查她手臂上的擦伤，确认是她关门时被木闩划到；伤口没有黑砂或蜡粒。声音本身没有留下录音，妇人的选择和伤情分开记录。

同一时刻，北镇户籍柜旁的地面发现三粒青白砂。文吏没有把砂粒与第二镇井底样本合并，而是先询问清扫者。清扫者只承接昨夜最后一次扫地时刻，不承接砂粒来源。三粒砂下压着半个圆形凹痕，凹痕宽度与旧功副页上缺失的石片相近，却没有石片断口。锁匠用木模复刻凹痕，发现相同宽度的三个不同物件都能留下类似压痕。

司空烬的见证官在门外提出把城内异常统一归为“关妖入城”。贺停舟要求他先列出证据和反证。证据只有霜线向内、铃绳收紧、四处蜡痕、白粉带和妇人声音；反证是没有脚印、没有共同纤维、三处样本开封人不同，且声音没有物证。见证官承认目前只能写“城内出现多处方向一致的异常”，不能写妖物已经入城。秦衡把这句承认抄入院方记录，注明由见证官本人承担。

下午，许青棠远程主持三项盲验。第一项比较铃绳白粉、木门蜡膜和石槽白粉；结果显示铃绳白粉和门槛蜡膜都有蜡感颗粒，却没有相同盐分，石槽白粉含盐并夹黑麻。第二项比较四处门痕的高度与擦拭方向，确认它们不是同一块模板连续拖过，因为每处起落方向不同。第三项比较湿木的含水量，湿木来自城内旧排水沟，不是旧驿路石槽木桩。三项试验把可疑材料拆成至少三组，没有找到一条能直接指向妖物的同源链。

正当众人记录盲验结果时，北墙小门内侧传来三下敲击。守线的卫岑没有开门，他先让敲击者说明身份和愿意承接的范围。门内没有回答，敲击却再次响起。锁匠从门缝下塞入一张无字纸片，纸片被推回时沾上湿痕，没有笔压，也没有指纹。纸片边缘有白粉和一根短黑线，二者没有混合。卫岑选择承接投递时刻，文吏选择承接纸片封存，没人承接门内“有人”的判断。

贺停舟命人从城内另一侧开一条观察缝。缝后不是人，而是一块被风吹动的旧木板。木板一端卡在排水沟，另一端抵着门栓，水汽使木板收缩，反复撞击形成三下声音。木板上没有脚印，门栓内侧却出现与门槛同类的蜡膜。这个发现排除了“门内有人敲门”的一种解释，却没有排除其他异常。贺停舟让木板、排水沟湿木和纸片分柜，不允许把排除结果写成全城无诡。

傍晚，霜线从药房门槛退了一寸，粮仓门的蜡膜却变厚。粮吏测出粮仓门外温度没有明显变化，门内两袋粮的麻绳受潮程度不同。第一袋由昨夜新入仓的押运人签领，第二袋由北镇粮吏代收但保留空白接收栏。两袋粮的责任链不同，蜡膜不能证明有人借粮袋进城。顾衡从跨镇账本回传一条消息，确认今日粮耗与实际发放一致，暂未出现少粮。

夜巡前，城内五名守线人分别汇报自己的疲劳、伤处和拒绝范围。铃声守卒耳道无新出血，药吏手背有旧裂，粮吏因擦拭蜡膜手指发麻，文吏无伤，卫岑左肩被门板反弹擦红。伤情由药吏分项记录，任何不适都没有被写成功劳或妖物反噬。陆昭从第四镇听到回传后，误把“铃绳薄蜡”复述成“铃架薄蜡”，立即由记录吏改正，并注明他没有见过城内原件。

司空烬在夜议中提出封闭北镇所有内门，避免异常继续移动。贺停舟反问，封闭会不会阻断药车、热粥和伤员本人选择。卫岑愿意承接两刻钟内门外封线，药吏愿意承接药房通行，粮吏愿意承接一轮发粮，文吏愿意承接证物房双人开门；四人都拒绝把全城门锁合并成一项。司空烬接受分段封闭，另拨两名不涉案巡骑守排水沟，但不取得证物解释权。

子时，城中所有门痕同时停止增加。北墙小门的无字纸片边缘干燥，短黑线蜷在纸角；四处霜样的温度记录显示，异常停止时没有统一降温。贺停舟把今日结果归为三类：已排除的木板敲击、可重复的门槛蜡膜与铃绳收紧、尚无法解释的纸片投递和霜线方向。所谓“城中有诡”只能作为待核标题，不能写成妖物身份、死者未竟之事或功簿新页。

天将亮时，司空烬问陆昭是否愿意以停职观察员身份承接城内异常总表。陆昭先报自己的限制：不触黑簿、不碰尸骨、不用听骨、不作未亲见方向判断。随后他同意只复述各镇已经由本人签认的时间、温度、样本编号和拒收范围。这个选择被写在观察员栏，没有把他恢复镇诡卫印权，也没有把城内异常算作他的功劳。

北镇城门重新开启一条供药车通过的窄缝。门槛上残留的蜡膜被分成两袋，一袋交复核署，一袋留北镇；开门者、押车者和接收药吏分别签下自己的动作。城内确实有某种能够留下物理痕迹、改变声音和门锁方向的异常，但它还没有被认作一只妖，也没有获得替任何人结算的资格。贺停舟在地图上写下“城内，多点，待核”，把笔递给下一位承责者，而不是替全城先写上答案。

药车过窄缝时，车夫发现右轮粘了一层薄蜡，左轮没有。卫岑先令车停在白线外，查门槛原蜡膜是否被轮辋刮走，又请粮吏量轮距。右轮蜡沾在外缘，不在与门槛接触的胎面；门槛原样留有连续边线，因此两处可能不是同一次刮擦。车夫愿意说明车曾在药房外停留，不愿替药房解释蜡从何来。两名见证者分别取轮缘和地面样本，药车仍可在卸去外轮套后运药，卸套的工钱另记。

贺停舟把这次停顿报给司空烬，要求院方下次发封城令时预留换车的时间。若每扇门都临时改为窄缝，药车要多走三处转弯，伤者便会在车里多挨半个时辰的冷。他没用伤者催人跳过取样，也没让证物压住药车；药吏先给车内病人添了热毯，随后由另一辆净车接运。陆昭在远处只读到两辆车的封签号码，拒绝凭轮痕判断城内异常已经扩到药房。城门重新合至守线宽度，今夜又多了一项必须有人接班的实耗。
