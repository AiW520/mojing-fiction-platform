# 第六十五章 九镇同时报诡

皇城的七日审查还剩四日时，九封急报在同一刻送进中书省。纸封来自九镇，印色、封蜡和骑卒脚印各不相同，却都在末尾写着同一句：“灾起，诡见，待上令。”中书省先把九封急报摊开，司空烬没有让人把九个“诡”字抄成一个总案，而是命秦衡逐封登记来源、到达时刻、传令者和未填空栏。

第一镇报西墙霜裂，第二镇报风卷粮棚，第三镇报河面倒流，第四镇报村民失名，第五镇报夜潮入城，第六镇报军医失踪，第七镇报旧阵复鸣，第八镇报城中出现空门，第九镇报北岭天黑。九镇相隔数百里，不可能由一名骑卒亲眼见证全部灾象。秦衡把每一封报文的见闻者拆开，发现其中四封只写“有人说”，两封只有守门人的印，一封盖了镇尉印却没有本人签名。

中书省有人提议先认定九镇同受妖灾，调兵封路，再追补证据。司空烬没有立刻答应。他把“灾起、诡见、待上令”四字圈出，要求先问三个问题：谁看见，什么被改变，谁愿意为第一步处置负责。若连风向、粮袋数量和伤员姓名都没有记录，调兵只会把空白送到下一座城。

陆昭站在旁听席，停职牌仍由许青棠保管。他不能碰九镇急报，只能听秦衡朗读。听到第八镇“城中出现空门”时，他短暂把那句错听成北线黑墙的四个职位栏，左手浅裂没有疼痛，错认风险随之升高。他主动闭眼，让秦衡重新报出纸封颜色、骑卒来源和到达时刻，不让自己的记忆替证物补齐缺口。

司空烬决定把九镇灾报分成三层。第一层是立即救命的事实，包括风灾中的失踪人数、倒塌房屋、伤员和现有粮水；第二层是可能涉及妖诡的异常，包括无影脚印、反向水痕、失名纸片和阵铃声；第三层才是是否建立未结之功的候选。三层分开，任何一镇的“诡见”都不能直接成为九镇共同结论。

为了让处置不等皇城回批，司空烬提出临时调度表。兵部副使卫岑只负责西关兵调、巡骑和城门封线，药粮由功簿院外仓和各镇自有账分开，证物由复核署格式统一但不收原件，家属和伤员本人选择由各镇留存。每一项都要填承责人和不能执行的部分。卫岑同意调一支小队去风灾最重的第二镇，却拒绝替其他八镇担保安全；顾衡同意拨三日灯油，不同意把未签领的粮袋写成已经送达。

许青棠查看九镇伤情栏。第二镇报“失踪三十七”，没有年龄、性别和最后见闻；第六镇报“军医失踪两名”，却把药车领用册整页撕去；第四镇的“村民失名”只附十七张空白木牌，未列任何本人姓名。她要求先补登记，不是为了拖延，而是因为没有姓名就无法确认谁能选择撤离、谁能接收药物、谁已经死亡。

这时第一镇的信使当众改口，说霜裂处曾看见一具黑甲尸体，尸旁有半根骨笛。司空烬问他是否亲眼看见。信使承认自己只在城门听到守夜人转述，尸体和骨笛均未由他验看。秦衡把“黑甲尸体”从事实栏退回传闻栏，不让熟悉的物件把卷三旧案牵回九镇。

第九镇的报文随即出现变化。原本的“北岭天黑”被一条没有笔压的灰线划去，旁边添上“天灾已定，候功”。纸纤维与九镇急报不同，灰线穿过封蜡边缘却没有留下蜡屑。司空烬让人在不触碰正文的情况下拍拓纸背，记录针孔、折痕和添字时刻。陆昭提出这不是九镇同意结功的证据，也不能证明纸妖来自功簿院。

中书省要求司空烬立刻选择一镇作为总指挥。司空烬反问，若总指挥承担全部镇民选择，谁来承担他无法到场的证据？他提出“分镇先救、统一回传”：每镇先做最小救命动作，调度中心只合并数字和路线，不合并姓名、功劳和妖物结论。这个方案会慢，却能让每一镇保留拒绝和反证的位置。

陆昭第一次被问到是否愿意参加第二镇风灾核验。皇城口谕仍称他停职待审，司空烬只能申请“事实观察员”身份，不许他开柜、持印或使用听骨。陆昭同意，但提出两条限制：一是所有异常证物由当地本人和复核见证双签；二是若错认风险升高，他必须立即交出记录，不得以停职身份继续判断。司空烬将两条写入临时调度表，承认这会降低行军速度。

北线出发前，许青棠把一只小药匣交给陆昭。她没有把它说成护身物，只说明其中是止血粉、冷敷布和记录蜡片，使用一项就要记一项，不能因为同行而替他承担伤情。她本人留在皇城复核九镇伤情回传，右肩牵痛未缓解，却坚持每两刻审一次失踪和伤员栏。

卫岑带六名骑卒、两名药吏和一名无涉案文吏上路。骑卒负责开道和撤民，不负责认定诡物；药吏负责温度和剂量，不负责粮道接收；文吏负责封签和回传，不负责替九镇签署功劳。顾衡把三日灯油分成九份，每份写上镇名、耗用时刻和退回条件。有人嫌格式繁琐，他回答，灾还没结束，先把损耗留下，才能知道谁被救、谁被漏掉。

队伍离皇城不到十里，第二镇的第二封急报追上来。报文说风声已经从屋顶转入井底，失踪人数增至四十一，新增“被风拖走的粮袋”十二袋。随报只有一截麻绳、一片被磨平的木牌和三粒青白砂。绳端没有血，木牌没有姓名，砂粒未标采集位置。司空烬命人把三件物证分袋，禁止因“风拖走”四字把它们直接写成妖物脚印。

陆昭看着被风吹动的麻绳，想起北镇四项分责和无旗黑墙的空职牌。他没有把两案合并，只问文吏：“绳端是谁封的？”文吏答第二镇守门人，守门人愿意承接封存时刻，不愿承接失踪者生死。陆昭把这一句记下，确认九镇灾报仍在事实层，尚未进入功簿四步。

黄昏时，九镇的回传同时亮起。第一镇霜裂扩大，第三镇河水恢复，第四镇有三人主动报出姓名，第八镇空门自行合拢。灾象有的加重、有的减弱、有的只是传闻被更正。司空烬没有把“同时报诡”改写成“同时发作”，而是在总表上写下：同一时刻收到九镇报告，不等于同一原因发生。

夜宿驿站，陆昭复测左手，依旧无痛，浅裂边缘发白。他把停职牌和事实观察员文书分开放，先听本人朗读，再核对纸背折痕。临睡前，北岭方向传来三声风响，驿墙上的空白职位栏被吹出一个“粮”字。陆昭没有伸手，也没有让人把它写进九镇灾报，只让守夜人记录风向、时刻和是否愿意作见闻证人。

第二镇的风灾还在等他们。九镇的报诡不是一只妖，而是一张需要被逐项拆开的网。陆昭知道，卷五的第一步不是斩诡，而是让每个镇在灾中仍能说出“这是我看见的，这是我选择的，这一栏我不能替别人填”。
在出发名册的背面，秦衡又补了一列“未能执行”。第一镇暂不能验霜下骨片，第三镇暂不能派船入逆流，第四镇暂不能让失名者代签，第八镇暂不能开空门内柜。每个“不能”后面都写着下一次回报时刻。陆昭看见这张表，忽然明白调度并非把九镇变成一条线，而是让每一处断点都能被找到、被解释，最后由真正到场的人承担。

九镇同时报诡的急报先按到达时刻排队，而不是按恐怖程度排队。司空烬让九名文吏分别写清看见的风、听见的铃、受损的粮和失联的人数，任何一镇不得抄另一镇的数字。陆昭被列为事实观察员，只能复读副本、检查封签和提出反证，不能开黑簿或代表九镇结功。许青棠留在皇城主持伤情回传，右肩牵痛仍须副署医官代写；贺停舟守北镇三钥柜，拒绝把急报当开柜理由。

第二镇的烽烟在北方天边压成一线。卫岑收起分镇调度表，命骑卒检查马蹄和缰绳；药吏将冷敷布分给同行者，文吏把九镇急报按到达顺序重新编号。没有人宣称已经掌握灾源，也没有人因第一批命令发出便获得功劳。风从空白职位栏上掠过，卷走一片未写完的纸，却没能卷走那些被逐项留下的责任。

出发前，卫岑把“未能执行”一列交给每队本人复读。骑卒确认自己只能承接马匹、缰绳和路况，药吏确认只能承接药箱和伤情采样，文吏确认只能承接急报编号。陆昭在旁边补上停职限制：不触黑簿，不碰尸骨，不替九镇结功。九镇第一次把不能做到的事写在最显眼的位置，反而让能做到的事更清楚。

第一批骑卒出发后，北镇文吏发现一份急报把“失联人数”抄成“死亡人数”。他没有撕掉副本，而是立即封存错误件，追查原镇回报。原镇确认只报失联，错误来自北镇抄录；两镇各自承接纠错和延误，搜寻队仍按失联人数出发。陆昭复读更正号时把“失联”听成“失散”，药吏让他休息后再读。九镇的急报因此多出一项实耗：先纠错，再让马走。
