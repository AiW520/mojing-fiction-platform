# 第二十七章 贺停舟的旧案

贺停舟的旧案藏在北镇司最底层的木柜里。

柜门没有锁，锁鼻却被人用黑蜡封过两次。第一次封蜡的边缘已经发白，第二次封蜡压得很重，像是有人不愿让后来的人看见里面到底少了什么。贺停舟把木杖放在门边，要求由他自己取柜中卷宗，陆昭只负责记录，许青棠负责伤情和纸材，秦衡的书吏不得先翻。

“你可以不看。”陆昭说。

“我若不看，旧案就会继续替我说话。”贺停舟回答。

卷宗题名是“镇南关乙巳年冬粮路误结案”。封面上的“误结”二字被刀划过，后面又补了“待议”。第一份证物清单列着：关北七号粮旗、三日军粮路条、守关卒陈述、受伤名册和一枚已断的黑铜印。清单末尾却有一行红字：“相关活人已接收，责任由贺停舟承担。”

贺停舟看见那行字，手指在木杖上停住。他说当年镇南关外有一支运输队失踪，留下半面军旗和七段没有写完的路条。守关卒都以为死者要把粮路送回关内，他便以镇诡卫身份封住关门，要求军需官在接收栏按印。军需官拒绝，因为那七段路中有两段涉及撤民，不是单纯军粮。

“我当时认为拒绝是怕担责。”贺停舟说，“我让书吏把拒绝改写成暂缓，然后盖了‘已交功’。功簿院后来认定我完成了第一步和第二步，第三步被一句‘军需官知情’替代。”

陆昭没有插话。他让书吏把卷宗原文和贺停舟口述分栏记录，不能用后来的悔意改写当年的字迹。

第二份证物是黑铜印断片。印面刻着旧式“镇南关”，边缘有一条自内向外的裂纹。许青棠用细镜看出裂纹并非摔断，而是从印面一处细孔扩散。她问贺停舟，当时是否有人用针在印面上做过记号。

贺停舟说不记得。他只记得自己在风雪里盖下那一印，左腿随即失去知觉。不是被刀砍，也不是冻伤；他站在关楼上，看见关外七段粮路一齐翻回，像被一只看不见的手从纸背推来。接着他摔下木梯，醒来时左腿已经坏死。

功簿院卷宗把那次事故定为“诡力反噬”，却没有记录反噬前军需官是否真正接收结果。贺停舟说自己后来问过军需官，对方只承认看见那张功单，不承认愿意承担撤民后的责任。那份口供被夹在卷宗末尾，纸角已被撕去一块，只剩“我没有……”三个字。

秦衡伸手想取口供，贺停舟拦住：“先写你的选择。你要看原件，还是只听我念副本？”

秦衡停了一息，选择只听副本，不碰被撕角的原件。他让书吏记录自己拒绝接触的理由，承认功簿院不能用掌院权限替军需官补完当年的选择。这个动作并没有洗去功簿院的责任，至少让今日的取证不再复制旧案。

许青棠检查贺停舟的左腿旧伤。她不是第一次见，但这次要求他在灯下把假肢拆开。腿骨外侧有一道弧形骨化痕，痕迹从膝下向外扩散，与陆昭听骨曾读到的任何尸骨受力都不同。她说明这只能证明旧伤后的骨化和长期承重，不可反推当年反噬来源。

“我这条腿不是功劳。”贺停舟说，“是我把一个人的拒绝写成知情后留下的账。”

陆昭翻到卷宗的附录。附录中有一张与第22章假功单极为相似的格式：姓名栏、路段栏、接收栏和责任栏被排成一页，右下角预先印着“功成”。纸材比东市粗纸细，却有同样的横线。墨迹经过多年褪色，遇水测试只能留下浅灰边，不能证明它与城门簿墨同源。

贺停舟说，当年那种格式来自功簿院的旧模板，不是妖纸。纸上预先写“功成”，是为了让核验官快速归档。他没想到格式会反过来压迫军需官，也没想到自己会把它当成了事实。

陆昭把旧模板、现行预录单和东市假功单并列，但不相互覆盖。三者都出现“功成”字样，纸纹、墨色和笔压不同；相似只说明制度格式可能被反复利用，不能说明同一个人制作。

旧案中还有一枚空白木牌。木牌背面写着“撤民先于领功”，字迹是军需官留下的，正面却被人刻成“已交”。贺停舟说军需官后来坚持把撤民物资送回关内，自己却因伤离任，没人知道那七段粮路最后是否完成。

陆昭要求把旧案的责任链重新摊开。关北七号粮旗由守关卒捡回，三日军粮路条由军需官保管，撤民物资清单则在关门后才补进来；三样东西从未同时交给同一个人。贺停舟当年把它们压在一枚镇诡卫印下，实际只确认了旗和路条的存在，没有确认接收人是否愿意接住撤民责任。许青棠在清单边缘找到两处被水泡开的朱砂点，一处压在“军粮”二字旁，一处压在“撤民”二字旁，点位并不相同，也不能由此推断军需官签过两种责任。

秦衡的书吏对旧模板作了纸纹拓片，发现模板左上角有三道极浅的折痕，现行预录单只有两道，东市假功单则在右下角多一处回折。许青棠又以旧黑铜印断片做接触比对，印面裂纹没有在三种纸上留下同样的压痕。她把拓片、印泥残屑和旧模板纸纤维分成三袋，注明只能说明模板曾被反复折叠，不能说明今日假功单由旧案原人誊写。

贺停舟听完比对，主动提出把自己当年留下的私记交出来。私记只有半页，记着“军需官说先撤北沟三户，再谈入册”，后面一行被冻裂的墨痕截断。他选择允许三方抄录，不允许任何人据半页私记替军需官补写姓名。陆昭则在责任栏写下：旧案原件留在北镇，封存期限由他承担；若有人擅自拆封，先追究保管链，不把失窃或篡改归到已死或失踪者头上。贺停舟按下手印时，木杖微微发颤，却没有把这次承认申报为功。

许青棠将贺停舟的旧伤与当年卷宗上的时间标记逐一核对。她指出，左腿骨化说明伤后长期承重，不能证明诡力从印面传入，也不能把陆昭左手的失痛与旧案反噬当成同一种代价。贺停舟接受这项限制，要求在卷宗上补一句“伤情未能解释反噬来源”，免得后来的核验者用一条相似的伤腿替代全部证据。

黑簿在陆昭怀中微热，却没有翻页。它没有死者姓名，也没有把贺停舟的旧案改写成今日未结之功。陆昭明白，旧案能证明一条规则的危险，却不能替今天的周循确定未竟之事。

秦衡提出把旧模板和旧口供带回功簿院，作为纸妖案的制度背景。贺停舟选择同意复制，不同意交出军需官口供原件；陆昭选择承担原件留在北镇的封存责任；许青棠选择保留旧伤复核副本，不让功簿院只拿“反噬”两个字解释伤情。三个人各自按印。

离开木柜时，贺停舟忽然说：“你们若遇到纸上先写好的功成，别急着烧。烧了，证人就只剩下你们的说法。”

陆昭问：“那该怎么办？”

“先把证人从纸后面拉出来。”贺停舟看向北门方向，“让他自己说愿不愿意承担。再斩纸，不斩人。”

夜半，镇诡司证物房传来一声纸裂。守卒来报，三方封存的城门簿、假功单和乙十七木牌都在同一只空木箱里轻轻移动，封条没有破，却有一张白纸从箱缝伸出。

白纸上没有姓名，只写着四个字：

贺停舟的旧案卷里，最关键的一页不是结论，而是他当年签过的退门记录。记录显示他看见过三名活人撤回，却没有权力替他们认领远处尸体。陆昭没有用旧案为他开脱，只问他是否愿意承接重新核查。贺停舟同意，并要求自己不参与第一轮盲验，避免熟悉的笔迹影响结果。司空烬得知后没有撤走旧卷，只加了一枚调阅时刻签。

“旧案重演。”

贺停舟说完便把退门记录推到陆昭面前，要求先看原件封边。封边上的旧蜡已经开裂，裂口里夹着一粒与今日白纸不同的黄砂。陆昭没有伸手取砂，只让阮遐用空针挑出，另封为“旧案封边样”。贺停舟承认自己当年曾在记录末尾添过一句“撤民已妥”，却说那句是上官口述后由他誊写，并非三名活人本人选择。他愿意接受复核，不愿把旧句改成自己从未写过。

司空烬派来的院吏要求把旧案模板与城门簿一同开柜。贺停舟拒绝让模板先接触原簿，提出先做纸张和印泥盲验。三份样纸被遮去来源，院吏只按纤维、墨色和蜡边编号。结果显示模板纸与今日假功单同属粗纸坊，却不能证明同一手抄写；印泥中盐分接近，也不足以证明使用过同一枚印。陆昭把这组排除写进复核表，提醒众人“不相同”与“同源”都需要独立证据。

贺停舟随后请当年三名撤民者的家属分别说明，家中是否保存过退门副条。两户愿意提供纸片，但拒绝公开完整姓名；第三户只有口述，没有纸。陆昭让书吏把家属愿意提供的范围逐项读回，家属可撤回尚未取样的部分。纸片上的“已撤”两字都有真实笔压，却没有接收栏，说明撤回动作存在，不能说明谁承接了远处尸体。

夜半那张白纸再次从空木箱缝中探出，这次纸面写着“退门可算”。贺停舟看见后没有用木杖压住，而是先说自己不接受这句话替旧案结论。陆昭让他本人写下拒绝范围，贺停舟只拒绝“把撤民写成已完成”，不拒绝重新调查三名活人的去向。白纸上的字随之淡去，箱内三件证物没有移动。纸妖仍能诱导解释，却不能代替活人把旧案改成已结。
