# 第九十六章 不替天下认名

北镇旧棚暴露人骨的第三日，功簿院送来一份加急文书。文书没有写结功，却把九镇所有未确认的尸体候选列成一张“待统一命名表”：第二镇八名未归者、第三镇两船未归船工、北镇旧棚一处前臂骨、旧总表三具无主尸，连同许青岚的候选身份也在其中。表末附一行小字：统一称谓后，便于药粮、搜寻和后续承责。

司空烬读完没有立刻盖印。他先看送文驿卒的证词。驿卒只承认从院门取到封袋，承认封袋在过桥时受过雪水，不知道表是谁拟的，也没有见过院中哪位官员落款。文书用的是新麻纸，印色与旧总表相近，纤维却比总表细，不能由印色推同源。司空烬命人把命名表、封袋和桥上雪水样分开封存，随后召九镇文吏回到验物厅。

第一镇文吏先指出，表里把他们送达的迟到药车写成护送人。药车夫此前只承认迟到时辰，不承认护送完成，更不愿让自己的名字进入待功栏。第二镇代表看见八名未归者被写成八具待认尸，当场要求划回八名待搜活人候选。此前两名砍柴者和一名自行回药房者都已从待搜数中核减，不能再拿他们冲抵眼下这八人。第三镇的两船则被写成船工遗失，可两名水卒仍在等接船人回报，不能把船未归等同船工已死。

北镇文吏把旧棚前臂骨的一行圈出。表上写义冢末一具，疑为阿岐，却没有注明阿岐只是周溯叔父听来的称呼，也没有写骨段没有性别、年岁和死亡时间结论。陆昭坐在白线外，先报自己能确认的内容：旧棚墙内有木匣，匣口露一段人骨，位置已画、危墙已支、原位未动。他拒绝在阿岐旁边写姓名候选，要求改为口述称呼候选，未具认尸效力。

司空烬的副官问，若每个镇都坚持自己的词，朝廷如何调粮调兵。贺停舟从北镇守柜回批上写明，粮袋按伤员、守线、车次和实耗调度，不需要先知道谁是尸体；搜寻按路线、最后见闻和水位执行，也不需要把未回写成已亡。顾衡补充，若将八名未归者写成尸名，搜寻队会少拨一队活人搜寻粮，遗属也可能被提前通知死亡。统一命名省的是纸，不是责任。

司空烬把命名表分成四种颜色。灰色是本人尚未询问，蓝色是活人明确拒绝代认，黄褐色是有物证但身份未闭合，白色才是经第三方确认的姓名。许青棠从皇城远程发来伤亡复核署的旧格式，要求颜色不能替代文字，每一色都须附来源、时间和可反证路径。她右肩牵痛加重，仍只签远程复核范围，不把自己的身体记录扩成九镇伤亡结论。

第二镇一名回城者被请来当面说明。她说八名未归者里有一个人曾与她共用药房棚，但她只知道对方自称老七，不知道姓名、籍贯或是否后来离开。她愿意承接自己的伤情和共棚时辰，不愿被写成八人中任何一人的家属。文书若把老七写进尸体候选，她要求撤回签字。秦衡让她在第三列具体写拒绝以共棚见闻替他人认名，并把拒绝对象列清，命名表因此多出一页。

第三镇水卒也来作证。他们在船铃断前听见两声回响，随后一条船向北漂，另一条被南流带走。他们只能承接自己听见的时刻和缆绳损耗，不承接船工死因。有人拿出黑蜡陶罐，说罐底也有两道回纹，似乎能解释回声。鉴纸师与陶匠分别检验，陶罐内盐分与旧门水样不一致，回纹是烧制时的收缩，不是刻意留下的标记。两船的命名仍被退回路线待核。

第九镇狭签的影像在此时送到。签面义冢，末一具，未移被命名表抄成末一具已定位。秦衡指出，未移只说明标签上的动作状态，既不能说明木匣仍在义冢，也不能说明标签指向哪一具。第九镇文吏补充，空匣在本地封存时底板有新刀痕，拆匣人只承认取影，不承认放签。两个镇的记录互相指向，却没有交接链，不能由北镇替第九镇完成解释。

司空烬的副官再次提出折中：先用临时编号替换名字，统一写成北九一、二镇八、三镇双船。陆昭认为编号若只代表位置和送达时刻，可以使用；但若编号被放进功簿或死亡名单，仍会变成不带姓名的强制认领。他要求每个编号后附三栏：谁可询问、谁拒绝代认、哪一项证物可能推翻当前状态。司空烬采纳，命文吏在编号旁留出反证栏，并承担因此增加的纸张与回传延误。

这项决定立即引发调度困难。北镇要不要为旧棚人骨候选派一队守护，还是把人手调去第二镇河堤搜寻？卫岑提出分时责任：两名守棚，四名沿河，若水位超过第二桩，守棚队先救遗存，河堤队仍按原路线搜人。顾衡算出多出的火油和干粮只够两日，要求九镇明确谁补足第三日。司空烬把补粮列院方承责，不以统一命名表向地方摊派。

贺停舟提醒，命名不是唯一的行政门槛。三钥柜若收到一张写满姓名的总表，后来的守柜人可能把它当作接收凭据。于是他要求所有临时编号表在封面印上不得作为功簿第三步，并把封签拓样寄给九镇。封面上不能有已认、已亡或代签，只能写本表用于搜寻、伤情和证物分流。司空烬同意，却保留自己解释朝廷命令的责任，不把限制归咎于贺停舟。

陆昭被安排核对编号反证栏。他先检查北九一：旧棚人骨一处、木匣位置有影、前臂未移、姓名未定、活人选择未获。再检查二镇八：八名仍待搜，先前归来的两名砍柴者与一名回药房者已有独立核减记录，家属各自选择未齐。第三镇双船只写两条待核路线，不写船工姓名。每核完一项，他都要让另一名文吏复读，避免自己把未定听成已定。半个时辰后，他左手麻意沿腕上行，主动交出副图，药吏记录休息，不让他硬撑到整张表结束。

休息时，陆昭问司空烬为何仍想统一。司空烬回答，过去九镇互相推责，活人被困在没有姓名就不能拨粮的空隙里；统一格式本来是为了让救援先走。可格式一旦携带姓名和结果，就会从调度工具变成替人决定的刀。他不承认自己已经想出完美办法，只承认院方必须同时承担格式误写、调度延误和对外解释。

一名年轻文吏低声说，若不给那段前臂一个名字，死者永远只是编号。北镇义冢守人回他，先给他一个不会被抹掉的原位，再给他一个别人能够反驳的记录；把不知道的名字写上去，才是让他永远被错认。周溯叔父的询问尚未完成，三具无主尸的家属尚未找到，谁都没有资格把想被记住当成死者的选择。

命名表最终被退回，改成《九镇未决对象与责任分流表》。它保留临时编号、证物编号、可询活人、拒绝对象、当前承责人和下一步复核时限，不写任何代结功名。司空烬在退文上承认原命名表造成了误导，承诺向九镇公开更正并补足调度延误的粮药；副官不情愿，却仍在见证栏签下自己的递送责任。

黄昏，九镇各自带走本镇副本，北镇只留封签拓样和反证索引。旧棚人骨候选继续由北镇守护，第二镇搜寻继续，第三镇水路复测继续，第九镇狭签留在当地。陆昭的临时编号职责没有带来新印权，也没有恢复听骨；他仍需双人复核，左手失痛和错认风险继续。黑簿原册在三钥柜，封功刀未动，功簿四步没有因为全天下都想知道名字而少掉任何一步。

不替天下认名的命名表把第二镇八名待搜、第三镇两船、旧棚人骨和三具无名尸混在一页。陆昭退回表格，要求保留错误、反证路径、送达时刻和院方补粮延误。第二镇三名已回者被独立核减，剩余八人仍待搜；第三镇两船仍只确认水位和缆绳，不认船工已死。陆昭半个时辰后交出副图休息，错听和伤情继续留档。

夜风从旧门一人宽的缝里进来，门槛没有浮字。守门人报横梁偏移未超过半寸，药吏报陆昭今日两次休息和一次错听，顾衡报补粮需多走三里。司空烬把这些责任写入分流表末页：不替天下认名，也不让天下因为无人先认名而停止救援。未知者仍未有名字，却终于有了不会被一张总表吞掉的证据位置。

分流表退回命名表时，原命名表上的三处朱圈仍然保留。第一处圈住“前臂”，表示尚未确认完整遗存；第二处圈住“末一具”，表示狭签字面不等于实际尸位；第三处圈住“无主”，表示没有找到家属而非已经证明无人。记录吏提出把朱圈涂白，陆昭拒绝，要求保留错误和曾经差点被认成结论的痕迹。司空烬让涂白建议写入异议栏，由提出者自行承接，不把撤回误当成从未发生。

旧棚危墙的支梁在雨后下沉半分，工匠先把露骨周围的砂袋加高，再测骨是否移动。骨未移，支梁却需再加一根木楔；木料短缺由贺停舟从守门备用料中调拨，补回时间和缺口分别记账。陆昭只在远处复读编号，没有靠听骨判断骨是否属于某具无主尸。救援仍先于命名，分权表也因此多出一笔真实的木料责任。

支梁加固后，守棚工匠发现一枚旧铜钉落在砂袋外。铜钉长度与木架现用钉不同，表面却沾有同色灰泥。工匠愿承接发现位置，不愿承接铜钉原来属于哪一架；北镇锁匠只负责量钉径，拒绝用相似灰泥把它接到旧总表。铜钉被单独封袋，木架的修缮记录留在北镇，跨镇索引只收编号和照片。司空烬承认每多一件“可能相关”的小物，就多一份保管和复读成本，不能因成本高便省掉反证路径。
