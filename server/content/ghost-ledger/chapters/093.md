# 第九十三章 九镇分簿

六名证人散去的第二日，九镇分簿草案被抬进外仓。九只木匣大小不一，封皮却都只写镇名、日期和送达时刻，没有“共证”“总功”之类的字。司空烬站在验物厅中央，先把院印放进空匣，命秦衡记录封印动作，再让九镇文吏各自开本镇木匣。每一把封签都由两人见证，开匣后只取出本镇原件的编号页，不许把别镇纸张压在上面。

九镇分簿的第一列叫事实，第二列叫证物，第三列叫本人选择，第四列叫后果承接。第五列原本写着“功名”，司空烬亲手用朱线划掉，改成“待申请事项”，并在旁边注明：没有四步完整记录，不得填写结算。有人问为何不留一格给功簿院，司空烬说院方可以承接复核、药粮和延误，不能替死者说遗愿，也不能替活人按下同意。

第一镇送来的事实只有一辆迟到的药车和两名换班巡骑。证物是车轴拓样、药箱封签和一枚被雪水浸软的木楔。本人选择栏里，巡骑只同意记录耳道伤情，药车夫只同意承认迟到时辰，二人都拒绝被写成“护送完成”。后果承接栏因此分成三项：第一镇承认半日药耗，北镇承认转运延误，个人不承接任何功劳。三项写完，木牌上的湿痕没有再扩散。

第二镇的回执更复杂。九袋粮里有六袋旧路条、两袋换线、三袋接收栏空白的重叠记录。顾衡把粮重、散漏和分装分别列账，阮遐从药房传来一名自行回城者的伤情选择，其余八名未归者仍写“待搜”。文吏差点把“待搜”抄成“待收”，陆昭在白线外听见后立即要求停笔。第三镇文吏重读两遍，承认纸边被湿气卷起，不能将一个字的形近当作事实。更正后，陆昭又把自己听到的“待搜”复述一遍，要求把这次纠正和错听风险同时留档。

第三镇的三船回执只证明一船在午前归航、两船尚未核验，另外两船的名册仍缺回声与接船人。水卒愿意承接缆绳损耗和自己的掌心擦伤，不愿替未归船工确认生死。第四镇则把小岚母亲的选择单送来：她只同意保留女儿的小名，不同意任何人补写大名，也不愿把同数户籍与第三镇待救户混成一案。两镇的纸张在同一张桌上，却被木尺隔出三寸空隙，目录上也不使用“对应”二字，只写“同时收到”。

第五镇至第九镇的材料更少。第五镇只有迟到药车的轮印和收药人的手写时刻；第六镇报空缺烽台，但守台人尚未确认是否离岗；第七镇交来白粉木屑，拒绝说明它是否来自北镇石槽；第八镇送来半字木楔，刻痕方向与别镇样本相反；第九镇则只有一个空匣和一份“原件未见”的回执。司空烬不许文吏因九镇都缺一项就把缺项写成同一异常，要求每镇在证物栏写出缺失的具体内容。

午后，院方旧总表被抬来作为对照。总表把九镇都缩成四个字：已回、已收、已守、已报。秦衡逐字指出，第一镇的“已报”只是送达，第二镇的“已收”只是一袋粮的重量签，第三镇的“已回”只对应一条船，第四镇的“已守”只对应小岚母亲在门内站过一刻钟。四个词看似整齐，实际上跨越了不同的人和动作。司空烬下令将总表退回，不许涂改，只在旁边加一张纠错索引，标明每个缩写对应的原件编号和未覆盖范围。

九镇文吏为纠错争了半个时辰。有人担心每个空白都写清，会让上报变慢；有人担心若不写清，下一任抄录者会把沉默当同意。贺停舟从北镇送来一张守柜批回，说明三钥柜只接受编号、封签和开柜人，不接受“九镇共同认可”的空泛结论。司空烬将批回放进第四列，注明这是北镇守柜责任，不是九镇对任何功劳的接收。顾衡又补了一笔，分簿制作多耗两名文吏和三十七张纸，纸钱列院方行政实耗。

陆昭被叫到分簿边上，只能看无姓名的编号页。第一列与第二列之间，文吏用细蓝线隔开；第三列每一项选择都须由本人签字、按指或明确拒绝，若本人尚未被询问，只能写“未询问”，不得留空。第四列则要求写出谁承担药粮、守门、复核、延误和损耗，并附起止时刻。陆昭指出，若把“拒绝接收”写进第三列却不写对象，下一次抄录仍可能把拒绝扩成拒绝一切。他要求每个拒绝后面附具体对象，司空烬采纳并承担增页责任。

一名轮值文吏提出，把陆昭的暂缓告示放进九镇共同选择栏，作为“观察员同意继续核验”。陆昭当场拒绝。他承认自己同意报告伤情、错听、复述和封签编号，却不承认以个人告示替九镇活人选择。司空烬让文吏另起一格，写“个人观察职责，范围限于本人签字内容”，并在下方记明陆昭未接收任何功劳。这个决定使分簿多出一页，却阻止了一个人的配合被抄成九镇共同授权。

夕阳下，九只木匣重新封回。各镇文吏互换封签拓样，却不互换原件；交换只证明封签形状，不证明内容相同。门外有人听见旧镇门横梁轻响，守门人按刻钟报告偏移，木匣没有随声震动。司空烬命人把声响列为另案现象，不能用分簿的整齐格式解释门槛异常。贺停舟在回批上写明北镇守柜将承担一夜复核，卫岑承接外仓巡线，粮吏承接增纸和封存油耗。

夜深时，九镇分簿终于形成九本各自闭合的目录，却没有形成一件共同功。第三列仍有拒绝和未询问，第四列仍有待核和承责未定，缺失第三联、三具无名尸、八名未归者与两船待核都未被填成结果。陆昭左手失痛，浅裂被药吏重新缠好，错听“目录”为“功录”后立即更正。他没有触碰黑簿、尸骨和封功刀，也没有使用听骨。

为防止夜间抄录走样，秦衡制定三次复核：第一次只读编号和页码，第二次只核本人选择，第三次才核后果承接。任何一名文吏若把“未询问”改成空白，必须保留原页、写明改动时刻，并由另镇见证人签名。若封签破损，先暂停传送，不得以急着回报为由补写内容。这个流程会让回传至少慢一刻钟，司空烬把延误写入院方责任栏，同时命粮吏在这段时间先按旧额度发放底粮。

司空烬把九本分簿锁入九个不同柜格，给陆昭一张不带印的副图，让他只核对编号和更正记录。陆昭接下这项有限职责，知道它会使自己继续暴露在名字和纸面异常附近，却拒绝承接九镇总功。分簿把“天下已同意”拆成九镇各自尚未完成的选择，也把下一步责任推回每一个真正做过动作的人。门外木楔声停了一刻，随后重新响起，像在提醒所有人：分开记录不是结束，而是让每一条因果重新找到能够作证的人。

分簿旁另挂一块纠错牌，记录谁在何时发现哪一字有误。纠错不抹原字，只标可追溯的更正号；本人若不同意更正，可以保留原述并另附说明。司空烬承认这会增加复核纸耗，却能防止后来的人只看最后一笔朱墨。九镇各派一名文吏轮流查牌，查出的疑点只退回本镇复核，不得由他镇替写结论。

九镇分簿第一次使用四栏：本镇事实、证物方法、本人选择、后果承接。原件留本镇，异镇交换编号和封签拓样。旧总表的已回、已收、已守、已报保留原页，纠错索引另附，不把送达、重量和站位缩成共同同意。陆昭只负责副图、错听、伤情和封签编号的有限复读，院方承担增纸、文吏、油耗和回传延误。

每次退回都留时刻与签名，旧页照存。

第一轮回传时，第三镇把一张缆绳影像误放进第二镇目录。发现错误的文吏没有把影像撕掉，而是补一张纠错单，写明误放时刻、发现人和重新封存位置。第二镇文吏拒绝在“本镇事实”栏签字，只承接把影像退回原镇。陆昭复读编号时把“退回”听成“退功”，当场更正并让药吏记录疲劳状态。错误没有消失，却有了可追的来路。

九本分簿外各设一页“未完成动作”，列出谁还要测什么、询问谁、在何时回报。司空烬承担院方汇总页的纸耗，贺停舟承担北镇柜门复核，许青棠远程承接伤情格式审阅。无人把这页写成总功清单。门外旧镇门每刻钟报一次横梁位置，救援路线和分簿编号因此各自保持边界。

第三镇退回的影像在第二次清点时少了一角，文吏先查是否装袋时折卷，再查原镇留存的底图。底图完整，缺角只在传送副本上，无法证明有人删改内容；第二镇因此只承接退回动作，不承接影像原貌。院方补做一份影像时，记录吏把“重做”写在新编号，不覆盖旧缺角。重做的油墨和驿骑耗费由院方承担，原件所在镇不因副本破损而被迫再开柜。

陆昭复读九本分簿的“未询问”栏时，要求每镇附上下一次询问的对象类别，而非直接写人名。有人认为这样会让搜寻变慢，许青棠回函说，先写“家属”“守门人”或“伤者本人”，可以提醒询问者尊重拒绝；先写一个未经确认的名字，反而会把询问变成默认认领。司空烬采纳后，在院方责任栏写下格式变更和一日回传延误。

第三镇文吏送回影像时，另附一张手绘的装袋顺序图。图上先画缆绳，再画封签，最后画驿骑手套；他承认顺序是凭记忆补画，未必与当日完全相同。秦衡不把图并入证物方法栏，只放进“送达过程自述”，并要求文吏写明不能证明的部分。陆昭看到“最后”二字时问是否指最后一件物证，文吏答是最后一只手套，记录人将问答一并保存，避免语义再次漂移。
