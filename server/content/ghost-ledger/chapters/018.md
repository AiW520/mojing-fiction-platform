# 第十八章 会写名字的纸妖

那张白纸被三层油纸包住，仍在木匣里发出细微的摩擦声。

陆昭回到北镇后，没有把它送进普通证物柜。纸面上先后出现“林漆已领”和“陆昭已领印”，两行字都像人写，却没有留下笔压。若把纸同姓名册放在一起，后果无法预估；他让韩六取来空木匣，匣底铺清砂，四角各压一枚没有刻字的石块。石块由贺停舟挑选，避免使用带有官号或死者姓名的物件。

许青棠把纸放在医署灯下，不让灯焰直接接触。她先量纸厚、纸纹和纤维方向，再用湿棉签试边缘。纸没有吸水，反而把水珠沿着纹路推到“领”字旁。她说：“这不是普通军令纸，也不像尸袋用纸。纸面有蜡，但蜡不是涂在外层，是夹在两层纤维之间。”

“会写名字的纸，先查它能不能写别的。”陆昭说。

他取出一块空白木牌，不写自己的名字，只画一个圆。木牌放在纸匣旁，纸面没有反应。再放一片无字瓦片，纸面也没有反应。许青棠让药童在另一张纸上写“甲”，然后把那张纸隔着油纸靠近匣盖。白纸上的“领”字轻轻一抖，像被风吹过，却没有新增笔画。

“它不照抄所有文字。”许青棠说，“它像是在等某种关系。”

陆昭把林漆妻子的限定选择、尸体封存单和城外空车拓本分开放。纸面最先朝尸体封存单折了一角，折痕指向“死者姓名”一栏；随后又朝派行单折去，折痕指向“镇诡卫陆昭”一栏。它没有碰家属拒绝祭名单的那一栏。

贺停舟看着折痕，慢慢道：“它不认识字，或者它认识的不是字。”

“可能是名字后面的责任。”陆昭说，“也可能只是纸上残留了某种术式。”

他们没有把推测写成结论。许青棠取下空车纸边一小片，分成三份：医署留一份，镇诡司留一份，第三份由林漆妻子决定是否带回。她选择带回，却要求不把纸片贴在丈夫的车铃旁，免得车铃被写上别人的名字。陆昭照录她的理由，并把“纸片未接触姓名册”作为交接条件。

午后，北镇司送来一摞失踪人口的旧报验单，要求陆昭用会写名字的纸“试一遍”，若能写出失踪者姓名，就可省去逐户查访。送单的吏员说这是上峰意思，没有拿出正式文书。陆昭没有接单，只请他写下姓名、来意、时刻和是否愿意承担纸妖写错后的家属追查。吏员脸色变了，说自己只是传话。

“传话也可以留名。”陆昭答，“但这不是同意把姓名交给一张来路不明的纸。”

吏员转身欲走，纸匣中的白纸忽然发出一声脆响。匣盖没有打开，油纸内侧却多出一行黑字：“赵衡。”

送单吏员看到这个名字，立即说是他父亲的名讳，要求陆昭把纸毁掉。陆昭没有动匣子，先问他是否愿意把父亲姓名写入涉诡记录。吏员摇头，又说这不是他写的。两种选择都被记下：他拒绝写入，承认纸面已出现与家族相关的名字。

许青棠检验纸面，发现“赵衡”两字的墨色比“林漆”浅，笔画却更像同一只手。墨迹未干，说明出现时间很近；纸纤维没有被笔尖压破，仍不能证明纸上存在真正的书写者。陆昭让吏员把父亲的户籍副本交给北镇司核对，但不允许原件靠近纸匣。吏员选择只交无姓名编号的页码，拒绝交出户籍，要求这项选择也写进记录。

纸匣内的白纸忽然向外鼓起。

清砂在匣底形成一个个浅坑，像有看不见的手指从纸下按压。陆昭没有拔刀。他先让贺停舟关闭医署东门，城防责任只限一刻钟；许青棠带药童退到三步外，仍由她负责判断伤情；送单吏员可以离开，但必须在交接单上写明纸匣曾出现其父姓名。吏员咬牙留下，拒绝接近匣子。

纸面上又出现两个字：“陆昭。”

这一次字迹从边缘向中间长出，像墨水在纸里生根。陆昭右手握住镇诡卫印，没有把印面盖在纸上。功簿没有发热，说明这不是未结之功的提示；镇诡卫印也没有赋予他识别妖物的权力。他只能依照证物规则处理。

“纸想要一个承认。”许青棠说。

“或者它想把承认写成我的选择。”陆昭看着自己的名字，“先隔离，不回答。”

他让韩六取来一块旧车轴木，把木块立在纸匣与姓名单之间。木块上没有名字，却有旧年收尸车的刮痕。纸面立即转向木块，边缘卷起一点，露出夹层中的细红线。红线与第十六章旧铁牌红蜡颜色接近，但没有蜡的裂纹；许青棠只取样，不判定同源。

红线被挑出时，医署东门外传来三声敲击。守门人报告，门外有个穿白麻衣的人，自称“送纸”。那人没有户牌，脚下没有雪印，手里却抱着一摞折好的空纸。贺停舟要出门拦截，陆昭先要求门卫把来人停在雪线外，不许带纸进城，也不许用姓名询问。

白麻衣人隔着门喊：“纸上写谁，谁就是欠功的人。你们只要把名字认下，妖就替你们查完。”

许青棠问他从何处来。白麻衣人没有回答，反而展开一张纸。纸面上先写“林漆”，又写“赵衡”，最后写出“许青棠”三个字。许青棠没有伸手抢纸，也没有否认字迹与自己的关系。她只说：“我的名字可以被写，不等于我同意被列入任何名单。”

白麻衣人笑了一声，纸上“许青棠”的最后一笔忽然折断，墨线沿着折痕向外爬，像在寻找下一个可接的名字。陆昭让贺停舟把门栓加固，却不下令追捕。门外人是活人还是纸妖尚未确认，若先以诡物处置，便会丢掉能核对纸张来源的口供。

他请门外人把三件事写清：送纸人的姓名、纸张来源、愿意承担的后果。白麻衣人沉默片刻，竟把一张纸塞进门缝。纸面没有落款，只有一行字：“北镇第七仓，第三把锁。”

这张纸与匣中白纸纤维不同，折痕也不同。陆昭没有把它视作同一纸妖留下的证据，只作为独立线索封存。门外白麻衣人的脚下仍无脚印，城门守卒却说风里闻到桐油味。

纸匣中的白纸此时猛地拍在匣盖上，墨色散成一圈。圈内没有名字，只有四个字：

“先认其名。”

黑簿在陆昭怀中终于发出一声轻响，但页面没有新增功劳，只把“未结之功”四字压得更深。陆昭明白，纸妖正在诱使他们用一张纸替活人作选择；只要有人把名字认下，证据、本人同意和责任承担便会被伪装成一笔墨。

他把镇诡卫印收回腰侧，吩咐所有人不得念出纸上新出现的名字。对林漆，先守尸体和家属限定；对赵衡，先守送单吏员的拒绝；对许青棠，先守她本人没有同意被列名的选择。三条边界互不相抵，纸妖便无法用一个名字串起三件事。

白麻衣人站在雪线外，忽然转身。风吹开他的衣摆，里面不是人的皮肉，而是一叠叠裁好的薄纸。每一叠纸上都写着不同的姓名，却没有一张写完整。

贺停舟想追，陆昭抬手拦住：“先封门，再封纸。追出去，谁来证明我们没有把名字带出城？”

北镇东门重新落锁。第十八章没有结算新的技艺，却确认了纸妖的第一个危险：它不靠刀爪杀人，而是借活人的承认把姓名变成责任。陆昭把“会写名字”写进诡物观察栏，把“纸上所写不等于本人同意”写进功簿规则旁。

木匣里，白纸又慢慢写出一行新的墨迹。

这次只有一个字：

“岳。”

白纸第一次写出陆昭姓名时，他要求守卒把纸放在两层玻璃之间观察，免得笔画自行折入夹层。纸背有红线，红线与旧铁牌红蜡颜色相近，却尚无熔点和纤维接触证据。许青棠把“陆昭”二字抄下，但没有让本人在旁边按印确认；名字被写出来不等于名字主人同意。众人于是把异常纸、本人证词和门外麻衣人纸条分成三栏。

陆昭没有追问这个字是不是姓名。他让林漆妻子先确认自己听见的是一个音节，而不是纸面上的完整字形；妻子点头，却说不知道岳成是否还活着。赵衡之子站在门外，只愿意证明父亲曾把一把仓钥交给谁，不愿意看纸上的名字。两份选择被分开记录，纸面上的“岳”因此没有得到任何活人接收。

白麻衣人留下的纸条边缘沾着细盐，和匣中白纸的纤维方向相反。许青棠取样时右肩牵痛，主动让药童扶住手肘，却不让药童替她写结论。陆昭把扶持动作记入伤情栏，要求下一班人知道她当时仍在场，但承受范围已经改变。门内的纸妖没有因为无人认名而消失，线索却被拆成了可以复测的几段。

换班前，陆昭把木匣、红线样本和门外纸条交给三名不同保管人。木匣留在医署砂柜，由许青棠负责温度与湿度；红线样本送北镇验物厅，由贺停舟安排双钥开袋；门外纸条暂存城门文书房，由守门什长只负责封签，不负责解释纸面文字。三人当面复读编号、封袋时刻和禁止事项，任何一栏写成“已认名”都被退回改作“纸面出现”。赵衡之子随后补交一份无名钥匙交接见闻，只愿证明父亲曾经在谁手中，不愿把父亲姓名与白纸相连。陆昭将这份见闻附在选择栏外，注明它不能替赵衡作答，也不能替林漆家属承认同一件事。纸匣里的墨迹因此仍是异常现象，不是活人的承接。夜班记录同时注明：纸面自行增字的时刻、在场者和未接触范围均可复核，任何人不得把异常字迹抄入功名栏。守卒还在封面补记门外风向、纸条落地位置和两次复读间隔，交班者逐项确认后才封柜，确保后来者能够区分纸妖动作、活人选择与保管过程中的普通移动并留痕。
