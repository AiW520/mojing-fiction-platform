# 第二章 功簿开页

粮仓里的撞击声停了。

陆昭没有立刻开门。他让韩六取来三根麻绳，把三具尸体的木板车横在驿站过道，再把风灯移到门槛内侧。许青棠站在粮仓西墙，弩口对着门缝，箭头没有越过封条。她问为什么不先救人，陆昭说因为刚才那声撞击太短，像木块碰铁，不像活人求救；如果里面真有活人，等一息可以减少一个被挟持的角度。

韩六想骂他冷血，又看见三具尸体，最终把话咽了回去。

陆昭用尸体登记牌压住门槛的雪，把粮仓门外的脚印、木套刮痕和封条阴影逐一拓下。封条上的副印缺了一角，缺角处沾着黑砂。砂粒与三具尸体袋中的砂颜色近似，但颗粒大小不一。他把两种砂并排放进白瓷盘，没有急着写同源。

许青棠低声道：“你在等什么？”

“等里面的人再碰一次门。”

“如果它不碰？”

“那就先查门。”

他说得像在说一具尸体。许青棠没有催，她把弩臂压低半寸，留出照明角度。陆昭取出细刃，从门锁外沿刮下一层油灰。油灰下面有新铜屑，铜屑方向朝里，说明锁舌被人从内侧顶过，门外的封条反而没有受力。有人在不破封的情况下动过门，或者封条是在门被动过后重新贴上的。

他伸手摸向腰间的收尸牌，指腹却碰到一块冰冷的硬物。

那不是他的牌。

陆昭把东西取出，发现是一册巴掌大的黑皮薄簿。簿面没有字，四角缝着细铜线，像被火烤过又浸入水中。它沉得不合常理，只有两层纸，却比一块同样大小的铁片更压手。黑簿没有锁，第一页贴在封底，翻不开。

陆昭记得自己出门前并未带它。他先把薄簿放在地上，用木尺推开，观察它是否会自行翻动。没有。许青棠问那是什么，他回答“不明物”，要求她不要靠近。她没有争，只问是否需要封存。

“等尸体登记完。”

“你把一册来路不明的东西放在尸体旁？”

“它自己来的，先看它要什么。”

门内又响了一声。

这次像指甲刮过木板。

陆昭让韩六退到驿厅，自己从门缝塞入一根细竹。竹尖触到某种柔软物，立刻被咬住。竹竿没有被折断，门缝里却渗出一线黑水。黑水落在雪上，冒起很细的白气。

许青棠射出一支短箭。箭没有穿门，而是钉在门栓旁的木板上，箭尾缠着银线。银线绷直，拽动门栓，让门缝扩大一指。陆昭看见里面堆着粮袋，粮袋后有一头白额狼，额上白毛像被刀劈开，双眼却没有兽光，只有两枚灰白的圆斑。

狼的嘴里叼着一枚铜牌。

铜牌上刻着北镇镇诡司的旧徽，边缘沾着血。

它没有扑出来，而是把铜牌放到地上，向后退了一步。

陆昭注意到狼的前爪被铁丝勒过，皮毛里嵌着粮袋麻纤维。它的右后腿有旧伤，落地时第三趾拖着地，正好能造成门外那串浅三趾印。它不是从冰面无痕走来，而是有人用木套遮过脚印，再把狼赶到门口。

“狼不是凶手。”陆昭说。

许青棠问：“你怎么知道？”

“它在送证物。”

狼听不懂这句话，却盯着地上的黑簿。

陆昭把黑簿拿起来。狼的灰白眼斑微微收缩，门内的粮袋同时倒下一层，露出后面一具蜷缩的尸体。尸体穿着巡河士卒的皮甲，胸口没有刀口，喉咙却被黑色细线缠住。细线与门外麻绳不同，像被水泡软的头发。

陆昭没有进仓。他让许青棠先从门缝观察尸体姿势，再让韩六把巡河名册拿来。名册上昨夜轮值有四人，三人已经回营，第四人名叫陈砾，栏中盖着“归队”印，却没有归队时辰。

黑簿在陆昭手中忽然发热。

第一页自行翻开，纸上浮出一行黑字：

“陈砾，未结之功：把被调换的军粮送到真正领粮的人手中。”

字迹下面有四个空格，像在等待证据。陆昭刚看完，胸口便传来一阵尖锐的寒意，仿佛有人把冰片塞进他的肋骨。他松开手，黑簿却没有掉下去。

许青棠看见他脸色变化：“那东西在取你的气？”

“不是取。”陆昭咬紧牙，“像在问我愿不愿接。”

“你可以不接。”

黑簿上的字迹开始变淡，陈砾的名字只剩一半。陆昭看见粮袋后的尸体，想起三具被刮净姓名的无名尸。如果今晚没人替陈砾把军粮送到真正的领粮人手里，明日北镇的炭和药就会少一半。少一半不是传闻，是一批尸体。

他把黑簿压在门槛上，先取出两类证据：第一，副印封条上的黑砂与粮袋底部同色但颗粒不同；第二，巡河名册上的“归队”印晚于换岗时间一刻；第三，死者右掌有粮秤绳压痕，说明他在查验粮袋时被人从后勒住。证据已经超过两类，却没有陈砾的同伴确认。

陆昭问许青棠是否愿意作为伤情见证。她说愿意确认伤口、绳痕与时间，不替陈砾认领动机。韩六也愿意确认粮仓封条，却不愿确认谁是“真正领粮的人”。两个人的选择被黑簿吸进去，纸上出现两道细线。

陆昭把门缝扩大，白额狼立刻咬住黑线，往后拖。线的另一端连着粮袋底部一只暗袋。暗袋里有一张被水浸过的军粮分配单，原本写着北镇军需处，墨迹被刮掉一半，下面露出三个民户的现用称谓。

“先送给这三户。”陆昭说。

许青棠看清称谓后，脸色变了。那是她昨日在医棚登记过的三名伤兵家属，他们已经三天没有领到粮。

陆昭将分配单、粮袋底灰、陈砾掌中绳痕和名册印时分别封存。黑簿上的四个空格填上三项，第四格仍空着。最后一项不是证物，是接收者本人是否愿意承认这批粮属于自己。

许青棠咬牙：“我去找他们。”

“不能逼他们按单领粮。”

“那就让他们自己决定。”

门内的白额狼低下头，额上的白毛渗出一滴黑水。陆昭第一次明白，这本簿子并不奖励他杀掉什么。它要他把一件死者未完成的事，送到活人愿意承担的位置。

而驿站外，镇门铜铃忽然响了第四次。

黑水河上的雪，开始往天上飘。

许青棠站在门内，看见逆飘的雪只在粮仓一侧升起，驿厅屋檐下仍按原方向落雪。她用箭尾在地上画出界线，提醒陆昭不要把异象范围扩大成整座驿站的诡域。陆昭点头，先让韩六拿一只空木桶放在界线上。木桶没有移动，桶里落入的雪却向上旋了一圈，说明空气流动异常，尚不能证明白额狼本身就是灾诡源头。

狼听见铜铃后没有朝门外看。它盯着陆昭胸前的黑簿，喉咙里发出细微的摩擦声。陆昭把黑簿暂时交给许青棠，自己去检查陈砾尸体的勒痕。黑簿落入许青棠手中后，第一页的字立刻暗了，功簿没有因为换了持有者就替她结算。她把簿子放在桌上，确认它更像一种责任登记，而不是可以抢走的兵器。

粮仓里的尸体被拖出一尺后，陈砾的右手露出一枚断掉的指环。指环内侧刻着一个被磨平的仓号，只有“九”字的半笔还在。陆昭把指环与粮袋封绳分袋，不用仓号半笔认定死者曾在哪一排值守。许青棠记录尸体喉部细线进入角度，确认勒痕由后向前收紧，但不认领是谁站在身后。

韩六看着那张写有三户称谓的分配单，终于承认自己昨夜曾被人要求盖副印。他没有看见对方的脸，只记得对方说“这是镇尉急令”。陆昭问他为何不写进驿站日志，韩六说怕丢掉这份差事。这个动机可以解释隐瞒，却不能证明他参与杀人。陆昭让他把“被要求盖印”单独写成本人陈述，另把没看见脸、没确认急令来源写入未答栏。

韩六的陈述写完，三人又回到粮袋旁。被刮的分配单上有三个民户称谓，却没有发粮日期，右下角一枚手印被水泡成两层。许青棠从昨夜医棚簿中找出三户领药时辰，能证明人确在镇内，不能证明他们在军粮出仓时已被列为接收者。陆昭把分配单放在灯下斜照，发现被刮掉的“北镇军需处”墨线压在新称谓下面；这是可复验的书写先后，却仍不知谁持笔。他请韩六和记功吏各看一次，二人只在“见压痕”栏署名，拒绝在“知改写人”栏按印。

陈砾的巡河同伴后来隔门送来一份值夜口供。他记得陈砾曾问过三户的炭粮为何迟发，却没听陈砾说要亲自运粮。陆昭把这份口供与黑簿文字并排，第一次看见异常簿页与活人口述之间的缺口。簿上写“送到真正领粮的人手中”，同伴只证明有人发过问；若他把问话写成遗愿，第一步便会被自己的愿望污染。他请对方第二日当面复述，今夜先记“口供待核”。

许青棠还要求检查白额狼背上三根短针的入肉方向。她只能隔着门缝看见针尾高低不一，狼每次呼吸都会牵动皮肉，强行拔针可能让活体证物死在现场。陆昭准她先以药布遮住狼的眼，再在门外留一条不落字的通路。若狼扑人，他们能关门；若狼只是递送铜牌，便能保住其动作本身。两人都没有把诡物的配合写成同意，它尚不能像三户家属那样作出可以理解的选择。

黑簿上的四个空格仍缺最后一格。陆昭没有急着把陈砾写成有功之人，只把当前证据、接收者选择和未确认的来使分开。窗外逆雪渐低，白额狼将铜牌拱到他脚边，牌背那道斜线里渗出一粒新的黑砂。陆昭取出镊子夹起，放进物证袋，袋外写下“铜牌接触后出现，来源待核”。
