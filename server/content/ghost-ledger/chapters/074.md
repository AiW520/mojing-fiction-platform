# 第七十四章 贺停舟守城

北镇的第一场雪在第72章三镇分功回批后的第二日落下。

他坐在外仓门房里，用木杖压住一张被风吹卷的城防图。图上四处标着守、医、证、粮，正是北线无旗黑墙留下的四个空缺职位栏。黑墙已经消失，墙根却留着一层硬灰，雨雪冲不掉。巡骑想把灰扫进袋中送皇城，贺停舟要求先问扫灰的人愿意承接什么。两名巡骑只承接出现位置和扫取时刻，不承接黑墙来处，也不承接它曾经挡过谁。

卫岑先行回到北镇时，带着一队没有完整军籍的流民；陆昭仍随第四镇记录队留在南汊村，没有与卫岑同行。十二人中三人有北镇旧路条，四人只记得自己从第三镇沿河上来，剩下五人说不出镇名。卫岑愿意承接领队见闻和城门时刻，拒绝替十二人确认姓名。贺停舟没有把他们全部关在城外，也没有直接开城。他将人分成伤情、粮食、证物和本人选择四栏，由北镇药吏、北镇粮吏、北镇文吏和两名自愿见证者分别接手；阮遐仍在第二镇药房，顾衡仍在核对跨镇粮账。

第一名流民脚底有新裂口，愿意接受清洗和包扎，不愿把自己的旧路条交给官署。北镇药吏只记录伤势和药量，允许路条由本人贴身保管。第二名流民带着一枚湿铜扣，称是在第三镇河滩拾到，却不愿说明拾取者是否已经死亡。文吏给铜扣单独封袋，接收人写明“拾得物来源未证”。其余十人有的同意登记临时称呼，有的拒绝登记，没人因拒绝被写成奸细或失名者。

贺停舟把城门开启拆成三步。第一步由卫岑承接门外秩序，第二步由北镇药吏承接伤者进入后的药房路线，第三步由北镇粮吏承接一日粮发放；北镇文吏只在三项签字齐全后盖“临时入城”印。原印仍由卫岑保管，四枚会签铜牌分柜，任何一块缺失都不能改成永久户籍或军籍。门内百姓抱怨流程太慢，贺停舟让他们选择是否愿意替某一栏作见证，没有要求所有人一起盖印。

一名守门老卒提出用自己的旧军籍替三名流民担保，理由是他们看起来不像带诡之人。贺停舟没有接受这份好意，也没有斥责老卒。他让老卒选择是否只承接见过其中一人的时刻和衣着，老卒同意；三名流民仍须各自决定是否登记临时称呼和伤情。担保人只能证明自己看见过什么，不能把陌生人的身份和清白一并领走。

午时，城北旧墙外传来三次空铃。铃声比北镇旧门铜铃低半音，却没有人在墙外看见铃。巡骑提出派人追声，贺停舟先问追踪者愿意承接什么。四人中两人愿意承接到达墙根和撤回路线，一人只愿承接铃声时刻，最后一人拒绝进入雪沟。贺停舟批准前三人的有限行动，拒绝把第四人的沉默写成阻碍。追踪队沿不同路线出发，不共享未经本人同意的见闻。

雪沟里找到一段白蜡木车轮擦痕和两粒干黑砂。车轮擦痕与第64章北线车队只在宽度上相近，木纹断屑不同；黑砂与第四镇户籍柜黑砂颜色相似，却没有同样的纸纤维。文吏分别封存，贺停舟在地图上标注“到达时间不明、接触者不明”。卫岑认为可以借此判断无旗黑墙曾向北移动，贺停舟只允许把它列为路线假设，不允许改写成妖关回城。

傍晚，城内粮仓收到功簿院的一日基础粮。北镇粮吏按袋称重，发现两袋少了半升，正是第72章第二镇补粮时出现过的损耗数。押运人说雪路颠簸造成散漏，愿意承接押运过程，不愿承接两镇粮损是否同一来源。贺停舟让他把散漏的麻绳、封泥和车板刮痕分别封存，既不把少粮算作妖物偷取，也不把解释写成押运人的过错定案。北镇先按足额标准发粮，短缺另记待补。

夜里，三名无军籍流民中的一人敲响守城鼓。他说自己想起曾在第二镇井边见过一只没有脚印的木箱，但只记得箱子的颜色，不记得谁搬过。卫岑希望立即把他列为风灾证人，贺停舟让他先选择是否接受问询。那人愿意说颜色、位置和自己离开的时刻，不愿提供同伴姓名，也不愿把木箱同无名尸联系起来。文吏按本人限制做了三份拓录，原话、推测和拒答各占一栏。

同一夜，北镇三钥柜的第一把钥匙出现细小锈斑。锁芯没有被撬，柜门也未开。贺停舟没有为了证明安全而强行开柜。他让持第二、第三把钥匙的文吏和复核署留守人到场，先拍下锈斑、擦拭工具和钥匙接触顺序。三人都承接保管和复测，不承接黑簿原册是否被妖物窥视。原册仍在柜中，是否需要转运，留待第二日按本人授权与皇城回批决定。

卫岑在门房问贺停舟，若无旗黑墙再次出现，城门是否继续坚持四项会签。贺停舟说会签不能阻止灾诡，只能阻止一个人把全城的责任写进自己的手里。他把守门图分成外墙、内门、粮仓、证物房和撤离坡五条线，每条线各有主责、备责和拒绝条件。若主责受伤，备责只能接现场动作，不自动接收原主全部功劳和旧案。

这句话刚说完，城北雪地出现一条没有脚印的拖痕。拖痕从墙根延伸到半里外的旧驿路，尽头压着一块没有字的白木片。木片上有四个浅槽，长度分别接近守、医、证、粮四字，却没有刻刀起落痕。巡骑想将白木片钉在城门示警，贺停舟拒绝。他让愿意承接的人先把木片放入证物袋，由两名不相同职责的见证者共同封存。

天将亮时，北镇临时入城的十二人已有三人自愿离开，五人选择留城治伤，两人撤回临时称呼，另两人只承接粮食领取。城门没有因此恢复永久登记。贺停舟把人数、伤情、粮耗、铜扣和白木片分成五份回传给许青棠的复核署，同时注明自己留守的责任边界：守门，不认名；保柜，不定功；发粮，记实耗；遇诡，先封线再请见证。

回传封签合上时，北镇旧墙外又响了一声空铃。贺停舟没有追出去。他让卫岑记录铃声，让北镇药吏准备药，让北镇粮吏核对粮袋，让文吏守住证物房，自己在地图上补了一条撤离线。城仍然有主，却没有一个人被允许独自替全城承接未结之功。

清点守城人时，卫岑发现一名年轻巡骑的左耳被空铃震出血丝。巡骑愿意接受北镇药吏的耳道检查，不愿把铃声解释成妖物命令；药吏只记录出血位置、持续时刻和药量。贺停舟让他暂时离开北墙，交出一项外巡动作，却保留他对先前守门见闻的签名。替换他的人只能承接接班后的守线，不能把他的旧见闻顺手改成新的结论。

两名留城流民在粮仓外发生争执，一人说另一人偷拿了少半升粮，另一人拿出封袋证明自己只领到应得份额。北镇粮吏没有按吵架声先罚人，而是称量剩余粮、检查封泥和记录领用时刻。少粮仍有三种可能：押运散漏、仓内分装或重复领用。三种可能分别列入待核，不因争执激烈就选最顺耳的一项。贺停舟把这件小事写入守城回传，提醒皇城责任拆分必须能落到一袋粮上。

贺停舟守城时，先将门、粮、撤民和三钥柜分成四支队伍。守门人只承接横梁偏移和火油，粮吏只承接袋重和发放，撤民队只承接路线与伤者，三钥柜仍由三人分别守。旧功副页送来后，贺停舟拒绝把自己的城防动作接成三名死者的未竟之事。陆昭在城外复读封签，左手麻意加重便退到白线外，由别人完成第二次核对。

日出后，白木片外封套出现一滴水。封套内层干燥，四个浅槽没有新增刻痕。文吏请示是否将木片转送许青棠复核署，贺停舟先征得两名见证者和持柜人的同意，确认转运只改变保管地点，不改变证物归属和拒绝解释的权利。转运单写明雪路、押送人数和预计抵达时刻，若途中封套受损则原样退回，不得补刻缺字。

押送白木片的车在北墙下等了两刻钟，等的不是院印，而是另一路药车先出门。年轻巡骑耳伤未愈，听见轮声便误以为墙外空铃又响。他扶墙站稳，药吏复查耳道，确认血丝没有加重，仍让他继续停巡。贺停舟没有把他的误听从昨夜见闻里抹掉，只在今日轮值栏注明不能以他一人判断铃声次数。替班者也未因此获得替他补签昨日口供的权利。旧墙上薄雪被车轮震落，守门人量了落雪位置，发现封套那滴水可能是车棚檐角融雪，便把檐水单独取样。

许青棠的回函要求在拆封前称外套和内袋两次重量，若外套变湿而内袋仍干，就不必为了找四字而立刻刮开木槽。贺停舟照做，将新旧重量写在转运单背面，并把送行的火油、车夫半日工钱列入北镇支出。卫岑问这笔账谁还，贺停舟说守城人既决定护送证物，就不能把路上的损耗推给一块没有字的木片。城外仍有铃声，城内至少知道自己为这次选择付了什么。
