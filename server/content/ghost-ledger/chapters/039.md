# 第三十九章 许青棠的弟弟

天亮前，灰布尸体被移进石棚。移尸不是为了认领，而是为了避免雪把鞋底和布结盖住。陆昭先让罗衍测量尸体到三条路口的距离，再让许青棠复核右肩。她报出牵痛仍在，指尖没有麻木，选择用左手持药钳，不接触重木板。

灰布下的人约二十余岁，身高比许青棠矮半掌。颈部没有明显勒痕，右腕有细窄磨伤，像长期被药囊带子压过。左前臂旧骨折已经长合，折痕靠近桡骨中段；骨折线旁有三道针孔，排列并不齐整。许青棠说这是多次注射或缝合留下的可能痕迹，不能凭一处伤认出谁。

她没有先看脸。她把竹牌、药囊、灰布和尸体手腕分成四组，要求秦衡把“青”字竹牌只写为物证编号。秦衡问是否可以在副封标题加上“许青岚”，她回答：“我能认出弟弟的字形习惯，也能记得他左腕旧伤，但记忆不是死者本人，也不是第三方签认。”秦衡点头，将她的拒绝和肩伤一并记下。

陆昭让罗衍去第三烽台找军医旧册，自己守着尸体不让推尸人影靠近。那影子仍站在乱石外，没有脚印。贺停舟问它是否愿意报姓名，影子抬手指向灰布尸体胸口，随后放下。陆昭把动作写成“指向未获解释”，不把它当作送尸口供。

石棚内的旧守台卒在半醒间咳出一句“青牌不是祭牌”。许青棠立刻转身，问他是否看清过持牌的人。守台卒只说“医署转运，三道封口”，便又昏沉。许青棠检查他的意识，确认这句话缺少时辰、地点和本人见闻，不能代替军医册，也不能证明灰布尸体就是弟弟。

罗衍带回一册被雪水浸过的军医领用簿。簿页中间有一行“青岚，左臂旧折，领止血散二包，针三枚”，日期是七日前，领用人栏只盖了医署半印，没有手押。紧邻一行写着“转第三台，随军令封口”，墨色比前一行新。陆昭让罗衍把两行分开拓录，不能把半印和新墨合成一次领用。

许青棠先看日期，再看笔画。她说“青岚”二字确像弟弟常写的急笔，左臂旧折也相合，可她不接受这两项作为身份结论。她要求找出簿册的保管人和领药的见证人。罗衍说簿册由医佐孙砚交给守台卒，孙砚现在在第三台下的废哨屋里，伤了脚，尚能说话。

孙砚被抬进石棚时，右脚裹着灰布，脚背有冻裂。他先报伤情，再说自己只负责发药，不负责验尸。许青棠问他是否见过许青岚，孙砚回答七日前见过一个自称青岚的军医，左臂旧折，领了止血散和三枚军医针；他没有验过户籍，也没有看见此人离开第三台。这个回答是活人口供，却仍缺乏尸体与本人选择的连接。

陆昭让孙砚看竹牌。孙砚没有伸手，只隔着木板辨认刻法，说医署青牌一共三十六枚，字由工匠刻，不能凭一个“青”字确认持有人。他补充，青牌背面本应有药库小孔，竹牌上只有一孔半，像被人削去一段。许青棠听完，选择把竹牌交给药库复核，不把孙砚的话写成弟弟身份。

尸体右腕磨伤里有一粒白色药蜡。许青棠取样后发现药蜡含止血散的苦味，但药蜡也可能沾自医棚绷带。她从军医簿中取一小角旧封蜡作对照，颜色相近，硬度不同。陆昭让她在两份封签上分别注明“可能接触”，不许写“同源”。

罗衍又取回第三台脚下的木桩拓样。木桩上有三道浅划，间距与灰布尸体腕带扣痕相近，却有雪水冲刷的方向差。贺停舟说这种划痕也可能是搬运木板留下，不能替尸体指出谁绑过他。陆昭把木桩、腕带、药蜡和军医簿分柜封存，给每柜写上独立时刻。

许青棠走到灰布尸体前，终于掀开半边脸。尸体左眉尾有一处旧疤，形状像被箭羽擦过。她脸色发白，却没有触碰尸体，只说弟弟十三岁时在校场摔伤过眉尾，伤口位置相同。她随即补充：“相同位置不是同一张脸的证明，先做面部拓样。”

孙砚看见拓样后摇头，说自己见过的青岚也有这处疤，但当时只在灯下看了一眼。两个独立来源分别是军医簿与活人口供，面部旧疤和前臂旧折形成身体证据；它们足以把尸体身份收窄到许青岚，却仍没有弟弟本人或家属以外的完整确认链。许青棠选择不在军籍栏签名，只在“亲属辨认意见”处写“高度相符，待第三方复核”。

陆昭问她是否愿意接收尸体身份带来的追查责任。许青棠沉默许久，回答愿意承担伤情复核和运回医署的责任，但不接收功劳，不替弟弟选择未竟之事，也不允许任何人用她的签名把尸体写成活祭名单上的“已交”。这份选择由她本人按下手印，秦衡作为文书见证，不扩大为军令接收。

黑簿在陆昭掌下微微发冷，浮出一句：“姓名可核，未竟未明。”随后字迹沉下去。陆昭知道功簿已经承认身份线索进入可查范围，却没有承认死者未竟之事。两类证据只能把人从无名推到许青岚，不能替他完成最后一件事。

石棚外，推尸人影往后退了三步，雪面依旧没有痕迹。它留下的灰布边角被风吹开，露出一枚细小铜片。铜片上刻着“活”字的一半，背面却有军医署的旧药库编号。许青棠没有伸手，陆昭让罗衍先隔袋取走，标作新证物，不把半字解释成活祭。

第三座烽台传来长鸣，紧接着是一声像人咽住的短响。孙砚说第三台旧册里曾有“活祭”两字，但那是军医署对一类押运任务的旧称，不一定指献祭。许青棠立即要求把旧册原件带回，不许只凭孙砚的解释结案。陆昭看着铜片半字，明白弟弟的死或许不是被送上祭台，而是被某种制度把活人与死者一起抹掉了名字。

陆昭让孙砚把旧册中涉及七日前的页码逐页指出。孙砚的手停在第三页和第七页之间，说明第六页曾被撕走，撕口上留着半滴青色药汁。许青棠用药钳取下药汁结痂，与尸体药瓶残粉分开封存；二者颜色相近，气味却一个偏苦、一个带薄荷，不能据此补回缺页内容。秦衡记录缺页存在，却承认功簿院没有权限要求医署当场交出原册。

罗衍检查第三台送来的木箱，发现箱底有两道新刮痕，方向与灰布尸体鞋尖相反。木箱轮距不足三尺，不能与白蜡轮车或第二座烽台尸体的搬运痕直接相连。陆昭把刮痕、木屑和尸体鞋底砂粒各取一份，要求交接人写明“同场可能，路线未证”。这些琐碎边界若不先钉死，任何一个“青”字都可能被人改成通向许青岚的唯一答案。

他在交接册上写下新责任：守住尸体、复核身份、查明“活祭”词源，期间不得让西关军需处接走原件。贺停舟承担退路，罗衍承担木桩和药库编号复核，秦衡承担副封文书。许青棠把右肩牵痛再报一次，选择留在石棚等第三台旧册，不把弟弟的名字写进任何接收栏。

许青棠还要求把复核时辰写在尸袋外层，防止夜里换袋后再以亲属记忆补齐缺失过程。

许青棠看见灰布尸体眉疤时没有立刻认名。她先让第三方医官复核牙列，再把自己记忆中的童年伤痕写在“亲属见闻”栏。孙砚补充他见过许青岚领药，却没见过其最后去向。两份信息相互支持身份候选，却没有替死者指出未竟之事。陆昭因此把“弟弟”二字写成候选称谓，等许青棠明确选择，不让亲情自动变成结算。

黑簿没有翻页。灰布尸体的身份已经近在眼前，未竟之事却被“活祭”二字挡住。雪谷深处有活人的脚步声传来，这一次，脚印没有被风抹掉。

脚步声靠近石棚时，陆昭让巡骑停在门外，先把声音方向和鞋底宽度记入巡查单，不许据此喊出人名。来人只在棚角留下一个空药袋和未盖印的取药单，转身便走；巡骑没有追上，也没看见脸。许青棠先问药袋是否接触过灰布尸体，得到“不知道”后，要求将它放在另一张木案上。鞋底拓影有三枚细钉，与尸体鞋底缺钉的方向不同，只能排除一小段路线，不能替任何人认名。

第三台木箱的刮痕经过侧光复看，深浅分成两层。锁匠说先有旧划，后有新擦，但不能判断哪一层对应哪次搬运。陆昭要求箱子保持原角度，由两名不知前次结论的工匠重新看。两人一人认为是木钩，一人认为是冻石，均同意留下反证。许青棠把右肩牵痛写进每次抬臂角度，不因弟弟的候选身份靠近就减少复测。她说，亲属更需要一份能被别人重做的记录，而不是一句安慰。

孙砚在门外补充，他曾看见有人把甲三药瓶放回木箱，却只记得袖口有灰，不记得那人的脸。记录吏让他分别承接“看见木箱”和“袖口有灰”，不让两项拼成一个人的身份。药瓶蜡封取下后，瓶口残粉与军医簿上的药名相合，却没有证明它属于灰布尸体。许青棠把弟弟身份候选写在独立页，陆昭只复读封签号，听骨仍未使用。
