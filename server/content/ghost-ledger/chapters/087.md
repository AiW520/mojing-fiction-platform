# 第八十七章 黑册不是天命

回到北镇的第二日，秦衡把十年前的补库登记、戚望三联副本和一张空白黑皮纸铺在验物厅里。黑皮纸并非从那名失踪库吏手中寻得，而是旧档库中另一册抄本的封里残页。纸色深，边缘有四个针孔，乍看与陆昭的黑簿相似，却不能因此说它们同源。

陆昭被准许坐在白线之外听取编号，不许看残页正面。他的停职令仍在，三钥柜仍由贺停舟的人分守。贺停舟把权限说得很清楚：“这次查的是库纸，不是黑簿。谁若以为找着相似黑纸就能开柜，我先撤谁的钥匙。”

鉴纸师先盲检，不看来源标签。黑皮残页含桑皮纤维，针孔间距二寸四；功簿院现存空账用麻纸，针孔间距二寸一；戚望随尸联则是竹纸，孔位不成直线。三者只有颜色接近。残页上的黑不是染料渗透，而是纸背涂过一层薄炭胶，刮去后仍有浅灰。黑簿的外页不在场，没人能把这一项结果外推到陆昭那册上。

司空烬拿出功簿院早年的制式册。册上记着三种用途：黑底是夜运尸册，便于雪夜辨认；空格是未核实项，不是待填功劳；红线只用于封存，不表示血祭。后来的统一抄本删掉了“夜运”两字，只留下“黑册”。这解释了一个词如何被制度改写，却解释不了眼前那些会褪字的门槛和湿痕。

秦衡把残页背面的针孔对着一张旧木架拓片。四孔能套住架子的两个横档，但横档距差了一寸。锁匠复测木架已经受潮变形，若照它反推原尺寸，会把孔距误差放大。鉴纸师遂用尚未弯曲的库内夹板比对，残页只能套上其中一档，不能整页固定。它更像临时封皮或隔页，不像一册账的内页。

陆昭听到“夜运尸册”，想起黑水驿那册按日记载收尸车进出的小本。他问秦衡，当年的黑册是否会记未竟之事。秦衡翻出目录，只有死者来源、停放位置、交接时刻、见证人和后续去向五项，连“功”字都没有。若有人后来在这种夜运册上添了未结之功，至少要找到增栏、添写人和改制令，不能凭名称推断。

司空烬并不回避制度责任。他承认功簿院曾把旧式夜运册改成统一总表，理由是战时纸粮紧缺、驿骑不足，集中记录能少漏掉尸体。那项改革救过一条边城防线，也让地方只剩抄报，没有原件。如今他仍认为院中复核能防止私刑和假功，但不再把“院里留存”说成“地方已经同意”。

“你会不会撤销旧制？”陆昭问。

“不能今天就撤。”司空烬答，“撤了，正在执行的粮令、伤员转送和死者复核都会断。可继续让地方只交总表，也会让每次遗漏都找不到源头。下一步要看三联能不能在现行九镇里重做，不是拿一张旧纸直接宣布天下制度有罪。”

他说得有理，也留下了实际代价：旧档库要抽两名鉴纸师、三名驿骑和一日药粮去追失踪库吏的借阅链；第二镇八名未归者搜寻不能因此停。顾衡坚持搜寻粮照拨，司空烬签下调拨令，把费用记到院方旧制复核项，不计入九镇救灾功劳。

查到午后，秦衡找到一册未入总档的封存簿。它记录十年前那名前任库吏借走戚望转抄纸时，另领了三张空白接收联，归还时只交回两张。第三张没有姓名、镇名或印记，不能证明他拿去造了黑簿，却足以说明那一段借阅链不完整。

秦衡要求封存簿原件留在北镇，功簿院只取编号副本。司空烬原本可用掌院印令强制调阅，最后只签了三日共同保管书：北镇守柜，院方复核，第三镇文吏每天核对封签。双方都得为多一层手续付出人手，却没有哪一方能独占结论。

封存簿一动，库房西墙的灰缝里掉出一小片纸。它不是黑色，而是被炭烟熏黄的普通竹纸，上面有半个“见”字和一段倒写的日期。字迹比戚望的旧联晚至少十年，日期却早于合并令。鉴纸师推测有人曾用旧联临摹，写错后塞入墙缝；也可能只是修库时留下的记事。没有笔压拓片、修葺簿和当年经手人证词，无法判定。

陆昭请记录吏把“黑册不是天命”写作本章标题，而不是审定结论。眼下能确认的，是黑底夜运册曾先于功簿院制度存在，空格原指未核实，三联原来分散保管；不能确认黑簿从何而来，不能确认所有异象由统一总表造成，也不能认定库吏就是幕后人。

傍晚，北门传来急报：那辆昨夜向下游走的平板车在冰滩搁浅，车上没人，车板夹着一块断裂木片。木片一面有旧棚三槽的倒印，另一面留着新刀痕。卫岑没有去追插牌者，而先按轮距、木纹和刀痕分样。三槽印迹让旧棚调查有了可复核的新物证，却仍不能证明木片来自戚望三联，更不能把无主之功塞进任何人的名字。

陆昭在外仓重新分配夜守名单，把会读旧册的人留在档库，把能识别轮距的人交给卫岑，把粮药签领和三钥柜分别交由不同的人。每一项都有人愿意承担，也有人拒绝额外职责。司空烬没有替他们签名，只在院方一栏承诺三日内补足少掉的驿骑和药粮。

为了避免新的空栏被后人误当成拒绝或默许，秦衡将当日能查到的五种状态另列在目录背页：已交接、暂存待核、本人拒领、送达未签、原件未见。每个状态都要写明记录者、时间和证物位置；若本人不愿留姓名，只记其自选的编号和可供复查的见证人。抄录员先写了一行“库吏拒交第三联”，陆昭请他指出是谁在场、何时开口。屋里没人能作证，这句话便被划为未经证实的叙述，旁边保留原字并记下删改人。拒绝补写，不等于承认隐藏。

鉴纸师又从封存簿封底取下极小的一条纤维，先拍摄两面断口，再与残页边缘在盲码下比照。断口走向不同，纤维长度也不相合；两者可能出自同一批桑皮纸，也可能只是同地常见纸料。她将比照结论封入独立纸袋，不让一张相似样本被抄进“同册”栏。另一名文吏逐字核对旧总表，确认“夜运”确在后抄本被删，却找不到删改命令或批校人的名字。制度沿革因此多了一项可以继续追查的缺档，不多出一个可以归罪的人。

秦衡把借阅链拆成领出、携行、归还和归档四段，逐段写明当前凭据。领出有印记，携行只有同伴口述，归还有两张副联，归档日期缺了一格。司空烬要求把缺格标为“未查”，不是“被撕”；贺停舟则要求这份目录留在北镇，院方只拿编号副本。双方各自签下领取副本的时间，交接人当场核了页数。多一道手续使鉴纸结果晚了半日，却没有把未查的部分交给最有权力的一方自行填满。

卫岑带回的木片也依此办理。旧棚三槽倒印先由锁匠测量宽度和间距，刀痕另用侧光拓影，轮迹由巡骑记录车板宽度；三项材料各自封样，木片暂不拼回任何一块旧架。路边工匠愿意说明自家常用的三槽车架，但不愿将姓名写入功簿候选册，只同意让两名邻人见证其陈述。秦衡照录范围，不把一次口述扩大成全城木匠的共同证词。

天黑前，第三镇文吏送来一张接收回执，证明北镇寄出的两份编号抄件抵达，但不证明对方认可内容。顾衡逐袋核过随行药粮，实际少了一包止血布，车夫承认途中拆包为一名冻伤老人包脚，却没有领取人签字。账册把它记作救急耗用并由车夫承责补购，既不向老人追偿，也不把缺物解释成门槛异象。眼前这些细小区分不能让案件骤然明朗，却使下一次追问有可复核的起点。

黑皮残页经盲检为桑皮纤维、背涂薄炭胶，孔距与功簿院空账、戚望随尸联都不同。十年前借阅簿只证明有人领过三张空白联、归还两张，第三联去向未明；没有见证的拒交不能写成盗取。陆昭把目录分为暂存待核、本人拒领、送达未签和原件未见，拒绝把空栏当成同一事实。黑册可以被人利用，却不是天命，也没有替陆昭指出源头。

这不是升级，也没有新技艺。陆昭得到的只是一个更稳的判断：功簿不该因为黑色封皮便被当作天命，旧制度也不该因曾经有效就免于复核。三张联里缺失的那一张，可能改变他们对旧案的理解；在它回来之前，任何人都不能宣布天下已有人替天下接功。

黑皮残页的背涂在暖炉旁出现细小起泡，鉴纸师立即把它移到冷台。起泡位置与孔距没有重合，可能是炭胶受热，也可能是旧水汽留下的层裂。陆昭没有把起泡解释成黑簿曾被火烧，先让两名工匠用同批桑皮做空白试验。试验只证明暖炉能让薄炭胶鼓起，不能证明残页曾在同一炉旁。空白试片和残页分柜，取样耗用的纸胶由院方补足。

第三镇回执里还夹着一段断麻，长不过半指。水卒说它从缆桩上取下，车夫说可能是药包捆绳。两人都愿意承接各自看见的地点，不愿承接麻线与黑册残页同源。许青棠要求先比纤维方向和盐分，再查断口是否被刀切；秦衡把麻线列入“待核材料”而非“源头证物”。陆昭复读编号时主动把残页交给另一名文吏，避免左手失痛下误将纸孔和麻结写成一回事。
