# 第五十九章 贺停舟交印

独立油车的油面在卯时降到最后一道刻线。封诡阵没有再添白线，旧井却每隔半刻传来一声闷响。守阵卒把响声记作“井内回声”，不写成阵妖呼叫；外仓二十七户已搬了十六户，剩下的人分别选择留下牲口、等待亲属或只领柴炭。每一项都有人按印，没人因住在阵外就被写入功劳名单。

贺停舟把自己的旧印放在桌上。印柄上的铜环磨掉一圈，印面仍能压出北镇城防四字。秦衡把交印申请摊开，第一栏写“暂交阵法供油和封线调度”，第二栏写“保留城防判断”，第三栏写“不得代三户、曹弥或任何无名尸作功劳选择”。司空烬看完，要求把保留城防判断改成具体人员和时限，否则交印只是一句不能执行的愿望。

“卫岑负责西关兵调，贺七只见证外仓出入人数，罗衍负责阵铃记录。”贺停舟说，“撤民指挥仍由北镇城防执令。我只保留各方意见冲突时的封门裁量，时限到日落。日落之后，若没有新的本人选择，裁量自动退回三方会签。”

司空烬没有立刻盖院印。他问贺停舟，既然旧印曾让错误功单进入阵眼，为什么还要把印交给别人使用。贺停舟看着自己的残腿：“因为印不是罪，也不是功。罪在没人问空栏是谁的，功在有人把空栏写成大家都同意。把印藏起来，阵也不会自己停。”

许青棠要求先检查交印申请与阵眼副页的物理距离。交印纸若靠近铜牌，纸背可能再次出现白线；她让秦衡把申请放在三尺外的无字台，等封印后再由两名无涉案人搬运。院吏觉得程序过多，许青棠指向上一夜的黑线：“多一步见证，总比少一个被代记的人好。”

贺停舟按下自己的主印，印泥没有沿白线扩散。卫岑在西关职责栏签字，贺七在外仓人数见证栏按指，罗衍在时序栏落笔。四处印记彼此留有距离，未形成一个可被阵眼认作共同接收的印面。司空烬最后才在院方见证栏盖印，注明仅见证交接，不取得北镇黑簿原件、户牌选择或定功权。

交印完成的一刻，旧功副页的“已接”两字暗了半寸，井内闷响却变成两声。阵匠拆开第二层油管，发现旧印交接并未修复供油回路，只把阵眼从一枚印的责任关系分成四个小栏。顾衡报出油耗下降，但外仓仍需柴炭；交印改变了权限链，没有让风险凭空减少。

就在此时，一名留守住户冲到阵边，称自家牛棚里有人敲门。贺七要开门查看，许青棠先让他说明是否愿意承担开门后验伤和重新封线。住户本人只同意让医官看牛棚，不同意把“有人敲门”写成失踪村民回返，也不接受任何功劳结果。医官隔门检查，发现是冻裂木梁撞击，不是人手。事实被排除，住户的选择仍原样保存。

陆昭在白线外听见这段问答，低头看自己的左掌。失痛没有消退，他仍不能碰封功刀。贺停舟主动让他核对交印编号，陆昭把“北镇城防”读成“北镇城门”，及时停口，由罗衍复诵。交印之后，陆昭的错认并未被当作旧印交出的代价，仍按伤情风险记录。

司空烬提出把交印申请送入功簿院总档，作为地方主动放弃部分权限的先例。贺停舟同意送编号副本，却要求原件留北镇双钥柜；司空烬接受，并在副本边注明“原件未移交”。这一步让掌院得到可以向九镇展示的法统成果，却没有得到一枚可以跨镇调用的空白印。

午时前，独立油车见底。阵匠需要再拆两车外仓备用油，顾衡说明若全拆，药车炭盆只能维持到日落。许青棠让药车夫、外仓住户代表和医官各自选择是否减少药车保温时长。车夫同意先保住止血粉，住户代表同意每户少领一捆柴，医官承担温度巡查；三项选择分别入救护账、住户账和阵法账，不能合成“北镇共担”。

贺停舟将旧印交给卫岑保管到日落，却不让卫岑单独使用。他命罗衍把钥匙和印盒分别封袋，卫岑掌印盒，北镇文吏掌柜钥，许青棠掌开封见证簿；贺七只核对外仓人数，不碰印盒。司空烬的院吏只能见证封蜡，不能取走印盒。旧印从贺停舟手里离开，却没有落入任何一个人的单独控制。

下午，黑账拓样中“空栏不得结功”旁边出现一处新折痕，折痕朝向交印副本。折痕没有笔压，也没有纸纤维断裂，许青棠把它列为异常折叠现象；她拒绝把折痕解释为黑账在呼应交印。陆昭提出应保持两纸三尺距离，司空烬同意，但要求把距离和时间记录进院方副本。

日落前，阵铃恢复为两声一停，封线暂时稳定。旧井第四声没有再出现，井口却结出一层薄霜。阵匠不敢开井，先把霜样封存。霜样里有松烟和细骨粉，和黑账、井沿骨片有待核关系；没有尸骨确认和活人选择，任何人都不能把井下东西列为功簿死者。

贺停舟在交印登记末尾写下：“交出旧印，不交出判断的证据；交出单独权，不交出本人选择。”他签完后把木杖交给罗衍保管片刻，让自己的双手空着。那是一个不习惯空手的人第一次主动承认，权力可以被拆开，责任却不能因此少掉。

司空烬看着登记，问他是否准备接受院方对旧案的追责。贺停舟答：“追责可以按证据来。若要我替三户、曹弥或井下无名者认功，我不接。”

黑簿没有翻页，封诡阵也没有完全恢复。旧印交接只让一扇门从单人手中移到三人见证之间，下一扇门仍在阵眼和药车之间等待。陆昭站在白线外，听见许青棠说要建立一处不靠镇诡卫主印的伤亡复核台，知道新的责任正在落到活人手里。

交印后的第一份调度不是封诡阵，而是外仓的热粥。顾衡按二十七户实到人数报出六十三人，贺七却只亲眼数到五十九人，其中四人可能从北墙口先行回家。贺停舟没有让任何一方改数，他令卫岑确认封路是否仍在、罗衍复核两处出口的时刻，最后找到四人在医棚换药的记录。两类记录合上，六十三人才成为可以发粥的数，不是由贺七的指印替所有住户选择。

贺七因此要求在见证栏添一句“只报见到的人，不报未见之人的去向”。卫岑原以为这是推责，听完医棚的时刻却接受了。贺停舟把自己的印盒推远，让文吏按新的分工把热粥先送给医棚和老人，再把发放差额记在外仓账；若夜里有人回城，需重新点数，不得凭先前的总人数领第二次。

阵匠又送来供油图，指出旧功副页仍压在铜牌下方，三钥盒只能防止旧印再次被单人拿去加签，不能消除副页上的假“已接”。司空烬建议先把副页拓成两份，封在北镇与功簿院各一柜；贺停舟同意拓样，不同意取走原纸。许青棠在图上标出拆副页可能牵动旧井的位置，要求明日先做空槽试验。新的交接因此换来了半日试验时间，也换来更重的油粮支出。

贺停舟交印时，将旧印、钥匙和自己能承接的城防事项分成三份。第一份交给镇诡司，第二份交给守门人，第三份留给复核署；他不把交印写成赎罪完成。家属领粥的账仍由他当面解释，旧功撤项不抵今日粮耗。陆昭看见一个失去权限的人如何继续承担后果，也把这段过程写进自己的停职观察记录。

夜巡时，贺停舟自己走到外仓，向第一户后人说明旧功撤项和热粥账互不相抵。妇人说她只同意今天领粥，不肯让当年母亲的避雪木牌被拿去给封诡阵续灯。贺停舟请罗衍当面写下限制，自己的手不再握印，只在见证栏签名。这是他交印后的第一项行动：不是借没有印逃开旧责，而是用空手把新责任记清楚。

临走前，妇人又问，若夜里阵灯熄灭，谁负责把她家的老人送到内城。贺停舟没有把问题推回镇诡司，也没有用旧印作答。他让罗衍把撤离路线摊在雪地上，逐段标出谁能开门、谁能抬担架、谁只负责报铃。妇人同意把自家牛车借给两户老人，却拒绝承担阵外所有人的车粮；另一户住家愿意接一名病人，但要求医官先确认病情。两份同意被分别写入救护栏，借车的油耗、草料和归还时刻也另立一栏。贺停舟只在“说明责任”处签字，承认自己能协调，却不能替她们把有限的车位说成全镇承诺。

许青棠复核那张路线图时，发现贺停舟把最短的一段路绕开了旧井。贺停舟解释，绕行多三百步，却避开井霜可能覆盖的石阶；若有人坚持走近路，必须由本人在风险栏签名，并由两名见证人陪同。妇人看了半晌，选择绕远路。她没有因此接收旧井里任何无名者的功劳，贺停舟也没有把她的借车记成阵法功。夜里第一声阵铃响起时，三辆牛车按各自签下的次序出发，谁先让路、谁暂缓领取柴炭，都能在账上找到对应的人名和时刻。

罗衍随后发现，第二辆车的归还时刻写在第一辆车的栏下。他没有擦去原字，先叫车夫停在门内避风，再请两名守门人分别复述放行时刻。两个时刻相差半刻，是因为第二辆车曾回头接人，并非多领了一辆车。罗衍在错栏旁画线更正，写明复述者和旧记位置。贺停舟让热粥照发，却暂缓用那张错栏账申领草料；等车夫与住户各自确认实耗后，才由粮吏补记。封线外的人仍在等车，这半刻的核对确实让他们多受了寒，医棚便把冻伤复测列入当夜值守，不能用“账目纠正”一句话抵掉。
