# 第三十六章 旧功反噬

回北镇的路上，贺停舟的旧腿每走十步便抽痛一次。许青棠让他停在避风石后复测，测得残端皮温偏低、脉搏快一拍，未见新裂。她说明这是伤情变化，不足以证明关妖在体内，也不能凭疼痛认定旧功反噬已经完成。

陆昭把第三十五章的六袋证物摊在无字布上。碎军令属于口腔取出物，铜哨片来自第二道雪沟，骨笛来自木车铜匣，铁甲鳞来自车底，白蜡粉来自车门刮痕，旧伤记录来自贺停舟本人。六类证物来源、接触人和时刻各不相同，不能因为都出现黑粉便并成一条因果链。

秦衡从副封中取出一张旧格式功单。功单上写着“镇南关撤民，功成”，下方有贺停舟当年的印记和一行被刮去的接收人。纸张没有异常红线，笔压却深到背面。贺停舟看见功单后选择承认印记属于自己，不承认下方接收人是军需官，也不允许秦衡用他的记忆补写空栏。

陆昭问他当年是否亲眼见过军需官接收撤民名单。贺停舟沉默很久，说只看见一名副手在门边点头，自己没有让军需官本人签字。他承认那次结算缺了本人选择，导致后来三户撤民被写成已经完成。话音落下，他旧腿骤然失力，木杖砸在雪上。

许青棠立即报告伤情，确认骨端没有新折。黑灰从铁甲鳞中涌出，沿木杖爬到贺停舟手腕，却在接触皮肤前停住。陆昭用无字木片隔开，不用封功刀斩断。他要求贺停舟本人选择：继续公开旧案口供，或停止复述，接受医署留观。贺停舟选择继续，但声明只说亲见部分，不替死者认领功劳。

这次选择让黑灰退回鳞片。秦衡指出旧功单上的“功成”仍可能影响今日军令，只要北镇把贺停舟当作关妖旧案的责任人，纸面就能再次牵引。陆昭让所有人把旧功单放入单独匣中，不与碎军令接触，并在副本中写明“旧案本人承认部分行为，不等于死者遗愿完成”。

第二座烽台的方向又传来闷响。紧接着，城外黑甲骑士的声音隔着雪坡传来：“把旧功还回去，关线自然会开。”贺停舟抬头问他所说的旧功是什么。骑士没有现身，只把一块深青铜片掷到坡下。铜片背面刻着半个“镇南”字样，边缘有与铁甲鳞相同的卷曲。

陆昭没有让人接铜片。他先让罗衍测量落点、旋转次数和雪层压痕，再由许青棠用长钳夹入空袋。铜片没有血迹，也没有黑粉；只是卷曲边缘与铁甲鳞相似。贺停舟选择不以旧案经验确认铜片来源，秦衡也承认功簿院没有权限凭半字认定旧功归属。

陆昭翻开自己的黑簿。第一页缺口边缘浮出一条极细红线，线头先指向贺停舟，再转向北方第二座烽台。红线没有写出姓名、死者或未竟之事。陆昭合上簿子，左手失痛忽然消失一息，随即恢复，错认风险却猛地加重：他把罗衍的木牌看成周循的乙十七，差点下令把人列作失踪驿卒。

许青棠及时指出木牌背面的城防刻痕。陆昭停住，承认自己出现错认，主动把指令交给罗衍复核。罗衍本人选择只承担押送证物，不替陆昭确认身份；秦衡则承担记录这次错认，不把它写成陆昭失职定罪。责任被拆开后，红线稍稍暗下去。

贺停舟看着陆昭，提醒他听骨的反噬从来不是疼痛本身，而是把未经核验的关系当成已经完成。陆昭回答，自己现在最怕的不是左手失痛，而是在失痛时觉得所有证据都足够。许青棠给他缠上新布条，说明伤口浅裂未愈，今日不得再碰骨片。

队伍回到第一座烽台脚下时，守台卒短暂醒来。他认出贺停舟，却没有说出姓名，只抬手指向铁甲鳞，又指向第三烽台。许青棠询问他是否愿意将这段指认写入军令核验，守台卒因意识模糊无法回答。陆昭把动作记录为非完整证词，不让功簿借此翻页。

黑甲骑士终于从雪坡后走出，提出以铜片换取守台卒。贺停舟拒绝把活人当作证物交换，选择让罗衍继续护送伤者。骑士拔刀一寸，刀锋却被骨笛声震回鞘内。笛声只有半个音，铁甲鳞上的黑灰便同时向第二座烽台方向聚拢。

陆昭看出规律：旧功单、铁甲鳞和骨笛都能牵动责任，却没有任何一项确认死者未竟之事。现在若强行使用封功刀，最多切断一段关系，无法结算，也可能伤及贺停舟。于是他让众人退到无字木桩外，记录骨笛半音、黑灰移动和骑士换位，不追击、不交人。

黑簿最后浮出一句话：“旧功反噬，非旧功归还。”陆昭明白，关妖正在借过去的错误逼活人替它补写结局。可要斩断这条线，仍必须找到真正留下未竟之事的人、两类独立证据，以及愿意承担结果的活人。第二座烽台的火盆，在远处终于亮了一瞬，又立刻熄灭。

回到北镇后，陆昭没有把贺停舟送进功簿院留置房，而是让医署和城防各自派一人见证。贺停舟本人选择接受医署留观三刻，不接受任何“旧功已还”或“旧功已清”的纸面结论。许青棠把右肩牵痛、贺停舟残端疼痛和陆昭左手错认分别列在伤情册三栏，避免把三种代价合并为关妖同一手段。

秦衡试图将铜片与乙巳年旧案档案同柜。陆昭要求先核对柜号、钥匙和封条，秦衡便选择把铜片暂存功簿院副柜，承诺封条仍由北镇保管人复核。罗衍把黑甲骑士的靴印拓样放在门外，不让其接触旧功单。贺停舟听见“镇南”二字时再次脸色发白，却坚持本人复述不得超过亲见范围。

夜里，守台卒醒来一次，承认自己曾在第一烽台听见第三台传来的求火声，却不知道是谁发出。他愿意让医署记录这句话，但不愿承担军令真伪的判断。陆昭把这项选择记在证词旁，写明“活人同意记录，不同意替军令定性”。黑簿没有回应，说明这仍只是证据的一部分。

陆昭最后检查左手浅裂。失痛时长比前日多了一息，错认却在夜间灯影里加重，他把自己的影子误看成黑甲骑士，直到许青棠敲桌才回神。他主动把夜巡交给罗衍，自己只负责封袋编号和回城报告。第二座烽台的火盆再没有亮起，关外的旧功也没有因此得到任何归还。

封袋编号完成后，陆昭让所有经手人分别念出自己承担的范围。许青棠只负责伤情和样本，贺停舟负责旧案口供与车辆留置，秦衡负责副柜核验，罗衍负责押送和夜巡，陆昭负责顺序、报告与不结算。每个人都拒绝替另一个人补写接收栏，旧功单上的红线因此没有重新出现。守台卒在医署里再次昏睡，无法作出更多选择，功簿四步仍缺死者与未竟之事确认。

窗外传来第三座烽台的长鸣，声音只到一半便像被雪吞掉。陆昭没有出城追声，而是让罗衍记录时刻，让贺停舟在地图上标出可能的风向误差。许青棠把半个“验”字湿纸放入独立封袋，说明它或许来自另一支传令线，也或许只是有人借军令字面制造牵引。所有判断都停在证据边缘，没人把黑簿提示当成结案。

旧功反噬发作时，陆昭先把左手交给许青棠检查，自己只用右手读军牌。黑簿旧页上“已结”二字褪去一笔，不能说明旧功被谁夺走；他让秦衡记录墨色变化，不让秦衡据异常要求打开黑簿原册。司空烬的使者催他承认上一案结算有误，陆昭回答反噬只能证明自己受过代价，不能证明任何人的罪。伤情、旧功和军牌分柜，三者不互相代签。

贺停舟在地图上圈出第三座烽台与旧渡之间的荒沟，提醒那里曾是乙巳年撤民时的临时集合处。陆昭没有把荒沟与旧功单直接相连，只让秦衡核对旧案档案中是否有集合名单。秦衡选择次日取卷，不在今夜凭记忆补名。许青棠给陆昭换下带血布条，确认浅裂边缘没有黑粉，说明他的错认不能归因于证物直接接触。陆昭将这条观察写进自己的伤情栏，并承认下一次接近骨笛前必须先有第三方复核。

第三座烽台的半声长鸣再次传来时，陆昭先让罗衍报出风向，再让两名守卒分别写下听见的时刻。两份时刻相差三息，足以说明山谷回声会拖长声音，却不足以判定发声位置。秦衡想用“第三台求火”作统一标题，贺停舟要求保留“半声铜鸣”原称，避免标题把尚未确认的对象写死。双方由司空烬的院吏见证，最终在目录里并列两种称呼，互不覆盖。

许青棠复查守台卒的昏睡状态，确认他在听见第三台声音时瞳孔没有主动追光，手指也未形成可辨指向。她把“未能作出有效选择”写进伤情和证词两栏，要求城防不得以他曾经说过半句梦话为授权。守台卒的同袍愿意提供换岗记忆，却拒绝替他判断军牌真伪；这项拒绝被记录后，旧功单上的空栏仍保持空白。

陆昭在副柜外复核“已结”二字的褪痕，发现褪去的是墨层最外缘，不是纸纤维被削。秦衡让书吏猜测黑簿正在撤销旧功，陆昭制止，要求先做相同纸张的冷湿对照。对照纸在同样温度下也出现边缘发白，说明褪痕可能受环境影响。黑簿异常只作为本人风险记录，不能越过两类独立证据，更不能替任何旧案重新分配责任。

夜班交接时，罗衍把骨笛封匣、碎军令封袋和守台卒药箱放在不同木架。药童询问能否借用封匣木板垫药，陆昭提醒封匣外板虽无字，仍属于证物保全的一部分。药童选择改用废板，罗衍在交接册上补写“未以证物作他用”。这些微小的拒绝没有带来功勋，却让第三台的声音、尸体的受力和陆昭的错认各自留在可追溯的范围内。
