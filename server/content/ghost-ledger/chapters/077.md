# 第七十七章 天灾源头

九镇会盟后的第三日，第一轮小令回传只到齐了六镇。

第二镇的药箱在卯时由药房文吏签收，阮遐复核了封签和药量，确认少了一包止血粉，少的不是押运散漏，而是药吏按本人同意拆出的临时用量。第三镇空船护送两名水卒到医棚，船户在水门留下离开和靠岸时刻，裂口船铃仍留在原柜。第四镇接生婆被允许通过封路点，却拒绝带走红布包，只确认了小岚出生时刻和脐痕位置。其余三镇的回传仍缺本人签名。

司空烬没有先看灾报结论，而是让秦衡把六镇回传按材料、接触和时间三列重抄。白线、湿木、铜钱灰纸、黑蜡、青白砂和四槽白木片被列在同一张索引上，却没有被划进同一案件。许青棠在旁边加了一列“是否经过旧驿转运”，提醒所有人，材料颜色相近只说明需要比对，不能说明经过同一只手。

第七镇烽台守卒送来的记录成为第一条可比线索。三日前夜里，烽台换班时有一辆没有旗子的白蜡轮车经过，车轮外缘沾着细白粉，守卒只看见车轮，没有看见车夫。白粉被扫入小袋，接触者和扫取时刻有记录。北镇白蜡木擦痕旁的木屑里也有白粉，但两者尚未做颗粒大小和熔点复核。

许青棠提出先比较粉末，不比较传闻。她让复核署记录吏取三份样本：第七镇车轮白粉、北镇白蜡木擦痕木屑、第三镇黑蜡陶罐外沿附着物。每份样本都由不同的人开袋、分取和封回。第一轮盲验显示，车轮白粉有两种颗粒，一种可在指腹上留下蜡感，另一种像干燥石粉；北镇木屑上的白粉只有蜡感颗粒；黑蜡陶罐外沿没有白粉，只有盐和河泥。

这个结果排除了一个过快的猜想：三镇的白、黑和盐不是同一种涂层。许青棠在报告上写下“至少两类材料，接触时序未闭合”，并拒绝把黑蜡罐列入白蜡车线。司空烬看着样本表，要求继续查同一车轮是否在六镇出现过，而不是先寻找一个听起来完整的源头。

第五镇粮吏随后补交一张旧驿路车轮拓图。拓图不是现场原件，只是根据雪地复刻，轮距六尺一，外缘有一道断续浅槽。西关北坡车也有六尺一轮距，但承运人和接收栏空缺。第七镇白蜡车轮则宽六尺二，外缘没有浅槽。三种轮距相近，却没有共同轮钉和同一断口，不能当成一辆车。

真正的时间关系来自第九镇空匣。木楔入匣时，封匣人记录了旧驿厅北墙一阵短风；会盟桌下敲击声停止后九息，空匣外封泥才出现轻微凹痕。封泥没有破，凹痕也不像有人按压。司空烬让人把这两件事分别记在会盟卷和第九镇物证卷，不把九息当作妖物固定规律。九息只说明两个记录在时间上相邻，尚不足以证明彼此因果。

陆昭的复述记录从第四镇送来，仍由记录吏朗读。他没有见过九镇样本，只报告南汊村接生婆的来回时刻、红布包未开和小岚母亲的拒绝条件。读到“封路点外有一阵白粉风”时，他停了一息，问这句话是谁亲眼看见的。记录吏承认那是村民根据门槛上的粉痕推测的。陆昭要求把“白粉风”改为“门槛有粉痕，来源未明”，并在旁边写明自己不作方向判断。

这个更正让许青棠意识到，九镇急报中可能还有同类词语。她抽出“风拖粮”“水推船”“名字被吃”和“黑墙移动”四个词，逐一追问原始见闻。第二镇的粮袋确实被拖入井沟，却无人看见风抓粮；第三镇水卒撤回“水下有人推船”；第四镇没有人亲见名字被吃；北镇黑墙只留下硬灰和无脚印拖痕。四个说法都来自后来的解释，不是同一现场的人直接看见。

司空烬没有因此宣布灾报失真。他把解释词和可见痕迹分成两层，要求各镇在下一轮回传时同时交上“我看见什么”和“我认为是什么”。这项要求让传令速度慢了半日，却保留了纠正入口。秦衡问若有人拒绝改写，是否算妨碍会盟，司空烬说拒绝改写传闻是允许的，拒绝交出原始时刻才需要另列责任。

午后，三镇样本的第二轮比对出来：第七镇车轮白粉中的蜡感颗粒，与北镇白木片外封套水滴留下的薄膜相近，但不是同一批蜡；两者都没有第三镇黑蜡陶罐的植物茎纤维。白蜡、白封套和灰纸可能在旧驿路上经过同一类保温或封存工序，却没有证据说明操作者相同。

司空烬据此批准一项有限行动：由第七镇守卒、北镇锁匠和复核署记录吏组成三人小组，沿旧驿路只查车辙、封泥和粉末，不追白蜡车，不寻找所谓灾妖。三人各自选择可承接的范围，任何一人都可在看见活人或尸体时暂停并请见证。陆昭不能参与现场判断，只能在第四镇复述已经核验的数字。

夜里，三人小组在旧驿路第七里处找到一段被雪覆盖的石槽。槽宽不足车轮，却能容下一只装样的小木匣。槽底有白粉、盐粒和一小截黑麻线，三者没有混在一起，分别贴在不同侧壁。石槽旁的木桩上刻着半个“回”字，刻痕新旧不一，不能证明与第九镇木楔同源。

第七镇守卒愿意承接石槽位置和粉末封存，北镇锁匠愿意承接木桩刻痕与钥匙锈粉的比较，记录吏只愿承接三人返回时刻。没有人愿意承接“这里就是天灾源头”。许青棠把这句拒绝原样写入回传，司空烬没有删掉。

石槽的发现让九镇第一次拥有可跨镇复核的物理结构，却仍没有死者、未竟之事或活人接收。功簿院的黑簿原册还在北镇三钥柜，陆昭也没有触碰尸骨、黑簿或封功刀。司空烬在会盟地图上把第七个黑点改成“旧驿石槽，待三方复测”，并撤回“异常道路”四字。

撤回令送到各镇时，第九镇空匣里的木楔自行翻了一个面。木楔背后露出一条极浅的直线，像是刻到一半便停手。封匣人立即封回，不补刻、不擦拭，也不把翻面写成木楔主动移动。天灾源头仍未找到，但各镇终于有了一件可以重复测量、而不能靠传闻解释的东西。

三人小组回城后还做了一次反向试验。锁匠把同样大小的白蜡木片放在石槽外侧，守卒在原记录位置点灯，记录吏只测量粉末落下的方向。灯火带动的热气使木片边缘沾上一层蜡粉，却没有形成石槽里那条分侧附着的白粉、盐粒和黑麻线。试验不能证明石槽曾装过旧功物件，却至少排除了“白粉只是灯油受热后的自然沉积”这一种解释。三人把试验材料另柜封存，不与现场样本混装。

回城前，三人又分别测了石槽两侧的温度和湿度。北侧靠雪，温度低两分；南侧被旧墙挡风，盐粒却没有向北侧迁移。记录吏把测量时刻、手套更换和封袋顺序写在同一张见证纸上，三人各自签下只承接本人测量的范围。纸上仍没有“源头”“妖关”或“操作者”等结论。陆昭听完复述时，把“样本未迁移”读成“源头未迁移”，立即停下，由记录吏更正。左手的失痛没有让他感觉到指节撞在桌沿，错认风险反而更清楚地留下了一个可以被别人纠正的痕迹。

天灾源头的候选样本先经盲验。白粉、白蜡、黑蜡和青白砂被拆为至少两类以上材料，石槽内侧的盐粒与门槛蜡膜未显示同一断口。许青棠要求记录样本温度和开袋在场人，顾衡担心手续拖慢调粮，司空烬批准增纸但要求公开实耗。陆昭没有凭黑簿提示把九门连成妖物，而是把“能够排除什么”写在每份检验单前面，保留源头仍未确认的事实。

许青棠在复核署回函中写明，能够排除一种解释，不等于已经找到源头。她要求下一轮行动增加两个记录：样本离开原地前的温度，以及每次开袋时谁在场。司空烬接受了这项增加，却提醒各镇，新增记录本身也要由本人选择承接。没有人因为站在样本旁边，就自动成为样本的结论者。

第二轮样本送回时，北镇锁匠发现先前用来刮取白粉的铁片边沿生了锈。若把锈屑混进粉末，颜色会更像旧门槛的黑膜。他当着守卒和记录吏的面用清水冲同材铁片，量出新锈落下所需的时间，再查原袋封口，确认原样本开袋前铁片没有伸进去。试验不能证明原粉绝无铁质，只说明不能用今日生锈的刮刀倒推昨日石槽的成分。许青棠让记录吏把工具状态并列在温度、湿度之后，原来的盲验结论不撤，也不扩大。

司空烬催问能否向九镇发一份“源头已定”的急令，锁匠却把手套翻给他看：掌心沾的是试验铁锈，指背沾的是石槽外墙盐霜，两处只隔半寸，却来自两次不同动作。若他不写手套更换时刻，任何后来的相似颜色都可能被误作同一次接触。司空烬最终只发“候选结构可复测”的回批，另拨一名工匠守石槽，免得守卒既看线又看证物。多出的工钱由院方承接，谁也没有借这份迟缓向未知的死者讨功。
