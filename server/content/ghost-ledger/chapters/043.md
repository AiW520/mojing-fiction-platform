# 第四十三章 关妖开口

阮遐下到沟底时，先把自己的军医领牌交给罗衍保管，声明只负责救人，不负责替伤者认领军籍。绳梯落在旧担架杆旁，三方各有一人扶住绳头。陆昭站在见证线外，左手失痛还未退，不能握绳，只能按贺停舟划出的三段范围报位置。

第一名活人被麻绳缠住左腕，手背冻得发白。阮遐剪开绳圈，发现绳芯是黑麻，外层却裹着一层浅灰药粉。孟岚在上面辨认出这是药箱封绳的旧式结，不敢说属于谁，只说明这种绳常用于把药脚绑在担架外侧。许青棠从上方报出伤者脉搏和瞳孔，要求先解除绳压，再问姓名。

第二名活人嘴里塞着半截药布，胸口有旧箭擦痕，右脚踝肿起。阮遐取出药布时，发现布边绣着一个被剪掉半边的“岚”字。许青棠看见那字，立刻让罗衍把布放进独立袋，不许把半字直接补成青岚。她说军医署绣字有三种针脚，半字只能证明布曾被绣过，不能证明谁穿过。

陆昭让两名伤者分别选择是否接受救治。被缠腕的人先点头，愿意让阮遐替他止血，但拒绝让镇南校尉查看腰牌；塞药布的人说自己愿意说话，却要先确认名字不会被写入“已接台”。贺停舟把两人的条件各自写在木板上，不用一个人的同意替另一个人作选择。雪壁上的“九人已接”因此褪去一角，露出底下的冰层。

被缠腕者自称齐三，曾在第三台做搬运脚，不是军医，也没有完整军牌。他说七日前奉命把两只药箱送往谷口，走到西南沟沿时听见骨笛半声，随后有人从后面勒住他，把他的腕子系在担架上。齐三没有看见施力者，只记得对方说“先把接台写满”。这段话有时间、有动作，却仍是单人口供，不能直接认凶。

塞药布者自称贺七，声称自己是北镇旧渡招来的临时车夫。他只记得一辆白蜡轮车和一块没有旗号的铜匣，不知道车上是谁。他承认自己曾在空回执上按过指印，但当时以为那是领取药袋的收条，并未同意把名字写成“九人已接”。他愿交出右手指印拓样，却拒绝替失踪的两个人作证。

镇南校尉要求先把齐三和贺七押回镇南，理由是两人涉及逃役。卫岑不同意，指出两人正在北镇救治范围内，且他们本人明确拒绝被旧功单代认。贺停舟让双方各自写明扣押理由和救护责任，谁要带人走，必须先接下冻伤、药量和夜间转运的全部风险。镇南校尉看见责任栏后没有立即签字。

许青棠从沟壁取出一片被冻住的药蜡。蜡上有半个甲三编号，与许青岚尸体药瓶底的编号相同，但蜡面有两次刮擦，一次在冻前，一次在冻后。阮遐确认甲三药瓶确为医署批次，却不能证明谁携带过它。许青棠把药蜡、药瓶和齐三腕部灰粉分成三袋，拒绝让“同号”替代接触时序。

罗衍在旧担架下发现一块薄铜片。铜片正面刻着“接”，背面刻着“反”，两字刀痕深浅不同。卫岑认出铜片可能是西关军需处旧令牌的边片，却不承认它属于自己的队伍；镇南校尉说镇南军中没有这种令牌。陆昭让三方只确认字形和材质，不让任何人补写“反向军令”。

沟外白纸忽然贴上雪壁，写出“齐三已交、贺七已交”。齐三看见后立即说自己没有交出军籍，贺七也说他只愿接受救治，不接受任何功劳。两人本人选择同时落下，白纸的“已交”边缘裂开。陆昭让罗衍记录裂纹扩散方向，许青棠则让伤员闭眼，避免他们被纸面牵引再次误认自身处境。

关妖第一次发出完整声音。

那声音不是人声，也不是号角，像一张湿纸在冰上被慢慢撕开。它从第三台石壁内部传出：“接谁？”

三方都没有回答。卫岑把副令压在膝下，镇南校尉把旧功单收回袖中，贺停舟让北镇士卒退到见证线后。陆昭也没有朝石壁喊军令。他只让罗衍记录声音出现时刻、石壁裂缝位置和纸面字迹是否变化。

石壁又问：“谁愿替九人签？”

齐三在沟底说自己不愿。贺七说自己只接收伤药和活路，不接收九人名单。许青棠说她愿意接收弟弟尸体的复核责任，但不替其他八人签名。孟岚愿意接收药箱清点，不愿替药脚作选择。孙砚在哨屋门口承认“未接台”是自己的笔迹，仍拒绝把缺页补成“已接”。

每一个活人的回答都不同，石壁里的声音便出现不同的回声。它像在寻找可以合并的句子，却只得到被拆开的责任。雪壁“九人已接”逐字剥落，露出一条向下的黑缝。黑缝里没有血，只塞着两张被裁去姓名的木牌。

陆昭让三方共同确认木牌位置，不允许谁先下手。阮遐负责继续救人，罗衍负责取牌，镇南校尉负责外缘警戒，卫岑负责桥南退路。每个人先报自己承担的范围，黑缝才停止扩大。陆昭没有动封功刀，因为刀只能切断纸件与责任关系，不能把石壁当作可斩的妖身。

罗衍用无字木板将两张木牌托出。第一张只剩“乙”，第二张只剩“青”下半部，断口一新一旧。许青棠看见第二张牌时没有伸手，只要求第三方验木纹和药库孔。她的肩痛因俯身指示加重，主动把近距辨认交给阮遐，自己退到沟口。

齐三看见第一张牌，说那是七日前被收走的搬运牌；贺七看见第二张牌，说自己曾在空车里见过，却不知道是谁的。两个人都把记忆限定在“见过物”，不承担身份接收。陆昭让秦衡把两份口供分列，不能因为两人都说见过，便把木牌拼成同一人的名字。

许青棠要求齐三和贺七分别描述看牌时的光线、距离和牌面朝向。齐三说牌在车板内侧，灯油将“乙”字照成一条斜影；贺七说另一牌贴在空车底，雪水把下半部泡得发白。两段记忆的观察条件并不相同，阮遐又让二人闭眼复述一次，齐三把“车板”说成“担架”，当即承认退热前可能混淆。陆昭将第一次和第二次口供并列封存，注明更正不抹掉原话。贺停舟把这项复问列入伤员回城后的七日复测，负责提醒他们本人可补充，却不得让北镇文吏代写。

罗衍用细绳量出两张木牌断口到沟壁的距离，发现一张距石壁不足半尺，另一张落在旧担架杆外侧。距离只能说明它们被发现时的位置，不能证明谁把牌推出黑缝。镇南校尉要求把两牌带回镇南比对军籍，卫岑提出先做三方拓样，避免原件离开救护现场后再出现“先后接收”的争执。两方都在责任板上写下自己的要求，贺停舟确认争议未解决，便不允许任何一方以军印压过另一方的保管意见。

齐三被送上木板时，还问自己的名字会不会出现在镇南的逃役榜上。校尉说按旧例需要先登记，卫岑却要求注明“救护转送，非收押”。贺停舟让齐三看清两个栏位的差别，由他选择是否留下通讯去处。齐三只同意北镇医棚知道床位，不同意张榜。校尉保留日后依法问话的权利，但暂时放弃当场押人；这不是被逼退，而是他若现在移人，就必须承担阮遐写明的失温转运风险。陆昭把这笔风险与木牌保管争议分开，活人的命先从军令文字里挪了出来。

石壁里又传出一句：“接台无回，谁回谷口？”

这次声音带着第三座烽台的铜角余震。黑甲骑士在旧驿道尽头停马，耳后薄纸被雪水冲开一道口子，露出半个“令”字。他仍不报姓名，却把空铜匣放在地上，示意里面可能有回声记录。卫岑要求他先按军籍编号签押，骑士转身消失在风里。

黑簿在陆昭掌下浮出一行小字：“活人可答，死者未回。”它承认齐三和贺七的选择，却没有确认两名缺席者的生死，也没有指出许青岚的未竟之事。陆昭承担封存两张木牌、保护两名活脚和维持三方边界的新责任，功簿四步仍未闭合。

天色转暗时，齐三忽然说自己记起一件事：七日前他听见第二声车轮后，车上有人把“反”字倒写在木牌背面。这个细节可能解释铜片“接、反”的先后，也可能只是冻伤后的记忆断层。许青棠要求等他退热后再复问，陆昭把“倒写”列为待核，不让关妖的声音替他补齐。

第三座烽台的石壁安静下来。两名活脚被抬出雪沟，九人名册仍缺两格，许青岚尸体的药瓶也没有找到最后接台回执。关妖已经开口，却只问活人愿不愿认责；真正的反向军令，仍藏在无人签押的那一面。

关妖开口时，石壁仿出许青棠的声音，齐三险些按下自己的回执。许青棠先报出肩痛和站位，再让本人确认声音是否由自己发出。她没有因为仿声准确就把妖物身份写定，只把声音的回声长度、冰壁湿度和纸面字迹分项记录。陆昭把“我听见她说”改成“石壁发出近似声”，让见闻回到可重复的范围。

阮遐在医棚门口补记了两名伤者的脉息和体温，齐三的腕部仍有麻木，贺七的踝部肿胀却没有继续上行。她让二人各自在伤情栏旁写下能够承担的范围，齐三写“腕伤、送北镇”，贺七写“指印、脚伤”，并在两行之间留出空白。许青棠说，空白不是遗漏，而是他们明确不接的部分。陆昭把这两行和石壁问话分柜封存，确认任何人都不能凭“已交”二字填平那道空白。
