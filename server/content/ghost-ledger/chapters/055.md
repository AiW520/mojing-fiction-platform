# 第五十五章 镇诡司内斗

司空烬离城后，北镇的第一场争执在辰时开始。保全筹片还挂在审计板上，西关药车的运送记录却先到了。记录写明，若北镇未在卯时前交出“北坡粮案相关原件目录”，西关将把药车停在旧渡，不再承担过桥后的损耗。药车里有第三台伤员需要的止血粉和三日粮，停一次，便可能让两名伤兵失去换药时刻。

卫岑的副使带兵站在左门，要求先交目录。贺停舟只让他看已经公开的编号，不让他接触双钥名册。秦衡站在中门，手里拿着司空烬留下的保全副本，提出折中：把旧功单、三户撤民簿、曹弥回执和无名尸编号列成一张不含姓名的目录，由功簿院先行核验；原件与家属选择继续留在北镇。

北镇文吏罗衍却当场反对：“目录一旦进入院里，院里就能凭目录申请整柜保全。昨日总表的无笔压字还没查清，今天再交一张空白授权，等于给它铺路。”

秦衡脸色发沉：“不交目录，药车停在旧渡，伤员的血不会因为你们坚持程序就少流。”

“那就把停药风险写进谁的名字。”贺停舟说，“不能写成北镇拒绝，所以西关自然停药；也不能写成陆昭停职，所以由他承担。”

陆昭坐在旁听席，停职告示的白线已经退到墙角。他不能主持会议，便让秦衡把争执拆成三项：药车是否已进入运送链，西关是否有权以保全令暂停拨付，目录是否包含本人选择范围。三项都有人能回答一部分，却没有一人可以替其他人作决定。

许青棠先检查药车封签。止血粉箱外有三层蜡，一层是西关医署，一层是旧渡巡卒，第三层却没有任何印记。箱轮底部带着湿沙，车轮宽六尺一，与第五十三章木箱痕相近，轮轴磨损位置却不同。她据此认定药车已经到北镇外，却不能证明它与曹弥旧车同源。

卫岑副使承认，停药不是司空烬直接下令，而是西关军需处依照保全副本的风险条款暂缓。条款写着“争议路线未明，货物不得进入争议封存区”，没有写由谁承担伤员损耗。秦衡让他把这段原文抄出，副使只同意抄录，不同意代西关承诺补给。

争执越过午时，镇诡司内部开始分成两派。粮仓经手人顾衡主张先交无名尸编号和曹弥全名，换药车过门；文吏罗衍坚持姓名与功劳名单必须分开；贺停舟只支持按双钥目录交出不含姓名的事实；秦衡则认为没有院方复核，北镇永远会被地方旧错拖住。四人都拿出真实风险，却把彼此的证物权看成了阻碍。

陆昭提出让每一派先报自己愿意承担的后果。顾衡愿意承担粮仓盘亏，却不能替家属公开姓名；罗衍愿意承担文书滞后，却不能负责药车停留损耗；秦衡愿意向司空烬报告院方复核迟延，却不能用副本打开北镇原柜；贺停舟愿意把城门和护送风险写在自己名下，但不愿把停药写成陆昭的责任。

这张责任表刚写完，保全筹片边缘便渗出一圈黑灰。灰烬沿“曹”字和“三户撤民”两面爬，像要把两个旧案压在同一行。没人喊出妖名。许青棠拿无字板遮住筹片，发现黑灰在碰到“双钥”三个字时停住。她要求把筹片与责任表分柜，不能因为灰烬趋向就证明两案同源。

下午，西关药车的车夫提出本人选择。他同意把车轮、封签和停留时刻交给北镇验看，但不愿把自己写成“曹弥旧案证人”，也不愿承担药材过期后的军需责任。车夫的选择由他亲自按印，卫岑副使和许青棠见证。药车因此获得一条明确边界：可以验车，不得代证。

司空烬的回函在此时抵达。函上说，若北镇能在日落前交出不含活人姓名的目录，保全令只冻结原件，不冻结药车；若连目录也拒交，则院方按九镇旧例申请临时接管。函印真实，发令时刻和接收人仍由秦衡补写，函背没有黑印。司空烬把选择写成两条路，却没有把北镇的沉默自动记成拒绝。

秦衡主张立即签字。罗衍问目录中是否包括“家属候选索引”的编号。陆昭在旁听席指出，编号本身若能与姓名在院中对应，也可能成为间接披露；应只交证物种类、封存时刻、保管人和复核期限，不交索引编号。许青棠支持他的异议，却提醒这样做会让院方更难判断保全范围。

贺停舟最终提出第三份文本：目录只列七项物证和三项程序责任，另附一张由各保管人签字的“姓名未授权”说明。秦衡将文本送到城门，要求卫岑副使确认西关是否接受。副使看过后，承认自己没有权限答应，只能带回军需处。

夜幕降下，药车仍停在旧渡。北镇内部的争执没有结成一项功劳，却使每个人的责任第一次露出边缘。陆昭在白线外听见许青棠复测自己左掌，失痛和浅裂未变；他仍不能开柜，仍不能碰尸骨，却能看见权力如何把证物变成交换物。

子时，罗衍来报，日落前交出的目录在功簿院副本中被添了一行无笔压字：“北镇已同意院方接管全部原件。”字迹只落在复本边角，没有人认领。秦衡立刻把副本封入袋中，指出原件目录的真实笔压与无笔压字并不相连。

贺停舟命人把药车从旧渡牵回北镇外仓，先按伤员急需开一箱止血粉，由三名本人见证人签字；其余药粮继续封车。这样既没有把药车视为军令接收，也没有让保全令替伤员选择。卫岑副使接受临时方案，却要求北镇明晨给出正式损耗账。

陆昭看着城门上两盏灯。一盏照着药车，一盏照着审计板，光线没有重叠。内斗没有结束，但北镇至少保住了把“救人”和“认功”拆开的机会。

药车进外仓前，许青棠要求先开最上层止血粉箱。车夫本人同意由她检查封签，却拒绝让任何人把开箱写成“西关已交粮”。箱内药包按三日分格，每格都有药师笔压和配方号，没有曹弥或旧功单字样。她取出一小包作盐分样本，余下药包重新封蜡，由车夫、北镇医官和贺停舟三人分别按印。这样的验收只证明药物到达，不证明军令或功劳完成。

顾衡仍不满意，他认为只要药车在城内，北镇就应当承担全部保管责任。贺停舟要求他先列出温度、损耗和换药时刻，顾衡写完后发现每一项都需要别人的选择：伤员选择何时换药，医官选择如何分配，车夫选择何时交接。陆昭在旁听席提醒，责任可以分担，接收却不能由人群自动合成。顾衡最终在账上补写“待本人确认”，承认这不是一句官印能替换的词。

罗衍把无笔压添字的副本与真实目录放在不同的木架上，分别记录纸张厚度、折痕方向和风干时刻。两份纸在同一盏灯下呈现出不同的反光，添字所在位置还有一层微薄蜡膜。许青棠判定蜡膜不是药车封蜡，但建议等盐分复核后再判断来源。内斗没有因此平息，却让每个人看到异常纸面也能被拆成材料问题，而不必先归给某个敌人。

镇诡司内斗时，韩六和顾衡各自拿出旧账，证明对方曾延误一刻。贺停舟要求先分清账上的时间、现场的时间和口述的时间，再讨论谁该担责。陆昭把争执中出现的每个姓名交给本人确认，拒绝把听来的辱骂列入审计事实。许青棠负责伤情，顾衡负责粮耗，二人不因站在同一边就共享对方的证词。

秦衡把日落前目录的回执递给贺停舟，回执上明确写着“仅收证物类别与时限，不收姓名、家属选择及功劳结论”。贺停舟让罗衍逐字念给药车夫听，车夫确认这份边界不会把自己的验车按印延伸成军需接收，才在见证栏签名。北镇内部第一次用同一份纸同时保护药物和拒绝代记，争执仍在，规则却留下了可以追溯的形状。

药车夫离开前又提出一个细节：西关车轴在第三台外曾换过一枚木楔，换楔人只报了姓氏，未报完整军籍。贺停舟没有把这条口述接到第三台案卷，而是让车夫本人选择是否留下路线见闻。车夫愿意保留旧渡和外仓两处站位，拒绝公开同伴姓名；秦衡给他编了单独的见闻号，许青棠在医案旁写明“路线可复问，身份不代认”。这条信息只扩大了复核范围，没有补齐任何功簿步骤。

车夫补充，换下的木楔没有带回车上，而是被放在第三台外侧的石缝。卫岑想派人去取，贺停舟先问谁愿意承接夜路失温和原位保护。车夫本人只同意说明放置处，不愿再随队返回；一名城防卒愿意去取，却拒绝替车夫确认木楔用途。于是秦衡把“放置处”列为可复核见闻，把“木楔是否参与接台”列为独立待验。陆昭记下两者不可互换，黑簿没有因此多出任何白线。
