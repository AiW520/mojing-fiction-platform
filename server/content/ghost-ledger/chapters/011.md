# 第十一章 借来的听骨

尸体被抬回黑水驿时，天已经黑透。

死者是个二十七八岁的驿卒，脸朝下，背上压着一只破麻袋。麻袋没有粮，内壁却粘着青石粉和黑砂。许青棠先检查颈侧和口鼻，确认没有明显冻死迹象；尸体右臂向前伸，手指缠着一截黑麻绳，绳端打着三道半结。

陆昭站在验尸台外，没有立即触骨。他先让药童记录尸体从北道沟底到停尸棚的搬运者、时刻和换手位置。若搬运改变了骨骼受力，听骨看到的就可能是抬尸动作，而非死者最后一次动作。韩六把每次抬起和落下写在纸上，贺停舟在旁边用木杖压住纸角，防止风把记录吹走。

停尸棚地面被分成四格，北墙一格、门边一格、验尸台两格。陈骁进棚时先放在北墙，后来由两名驿卒抬到门边，最后才由陆昭和韩六抬上台。每次移动都留有脚印，陆昭让药童在脚印旁插纸签，标明“搬运痕，不是死者痕”。许青棠还检查麻袋是否在三次搬运中滑过尸体背部，发现麻袋边缘确实擦到右肩，却没有接触掌骨。

死者衣领里夹着半张军令，墨迹被血和雪水泡开，只剩“北门旧渡”“七袋”“不入仓”几个字。许青棠不让陆昭自己解释字面，只把纸张交给记功吏封存。字迹的压痕与第十章半焦路令不同，笔锋更重，纸纤维却相同。

她先在衣领外层拍下纸张位置，再用木片撑开缝隙，把半张军令连同缝线一并取出。缝线是普通灰麻，与黑麻绳不同；纸背却有一层薄薄的蜡，蜡面压着两个小孔。许青棠说这说明军令曾被别针或细钉固定在衣物上，不能证明陈骁亲自读过。陆昭把“携带”与“知情”分开写，免得死者身上的文书替他承担活人的意思。

“驿卒是谁？”陆昭问。

韩六认出腰牌上的名字：“陈骁，北镇旧渡的换马卒。三年前父亲死在雪线外，他接了驿路的差事。”

陈骁的姐姐被请到驿厅。她先问尸体能否由自己验看，再问能否把弟弟的腰牌取走。陆昭逐条答：她可以在医官陪同下确认衣物、腰牌和伤痕；腰牌需留在证物柜，待身份记录完成才可取回；她可以拒绝让弟弟的骨骼用于技艺判断。姐姐沉默很久，最后说：“若能知道他最后是往哪边拉绳，我愿意让你看，但不许把他的名字写成军功。”

许青棠把这句话照录，请姐姐在“同意限定为最后受力方向，不等于认领军令、不等于接受功劳”一栏按手印。四步中的“本人选择”因此被明确，但陈骁的未竟之事仍不清楚。陆昭先验尸：颈部无勒痕，左肋有两道压伤，右膝外侧擦破，掌心被麻绳磨出新血痕；死亡时间约在昨夜戌时至子时之间。

他翻开陈骁的右手，发现指骨没有明显新裂。若要使用听骨，只能读取最后一次受力方向，不能判断死因、绳子主人或军令真伪。许青棠再次问姐姐是否确认，姐姐点头，却补了一句：“我只要一个方向，若你看不清，便说看不清。”

为了避免把第一次触骨当成结论，陆昭先用一截无主的旧指骨做空试。那截骨头来自义冢，受力记录不全，听骨没有反应，只让他感到一阵散乱的麻意。这个结果说明技艺不是碰到骨头便会给答案，也提醒他不能用陈骁的骨头反复试验。许青棠把空试的时间和接触部位写在伤情单上，姐姐看过后才允许正式触骨。

陆昭把左手绳结交给韩六保管，改用右手触碰陈骁掌骨。骨纹沿拇指旧茧爬起的一刻，他听见的不是声音，而是一阵从腕骨向肩侧推开的闷震。右掌最后一次受力不是向河沟下方，而是向北门方向横拉；拉力中途突然减弱，像绳子被另一端割断。

他立刻松手，眼前的验尸台短暂变成两张：一张摆着陈骁的右手，一张摆着陈砾的右掌。两只手的骨节位置互相叠在一起，陆昭险些把陈骁叫成陈砾。

许青棠按住他的肩：“先说代价。”

陆昭闭眼数到十，才回答：“左手仍失痛，刚才出现一息错认。陈骁最后受力向北门横拉，随后绳力中断。只到这里。”

贺停舟问他能否确认是黑麻绳。陆昭说不能；骨头只给方向，绳子的颜色、材质和另一端是谁，都需要实物与口供。陈骁姐姐听完，要求把“向北门横拉”写在验尸记录上，把“不能确认黑麻绳”写在同一行，不许只抄前半句。

许青棠照她的要求改写。她又检查陈骁掌心的绳痕，发现三道半结留下的压痕与陆昭看到的“突然中断”相合，却不能据此推出割绳工具。药童从衣领纸张上取下一粒青石粉，和第十章车板擦痕放在两张玻璃片上，颗粒大小接近，仍需北门磨石对照。

陈骁姐姐在确认尸体身份后，取走腰牌，却拒绝领取那半张军令：“我弟弟的东西我认，军令上的话我不认。谁写的，让谁来领。”

功簿没有翻页。它只在陈骁名下留下一道未闭的细线：死者身份已确认，最后受力方向已有两类证据，相关活人选择也已留下，但未竟之事和责任对象仍不完整。陆昭没有把陈骁的方向硬接到陈砾的粮案上。

夜半，周槐被押到验尸棚外辨认陈骁腰牌。周槐说自己见过陈骁，三日前陈骁曾问北门旧片为何被回收。这个口供让旧片与驿卒的联系更近一步，却没有解释陈骁为何在七袋粮车旁死去。押送周槐的守卒催他签认，陆昭要求先写“见过腰牌，不确认死者最后任务”，守卒不耐烦，但庞复核官的记功吏在场，只能照写。

陈骁右手的三道绳痕被分为三份：一份随尸体封存，一份交许青棠做伤情比对，一份由陆昭带回功簿旁，不作结算凭证。黑麻绳仍在北道现场，不能因为尸体掌心有痕便把两者合并。

天将亮时，陆昭的左手终于恢复一点温度，却仍没有痛感。他试着捏住铜钱，能感到边缘，却不知道自己用力过重，直到铜钱在掌中弯出一道白痕。许青棠把铜钱拿走，告诉他恢复不是一刻钟内忽然完成，而是从分不清冷热到能感到温度，再到疼痛回来，必须逐段记录。

她用温热的药包、凉水和无锋木片各触一下陆昭左右手，让他分别说出“能感到”“能分辨”“能否判断危险”。右手三项都能回答，左手只能回答前两项，最后一项仍是空白。她要求他在下一次睡前、起床后和日落前各复测一次，并把结果交给她保管。陆昭嫌这些记录比粮道图还细，许青棠说正因他习惯记路，才更容易误以为身体也会自动记住危险。

陈骁姐姐听见这段话，主动问能否把弟弟的尸体暂存一夜再送义冢。她想等北镇回执，确认半张军令不会被抄成“陈骁领功”。陆昭说明停尸棚只能保温到明日午前，若她愿意，许青棠可以在场见证二次验看；姐姐选择暂存，并在保管栏写下自己的期限。这个选择没有让功簿前进，却让死者的尸体不被官署用时间替她决定。

暂存前，许青棠又把停尸棚的温度记在三处：门缝、验尸台下和尸袋肩侧。门缝最低，肩侧因炭盆余温高出两分。她让姐姐亲自选择尸袋摆放位置，并把选择写成“保温优先，不改变验尸顺序”。药童负责添炭，韩六负责看门，陆昭只负责记录交接。若夜里有人要求提前移动尸体，必须由姐姐、医官和保管人三方重新签认。这个小小的分拆让尸体不再只是等待官署处理的物件，也让“暂存”有了可追问的边界。

黑簿在陈骁名下写下最后一句：

“借来的听骨，不替死者认军令。”

陆昭把听骨借来的边界写在验尸台旁：只读最后一次受力，不读死者的记忆，不读活人的心。许青棠要求他先让另一名医官复量骨裂，再接触任何新增尸骨；他同意将听骨使用次数、触碰部位和失痛时刻列入专页。韩六觉得这样像给一把刀写说明，陆昭答，刀若不写边界，握刀的人迟早会把责任也切开。

窗外北门的铜铃响了一声。陆昭望向风雪，知道陈骁留下的方向把他们带向旧渡，也可能把他们带向一个专门等着他们追过去的人。

封棚前，许青棠又让三名在场人分别复述搬运顺序。韩六记得第一次由北墙抬到门边，药童只记得自己插纸签的时刻，贺停舟只确认门边到验尸台的落点，三段口供没有被拼成一条超过本人见闻的完整路线。陆昭把每段之间的空白留在图上，注明“无人承接”，不让路线图看起来比证据更完整。

陈骁姐姐要求看一眼封袋编号，确认腰牌、军令和绳痕没有被放进同一袋。她逐袋念出物件名称，又主动指出自己没看见军令书写、黑麻绳来源和北门旧渡现场。记功吏把这些“未见”与她的身份确认分栏，她随后选择在明日午前再来一次，不接受任何人代领军令或代签送葬。这个期限由她本人提出，保管人只能按时提醒，不能因过期替她作决定。

陆昭临离棚时，药童将温度复测单递到他右手。他先慢读三遍，仍把“肩侧高两分”错听成“门缝高两分”，便在纸上留下更正号，要求由许青棠复读后再封存。失痛没有被解释成技艺损耗，也没有被写成伤情已经恢复。黑簿那道细线继续停在未竟之事一栏，任何人都不能借一个清楚的受力方向跨过后面的责任。
