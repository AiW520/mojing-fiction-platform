# 第六十九章 诡潮入河

第三镇的急报在第二镇风停后的辰时抵达。送信的水脚只带来半截湿木牌和一只裂口船铃，报文上写着“河水倒行，三渡断航，四十七户待救”。他承认自己没有到过三渡，只在上游驿棚听见船夫转述；湿木牌是从河滩捡来的，裂口船铃属于一条失踪的摆渡船，均不能替第三镇确认死亡人数。

司空烬在皇城回文中要求第三镇先做水位、风向、船数和本人选择四项记录。许青棠把报文送进复核署，提醒陆昭：第二镇的青白砂、粮袋和铁环不得带去第三镇比对成同源证据，最多作为格式参照。陆昭站在回传台外，听见“河水倒行”时没有下结论，只让文吏抄出报文到达时刻、送信人亲见范围和未填栏。

卫岑决定派一支小艇队沿北线河道前往第三镇。队伍只有一艘平底测水船、两名水卒、一名药吏和一名记录吏，另配四名负责岸上撤离的巡骑。顾衡拒绝从第二镇调走剩余粮车，只拨给第三镇两日干粮和一日灯油，注明由第三镇本人签领；第二镇的半日粮车继续按原表执行，不因新报文自动改写。

出发前，卫岑把第二镇的井口封线、九名未归者搜寻和无名尸遮棚分别交给守门人、两名步卒与阮遐。三人只接本镇事务，不接第三镇河灾。陆昭因错认刚发作过，本不在出行名册里；他申请随行仍只作事实观察，须由记录吏每两刻复述路线，若再次错认立即留在岸上。卫岑在文书上写明这项限制，才准他登船。

船队到达第三镇外渡时，河水已经漫过第一道石阶。水面上漂着三只空木盆、一段断桨和许多白色芦花，水流却朝上游缓慢移动。水卒先用染红的麻线投测，发现水面流向与河底流向不同：浮物向北，沉入半尺的木片向南。两种方向同时存在，不能简单写成“河水倒行”。记录吏将水深、风力和投测时间分开记下。

渡口的老船夫贺勉愿意承接自己看见的船数。他说昨夜有五条渡船离岸，三条回到南汊，两条没有回来；他不愿把两条船写成沉没，因为没有看见翻船、落水或遗物。镇上的巡河册却记着“七船未归”，其中两条船名被墨水涂去。贺勉只同意把自己的听见和看见列为见闻，不接受巡河册上的七船结论。

药吏在第一道石阶上发现一层细黑泥，泥面压着三种不同鞋底：草鞋、军靴和船工赤脚。黑泥只覆盖昨夜水位以下部分，不能推断鞋印主人是否被水卷走。巡骑沿岸寻找个人物件，先找到一只刻“陆”的木碗和半枚铜钱；附近没有尸体，木碗的主人也无人确认。记录吏把物件封存，不放入失踪船工的索引袋。

午时，第三镇镇医带来两名受伤水卒。他们在上游石滩被回流撞翻，手臂有擦伤，均愿意承接自己的伤情和落水位置，不愿确认河里是否有妖。镇医报告水卒伤口沾有白色细砂，砂粒形状与第二镇青白砂不同，颜色相似不能并案。许青棠远程复核后要求把两地砂样分柜，标明采集水域、时刻和取样人。

船队沿南汊行至半里，发现一条摆渡船倒扣在芦苇间。船底没有破洞，缆绳却被从内侧割断，断面平齐，木桩上留着三道新鲜刮痕。船舱里有一只湿布包，内装三张未写完的渡船名册和一枚铜哨。水卒愿意承担翻船取证，船主的弟弟只愿承认布包是哥哥常用物，不愿确认哥哥已经死亡。

翻船时，两名水卒先将船尾用普通缆绳系在岸桩上，再用木尺测量舱内积水。船主的弟弟可以选择只在岸上看布包开封，他没有义务下水证明哥哥的去向。记录吏把这一选择写进封签背面，另记船底无破洞、缆绳内割和水位不高三项事实。这样即便有人后来声称翻船就是溺亡，也能找到相反的现场依据。

陆昭不能触碰船骨，只在岸上听记录吏朗读证物。名册第一张列五条船，第二张列七条，第三张只剩半行空格。三张纸的墨色相近，但折痕方向不同；“七船未归”可能来自第二张草记，也可能是后来添写。船底刮痕与黑泥鞋印没有直接接触，不能把割缆者认成某一名船工。

河面突然升起一条窄水脊，像有人从水下推着河水向上游。四名巡骑准备拉船靠岸，卫岑先要求他们各自选择负责拉绳、固定桩和记录水位，不许一人把所有动作写成“救船”。水卒用普通木桩固定测水船，水脊撞过船舷后散开，露出一串沉在水下的空陶罐。陶罐上没有姓名，罐口封着黑蜡，内里全是河沙。

封蜡被分柜后，镇医发现黑蜡中混有细小的植物茎，和第三镇河岸芦苇相似，但尚未完成熔点和接触顺序比对。黑蜡没有功簿院印，也不能证明陶罐属于失踪船队。记录吏把陶罐数量、位置和水脊出现时刻写在异常栏，明确不写“河妖吐罐”。

下午，第四镇边界的南汊村送来四名自愿撤离者。村民说昨夜听见河里有人喊自己的小名，随后家中水缸全部朝上游倾斜。四人只愿记录自己听见声音和看见水缸，不愿确认声音来自活人，也不愿把其他住户写进失踪名单。巡骑按户登记愿意撤离者，留守者另列，不用“河潮入村”替他们作选择。

南汊村行政属第四镇，受第三镇河水影响，但第四镇此前报来的“村民失名”尚未由现场证实。卫岑只让巡骑记录村界碑、河堤高度和四名撤离者的本人选择，不把河中陶罐送进村里的证物柜。第四镇镇尉另派文吏来接手户籍与门牌，接手时辰晚于第三镇船队的水位记录，两条证据链自此各自编号。

第三镇的河道在酉时恢复普通流向。五条渡船里，三条已在南汊找到，船工本人各自回报；两条仍失踪，船主家属只确认最后出船时刻。七船未归被拆回两船待核，和第二镇二十八人、九名未归者没有数字关系。第三镇急报因此只确认水流出现双向、两船失踪、四十七户待救中的十九户愿意撤离，妖物身份和死者数量均未确认。

许青棠的复核意见在夜前送到：船底内割缆、黑泥鞋印、未完名册、黑蜡陶罐和白色砂粒属于五类证物，尚未形成同一因果链。她要求第三镇保留两名船工家属的拒绝选择，并将受伤水卒的落水见闻与船主生死分开。阮遐在第二镇药房回传，确认第二镇伤员没有新增重伤，不能因为第三镇河灾改变用药顺序。

陆昭把第三镇回传写进九镇总表，却在表头另加一行“河道独立案”。他没有把河水双向流动解释成关妖残响，也没有把黑蜡、白砂和第二镇证物并案。左手失痛仍在，浅裂没有重新出血；听见水下陶罐碰撞时，错认风险短暂升高，他便让记录吏代为复述水位数字。

夜宿渡口，失踪摆渡船的裂口船铃忽然在空船棚里响了一声。贺勉愿意承接铃声出现的时刻，不愿承接铃声来自失踪船工。卫岑封住船棚，只让两名本人选择的见证者明日开门。河水恢复向下流，河滩仍留着两条被水冲直的缆绳，像有人把一条断航拆成了两种方向。

第三镇河面出现双向流后，水卒先测水温、流速和风向，再决定是否靠近裂口船。两条待核船被编号而非命名，三张未完名册不合并。黑蜡陶罐由船户和文吏共同封存，内侧割缆绳则由水卒单独承接取样；任何人不能以铃声方向替船工报死。陆昭把第三镇回传与第二镇风沟分柜，形态相似的黑蜡和青白砂暂不并案。

第三镇暂时保住了渡口和愿意撤离的人，却留下两条失踪船、三张未完名册、四只黑蜡陶罐和一段内侧割断的缆绳。诡潮的第一层证据落在水与物之间，没人能用一声铃替船工报功，也没人能用“倒行”二字替河流宣布主人。

水卒把两条待核船的缆绳分别放在干燥架和原水边，记录温度、湿度和绳纤维收缩。船主家属只选择确认最后出船时刻，不选择确认船工是否仍在船上；水卒不能把家属的时刻证明扩写成死亡证明。黑蜡陶罐由船户本人封口，文吏只负责编号，若封蜡再次裂开，必须由原封人或其指定见证者到场。

双向水流的第二次复测在不同风向下进行。第一次由南向北，两刻后转为向下，水卒把风向、潮差和闸门开度列成三项变量，没有把“倒行”写成妖物动作。陆昭看到回传上的“主人”二字时出现短暂错认，便要求删去该词，改为“船只所属待核”。记录吏虽觉麻烦，仍按他的选择留下原字、更正号和更正时刻。

渡口医棚还接收了一名被缆绳擦伤的水卒。水卒愿意让医官记录伤口，不愿把伤口解释成失踪船工的反噬。他选择继续提供两次水位见闻，但拒绝夜间再次下水。卫岑为他安排替班，替班人只承接接班后的水位测量，不能把旧见闻顺手接成同一人的连续观察。救伤与查船因此同时进行，却没有牺牲本人选择。
