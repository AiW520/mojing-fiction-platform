# 第九十九章 功簿归还

试行令落印后的第七日，九镇把各自的分簿副本送回北镇验物厅。送来的不是一摞可以并入总柜的功名册，而是按四栏拆开的薄册、原件位置图、封签拓样和一份仍留空的争议栏。驿骑在门外排成三列，第一列报送达时辰，第二列交接封袋，第三列只负责把退回单带走。司空烬让秦衡逐一核对，任何一镇多写一页、少写一页，都先记为页数差，不把差额抹平。

陆昭持着临时铜牌站在桌边。铜牌背面的“复读、反证、限责”已经被雪水磨得发亮，正面仍没有品秩。司空烬把一张退牌文书推给他：“试行期内，你可以继续用它要求重读，却不能把它带进三钥柜。今天要先决定，是归还，还是把使用范围延长到下一轮。”

陆昭没有马上答。他先叫来两名见证人，一名是北镇档吏，一名是九镇轮值复核人。两人分别读出铜牌编号、领用日期、领用人、允许场所和禁止事项。档吏把“可进入原件存放外廊”读成“可进入原件存放柜”，陆昭按住他的笔，要求重读原文。第二遍确认后，错听被写进更正栏，原句保留，不能只留下改后的漂亮版本。

九镇文吏随后把自己带来的薄册一一摊开。第一镇的伤药实耗与护送迟延分成两页，药车夫的姓名只在“本人承接”栏出现一次；第二镇的八名待搜仍以编号列出，三名已经回城者附有独立回执，不被并入搜寻完成；第三镇的两船记录了缆绳、铃声和水位，却没有把船工写成死者。第四镇的临时称呼、第五镇空缺的烽台、第六镇迟到的封袋，均各自留有拒绝、未询问和待补证的字样。

秦衡建议将九镇副本全部收入院方总档，以便将来查阅。司空烬问：“总档能保管，能不能替原地回答？”秦衡说不能。司空烬又问：“总档能标出哪一页有争议，能不能替本人说同意？”秦衡沉默片刻，改口建议设立索引柜，只收编号、封签拓样和复核方法，原件仍归各镇。索引柜由三名轮值人共管，院方只占一席；调阅留下理由和归还日，不许抄去活人的拒绝范围。

陆昭听完，把铜牌放到索引柜外的白布上：“若我继续持牌，别人会把我的复读当成院方认可；若我现在归还，已经登记的反证又可能无人追问。”许青棠从皇城发来的复核署函件正好送到。函件写明，牌可以归还，但牌上已经产生的复读记录、错听更正和拒绝越界记录必须留在独立复核署，不能随牌一同消失。她还补了一句：伤情与制度记录要分柜，免得后任把反噬写成失职，或把失职写成反噬。

司空烬让陆昭再读一遍函件。陆昭读到“归还”时，左手指腹一阵麻，险些把“独立”看成“统一”。他停下，交给许青棠的远程见证人复读。对方逐字核回，陆昭在旁边写下自己的错认时刻、休息时长和更正人。没有人因他仍能把句子读完，就把反噬写成痊愈。药吏照旧拆下掌心布条，浅裂边缘泛红，便让他今日不再誊第二份目录。

午后，三钥柜外廊举行归还仪式。仪式没有鼓乐，只有三把钥匙的持有人、两名复核见证和一名记录人。黑簿原册仍在柜内，柜门没有打开。贺停舟在北镇守着第一把钥匙，另两把钥匙分别由司空烬和本地档吏保管，三人只核对封签重量与柜号，不触内页。陆昭把自己此前申请查看原册的撤回文书放入外廊档袋，确认这次归还不等于批准他查阅，也不等于承认黑簿归院方所有。

第九镇来了异议文书。狭签本镇保管人提出，既然索引柜可收拓样，北镇复核人须在样本旁标明“受压先后不明”；北镇锁匠随即写下同意标注，但拒绝把第九镇木屑和旧棚木架屑判为同源。鉴材师把此前盲验的陶片编号重新核了一遍，发现陶片包装蜡封有一处浅裂。裂纹没有贯穿袋口，却足够让人质疑保存条件。他没有重做一次来覆盖旧结果，而是将旧结果保留为“封存后状态待核”，另约定在两镇各自取同批榫板前，不得拿木屑差异写入身份推断。

秦衡提出先借北镇木架作对照，锁匠立刻指出木架已受潮，取一片下来便会改变支梁受力。两人来到旧棚外，只隔白线看木匠用尺量榫脚；榫脚偏斜两分，仍在今日可守范围内，却不能为了一张索引毁掉支撑。第九镇文吏隔着驿骑传回本镇榫板存量：同批只余一段，另一段已补进民房门框，住户尚未被询问。司空烬在申请栏写“不得以核验为由擅拆”，把下一步交给住户选择与工匠安全复测，而不是以掌院身份发一道拆门令。

旧棚传来水尺单，第一基准桩的泥线又高了一分。卫岑没有为了赶上归还仪式撤走守梁人，反叫木匠复量梁脚并保留夜班。顾衡核出多耗半桶火油和两班干砂，司空烬签下院方补给；义冢守人签下现场通行限制。两份签押都写明只护遗存原位，不承认遗存身份。第九镇文吏看到单据，终于把狭签影像的复核期限从“今日”改为“待原地条件满足”，不让远方的时钟压过危墙下的安全。

有人问，既然铜牌能让人拒绝越界，为何不把它铸成正式官印。司空烬回答：“官印会让别人把拒绝当成命令。牌只能让一句话多一次复读，不能替活人拒绝，也不能替死人提出愿望。”他说完，亲自把铜牌交回牌房，并在领用册上写明归还时刻。牌房吏想把使用者一栏改成“镇诡司”，司空烬让他保留陆昭的名字，另加机构承接栏，避免个人责任被机构吞掉。

九镇副本随后分别退回。每个封袋都附一张退回清单：原件是否随袋、影像是否完整、拓样能否重做、异议是否保留、下一次复核由谁申请。第九镇狭签没有离开本地，北镇旧棚前臂人骨没有被运走，第二镇八名待搜的路线图和第三镇两船的缆绳数据也没有被中央索引改成一项功。归还不是把问题送回黑暗，而是把能够被追问的东西送回原地。

天黑前，司空烬在试行令末页补写一条：凡归还之物，须同时归还其异议、拒绝和未询问状态；缺页先记缺页，不得用总档副本补成完整。秦衡问这条是否会让案卷变厚，司空烬说：“厚一点，至少知道哪一处薄得不该。”他让轮值人把此条送到九镇，任何一镇若认为院方退回不全，可以在七日公示栏下提出具体页号，而不是整镇重填。

第二镇驿骑要走时，发现本镇搜寻图的角上少了复测人签名。他不敢代签，转身去找文吏。文吏核过原图，确认那一角在湿布下洇开，姓名并非被人故意裁去，于是另附一张当日见证单，把能证明的路线、不能证明的去向分别写清。耽搁的一刻钟由院方出驿粮，不扣搜寻队的口粮。第三镇水卒也补报两只铃的封袋重量各差一钱：袋布一干一湿，暂不判铃有增损，只定下同湿度重称的时刻。退回仍要退，缺口也须一起走。

陆昭在白布旁看这些小事，明白“归还”比“没收”更难。没收只需一纸命令，归还却要知道原物在哪里、谁有权收、路上改变了什么。院方曾想把这三件事压进一个“已交”印格，如今每格都要有人署名。他不能再凭旧日收尸役的敏捷替一整镇补空格，左手连握笔半刻都疼不出警告；药吏守着更漏，到时便把笔从他面前收走。

功簿归还日，九镇副本按原地退回，索引柜只收编号、影像和拓样。狭签、人骨、搜寻图和缆绳数据没有被中央索引改成一项功；异议、拒绝、未询问也随退回清单同行。临时铜牌归还牌房，错听更正与越界记录留独立复核署。陆昭不进入三钥柜，黑簿原册封签和重量不变，归还不是删除责任。

陆昭收起自己的伤情簿，最后看了一眼已经空下的牌房架子。功簿四步仍没有闭合，黑簿没有翻页，旧门、缺联、人骨、狭签和未归者仍各有自己的柜门。可这一次，归还没有把责任归还给一个人，而是把证物、选择和后果分回它们真正发生的地方。

归还清单送到北镇时，贺停舟发现第三镇影像的封签号在副本上少了一笔。他没有凭记忆补全，而是让第三镇文吏把原回执的拓样和发出时刻一同传来。两地暂以“编号不全”登记，缆绳数据继续按原袋保管。补传耗去一匹驿马和半日路程，司空烬在院方账上签下费用；归还不是把每个缺口都立刻补平，而是让缺口本身能被追问。

陆昭最后一次复读归还目录时，左手握笔不到半刻便失去疼感。药吏按约收走笔，让他改为口述，另一名文吏记录并由第三人复读。陆昭承认自己想把“责任分回原地”写成一句结论，却被提醒这只是制度动作，不代表原地已经找到死者或完成选择。他在更正栏补上“仍待证”，这三个字没有让归还变慢，却阻止一册副本把未结之功偷偷写成已结。

复议日期仍按原约保留。各镇收到通知后，只确认日期、递送人和本镇见证，不预填复议结论。若新证据在日期前到达，仍须按原件保管、两类证据、本人选择和后果承接逐项登记；若没有新证据，会议也只能复核缺项，不得把等待本身写成同意。归还的柜门暂时合上，追问的路并未合上，责任也没有被封死；各镇仍按既定期限回报。未改结论。
