# 第五十七章 旧案重算

黑账拆开后的第二天，贺停舟在第七仓门外摆了四张案几。第一张放乙巳年的旧功单，第二张放三户撤民簿，第三张放西关回执与黑账拓样，第四张空着，专供活人更正。案几之间留一丈空地，谁也不能把相邻的纸推成一叠。司空烬坐在中门，掌院印留在匣里，只叫秦衡报各件原纸的封号。

陆昭照停职令坐在白线外。他能听、能提出事实异议，不能开柜、移纸或盖印。左掌裹着薄布，裂口没有痛感；许青棠先让他看三个封号，他把第三个读成了前一号，随即停下，请罗衍复核。她在医案上如实添一笔，没让这次错认替他先定整场听证的输赢。

第三方牙医先到，带来两份遮名齿图。一份由许青棠和阮遐在无名尸上各自绘成，一份是曹弥叔父获准调出的北坡旧医簿。两人分别比对缺齿位置、齿根磨耗与旧补片，不看木牌和黑账姓名。尸体右下第二臼齿有生前拔除后的平整骨缘，旧医簿却记曹弥同齿尚在，且左上缺一颗门齿。浸水会使齿面变色，不会凭空长回门齿。牙医在两名医官见证下给出结论：现有齿证反对把水渠尸体认作曹弥。

曹弥叔父看了遮名图，承认自己记得侄子的刀疤，却没记住这颗牙。他撤回“旧疤足以辨认”的意见，只保留“曾见曹弥带回无编号木箱”的家属见闻。许青棠将尸体柜外的“曹弥候选”改为“水渠无名尸”，原候选记录没有涂掉，划线、日期、撤回人和反证位置全留在旁边。司空烬也令院吏更正副本，不得把家属撤回解释成家属拒认这具尸体的一切经历。

贺停舟盯着那枚半字木牌：“若不是曹弥，谁把牌系在他腰上？”

“还不知道。”许青棠答，“只能先查系绳的磨痕、浸水先后和木牌削口。尸体仍是死者，但姓名和未竟之事都没有得到。”

第一层身份被排除，旧功案反而清楚了一点：不能再用一具刚发现的尸体，替十余年前失踪的军需官补上死亡。陆昭在白线外把这条反证报给罗衍，罗衍亲笔写进第四张案几的更正栏。黑簿没有动静，听证也没有因一项排除而终止。

司空烬让贺停舟逐项读旧功单。“封北门三日”，有城防轮值、门轴油痕记录及贺停舟本人印，三类材料时序相合，可认定动作发生；但三日内每个时辰是否都封死，轮值有两段换岗空白，必须限写。第二项“三户撤民已成”，只有一户的指印落在避雪日期外沿，第二户邻里代写“暂避”，第三户整栏被撕，既不能算三户本人同意，也不能据此说三户未被救。第三项“粮道已验”，西关回执写“本人已验，暂不入功”，黑账却写“验过，未交”和“空栏不得结功”，接收人均无完整签押。

贺停舟自己把三项写成三行。第一行改“北门曾按令封闭，缺两段轮值时刻”；第二行改“撤民行动发生，三户本人接收范围待核”；第三行改“粮经查验的材料存在，交付与功劳接收未证”。他在旧功单边上盖了一枚“重算待核”的小印，没有用自己的主签印再压一次。司空烬检查措辞后同意，要求把失去的功勋粮额算进追偿账，不能只靠一个改字免去当年的资源占用。

顾衡报出旧账：乙巳年那笔“已成”功曾支出城防煤六车、粮七袋，后来又从北镇别仓补过七袋。煤车有领票，七袋补粮只有库门出入时刻，没有接收人的手押。贺停舟承认自己的印让煤和粮能出仓，愿把可证的六车煤记作本人调拨责任；那七袋粮却不能算到三户头上，得查实际去处与经手人。司空烬把追偿分成已用资源和去向不明资源两册，不让院中一纸罚单把失踪者写成欠粮人。

一名自称第一户后人的妇人走到右门。她带了当年的避雪木牌和一张后来领到的柴票，愿意说明一家确曾进内城住过两夜；至于户籍转入，她母亲生前从未提起，她不肯替母亲承认。柴票的纸和旧簿指印来自不同来源，足以支持避雪行为，却不能填补母亲的接收选择。贺停舟向她致歉，妇人只让秦衡记下这句话，不把道歉换成任何功劳。

第二户的邻里已迁往镇南，只来了一封真印回函：代写者承认“暂避”是自己当年按妇人口述写的，妇人是否到达内城，他没有亲眼看见。司空烬让镇南保留原函，北镇仅留副本；他也不把这一份有限口供算作第二户本人授权。第三户仍无人到场，被撕栏的麻纤维与黑账撕口方向近似，断面却缺失，两件纸未被拼成一页。

陆昭提出一项异议：“重算的是旧功单，不是给一具新尸安排功劳。第一户能证明避雪，不能替另两户证明；曹弥的回执有全名，也不能替曹弥本人到场。”司空烬点头，令书吏把“重算待核”与“功簿未结”分写在不同纸上。贺停舟既没有因承认旧错就失去现有点柜职责，也没有因肯承担煤账而得到旧功归还。

接近午时，黑账第四页“空栏不得结功”下方渗出一条黑线，沿着旧功单的“已成”字爬向贺停舟的木杖。许青棠让众人离开纸面，先隔开两张案几。黑线在两纸间断了一寸，木杖上却留下一层极薄的灰。她取样后发现灰里有煤末和蜡屑，不能认定那是贺停舟旧伤反噬，也不能把黑账当施术者。

贺停舟的残腿此时确实疼了。他坐下，由医官查残端，没有新裂，只是旧疤发热。他不肯把疼痛写成洗罪的代价，仍在追偿册上亲笔承担六车煤的去向复核。秦衡把黑线出现时刻、两案几间距和残端检查分三栏记录，避免先后相邻被写成因果。

午后的重算结论宣读给所有在场人。旧功单的“三户撤民已成、粮道已验”两项从可结功栏撤出，保留真实发生的封门和有限避雪行动；已发放的功勋粮额暂入争议账，由贺停舟和院方共同追查，不向三户或无名尸追偿。司空烬在结论旁盖院印，贺停舟按自己的旧印，两个印不相互覆盖。

这是陆昭停职以来第一次看见一项旧功被公开撤出，而药车没有停，黑簿原件也没有被收走。他没有欢呼。第三户仍下落不明，曹弥仍失踪，水渠尸体依旧无名；能撤掉错误，并不等于已经找到真相。

傍晚，罗衍从旧城墙送来封诡阵的巡检板。阵眼旁原刻“乙巳撤民功成”的铜牌出现一道新裂，裂口朝向第七仓。巡检板记录的灯油耗量比前夜多了一倍，守阵卒却未添油。贺停舟让人先撤墙下住户，通知卫岑双签封路，再请阵匠检查铜牌与油槽。陆昭站在白线内侧听见远处阵铃低响，知道旧案的“已成”被撤掉后，另一套靠它运转的东西开始索要解释。

撤离名单由许青棠逐户念给住户本人听。有人同意暂住外仓，有人只同意把老人和孩子送走，仍要留下看守牲口；住户的选择被分成两栏，没有人因同意搬迁就被写成接受阵法结论。顾衡按人数重新计算热粥和柴炭，发现旧功单中多领的一车煤并未全部用于三户，至少有两车在北墙守阵时消耗。贺停舟承认这些资源去向必须从守阵轮值册追查，不能把所有缺口归入撤民功。

旧案重算时，最先被撤下的是“已替家属认领”的空泛字样。家属本人被请来选择是否看物件、是否承接称呼、是否接受后续追查。有人愿意看鞋，有人只愿意领回药袋，有人拒绝进入案册；每种选择都被保留。陆昭把过去的错误字样划掉但不覆盖原页，旁边写更正号，确保后人能看见制度如何制造了错。

重算案几上的三枚旧印分别封在透明纸袋，贺停舟只承认主签印的使用，不承认被刮去的小印是谁盖的。司空烬让院吏测印泥厚度，发现主印边缘干裂、小印痕迹被火燎过；这能证明盖印先后可能不同，却不能指出盖印人。陆昭把“印记可分、责任不可合并”写入异议栏，要求明日以原印模和当年轮值人员逐一核对。

撤项公示结束后，三户家属分别领回一件物品：一只空药袋、一枚旧门钥和一段被水泡硬的麻绳。每个人都先听记功吏读出物品来源，再选择是否把物品带回家。有人只看不拿，有人愿意保管却拒绝解释死者最后意愿，所有选择都附上时刻和见证人。陆昭没有因家属接过物品就写成“认领完成”，而是把接收范围停在物件保管栏。

守阵卒复查油槽时发现，旧功单记载的一车煤里有一部分用于夜间救火，另一部分被雪水浸坏。顾衡让两名不同班次的粮吏重新称重，浸坏煤的重量和灰烬重量分别记账，不能以“消耗”二字把两种损失压成一栏。司空烬承接院方补给解释，贺停舟承接守阵实耗，陆昭只负责把双方数字并列，不代任何一方认功。

夜深后，曹弥的旧名在撤项索引旁短暂浮出。许青棠先检查陆昭的瞳孔和左手温度，确认他没有靠听骨或触碰黑簿。索引字迹被三人盲读，一人读成“曹弥”，一人读成“曹民”，第三人只认出两个偏旁。文字在无人落笔时散开，陆昭把这次分歧列入反噬记录，也把“名字出现”与“活人确认”严格分开。
