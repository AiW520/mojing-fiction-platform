# 第六十三章 罪功同卷

皇城的车队走北线第三日，第一封催问文书在辰时送到。封套上写着“罪功同卷”，要求把三项罪名与乙巳旧功、北镇原册和复核署章程装进同一卷宗，七日内由三人共同按印。秦衡接过文书，没有立刻拆封，先让传令的驿吏报出交接地点、时刻和上一手接收人。

驿吏只知道文书从中书省外廊交到他手上，外廊当值者没有在封底留名。他愿意证明自己在北线驿站交付，不愿替外廊官员证明文书内容。司空烬让他把这项选择写进见闻栏，才准秦衡拆封。封里不是一张诏，而是三张罪名单和一张“同卷”索引。每一张罪名单后都留着一格，题名分别是事实、反证、授权、承责。

“他们要的不是你们认罪，”司空烬说，“是要把四格压成一格。只要同卷里有一项写成已结，其余三项便会被牵成同意。”

陆昭隔着车厢木栏看文书，没有伸手。他的左掌仍无痛，指缝浅裂结痂，看到“原册持有人”时，脑中短暂闪过三钥柜的黑影，几乎把眼前的罪名单错认成黑簿副页。许青棠察觉他的停顿，把文书转向秦衡，让他只听本人朗读，不让陆昭凭纸面形状判断。

第一项是拒奉诏。事实格列出第六十一章三日保全尚未届满、原册一直在北镇三钥柜、皇城诏书只要求证物目录。反证格列出保全令上“原册入院复核”的字样和司空烬签过的接管申请。授权格空着，承责格写着“待裁”。秦衡指出，申请与执行不是同一件事，格内不能把申请当成转移完成。

司空烬没有为自己辩解，只让秦衡把他的接管申请编号抄出，并补上“未取得北镇三钥持有人同意”。他承认功簿院有法统，却没有一纸口谕能让三名钥持人自动成为转交者。传令骑卒愿意见证这一条，但不愿替北镇或皇城承担原册损毁责任。

第二项是擅改旧功。罪名单把第57章旧案重算写成“地方撤销院定旧功”。陆昭听见“撤销”二字，提醒秦衡，实际记录是从可结功栏撤出三户撤民和粮道已验，并保留原功单、黑账、三户本人选择和旧印交接副本。贺停舟没有凭旧印删页，重算由盲验牙图、煤车调拨账和后人有限见闻共同触发。

许青棠从药匣取出复核署的盲验意见。水渠无名尸牙证反对认作曹弥，第一户后人只承认避雪两夜，第二户只承认听闻，第三户缺席。她把每一项证据的来源和反证位置读给传令骑卒听，随后问他是否愿意在授权格里确认“见证材料存在”，而不是确认旧功被错误撤销。骑卒同意前者，拒绝后者。秦衡依选择填写，不将拒绝写成反对重算。

司空烬看着两张罪名单，忽然要求把功簿院自己的责任也并入同卷。他让秦衡添写：院方在第49章接受“已收文、未交簿”的有限回执，在第61章驻两名见证官但未取得原册；若皇城把保全申请解释为已经接管，解释责任由提出解释的一方承担。秦衡迟疑片刻，问这是否会让掌院承认有失察。

“同卷不是同罪。”司空烬说，“罪与功若共用一格，谁的手离纸最近，谁就能把另一人的责任写成自己的功劳。把我的责任写进去，至少能看出哪一段是院方选择。”

第三项是许青棠私立复核署。罪名单称她以临时章程替代镇诡司验伤，并擅自保留姓名索引。许青棠没有否认设署，只把木板章程、器械领用、阮遐和孟岚的本人授权一一列出：复核署无定功、无调兵、无代选择；姓名索引只在内层柜，候选人可撤回；任何材料意见必须同时记来源、反证、授权范围和期限。

她还提出一条反证。第60章门外异常白纸写“代全镇验伤”，本人已经写下只接受复核台职责，不替全镇认名定功，纸面字迹才淡去。若她真想以复核署夺权，最简单的做法是把这句异常字样留下，作为全镇授权。她没有这样做，反而公开限制条件。

罪名单的授权格要求许青棠确认“复核署代表北镇”。她拒绝，只同意确认“复核署代表签署该份材料意见的本人”。秦衡把代表两字划去，改成“签署者对所列材料负责”。墨迹刚干，文书边缘浮出一条无笔压白线，沿三项罪名相互连缀。许青棠没有拔弩，先让所有人报出自己是否同意被连为一名承责者。

驿吏拒绝替中书省承责，传令骑卒只承接交付见闻，司空烬承接功簿院申请与见证，秦衡承接副本抄录，许青棠承接复核意见，陆昭承接事实异议。白线在每个名字旁停了一息，无法把五项选择合成一栏，最后断在“同卷”索引处。纸面异常留下三枚针孔，和复核署白纸的针孔不同。

第四项是陆昭本人责任。皇城要求他承认拒交原册、扰乱功制并接受功簿院暂时收回结算权。陆昭不能替黑簿选择，也没有结算权可交。他请秦衡把自己的事实写成三句：停职后未触碰原册；在白线外提出异议；因失痛和错认风险，曾主动把指挥牌交出。承责格则写“接受事实核验及停职期间的伤情复测，不接受以空栏完成结功”。

司空烬听完，问他是否愿意把“不得结功”承担成一项新责任。陆昭说愿意承担看守证物和说明边界，但这不是功簿第四步，因为尚无死者、未竟之事和活人选择。他的声音很慢，生怕把责任与结算混在一起。黑簿远在北镇，不能替他把一句愿意变成技艺。

同卷索引因此被拆成四卷：罪名事实卷、旧功重算卷、复核署授权卷、陆昭停职责任卷。四卷共用编号，不共用结论。司空烬在封面写“罪功同卷，责任分卷”，秦衡加盖副本章，许青棠在授权卷末尾注明右肩牵痛尚在，搬运和盲验由阮遐负责。她不把伤情写成免责，只把它写成调度事实。

傍晚，北镇传来贺停舟的远程复核。卫岑用旧印交接副本证明贺停舟留守，不是拒入京，而是因原印、阵灯和外仓供粮需要一名现场承责者。贺停舟本人选择留下，承接阵灯供油、外仓伤员、三钥柜封签和皇城文书回传四项，不承接陆昭罪名、不代黑簿接收任何功劳。卫岑愿意作现场见证，北镇文吏愿意作柜钥见证，复核署远程接入不改变许青棠已在京的行程。

这份回传使诏书“须三人共同入京”的命令出现事实修正。司空烬向中书省递交临时豁免申请，说明三人中的贺停舟必须留守原册和阵灯，若强行离开，皇城问罪反而会制造无人承责的北境空档。申请没有请求免罪，只请求把“入京”改为“到场或远程见证”，并列出贺停舟每日两次的固定回传时刻。

夜半，司空烬收到回批。中书省同意临时豁免三日，条件是贺停舟的四项责任不得转写为北镇全体同意，且每次回传必须留下本人选择和反证栏。回批仍没有传令者全名，司空烬把它列为来源待核，只执行其中不扩大的部分。陆昭看着四卷分开的卷宗，明白皇城暂时没有收走黑簿，却把所有人都拉进了同一张责任桌。

罪功同卷的第一页同时出现撤项和承接，陆昭坚持两者不能相抵。贺停舟的旧功被撤，今日守城实耗仍要补；司空烬的统一令有法统，延误造成的粮损仍要公开。许青棠把伤亡复核写入独立附件，不让功勋数字遮住骨折和失血。卷宗变厚的同时，责任的归属更清楚，陆昭把这看作制度第一次真正承担代价。

车队继续向南。罪名没有消失，旧功也没有恢复；但每一格都有来源、反证和愿意承担的那个人。陆昭在停职记录末尾补写：“罪可同卷，功不可代领；同卷之内，先问谁选择，再问谁受益。”他放下笔，左掌仍无痛，错认的阴影仍在，唯有这句话不需要黑簿替他证明。

入京前的最后一次交接由三名不同岗位的人完成。押车吏只核对封袋数量，医官只核对伤情附件，文吏只核对页码和更正号；三人各自拒绝在别人的栏位盖章。车轮经过冰桥时颠簸了一下，封袋没有破，但一枚副本章沾上水迹。司空烬没有补盖原章，而是另附受潮说明，写明受潮时刻、车上人数和未改变的页码。

中书省回批到达时，贺停舟的远程见证仍按时传来。他主动读出“留守不等于拒绝入京”，又补充自己不能确认皇城文书的原始笔压。司空烬把这段限制抄回批单，承接回传延误与北境守线的双重责任。陆昭只复读，不替贺停舟把远程见证换成到场签押；距离不同，责任形态也不能被一句“已到”抹平。

许青棠在车厢里为右肩换药，发现牵痛由抬臂动作引起而非伤口扩大。她选择把换药交给副医官，自己保留复读和授权决定。副医官先朗读药名、剂量和剩余包数，再请她确认是否接受，药袋上的蓝线因而没有被误写成独立复核署的印。伤情、药耗和制度权限继续各自有来源。
