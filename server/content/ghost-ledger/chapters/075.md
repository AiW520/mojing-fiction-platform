# 第七十五章 司空烬封路

司空烬的封路令在午时前后抵达皇城。

令纸一共三张，分别发往北线、东河和西关。第一张说九镇灾情尚未厘清，所有跨镇车队暂停；第二张说药粮和伤员必须由中央统一编队；第三张只写了“无本人签认者，不得擅入灾区”。三张纸都有功簿院朱印，封泥颜色却各不相同。秦衡把它们摊在伤亡复核署的长桌上，先标出封泥、递送时辰与传令骑卒的姓名，再问许青棠是否愿意让复核署收下原件。

许青棠说可以收，但只能收一份。三份封路令涉及三条不同道路，接收人、保管柜和回传时刻必须分别登记。她还要求把“不得擅入灾区”拆成两种意思：禁止未经见证的私自进入，还是连携药物、护送伤员也要停在路外。秦衡回答，司空烬要的是后一种，理由是地方互相借口救援，可能把证物和责任一起冲散。

“那就不能只写封路。”许青棠指着纸面上的一行，“封哪一段，谁承接等待，伤者在等候时由谁照看，都得有名字。否则封住的是路，留下的是没人领的后果。”

秦衡没有反驳。他带来的第二份附件里有九镇道路图，每条路旁边都标着一枚黑点。黑点不代表妖物，也不代表伤亡人数，只是中央认为可能出现异常的路段。司空烬要求九镇在一刻钟内停止跨镇往来，所有车队回到最近的关口，等统一核验。

北镇的回信比诏令更快。卫岑说城外已有三批流民候在雪沟，一批要回第三镇，一批要去第二镇取药，剩下一批只想找失散的家人。若封路，北镇能提供一日粮，却不能替他们决定去向。贺停舟在回信末尾补上四项数字：守门巡骑三十七人，药房可用止血粉六箱，实粮可供二日，三钥柜第一把钥匙的锈斑仍未解释。

司空烬看完数字，要求北镇把所有候路人送进城内，由统一文吏替他们登记。贺停舟回了一句：“入城可拆栏，不可合成一张总表。”这句话被秦衡原样抄在封路令的边栏里，标注为地方异议，不改成拒令。

下午，皇城南门出现一辆挂着白布的药车。车夫拿着第八镇急报，说车上有一箱止血粉和两名发热伤员，必须赶往第二镇。守门校尉已接到封路令，不许车辆出城。车夫承认自己没有两名伤员的姓名和本人授权，只有药房封签与一张写着“先送”的纸条。许青棠没有直接替他争门，而是让他选择三件事：留车待验，卸下药箱交由指定药吏保管，或者把伤员送入城内临时医棚。车夫选了第二项，伤员则选择留在车上，不愿被搬动。

许青棠把这个选择写入封路副册，注明药箱已交、伤员未转移、车夫只承接出发时刻。她随后给司空烬发去一封短函，问统一编队是否愿意承接两名伤员在等待期间的照看。司空烬回函很快，答复是由皇城医署接手，但未说明具体医官姓名。许青棠退回“皇城医署”四字，要求落到一名本人同意的医官。

与此同时，第二镇的阮遐发来伤情复测。九名未归者仍有三名家属拒绝将物件交出，六名家属只同意核对最后见面时刻。阮遐在药房里把麻绳擦伤、井边跌伤和粮车挤伤分成三页，写明每个人只承接自己的观察。她没有提到皇城封路，因为她不愿把“未接到上级命令”写成病人的伤因。

北镇的封路执行先从西门开始。卫岑让巡骑把雪沟里找到的白蜡木擦痕和干黑砂放回证物房，不随车队上缴。三名流民要求离城，分别选择回第三镇、留在旧驿路和等待同伴。贺停舟让每人按指印确认自己的方向，却不让他们互相替签。有人问封路令是不是要他们永远留在北镇，贺停舟答：“它只能命令道路，不能替你选择家在哪里。”

这句话传到皇城时，司空烬正看着九镇回传的第一轮数字。七镇按时封住关口，第八镇药车未出，第九镇只回了一张没有本人签名的空表。司空烬没有因为空表而下令抓人，只把第九镇列为“无法确认执行状态”，并派一名传令骑卒携两份空白责任栏前去补记。秦衡提醒他，这会让封路令慢上半日。司空烬说，慢半日比把没见过路的人写成执行者好。

夜里，第四镇南汊村传来新的消息。陆昭仍随记录队在村西，不能离开封路范围。他只负责复述，不作方向判断。村口有一名妇人拿着红布包，要求去皇城找接生婆；她的女儿小岚在梦醒后脉搏急促，却仍不愿把陌生大名写进异常样本。记录吏问是否要把妇人送往第三镇，再转皇城。陆昭只复述她的选择和道路封闭事实，没有说哪条路更安全。

妇人最后选择留在第四镇，等待接生婆能否经许可进入。她同意记录小岚的脉搏和惊惧，不同意开红布包。陆昭把“道路封闭导致等待”单独写在责任栏，不把它写成小岚梦话的原因。记录吏问是否要将此事报为封路令造成的新伤，陆昭回答：“只能报等待发生，不能替她判断等待造成了什么。”

半夜，司空烬收到三镇同一时刻的回传。北镇报告封路后仍有候路人，第二镇报告药房可用量下降，第四镇报告接生婆未到。三份回传都没有把等待写成死亡或功劳。司空烬在总表上划出一条分界线：中央承接封路命令的发布与撤回，地方承接封路期间具体看护和证物保全；若道路重新开放，仍须本人选择是否出发。

这条分界线让功簿院的统一表格出现一处空白。原本表格只有“执行人”一栏，秦衡依司空烬命令增设“等待承接人”和“拒绝条件”。他把空白栏送去各镇，要求不迟于次日卯时回传。许青棠提醒，空白栏不能逼人签名。秦衡便在栏下添注：本人可以拒绝承接，拒绝本身不构成阻路或怠职。

天将亮时，一名北镇巡骑在封闭雪沟外发现半枚铜钱。钱面刻有旧镇名，背面粘着一小片灰纸。巡骑想把铜钱交给贺停舟，贺停舟让他先写明拾得位置、手套更换和是否愿意承接转交。巡骑只承接位置和时刻，不承接铜钱主人。灰纸与皇城封路令纤维不同，铜钱也没有与任何已封存证物的共同断口。两件东西被分袋编号，未被写进妖关或粮损案。

封路令让九镇的道路安静下来，却没有让灾情停止。药箱在门内，伤员在车上，家属在雪沟边，证物留在原柜。司空烬知道集中命令无法替任何一个人完成选择，仍坚持先把路封住。他在批文末尾写下：“封路只为减小新证物流动，不为宣布旧证物已经解释。”

北镇回传最后一行由贺停舟亲自落笔：守门已承接，保柜已承接，实耗已承接，候路人的去向仍由本人选择。许青棠把这行抄进复核署总册，又在旁边加了一句：“中央封路的后果，也须由中央留下可追问的人名。”

司空烬看见这句，没有删。他让秦衡把自己的姓名写在封路令的承接栏里，另列发布时辰、撤回条件和等待医护的责任范围。秦衡问掌院是否确定要亲自承接，司空烬说：“命令能集中，后果不能藏在印里。”

司空烬封路并非为了阻止救援，而是防止多镇队伍带着不同编号进入同一现场。封路令列出例外：药粮、伤员和必要的原位保全可以通过，但必须记录门槛、路线和改变的证物。卫岑担任现场放行人，司空烬承接延误解释，许青棠的复核署承接伤情建议。陆昭把封路令的缺项标出，要求补上谁能撤回放行；没有人因持院印就能替民户承接风险。

就在承接栏合上的一刻，九镇地图上第七个黑点自行向北挪了一寸。纸面没有笔压，墨色也未改变。司空烬没有把它认作妖物移动，只让人记录发生时刻，封存地图，通知各镇不得追着黑点改道。封路仍在，救援仍要等本人选择，黑点的意义留到下一轮证物核验。

封路的第一个时辰，药车便在北镇门前遇到难题：车上有两名冻伤者，押车人持皇城通行单，却没有他们的姓名。卫岑不让伤者为过门临时认一个名字，先请药吏当场验呼吸与手指颜色。年长者愿意报姓，不愿留村址；少年只点头同意检查。卫岑在放行页分别记下两人的选择、药吏所见和车轮压过的门槛位置，药车随即进城。守门时刻晚了半刻，司空烬的封路令因这个例外添了一笔院方解释责任，但没有让两人变成失名村的证人。

地图封入匣后，秦衡又取一张空白同尺寸纸，在原桌、原灯下放了一刻钟。空纸边缘受潮卷起，墨点却不可能从纸里自己长出；这个试验只排除了灯热使整张纸滑移的解释，不能认定黑点是何物所为。陆昭要求把空纸也封存，免得日后只剩那一寸位移供人编故事。他读封签时把“第七镇”一瞬听成“第九镇”，立即停读，交给秦衡复核。司空烬没有让他以这次错听退出所有观察，却也没有让他独自复述下一份急报。
