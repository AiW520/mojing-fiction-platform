# 第二十章 许青棠的箭

西墙外的轮痕只剩半圈。

雪风一吹，轮痕边缘便开始塌陷。陆昭没有让守卒追车，而是先用木框罩住半圈痕迹，再把车辙的宽度、深度和消失点交给贺停舟。贺停舟量完后说，车轮不是抬起消失，而是被某种硬板压过，硬板宽度超过一臂，可能是临时铺路，也可能是纸片叠成的支撑。

许青棠站在西墙内侧，手里握着三支短箭。她没有看轮痕，而是看账匣锁孔伸出的那根红线。红线在白布上微微颤动，像被墙外什么东西牵着。她问陆昭能否让她截断。

“截断之后，纸妖可能换一条路。”陆昭说。

“不截断，它会继续把姓名送进匣里。”

顾衡立即反对，说红线连着旧粮单，若箭断线，可能破坏唯一的纸证。许青棠没有与他争，只把箭头放在白布上，说明箭不射红线本身，而是射线下方的影子。她要先验证红线是否承受实物拉力。

她让药童把三枚空铜钱放在线旁，逐枚推动。第一枚停在红线外，第二枚被线轻轻弹开，第三枚贴近线时竟向西滑了半寸。红线并非单纯墨迹或纤维，它在纸面上形成了极细的牵引力。这个现象被三人共同记录，却不能直接证明纸妖拥有完整身体。

“我射第三枚铜钱。”许青棠说。

她没有征求陆昭替她决定。陆昭只确认她愿意承担箭头反弹和证物受损的风险。许青棠在责任栏写下“只负责截断可见牵引，不负责解释纸面姓名”，然后搭弩。

箭没有射向红线，而是穿过第三枚铜钱的孔，钉在账匣下方的砖缝中。铜钱被箭杆带偏，擦过红线。红线猛地绷直，旧粮单从匣内滑出一寸，纸面上七个袋位的墨迹同时变黑。

仓内所有纸签开始鼓起。

第七仓三十六袋粮的编号一齐变动。最里面七袋的“待验”被墨线覆盖，外侧几袋上出现陌生姓氏。严鹤下意识要去按住纸签，陆昭喝住他，要求先把手收回。纸签上的姓氏并不等于粮袋归属，任何人直接按压都会留下新的指印。

许青棠第二箭射向西墙。箭镞擦过砖面，钉住一条从墙缝伸出的白纸带。纸带没有纸妖的完整字迹，只有半截“岳”与两道未完成的横线。箭身将纸带钉在墙上，纸带仍在挣动，像一条被钉住的舌头。

“现在能取样了吗？”药童问。

“先让它写完，还是先让它停？”顾衡问。

许青棠看向陆昭。陆昭没有替她选，只说：“箭是你的，责任也由你说。”

她选择先停，不让纸带继续写。第三箭从她手里离弦，箭尖不碰纸面，只切断纸带后方一根几乎看不见的黑麻纤维。纤维断开的瞬间，所有粮袋纸签同时恢复原状，只有被箭钉住的纸带留下一个完整的“岳”字。

仓门外传来一声闷响。

白麻衣人站在霜墙另一侧，衣摆下露出成叠薄纸。他没有脚印，身后却拖着一块宽木板。木板压住雪面，正好抹去车轮痕。贺停舟要开门，陆昭先让严鹤封住第二道横闩，要求白麻衣人停在证物边界外。

“你们已经认了岳。”白麻衣人说。

“我们只封存一个被箭截下的字。”许青棠回答，“没有人替岳成认领，也没有人替纸上的字承担功。”

白麻衣人把一张纸贴在霜墙上。纸上出现“许青棠”，随后被一支箭钉穿。许青棠没有再射第二次，任那张纸在风中翻动。她说：“我可以让箭阻止它靠近，但不负责让它从我名下消失。”

这句话被医署记功吏写下。纸面上的“许青棠”墨迹随即变淡，却没有消失。纸妖并不怕否认，它要的是把否认也变成一种可追查的关系。

陆昭请白麻衣人把姓名、纸材来源和承担后果写清。对方没有写自己的名字，只在纸上写“第七仓第三锁”。许青棠的第三箭仍钉着墙缝纸带，箭羽被风吹得发响。她忽然发现纸带背面有一层细小的白砂，砂粒排列成粮袋编号的顺序。

她没有用手抹掉白砂，而是用箭杆尾端轻敲墙面。墙砖内部传来空声，空声位置与第七仓外墙的第三块砖相合。贺停舟从外侧量出砖缝，发现里面藏着一个比拳头略大的纸筒，筒口被黑麻纤维塞住。

纸筒取出后，里面不是名单，而是七段没有写完的粮路。每段只有车号、转向和一个空着的接收栏。纸筒纸材与白麻衣人投递的纸条相近，却与匣中异常白纸不同。第七仓、旧渡、北门三条路线被画在同一张粗纸上，仍不能证明路线上的车由同一人驾驶。

顾衡看着七段粮路，承认其中三段对应自己过去签过的外仓路条。他愿意核对签押，但不愿把未填的接收栏补成某户姓名。陆昭让他在选择栏写明“只核对签押，不补接收者”。顾衡照做，纸筒没有再出现字迹。

许青棠收回第一箭，用布包住箭头。第二箭仍钉在纸带上，她选择暂不拔出，直到医署、城防和粮官共同完成拓样。第三箭切断的黑麻纤维则由她本人封袋，并注明“截断动作由许青棠执行，不能由此推定牵线者身份”。

白麻衣人忽然向后退。霜墙上没有脚印，宽木板却在雪面压出一条直线。贺停舟打开外门追了三步，见那人把一叠纸撒向半空。纸片没有落地，全部贴到北镇城墙的告示上，瞬间写出几十个残缺姓名。

许青棠抬弩，却没有射向人影。她射的是最外侧那张写着“赵衡”的纸。箭把纸钉在告示木框上，其他纸片因牵引改变方向，纷纷落入空木箱。守卒合上箱盖，避免姓名被风带出城。

这一箭没有杀死纸妖，也没有抓到白麻衣人，却截断了纸片进入城内姓名册的路径。赵衡之子站在远处，看见纸被钉住后，主动说：“我不认这张纸上的功，但愿意看它从哪来。”他的选择由本人说出，医署当场照录。

黑簿在陆昭怀中微热，仍没有结算技艺。纸妖的证据、活人的选择和后果承担尚未落在同一件未竟之功上。陆昭把纸筒、三支箭、截断纤维、七段粮路和被钉住的残名纸分开封存。

许青棠检查弩弦，发现第三箭出弦时右肩有轻微拉伤。她自己报出伤情，拒绝让陆昭把“箭术救场”写成无伤功劳。陆昭把她的箭伤、截线选择和赵衡之子主动查看的决定一并写入责任页。

庞复核官随后赶到。他看见七段粮路，没有立即宣布追回七袋粮，而是要求先查签押、车号和第三把锁的保管链。陆昭把镇诡卫印交给顾衡暂存，自己只保管证物清单。

第七仓重新上锁，第三把锁外又加了一道见证封。许青棠的箭留在封条旁，箭羽迎风，像一根拒绝替任何人签名的笔。

第二十章的爽点终于落地：纸妖能写名字，却无法越过一支由证据、权限和本人选择共同校准的箭。可黑簿最下方浮出的新字仍然冷得刺眼：

“有人以功为饵，粮路未完。”

许青棠收弩后没有立即离开第七仓。她让药童检查右肩活动范围，确认只是拉伤，没有脱臼；她选择把伤情写入自己的医官记录，并拒绝让别人用“箭断纸妖”替她申报功勋。陆昭把三支箭按出弦顺序封存，箭头的砖粉、铜钱擦痕和纸带纤维各取一份，不能因为三箭出自同一张弩就把三种接触物视为同源。

赵衡之子在空木箱旁看了被钉住的残名纸，主动要求知道纸上出现过几次父亲的名字。他同意医署告知出现次数，不同意把父亲姓名抄进粮道名单；这个选择使“知情”和“认领”保持分开。顾衡在旁边补写，七段粮路只有三段能与自己旧路条的签押时间对应，另外四段的车号和接收栏仍为空。空栏没有被任何人补名，纸妖也没有再长出笔画。

许青棠射断姓名牵引后，先检查箭矢是否伤到纸带后的人。她的右肩有拉弩后的牵痛，仍把药粉、箭头砖屑和纸带纤维分袋。陆昭让她决定是否把这次截线写进功劳栏，她拒绝，称自己只承接箭矢轨迹与伤情。两人把“救下活人”和“斩断纸线”分成两项事实，任何一项都不能自动升级成新技艺。

北镇司最终决定把第七仓封存延长两日，封存责任由严鹤、顾衡和陆昭三方承担。陆昭在附页写明，延长封存不代表七袋粮已追回，也不代表纸妖被制服；若两日内有人申请开锁，必须重新取得本人选择和见证。许青棠的箭留在封条旁，箭杆上的霜慢慢化开，露出一道细小的墨痕，像有人仍在等待下一次认名。

第七仓两日封存令的第一夜，三名钥匙保管人各自把钥匙放进独立布袋，再由不涉案的文吏核对重量。布袋没有共同封绳，开袋顺序也被分开记录。若其中一袋遗失，只能追问对应保管人，不能让“钥匙都在北镇”成为一项无人承接的总责任。

赵衡之子选择只看残名纸的背面，不看正面字迹。许青棠尊重这一选择，把纸张接触事实告知到“曾靠近粮箱”，没有告诉他无法确认的出现次数。陆昭把知情范围列成一条可复读的授权线，纸妖没有因此得到新的姓名。
