# 第五十一章 功勋审计

审计箱打开前，司空烬让人把第七仓的三道门重新量了一遍。院吏从中门进，北镇原件从左门上台，涉案活人从右门来，三条路线都在白板上标出时刻。贺停舟拄杖站在左门旁，旧功单由他亲手从箱底取出。纸面发黄，边角被火燎过，右下角却留着一枚完整的军印。

“先说单上确实有你的部分。”司空烬没有问罪，先把拓本和原件并排，“乙巳年冬，北门粮道封闭三日，撤民三户，军需官一人失踪。你在主签栏盖印，日期和城防轮值相符。”

贺停舟看了很久，说：“印是我的，封门也是我下的。三户撤民，是我派人去接。但撤民是否自愿、粮是否交到军需官手里，不该由我的印替他们回答。”

司空烬让书吏把原件转向众人。主签栏下方有三道细刮痕，像有人把另三枚印记一一剐去。刮痕底部残留的纸纤维向东卷，和拓本上的黑线方向不一致；拓本又少了一角，无法证明是原件第一次誊写时就缺，还是后来被裁。许青棠从右门看过来，只说刮痕边缘没有新鲜蜡色，不能凭肉眼判断发生在何时。

司空烬问贺停舟：“三户是否本人同意？”

“我见过其中两户。”贺停舟答，“他们说先避雪，没说把户籍和粮契交给谁。第三户由副校尉带队，我没有见到本人。”

“那你当年为什么在功单上写‘三户撤民已成’？”

贺停舟的木杖轻轻碰地：“因为当时城外有狼诡，三户已经被赶进内城，若不先记成完成，守门的粮和火都领不到。我把安全动作写成了功成，省了半个时辰，却把选择写没了。”

这句话落下，台下没有人替他辩护。司空烬也没有让书吏立刻把“冒领”二字填进罪栏，只让人标注“本人承认印记及部分行为，撤民选择未证”。他转向第二件物证：三户撤民簿。簿页上有三种墨色，第一户的指印压在日期外沿，第二户只有一行由邻里代写的“暂避”，第三户的整栏被撕去，留下两根细麻纤维。

许青棠要求把三种墨分别封袋。她指出第一户指印边缘有旧泥，第二户代写字迹的笔压向右下，第三户麻纤维带有车棚木屑；材料显示三次记录并非同一时间完成。司空烬准许，且把“邻里代写”从接收栏移到见闻栏。秦衡抄录时问，若第一户本人只同意避雪，是否能把撤民算作已结。贺停舟说不能，避雪是当下选择，不等于把功劳交给某个军官。

第三件物证是被刮去的军需官空栏。原纸上只剩“曹”字半边，旁边有一处未落笔的方框。司空烬报出军需官全名曹弥，说明此人当年负责验粮，却在封门次日失踪。北镇旧档没有曹弥接粮的印，西关回单也只有“车至北坡，接收待核”。这两份记录时间相邻，却来自不同柜，不能因都写着“粮”就合为一条证据。

陆昭站在白板后，左手仍没有疼痛。他看见“曹”字旁的刮痕时，差点把那半边误认成旧案里的“周”字，拇指已经抬起。许青棠立即报出字口弧度，提醒他“曹”下有双横，周字没有。陆昭停住动作，主动让贺停舟接过指认，把自己的错认写入审计记录。

司空烬没有放过这一步：“连续错认三次，你仍持有点柜和封门权限。若今夜有人把乙九牌换成乙十七，你是否能保证不按错？”

“不能保证。”陆昭说，“我能保证的是，错认会被旁人纠正，且纠正痕迹留在原纸上。若你要撤我的权限，应撤的是我单独开柜、调车和调兵的权限，不是把我的每次见证一并抹掉。”

司空烬示意书吏把这段分成事实、风险和本人异议三栏。随后他拿出一张旧院规，指向“持印者连续三次错认，暂停接触未结原件”一条。那条规矩并不针对陆昭，早在南镇旧案前就存在，只是从未有人把错认记录得如此完整。

贺停舟问：“暂停接触原件，是否也包括听取活人本人选择？”

“不包括。”司空烬答，“本人说什么，仍须由本人说。陆昭可以见证、提出事实异议，但不得再替任何人开柜、调车、调兵或封门。”

陆昭看着黑簿所在的副柜，没有争辩。他知道这不是功簿反噬，黑簿没有翻页，左掌的裂口也没有新印。停权如果成立，责任不会随之消失：他仍要对已经签下的“不替”负责，仍要在案件证据与本人选择之间作见证。

就在书吏准备起草停职建议时，第七仓第四袋路条从封套底部滑出。原本空白的背面浮出一个没有笔压的“曹”字，字下有两道平行压痕，一道指向西坡，一道指向关后无人村。罗衍立刻封住纸条，不许任何人顺着压痕猜路线。两道压痕间的砂粒与无人村车痕相似，却没有共同断面，不能证明曹弥去过那里。

司空烬盯着那字，命人记录出现时刻和在场位置。贺停舟问是否要把曹弥列为死者。掌院摇头：“一个无笔压的字，不能给活人定死，也不能给失踪者补上未竟之事。”

日落前，审计结论分三层写成。第一，贺停舟本人盖印及封门行为成立；第二，三户本人选择、曹弥是否接粮、撤民后的责任对象均待本人或独立证据确认；第三，陆昭存在连续错认风险，建议停职并拆除点柜、调车、调兵、封门权限。建议不是判罪，旧功单也没有被结算或撤销。

陆昭在异议栏写下：“接受风险记载，不接受把未确认的三户和曹弥写成已结。停职期间保留普通见证、事实异议和听取本人选择的资格。”他按下指印时，纸边没有黑线，只有左掌一道细血痕落在自己的名字旁。

审计箱合上，司空烬把旧功单交给贺停舟保管。贺停舟没有立即收进柜，而是先问陆昭：“明日告示若落，你还会来听证吗？”

“会。”陆昭说，“不拿刀，不开门，只看每一个人是否亲口说了自己的选择。”

黑簿在副柜里保持沉默。第七仓外的雪压住两道无笔压的路痕，却没有替任何一个名字决定该往哪里去。

司空烬临走前又把审计板翻到背面，要求补记一项经常被忽略的事实：旧功单盖印之后，谁曾实际领过粮。曹弥空栏旁的接收日期被刮去，只剩半枚圆孔；西关回单的折角却有一粒白蜡木屑，木屑与第七仓平板车的木纹方向不同。秦衡建议把木屑列为车源线索，司空烬同意，却强调它只能说明纸张曾接触过某类木料，不能把曹弥和第七仓车夫绑在一起。

许青棠随后复核三户撤民簿的三枚印泥拓样。第一户的印泥已经发硬，第二户代写栏边有新磨墨痕，第三户被撕处夹着一小段麻线。她把三份样本分别装入蜡纸袋，写明“不得拼接为同一户选择”。贺停舟看见第三户栏下的空格，承认当年正是这片空格让他误以为事情已经结束：没有人要求第三户亲自说不，空白就被官印吞掉了。

功勋审计从贺停舟旧案开始，审计吏先列他承认做过的城防动作，再列没有证据的合并功。贺停舟拒绝替失踪者认领，愿意承接旧印、撤门和迟报三项责任。陆昭没有为他作证，只把旧案原页、刮痕和退门回执依次编号。司空烬让审计继续，说明掌院也不能用新的集中权力把旧错误一笔抹掉。

陆昭将这句话补进审计附件，注明说话人为贺停舟、时刻在日落前一刻、见证人为许青棠与秦衡。司空烬没有把它当作贺停舟认罪，也没有把附件直接送入功簿院结算，只要求明日停职告示同时附上“事实可核、责任未替”的说明。这样一来，旧功单的错误不会因停职或掌院签字自动消失，后来任何人若要重算，都必须面对原件上的刮痕、空栏和本人拒认。

审计吏又取出当年门房的炭条记录。炭条只剩两截，一截写“二更开”，另一截写“人未齐”，断口之间缺了三行。司空烬要求分别记录炭条的保管人、发现地点和受潮痕迹，不许把两截拼成完整命令。贺停舟愿意说明自己当夜在哪面城墙，却不愿替缺失三行猜测谁先下令。陆昭把“可说明站位”和“不可说明发令”印成两枚不同颜色的签，贴在审计附件边缘。

许青棠对旧案伤情页做盲复核，发现一名所谓“无伤归队”的士卒手指曾包过布，但原页没有记录。她不把这个遗漏直接归给贺停舟，只要求找到当年的药房领用册。药房愿意交出当天的领药数量，不愿交出病人姓名；这一选择被完整保留，审计因此多出一条能继续查而不能强行填满的路。

领药数量核过后，药房又发现一本旧册的页码被重排。重排只改变了装订次序，未改变墨迹和纸边；秦衡让记录吏先拍下现状，再按孔位复原原序，不能把装订错误写成有人删去病人姓名。陆昭承接复读页码和封签，拒绝触碰旧功原件。审计附件因此多出一项保管责任，缺失的姓名仍由可能知情的活人自行决定是否提供。
