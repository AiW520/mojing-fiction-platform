# 第八十九章 无主之功

旧棚里被抄作“戚望已结三功”的木牌，挂在验物厅最远的一面墙上。卫岑不让任何人把它挪近戚望名录。木牌的刻口新，背上的老灰泥却可能从旧棚墙脚随手刮到；若把两件东西并放在案上，来查案的人就会不自觉地替它们补出一段几十年的来路。

秦衡拿来北镇保存的旧总表。表中七具尸体分作两栏：四具写有接收镇与家属记号，三具只写“无主”。下方另有一行小字：“无主之功，归收尸人代结。”这行字在转抄纸上有笔压，在废渡随尸联上没有；周溯原件只到“旧棚暂置”，之后半张缺失。秦衡让鉴纸师先遮住字义，只测笔墨、压痕和纸纤维。小字墨粒细于正文，透过背面可见另一页的格线。结果说明它是后写，写于何年、由谁补上，仍须核同批账。

一名年轻复核官却先问：“既然三具无人认领，总不能让戚望白跑一趟。”

陆昭坐在白线外，左手裹着布，隔了一会儿才答：“跑一趟可以记劳。尸体无人认领，不等于死人许过他一件未竟的事。”

司空烬没有替复核官解围。他要对方把两种账拿出来：运尸工钱属活人的差役耗费，有时辰、路程和见证便可核发；功簿的未结之功须先知道死者是谁、临终未竟何事，再找两类独立因果证据、相关活人接收和结算后承责。旧总表把工钱与死者之功并成一栏，既可能让戚望平白得罪，也可能让他应得的工钱多年没拿到。复核官依次划开两栏，不再用“无主”二字填补证据。

秦衡查到一张更早的发粮签，记着七具尸体雪夜停棚，守棚者领三日火油、一斗杂粮。签名不是戚望，而是一个只留下姓氏的棚役。另一张路耗单写着戚望驾车折轴，换轴由义冢木匠修。两张原件分别压在粮册和工匠账底，不在总功表内。粮吏可核发当年的实耗补账，义冢木匠后人却只承认家里存有折轴，不愿替祖辈追索工钱。两个选择都被记录，不能把一斗粮算作三名死者的遗愿。

顾衡叫人拿同年别处雪灾的领粮签作对照。那一年几处义冢都以“无主”登记无人认领的尸体，却照样把烧柴、覆土、搬运的人工记在活人名下。三份账里只有北镇总表把“无主”接到“代结”后面。它可能是北镇独有的临时办法，也可能是后抄者误把两栏合在一起；同年另一镇的惯例不能直接证明北镇违法。顾衡把对照账页的来源和馆藏位置写清，催院方查有没有当年批准临时办法的令。没有令之前，补发工钱与核查虚功可以并行，不能互相抵销。

贺停舟把新木牌翻到背面，指着灰泥里混着的一小片红砖屑。旧棚墙底是灰白砖，义冢碑座却有红砖。卫岑已留样，但砖屑可能来自搬运途中碰过的河堤旧桥。锁匠量了木牌底边，一侧刀口比另一侧浅半分，像匆忙改过固定槽。现场旧棚的三槽倒印与它宽度相近，间距却差一指。木牌可以插在旧棚的新补槽里，不等于当年就在那儿，也不等于戚望曾见过它。

这时第二镇回报，河堤草鞋附近发现一段拖痕，尽头不是水，而是旧渡口的干燥碎石。卫岑请当地熟路者沿岸复测，不让人顺着拖痕宣称八名未归者已有一人返镇。拖痕一侧有长柄撑杆的圆点，另一侧没有伴行脚印；水涨落之后，点印和鞋底也许都被搬过。家属要求搜寻延至夜里，药吏认为碎石坡夜行容易滑落。司空烬批准两骑守住出口、天亮再入坡内，延误风险和守夜粮记在院方救援项，不从家属同意里扣。

陆昭听完碎石坡回报，忽然把“干燥”说成了“无水”。秦衡在记录上圈出这两个不同的词：坡上有干石，不能推出坡下没有水。陆昭认下错述，不再负责口头汇总。左手失痛尚未退，布下的浅裂不知何时又蹭开，药吏重新包扎，禁止他夜间独自核页。他想摸拇指旧茧，却只摸到湿布，便让第三镇文吏代他继续查旧总表的页序。

文吏从总表的装订孔里发现两轮穿线：内圈孔边磨损，外圈孔边新净。两轮之间夹着一张窄纸，正面只有“无主”二字，背面是出入库的半个印。鉴纸师先为窄纸定独立编号，再在侧光下拍两面的压痕。半印与十年前前任库吏的借阅印形似，却少一角；磨损可由旧印、残印或后人仿印造成。若现在把它装回总表，它的夹入时间便再也无法查清。秦衡让众人在取出位置签字，把孔位拓样与窄纸分袋。

小吏问能否先把总表上那三笔旧功冻结。司空烬答，可以暂停争议栏的结功效力，不能停掉对应的旧棚修缮和义冢药粮。若后来证明当年确有活人凭这栏受益，须逐笔查领取者、实际支出和受损人；若只是抄写造成误记，也要为多年未核的档案负责。他让秦衡把暂停理由写作“缺死者身份及本人接收链”，不写“戚望盗功”。这样一张纸并不让任何人痛快，却使真正签过字的人将来不能躲在“年代久远”之后，也不让死者替后人背一个未证的罪。

贺停舟问，若这张纸恰好是失踪的第三联，又该怎样。鉴纸师回答得很快：“第三联是空白接收联，至少该有预留的三格和纸幅。它只有两字，纸幅窄了一半。除非有人裁过，否则不能称第三联；裁过又要有断口和来源。”她的回答没把人从疑心里拉出来，却把疑心放回能查的纸边上。司空烬命院方另查同年同制的空联，北镇守住窄纸原件，双方不互换保管权。

黄昏，周溯托乡邮带来叔父的答复。老人愿在废渡本地说一次自己听过的名字，但要见证者只记原话，不能把名字写进功簿，也不能用他的记忆开义冢。周溯还附了匣盖旧裂纹的拓样，供日后核对木匣是否被调换；拓样不能证明木匣过去从未到过北镇。秦衡把邀约改为原地询问，许青棠从皇城回函：在死者家属未确定、第三方遗存未比对之前，她只接收伤亡核验程序，不接收任何三功结论。她的右肩仍痛，亲自出发的时刻由她自己决定。

周溯另划了一条边界：叔父若在询问中想起称呼，记录只用于寻访可能的亲属，不用于公布失踪名单。第三镇文吏把这句话写入邀约底页，乡邮带回让老人先看；若老人不认可，询问取消。司空烬本想派院中善记名册的人随行，秦衡提醒对方参与过争议总表复核，容易让老人顺着问题答。最终派去的是不知三功结论的医官和一名当地文吏，各自只问身体承受与原话来源。询问慢了一日，偏差却少了一层。

旧棚门槛在入夜后又浮出一行浅白字：“无人认，便无人欠。”守门人记下水线起点、温度和当时经过的三辆粮车。字面旁有蜡膜，却没有笔压；最先见字的粮吏正忙着把预留两袋底粮搬离潮处，没有空手触门槛。司空烬没有命人照字办事，也没有命人抹去。他让第三方先复测门槛木纹和水线，城门另一侧照常放行药车。字能诱人把空白看作免责，恰好不能拿它当免责的证据。

陆昭在新卷的题目上写“无主之功”，把“功”字圈住，旁边列下四个没有答案的问题：三具死者是否确无家属，谁把暂置抄成代结，窄纸何时夹入，门槛字是谁或什么留下。圈住不等于认下。他让秦衡另发一张差役补账给旧棚守者后人核对，工钱与火油先按现有凭据办理；三名死者一栏仍空着，等待能承受反证的人来填。

无主之功的旧小字经过墨粒和背面透格线比对，确认是后写，但写入人和年代未定。废渡随尸联只证明戚望领尸至旧棚暂置，不能证明三具尸体身份、未竟之事或家属选择。差役工钱、火油杂粮和尸体保全另行入账；周溯叔父只承接听过阿岐称呼，不承接认尸。陆昭把窄纸半印、缺联孔位和木匣拓样分袋，旧小字不能替活人结功。

当晚，守门人拿来一份旧镇门的开合图。图上有一条早被封死的小门，通向废渡坡的上沿，能避开河堤碎石。若明晨要继续找人，他们必须决定是否打开它。贺停舟看着图上那道旧闩，说开门先验承重、封存和撤离线；没人能为追一页旧功，把活人的退路锁在门后。

开合图的纸角有一处被火烤过的弧痕，旧门守人说那是多年前烘干地图留下，不能证明小门曾经着火。锁匠用同样的油灯在废纸上做试片，弧痕宽度相近，却因纸龄不同出现两种褪色。贺停舟让试片留在工匠柜，原图继续由北镇保管，不把相似烧痕写成同一场火。卫岑沿小门外侧量出三段松动砖缝，承重尚需白昼复测，今夜不开门。

周溯叔父听见小门通往废渡坡，愿意承接自己童年走过的坡口，不承接“戚望当年也从此门走”的说法。记录吏把他的记忆拆成两个栏，前者附一枚旧鞋钉作询证条件，后者标作拒绝推断。老人要撤回“阿岐”只是长辈称呼的影像交换，秦衡允许撤回，但保留原来的拒绝和撤回时刻。废门仍是路线候选，不是给三具无名尸补上的来路。

旧门图上标出的坡口后来被雪覆盖，卫岑只在图外立了木桩，不按旧线挖雪。木桩由守门人承接位置，挖雪队承接今日清除范围，谁也不承接“那里一定有路”。贺停舟把开门申请顺延到承重复测后，药粮仍按现有南门路线发放。开门的责任因此没有被一张旧图催熟，搜寻也没有因等待而停下。
