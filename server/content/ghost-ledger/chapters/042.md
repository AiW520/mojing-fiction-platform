# 第四十二章 听骨第二式

第三台哨屋的门槛上钉着一条新木，木下却是七年前的旧灰。秦衡在三方到场前划出见证线：北镇验原件，西关验副本，镇南只验自己携来的旧功单。卫岑派来的军医名叫阮遐，带着药库领牌和验伤印；镇南领兵者仍不报自己的私名，只把官衔写作“收役校尉”。这不妨碍他查旧单，却使他不能代两名缺席者作亲属见证。

陆昭先让罗衍复核第41章雪桥图和第40章回声纸。桥南收到两名伤员的时刻、第三台七日前的二长一短、油纸“接台”空栏互不等同。阮遐查药量，发现九人名册所列的止血散少两包，药库总账却只记一次出库；孟岚药箱中少的两份可能是送药，也可能是被人从箱里取走。没有车号和接收人，谁都不能据此认定两人逃役。

收役校尉把镇南副本压在桌上，指出“已接台”上有真的旧印和贺停舟旧案同式的黑铜压纹。他并不否认空栏，说军中紧急运送允许先印后补。贺停舟承认旧制确实允许暂记，却问补记的期限和见证人在哪。校尉拿不出来，转而要求北镇至少允许验一具尸体。陆昭答应在许青棠、阮遐和罗衍三人到场时验尸，不答应把尸体交给镇南车。

许青棠将灰布尸体移到白布上。她的右肩仍痛，尸板由罗衍和阮遐抬；左手旧折、眉尾伤、右腕药带磨痕都由第三方逐项核对。阮遐带来的领牌册写着许青岚左臂曾在十四岁重接，眉尾疤在十三岁留下，药箱编号甲三由他签领。册上有当年的医署封印和另一名医佐手押，来源独立于孙砚的七日前簿册。阮遐仍谨慎，只在“身体特征、旧案册及甲三号相合”处盖验伤印，不替家属宣布祭名。

许青棠这才在亲属辨认栏补写：“认许青岚为死者；不认活祭已结。”她签名时没有看陆昭。陆昭也没有让黑簿翻页。姓名虽有独立支撑，死者最后要完成的事仍缺明证。第三台旧册撕去的第六页能解释什么，尚无人知道。

第二台灰甲尸体也被抬到哨屋外，由罗衍守着。卫岑带来乙九军籍底册，底册记乙九为护送药脚的轮替编号，两个月内曾分给三人使用。灰甲尸体随身的军牌不能单独认名。阮遐验到其右掌虎口有旧烫痕，底册中三人的伤情只有一人相符，叫方录。卫岑仍需向本营核对指印，先将“方录候选”写在副本上。陆昭不把一处烫痕变成结案。

北镇收尸车里另有一具七日前留下的旧骸，是罗衍在第三台井底找到、尚未入册的守令卒。骸骨腕上系着半枚木签，签上只有“戌”字；井壁冻土分层显示尸骨至少埋了数日，不能当作今日死去的第三人。许青棠检视骨端，说明其右腕最后有一处向外撑开的新裂，裂口被旧血浸过。她不准陆昭立即触骨，因为这具骸骨身份、家属和搬运时序都未复核。

陆昭看向自己的左掌，布带下浅裂仍在渗血。第37章听骨后的错认虽已停止，失痛却没有恢复。他提出的“第二式”不是让黑簿再赐一只眼睛，而是把两具已记录受力方向的尸骨分别固定在现场原位，用不同见证人读出方向，再比照同一条台阶的坡向。若第一具指西北向下，第二具可能指向护栏外；相交只能收窄发生受力的区域，不能凭交点认凶手，更不能替未知骸骨认名。

贺停舟要求先给这办法立边界。他以木杖在地上画两条线，指出尸体被搬动后若不重建原位，交点会随人摆放而变；即使两条线真的相交，也可能属于相隔七日的两次事件。陆昭承认，先不用未知骸骨。第二条线改取已确认许青岚身份的尸体，并由许青棠本人决定是否允许触骨。她沉默一刻，答应一次，只许读取最后一次受力方向，不许用它推断弟弟自愿入祭。

阮遐和罗衍分别确认尸体搬运记录：灰布尸体落在雪谷入口的时刻、移入石棚的时刻、送至哨屋的时刻都有各自木签。原位与第三台之间的高度差由贺停舟测出，误差至少两尺。陆昭把这两尺圈成一段，而不是画一个看似精确的点。他让秦衡记录，如果今日再出现错认，指挥权自动交给贺停舟，自己只作口述证物，不发军令。

许青棠解开弟弟腕上的冻布。陆昭没有触碰药瓶、木牌或纸张，只以右手扶住尸板，用左手两指触到腕骨。骨中传来的最后受力是向南上方的一次猛拽，短而急，像有人在坠落前攀住了高处。它没有告诉他谁在上方，也没有告诉他许青岚握的是什么。陆昭立即收手，罗衍按沙漏记下接触只持续两息。

失痛从左指漫到肘部，陆昭一时把阮遐手里的领牌看成了乙九军牌。他张口要喊“方录”，听见许青棠说“那是医署领牌”，才停住。错认写进伤情册，贺停舟接过现场指挥。陆昭用右手指着地上的方向图，说明自己只报告“南上方受力”；图纸由罗衍执笔，不能让他在错认时独自画线。

第37章灰甲死者的“西北向下”来自颈骨，第42章许青岚的“南上方”来自腕骨，两次受力不在同一时间，也不在同一尸体上。贺停舟把线投到第三台西南角的旧护栏，交集不是一个人影，而是一段宽三丈的沟沿。若灰甲尸体被按下台阶，许青岚向上攀扶，那里可能曾同时有人救援和压制；也可能先后发生两场无关的事故。两条线只指向应当勘验的地点。

镇南校尉当场要派人下沟，说一旦找到两名逃役便可收押。卫岑拦住他，理由是沟沿仍连着自己的药车和伤员退路，贸然踩踏会毁掉雪层。陆昭不再发令，贺停舟把沟分成三条：西关查车轮，北镇查尸体搬运痕，镇南可在外缘见证但不得先翻尸袋。校尉争了片刻，同意一刻钟的现场保护，条件是三方同时入沟。这个条件使各方都有监督，也使任何一方无法私带走证物。

沟沿第一层雪下，罗衍找到两根折断的医署担架杆，断面一新一旧；旧杆刻着“戌后换岗”。杆间还夹着一枚完整青牌，牌背药库孔和第39章残牌的孔位相近，木纹却未验，不能立刻拼成同一人的身份物。孟岚隔着见证线补报：七日前子初前他听到第一阵车轮，丑初后听到第二阵，中间没有看见车号或车夫。两次声音与两根杆的断裂先后无法对应；罗衍分别取雪层、断面和牌孔拓样，交三方盲验。陆昭看见井底守令卒木签的“戌”字，与担架杆只共享一个字，不足以并案。黑簿安静得像一块冻铁，两次受限听骨仅让三丈宽的沟沿接受查验，同时让陆昭交出现场指挥。

沟深处突然响起骨笛的半音。雪壁上浮出“九人已接”四字，旁边却露出两只仍带体温的手。贺停舟命三方先救人，镇南校尉也不得不让开木板。陆昭站在见证线外，没有冲下去认那两只手是谁。他知道若活人尚在，接下来的问题不是谁先领功，而是谁愿当着两军的面承认那张“已接台”旧单写错了。

所谓第二式只是两次受限听骨结果的交叉复核，不读取受力先后，更不能读军令、活人或妖物名字。贺停舟把方向、担架杆和车轮声分开编号，要求另一名验尸人复核记录。陆昭明白，图上的交集越窄，越须写明不能排除的误差。

罗衍先用木杆探出两人的肩线，确认他们被旧担架压在雪沟侧壁，手腕尚有脉搏，但一人左手被麻绳缠住，另一人嘴里塞着半截药布。许青棠在上方报出两人的呼吸与失温程度，选择让西关军医阮遐先下沟，自己只负责远距指示，避免右肩再次受力。镇南校尉同意把弩手撤到外缘，贺停舟则把救人时刻与“已接”字迹出现时刻分开记录。

阮遐先剪药布，露出其中一人舌下的旧伤，确认他能自主呼吸，却不能立刻回答姓名。另一人的麻绳打结紧贴手腕，若硬扯会毁掉结法与皮下压痕；她让镇南军医从绳外侧剪开，保留结芯，再按原位图给绳端编号。两名活人被抬出沟沿时，贺停舟先报救护完成，不报身份确认。校尉想问是否是逃役，被卫岑拦下，等失温缓解后再问本人。

沟壁上的“九人已接”没有因救人而消失。秦衡的书吏建议把这行字拓在旧单旁，陆昭要求先标明它出现时活人仍在沟内，否则后来的审计者会误以为“已接”是救护结果。罗衍把写字位置、救人路径和两张担架杆断面画在同一张图上，却用三种线型区分现象、动作和物证。陆昭没有碰图纸，只在见证栏签下“时序已复读”。


许青棠看见一名伤者手背有药袋细线，想起弟弟许青岚用过相似扎法。她没有认人，先让阮遐把细线长度、结头和药渍位置抄入医案。相似扎法在西关药车常见，不能从结法推到死者身份，更不能据此完成未竟之事。她的右肩在寒风中牵痛，选择退出下沟复测，由阮遐和北镇另一名医官盲验；这个退位被写进公开记录，不影响她之后提出异议。

两名伤者恢复意识前，沟沿仍由三方守住。镇南校尉承接外缘警戒，卫岑承接药车退路，贺停舟承接证物原位，陆昭只承担听骨感知的边界说明。黑簿第二式没有给他更多命令权，反而让每个方向都必须找到独立复核的人。三丈宽的沟沿里，救人是已经发生的动作，接台是否完成仍无人能答。
