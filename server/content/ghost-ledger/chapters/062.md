# 第六十二章 皇城问罪

皇城问罪诏在三日保全期限的第二天抵达北镇。诏书不问曹弥是否是无名尸，也不问三户是否本人同意，只列三项罪名：陆昭拒交功簿，贺停舟擅改旧功，许青棠私立复核署。诏尾命三人携证物目录入京，司空烬随行监核，北镇不得以伤员、阵法或活人选择为由延期。

秦衡读完诏书，先检查玉印边缘。印是真的，诏纸却缺少传令时辰和沿途接收人。卫岑的副使说皇城急诏允许先印后填，司空烬当场纠正：“允许先印，不等于已经有人接收。”他让传诏骑卒本人选择是否在北镇补写时辰。骑卒同意补写自己到城门的时刻，不同意替皇城证明沿途每一站都有人接到。

这项本人选择被记下后，诏书仍然有效，却不再是一张可以吞掉所有空栏的纸。贺停舟问是否必须把黑簿原件带走。司空烬答诏书要求“证物目录”，没有写原册；功簿院若要原册，仍需三日保全令之后另行申请。陆昭听见后没有松气，他知道皇城问罪的锋口在于把程序异议写成个人抗命。

许青棠把复核署章程、盲验意见和活人授权索引分成三个封袋。她同意带走编号副本，不同意交出姓名、家属选择和药车夫按印。曹弥叔父被问是否愿意随行作家属证人，只同意在北镇复核署远程提供牙列见闻，不同意进皇城，不同意把候选索引改成死者确认。秦衡按他的口述逐字登记。

贺停舟交出三钥盒的封存副本和旧印交接记录，保留原印在北镇。卫岑问他若皇城要求恢复旧印，谁来承担封诡阵和外仓的风险。贺停舟答，能恢复印，不代表能恢复三户“已接”；若皇城命令触发阵眼，他会要求把阵灯、药粮和住户撤离列为明账。司空烬没有说这是抗命，只让他把这句话写入随行异议。

陆昭站在复核署门外等候押解。停职告示仍贴在北镇墙上，诏书却把他称为“原册持有人”。他提出事实异议，说明黑簿自第49章起一直由北镇三钥保管，自己没有单独持有原册；传诏骑卒将这句写入补录，司空烬要求把“持有人”改为“案件责任相关人”，避免诏书用词提前定罪。

诏书队伍出城前，旧井第四声忽然响起。阵灯没有下降，井沿霜样却裂成两半。许青棠要求先封裂霜，不得因皇城诏书在场就把异常解释为问罪应验。阵匠查到霜下是一截被挤裂的牲畜骨片，骨面“七”字只剩半道，和第58章井沿骨片没有共同断口。陆昭不碰骨片，只复述编号，罗衍负责封袋。

司空烬看着那半道“七”，提出将骨片列为随行物证。许青棠拒绝把原件离柜，只同意提供两份拓样和材料报告。掌院坚持皇城有权见原件，陆昭指出诏书只要求目录，许青棠的复核署章程也规定原件需本人授权或双钥申请。三方僵持时，传诏骑卒说愿意在场见证拓样，但不替皇城决定是否取原件。这个选择让争执重新回到程序，而不是互相拔刀。

最终，随行物证只包括编号目录、黑账拓样、旧功重算副本、阵眼副页拓样、霜样报告、交印记录和复核署材料意见。每份副本都附来源、反证、本人授权范围和复核时限；原件留在北镇双钥柜，黑簿留在三钥盒内。司空烬在目录末尾签“原件未随行”，陆昭在异议栏写“不同意据副本替代本人选择”。

出城前，司空烬单独对陆昭说，皇城问罪不一定要他认罪，只要他承认地方不能自行解释功簿。陆昭回答：“我可以承认地方会错，也可以承认我会错；但不能承认一个没有本人选择的空栏已经完成。”司空烬没有反驳，只让他把这句话留在随行异议里。

雪关外的驿路被封诡阵照成一条灰线。陆昭坐在无印车上，不能调车、不能开柜、不能听骨。许青棠坐在另一车，右肩牵痛仍在，却把复核署章程压在膝上；贺停舟留守北镇，旧印交接后的权限由卫岑、罗衍和许青棠的远程见证共同维持。三人第一次被分开，责任却没有因此消失。

半日后，皇城中书省的第二道口谕追上车队：若北镇不在七日内交出黑簿原册，将按“拒奉诏、扰乱边镇功制”先行定罪。口谕有中书省副印，却没有传令者姓名。司空烬让骑卒本人说明来源，骑卒只能说自己从驿站接令，不知道中书省哪一名官员交付。口谕被列为待核，不直接执行。

夜宿旧驿时，陆昭复测左手。疼痛仍不存在，错认风险却在听见“皇城”两字时突然加重，他差点把许青棠的复核署章程当成黑簿副页。许青棠收回纸张，让他只听本人朗读，不看封面。陆昭主动把这次错认写进随行记录，承认问罪路上也不能假装自己可靠无缺。

司空烬把皇城罪名逐项拆开：拒交功簿对应的是原册未移交，但三日保全尚未到期；擅改旧功对应的是公开重算，已有院方印和证物链；私立复核署对应的是临时材料协作点，未取得定功或调兵权。三项罪名都可能成立为程序争议，却没有一项能直接证明陆昭用谎言结算、贺停舟冒领资源或许青棠代活人认名。

车外风雪压住驿站旧牌。陆昭在随行异议末尾写下：“愿受事实核验，不受空栏定罪。”黑簿仍在北镇，皇城的问罪已先于原件抵达。真正的审判不会只问谁盖过印，还会问谁有资格让一个人被写成已经同意。

驿站值夜的老卒听见车队来路，愿意说明中书口谕是在西门外交给传令骑卒的，却不愿把自己写成皇城传令链上的正式接收人。司空烬让他只在“见闻”栏按印，秦衡把他的姓名留在内层，不放入随行目录。老卒还指出口谕封套曾被火烤，封蜡边缘有一圈细裂，与北镇旧功单火燎角相似；许青棠提醒这只是形态关系，不足以认定同一只手或同一场火。

第二日清晨，车队在驿路分叉处停下。皇城要求走南线，南线经过旧渡和曾出现六尺一车痕的无人村；北线多三十里，却有西关药车的备用驿站。司空烬不能替药车夫和伤员选择路线，先问随行医官、车夫和传令骑卒各自愿意承担什么。车夫同意走北线但要求补足一日草料，医官同意延长一刻换药间隔但不减止血粉，骑卒只同意报告口谕来源。路线因此由三份本人选择共同决定，未被诏书一句“速行”覆盖。

陆昭在车内听见司空烬把南线风险写入行程表，第一次看见皇城问罪也会被证据和本人选择拖慢。拖慢不是脱罪，北镇仍要在七日内回应；但每一次停留都留下责任人、材料和反证位置，不能让“急”成为空白的印章。

夜深后，秦衡把皇城诏书的三项罪名与北镇随行目录逐项对照。拒交功簿对应原册留北镇，但保全期限和双钥程序尚未逾期；擅改旧功对应公开重算，贺停舟旧印、黑账“空栏不得结功”和三户有限见闻均可复核；私立复核署对应临时材料协作点，器械领用单写明用途限于复核。每一项都可能被皇城认定为程序违抗，却没有一项能够直接跨过死者、证据、本人选择和结算责任四道门。

皇城问罪时，许青棠提交的是伤情和复核流程，不是替陆昭求情。贺停舟提交旧案责任，司空烬提交统一尺度的收益与风险。陆昭只回答自己曾经签过哪些栏，拒绝回答没有见过的幕后人。问罪官要求一句“皆由功簿所示”，陆昭指出功簿不会直接告诉凶手，也不能替活人认名。皇城因此只能按证据列问，而不能用一句神谕收卷。

司空烬在旁边补写一句：“皇城可问责程序，不可替功簿完成事实。”他写完后停了笔，仿佛意识到这句话同样会约束功簿院。陆昭听见秦衡读出这句，没有因此放松；若司空烬日后改变尺度，墨迹仍会留在副本上，成为可以追问的证据。

车队在北线驿站停下时，随行文吏重新核对三项罪名的来源。诏书原件、口谕封套和老卒见闻被放在三张不同的案几上，案几之间留出一臂距离，避免纸边相碰后留下无法分辨的纤维。老卒愿意指认自己看见火烤封套，却不愿猜是谁先把封套递给骑卒；秦衡把“看见”与“推测”分成两栏，要求每次复读都照原词念。传令骑卒补写时辰后，发现自己记错了半刻，主动要求把旧时辰划去并在旁边重写。没有人因他先前写错就把整道口谕判成伪造，也没有人把改正写成已经确认来源。

司空烬让车夫清点北线备用草料。草料少了两捆，驿站管事只承认入库时见过完整数量，不承认是车队取走。车夫愿意承担一捆的实际消耗，另一捆则要求查封袋和称重记录；医官同意把换药间隔延长一刻，却拒绝用自己的签名替伤员放弃止血粉。陆昭听着这些细小的选择，明白皇城的“速行”并没有消灭边地的责任，只是把每个人都推到必须说清楚的位置。秦衡将草料差额、路程延误和伤员复测分别编号，附在问罪副本之后，注明它们不是功劳，也不能抵销任何罪名。
