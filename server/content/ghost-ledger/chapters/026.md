# 第二十六章 三次验墨

许青棠把三份墨样摆在医署北窗下。

第一份来自城门簿上的“乙十七，已交功”，第二份来自东市抄写铺的假功单，第三份来自废驿井壁那道窄掌黑墨印。除此之外，她还取了一小片无脚印白纸上的墨迹，作为异常样本，不把它混入前三份。四份材料各有编号，封袋外写明取样人、时刻和接触物。

陆昭、贺停舟、秦衡和书吏四人分站桌边。许青棠先报右肩：“仍有牵痛，今日只做验墨，不拉弩。任何人不得把我的操作写成无伤功劳。”她选择由药童递工具，自己只碰医署器皿；这个选择被记录，防止功簿院把验墨结果归到她一个人名下。

第一次验墨是遇水。

四滴墨分别落在四片相同的粗纸上。城门簿墨遇水先向东扩，边缘留下一圈淡红；抄写铺松烟盐墨扩散慢，干后析出细白盐点；井壁墨扩散最快，水边出现黑褐色沉积；异常纸墨没有扩散，反而把水珠推向纸纹深处。四种反应不同，说明至少存在三种人工墨和一种异常附着方式，却不能凭一次验水确认谁写了哪一行。

秦衡问：“异常纸墨不溶，是否就是妖墨？”

许青棠说：“我只能说它不按普通墨的方式遇水。若要叫妖墨，还需术式残留、纸材和出现条件的独立证据。”她让书吏把这句原样记下，不许把“可能”删成“就是”。

陆昭注意到城门簿墨的淡红边，与第十九章锁孔红线只在颜色上相近。许青棠拒绝把两者并列成同源，改取红边纸纤维，单独封存。

第二次验墨是受热。

她把四片纸分别放在陶片上，用同一盏灯由远及近加热。抄写铺墨最先发出松烟味，盐点在纸面结成细针；井壁墨遇热后留下水泡过的灰痕，掌印轮廓断成三段；城门簿墨没有气味，淡红边却向外扩了一线；异常纸墨在火光下显出极细的横格，像纸内藏着一层薄蜡。

纸匣中的异常样本忽然抖了一下。它没有写字，只把横格朝“周梅”两字的拓片方向折。周梅人在门外，没有接触验墨室。陆昭让贺停舟关上内门，询问周梅是否愿意让这次纸面牵引继续观察。周梅选择同意观察，但拒绝让自己的姓名作为实验材料；许青棠遂把拓片移走，纸张的折向改朝一块无字木片。

这个动作证明牵引依赖现场关系，不证明纸妖能够远距离认出周梅。陆昭将周梅的同意范围写清：只同意观察，不同意写名、认功或承受纸面结果。

秦衡的书吏提出把异常样本送回功簿院，用统一炉火复验。陆昭要求先在北镇做第三次验墨，否则原纸离开后无人能证明途中是否接触姓名册。秦衡起初不同意，贺停舟将城防责任写成两行：交出原纸意味着功簿院承担运输封存；留在北镇则由北镇承担夜间防护。秦衡选择留纸一夜，接受三方封条。

为了避免三次验墨受到前一次加热和水分影响，许青棠另取同批纸张作空白对照。药童先在对照纸上滴清水、照灯火、压铜片，确认纸纹不会自行出现横格；贺停舟则把验墨室门槛、窗缝和灯油来源写入城防栏，防止有人从外面调换器皿。秦衡的书吏不许单独触碰异常样本，书吏同意这一限制，却要求保留自己对封袋编号的复核权。

第三次验墨是压痕。

许青棠把同样力度的铜片压在四片纸上，再用空白木板覆盖。城门簿墨在纸背留下浅浅的凹槽，说明落笔时有压力；抄写铺墨压痕最深，笔锋起落清楚；井壁墨因水浸，只有掌印边缘留下断裂凹纹；异常纸墨完全没有纸背凹陷，只有横格蜡层被压出细小裂缝。

“三次验墨的结论不是一个凶手。”许青棠说，“是三种人工书写与一种不具笔压的附着。城门簿那行字有人写过，假功单有人抄过，井壁掌印经历过接触，异常纸仍不能按普通书写解释。”

陆昭让书吏把三类人工墨的责任边界分别写入报告。秦衡承认功簿院预录单的墨与东市假功单不同，愿意把原纸的墨样交给医署，却要求医署不公开功簿院书吏姓名。许青棠选择接受墨样，不接受隐去取样责任；她要求封袋写明“功簿院提供，书吏身份暂保密”。

验墨室外忽然传来脚步声。

守卒报告，北门簿房有一名穿灰短袍的人要求取回“乙十七”的临时牌。罗衍没有放行，只隔门问其姓名。门外人没有回答，把一块木牌从门缝下推入。木牌正面刻着乙十七，背面却贴着一片白纸，白纸上写“周循本人”。

周梅赶到门外，看见木牌后没有伸手。她说：“我可以看刻痕，不能替我弟弟认这张纸。”陆昭让罗衍把木牌留在门外雪线上，先量门缝宽度、推入方向和纸面折痕。贺停舟把城防卒安排在两侧，不追灰袍人，避免脚印和风把证物搅乱。

灰袍人忽然用指节敲门，三长一短。

纸牌背面的“周循本人”最后一笔向门内折去，像在寻找谁来接收。陆昭用无字木夹压住纸，不让任何人念出姓名。许青棠隔着门缝取下一小片白纸，发现纸背仍无笔压，但夹层中有与第18章不同的细红线。她把红线单独封袋，不能因为“同为白纸”合并。

门外人退走后，雪面没有脚印，只留下半枚灰布纤维。城门簿上那行“乙十七，已交功”同时褪去一个墨点，变成“乙十七，已交”。这不是功簿院正式更改，因为没有官印和书吏签押；陆昭把簿页、木牌、白纸、灰布纤维和敲门时刻分开编号。

黑簿在桌角发出一声轻响，浮出一句完整的话：

“验墨可辨手段，不可代替本人。”

许青棠把四种墨迹的结果拆成三张表：扩散表只写遇水范围，热变表只写气味、残痕和横格，压痕表只写纸背受力。她拒绝在结论栏填写“周循所写”“灰袍人所写”或“功簿院所写”，因为当前没有任何一项实验能连接到具体活人。陆昭把三张表分别交给医署、北镇和功簿院，秦衡若要带走原件，必须同时带走三方封条。

这句话没有指向周循，也没有指向灰袍人。陆昭把三次验墨报告递给秦衡，要求功簿院在二日复核前先确认预录单的书写者和批准人。秦衡选择接受报告，却提出一个条件：若周循确实已进城，北镇必须负责把他从城门簿中“领回”。

“领回是搜人责任，不是认功。”陆昭说。

秦衡在责任栏写下功簿院承担文书核验，陆昭写下北镇承担两日内搜寻，周梅写下愿意提供弟弟旧路线但不替他接收功劳。三份选择各自落印，功簿没有翻出新技艺。

陆昭随后让罗衍把门外灰袍人敲门时的木牌、门缝宽度和守卒站位重新画了一遍。灰袍人若从门外推入木牌，纸面折痕应当朝城内；若有人从城内接过再放回，折痕会在另一侧留下指压。拓样显示两种痕迹同时存在，却没有足够指纹证明是谁接过。罗衍选择承担小门封锁两刻钟，周梅选择只看拓样不碰木牌，秦衡选择让功簿院书吏在场见证。三人的选择把木牌从“周循本人”字样中分离出来。

夜深时，第四份异常墨样在封袋里慢慢变淡，露出纸背一行字：

“第三次验完，城内有人替你们开门。”

三次验墨分别取自假功单、城门添字和白纸夹层，结果显示灰墨、蓝墨与带胶墨并非同批。秦衡承认“功成”预录可能来自不同环节，不能再用一种墨色解释整个纸妖案。陆昭把检验失败的一次也写入报告：有一滴水碰到样片，无法排除稀释影响。许青棠说承认样本被影响，比给出一个漂亮的同源结论更有用。

北门铜铃随即响了一声。没有人开闸，门内却多了一道湿脚印，脚印尽头指向第七仓。

陆昭没有让守卒追着脚印走。他先让两名文吏从相反方向量脚印长宽，再把湿痕边缘的泥粒刮入两个小纸袋。东侧文吏认为脚印是靴底压出，西侧文吏认为像赤足外套薄袜，二人都承认灯影使纹路缺了一截。陆昭把分歧原样记下，要求第三次复测等天亮后进行。罗衍封住通向七仓的侧廊，只保留搬运药箱的一条窄路，并在路口放置无字木楔，避免后来有人把木楔上的刻痕当作妖物留下的字。

周梅听见铃声后要求查看弟弟旧路线，却只愿看地图，不愿走进湿脚印范围。她的选择被写成“知悉声音，拒绝接近”。秦衡本想让她在仓门外确认一枚木牌，周梅问木牌是否已经与异常白纸接触，得到无法确定的答复后便不碰。陆昭让书吏把这次拒绝和询问条件并排保存，提醒所有人：活人选择必须在知道对象与风险后作出，不能拿一句模糊的“愿意帮忙”替代。
