# 第八章 认领与拒领

第三日清晨，黑水驿的雪停了一刻。

陆昭趁风小，把第三组木楔、木套断片和两块冻木对照样送到北巷木作铺。铺主谢大木五十多岁，左耳缺了一角，见到木楔时先看刃口，再看桐油颜色，没有急着认领。

“这不是我铺里的成品。”他说。

陆昭把半枚铜牌放在柜台外沿，说明只查制作处，不授权搜铺。谢大木这才取来一把窄凿，分别比对木楔断口。第一根木楔的木纹与北巷常用的榆木相合，第二根却是旧松，内里有虫孔。木套断片上的三趾边缘更像薄板拼接，不是整木雕出。

许青棠把雪上四个圆孔的拓纸铺开。谢大木用凿背轻敲纸面，指出孔距不稳，像有人拿废木板反复试压，不像为守门器械制作的模具。可木套内侧有一层黑麻纤维，北巷木作铺只用麻线绑货，从不用黑麻绳。

“你见过这种黑麻吗？”贺停舟问。

谢大木摇头，随后从柜底取出一张旧货票：“三日前有人来买两块薄板、半合桐油，还问有没有不用留名的黑麻绳。我没卖黑麻，只给他看了废绳。他最后买走薄板和桐油，付的是一枚北门旧铜片。”

铜片已经不在铺里。货票上只有一个模糊的“岳”字，后面被水晕开。谢大木说买货人戴着厚毡帽，脸被围巾遮住，声线偏哑；他不能认定就是岳成，只记得对方右手拇指有一圈压痕。

许青棠取出周槐拇指伤情记录，纸上只有圆痕位置和深度。谢大木看过后说相近，但不相同。陆昭将货票、木套碎片和谢大木的口供分开封存，注明“票据可证明三日前有人买板油，不证明买货人身份”。

“那半枚旧铜片呢？”陆昭问。

谢大木指向后墙：“买货人走后，我拿它当压纸石。第二天有人来收，说是镇尉要回收旧片。我照交了，没留名字。”

这条口供让贺停舟脸色一沉，却没有把谢大木写成同谋。能证明的只有旧片经木作铺短暂保管，收取者身份未知。陆昭让谢大木在货票旁补写交片时刻，又请他按手印。谢大木签完，问：“我若不签，是不是就会被抓？”

“不签是你的选择。”陆昭说，“但没有你的选择，货票只能记成无主纸。”

谢大木重新看了一遍纸，还是按了手印。许青棠把原票交还给他，只留拓本和经本人确认的副本。

离开木作铺前，陆昭请谢大木把铺内现有的薄板、桐油和麻绳逐一摆出。谢大木不满地说这是生意，不是案发现场；陆昭便先说明只比对纹理，不带走材料，也不要求他停工。两块新榆木的纹路太直，无法形成第三组木套断片的弯曲压痕；桐油里的灰粒则比秤房粮袋底灰细。黑麻绳只有一小卷，纤维没有在空铃内壁留下的铁锈色。许青棠把“不同”也写进记录，避免后人只记相似处。

谢大木见他们没有把铺子封起来，才补充说，北门旧铜片并不是一枚完整铜牌，而是从一块废弃门牌上剪下的三角片。那块门牌三年前就被送回镇尉库，谁有钥匙他不知道。陆昭让他在口供中把“听说门牌已入库”和“亲眼见到买货人持片”分开写，谢大木照做后，自己的手印落在两段之间。

午前，他们回到黑水驿。十一斤补粮的封签即将到三日限期，崔录事带着北镇粮官的复核文书赶来，要求第三户妇人当场选择：收下、退回军仓，或继续暂存但承担霉变损失。

妇人抱着女儿站在檐下，先问损失从什么时候算。顾衡派来的粮吏说封存期间若粮袋受潮，责任由保管方承担；陆昭查看驿仓地面，发现墙根一尺处有水汽，若继续放在原处，三日后确有霉变风险。

“我不领十一斤。”妇人说，“原袋也暂不领。我只要把孩子的鞋带回去，粮由你们按军仓规矩处理。”

田婆婆听见后，把自己的收条递给她，说她愿意代为保管一日，但不替第三户认领。伤兵长子也说医棚能放袋，却只能保证干燥，不能替人作接收。三个人都没有替对方作决定。

崔录事皱眉：“三袋粮各有去处，驿站如何交账？”

陆昭让韩六取来三份收条和十一斤封签，逐项写明：田家已收原袋，伤兵家已收原袋，第三户拒收且要求取回鞋物，十一斤退回外仓待复核。顾衡的粮吏检查封线，确认没有拆封，才在退回栏盖印。

功簿在陆昭怀中微微发热。第一页的空格没有完全合上，边缘却浮出一行小字：“本人拒领，责任不得代转。”

第三户妇人看见这句话并不知道它是什么，只问陆昭能否保证退回军仓的路上不把她女儿名字写进名单。陆昭说，他只能保证自己交出的记录不写；军仓接收后如何归档，应由顾衡和崔录事在文书上各自署名。妇人要求把这句也写进去，陆昭照写。

三日粮道的责任随即收窄：两袋已由本人接收，十一斤封存粮退回外仓，第三户继续拒领但不再承担封存损失。陆昭没有得到新的技艺，听骨的骨纹也没有变化。黑簿承认的是拒绝被完整记录，而不是把拒绝变成功劳。

崔录事要求陆昭在退回封签上写“已妥善处置”，陆昭把“妥善”划去，改成“按原封退回，内含重量十一斤，运送风险待交接”。顾衡的粮吏起初嫌他措辞难看，称军仓文书不该留这么多空白。陆昭指出封签只能证明没拆过，不能证明路上不会受潮，若把风险写成妥善，就会让真正搬粮的人无法说明损失发生在哪一段。顾衡的粮吏沉默片刻，改在旁边注明“交接后由接收方复核”。

许青棠在医棚复核第三户女儿的鞋。她把鞋扣、鞋底和雪地未认领鞋扣并排，却发现两枚扣子的金属含锡比例不同。雪地那枚更脆，边缘有被木套夹过的压痕；孩子鞋扣虽有“北”字，却没有同样的三圈工具痕。

“不是同一枚。”她说。

妇人听到后松了一口气，又问这是否说明狼与孩子无关。许青棠回答：“只能说明这两枚扣子不是同一件物。狼身铜钉、短针和鞋底的工具痕仍要另查。”

妇人点头，没有要求把“无关”写进记录。她把女儿的鞋收好，只在拒领文书上按了手印。

下午，岳成仍未找到。北镇却送来一张回收旧片的清单，列明昨日从木作铺取走一枚“废旧北门铜片”，经手人署名“岳”。字迹比周槐换岗收据上的残字更工整，不能证明是同一人。陆昭要求看原件，送文书的兵卒说原件在镇尉处，不得外借。

他没有让兵卒带走副本，而是请对方在副本背面写明“本件为转抄，不具原件封印”，并由送文书者按手印。兵卒问这样是否等于怀疑镇尉，陆昭说不是，恰恰是因为不怀疑，才要把副本的边界写清。贺停舟在旁边补了一句：真正的官署若怕一行边注，说明它怕的不是误解，而是日后没人能分清谁看过原件。

贺停舟把木杖横在门槛上：“那就请他们派人来当面核对。”

兵卒不敢擅入，留下传话时刻。陆昭把清单副本与谢大木货票放在一起，发现两份纸张纤维不同，墨色也不同。有人确实回收旧片，但不能确认回收人就是买货人，更不能确认旧片已经装进铃架。

黑簿在夜里重新翻页，提示由“木套制作处”改成“旧片去向待核”。陆昭看着那行字，明白第一个问题并非抓到一个姓岳的人，而是让每个“岳”字都必须回到它所对应的纸、物和活人。

顾衡的粮吏把十一斤粮押回外仓时，按陆昭的要求先在驿站门口过秤，再在军仓外院过秤。两次读数相差半两，押粮车夫说雪水进了袋布，粮吏则说秤砣未放平。二人各自留下解释，封绳没有拆。顾衡没有用官印指定哪一次才是真重，只叫另一个没上过车的秤手用同一副秤复称，结果落在两数之间。陆昭把三次读数并列，不取平均；若日后袋内少了粮，必须先分清袋布湿重与粮本身重量，不能让第三户因拒领承担差额。

谢大木听说雪地鞋扣并非孩子那枚，主动将货票上的“岳”字再给一名见证者看。见证者说它也可能是木纹压出的“兵”字下半，谢大木却记得买货人确实说过“岳家会来取”。陆昭把视觉字形与口述分开。若寻到岳成，只能问他有无到铺、买过什么、谁收走旧片，不能拿一张水晕货票逼他替三件事认罪。贺停舟答应查镇尉库旧片出入，不许先动木作铺的剩余薄板。

门外雪线又被风吹开。驿站粮车的车辙却在北道尽头突然消失，像有人把路连同粮一起从地面上抹掉了。

车辙消失处的雪层被分成新旧两圈。押运官只承接内圈封线，车夫只承接自己最后看见粮袋的时刻，陆昭负责外圈影像，不把三人的范围合并成“车辆被妖物吞走”。风向和坡度由锁匠复测，结果显示雪面可能自然塌陷，不能代替搬运者口供。

谢大木在听见旧片清单后，选择允许检查铺门外的木屑，不允许拆开尚未售出的木匣。贺停舟把这个限制写在搜查单上，若后续出现新证物，必须重新询问。陆昭把“曾经回收”与“已经装入铃架”分成两条线，避免半枚铜片替任何活人承认完整的转运责任。
