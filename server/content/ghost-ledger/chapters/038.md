# 第三十八章 百里雪谷

第二座烽台的白火熄灭后，雪谷里出现了三条路。

第一条沿旧驿道向西，路面有黑甲骑士留下的深齿印；第二条贴着冰河向北，只有拖车的浅痕；第三条穿过乱石坡，脚印被风吹得断断续续。贺停舟让罗衍把三条路分别编号，不允许因为黑墨路线曾指向旧渡和西关，便把其中一条写成唯一军道。

陆昭先处理第二座烽台尸体。许青棠重新确认尸温、冻硬程度和颈部勒痕，把死亡时间估在昨夜子初到丑初之间；这个时间段与关印纸短暂出现半个“子”字相近，却没有直接重合证据。她把尸体左耳后的灰麻取样，发现纤维里混着谷壳，不是城门吞令纸的白灰纤维。

秦衡想将“乙九传令”写进副封标题。陆昭拒绝，要求标题只写“军牌刻乙九，姓名未明”。秦衡沉默片刻，选择接受这个限制，承担功簿院副封可能被上级追问的后果。贺停舟把死者军牌交给石棚外的空匣，不让黑甲骑士隔着门取走。

黑甲骑士没有追来，只在第一条路口留下半根骨笛。骨笛插在雪里，笛孔朝向冰河。罗衍要拔出，陆昭让他先测量插入深度和周围雪层。许青棠发现笛身表面没有新血，却有一圈被绳索勒过的白痕。白痕与第二座烽台尸体颈部勒痕形态相近，力度和材料仍无法确认。

陆昭让所有人退到无字木桩后，再由本人选择是否接近。贺停舟选择负责退路，许青棠选择观察伤情和笛面，秦衡选择只作文书见证，罗衍选择取样而不接收骨笛。陆昭承担把骨笛带回北镇的责任，却不把它当作击杀关妖的战利品。

骨笛被药钳夹起时，冰河对岸传来一声短促的号角。号角只响半声，河面便浮出十几张白纸。纸上没有姓名，只有接收、责任和“先行”三栏。许青棠立即报出白纸材质与异常白纸不同：纸纤维粗，边缘有谷壳，未见蜡夹层。她没有用火烧，也没有把白纸称作纸妖。

陆昭让罗衍用木杆拨开第一张纸。纸下压着一枚灰铜扣，扣面刻着“乙九”半字，背面有一道新划痕。军牌、铜扣和尸体军靴属于同一现场范围，却没有直接接触证据。秦衡要求把铜扣交给功簿院，陆昭让他先列出交接人和回收时刻，秦衡只好承认交出原件会破坏北镇封存链。

雪谷深处突然传来拖车声。三条路上的痕迹同时向前延伸，第一条黑甲靴印加深，第二条浅车痕被雪覆盖，第三条断脚印则在乱石后消失。贺停舟判断有东西在利用风雪制造多条路线，但这只能说明痕迹变化，不能认定关妖在操纵道路。

陆昭用无字木桩分别插入三条路口。第一条路的白纸向西折，第二条路的铜扣向北滚，第三条路没有反应。陆昭记录“纸、铜扣、脚印对不同接触的反应不同”，不把木桩当作驱妖阵。封功刀只能切断纸件与责任关系，不能斩断冰河或尸体因果，他没有拔刀。

许青棠在冰河边发现一只冻裂的药囊。囊中有止血散、两枚军医针和一小片刻着“青”的竹牌。她看见竹牌后脸色一变，承认弟弟许青岚曾在军医署使用过同样的青竹牌，但她没有确认这是弟弟的牌，也不把亲属记忆当作身份定论。她选择将竹牌交给第三方复核，自己只负责记录药粉和伤口可能的对应关系。

陆昭没有安慰她，也没有替她把竹牌写进功簿。他让她本人选择是否继续同行。许青棠说肩伤虽痛，仍选择留在雪谷，但不接收任何与弟弟有关的功劳结果。她把右肩牵痛列入记录，要求罗衍暂代重物搬运。这个选择让白纸上的“责任”栏短暂褪色，却没有让竹牌显出姓名。

第三座烽台方向传来连续三声闷响，第一声像铜角，第二声像骨笛，第三声完全无声。守台卒在石棚里被远声惊醒，断断续续说“先验尸，后开门”，随即再次昏迷。陆昭让秦衡记录原话和意识状态，不把它当作第三座烽台的军令，也不把“开门”解释成活人接收。

雪谷上空压下一片灰云，白纸开始向尸体所在的第二座烽台飘回。贺停舟让城防卒守住石棚，自己承担不追击黑甲骑士的责任。秦衡选择封存竹牌和铜扣，许青棠选择把尸体伤情与竹牌药粉分成两份报告。陆昭则把五类尸体证物、半根骨笛、灰铜扣、白纸和竹牌分成九袋，确保任何一袋都不能单独写成结论。

黑簿在他掌下发冷，浮出一句话：“路有百里，功未有主。”

陆昭看见第三座烽台的方向立着一个人影。那人影没有旗，没有军牌，也没有脚印，只把一具裹着灰布的尸体推到雪谷入口。陆昭没有让弩手放箭，而是先让罗衍记录尸体落地时间，让许青棠报出自己是否愿意验看。百里雪谷的下一具尸体，正把未竟之事推到了所有活人面前。

那具灰布尸体停在第三条乱石路外，没有继续滑动。贺停舟让城防卒拉出三道绳线，分别标出尸体、推尸人影和第二座烽台的方向。绳线之间没有姓名，没有军牌，也没有任何可供纸面牵引的接收栏。推尸人影站在灰云下，始终不肯走近，陆昭只让罗衍记“人形轮廓、无足迹、距离未测”，不把它写成妖或证人。

许青棠先验自己的右肩，再决定是否接近。她报出牵痛仍在但没有麻木，选择只带药钳和薄布，不带弩。陆昭承担保护她退路的责任，贺停舟承担不让城防卒追逐人影的责任。三人各自说完选择，白纸上的“责任”栏才没有向他们飘来。秦衡把这一现象写进副本，承认活人选择先于功簿结论。

陆昭让罗衍从上风口绕行，先测灰布边缘的雪压。灰布下露出一只军靴，靴底没有深齿，鞋帮却沾着青白砂。许青棠用药钳挑开布结，发现结法为普通平结，与第一座烽台骨片麻绳三圈不同。她没有掀开头部，只记录布结、鞋底和雪压，避免未核验的尸体暴露在风中。

推尸人影忽然抬手，指向第二座烽台的白火余灰。贺停舟要求它报姓名，影子没有回应。陆昭让罗衍用无字木板写下“指向动作未获本人解释”，不替影子补上“送尸”或“求验”。黑簿没有任何反应，说明这具灰布尸体的未竟之事还没有被功簿承认。

冰河对岸的半根骨笛自行滚动，笛孔朝向灰布尸体。陆昭没有伸手，只让秦衡用空匣隔开笛子和尸体。许青棠发现灰布上有一处圆形压痕，大小与骨笛末端相近，但压痕边缘没有血迹。她把压痕与骨笛白痕分袋，强调形状相同不能证明曾经接触。

守台卒从石棚里喊出一句“别让它替我报功”，声音很快被风打散。陆昭让许青棠确认守台卒意识，许青棠只听见后半句，不能确认前半句是否完整。秦衡记录为残缺口头表达，不构成守台卒本人接收或拒绝军令的完整选择。贺停舟因此把石棚门再加一道木栓，避免纸面把伤者写成证人。

陆昭看着百里雪谷三条路，决定先将灰布尸体留在原位，以无字木桩标出验尸起点，次日再由北镇收尸车运回。这个决定增加了夜间守尸和防冻改证的责任，他本人在交接册上签认。许青棠选择留下第一轮伤情记录，罗衍选择每半刻报一次人影距离，秦衡选择将骨笛送回副柜而不带走原件。

百里雪谷的两队人马在同一片风口停下，各自保留路线图。雪谷中的车痕会被风填平，许青棠便以桩距和药瓶残量校准时间；孙砚只承接自己送药到哪一台，不承接谁从台上消失。陆昭把灰布尸体旁的折纸、眉疤拓样和军医簿领药记录分柜，许青棠可以看，但是否接收身份结论仍由她本人决定。

推尸人影终于后退一步，脚下仍没有雪痕。第三座烽台传来一声短促铜响，灰布尸体的脚趾在布下轻轻收紧。许青棠立即说明可能是冻硬变化，陆昭不许任何人把动作写成尸体复活。黑簿在掌下浮出“路有百里，功未有主”八字，随后恢复冰冷。百里雪谷的第二具尸体尚未验明，所有活人却已经先承担了守住它的责任。

夜守分成两班。罗衍带城防卒守无字木桩，秦衡的院吏在上风口只记录封条和时刻，不靠近灰布尸体。第一班交接时，罗衍数出四个脚印，第二班数出五个；多出的一个是医官搬药箱时留下的，医官本人指出落脚位置，许青棠用药箱底的雪泥对照。若没有这次交接，一枚普通脚印便可能被写成推尸人影留下的证据。

许青棠复看尸体脚趾收紧的记录，要求注明观察者隔着灰布、角度偏东，无法看见皮肤颜色和肌肉状态。她让阮遐在不知先前结论的情况下复测，阮遐只见布面抖动，没有见到第二次收紧。两人把差异同时保留，不互相删改。陆昭则把那句“功未有主”写在个人见闻册，不让它进入验尸结果，因为黑簿提示不能证明尸体身份。

夜守分成两班。罗衍带城防卒守无字木桩，秦衡的院吏在上风口只记录封条和时刻，不靠近灰布尸体。第一班交接时，罗衍数出四个脚印，第二班数出五个；多出的一个是医官搬药箱时留下的，医官本人指出落脚位置，许青棠用药箱底的雪泥对照。若没有这次交接，一枚普通脚印便可能被写成推尸人影留下的证据。
寒风最重时，守尸卒提出把尸体立即运回，以免冻裂。许青棠承认风险，却指出雪层还未完成第二轮测绘；她选择用空布挡风，不移动无字桩内的尸体，并承担冻裂后再验的记录责任。陆昭在交接册上确认这个决定只保护尸体，不等于确认“送尸”者的目的。雪谷静下去后，人影没有回来，空白仍由活人守着，而不是被黑簿替他们填满。
