# 第九十一章 陆昭被结算

旧镇门试开后的第三日，北镇外仓收到一份没有骑印的急递。封面只有六个字：陆昭，已结旧功。送信的驿卒说信在废渡坡下的空木箱里找到，箱底压着一层白蜡，木板没有撬痕。他不认识陆昭，也没有见过写信的人，只负责把东西送到最近的官署。秦衡接信时先问驿卒是否愿意留下姓名。驿卒说可以留姓名和送达时辰，不愿被写成这桩“旧功”的见证人。秦衡照录他的选择。

信纸不是黑皮，也不是门槛上那种无笔压的湿字。它有淡青色的纸纤维，墨痕压进纸里，右下角盖着一枚模糊的半印。半印缺口与总表窄纸上的半印方向相反，印泥却都带细盐。鉴纸师把两块印泥分为甲、乙两号，不许复核官凭“都是半印”写成同一枚印。信上所谓“旧功”没有案号、死者姓名、未竟之事、证据清单或承责人，只在末尾画了一道圈，像某种结算栏。

司空烬看完，把信递给贺停舟。贺停舟没有接，只问：“谁要陆昭承什么？”

没有人回答。信若是真的，陆昭的停职身份会被改成已经承接一桩旧功的镇诡卫；信若是假的，仍有人把他的名字放进了能调动粮械和证物的文书。两种后果都不能由一句“无主之功”带过。司空烬立即下令，北镇所有关于陆昭的结算栏暂时冻结，既不注销他的观察员身份，也不让人凭这封信调开三钥柜、尸骨房或封功刀。

秦衡从功簿院调来旧档索引，却没有带原册。索引显示承熙五十六年曾有一项“收尸役代验，陆氏，旧棚三具”，承责栏为空，状态栏先写“待”，后被朱笔改成“结”。改字笔压很重，穿透两页，背面却没有对应的批令编号。更古怪的是，索引中的“陆氏”没有年龄、籍贯和驿牌号，不能确认就是陆昭。陆昭本人在那一年尚未出生，但这只能排除他亲自执行，不能说明后人没有借他的名字代签。

陆昭被叫到白线外辨认驿牌。牌上的旧刻只有“陆”半字，旁边是一个被磨平的七。他说自己不认得这块牌，也不能判断它属于父辈或别的陆姓。许青棠从皇城送来的复核函提醒，亲属记忆和残字只能缩小候选，不能让陆昭替没有见过的收尸役接收功劳。她还要求记录陆昭的脸色、呼吸和手部情况，避免异常纸件引发的惊惧被误写成反噬证据。

就在鉴纸师准备将信纸收入袋中时，纸面圈内浮出一行浅黑字：承接者，陆昭。字没有笔锋，边缘像被湿气推开，却比门槛字更快干。韩六下意识要按住纸角，秦衡喝止他先戴隔纸夹。守门人记录温度，药吏记录陆昭的脉搏和左手布痕，三人没有一个把字当成命令。陆昭听见“承接者”三个字，左手忽然一阵麻，指尖却仍分不清冷暖。他退到第二条白线外，叫记录吏把这次感觉写成身体变化，不写成功簿反应。

黑簿原册在北镇三钥柜，陆昭没有触碰。司空烬却担心异常字会沿着旧记录找上门，命人把信纸、索引副页和旧驿牌分开置于三处，分别由北镇文吏、功簿院复核官和贺停舟的人看守。这个决定让复核速度慢了许多，夜间调粮也多出一道核封手续。顾衡指出，若因守一张纸延误底粮，责任要写在院方，而不是推给陆昭的名字。司空烬在调度单上承认多耗两名夜守和半盏火油。

秦衡又查出一份旧棚修缮名册。名册上有“陆昭”二字，却是今年才补写的蓝墨，补写者在页边留了自己的短押。短押与半印不合，说明至少有一名活人曾把陆昭名字补进旧棚档案，但不能证明此人制造了急递。补写者是旧棚守人后人，承认自己为申请修缮粮，把“陆氏旧收尸”写成祖上经历；他愿意撤回这笔称谓，却不愿承担别人借名结功的后果。司空烬让他分别签撤回与不知情两项，不把撤回推成认罪。

修缮名册的蓝墨还在三处材料申请上出现：一处写木楔，两处写石灰。秦衡请不知争议的文吏做墨色盲比，结果只能确认同一批蓝墨，不能确认同一支笔。旧棚后人承认自己曾借用公房笔，另外两张由谁填写仍未知。司空烬没有因同墨便扣押后人，只把三页分别封存，并要求木料商、石灰仓和修缮队逐项回报经手时刻。名字进入档案的途径变多，反而更需要把每一条路留给反证。

这一来，几条看似相连的东西被拆开：旧总表的“陆氏”可能是年代更早的收尸役，蓝墨补写是今年的修缮申请，急递的半印又来自尚未识别的文书链。它们都围绕陆姓和旧棚，却没有共同纸纤维、共同印泥和连续交接。陆昭把这三项写在副图上，写到“共同”二字时错听成“共功”，秦衡让他停笔复读。陆昭当众更正，承认左手失痛和错认风险仍在，改由第三镇文吏抄写。

夜半，急递背面的白蜡出现一道细裂，裂口里掉出一粒青白砂。药吏用盲码盒将砂粒与旧驿石槽、黑布匣、门槛旁青白砂逐一比对，粒径相近但盐分不同。第三方鉴验认为至少有三种来源可能：旧墙填料、河堤车辙带入、或某种装箱垫料。砂粒不能证明急递经过三联旧棚，更不能证明它由妖诡写成。司空烬不许任何人因“青白”两字把样本并案。

天亮前，司空烬发出一纸暂缓告示，内容只有事实范围：陆昭姓名出现在三类记录中；记录的形成时间、经手人和接收权限未明；陆昭未作本人接收，暂不承担所谓旧功的结算责任。告示同时保障他继续领取基础粮和伤药，却暂停他接触结算档与封功器具。陆昭没有把这看成清白证明，只在告示末尾签下“已阅，不等于同意”，并请求由活人见证其签字范围。

告示还写明，任何人若以陆昭名义调粮、开柜或召集镇诡卫，须同时出示本人选择记录和两类独立证据。没有这两项，只能按普通行政请求转交，不得挂入功簿。这个限制会让紧急调度多一道核验，顾衡要求在粮仓门边另放一份空白应急单，先发救命物资、后补查证据，免得有人借“暂缓”克扣活人的粮。陆昭同意承担配合复核的时间，却不承接由他人擅自使用姓名造成的损耗。

贺停舟看着那行字，说一个人可以承认自己读过文书，却不承认文书替他做了选择。司空烬说，若这条边界成立，旧总表上许多“代结”都要重新拆开。代价是功簿院会失去一部分迅速结算的便利，功劳和责任的追问会拖慢边镇调度；但若不拆，陆昭的名字只要被写上一次，往后每个空栏都可能变成他已经答应过的事。

门外又传来旧镇门复核的木楔声。门槛没有新字，旧信却在封袋里轻轻收缩。守门人只报温度变化，不报“纸在回应”。陆昭望着自己的名字被三份不同的纸分开保管，第一次明白“被结算”也可以是一种强加的债。没有死者，没有未竟之事，没有两类独立证据，更没有他的接收和新责任，功簿四步一项都没有完成。有人想让他先背上结果，他只能先把“未同意”留在记录里。

陆昭被结算的异常来自急递、旧索引窄纸、蓝墨名册和旧驿牌四条链。承熙五十六年尚无陆昭，说明他不可能亲自执行，却不能据此指认后来补写者。暂缓告示冻结结算栏、调柜、尸骨房和封功刀权限，基础粮药照发；外仓值夜吏记录封袋重量未变，纸面收缩未改内容。陆昭明确拒绝急递和旧功，错认风险继续记在伤情簿，不以异常字面替代本人选择。

外仓值夜吏另记封袋每刻钟重量未变，排除了纸面收缩造成内容增减的猜测。

为防止“被结算”再次借急递扩散，司空烬要求所有涉及陆昭姓名的文书先经过三人复读。第一人只核姓名出现位置，第二人只核记录形成时刻，第三人只核本人有没有作出选择。三人中任何一人听见“已受”“已结”之类结果词，都必须停笔，另起异常栏。陆昭接受复读职责，却不进入结算柜；他把自己能承担的部分写成读号、报错和确认封签，不能承担的部分写成代签、认功和触碰封功刀。

顾衡提出把基础粮药从告示附页删掉，免得有人误以为院方已经认定陆昭无责。司空烬否决，认为救济和结算必须分栏，不能用停发粮药逼人接受旧功。贺停舟在门边复核三钥柜封签，发现一处蜡面有细裂，来源可能是低温收缩，也可能是搬柜擦碰。他只记录裂痕，不把它与急递纸材并案。

三人复读开始前，司空烬让陆昭先说自己今日是否疲劳。陆昭承认左手麻意比昨日更早出现，便只负责第一层的页码和封签号。第二人复读时把“旧功撤项”听成“旧功入项”，陆昭听出不对却没有抢话，而是让记录吏保留两种口述，再请第三人回看原页。第三人确认是撤项，错读者在更正栏签名。复读没有因为人人都小心就变快，院方另拨一盏灯和一名替班文吏，保证停职观察员不靠硬撑换取清白。

急递送来的蓝墨名册有一页边缘被雪水浸软，姓名栏没有脱墨，时辰栏却少了两个字。司空烬要求先晾纸再抄，不准用同批蓝墨猜补。晾干后只能辨出“卯后”，具体时刻仍缺。贺停舟把这页列为缺项，陆昭在自己的名字旁写“出现，不等于选择”，并要求凡涉及他的文书继续三人复读。缺时辰让交接链更短，却没有因此把急递直接判伪。

蓝墨页晾干后，纸背露出一行被压平的旧格线，格线与旧总表窄纸的宽度相差两分。鉴纸师只能说两种纸曾用相近尺规裁过，不能说出自同一张大纸。司空烬把尺规测量列为待核，并承担再取样的纸耗；贺停舟提醒所有人，格式相似最容易让人提前相信“同源”。陆昭复读这条提醒时，把“相差两分”读成“相同两分”，立即要求重读，错听记录又添一笔。
