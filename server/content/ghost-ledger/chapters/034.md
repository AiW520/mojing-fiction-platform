# 第三十四章 第一座烽台

去第一座烽台的路没有军旗。

贺停舟把出行人数定为六人：陆昭、许青棠、贺停舟、秦衡的书吏、罗衍和两名城防卒。陆昭提醒他是七人，贺停舟看了看站在门口的周梅，说明她可以同行到城外旧驿，却不进入烽台，也不替周循接收任何结果。周梅选择跟到烽台脚下，只负责辨认弟弟留下的身份物和铃声，不负责认领关外尸体。

秦衡原本要把两名功簿院随从也带上，陆昭要求先列每个人的责任。随从一人负责关印副本，一人负责封袋；若有任何人要求带走原件，必须由本人在交接栏签字。秦衡接受这一限制，承认功簿院的核验权不能覆盖北镇已经承担的证物保管。

第一座烽台建在黑石坡上，台身只有三层，台顶的旧火盆被白霜封住。山脚有两道车辙，一道向北，一道向西。向北的车辙轮距接近城外白蜡轮木车，向西的车辙则只有半轮宽，像一辆车在雪坡上被拖过。贺停舟先让罗衍测轮距，不让任何人踩进车辙。

许青棠发现向北车辙边有细白蜡，向西车辙旁则有黑骨粉。两种痕迹都未与城门外样本直接重合。她把取样位置、雪层厚度和风向逐项写下，右肩牵痛在搬动药箱时加重一瞬，她立即选择减轻器械重量，不拉弩，由罗衍负责照明。

烽台门锁没有被撬。锁孔里塞着一截纸卷，纸卷外层写着“守台已接”，内层却是空白。秦衡的书吏要求取出，陆昭先让贺停舟确认锁孔周围没有新的铁屑，再由许青棠用药钳夹纸。纸卷离开锁孔时，台顶火盆方向传来一声闷骨响。

众人抬头，第一座烽台的铜角上挂着一片白骨。骨片被麻绳缠过三圈，绳结与雪沟反扣结相似，却没有黑麻纤维脱落。周梅看见骨片上的一道缺口，认为和弟弟旧皮囊的骨牌缺角相近，但她只同意记录形状，不确认骨片属于周循。

陆昭把骨片留在原位，先检查台顶灰烬。灰烬分三层：最上层是新雪和木炭，中层有纸纤维和青白砂，底层则混着极细铜屑。三层灰的水分和颜色不同，说明至少经历两次焚烧或覆盖。许青棠取样时没有碰骨片，秦衡也没有用关印副本压住灰烬。

“守台的人呢？”罗衍问。

台内无人回应。木梯上却有一串擦痕，从第三阶一直延到台门，痕迹不是鞋底，而像重物被拖过。陆昭查看擦痕方向，发现上行与下行宽度不同，不能直接判断是尸体、粮袋还是车轴。听骨只能用于尸骨最后受力方向，他没有触碰任何骨片或疑似尸体。

秦衡的书吏打开纸卷外层。纸上“守台已接”四字遇到灯火不变色，遇到湿布却从右向左褪去。内层空白处随即浮出一条红线，牵向台顶骨片。陆昭让所有人退开一尺，先问秦衡是否愿意承担纸卷与骨片接触的后果。秦衡选择只记录，不让功簿院副印参与。

红线越过火盆边缘，骨片上的麻绳自动收紧。麻绳绷直后，台外向北车辙里传来一声铃。陆昭让罗衍记录铃声与红线收紧的时间差，罗衍写下“先铃后线”还是“先线后铃”无法凭听觉确定，只能标为同刻待复核。没有人把铃声当作守台人回应。

贺停舟走到烽台外墙，发现石缝里嵌着一枚深青铜屑，形制与黑甲骑士关印边缘相近。铜屑没有印面纹理，也没有血迹。秦衡承认它只能说明某种深青铜物曾擦过石墙，不能证明黑甲骑士到过第一座烽台。贺停舟选择把铜屑留在北镇旧关印样本旁，但不合并封袋。

台内忽然传来咳嗽声。

罗衍拔刀半寸，陆昭抬手让他停。众人按原位置退到门外，只有许青棠把药钳放在身侧。咳嗽声再响一次，来自台下地窖，不像纸张折动。贺停舟确认地窖门上有旧封条，封条年份与当前军令不符，不能直接撕开。

“若里面有人，等一刻钟会死。”罗衍说。

“若里面是妖，贸然开门会让它借人名进城。”陆昭回答，“先问门后的人愿不愿意被救。”

他让罗衍朝地窖门报出姓名和职务，说明北镇只会打开一道缝，里面的人可以选择回答，也可以保持沉默。门后没有回话，只有指甲刮门的声音。许青棠根据刮痕长度判断像人的手指，却不能据此确认活人身份。

陆昭让贺停舟承担开门后的城外接应，秦衡承担封条原件保管，罗衍承担救出活人的搬运，许青棠承担伤情复核。各人明确选择后，贺停舟才用木杖挑断旧封条边缘，不碰正中朱印。门缝打开，一名守台卒滚了出来，胸前没有刀伤，嘴里却塞着一团被咬碎的军令纸。

守台卒尚有气。他看见周梅，试图说出“乙十七”，却只咳出黑粉。周梅没有替他解释，选择让医署先救人，自己只确认他不是周循。许青棠把碎纸从守台卒口边夹出，发现纸上残留“第三烽台”“不许开火”半行字，墨迹被唾液和黑粉混成一团。

陆昭没有触碰守台卒的骨头。他让许青棠记录口腔伤情，秦衡记录碎纸位置，罗衍记录救出时刻。守台卒的活人证词未完成，碎纸却与城门外被吞的“取粮”军令存在语义关系。两类证据仍未闭合，因为还缺发令者、接收者和守台卒本人愿意承担的后果。

守台卒抓住陆昭袖口，断断续续说：“不是……西关……它先吃令……再吃人名……”说完便昏过去。陆昭没有把这句话写成完整口供，只标注“意识不稳、需复问”。

台顶骨片突然折断，白骨缺口落入灰盆。灰盆中的黑粉迅速聚成一个没有五官的纸脸，脸上三道横线对准守台卒。陆昭让罗衍把人移到无字木板后，许青棠以药钳压住纸脸边缘。她右肩牵痛加重，却仍先报伤情，再选择继续压制，不把动作申报为功。

陆昭取出封功刀，没有直接斩纸脸。他先确认红线是否连着守台卒姓名，确认无红线后才切断骨片与纸卷之间的细线。纸脸塌成黑灰，骨片、麻绳和碎纸分别落地。刀口只断关系，没有伤到守台卒，也没有让黑粉消失。

黑簿在陆昭胸口发热，第一页仍未翻开。它只浮出一句：

“守台未死，军令未完。”

第一座烽台暂时保住了活人和原始证物，却暴露出通往第三座烽台的更深黑线。守台卒醒来前，谁也不能确认关妖究竟吃掉的是命令、名字，还是承担命令的人。

回城前，陆昭让众人在烽台脚下重新核对封袋。碎军令的纸纤维带着唾液盐分，城门外被吞的军令则有冰水浸痕；两者都出现黑粉，却不是同一处理时序。麻绳三圈的结法只能说明有人把骨片固定在铜角上，不能证明结绳者就是送令骑士。秦衡把差异写进副本，并承诺不以功簿院旧格式抹去任何空栏。

许青棠给守台卒做了第二次伤情记录：口腔黏膜有细小划伤，右手虎口冻裂，胸骨无明显压陷，尚不能据此判断他曾被纸脸拖拽。她的右肩在压制纸脸后牵痛加重，选择减半夜间弩值，由一名城防卒接替。贺停舟把撤离顺序写在无字木板上，仍不写“已救”二字，避免把尚未稳定的伤者提前结算成结果。

烽台验尸时，守台卒要求把灰甲尸体移入暖棚，以免骨缝继续冻裂。许青棠同意救护，却先让木匠画出尸体原位、台阶积雪和灰粉落点。移尸由三人见证，搬动方向和缺失物件均记在原位图上。陆昭没有用骨笛靠近尸骨，听骨残技只在陈砾案中有效，新的灰甲死者仍须靠军牌、口供与身体特征逐层确认。

陆昭最后看了一眼台顶。白骨缺口落入灰盆后，黑粉没有追向守台卒，而是沿第三阶擦痕向下散开。那条痕迹可能通往地窖，也可能只是重物拖行后的残屑，他没有用听骨去碰任何骨片。众人带着活人和分项证物下坡，第二座烽台在远处没有亮火，像一枚未被承认的空印。

下坡前，许青棠让阮遐把守台卒的口腔、虎口和胸骨记录复读一遍。守台卒本人仍未清醒，任何沉默都不作为选择；城防卒愿意承担护送，拒绝替他回答第三台求火声。陆昭把这项拒绝写在伤者栏旁，提醒秦衡：证人未能作答并不等于证词不存在，只是证词暂不能进入第三步。黑簿没有因救人动作改变，黑粉也没有自行靠近军牌。

贺停舟在台脚设置三枚无字桩，分别标出原位、搬运线和雪层被踩区域。镇南校尉想把三枚桩写成“已封关”，卫岑要求改成“保护范围暂定”，因为第三座烽台尚未确认是否有人进入。双方争执后，由罗衍在桩旁挂上时刻牌，牌上只写开始保护和预计复测时间，不写结案或斩妖。陆昭负责把这份争议记录交给司空烬，不替任何一方决定军法含义。

下坡途中，一名伤兵指向灰盆，称看见里面有“半张脸”。许青棠先检查他的体温和意识，再请他说明自己是亲眼看见、听人说起，还是在火光中猜测。伤兵选择只提供“火光里像有影子”的见闻，不愿把自己写成纸妖目击者。陆昭把见闻与灰盆黑粉分袋，强调感知受伤、烟尘和灯火影响，不能用一句惊惧描述替代物证。

回到临时棚后，秦衡提出把灰甲尸体、碎军令和第三台求火声合并为一份“关妖待结”案。陆昭拒绝，他要求尸体、军令和声音各自保留编号，待找到死者身份、独立证据和愿意承担的活人再决定是否并案。司空烬的使者记录了这份拒绝，却没有强行改标题。第二座烽台仍未亮火，北镇却先把不能证明的部分写得清清楚楚。
