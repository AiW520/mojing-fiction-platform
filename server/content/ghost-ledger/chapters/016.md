# 第十六章 北镇授印

北镇没有在明夜之前打开城门。

镇尉使者带走原件封袋后，留下的不是复核回执，而是一道“待议”批语。批语承认陈骁死于北道附近，却避开了他的最后方向，也没有说明羊骨牌从何处来。许青棠把批语放在医署灯下看了三遍，最后只说：“这张纸能证明他们收到材料，不能证明他们接受材料。”

陆昭把话记在路线复核单上。黑簿一夜未动，陈骁名下那条细线停在北门两个字边上，像一条没有铺完的路。车棚里，半块羊骨牌、断鞋带、两组手印拓样和铁钉分列四处。活人手印已被雪覆盖，拖痕却因夜寒凝结成浅灰色的硬纹，若再拖一日，风一吹便会碎。

“镇尉说午时前要清场。”守门什长送来口头传令，“车棚、河沟和北门外都不得继续占道。”

陆昭问他有没有正式文书。什长摇头，说传令者是镇尉亲兵，穿深青短袍，腰上没有铜片。陆昭让他把姓名、时刻和“口头”二字写清。什长苦笑：“我已经因为按手印被问过一次。”

“所以更该写第二次。”陆昭说，“一张记录若只留在一个人手里，就会变成他自己的记性。”

什长看了看棚里四组证物，最终在空白栏按下手印。陆昭没有阻止他清理道路，只要求先用木框罩住拖痕，把取样后的雪层、车轮压痕和河沟细线各拓一份。清场责任由北镇承担，陆昭只负责把拓样送入医署与镇诡司各一份。这个分界写在交接单上，守门什长看完，第一次主动要求副手陪同见证。

许青棠带着医署拓本回来。她没有拿回旧门簿，只拿回一张复核期限：三日内可向北镇司申请查看原册，三日后若无异议，原册按封存档处理。期限很短，短到足以让风雪替所有没有抄下的字作结。她把期限交给陆昭，问他是否要把“许”字列为家属线索。

“由你决定。”陆昭说。

许青棠沉默片刻，在医署副本上写：“残字涉及本人家事，允许作为物证关系核查，不允许作为身份确认。”她又在下方写明：“若三日内无法复核原册，我选择暂不公开弟弟姓名。”两句话都是她的主动选择，不是陆昭替她挡下来的。

贺停舟从北门赶来，带着一面旧铁牌。铁牌只有半枚，边缘刚好嵌入那块被剪过的旧木牌。他说这是从镇诡司废库调出的同批门牌，调取经过顾衡签批，原物只能看一刻钟。铁牌背面有七个浅槽，第七槽内残留一粒红蜡，与羊骨牌背面的蜡色接近；但铁牌上的红蜡是冷裂，骨牌上的蜡是热融，不能判同一炉。

陆昭让贺停舟把铁牌放在白布中央，先拍正反两面，再请许青棠比对孔眼。孔距和羊骨牌第六、七孔接近，却相差两分。许青棠说可能是同一类钻具，也可能是不同工匠按旧模仿制。贺停舟没有把铁牌指向旧案经手人，只在交接单上写“废库调取，限时归还”。

陈骁姐姐也来了。她收到北镇批语后，没有哭，也没有骂，只把弟弟的腰牌放到证物桌边：“我不认军令，也不认冬祭。可若他最后真的往北门拉过绳，我愿意让这个方向给还活着的人看。”

陆昭将她的话拆成两栏：同意公开最后受力方向；拒绝把方向解释为军令执行或祭礼自愿。姐姐看完，要求再加一项：“若有人因这方向去找家属，先由我决定是否见面。”这项选择意味着公开证据后可能出现的追查责任仍由活人承担，功簿上的第四格因此终于出现了第一道完整的边线。

然而第二格仍没有合上。许青棠把北门路线图、陈骁右手绳痕、车棚水线和旧门铁牌摆成四件独立物证，解释它们各自证明的范围：路线图证明有人记录过车行方向；绳痕和听骨证明陈骁最后向北门横拉；水线说明尸鞋或湿物曾被拖过车棚；铁牌和羊骨牌说明旧门存在同类孔位与蜡封。四件证据互相指向，却没有一件单独证明陈骁曾执行祭名单。

“那就再找一件。”陆昭说。

他想起陈骁衣领里那半张军令上的“七袋”“不入仓”。若路线与军令属于同一趟车，旧渡的换马记录应当还有一份。可换马册在镇门封档内，半枚铜牌不能调阅。陆昭于是请顾衡的记功吏把前线缺粮文书与北门换马册的索引号并列，申请只核对页码和时刻，不带走原册。顾衡的记功吏提醒，索引不等于内容，不能把“有一页”写成“页上有陈骁”。陆昭让他把这句限制也写进申请。

午前，申请尚未回执，镇诡司却派人送来一只木匣。木匣上盖着北镇现用印，匣内放着一枚完整的青铜镇诡卫印，印钮是一头伏在雪上的狼。送匣的庞复核官说：“陈砾首段功已结，三日粮道责任完成了两户交付和一批退回。你保住了证物，也没有代人认功，北镇暂授你镇诡卫印。”

陆昭没有立即接印。他问授印文书是否写明权限。

庞复核官把文书展开：“可查北镇驿路、外仓与封门证物；可请求一名记功吏、一名医官和一名城防见证随行；不可擅开军仓，不可代家属认领，不可凭功簿单独结算。”

这是第一次有人把他的责任写在晋升旁边，而不是只写一枚印能做什么。陆昭接过印，先在文书上写明左手失痛、浅裂和复测时刻，再请许青棠检查他是否能安全握印。她说可以，但要求印柄不得交给失去痛觉的左手。

庞复核官又递来一张北镇授印名单。名单上只有陆昭一人，随行三格空着。陆昭没有把许青棠、贺停舟和韩六直接填上，而是分别询问：许青棠愿意作为医官见证，但不接受代她公开家属线索；贺停舟愿意作城防见证，但不替旧案承担功过；韩六愿意继续收尸和保管车路，不愿进入军仓。三人的选择被各自写入授印附件。

黑簿在此刻翻到陈砾名下，原先“首段已结”的字旁出现一枚小小的封印，却没有释放新技艺。陈骁名下的路线线条则向前延伸，仍停在一处空格前。陆昭明白，授印不是第二次结算；它只是把查验责任交给了一个有名字的人。

城外忽然传来一声惨叫。失踪车夫的家属在旧渡找到一具被炭灰覆盖的尸体，尸体左脚穿着深齿军靴，右脚光着，脚踝上缠着半截黑麻绳。守门什长说，尸体旁还有一块被咬碎的羊骨牌，牌上只剩编号“七”的下半。

众人要出门，庞复核官却拦下他们：“授印尚未入档，半枚铜牌不足开闸。”

陆昭看向北门闸链，再看向木匣里的镇诡卫印。他可以用新印请求开门，但开门会让封门责任、尸体保全和城外家属安全同时落到他身上。若不开，尸体可能被雪水浸烂，羊骨牌也可能被人先取走。

他没有让黑簿替自己选。陆昭请陈骁姐姐、失踪车夫家属、许青棠和贺停舟分别说明选择。陈骁姐姐愿意让弟弟方向继续查，但不承担车夫案；车夫家属愿意让尸体入城验看，但要求保留右脚鞋与绳子的副本；许青棠愿意开闸验尸，前提是城外伤情由她独立记录；贺停舟愿意承担开闸后的城防见证，不负责追捕。

四人的选择满足了开闸这一件事，却没有替功簿完成陈骁的未竟之功。陆昭在授印文书上签下限定责任：开闸一刻钟，负责尸体、羊骨碎片和绳端的入城保全；不负责确认车夫是否参与祭礼，不负责将两案合并，不负责补写失踪者姓名。庞复核官看完，才允许司门按时开闸。

闸链升起，黑水河的风灌进城门。陆昭把镇诡卫印挂在腰间，仍把收尸牌压在最外层。一个新官职没有替他遮住旧身份，反而让更多人知道每一具尸体该由谁记录。

城外尸体被抬近时，陆昭看见右脚踝的黑麻绳结打成三道半结，和陈骁掌心绳痕相合，却没有立即写成同一根绳。许青棠在尸体颈侧发现一处针孔，药童在炭灰里找到青白砂。贺停舟则在旧渡雪下找到一枚新鲜车辙，车辙向北门而来，轮距与收尸车不同。

四项证物摆在北镇门下，功簿仍没有结算。第十六章的爽点不在印落下来，而在陆昭拥有了第一次可以调动三类见证人的权限，却必须把权限锁在证物和时限之内。

他低头看着黑簿最后一行：

“未结之功，不因授印而改名。”

风雪越过门槛，带走一粒炭灰。陆昭抬起右手，示意先封尸、再查车、最后验骨牌。

北镇的第一枚正式印章，在一具尚未确认姓名的尸体旁，开始承担它真正的重量。

印章收回牌房前，司吏用干纸和湿纸各拓一次，湿拓边缘晕开半寸。两份拓样分别编号，不能把清楚的干拓替湿拓补全。陆昭要求记录每次拓印的操作者、纸张来源和晾干位置，防止日后有人用一张漂亮拓样覆盖另一张不稳定的事实。

许青棠让林漆妻子复读自己的授权，妻子把“知道接触事实”改成“知道接触事实及保管期限”，并拒绝扩大到纸上文字。更正由她本人按印，医官只见证不代写。家属的边界因此成为案卷的一部分，而不是附在案卷外的口头请求。
