# 第七十章 失去名字的村

第三镇河水恢复下行后的第二日，位于第四镇边界的南汊村，村民开始忘记彼此的名字。最先发现异常的是村医。他给一名跌伤的老人换药时，能认出伤口、屋舍和药量，却想不起老人叫什么。老人也记得自己住在河弯第三户，记得有三个孙子，却只会指着门框上的空木牌说“那是我家”。

镇医把“失名”拆成三项：口头叫不出名字，木牌上的字褪去，户籍册中的姓名变成空格。三项并非同时发生。村东七户只失去木牌，村西四户连户籍册也缺字，还有两名孩子仍能叫出自己的小名。村民没有因此被写成死亡或被妖吞名，镇医要求每个人本人选择是否登记可用称呼、旧物和亲属关系。

卫岑把第三镇河道案的巡骑分出一半守渡，另一半进南汊村。两名巡骑愿意承接门牌拓样，三名村民愿意承接自家物件来源，村老韩荻愿意承接村界和水位见闻，但不愿替全村确认谁的名字被夺。陆昭仍站在白线外，由记录吏逐户朗读选择，不接触户籍册原件。

村口有一座旧祠，祠门两侧原本挂着百户木牌。如今木牌全变成光滑白片，只有挂绳磨痕留下。祠堂地面却有新湿泥，泥里压着十九枚鞋印，大小和方向各不相同。村民说昨夜无人进祠，守门孩童只听见水声，没有看见人。鞋印不能替失名者证明曾经到过祠堂。

韩荻领他们查看村西户籍柜。柜门没有撬痕，锁芯里却塞着细白芦花。柜内册页被水汽浸湿，缺字处并非撕掉，而是纸纤维像被指甲刮过，留下浅毛边。三户家属拿出旧婚书、药方和借粮条，能够证明姓名曾在日常物件中出现，却不愿把这些物件交给镇诡司永久保管。文吏按本人选择做拓样，原件由家属带回。

药吏在祠堂后墙找到一条浅水沟。沟宽一尺，水从河边向祠堂流，沟底有黑蜡碎屑和四根芦苇茎。黑蜡与河中陶罐封蜡颜色相近，却没有共同植物纤维；芦苇茎的切口新旧不同，不能据此认定河水带来失名异常。许青棠远程要求把“相近”标成材料候选，把“同源”留空。

午前，一名叫小岚的女孩主动来到村口。她能清楚说出自己的小名，却不知道户籍上的大名。母亲拿出出生时的红布包和一张接生婆手写的纸，纸上原本有名字的位置变成一片空白。小岚同意镇医记录“小岚”作为当前称呼，拒绝让巡骑替她猜大名，也拒绝把空白纸写成死亡证明。

这一选择让村里其他人开始争执。有人要求镇诡司把所有人的名字先写回去，认为只要有人代填，河妖就会退；也有人担心写错名字会把活人绑定到别人的债和旧案上。卫岑没有替他们投票，只让两边分别说明愿意承担什么。愿意临时登记的人承接复核和更正，不愿登记的人只承接撤离路线，不因沉默被写成拒绝救助。

村西第三户的老人突然认出一块磨平木牌。他说那是已故妻子年轻时挂在粮柜上的牌，却叫不出妻子的名字。家属愿意确认木牌来源，不愿确认木牌上的人已经死亡，更不愿把老人的记忆当作全村失名的解释。陆昭让记录吏把“物件认出、姓名缺失、死亡未证”分成三格，防止情绪把证据推过一步。

午后，南汊河水又升高半尺。祠堂白牌同时出现一条湿痕，像有人用水指写过字，转眼却只剩四个没有笔压的空格。四名村民愿意记录看见湿痕，没人愿意把空格解释成四个名字。卫岑命巡骑封住祠门，不许撕牌或用墨填字；村民可自愿撤到高地，留下者按户登记。

第二组巡骑沿浅水沟寻找来源，在河堤下发现一只倒扣的木盆。盆底有五道刻痕，每道旁边都留着空白。木盆内装着两枚户籍柜锁片和一小团黑蜡。锁片属于村西户籍柜，黑蜡与陶罐封蜡只有色泽相近，不能证明盆里有人刻意抹名。文吏封盆时，村老韩荻承接物证位置，拒绝承接是谁放置。

小岚的母亲在此时改变选择。她愿意把女儿的小名、出生时辰和红布包的来源写进临时索引，但不愿把大名交给任何官署，直到接生婆本人到场。镇医尊重这项限制，只在伤情和撤离表上使用“小岚”。这不是拒绝救助，也不是拒绝功劳，而是把身份确认留给真正能承担的人。

一名村民却私自拿炭笔在三块白牌上写字。第一块写成自己的名字，第二块写成邻居的，第三块只写了一个“水”字。字迹落下后，祠堂的空格同时变黑，写字者手背却出现细小水泡。药吏先处理伤口，卫岑让他本人决定是否承接书写事实。他承认三块字都是自己写的，但不知道第二块邻居是否同意，也不愿承接邻居生死。三块木牌分开封存，不能把反噬当作妖物已现的证明。

许青棠在皇城收到样本拓片后指出，白牌空格没有木屑，炭笔字却有清晰压力；异常空格和人为添字不是同一层材料。她要求第四镇把失名分为“记录缺失、本人记忆缺口、异常纸面”三案并列，禁止用一张总表把三者写成河妖夺名。阮遐回传第二镇伤情无变化，九名未归者仍未找到，第二镇的无名尸不能成为南汊村的参照尸体。

傍晚，村东七户中的五户选择撤离，另外两户愿意留守牲口。撤离者由巡骑带到高地，粮食按本人签领取用；留守户只承接牲口和屋舍，不承接失名者的统一结论。卫岑把河堤封线、祠门封存、撤民人数和临时称呼四项责任分别交给不同的人，避免一个印章替全村接收。

陆昭听着“临时称呼”四字，想起功簿四步里的活人选择。他没有碰黑簿，也没有把小岚的选择写成死者未竟之事。左手失痛依旧，浅裂边缘发白；错认风险在看到三块炭笔字时升起，他主动让记录吏遮住木牌，只听本人朗读来源和承责范围。

夜里，祠堂门外的十九枚鞋印被新水冲掉了七枚，剩下十二枚仍无法对应村民。韩荻愿意承接鞋印消失时刻，不愿承接鞋印属于谁。河堤下的木盆没有再出现黑蜡，户籍柜锁片和白牌按三处证物柜分存。南汊村暂时保住了人、牲口和撤离路线，却仍没有找回任何一个被抹去的正式姓名。

第二日的回传写得很慢：第四镇存在姓名记录异常，部分村民保有小名和物件关系，部分户籍与木牌出现空白；人为添字造成轻微反噬，但尚不能证明有夺名妖物。第四镇四十七户待核中已有三十一户完成本人选择，剩余住户要求家属或接生婆到场。河水继续下行，村子却像被留下了一层没有门牌的影子。

第四镇文吏复核户数时发现，第三镇急报里的四十七户指沿河待救人家，南汊村的四十七户则是本村待核户籍；两个数恰好相同，册页、村界和填报人却不相同。他把两张表各钉一枚不同颜色的线签，拒绝将第三镇十九户撤离者挪入本村三十一户选择栏。韩荻也只按村界作证，不替上游住户认名。水位可以跨镇传来，签过字的责任不能跟着水漂过去。

第四镇失名村的第一项救助是让每户能领药，不是立刻恢复户籍姓名。小岚愿意用小名领取水和药，拒绝他人代填大名；三十一户同意临时称呼，两户撤回，文吏把撤回时刻和原因写清。门牌空白、户籍黑砂和井边乳名声分别取样，不能因为四十七户与第三镇沿河户数相同就合并。许青棠的复核署提醒，失去名字是行政事实，不等于失去生命。

陆昭在总表上把第四镇写成“失名待核”，而不是“无名已死”。他在备注中加上：名字可以暂时缺席，活人不能因此失去选择；证据尚未指向功簿，责任却已有人接住。远处河面传来裂口船铃的回声，南汊村没有人替它喊出主人。

失名村的救助站先发药，再处理户籍。三十一户临时称呼各自领取水和药，药袋上只写领取编号，不写推定大名。两户撤回同意后，文吏当场收回旧牌，却保留撤回前已经发生的领药事实。韩荻承接井边水样的保管，不承接任何一户的姓名恢复；她要求每次开柜前先读出自己授权的三项内容。

接生婆到场后，四户补充了乳名与出生时节，但她们也明确说记忆可能有误。文吏把口述拆成“本人自述”“他人见证”和“待查旧册”三栏，不能因为接生婆熟悉孩子就直接恢复大名。许青棠的复核署建议先做药物和身份风险筛查，拒绝让复核署代替家属决定是否公开乳名。伤情与户籍仍是两条责任线。

第三镇传来的两船铃声与南汊井边乳名声在时刻上相近，陆昭让人把两份回传放入不同柜。相近时刻只说明同时发生，不能证明一声铃跨过水道替一户人家报死。水卒愿意提供原始录音，村民却拒绝让陌生人抄录哭声；两种选择都被保留，失名不被强行换成失踪。
