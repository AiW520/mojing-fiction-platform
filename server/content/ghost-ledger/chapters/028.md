# 第二十八章 斩妖不斩证人

证物房的门没有开。

门外三层封条完整，门内的木箱却在自己移动。第一只箱子装城门簿，第二只装东市假功单，第三只装乙十七木牌和灰布纤维。三只箱子本来分放在不同架上，此刻却被一条细红线牵成一列，线头穿过箱缝，指向门后的旧姓名柜。

贺停舟让守卒退到廊柱后，不许拔刀。陆昭先查看封条，确认秦衡、北镇和医署三方蜡印都没有被破坏。许青棠在门外复测右肩，选择只用空箭管和药钳，不拉弩；秦衡选择让书吏记录，不让随从先冲入房内。陆昭把四人的选择写在门槛白板上，随后才要求开门。

门内的空气有一股湿纸味。

白纸从第一只箱子缝里伸出，先贴向城门簿，再贴向第二只箱子的假功单。它没有写名字，却让两处“接收栏”同时凹陷。第三只箱子里的乙十七木牌轻轻翻面，背后的“周循本人”白纸开始鼓起。

“先取哪一件？”秦衡问。

陆昭没有替他选：“你负责功簿院文书核验。若要动第一箱，先说你承担哪一段；若不动，就在旁记录。”

秦衡选择先记录，不直接取箱。贺停舟让城防卒把旧姓名柜前的通道封住，承担不让纸线进入户籍册的责任。许青棠把一块无字木板放在三只箱子之间，观察纸线是否改变方向。

纸线没有被木板吸走，反而绕过木板，朝门外一名守卒的腰牌卷去。守卒名叫石七，他的腰牌上有军籍编号和“已领冬衣”的旧字。纸线在腰牌边停住，守卒本能地伸手去按。

“别碰。”陆昭喝住。

石七停住，问自己是不是已经被纸写进去了。陆昭让他先选择：愿意让医署观察腰牌，不愿意把姓名和军籍写入异常记录。石七按下两栏，许青棠把腰牌放到空木盘中。纸线果然缩回箱缝，却在箱面写出“已证”。

这一次纸面出现的不是姓名，而是一种责任结果。陆昭把“已证”与石七本人选择分开登记，明确石七没有承认纸面文字。贺停舟让石七退到门外，城防责任由自己接管，不让守卒继续站在牵引范围内。

白纸忽然从箱缝里钻出半尺，纸面折成一张没有五官的人脸。脸部没有眼鼻，只有三道横线，像旧模板上的姓名、接收、责任。纸脸朝秦衡转去，秦衡后退半步，书吏的笔却仍在记录。

“这就是纸妖？”随从拔出短刃。

“先别替它定名。”陆昭说。

纸脸向书吏扑去。陆昭用右手抄起空木夹，夹住纸脸下缘；许青棠用箭杆尾端压住纸线，不让它碰到书吏的手；贺停舟将木杖横在两人之间，阻断纸脸与旧姓名柜的直线。三人的动作各有边界，没有人把纸脸当成活人。

纸脸发出一阵细响，像十张纸同时翻页。它的表面浮出“周循”“陆昭”“周梅”三个名字，随后又将三名下方的接收栏填成“已交”。周梅正站在门外，她看见自己的名字，没有伸手，也没有否认，只说：“我不接这张纸给我的结果。”

她的选择一说出口，纸脸上的“周梅”立刻裂开一道缝。黑簿在陆昭怀中发热，却没有结算。陆昭让许青棠确认周梅是否愿意继续留在门外见证，周梅选择留下，但不进入证物房、不接触纸脸。

秦衡此时提出用功簿院的封功刀斩纸。那把刀专门切断异常文书与官印的牵连，但若纸线另一端仍连着姓名柜，可能把柜中数十户姓名一起撕出。陆昭要求秦衡说明刀的使用责任和失败后果。

秦衡承认功簿院愿承担刀口判断，却不能替北镇承担户籍册损毁；贺停舟随即补充，户籍册一旦损毁，城防与民户追索会由北镇负责。陆昭因此选择不让功簿院直接出刀，先把纸线从三只箱子分开。

他让石七从门外读出自己的选择，不读纸面三个名字。石七只说：“我同意腰牌验看，不同意接收任何功。”纸线从腰牌旁退回，第一只箱子上的城门簿“乙十七”字迹随之变浅。

陆昭趁纸线松动，把三只箱子分别推回原架。每次移动前，他让负责保管的人确认：罗衍的城门簿由北门承担，抄写铺假功单由医署与功簿院共同承担，乙十七木牌由周梅限定见证、北镇封存。责任被拆开后，纸脸的三道横线开始错位。

纸妖没有立刻消失。它把自己折成一把薄刀，刀尖指向贺停舟手里的旧案模板。贺停舟没有躲。他把旧模板放到地上，先声明自己同意让纸面接触，不同意让旧案中的军需官姓名被重新写入。纸刀贴到模板时，模板上“功成”二字迅速变黑。

“现在。”贺停舟说。

秦衡把功簿院封功刀递给陆昭，却没有替陆昭决定。陆昭选择承担切断纸妖与旧模板的后果，先让许青棠确认纸线未连户籍柜，再让贺停舟固定模板。许青棠报出右肩牵痛未加重，选择继续只用左手协助，不拉弩。

陆昭一刀切下。

刀刃没有碰到纸脸，而是切断模板边缘一根几乎透明的红线。红线断开的瞬间，三只箱子同时落地，纸脸塌成一团空白纸。白纸上的姓名没有消失，却从“已交”改成了空栏。旧案模板也裂开一角，露出里面一行被刮去的字：“本人拒绝。”

贺停舟看见那行字，闭了闭眼。他没有把它说成军需官最后的遗愿，只要求书吏照录原样。秦衡承认这一刀只证明纸妖依附模板关系，不能证明纸妖就是旧案制作人。

门外忽然传来三长一短的敲击。灰袍人站在廊尽头，手里没有刀，只有一叠写满残缺姓名的纸。他看见纸妖塌下，转身便走。贺停舟没有追，陆昭也没有下令放箭。

“他是证人。”陆昭说，“先封住路，不要斩他。”

城防卒封住两侧，灰袍人却把一张纸抛向屋檐。纸片在半空展开，写出“周循已进城”。周梅在门外主动说：“我愿意看这张纸，但不认它代表我弟弟。”纸片因此停在风中，未能贴上她的手。

灰袍人趁停顿消失在雪墙后，只留下半枚灰布纤维和一滴普通黑墨。陆昭让守卒封存纤维，不追入民巷；秦衡接受“斩妖不斩证人”的处置，书吏记录灰袍人逃离而非认定其为纸妖。

证物房重新封门。石七的腰牌、三只箱子、旧案模板、断红线、纸脸残片、灰布纤维和普通黑墨分项入柜。黑簿在陆昭掌下显出一句新字：

“证人不替功，妖不替人。”

封存前，陆昭让每一名保管人当面复述自己的范围。罗衍只对城门簿的入柜和封条负责，不对簿上添字负责；医署书吏负责假功单的纸袋和纸脸残片，不负责判断纸妖是否已经离开；周梅的见证只限乙十七木牌和灰布纤维，她再次拒绝把弟弟的姓名写入任何接收栏。石七把腰牌交回城防，不再站到姓名柜前，贺停舟则把旧案模板单独放入无字木匣，避免模板与今日纸脸残片再次接触。

秦衡要求在封条上加盖功簿院朱印，陆昭同意盖在外层副封，不同意覆盖北镇原封。秦衡承认两层封条分别代表核验权和保管权，日后若要开柜，必须同时通知三方。许青棠记录断红线的长度、颜色和两端纤维，发现它在切断处呈毛刷状，并非刀刃直接削平；她把“红线自行收缩后断裂”的观察列为纸妖反应，不写成封功刀的新技艺。

门外的灰袍人留下的普通黑墨被滴在空白对照纸上，墨色先晕开，再沿纸纹下沉，与异常白纸不扩散的墨迹不同。陆昭因此只把灰袍人列为可能掌握纸面材料的证人，不把黑墨当作纸妖本体。贺停舟在廊柱上补画两条撤离路线，一条通往民巷，一条通往北门水沟，要求城防只设哨、不设伏；若灰袍人再次出现，先截住纸件，保留其开口和选择的机会。

斩断纸妖牵引后，活人仍需回答各自愿意承接什么。石七只承接看守粮门，周梅只承接弟弟物件，严鹤只承接钥匙，杜乙只承接搬运时刻。陆昭把这些选择逐项读回，任何人都可撤回尚未发生的后果。纸墙因此塌了一角，却没有凭空消失；残纸被封入干燥盒，等待查出它依附过哪些责任关系。

这一夜没有新的技艺结算，却第一次斩断了纸妖与旧模板的牵引。纸妖仍在城内，周循仍未找到，功簿院的预录单仍等复核；但活人没有被一张纸强行写成已承担者。

封存后，秦衡要求把“纸妖仍在城内”写进功簿院日报。陆昭提醒这句话包含地点判断，当前证据只能证明异常纸在北门、东市和证物房出现过，不能证明本体始终未离城。秦衡把日报改成“异常纸面曾在城内出现，去向待核”，并在修改处留下本人签名。司空烬听到后没有追问谁更谨慎，只要求日报与原始时序表同柜，避免摘要脱离证据。

周梅第二次来访，带来弟弟周循用过的半枚铜牌。她愿意让医署比对木纹和缺角，却拒绝让陆昭把铜牌放入姓名柜。陆昭让许青棠先问她是否了解比对可能产生的后果，周梅选择只接受材料比对，不接受身份结论扩展。铜牌与乙十七木牌的木纹有两处相似、一处断裂方向不同，结果被记为支持与排除并存，不能单独完成第一步。

证物房守卒提出把空木箱换成铁柜，理由是纸妖可能再次伸纸。贺停舟先询问铁柜是否会刮伤残纸，木匠用废纸做了封存演示。演示显示铁柜边角会留下新压痕，守卒于是选择继续使用木箱，但在箱外加两层无字板。这个选择没有把防护措施写成制服妖物，只增加了保全责任。陆昭负责把演示纸与正式证物分柜，并在交接册中注明未接触原件。

天亮前，灰袍人留下的普通黑墨瓶被发现少了一指深。罗衍怀疑有人取样，灰袍人却未现身。许青棠让医署清点瓶口、塞蜡和桌面落尘，发现瓶口无新指纹、桌面有一处被袖口擦过的弧痕。弧痕只能证明有人靠近，不能证明取墨者身份。黑墨仍被列为材料证物，纸妖与灰袍人的关系保持待核，没人借这个缺口追加一笔功。
