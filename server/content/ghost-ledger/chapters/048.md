# 第四十八章 三镇联书

北镇城门内，三张长案拼成一张不完整的桌。桌面左侧放关印副令复制件，中间放第六页三份拓本，右侧放无人村的空铃、湿木牌、半焦木牌和石满的选择板。所有原件仍在分柜，联书只能引用编号，不能把复制件变成原件。陆昭先写下这条限制，秦衡才肯把功簿院的空白格式铺开。

卫岑提出第一条：西关承认第三台军令未完成接收，暂缓调药和取粮。镇南校尉提出第二条：镇南承认旧渡扫痕和关后车痕只由斥候见证，不据此追认车队身份。贺停舟提出第三条：北镇承认封门、护送、粮耗和伤员转运责任，任何一项损失都留在北镇账上。三条都有人愿意签，却没有人把“九人已接”写进联书。

秦衡指出，若联书只写各自承担，便无法形成对关妖的共同约束。陆昭回答，共同约束不等于共同结论，三镇可以约定不改原件、不代活人接收、不追认无名车队，但不能约定一名不存在的接收人。许青棠在旁边补充，伤情和尸骨的复核也必须保留异议栏，否则亲属辨认会在誊抄时被磨成最终身份。

石满被请到案前。阮遐先问他是否愿意让三镇引用自己的见闻，石满选择同意引用“车声九下、村人离开、未见死亡”，拒绝引用任何“已归”或“已接”。秦衡把这两种选择分行记录，并注明石满的指印只确认本人说过，不确认事情本身全部真实。石满没有反对，反而要求把“不知道”两个字保留在联书上。

联书写到第五行时，空铃突然发出闷响。第六页拓本上的“反送”两格分别渗出一道灰线，灰线没有碰到原件，只沿桌面向三份副令复制件移动。陆昭让所有人停笔，先测量灰线距离与闷响时刻。闷响落在石满选择板之后，说明语义牵引可能依附共同书写，而非单独依附空铃。

许青棠用远距铜钉压住三份复制件之间的空白处，右肩牵痛立即加重。她选择由阮遐替换铜钉，自己只报线头位置。铜钉没有斩断灰线，反而让灰线分成三股，分别指向三镇的“承担”二字。陆昭要求每镇删去一句形容词，只保留具体行动和时限。卫岑删去“忠勇”，镇南校尉删去“紧急”，贺停舟删去“已妥”，三股灰线因此减细。

这次变化让陆昭提出一种尚待复验的解释：关妖也许不需要完整军令，只要把人的自我评价写成结果，便能借共同文书扩大牵引。秦衡承认功簿院旧格式中的“功成”二字可能正是最容易被利用的词，但他拒绝承认功簿院因此就是关妖制造者。陆昭把他的保留写入联书异议栏，没有把怀疑写成指控。

三镇开始重写联书。第一部分只写已观测事实：第三台有两格“反送”，接台栏被黑线划穿；两名活脚确认本人选择；无人村有九个桩位、两根短桩被拔、两只不同空铃；关后车痕轮距六尺一，旧渡扫痕未见扫痕者。第二部分写证物编号和分柜位置。第三部分写各镇承担的护送、封门、复核、粮耗和不追击责任。第四部分单独留出“未竟与待选”，不填姓名。

许青棠在“灰布尸体”一栏写下“身份高度相符，待第三方复核”，并附上阮遐医案、甲三领牌册和尸骨特征编号。她拒绝将第六页许青岚笔画直接抄成姓名确认。石满在“无人村”一栏写下“我只认见闻，不认生死”，齐三和贺七的选择则由本人补入附件。三镇都必须在附件上承认，附件不能替代失踪者选择。

秦衡忽然指出，联书中的“共同封存”可能被纸妖解释成所有人共同接收。陆昭便把词改为“分别封存、互相见证”，并列出原件保管人：第六页与门栓由北镇，西关副令与药车清单由西关，扫痕图与斥候口供由镇南。任何一镇调阅，都要留下时刻、理由和本人签押。这个安排增加手续，却让责任不再能被一句“共同”吞掉。

空铃再次响了一声。第六页拓本的灰线退回纸边，桌面没有出现“已结”。黑簿在陆昭掌下打开，先显出四步规则，随后在第四步旁写出“共同守关，分柜担责”。没有技艺名称，也没有力量涌入。陆昭知道这不是升级，而是三镇第一次把责任制度化。可黑簿灰线向卷四方向延伸，像有人正在等待更高的文书来收回他们的选择。

三镇联书由卫岑、镇南校尉、贺停舟和陆昭共同签押。卫岑签的是军令未完成与药车留置，校尉签的是扫痕不追认与斥候责任，贺停舟签的是北镇封门、护送和粮耗，陆昭签的是证物分柜、时序复核与不代活人认责。秦衡在末尾加注：功簿院仅收副本核验，不取得原件和地方接收权。

签完后，纸面出现一个很淡的“掌”字，像墨迹从纸背顶出。秦衡脸色变了，说这不是三镇任何人的笔迹。陆昭没有拔封功刀，先让所有人离案，再以无字板盖住“掌”字。盖板下传来一声细小的纸裂，三镇联书却没有被撕破。陆昭命罗衍封存盖板和纸屑，注明异常字样未获本人选择，不得当作掌院亲临的证据。

夜深时，司空烬的功簿院急函抵达北镇，函上只有一句：“联书既成，地方功簿当归院复核。”函印是真的，时辰和接收人却空着。贺停舟看完没有开门，卫岑把急函放进副柜，镇南校尉把斥候撤回城内。陆昭在回执上写“已收文，未交簿”，并让秦衡见证。

秦衡提出可以先交一份黑簿目录，陆昭问目录是否会包含未结之功的姓名和活人选择。秦衡答会。石满听见后摇头，说自己同意三镇引用见闻，却没有同意把姓名送给不在场的人。陆昭因此把目录拆成证物编号、责任时限和待核事项三栏，删去姓名与功簿内页。秦衡虽然担心此举违背功簿院惯例，仍在副本上写明“活人选择未授权转交”。

急函背面很快浮出一枚淡淡的黑印，形状像掌心，却没有指纹。许青棠远距观察后指出，黑印边缘有纸纤维翻起，不是印泥渗入；她要求把函背单独封袋，不能据印形认定司空烬已经按印。陆昭让秦衡记录发现时刻，贺停舟则把急函从联书旁移开，避免“掌”字异常与功簿院来函被误并为同一纸源。

卷三没有斩出一门新技艺，却让三镇在关妖逼迫下保住了各自的选择。第六页的两格仍未还原，许青岚和乙九的未竟之事仍未结，关后无人村也只留下一个活人证词。陆昭合上黑簿，左手失痛尚未完全退去，新的责任却已经先于掌院的脚步抵达：功簿院要收回的，不只是一本黑册，还有三镇刚刚写下的“不替天下认名”。

为防联书在夜间被重抄，贺停舟把三镇签押的原纸分别收进三只封柜，柜钥由三名不同的保管人持有，任何一人都不能单独开启。秦衡只带走编号副本，并在副本背面写明抄录时刻、纸张尺寸和缺失栏位。副本中没有石满的完整姓名，只有“关后村唯一自愿作证者”这一称谓；石满确认这样的称谓不会代替他的姓名选择，才在见证栏按下指印。

卫岑与镇南校尉还各自提出一项可执行的复核时限。西关在两日内比对药车清单、甲三药袋和车痕轮距，逾期须把未完成原因写入联书附件；镇南在三日内复测旧渡扫痕与无人村消失点，若无法找到扫痕者，必须保留“未见扫痕者”的原句。北镇则负责在第三台封门前复核第六页两格的撕裂方向。三项时限均由本人承接，没有被写成对失踪者的代办。

急函被移入副柜后，陆昭让罗衍在柜外画出函件与联书的距离，作为后续比对的基线。函背黑印旁的纸纤维翻起方向朝外，联书上淡“掌”字的纸裂方向朝内，两处形态并不一致；这只能说明两种异常痕迹目前不可直接合并，不能据此排除同一势力的间接利用。秦衡将这项保留意见抄入副本，承认功簿院既未收原件，也未获得活人选择的转交许可。

三镇联书签发前，三镇文吏互换的只是事实页、物证索引和本人选择页。司空烬急函上的黑印没有被抄进联书正文，只作为异议附件保留。陆昭要求每镇写出自己不知道什么，第三镇写船工去向，北镇写骨笛来源，关镇写两名缺席者。联书因此不够漂亮，却能让下一镇知道不能从哪里开始妄猜。

陆昭最后把四步规则写在联书封面内侧：先确认死者与未竟之事，再取两类独立证据，随后由相关活人亲自选择，最后由自己承担结算后的责任。第47、48章只有共同守关和分柜担责形成了第四步的局部承接，死者身份、未竟事项与活人接收仍未同时闭合，因此不得登记新技艺。封柜合上时，黑簿只留下“未替”二字，提醒所有人责任可以共同承担，结论却不能共同冒领。
