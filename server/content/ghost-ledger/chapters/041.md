# 第四十一章 两军相撞

北镇收尸车刚到雪谷口，西关的黑甲骑兵也从旧驿道压了下来。两支队伍隔着三道无字木桩停住，谁都没有先拔刀。北镇车上载着灰布尸体与九只证物匣，西关车上载着两名冻伤的军卒和一车药粮。雪桥只能过一辆车，桥下冰水又正漫过木桩，等待本身会要人命。

黑甲骑士这次带来一名有姓名的军需校尉，叫卫岑。卫岑交出关印副令，令上有发出时辰和他的签押，却仍缺第三台接收人的手押。他承认西关缺药，要求先让伤员过桥，再将“乙九传令”遗体交给军需处。贺停舟说可以讨论伤员，不把伤员与遗体捆成一笔交易。卫岑没有反驳，只要求北镇给出每刻钟的过桥计划。

陆昭看过桥面。北侧两块木板有新铁钉，南侧旧榫已经裂开，若两辆满载车在中间相遇，桥会从旧榫处折断。他拿木尺量轴距，西关药车比北镇收尸车宽半尺，不能擦肩。罗衍将裂榫、车宽和河面上涨高度画在一张无名图上，让双方各自确认看见的部分。卫岑的马夫在图旁签了车宽，拒绝为桥的承重签字。

许青棠先验西关伤员。第一人小腿冻坏但尚能说话，第二人胸口箭伤失血，必须在半刻内止血。她右肩牵痛，不能把人独自抬上木板，便请孟岚和两名西关卒协助。卫岑答应让药箱先过，条件是不得从中取走军医署旧册。许青棠指出药箱清单与旧册本就是两种物件，伤员用药可由她按量发放，旧册仍留在北镇副柜。卫岑接受，命令马夫先卸药车，不越木桩。

黑甲骑士却把半根骨笛举到嘴边。第三台铜角应声转向雪桥，桥面白霜里浮出一行“乙九已交”。卫岑立即让骑士放下骨笛。他也看出了麻烦：倘若让这行字替军需处接尸，日后西关一旦查错军牌，所有人都要背冒领军功的罪。骑士说自己奉的是更上层军令，没有报出发令者。卫岑要求他把原令交来，骑士只给出一个空铜匣。

陆昭没有同骑士争令。他把北镇收尸车拆下两块旧车轴木，借西关药车的绳索在桥边搭成临时窄板。伤员可由四人抬过，车辆原地不动。贺停舟在桥北布置退路，卫岑在桥南压住马队，双方各出两名抬担架的人，责任按所属军籍记录。木板承不了一车粮，却足够过两个人。这不是谁向谁让步，而是把最急的一件事从争执里单独拿出来。

第一名伤员过桥时，白霜上的“已交”字沿木板爬向他的担架。许青棠让抬人者报出各自愿意承担的事：北镇卒只负责桥北接应，西关卒只负责桥南抬送，孟岚负责药量，自己负责伤情。四人没有一人说“乙九已交”，霜字便停在板缝。陆昭用干布覆盖板缝，令罗衍测字迹出现到停止的时刻，不用封功刀砍活人脚下的桥。

第二名伤员抬到桥中央，骑士忽然催马。马蹄震得旧榫裂开一道新缝，卫岑喝令后队勒住，自己下马抓住桥绳。贺停舟让罗衍先固定担架，不追骑士。陆昭右手顶住车轴木，左掌的浅裂被粗绳磨开，他仍没有感觉到痛，只看见血在麻绳上晕开。失痛让他无法判断握力是否过大，便把结绳交给卫岑，自己按图指挥两侧先后收紧。

伤员上岸后，西关士卒欢呼了一声。卫岑没有趁势索尸，先让军医确认胸伤仍在出血，又命人将桥南药粮按车号封住。他问陆昭，若北镇肯让药粮过桥，西关能给什么回执。陆昭说接台栏有姓名、时辰、药量和实际接收人四项，缺任何一项，都只能写“已送到桥南”，不能写“第三台已收”。卫岑把这话抄在副令上，自己先签押“愿担桥南车粮”，不替第三台签押。

孙砚从第三台旧哨屋传来消息：七日前的九人名册原本有一道折边，失踪两人的格子被裁走，裁口压着一层药蜡。卫岑要求把裁口送给西关查，许青棠只同意做双份拓样，原件仍按先前封存链保存。她对卫岑说，西关军医若要复核，可以派有姓名的人到场，不能以一支没有发令人的骑队把册页拿走。卫岑答应派一名军医来，并把到场时辰写在副令背面。

桥另一端却有第三支人马靠近。他们披着镇南旧甲，打的是“收回逃祭者”的旗。旗上七个墨点与北镇旧祭名单相近，但布底比旧旗新，旗杆端有补接的铁箍。贺停舟认出甲式，却不认旗主。来人声称按照旧功单，第三台两名缺席者属于镇南逃役，要西关和北镇一并交人。

卫岑侧身挡住桥南口。他提醒镇南领兵者，西关伤员尚在北镇医棚，任何冲桥都会危及人质般的伤者；他不肯以一个无时辰旧功单为镇南开路。领兵者拿出有封印的副本，印面并非假物，问题在于副本写着“九人已接台”，没有两名缺席者的本人签押。镇南不是毫无凭据，北镇也不能凭相似旧甲便宣布对方是妖兵。

陆昭将九人油纸和镇南副本隔桥并排举起，让各方自己看见空栏与“已接”的冲突。孟岚确认油纸出自自己的药箱，孙砚的“未接台”拓样由秦衡展示；卫岑确认副本的印式可用，却不承认印式能证明实收九人。领兵者听完，提出至少查验北镇车上的灰布尸体。许青棠拒绝他隔布认人，说明亲属只签了“高度相符、待第三方复核”，卫岑也没有权力代她揭布。

两军的弩都已上弦。贺停舟算出镇南若冲桥，木榫最多撑三十步，冰河会吞掉所有人和两车药粮。他没有喊“大军后退”，而是请卫岑当众确认西关愿不愿先保住伤员与药粮。卫岑说愿意，并命马队退到旧驿道石线；镇南领兵者见桥南空出一段可谈的地，暂时也令弩手松弦，但要求一个时辰内得到正式核验地点。

陆昭在地图上圈出三处：北镇医棚验伤，第三台哨屋验册，雪桥两侧验车。没有任何一处同时交尸、交令和交人。卫岑签下西关边界，镇南领兵者只签“到场见证，不认可结论”，贺停舟签北镇桥防。三方不和，却都被各自能承担的纸面限制住。许青棠把伤员送入医棚时，肩伤再次牵痛，主动退出下一轮抬运。

黑甲骑士在众人签押时没有动。他耳后的姓名纸被雪水浸透，纸上隐约出现一个被抹去的“接”字。陆昭让罗衍远距记下，不强揭薄纸。骑士忽然问：“若他们两人不是逃役，是谁把药送到了第三台？”卫岑转头看他，第一次要求他在众人面前报自己的军籍编号。骑士仍未答，驾马退入旧驿道。

黑簿在陆昭怀里轻轻一震，只写“桥已过人，令未过关”。两名伤员获救、药车免坠，是这场相撞里可核验的胜果；两名缺席活脚与灰布死者的去向，仍没有被任何印章解决。陆昭手上的血染红桥图，他把图交给罗衍保管，自己不再握绳。一个时辰后，三方将在第三台哨屋重新对上那张被裁去两格的名册。

两军相撞后的第一轮清点只清出受伤者，失踪者仍按最后站位列候选。卫岑愿意承接撤退路线，贺停舟承接城门开合，齐三和贺七分别承接自己的伤情。任何人都没有资格把未归者写成已死。许青棠让伤兵亲自选择是否接受军医复查，拒绝者仍可领药。陆昭把战场上的空位也画进图中，空位不是尸体，却是必须追问的责任。

阮遐在伤员担架脚下取出一片被压裂的白蜡，确认它来自药车旧轮而非桥梁新木；贺停舟在旧榫旁找到一枚西关铁钉，钉口没有镇南旗布纤维。两件物证分别说明药车确曾靠近桥、旧榫确被新钉加固，却不能替任何一方认定谁先动了桥。卫岑和贺停舟各自在封签上写下“只证接触，不证冲突起因”，随后才让人把伤员送入医棚。

伤员入棚后，许青棠让每个人先选择是否接受第二次触诊。齐三同意，贺七只同意看伤口不拆绷带，另一名镇南弩手拒绝触碰但愿意领取药。三种选择分别列在伤情单上，拒绝者仍有领药回执，不能被写成拒绝救治。阮遐把白蜡碎片的取样人和封袋人分开，避免同一双手同时决定物证意义。贺停舟复测桥榫承重，发现木屑落在南侧而不是中线，说明受力偏向，却不能证明哪支队伍先冲桥。

卫岑要求把旧驿道石线的撤退令读回两遍。第一遍有人把“保伤员”听成“保军旗”，第二遍当场改正。陆昭的左手失痛仍在，他把自己错听的字另行登记，没有参与最终军令复述。三方因此多花一刻钟，却保住了伤员选择与军令原文之间的距离。

复读后，卫岑把命令拆成路线、药车和撤回条件三栏。镇南校尉只承接自己收到的副令，不承接缺角处的文字；贺停舟承接桥面封线，不承接反向车辙；许青棠承接伤员复查，不承接未归者的生死。三栏分别留有反证位置，谁补写都必须说明来源。

一名伤兵选择不让人拆开左臂绷带，却愿意口述自己听见的两次铃声。药吏把伤口观察与听闻分开记录，陆昭不以听觉代替死者身份。撤退队因此少了一名搬运人，贺停舟承接重新分配的火油，具体耗量按袋登记。
