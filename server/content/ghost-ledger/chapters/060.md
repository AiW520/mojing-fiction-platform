# 第六十章 许青棠立署

许青棠没有把“伤亡复核台”设在镇诡司正堂。她选了第七仓西侧一间废弃药房，门上原有的军医署牌被拆下，换成一块没有官印的木板，只写“伤情、物证、本人选择”。木板下留三道空栏，分别供医官、证物保管人和当事人填写。司空烬到场时，第一句话不是问她要什么品秩，而是问这块牌子由谁承担法律责任。

“我承担医案和伤情复核。”许青棠说，“证物由贺七和罗衍分柜，活人选择由本人亲自写。凡是功劳、死因和军令效力，复核台只出材料意见，不替镇诡司下结论。”

司空烬看向贺停舟。贺停舟的旧印已经封在三钥盒里，不能用来给废药房挂名。他回答，北镇只承认这处复核台是临时证物协作点，不授予调兵、开柜或定功权限。掌院似乎早料到这个答案，拿出一份临时署样式：院方可认可材料格式，但不直接任命署长，不接管活人选择。

许青棠没有立即接纸。她先让阮遐、孟岚和曹弥叔父分别说明愿意在复核台做什么。阮遐愿意搬运和盲验，不愿被写成许青岚身份的最终裁定人；孟岚愿意提供甲三药袋时序，不愿扩展到两名缺席活脚；曹弥叔父愿意让牙医继续复核，不愿让家属候选索引进入功劳名单。三人逐项按印，复核台才有了第一批真实边界。

陆昭坐在门外旁听席，停职权限仍未改变。许青棠让他复述三人的范围，他把孟岚的“药车时序”误听成“药车接收”，当即停下，请孟岚本人重新说。孟岚没有责怪他，只把“时序，不含接收”写得更大。许青棠把这次错认作为复核台的第一条反例：材料名称相近，授权范围仍可能不同。

复核台的第一项工作是重新检查封诡阵井沿霜样。许青棠安排两名医官先盲测盐分和骨粉，第三名无涉案文吏只记录编号。结果霜样松烟含量高、骨粉颗粒长，黑账夹层骨片则短而脆；两者都来自牲畜骨或加工残端的可能性较高，但无法确认同一动物、同一地点或同一操作者。阵匠要求用霜样去试阵，许青棠拒绝：“材料测试不等于施术授权。”

第二项工作是旧功单三户选择。第一户后人把避雪木牌交来，授权复核木牌和柴票，仍不授权户籍转入；第二户邻里授权复核代写回函，拒绝补写妇人姓名；第三户没有活人到场，复核台只把撕口、麻线和黑账空格列为待核。三项被放入三个封袋，任何一袋都不能填满第三户的空栏。

司空烬问许青棠，若复核台只报告不能确认，功簿院如何利用它。她说：“可以利用不能确认的边界。若你要一个结论，就去找对应活人和两类证据；若暂时找不到，就把空白留给下一次复核。”

掌院没有反驳，只让秦衡记录这句。随后他提出交换：功簿院提供一套标准医案纸和显微镜片，条件是复核台每月向院中报送编号、伤情类别和未结数量。许青棠接受器械，不接受报送姓名、家属选择和功劳结果；她在器械领用单旁加写“用途限于材料复核”。司空烬在院方栏盖印，承认这是资源交换，不是权力接管。

贺停舟来送三钥盒的封存副本。许青棠要求把旧印交接的时限、保管人、退席条件和阵法损耗一并列入复核台的公共板。卫岑认为这些属于城防，不应由医官记录；贺停舟反而同意，因为阵灯、药车和住户撤离已经互相影响。许青棠把城防内容放入“关联责任”栏，不把它改写成伤情结论。

中午，废药房外出现一张无笔压白纸，纸上写着“许青棠，已立署，代全镇验伤”。纸边没有蜡膜，折痕却与第50章总表不同。围观者以为这是对她的任命，许青棠让所有人退开，自己不去碰纸。她问在场活人是否接受这句话，没有一人点头。

陆昭指出纸上“代全镇”把有限责任扩大成总责任，可能沿着新署的责任关系牵引。许青棠让罗衍记录纸张位置和出现时刻，再由她本人写下：“我只接受复核台职责，不接受代全镇认名、定功或替活人选择。”她的字有真实笔压，墨色与白纸字迹不合。白纸上的“代”字随即淡去，留下三枚针孔；针孔间距与第50章总表不同，纸材仍需分柜。

司空烬看完，提出撤掉“立署”二字，改称“临时医案点”，以免异常纸面借正式官署牵引。许青棠拒绝，她认为名称不能因异常纸而被迫退让；她愿意在木板下加注“无定功、无调兵、无代选择”，让职责边界公开。掌院同意，双方第一次围绕一个名字达成的是限制条件，而不是谁拥有命名权。

下午，复核台给出第一份正式材料意见：封诡阵井沿霜样与黑账骨片均非已确认人骨；旧功副页与户牌齿轮存在机械牵连；阵灯临时供油可维持至次日午时；药车炭盆方案能保止血粉温度，但须每刻巡查。意见末尾列出四项反证位置和三项本人选择范围，没有“阵妖已除”“曹弥已死”或“功簿已结”字样。

这份材料意见让北镇各方都不满意，却没有任何一方能说它错。阵匠得到可执行的齿轮隔离条件，顾衡得到明确的油耗时限，司空烬得到可以纳入统一尺度的格式，家属和药车夫得到没有被扩大的选择边界。许青棠把原件封入复核台内柜，副本分给各责任人，任何人不能单独改动。

黄昏时，黑簿在陆昭身旁显出一圈浅白，没有文字。许青棠问他是否感觉到功簿在回应新署。陆昭摇头，左掌仍失痛，封诡阵的责任也没有结算。那圈白只是黑簿对“未替”旧印的牵动，不能解释为新技艺。

贺停舟把三钥盒的退席条件交给许青棠：若他因旧腿、城防或追责无法到场，卫岑与贺七不能自动合成他的选择，必须延时并说明药粮代价。许青棠把这条写进复核台章程，随后请曹弥叔父确认候选索引仍只在内层。老人确认后，复核台第一日的记录完成。

夜里，许青棠独自检查右肩。牵痛没有加重，但她的手臂不能长时间拉弩。她没有把建立复核台写成无伤功劳，也没有把器械资源写成掌院赏赐。她在署牌背面补了一句：“先验伤，再验物；先问本人，再谈功劳。”

司空烬离开前说，明日功簿院会根据临时署格式申请读取北镇部分副本。许青棠答应按编号提供，不交姓名与活人选择；若院方要扩大范围，须重新取得本人授权。掌院没有强行取走原件，只把申请时限写在门外。

陆昭站在复核台门槛，看见旧印、黑账、霜样、药车和家属索引被四种颜色的封绳分开。停职让他不能替别人开门，许青棠立署却让更多人学会在门口先问一句“你同意到哪一步”。黑簿依旧没有翻页，新的责任却已经有了一个不靠单一官印维持的屋檐。

复核台收门前，阮遐与另一名医官交换了各自的盲验图，确认两人在不看姓名的情况下都把水渠尸体列为无名。许青棠把一致项和分歧项分别写出：牙位相合，死亡时辰仍有半日差，颈部浅压痕的施力方向尚无共同结论。她要求明日先复核水渠水位和搬运痕，不准凭“同意无名”推得“同意死因”。

许青棠立署的第一天，复核署没有掌功名，只掌伤情、死亡记录和更正权。她让每名医官写出自己不能判断的部分，连“未见伤口”也不许改成“没有伤口”。右肩牵痛发作时，她由副署医官代写，自己只口述并复读。独立不是一个人变得无所不能，而是让另一双眼睛能够在她受伤时继续工作。

复核署收案时，先把提交人分成三类：本人到场、家属代送、官署转抄。本人到场的伤情可以当面复读，家属代送的物件必须另问是否愿意进入案卷，官署转抄则只证明曾有一份文字经过，不证明原作者仍同意公开。阮遐在第二镇药房按这三类重排旧单，发现两张“家属同意”其实只有邻居代签，遂退回补问，没有把退回写成拒绝。

秦衡提出用功簿院的统一表格替换四卷旧表，许青棠要求先做一日空白测试。医官拿同一块木板分别填“未见”“未检”和“未确认”，结果三栏在旧表里会被压成同一个小格。她因此保留四卷原格式，并让院方在副本上标记可比字段。统一字段的好处是检索更快，坏处是把不确定削平；两种代价都被写入试行意见，不能只报其中一面。

陆昭送来自己的失痛复测。左手能辨温凉，仍不能判断木片尖角是否危险；他没有要求复核署替他宣布停职结束，而是选择暂停触骨和抬尸。许青棠给他安排两日由他人握笔、自己口述的替班，替班粮和记录耗材由司空烬承接。伤情没有被变成免责，反而成为调度表里一项必须有人接住的现实。

秦衡问新署若与功簿院结论冲突，谁能改原件。许青棠答，谁也不能单独改；院方可在副本提出反证，北镇可保留原件异议，相关活人有权查看自己授权范围内的文字。司空烬让他把这段写入临时署章程，既留给院方复核入口，也留下日后追究复核台失察的凭据。
