# 第二十九章 北镇夜宴

北镇的夜宴设在镇尉署后堂，门外挂着三盏不点火的白灯。

白灯不是照路用的。灯罩上分别写着“粮”“纸”“人”，每一盏下面都压着一枚未盖印的空木牌。陆昭到门口时，先看见木牌的边缘被磨得发亮，像有人用手指反复摸过。贺停舟拄杖站在他身后，低声说，这是北镇旧规矩，凡是涉及粮道、异文和活人选择的席面，都要把三类责任摆出来，免得酒一喝，话就替人接了功。

“旧规矩如今还算数？”陆昭问。

“看谁敢把它写进账里。”贺停舟说。

后堂坐了九个人。镇尉崔录事居主位，秦衡在左，功簿院书吏抱着一只窄匣坐在他旁边；右首是严鹤、杜乙、顾衡三名粮仓经手人。许青棠没有坐在医官席，而把药钳和验墨纸放在自己面前。周梅被安排在靠门的位置，石七则站在门槛外，腰牌已经交回城防库。

席面上没有菜名，只有十二张木签。每张木签刻着一段粮路、一个时辰和一处接收地，背面却留着空白。崔录事举杯说，北镇连日受纸妖扰乱，今夜请众人先把七袋待验粮的归属说清。只要众人同意，明晨便可开封，给城外三处哨点送粮。

秦衡立即接话，说功簿院只需一份“在场见证记录”，不需要任何人当席定功。可他话音落下，书吏便把一张印有“粮路已核”的纸放到了陆昭面前。纸的右下角有一个极浅的“功成”凹痕，墨迹却没有笔压。

陆昭没有碰纸。他让书吏先写清楚纸张的来源、送达时刻和接触者。书吏说纸是随功簿院文书带来的旧格式，未记具体经手。陆昭又问，若今夜有人在木签背面补上接收人，谁承担补写后果。崔录事沉下脸，说北镇需要一份可执行的决定，不是再听一轮查问。

“可执行不等于已经有人选择。”许青棠把验墨纸推到桌中央，“这张纸没有笔压，不能证明是谁写的；木签背面有新刮痕，却没有新木屑落在席面上，说明它们可能在入席前就被处理过。先问木签从哪里来，再谈决定。”

严鹤承认木签由仓房发出，但不承认自己刻过“接收”二字。杜乙说他只负责昨夜交接，顾衡则坚持旧路条不能离开副印柜。三个人的说法互相咬住，却没有一个人愿意把空白接收栏填满。

崔录事让周梅先说。周梅看了看木签，指出第三张签上的北门缺口与弟弟周循曾领用的旧路条不一致，签面把“北门”刻成了“北门外”。她同意让医署记录这处差别，不同意以弟弟姓名替任何一段粮路接收。她把木签推回桌边，手指没有越过那条刻线。

纸上的“粮路已核”忽然向周梅方向折了一下，像被风吹动。门槛外的石七立刻退开半步。陆昭让所有人停筷，先看纸张反应，不许用手压住。纸边贴到第一枚白灯的灯罩时，灯罩上的“人”字渗出一圈湿痕，下面的空木牌随之翻面。

秦衡想让随从收走白灯。陆昭拦住他，问这动作的责任是谁承担。秦衡承认功簿院可以暂时封存异常纸，却不能替北镇承受灯罩损坏后无法辨认三类责任的后果。贺停舟让城防卒关上后堂两扇侧门，承担不让纸张进入账房的责任；许青棠则选择继续验纸，不拔弩，也不让人把她的观察记成截妖之功。

陆昭拿起一枚未刻字的木签，放到纸边。纸没有靠近，反而把“粮路已核”四字折成一条细窄的长缝，缝里露出半行旧墨：“撤民先于领功。”这行字与贺停舟旧案木牌背面的字迹相近，但纸材和墨色完全不同。贺停舟看见那行字，没有伸手撕开，只说旧规矩被人拿来做过格式，不等于今夜的纸与旧案同源。

崔录事终于承认，今夜的宴席不只是压惊。他收到一份镇门外三处哨点的缺粮急报，若明晨不开封，便要由北镇镇尉承担军令延误；若开封后找不到接收人，功簿院又会把粮损算在经手人头上。于是他想让在场者以口头方式先确认一段粮路，至少留下可追责的人名。

“这才是宴席的真正席位。”陆昭看向桌上十二张木签，“不是让谁喝下功，而是让谁愿意承担一段后果。”

他把十二张签分成三堆：有旧路条签押的，只有顾衡可以说明来源；曾出现纸妖牵引的，必须由周梅和石七决定是否见证；完全空白的，只能暂存，不得在宴席上补名。顾衡选择承担两张旧路条的开封核验，严鹤选择承担第三把锁的钥匙交接，杜乙选择承担昨夜封条复查。三人都没有说“粮已交”，只说自己愿意负责哪一步。

秦衡沉默很久，也把功簿院的纸匣推到自己面前。他选择承担“功成”旧格式再次流入北镇的文书核验，但明确不替任何活人接收粮路。崔录事则选择承担明晨开封前的三方通知，不把军令延误先行归罪于拒绝签名的人。

陆昭没有让这份选择停在口头。他请书吏把每一人的席位、面前木签和承诺范围画成三列。崔录事坐在主位，只能承担当夜召集和次晨通知；秦衡坐在左首，负责院内文书而不触碰地方粮袋；顾衡面对两张有签押的木签，严鹤面对钥匙，杜乙面对封条；许青棠和周梅的席位则被划在“观察与本人选择”一栏，不能因为坐在席上就被算作接收人。石七站在门外，也被记入在场见证，却没有被拖进席面。

许青棠又要求验看十二张木签的边缘。她发现第六至第九张签的木粉颜色不同，像是从两块相近但不相同的木板上削下；其中一张签的刻槽内塞有青白砂，砂粒被酒气润湿后才显出黑亮膜。她把木签分成两组，注明“材质相近、来源未定”，不允许宴席上以同一把刻刀、同一块木板解释全部签面。崔录事承认木签不是今日临时制成，而是从三处旧仓房拼来的。

贺停舟让人取来北镇旧宴账。账上记载，七年前也有一次“以席定粮”的做法，主位官员将空白木签交给各路接收人，等对方吃完最后一盏酒才补名。那次账面写着“众议同意”，却没有一人留下拒绝记录。贺停舟指出，旧账能证明这种席面惯例存在，不能证明今夜任何人已经同意，更不能证明旧宴与纸妖同源。秦衡听完，主动让书吏把旧账只作制度背景，不带回功簿院原件。

崔录事第一次没有反驳。他把主位前的酒杯倒扣，选择不饮，说明自己不愿让酒后言语成为军令依据。严鹤、杜乙、顾衡也各自把杯沿离开木签，只有功簿院书吏仍握着笔。陆昭让书吏先写“未饮酒而作证”，再允许他继续记录，避免将醉意、沉默或点头当作活人选择。

纸张上的墨痕一阵收缩，十二张木签同时停止颤动。黑簿在陆昭怀中微热，却没有翻页。它承认了若干新的责任边界，却没有找到死者，也没有得到任何一名相关活人对未竟之功的接收。

宴席散前，周梅突然指向最靠近白灯的一张空签。签背不知何时多出两个湿黑小字：“乙十七”。她没有碰，只说：“我愿意把它作为弟弟的身份线索封存，不愿意把它当成弟弟已经接收粮路的证明。”

陆昭让书吏照录原话，并把木签放入三层空匣。匣盖合上的一刻，后堂外传来两长一短的铃声，和周循领用的无舌空铃声调相同，却没有人看见铃在何处。

夜宴的酒席被分成两桌，一桌是镇诡司值守，一桌是粮道与民户见证。司空烬没有要求民户饮酒作证，顾衡也没有用军粮席位换取签名。陆昭听见有人把“纸妖已伏”说成酒话，便让书吏在记录末尾标注未证传闻。许青棠悄悄问他是否会因此得罪掌院，他说酒话可以留，怕的是酒话被抄成军令。

夜宴没有定功，却定下了明晨开封的责任顺序。门外三盏白灯仍未点火，灯罩上的“人”字却比来时更湿。

散席后，顾衡把三张被酒水溅湿的木签交给许青棠，说明签面上的“收”“证”“代”三字有一字曾被人用袖口擦过。他愿意承认自己当时站得太近，不能承认是自己擦掉了字。许青棠把湿度、擦痕方向和在场人的座次分别记录，要求酒席账房提供擦拭布的来源。账房只愿提供布料，不愿提供客人姓名，陆昭把拒绝范围照录，未以此推断谁心虚。

司空烬让院吏复读夜宴上每个人的选择。崔录事仍只承接“不饮酒作证”，拒绝把酒后听闻写成军令；周梅只承接乙十七木牌的材料来源，不承接弟弟下落；严鹤、杜乙和顾衡各自确认钥匙、搬运和粮单范围。书吏试图把四人的选择合并成“众人认定”，陆昭当场提出异议。司空烬命其分栏重抄，并在总表上注明“不得从并列选择推导共同授权”。

门外白灯的湿痕在子时变成三条短线。贺停舟先用干纸盖住灯罩外围，不触碰灯面，观察湿痕是否继续扩散。扩散在风停后停止，灯油温度、雪水和纸材都可能造成变化，不能直接写成纸妖离开宴席。守卒愿意整夜看守，却要求每半刻轮换，避免疲劳导致误报；这个要求被列为城防责任，不被装进未结功的第四步。

陆昭把夜宴记录、酒水样、木签湿痕和白灯照片分成四袋。秦衡建议将“纸妖已伏”四字作为线索标题，陆昭改成“未经证实的席间传闻”，并保留原话作为口供。黑簿没有翻页，说明一场没有本人选择和独立证据的宴席，只能增加后续核验，不能制造一个已经完成的功。
