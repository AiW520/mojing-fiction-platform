# 第十三章 活祭名单

许青棠把旧门簿送到北镇医署时，天还没有亮。

她没有带走原册，只带走经守门什长、贺停舟和陆昭共同见证的拓本。拓本每一页都标了纸纤维、刻痕和缺损位置，最后一页多出她自己的附注：第六行残留“许”字，不能据此确认亲属。医署的值夜医吏问她是否要把这件事报作家属案，她说先报物证，不报认领。

陆昭在门外等她，怀中黑簿一夜没有翻页。陈骁的半张军令封在证物箱里，证物箱由贺停舟押回北门。城门里的木箱却被临时移到医署偏房，理由是羊骨牌可能受潮。移交单上写得很清楚：移动不等于入库，保管责任由医署值夜医吏承担，陆昭只负责记录链路。

许青棠出来时，手里多了一只小铁盒。

“我在拓本边缘发现了蜡屑。”她说，“和陈骁衣领里半张军令背面的蜡不是同一色，但压痕方向相近。我取了两份样本，没有把它们写成同一封文书。”

陆昭接过清单，没有接铁盒。她便把铁盒交给药童，由药童在两人面前封签。许青棠做事总先把可能指向自己的东西交给别人看，这让陆昭想起她说过的那句“不能让别人替我写”。他没有因此更信她，只把她愿意接受复核的选择写进记录。

医署偏房里，七块羊骨牌已经排在白布上。第七块被削去一半，剩下的编号只到“七”。第六块刻着日期、一个“许”字和三道短横。短横不是字，像用刀背反复压出来的记号。许青棠先验骨牌上的油脂，发现羊骨曾被温火烘过，表面没有血，不能证明它接触过祭台或尸体。

陆昭让她把每块牌的重量、厚度、孔眼位置记录下来。第五块的孔眼偏向左侧，第六块偏向右侧，若用同一把钻具，孔径接近却不完全相同。七块牌可能不是同一批制成，也可能经过不同修补。牌面名字被刮去，并不等于名字曾经真实存在；刮痕还需要与刻刀对照。

“你要查刻刀？”贺停舟从门边问。

“先查能不能查。”陆昭说，“我只有半枚铜牌，没有搜查权。”

贺停舟把一张北镇医署的临时调阅单放在桌上。调阅单允许他们查阅医署三年前的冬祭伤亡记录，但不许带出原册，也不许接触镇尉库的祭名档。批文底部留着一道旧章压痕，印面缺了一角，和门牌旧片的缺口方向相反。贺停舟说这份权限是顾衡签的，不是镇尉给的。

“顾衡为什么愿意让医署看？”许青棠问。

“他说伤亡记录本来就该由医官复核。”贺停舟答，“动机合理，不能因此把他写成支持活祭。”

他们先查冬祭伤亡册。三年前北镇共有七名“自愿献名”，其中五人有家属签押，一人写“无亲”，最后一人只留一个空格。许青棠翻到空格时，手指停在纸边，没有碰墨。那一页的纸纤维里掺着细黑砂，和黑水河三具尸体的砂粒颜色接近，颗粒却更细。

“记录上写的是死亡，还是失踪？”她问。

医吏翻看旁页：“空格那人没有入死亡册。祭后只有一辆空车回城，车上少了一副木枷。”

陆昭让医吏把这段话写成原话，并注明来自旁页口述，不把空格自动补成一个死者。医吏不解，问一个没有姓名的人为何还要分生死。陆昭回答：“因为死者可以有未竟之事，失踪的人仍可能有自己的选择。把两者写成一个，会让后来的人替他结算。”

许青棠继续翻页，在五名签押者的名字旁找到两种不同墨色。前三名的家属签押在祭前两日，第四名在祭后补写，第五名的“愿”字比整行粗一倍。她请医吏用现存墨样比对，医吏只能确认墨色不同，不能确认谁代写。许青棠把这些差异抄下，没有把“代写”写成既定事实。

医署后院传来弩弦声。许青棠转身看见一名药童正练习拉弩，弩尖对着墙上挂的草靶。她立刻命他放下，说墙上旧祭名牌的位置和草靶太近，任何箭痕都可能被误认成祭台伤痕。药童问那不是普通木牌吗，她让他先把箭靶移开，再由两人检查墙面原状。

墙砖上确有七个浅孔。孔内填着红蜡，蜡色和羊骨牌背面的蜡接近。第六孔下方多一条向下的刮痕，像名牌曾被人急着拔走。陆昭让贺停舟在墙外量孔距，发现第六孔与第七孔之间比其余孔距窄半寸。孔距异常可以说明牌位曾调整，不能说明第六行就是许青棠弟弟。

许青棠没有问“许”后面原本是什么字。她拿出自己的旧医署登记，说明弟弟三年前被征调的日期，只允许医吏核对月份，不允许抄走家属住址。医吏在登记旁写下“本人主动提供月份，拒绝提供住址”，并把原册合上。陆昭看着她把手从纸上收回，知道她正在用自己的选择把案子从私仇拉回证物边界。

黑簿这时第一次对羊骨牌有了反应。它在陆昭胸前缓慢展开一页，写下：

“活祭名单，未竟之事：有人把被选者的名字送进门，却没有让本人知道名字去了哪里。”

下面列出四个空格：被选者身份、名单流转、本人是否知情、由谁承担后果。陆昭没有把前三项填成“许青棠的弟弟”，只将空格转抄到记录上。功簿没有要求他斩妖，也没有给出任何奖励，甚至没有说明那名失踪者是否已经死亡。

“这算陈骁的未竟之事吗？”贺停舟问。

陆昭看向半张军令的封袋：“还不能算。陈骁把绳拉向北门，北门里有名单；方向是证据，未竟之事要等死者身份、名单链路和相关活人选择都对上。”

门外，押送证物的守卒送来一份新口供。昨夜木箱少掉的那块骨片并未离开城门，而是在闸链落下前被一名穿深青短袍的人拿走。守卒只看见腰间一枚缺角铜片，没看见脸。口供最后写着：那人说“明夜只需一名，别多写。”

许青棠问守卒是否愿意把这句话公开到医署档案。守卒说愿意保留原句，却不愿让姓名出现在对外告示上，怕家人被追问。她把两项选择分开登记。

“明夜就会再有人来取名。”贺停舟说。

“也可能是有人想让我们以为会来。”陆昭答，“所以今晚先保门，不先抓人。”

他把任务限定成四件事：由医署保管拓本，北门保管原木箱，许青棠复核伤亡册与骨牌，自己在日落前核对陈骁军令、空铃和旧片的交接。任何人若要求把“许”字补全，必须先取得许青棠本人选择；任何人若要求把失踪者计作死者，必须先找到身份与尸身。

黑簿的字停在空格边缘，仍未结算听骨之外的新技艺。陆昭的左手在温水测试中已经能辨冷热，针尖触到指腹时却只觉压力。他让许青棠把这段伤情也登记到当日责任里，避免下一次追门时把失痛误当勇气。

午后，北镇的告示贴上城墙：明夜封门，冬祭名单复核，闲人不得靠近。

告示落款只有“北镇司”，没有具体署名。墨色新、纸纤维旧，边缘还粘着一粒细黑砂。陆昭没有撕下告示，只请守门兵在旁边加盖张贴时刻。许青棠站在告示下，抬头看那个残缺的“许”字拓本，最终说：“我愿意查这一行，但由我决定什么时候承认它与我有关。”

陆昭把她的话写入记录，随后将黑簿合上。

暮色落下时，镇门外的黑水河结冰声一阵紧过一阵。城内七块羊骨牌少了一块，城外却多出一串没有脚印的拖痕，拖痕一路通向收尸车停放的棚子。

这一次，来者没有留下炭字。

军医孟岚不愿承认名册上削去的半字属于谁，她只同意说明自己何时看见木牌、何时给七人发药。陆昭没有逼她补全名字，反而把削痕拓成正反两份，交一份给她保留。两名缺席活脚的空回执也分开封存，空栏不写成死亡。许青棠在名册旁加注：旧称“活祭”是待核术语，不是结论；任何人若想把它写成祭品，必须先拿出发令、接台和活人选择。

只留下一个被雪压扁的活人手印。

许青棠先把手印周围的雪切成方块，标出指尖、掌根和雪层底部的泥色。手印比陆昭的手宽半寸，掌心有一道斜裂，却没有血迹。守卒说像某个搬尸人的手，许青棠要求他改成“与已知手掌宽度相近”，并询问他是否亲眼看见那个人按下去。守卒承认没有，只见到雪面从平变凹，口供因此被分成观察和推测两栏。

陆昭把空白纸压在手印旁，要求三名见证人各画一次方向。有人画指尖朝南，有人画指尖朝东，第三人只画出掌根阴影。方向差异可能来自夜灯位置，他把三张图都封存，不用多数替代原地复测。手印没有回应黑簿，也没有指向名单上任何名字；它只证明曾有一只手在雪面施过力。
