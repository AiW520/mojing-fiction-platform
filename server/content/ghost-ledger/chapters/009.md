# 第九章 驿路断粮

第三日夜半，北镇前线的催粮旗插进黑水驿。

来人是顾衡的押运官，脸上冻得发青，手里拿着一支折断的路签。他说北道的两辆军粮车在距驿站四里处停住，车夫没有受伤，粮袋却少了七袋。雪线把车辙掩去一半，剩下的印子向河滩分开，像车被两股力同时拖过。

陆昭先问：“少的是哪七袋？”

押运官答不上来，只说车上原有三十六袋，按军仓封单应剩二十九袋。顾衡派来的随车记功吏在旁边补充，封单上没有逐袋编号，只有车号、总重和目的地。

他让押运官把两辆车停成一前一后，车轮用木楔卡住，所有人退开三步。药童先用干布扫掉车板表面的浮雪，再按车号、车厢方向和封签位置逐项画图。这样做很慢，却能防止有人在争执时踩过沟边或碰到袋口。押运官催了两次，陆昭都只回答“先保现场”。贺停舟把催促的时刻写在路条背面，提醒押运官自己也可以把急迫作为责任的一部分留下。

“那就不能写七袋被谁拿走。”陆昭说，“先把车、封条和余粮隔开。”

押运官急道前线等粮，若再拖一刻，夜岗换防会断火。贺停舟看了北道图，说四里处有一段废弃驿沟，沟底通向黑水河旧渡。若有人从沟里拖粮，车辙会在雪面上消失，却会在沟壁留下擦痕。陆昭于是把半枚铜牌递给押运官，说明自己有查验权限，没有调军车权限；要查粮，必须由对方书面承认他只负责证物与封签。

押运官不愿签，说前线出了事谁都担不起。顾衡的记功吏却拿出随车副单，写下“临时查验，不替军仓改重”，并让押运官和车夫各自按手印。陆昭这才让韩六准备旧木车，把第三户退回的十一斤封存粮留在驿内，不能混入军车。

许青棠没有随车。她要留在镇门复验编号七铃钉，便把一支短弩交给贺停舟，自己派医棚的年轻药童跟车记录伤情和冻伤。她说药童没有验粮权限，只能记录谁在什么时候碰过车绳。陆昭接受了这个限制，给药童一张空白时刻表，不让他用“可疑”替代看见的动作。

队伍出驿站时，周槐的看押房忽然传来响动。守卒发现窗栅外钉着一枚黑麻绳结，绳上没有人影，旁边却留着一小撮黑砂。周槐说那是岳成常用的结法，贺停舟没有采信，只让守卒封窗、封绳，不许拔钉。陆昭把这件事列入同一时刻线，却没有因此中止押粮。

北道四里处，两辆粮车斜停在雪沟旁。第一辆车的六个封签还在，第二辆车的三个封签被雪水浸过，印泥边缘有重新压合的细裂。余粮袋堆在车厢后半，前半空出七个位置。车夫说夜里听见河边有铃声，打开车门时已经少了粮袋；他没有看见人，只看见一片灰白从沟口掠过。

两名车夫各自指出空位，手指落点却不一致。第一名指向靠门的三格，第二名指向中间四格。陆昭没有让他们互相说服，而是取出前一日的装车草图。草图上袋口朝向有一处模糊，无法恢复编号；他便把“空位”改写成“现有袋数与总重不符，具体袋位待复核”，要求随车记功吏在旁签注。这样一来，缺粮仍是事实，却不让一张不完整草图替七袋粮决定来处。

陆昭先把“灰白”记作口供原词。许青棠不在，他请药童量车厢擦痕。车板上有三条新刮痕，宽度分别为一寸、一寸一和一寸三，与第七章木套圆孔间距不完全相同。刮痕中粘着青石粉和黑麻纤维，不能证明木套到过车上，只能证明某种带石粉的粗物擦过车板。

贺停舟下到废弃驿沟，发现沟壁冻土被削掉一层。七个麻袋拖痕从车边下沟，拖到半途却分成两股：一股向旧渡，一股向北门。两股拖痕都没有脚印，只有绳结压出的间隔。若一人拖七袋，间隔应因重量变化而不同；这里每隔三步便有一次相同深度的压痕，像有人用滑轮或木桩分段借力。

“粮不是被一把扛走的。”贺停舟说，“有人提前布了受力点。”

陆昭在第二股拖痕旁发现半枚旧铜片。铜片边缘有新的桐油污，背面刻着残缺的北门纹。它与谢大木货票所说的旧片形制相近，却没有完整编号。押运官见到铜片，要求立刻收回，说这是军械物，不应落在收尸役手里。

陆昭把铜片放入封袋，递给押运官看封口：“你可以在封签旁写接触记录，但不能凭口头把证物变成你说的类别。”

押运官反问他，若铜片真是军械物，封存迟一刻便可能影响城门防守。陆昭让他指出哪一条现行军令规定半枚残片必须立即交回；对方拿不出原文，只说过去都是这样。贺停舟请记功吏把这段争论记在现场单上。押运官仍有权提出调取申请，却不能用“过去如此”替换今日的签收手续。

押运官拔刀半寸，问他是不是要耽误前线。贺停舟拄杖横在两人之间，没有拔兵器，只说若有人抢证物，责任便从丢粮变成阻碍查验。押运官看了看半枚铜牌和路条，最终收刀，却要求陆昭在天亮前给出结论。

“天亮前能给出封存数量。”陆昭说，“给不出凶手。”

药童按照陆昭要求，逐袋记录剩余二十九袋的封线、重量和麻布补口。第二辆车少的七袋中，有三袋原本标作军前急用，四袋标作驿站转运。陆昭将两类袋子分开，发现驿站转运袋的麻线与秤房十一斤粮袋同粗，军前急用袋则用更细的黑麻线。这个差异足以提示调换方向，却不足以证明谁调换。

他让车夫分别说明自己最后一次看见七袋粮的时间。第一名车夫记得戌初，第二名只记得更鼓响过一声，两人的时刻不一致。陆昭没有取平均，反而把两份口供分开，要求他们在各自说法下按手印。

天将亮时，北门传来急铃。许青棠派人送信，编号七新钉在夜风中自行松动，铃架没有倒，钉帽却从内侧被推出。她没有拔钉，只用木楔固定，并在现场留下三份拓样。更重要的是，门外发现一条向城内延伸的黑麻绳，绳端打结方式与周槐换岗收据上残留的纤维相近，但仍需实验比对。

黑簿在陆昭怀中发冷，第一页最后一格没有填满。它浮出一行新的要求：

“粮已失，谁愿接收余责？”

前线催粮官要他签下“七袋由陆昭负责追回”。贺停舟提醒，签下这句话等于把追回、验封、军仓补足和途中伤亡都归到他身上，不是普通的查验责任。陆昭看着雪沟两股拖痕，又看向驿站里第三户拒领的空袋，知道有人正利用“缺粮”逼他把所有未知都写成自己的功。

他没有签追回全责，只在文书上写下四项限定：负责封存余粮、负责保全旧铜片和绳样、负责在十二个时辰内核对两股拖痕、不得代军仓认定七袋归属。押运官骂他胆小，顾衡的记功吏却按规章收下限定条款。

陆昭又把两股拖痕的起点、分叉位置和每隔三步的压痕画在文书背面，标明这是现场观察，不是追回方案。若十二个时辰后风雪填平沟壁，他仍只能凭这张图说明当时看见了什么，不能凭记忆补出看不见的搬运者。贺停舟看完，在图角写下“见证，不作推断”，并把木杖印在旁边。

粮车暂时停在北道，前线仍缺七袋。陆昭回头看见天光刚越过城墙，第三组假脚印的拓样被风吹起一角，露出下面一行用炭写的字：

“若要领功，先把路写死。”

贺停舟看见炭字，先让两名守卒记录它出现的雪层。字在拓样下方，不在原脚印里；炭末压住新雪，说明它写在他们离开现场之后。守卒想顺着字意把沟口封死，陆昭不许。他们尚未查完两股拖痕，一句匿名劝告既可能来自搬粮者，也可能来自试图让他们错过另一条路的人。贺停舟只增加两名守线兵，命他们守住拓样和分叉点，不追看不见的写字人。

顾衡的记功吏问若前线再催粮，如何同时守车、送粮和查沟。陆昭把路图划成三块：已封的二十九袋由押运官决定是否发出，旧渡一股由贺停舟带两人沿沟量痕，北门一股交给自己和药童记录，不要求药童辨妖。每块都有时限与撤回条件，不能写“陆昭负责追回七袋”这句总话。他承担的是十二个时辰内可复查的路线，不是未见过的七袋粮能否回来的保证。

这不是功簿的字。

回城前，三名承责者各自写下撤回条件：风雪加大时停止拓样，人员冻伤时先回城，封线被撞开时重新取证。条件逐项写入路图背面，避免“继续查”变成没有期限的命令。陆昭左手的浅裂再次渗血，他把更换绷带交给药童，自己只复读时刻和编号。

车夫看到炭字后选择不再靠近拓样，只愿确认自己来过北道。守卒则愿意承接保护拓样，不承接字的来源。两份选择并列后，匿名劝告既没有被当作军令，也没有被当作妖物挑衅；它只能在证物栏里等待新的纸纤维和笔压对照。
