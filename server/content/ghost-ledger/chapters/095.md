# 第九十五章 最后一具尸

第九镇的驿骑在天亮前递回一张图。图上没有尸体，只有空匣底板的三道榫缝：中缝较宽，狭签卡在第三道下面，纸边离木面有一线空隙。匣底背面落着一层均匀旧灰，签的外缘也沾灰；灰能说明两者曾一同存放，不能说明签是何时塞入。第九镇文吏只愿在本地拆榫，拒绝把空匣送往北镇。司空烬批准原地验匣，秦衡带去盲码纸样，院方只得取影，不得携走原签。签上所写的义冢七坡在北镇旧渡一线，匣与地之间尚缺交接记录。

陆昭仍在北镇白线外。药吏给他换布时，发现左掌浅裂边缘泛白，昨夜木牌复测后又有一点新血。陆昭没有申请随队，也没有请人替他动黑簿；他只把义冢七坡旧图抄成三条可检路线。其一查修坡账是否出现“未移”，其二查旧棚封墙前后的木料数，其三查下层灰泥是否留有搬运停位。三条分别交给北镇义冢文吏、义冢工匠和北镇锁匠，谁也不看另外两人的先行判断。

北镇义冢修坡账先给出反证。十年前那次春修，七坡只搬了两具无名骨匣，第三具写在“待迁”栏，旁注“旧棚墙潮，先护木架”。账末没有“已迁”回执，后来两年的修坡账也没有补记。文吏把原账、封皮和馆藏号一起拍影，注明“未见回执”不等于证明未迁；若有人走过不入账的夜路，还需要查木架、车辙和在场人。司空烬让修坡队先停下清理旧棚墙脚，不是为了守一页纸，而是怕惊动尚未验明的遗存。

义冢工匠量旧棚外墙，发现最下排三块砖背面有一条旧木梁压痕，长短与修坡账所记护木架相合。砖缝下有积水，不能直接拆墙。卫岑带人先支两根新梁，守住外侧退路；贺停舟在北镇远程核城防图，提醒他们旧棚下方通一条积水石涵，若把砖一口气敲下，墙会朝义冢路塌。工匠只剔松动灰泥，留原砖位置与侧光影。半日过去，里头传来木框碰石的轻声，却没有人说那是棺材。

空匣在第九镇同一时刻拆榫。榫头内侧有新刀划痕，外侧却是旧磨损；狭签纸边受挤，折线恰与中缝宽度相合。鉴纸师在不抽签的情况下取到一点露出的纸纤维，与同年修坡账的竹纤维相似，浆料颗粒却粗一些。两份纸可能出自不同批，也可能经过不同潮湿环境，不能以纤维相近认作同一书吏。拆榫所得只能说明有人在匣组装后塞入狭签，不能说明那人知道义冢墙内还有什么。

午后雨水转急，旧棚石涵倒灌。守在墙脚的工匠听见木框第二次撞石，脚下灰泥随水向外鼓起。卫岑立即让所有人撤到绳标外，独自用长杆抵住摇动的外梁，木匠从高处加斜撑。药吏核对人数，发现先前送热水的少年还在棚侧避雨。卫岑没有命人破墙找尸，先让少年沿已经量过的右侧石路出来。少年出来时抱着一截脱落的木板，板背有三道横钉孔，板上未见姓名。救人多耗一根新梁和半袋干砂，顾衡记在救援实耗。

雨水退到脚背以下，墙脚自行裂开一道口。北镇义冢守人用灯照见里头一只斜倒木架，架下是未封口的木匣，匣内露出一段灰白前臂骨。那是现场第一次出现遗存，不是从七坡坟里挖出来的。众人退后，让当地医官、义冢守人和轮值见证人先画位置：骨端朝东，木架压在匣口，三块墙砖仍半悬。医官只确认这是人骨的一部分，不能从一段前臂判性别、年岁或死亡时间，更不能认作“阿岐”。

司空烬收到急报，派复核官写下“最后一具尸”。北镇义冢文吏却退回标题，理由是义冢七坡还有三处无名位，眼前只是一处旧棚遗存。司空烬没有强押标题，改作“旧棚未移遗存候选”。他承认那条狭签与修坡账、墙内木架形成可以追查的路径，却不能因此把三份材料合成一个已确认的人。陆昭在北镇收到更正，先把自己抄图上的“末一具”圈去，改为“旧棚一处人骨候选”。

墙内木匣还压着一块旧路牌。牌面朝下，边角露出七个小孔。卫岑不让人伸手摸，只把口外可见的一角画在纸上。七孔可能是固定绳孔，也可能是编号；先前羊骨牌上的“七”与它材质、尺寸不同，没有并案依据。旧棚内的白蜡木屑被流水推向墙口，另取上游雨水作对照，水样里也有细白粒。若不分上下游，谁都可以把泛白水说成诡物洗过尸骨。

许青棠从皇城回函，要求先决定遗存保全和活人选择的权限。周溯只是同行者之孙，不是三具死者的家属，不能授权开棺或认尸；北镇义冢守人能授权抢救暴露遗存和支撑危墙，却不能替未知家属接收遗愿。医官可在不移动骨骼的前提下记录可见部位，若结构再塌必须移走，需三人同场记录原位、搬动理由和每段骨的去向。她仍未亲临，右肩牵痛的药量与复核时长另记，不让远函伪装成现场证词。

旧棚守人提出一个实际难题：暴露的前臂若留在流水里，明晨可能被冲走；若现在收走，原位关系又会丢。卫岑与工匠把斜撑加固到能遮雨，却不跨过半悬砖。医官隔着灯影描摹骨与匣口的接触面，在墙外立两根基准桩、量深度和方位；义冢守人封好通道，夜里轮班守护。若水位再次越过第二桩，他们才按抢救遗存程序移出可见部分，所有人先在风险单上签明自己的权限。

夜深，修坡账的第二册送到。账上有一笔旧棚木架维修费，领钱人只按了半枚指印，旁边写“留一”。这两字可解释为留一只木架，也可解释为留一具遗存，原文没有宾语。秦衡要求先找同年木料采购单，看“一”对应几根梁；不能让两个字替墙里的人起名。空匣狭签的背面则显出淡淡格线，像曾压在别的账页下，却没有共同断口。两条新发现都延长了核查，不缩短四步。

北镇外仓有人不满，说尸骨都看见了，何必不肯写“找到了”。陆昭答：找到了骨，不等于找到了谁，更不等于知道他最后想做什么。一个真正的尸体使旧总表“三具尽迁”的说法受到实物挑战，院方可以据此暂停那栏的迁葬结论；但若把“末一具”写成身份，又会让三处无名位里任何一具都失去被重新辨认的机会。司空烬听见后，命功簿院公开旧总表的更正索引，把“尽迁”降为“缺至少一处交接记录，旧棚见一处暴露遗存”。

更正索引送到义冢守人手里时，他问明日来祭扫的人该听哪一句。陆昭没有替陌生家属拟好结局，只建议由守人公开两件可核的事：旧总表的“尽迁”已经撤项，旧棚确见一段人骨；至于骨属于谁，尚需独立查验。守人要求把危险墙段和不得入内的范围也写在告示上，免得求证者踏坏基准桩。司空烬承担告示纸张和错写后的更正费用，卫岑负责派人守线；两人都没有因此取得认尸权。

医官又核了一遍前臂骨可见长度。第一遍隔着斜梁测得不足一尺，第二遍换了细木尺，多出半寸。差异来自观察角度，不能据此推年龄或身量。陆昭在副图旁把两次读数并列，自己只核桩号，不触骨端。雨水顺砖缝滴入匣口，守人用新布引流，却不让布碰到骨面；布的放置时刻由卫岑记录，防止明日有人误把新湿痕当作旧葬层。原位仍在，能回答的问题却并未因此多一个名字。

代价当天就到了。北镇义冢路暂封，送药车绕行三里；卫岑守棚两班，顾衡多拨干砂和粮，司空烬要为误写“尽迁”的旧总表向九镇解释。陆昭无权签这些调度，只在不带印的副图上核一遍桩位，半个时辰到点便交给另一名文吏。他左手仍失痛，浅裂未合，错认风险没有因发现骨而消失。黑簿原册仍在北镇三钥柜，封功刀未出鞘，听骨没有被用来替医官验遗存。

最后一具尸的章名没有预设尸体身份。第九镇原地验匣，北镇旧棚危墙下只见一段前臂人骨，医官确认局部而不判性别、年龄、死因或死亡时刻。修坡账的“留一”缺宾语，七孔旧路牌、木架、墙砖和水样分线保全。陆昭把狭签与人骨分成两条线，周溯叔父没有认尸授权；暴露遗存是救援和保全责任，不是功簿四步完成。

旧棚里的人骨候选终于有了一个能够指向原位的编号，却仍没有名字。北镇义冢守人把“原地待验”续写为“危墙下守护”，没有写“接收”。司空烬把修坡账、狭签、木架和骨分别列成四条证据线，允许它们互相质询，不许它们彼此冒充。夜雨落在新撑的梁上，义冢七坡仍未打开；北镇旧棚的灯一整夜亮着，为一个尚不能认名的人留下可以被后来者复查的现场。

守棚工匠轮班时发现砂袋外侧多了一道水痕，水痕来自屋檐还是地下渗水尚不清楚。他先在墙角设两根量水木签，一根靠檐，一根靠骨旁，交接人每刻钟只记水位，不碰遗存。屋檐签先升，骨旁签仍干，不能据此保证整夜不渗；贺停舟让下一班继续观察。两班工钱和火油由北镇先垫，司空烬在院方补给单上签名。雨势未逼近抢救线，骨仍原位，任何人都没有借保全之名把它送去认名。

第九镇文吏回报，狭签木匣的外封上有一道旧绳压痕，与北镇旧棚木架捆绳宽度相近。两地各自取拓样，却没有绳子原件，也没有可比的断口。秦衡把“宽度相近”写进观察栏，“同一次捆扎”留空。陆昭读到两地字样时停下，让另一人按镇名分开复读，避免旧棚人骨被一个相似的绳宽送进第九镇义冢。
