# 第八十五章 功簿源头

北镇天亮后，卫岑带人把九个浅坑重新量了一遍。旧驿碑歪了半尺，昨夜用它作基线的人没有错，错在把一块会动的石头当成了不会动的界。新木桩打进冻土，九个坑在图上分成三簇，每簇各有三个，落点分别靠近旧排水口、废渡坡和义冢车道。它们没有正对九镇木牌，更不朝同一个门心。

司空烬看完两份底图，命人把“九门已开”的传闻从报单里撤掉，却没有解除封路。他说九个坑也许不是门，而是让人往三个旧地点跑的引路痕。若地方自行追线，黑簿原册可能被迫离开三钥柜；若院方强行带走原册，九镇会以为朝廷正在收天下未结之功。两种风险他都写在令纸上，限一日核查旧路线。

陆昭听到义冢车道四字，先摸了一下拇指旧茧。他曾在那里修过收尸车轴，知道车道下有旧石涵，夏天过水，冬天藏风。九个坑的泥边却没有车轮碾压的新痕。他没有说“我认得这条路”，而是请卫岑带一块未经绘线的板，让三名不知九坑位置的老车夫各自指出旧车会停的地方。

三人画出的路线并不相同。一个把义冢画得太近，一个忘了废渡，第三人提到一处早被填平的收尸棚。锁匠带着这三张图去查旧墙砖，砖下果然有一个封死的棚门。门楣刻着三道浅槽，槽距与九坑的三簇间距相近，可石上的苔痕早于今夜的霜，不能把二者写成同一人所刻。

卫岑另派一队守在粮仓，没有抽走原本看护药房和三钥柜的人。九坑若是诱人追路的饵，最容易被忽略的就是留下的粮和簿。司空烬提出从城外调院卫补上空缺，贺停舟同意人手，却要求院卫只守外围，不持北镇钥匙。双方把巡更、换岗和油耗写在同一张临时守线令上，签名分别落在自己做得到的那一行。谁都知道这一日的防线比平时薄，因而不能把查源头写成没有代价的壮举。

封死的棚门前有新雪，雪面没有脚印，门下却夹着一角褪色油布。卫岑没有撬门。锁匠先验砖缝：上层灰泥是十年前补的，下层老灰混着木炭；油布只塞在新灰裂开的缝里，不可能证明当年棚里就有它。贺停舟让人以两种拓纸取下缝形，又留一份原状给第三方复测。

油布上只有几个可辨的字：“旧镇收尸，三联留证。”秦衡认出这不是功簿院现行印式。现行印式只有案号和中央接收栏，不会给死者家属、运尸人及留地见证各留一联。司空烬没有辩解：“若它真比功簿院旧，就该从旧档查起，不该从黑簿猜起。”

旧档库在北门内，距三钥柜仅一墙。司空烬提出请院方调取库钥，贺停舟不肯让院印单独开库，双方最后各交一把钥匙，第三把由北镇无涉旧功案的文吏持有。开的是旧档库，不是黑簿柜；三钥柜外封由卫岑在原处拍拓，贺停舟和秦衡只核封泥、边角、锈斑与封存时间，谁也不碰黑簿内页。

档库里没有所谓“天命册”。最早的记录是一次饥年迁尸：三镇互送冻死者，尸身走到哪里，运尸人都须留一片木牌，目的地的活人若不愿认领，也要记录拒绝和后续埋葬者。三联收尸牌一联留出发镇，一联随尸，一联留接收镇。后来的功簿院抄本只保留了“随尸”一联，其余两联散落在地方库房。

陆昭在白线外听秦衡念到这里，问：“第一联和第三联为什么不进总院？”

“不是不进。”司空烬指向残破的封皮，“当年驿路断了，先保人和尸，再补信。院方是后来才有的。”

院吏翻出一份更晚的合并令，令上说地方三联繁复，统一报功可省驿骑与纸粮。墨字有笔压，印也真；可令后附着一张无签名的“已同意”总表。秦衡本想把两张并列，陆昭提醒他先报纸张年代。鉴纸师用水印、竹纤维和封线逐一比，发现合并令比那张总表至少晚了七年。有人后来把一张早年的空同意表钉在令后，造成“合并前已有各镇同意”的假时序。

鉴纸师不肯只凭水印下断语，又取同库同年的六张军粮单作盲样。六张里有两张曾被火烤，水印收缩，若只看尺寸也会被误判成更早的纸；竹纤维切口却与合并令相合。无签总表的纤维短而碎，孔位又被后来那枚铁钉重新挤开。秦衡写下两种可反驳的解释：有人故意后钉，也可能库吏修册时误配。只有借阅链与当年的修册记录能分辨动机，现下能确认的只是两纸不同年、总表不能替各镇作先行同意。

司空烬让秦衡当众拆钉，钉孔先拍拓、再分别封存。院吏脸色变了：“这会推翻现行总表的沿革。”

“推翻的是沿革里那句‘各镇先同意’。”司空烬说，“现行救援令不能因此停，但我署过名的旧式依据必须重审。”他把一日核查延为三日，并在延时单上写明院方承担药粮、驿骑及复核耗费。

库中另有初代收尸人的名录。第一栏写着戚望，身份不是功簿执掌者，只是北境旧驿的收尸役。第二栏留着他最后一趟运尸的路线：北镇、废渡、旧棚、义冢。第三栏是他亲手划去的一个字“领”，旁边补“见”。一笔之差，接收者从领功的人变成见过尸体的人。

贺停舟忽然拍住案角。他认得这笔改动的姿势：旧功表里也曾有人把“见”写成“领”。但字形相似不证明同一个人，年代更隔了几十年。他没有指认任何后人，只要求把戚望名录、合并令、无签总表和黑布匣副页分别列为四条待核线。

外面突然传来石涵积水倒灌的声响。卫岑的人报说旧棚门前新雪塌下半尺，里面有两名避风的孩子，棚门若被水压顶住就出不来。贺停舟不等源头讨论，命锁匠先测承重，卫岑卸下旁边松砖，药吏带担架候在外侧。陆昭没有冲进棚里，他在车道旧图上指出上游泄水口，顾衡调来沙袋挡住粮仓方向的水。几人各尽其职，把两个孩子从侧口带出，棚门没有被强撬，底层灰泥也得以保留。

侧口窄得只能容一个成年人蹲行。卫岑先让守线兵把长枪横在砖下，免得松灰砸住孩子；锁匠敲了三下砖，听出上层回声发空，叫人从右边拆而不是从承重的左边撬。两个孩子一个还抱着半块冻硬的饼，另一个的靴子陷在湿泥里。药吏先量脉搏，再把人交给等在外面的家人。旧棚里没有黑簿，没有自发翻动的纸，只有积水和一条曾供收尸车避雪的旧道。陆昭提出上游泄水口的动作因此可以由在场人重做，不须相信他曾走过这条路。

孩子说自己只因风冷才躲进去，没有看见任何放油布的人，也不愿被写成发现功簿源头的证人。药吏记下体温和冻伤，准他们自行选择是否留下名字。陆昭看着水从三道旧槽里分走，终于有了一项能落地的判断：九坑可能指向旧收尸路线，而不是九扇门；至少在旧棚这一处，先救人比追诡更快，也没有毁掉证物。

查功簿源头前，司空烬准许陆昭阅戚望三联旧档，明确只看原件外层、转抄内容和来源柜号。陆昭发现旧夜运尸册只记来源、停放、交接、见证和去向，不记功；后世总表却把“见”改成“领”，把分散责任缝成一册。这个差异足以说明制度转写，不足以证明黑簿由谁制作。贺停舟把三钥柜封签重称，记录没有变化，黑簿源头仍留在待证栏。

夜里，司空烬送来准许查阅戚望三联旧档的批签，只准看原件外层、转抄内容和来源柜号，不准据此开启黑簿三钥柜。陆昭接过副本，没有把“功簿源头”四字写成定论。他在事实栏里只写：第一代收尸人曾让三地各留一份证，而后来的总表改变了这件事。谁把散在各地的未结责任缝进一册黑簿，仍无证据。

查阅在午后进行，三联旧档由三名不同柜吏轮流递送，每次只出一联，桌上铺新白布。陆昭先量纸边，再读转抄页，发现第二联的“见”字被后人描粗，原纸压痕却停在左半，不能据此断言曾有人要把它改成“领”。柜吏愿承接递送时刻，鉴纸师愿承接纸纤维观察，陆昭只承接自己的复述；三人都拒绝把描粗动作指向某个已死的收尸人。

许青棠从皇城发来一张伤亡复核表，要求旧档查阅者也记录疲劳和照明。陆昭读到第三联末行时，灯芯忽然爆了一声，他把“归旧棚”听成“归旧门”，立即放下纸页。重新点灯后，两名柜吏分别复述原句，确认是“旧棚”。这次停读让查阅多耗半个时辰，司空烬在院方账上补一盏油，不让陆昭用错听去换取一个更像答案的源头。

查阅结束，三名柜吏按相反顺序把旧档送回柜内。第一人只确认页数，第二人只确认纸角没有新增折痕，第三人才核封签蜡面。陆昭在门外听见“第三联归柜”，没有把这句话复述成“第三联已找回”；缺失的那一张仍缺失。司空烬让文吏把这次返柜耗用的油、白布和半日工钱列入院方账，避免地方为了省一张纸而把复核责任推给一具无名尸。
