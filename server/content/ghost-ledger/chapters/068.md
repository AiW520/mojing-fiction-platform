# 第六十八章 第二支小队

第二镇的第二支小队在卯时成形。卫岑没有从巡骑里再抽人，而是把队伍拆成三种职责：搜人、护证、回送。两名步卒带普通绳和木楔，药吏带伤情卡与热水，文吏带封袋、拓纸和两把不刻名的短铲。陆昭仍是事实观察员，停职牌由文吏保管；他能听取汇报和指出证据缺口，不能触尸、开箱、用印或使用听骨。

十一名未归者的名单先被逐户核对。十七人已经回城，其中三人说自己在南坡听见井底风声，另外两人说旧柴场有人影，却都只愿意承接自己的见闻，不愿替十一人判断去向。二十八人的原始数字被划去，旁边写上回城时刻、本人签名和仍未回报栏。守门人承担登记时刻，家属承担物件来源，不承担搜寻结果。

第一组沿窄沟向旧柴场走。沟底两枚鞋钉大小不同，一枚是铁，一枚是铜；铁钉与无名尸左鞋底的缺口形状相近，铜钉却来自军靴。药吏用木尺量过后，将两枚鞋钉分装。陆昭让文吏在表上加一句：相近只支持路线候选，不支持尸体身份，更不说明军靴主人是否属于巡骑。

第二组留在废井护证。井口的普通麻绳已经被风磨出毛刺，九号粮袋麻线也有同样的毛刺方向，但纤维里混着不同颜色的泥。文吏把两种泥分别封袋，要求在场的守门人和顾衡各自承接取样时间。两人都拒绝承接“有人操纵风”的推断，只愿意证明样本来自井口和粮袋。

第三组把无名尸移到临时遮棚。移尸不是结功动作，仍需本人选择和见证。邻人认出尸体腰侧的铜环与南坡一个挑水人常戴的相似，却不敢确认姓名；粮铺掌柜确认死者衣物上有旧路条粮粉，不能确认死亡时辰；守门人承认尸体出现前曾听见长车声，不承认自己见过搬运者。三类见闻被分在三张表里，互不替代。

许青棠在皇城收到回传后，要求第二支小队先做伤情和身份候选，不得先问“是谁害死他”。她让阮遐按现场药吏的记录复核右腕两向擦伤：第一道擦痕浅而长，第二道短而深，方向相反，可能形成于不同接触阶段。许青棠没有给出死因，只要求寻找能解释两次受力的物证。她右肩牵痛仍在，复核署记录注明无法搬运原件，但可以审核盲验图。

旧柴场的空木箱成为搜寻重点。箱底有九号袋麻线、青白砂和一片窗帘布纤维，箱盖倒“食”字的刻痕却没有砂粒。步卒在箱后发现两道拖痕，一道向废井，一道向东粮场，方向交叉处有冻泥被重新压实。没有脚印，不能断定拖痕由人或风形成；队伍只在交叉处立普通木桩，记录风向和雪面温度。

陆昭听到“交叉”一词时，短暂把两道痕看成北镇纸城崩塌前的白线。他闭上眼，让文吏重复报出箱底材料、刻痕深度和拖痕宽度。错认退去后，他主动把观察位置交给药吏，退到三丈外。停职责任表新增一项：错认发作时不作方向判断，只复述已经由他人记录的数字。阮遐在回传中确认这一限制，许青棠没有替他删除风险。

午时，第一组在旧柴场北坡找到三件个人物件：一只缺盖的铜壶、一串麻籽和一块绣着“梁”字的布片。物件分属三户，家属只承认来源，不承认十一人中谁已死亡。布片上的“梁”字可能是姓，也可能是作坊标记，不能与无名尸磨平木牌合并。文吏把家属本人选择写在每件物件后，防止搜寻表把物件自动变成认领。

第二组在井壁黑线附近听见三次轻响。第一次间隔七息，第二次三息，第三次没有回声。守门人愿意记录响声，不愿称其为井中妖物；药吏发现每次响声后井水面都下降半指，却没有看见水流入口。文吏用普通短铲清掉一层灰泥，露出铁环外侧的细刻线，刻线不是字，而是四道等距缺口。铁环仍未取出，黑线仍未拔断。

卫岑从城门赶来，带来一张军需接收表。表上记着六袋旧路条粮曾在昨夜酉时出场，接收栏写“北坡待验”，却没有接收人姓名。顾衡确认表上墨色与粮袋路条相同，但印泥不是第二镇常用的红蜡。卫岑可以确认表由西关兵调副使的文吏转送，不能确认北坡是否真的收到六袋粮。调兵表因此继续只记护送和封线，不把军需表当作粮袋到达证据。

十一名未归者中，一名叫梁朔的木匠的家属赶到井边。他认出绣“梁”字布片是自家作坊旧料，却拒绝确认布片属于梁朔本人，只愿意把梁朔昨日未回、常去旧柴场和左手有旧烧痕写入候选索引。家属还交出一枚木楔，承认是梁朔修车时常用的工具，不愿把它放进无名尸袋。陆昭听完，要求所有人尊重这一拒绝，不能因为家属最接近死者就替他选择功劳。

傍晚，第二支小队在交叉拖痕处找到一截被风埋住的麻绳。绳端打着半结，结心夹一粒青白砂；半结与无名尸右腕浅擦痕的方向可以对应，却缺少接触血迹和死者本人选择。绳端被普通木楔压住，木楔上有新鲜刮痕，和空木箱盖内倒“食”字的刻刀痕不同。文吏将绳、砂、木楔、箱盖拓纸分柜，标明“形态对应，因果未闭”。

夜色降下前，旧柴场深处传出呼救。第一组没有立即冲入，先让三名见闻者分别报方向。木匠家属听见声音来自北坡，步卒听见来自井边，药吏只听见风穿树缝。三种方向不能合并，卫岑命人以普通绳连接三处标记，逐段排除回声。最终在一处废窑里发现两名活人，他们是昨日离城砍柴的兄弟，因风雪躲入窑中，未曾被拖走。

两兄弟只愿意承接自己的避险见闻，不愿代其余未归者说明生死。他们说昨夜听见车轮声和木箱撞击，却没有看见车。文吏按本人选择登记，药吏检查两人冻伤，卫岑安排他们由南门自愿回城。十一人名单因此减少两名仍未回报者，但剩余九人依旧没有证据指向同一地点。

许青棠的复核意见在入夜前抵达：无名尸与粮场接触得到衣物粮粉和旧路条支持；右腕两向擦痕、半结麻绳和木楔形成一条可复核的接触候选，但未完成身份、死亡时序和未竟之事确认。她建议暂不建立功簿新页，先寻找能解释“尸体为何从粮场到井口”的第三类独立证据。功簿四步仍停在门外，任何技艺结算都不成立。

陆昭把第二支小队的回传按“人、粮、绳、箱、井”五栏重新抄录。人栏有两名自行回城，九名未归；粮栏确认九袋损耗、三袋路线待验；绳栏出现半结与两向擦痕的对应；箱栏有倒刻“食”和两条交叉拖痕；井栏有铁环、四道缺口和黑线。五栏之间存在路线关系，却没有一项能替另一项完成死者选择或结算责任。

夜半，空木箱里忽然传出一声轻响。守棚者打开箱盖，里面只有一小撮新落的青白砂。砂粒没有脚印，也没有风口。卫岑封住箱盖，规定下一次开箱必须由两名见证者本人选择承担。陆昭站在远处，左手依旧无痛，浅裂没有扩大，错认风险在“食”字上升起又退下。他没有靠近，只让文吏记录箱内砂粒的数量和落下时刻。

第二支小队出发前，九名未归者的家属被逐一询问。有人同意搜河，有人只同意查旧柴场，有人拒绝让陌生人进入家中取物。药吏把同意、拒绝和未询问列成三栏，卫岑为每条路线配不同颜色的绳牌。陆昭提醒队长，家属物件只能提供候选身份，不能替本人完成功簿第三步。小队因此带回更多路线差异，却没有带回一个可以强行认领的名字。

第二支小队完成了第一轮搜寻，却没有找到妖物，也没有把无名尸变成有名功劳。它带回的最大结果，是证明“失踪”里有自行避险者，也证明粮、尸、木箱和井沟之间确有多段接触。下一轮必须决定是否扩大到河道；而在那之前，九名未归者的家属还要逐一说出，他们愿意让谁寻找、愿意让谁记录、又拒绝谁替他们认定结局。

搜寻队把带回的物件摊在五张不同颜色的布上：人的随身物、粮袋残片、绳索、木箱碎片和井口泥样。每张布由不同人看守，开袋前先报编号和本人承接范围。队长想用一张路线图串起五类物件，许青棠在回执上划掉“同一现场”四字，改为“可能存在接触，尚无交接链”。改动由队长本人确认，不能算医官替他认定。

九名未归者的家属第二轮选择出现分歧。三户同意沿河搜，二户只同意查旧柴场，一户暂缓，剩余三户仍未询问。卫岑把三条路线分开派人，并要求每队归来时先交“未到之处”清单。陆昭提醒，搜寻队没有走到的地方不能被记作未见；他们只能写“本次未进入”，给下一班人留出反证入口。

夜里木箱再响时，守棚者没有立即开箱。他先让箱主和两名见证者各自选择是否承接开箱风险，药吏在旁记录手套、灯油和箱盖受潮程度。开箱后青白砂比前次少一撮，可能被风带走，也可能粘在木缝，无法据此判断箱内曾有尸骨。陆昭听完回报，左手麻意加重，主动把数量复核交给文吏。
